# 구현 범위 전체 검수 및 정착지 응급 처치 — 2026-09-23

## 검수 범위

현재 구현된 시작/설정/새 게임, 대원 선택, 세 정착지 선택, 정착지 시설, 개인 가방/창고, 대원 목록 페이지, 작업/시간 진행, 출발 준비, 방 이동, 수색 후보와 도구 지원, 귀환 정산, 재방문, 전투 진입/승리 후 탐험 복귀를 대상으로 한다. 새 방·저장/불러오기·전투 최종 밸런스가 완료됐다는 뜻은 아니다.

실행 증거: `AgentScripts/review-results.jsonl`. 실패 및 재검증 이력을 모두 보존한다. 초기화용 `VerifySettlement.Flow`는 테스트마다 새 캠페인을 구성한다. 대원 부상/장소 확률/재료를 주입한 테스트는 런타임 검수용이며 신규 게임의 시작 데이터에 적용하지 않았다.

## 수정한 문제

- 복도 안내문: 두 줄에서 높이 초과. ExpeditionArrivalPanel의 Status를 24pt/높이72로 보정했다. `FixArrivalStatus.Run`으로 재적용한다.
- 출발 준비 체크리스트: 항목 사이 이중 개행으로 마지막 빈 공간 수치가 잘림. 세 항목을 단일 개행으로 구성했다.
- 예전 검증 기준: 방 이동이 시간 0이라는 테스트를 현재 1턴=10분과 일치시켰다. 수색 후보 스크롤은 현재 기본 목록이 짧아 넘치지 않으므로, 임시로 후보를 늘려 스크롤을 검사하고 원본을 복원한다.

## 다음 단계: 정착지 응급 처치

이미 있는 창고/개인 가방의 `사용` 버튼을 천 조각의 `응급 처치`로 연결했다. 원화와 UI 패널은 새로 만들지 않았다.

임시 수치: 천 조각 2개를 선택한 보관 위치에서 소비하고 선택 대원의 체력 1을 최대치까지 회복하며 10분이 흐른다. 같은 시간 동안 다른 대원의 거점 작업도 진행된다. 아이템 데이터의 Recovery, UseCost, UseMinutes로 조정한다.

창고에서 선택하면 공용 창고 재료만, 개인 가방에서 선택하면 그 대원의 재료만 사용한다. 제작 예약 재료는 제외한다. 체력 만충/행동 불능/작업 중/재료 부족/수량 이동 확인창에서는 처치할 수 없다. 불가 상태의 클릭은 시간과 재료를 소비하지 않는다. 부활, 원정 중 치료, 치료 전용 직업 보너스는 미구현이다.

설명에는 소모량·시간·회복 전후 체력을 보여준다. 처치 후 하단 안내와 활동 기록에 결과를 남긴다. 일러스트는 기존 천 조각을 그대로 사용하며 새 PSD는 만들지 않았다. 수정 단위는 InventoryPanel.prefab과 실제 Unity Text다. `ConnectFirstAid.Run`으로 연결을 재적용한다.

## 남은 제작 작업

연결 방 확장과 신규 배경, 지속 저장/이어하기는 아직 남아 있다. 정착지 응급 처치는 비전투 생활 기능의 첫 연결이며 조리/정수/방문자까지 완료한 것은 아니다.

## 검수 결과

시작/설정/새 게임, 대원 선택 및 7후보 페이지, 3개 정착지 선택, 6명 정착지 HUD 페이지, 창고 수량 이동/예약 보호, 제작·휴식 병행/날짜 변경, 출발 준비, 방 왕복과 시간, 손전등 전달/수색 보정, 수색 미리보기와 확장 목록 스크롤, 귀환 정산/재방문, 전투 승리 후 탐험 복귀 검사가 통과했다. 오류 2건(복도 안내, 짐 체크리스트)은 수정 후 해당 검사를 다시 통과했다. 전투 결과 검수는 연결 유지 목적이며 최종 재미/밸런스 검증은 아니다.

응급 처치 검증도 통과했다. 만충·행동 불능·작업 중·수량 이동 중 거절, 창고/가방 각각 소비, 예약 재료 보호, 타 대원 비변경, 회복 최대치, 비용과 시간, 결과 안내를 확인했다. `first-aid-ready.png`, `first-aid-result.png`를 캡처하여 그림과 글자 배치를 확인했다. 기존 기능 검수에 더해 응급 처치까지 구현했으며, 저장/새 방/전체 콘텐츠 완성을 뜻하지 않는다.

# UI 폰트 변경 — 2026-09-23

- 사용자 제공 한글 서체 `Assets/funflow_font/TWD-AS_FUNFLOW SURVIVOR_Font/펀플로 생존자.ttf`를 공통 UI 폰트로 사용한다.
- UI 프리팹, 게임 씬, 화면 생성 스크립트의 폰트 참조를 변경했다. TitleViewport와 NightRunView에도 직렬화된 FontOverride를 연결한다.
- 자체 굵기를 사용하도록 FontStyle.Normal을 적용한다. 기존 UI 위치를 유지하고 폰트의 높은 글자 높이에 맞춰 텍스트 크기를 줄였다.
- 화면을 생성하는 AgentScripts 작업 후 Play를 중지한 상태에서 ApplyFunflowFont.Run을 실행하여 폰트와 텍스트 영역 맞춤을 다시 적용한다.
- Unity Editor 검증: VerifySettlement.Flow 통과. 대원 선택→거점 선택→정착지, HUD와 대원 설명 팝업 글자 영역 및 버튼 동작 확인. VerifyEncounter.Preview 통과, 조우 선택 화면 텍스트 영역 확인.
- 실제 화면: Assets/Screenshots/Settlement/funflow-settlement.png, funflow-encounter.png.
- 실행 파일 빌드는 하지 않았다. 향후 새로운 동적 문구를 추가하면 해당 문구의 줄바꿈도 확인한다.

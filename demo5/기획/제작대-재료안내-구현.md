# 제작대 재료 안내 — 2026-09-23

제작대 오른쪽 빈 공간에 재사용 가능한 CraftMaterialGuide 프리팹을 추가했다. 필요한 재료 행을 누르면 안내 대상이 바뀐다. 처음에는 부족한 재료를 우선 표시하며 제작 수량 변경 시 필요/부족 수량을 갱신한다.

- 개인 가방에 있으면 보유량을 안내하고 그 대원의 가방으로 이동한다. 창고로 옮기는 행동은 기존 수량 이동 UI를 사용한다.
- 제작 가능한 재료이면 제작법으로 전환한다. 사용 가능한 기존 담당자 선택은 유지한다.
- 현재 폐상가 수색 후보에 포함된 재료이면 원정 계획을 연다. 자동 출발하거나 대원을 강제 선택하지 않는다. 획득을 보장하지 않는다.
- 재료가 충분하거나 시설이 완료/진행 중이면 안내 버튼을 비활성화한다.
- 안내/화면 이동으로 시간·아이템·제작 예약을 변경하지 않는다. 예약 중인 창고 재료는 사용 가능 수량에서 제외한다.

현재 폐상가 한 장소의 수색 상태와 남은 물자를 안내한다. 다른 미구현 지역의 획득처와 지속 퀘스트 추적은 포함하지 않는다.

편집: Assets/Prefabs/Settlement/CraftMaterialGuide.prefab, CraftWorkPanel.prefab, CraftCostRow.prefab. 프리팹 연결 재적용은 BuildMaterialGuide.Run. 기존 정렬 스크립트 후 적용한다.
이미지: 기존 종이를 재사용했다. 아트/재료안내-v1/PSD/material-guide.psd는 패널/버튼 2개 레이어이며 동적 아이콘과 글자는 Unity에서 편집한다. 원본 픽셀을 함께 보존했으며 배치용 확대는 디테일 복원이 아니다.
검증: VerifyMaterialGuide.Flow — 실제 재료 행 클릭, 수량 갱신, 담당자 유지한 제작법 이동, 가방 이동/입고, 원정 계획 이동, 시간/물자/예약 비변경, 문구 높이를 검사한다.

검증 통과: 재료 행 클릭, 제작 수량에 따른 부족 수량, 제작법 이동 시 담당자 유지, 가방 정리 후 실제 입고, 원정 계획 이동, 안내만 열었을 때 시간·물자·예약 비변경, 글자 높이. 나무 판자는 현재 수색 데이터에 없어 미확인으로 표시하며 천 조각으로 실제 원정 연결을 검증했다. 나무 판자 획득처 추가는 향후 연결 방 확장에서 해결할 항목이다.

후속 변경: 낡은 탁자 수색에 나무 판자 후보가 추가되어, 이제 판자도 원정 계획으로 안내한다. 이전의 미확인 표시는 당시 데이터 상태이며 현재는 해결되었다. 상세는 탁자-나무판자회수-구현.md 참조.

## 수색 이력 반영 — 2026-09-23

- 미착수/진행 중인 후보는 미완료 수색 장소 수로 표시한다. 아직 찾지 않은 물자의 실제 획득량을 미리 공개하지 않는다.
- 완료한 수색 대상에 남은 해당 물자는 정확한 합계로 표시한다. 원래 드롭 목록에 없더라도 플레이어가 현장에 두고 온 물자는 포함한다.
- 후보를 모두 확인했고 남겨둔 물자도 없으면 안내 버튼을 비활성화한다. 다른 목적의 원정은 기존 원정 화면에서 계속 가능하다.
- 가방 보유분과 제작 가능한 재료의 안내 우선순위는 유지한다.
- 조회는 수색 상태를 생성하거나 보상을 추첨하지 않는다. 시간·창고·난수 상태도 바꾸지 않는다.
- 이력은 현재 실행 세션 기준이다. 종료 후 저장/복원은 별도 미구현 항목이다.

검증: VerifyRemainingMaterials.Flow 통과. 미착수/부분 진행/남은 물자/고갈/현장에 두고 온 다른 물자의 상태를 런타임 테스트 데이터로 구성해 안내와 실제 원정 계획 버튼, 재개방, 문구 높이, 시간·난수·창고 비변경을 확인했다. 실제 확률 수색과 입고 연결 검증은 앞선 VerifyWoodSalvage에 기록되어 있다.

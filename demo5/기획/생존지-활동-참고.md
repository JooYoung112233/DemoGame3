# 생존지 활동 — This War of Mine 참고

2026-09-21 사용자 지시: 생존지 내부 활동은 This War of Mine을 참고한다. 기존 승인 종이 화풍은 유지하고, 게임 규칙과 시설 목록은 아래 제안을 바탕으로 사용자와 순차 확정한다. 이번 작업은 조사·기록이며 코드나 원화는 수정하지 않았다.

## 참고한 핵심

개발사 공식 소개는 낮에는 거점 유지·제작·거래·생존자 돌봄, 밤에는 외부 수색이라는 주기를 설명한다. 우리에게 적용할 핵심은 밖에서 확보한 물자를 안에서 소비·가공·투자하고, 다시 다음 탐험을 준비하는 연결이다. 원작의 실시간 진행이나 낮 외출 제한까지 채택한 것은 아니다.

## 우리 게임 적용 제안 — 아직 세부 확정 아님

| 클릭 오브젝트 | 가능한 활동 제안 | 연결되는 선택 |
| --- | --- | --- |
| 침대 | 수면, 부상자 안정 | 누구를 쉬게 하고 누가 일할지 |
| 조리대 | 식사 만들기, 식량 배분 | 재료·물·연료를 지금 쓸지 보존할지 |
| 작업대 | 도구 제작, 장비 수리, 시설 개선 | 다음 수색 도구와 거점 개선 중 투자 우선순위 |
| 물통·정수 장치 | 물 정리, 정수 | 식수·조리용 물 확보 |
| 구급함 | 약·붕대 사용, 치료 담당 지정 | 약품을 아낄지 다음 탐험을 위해 회복할지 |
| 출입문·창문 | 보강, 경계 담당 지정 | 자재·인력을 방어에 투입할지 |
| 라디오·방문자 문 | 정보 확인, 거래·도움 요청 이벤트 | 물자 부족이 새 탐험 목적과 선택으로 이어짐 |

공통 UI는 오브젝트 선택 → 작업·담당자 지정 → 시간·소모·결과 확인 → 실행. 원작의 항목을 전부 첫 버전에 넣지 않는다. 우선 침대·조리대·작업대·보관함을 기본으로 검토하고, 치료·정수·거래·방어는 순차 확정한다. 보관함의 단순 조회·장비 확인과 실제 시간이 드는 작업을 구분한다.

특성이 있는 캐릭터는 동일 작업의 시간·소모·효율에서 차이가 나도록 검토한다. 캐릭터 두 명이 하는 작업의 동시 진행, 시간 진행 단위, 중단·예약, 기습과 거점 방어 규칙은 아직 정하지 않는다.

## 리소스 영향

승인한 생존지에는 이미 침대·작업대·물통·보관함·출입구가 있다. 이 물체를 우선 상호작용 후보로 활용한다. 조리대나 구급함 등 새 소품은 사용자와 활동을 확정한 뒤 별도 제작한다. 활동 제안을 이유로 승인된 전체 배경을 재생성하거나 가구를 임의로 이동하지 않는다.

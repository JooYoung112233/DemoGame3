# 탐험·분리 전투 시제품 — 2026-09-21

## 실행

Unity 6.6에서 `Assets/Scenes/NightExpedition.unity`를 열고 Play.
모험가 2명 → 정착지 선택 → 폐상가 수색 출발. 바로 전투가 시작되던 기존 UI 흐름을 탐험 시작으로 교체했다.

- 장면의 물자 상자 / 자판기 아래 / 보관함 표식을 선택한다.
- 하단 왼쪽 카드로 수색 담당자, 오른쪽에서 빠름·보통·정밀과 동료 역할을 고른 뒤 수색한다.
- 첫 수색은 안전하다. 이후 행동 완료 시 시간·소음에 따라 확률 조우. 수색도와 보급품은 즉시 기록된다.
- 손전등은 시제품에서 두 번째 선택 대원이 가지고 시작한다. 그 대원이 지원하고 배터리가 있어야 조명 지원 가능. 실제 장비 인벤토리·교환은 미구현이다.
- 조우 후 교전 또는 회피. 전투판은 양 진영 3×3, 자기 차례에 인접 빈칸으로 이동 1회와 공격/방어 1회. 근접은 전열만, 사격은 탄약 1 소비. 적을 클릭해 공격한다.
- 아군 둘이 행동하면 적 차례. 승리·도주 후 같은 장소 탐험으로 복귀. 부상·탄약·수색 진척 유지.
- 탐험 중 귀환하면 정착지 보급품과 대원 상태에 반영. 전멸 시 원정 실패.
- 왼쪽 아래 ‘전투 시연’은 확률을 기다리지 않는 검수 버튼이다. ‘전투판 3×3 · 변경’으로 4×3 확인 가능. 정식 게임에서의 보드 확장 조건은 아직 연결하지 않았다.

## 수치 및 미구현

빠름 5분 / 보통 10분 / 정밀 18분, 역할별 단축. 정찰수는 빠름, 운반꾼은 보통, 사수는 정밀에서 3분 단축하며 경비원은 망보기 효과가 크다. 전부 임시 밸런스다. 수색 장소당 보급품 2개로 유한하며 수색도가 100%면 남은 물자를 정산한다. 정밀 수색의 전용 단서나 다양한 아이템 분류는 아직 없다.

For The King II를 참고한 양 진영 분리·위치 변경·개별 차례 구조만 간단 구현했다. 속도별 행동 순서, 판정 슬롯, 무기 스킬, 상태이상, 엄폐 효과, 적 종류별 AI, 공격 모션과 효과음, 세이브는 미구현이다. 탐험 중 배터리는 조명 지원에서만 소비한다.

## 리소스

- 배경: `Assets/Art/Backgrounds/arcade-unlit-v1.png`, `shelter-unlit-v2.png` (기존 1672×941 원본 유지).
- 캐릭터: `Assets/Art/Tokens/*-body.png` (기존 승인 그림에서 분리한 작은 시안용 이미지). 여전히 고해상도 최종 자산이 아니며 실루엣 2종을 4개 후보가 공유한다.
- 흰 받침대: `Assets/Art/Tokens/base-white.png`, 색상은 WorldStage에서 지정. URP Sprite Lit 유지.
- 기존 말 프리팹: `Assets/Prefabs/NightRun/TintableStandee.prefab`.
- 신규 전투판 UI: `Assets/Prefabs/Exploration/FormationTile.prefab` + `FormationTile.cs`. 벡터 메시여서 확대해도 래스터 해상도에 묶이지 않는다.
- 신규 종이 표면 UI: `Assets/Prefabs/Exploration/PaperGrain.prefab` + `PaperGrain.cs`. 절차적 입자 표현이며 원본 시안의 종이 질감을 완전히 재현한 최종 원화는 아니다.
- 화면 조립: `VisitView.cs`. 전체 화면을 평면 이미지로 굽지 않고 UI와 바닥판, 말, 배경을 별도로 렌더링한다. 개별 화면 구성 전체가 편집용 프리팹으로 변환된 상태는 아니다.

## 검증

`AgentScripts/VerifyVisit.cs`의 Rules: 27개 검증 통과. 첫 안전 수색, 확률 조우, 고갈, 조명 지원, 3×3/4×3, 이동 제한, 빗나감 탄약 소모, 승리·패배·귀환·중복 보상 방지.
UI: 18개 검증 통과. 실제 버튼으로 모험가 선택 → 정착지 → 수색 → 조우 → 이동 → 사격.
실행 파일 빌드 없이 Unity Editor에서 확인했다. 이전 `VerifyPrototype.PlayThrough`는 구형 공용 4×4 UI용 테스트로 현재 흐름에 사용하지 않는다.

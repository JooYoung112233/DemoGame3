# 정착지 성장과 생활 특성

2026-09-23 사용자 지시를 반영한 기획 문서. **이번 작업은 문서만 작성하며 Unity 코드·프리팹·밸런스 데이터는 변경하지 않는다.** 아래 확정 방향과 세부 제안을 구분한다.

## 1. 확정 방향

- 누가 요리하느냐에 따라 속도 또는 자원 활용 효율에 차이가 난다.
- 시작 시 사용할 수 있는 정착지 내부 시설은 모두 1레벨의 기본 기능을 가진다. 시설을 업그레이드하며 생활 기능을 성장시킨다.
- 초기 개방된 1층 기본 구역의 최대 정착민은 **3명**이다. 기존 2명 선택 시작은 유지하며 처음에는 한 명의 여유가 있다.
- 더 많은 사람을 수용하려면 옆방이나 계단으로 연결된 추가 구역을 해금한다.
- 시설 성장과 공간 확장을 다음 탐험·파밍의 목적으로 연결한다.
- 이번에는 기획만 반영한다. 현재 조리 UI는 여전히 시안 재고를 사용하는 미리보기다.

‘1층까지 3명’은 초기 1층 기본 구역의 한도로 해석한다. 같은 층의 옆방도 별도의 잠긴 확장 구역으로 취급한다. 층 하나마다 무조건 3명씩 더하는 규칙은 두지 않는다.

## 2. 성장의 두 축

| 성장 | 하는 일 | 늘어나는 것 | 늘어나지 않는 것 |
| --- | --- | --- | --- |
| 시설 업그레이드 | 조리대·작업대·침대 등 개선 | 작업 효율, 가능한 작업·조리법 | 정착민 수용 한도 |
| 공간 확장 | 옆방·계단·상층 방 개방 | 시설 배치 공간, 거주 가능한 방의 수용 인원 | 기존 시설의 레벨 |

침대를 고급으로 바꾸는 것만으로 정착민 한도가 늘어나지는 않는다. 계단을 뚫는 것만으로도 인원이 늘어나지 않는다. **연결된 거주 구역을 사용할 수 있게 만드는 것**이 수용량 증가 조건이다.

## 3. 요리 담당자의 차이 — 세부 제안

누구나 기본 조리는 가능하다. 요리 특성이 없는 대원을 실패시키거나 특정 직업 없이는 먹지 못하게 하지 않는다. 담당자를 고르는 즉시 재료·인분·시간을 다시 보여준다.

| 특성 예시 | 효과 제안 | 플레이 선택 |
| --- | --- | --- |
| 빠른 손 | 조리 시간이 기본보다 20% 짧음 | 출발 전에 급하게 식사를 준비 |
| 알뜰한 조리 | 지정된 여러 인분 조리법에서 같은 재료로 1인분 추가 | 식재료가 부족하거나 정착민이 많을 때 유리 |
| 기본 조리 | 기본 시간과 기본 인분 | 전문 대원을 원정이나 다른 작업에 배정 가능 |

특성 이름·20%·추가 1인분은 밸런스 검토용 예시이며 확정 수치가 아니다. 첫 구현에서는 한 대원이 속도와 추가 인분을 모두 독점하지 않도록 역할을 나눈다. 별도 요리 숙련도/경험치 시스템은 아직 확정하지 않는다.

### 적용 범위와 중첩

- 조리 특성은 조리법에 명시된 작업에만 적용한다. 통조림 개봉이나 도시락 포장만 반복해서 음식을 불릴 수 없다.
- 알뜰한 조리는 ‘남은 음식 환급’이 아니라 해당 조리법의 명시된 추가 산출량이다. 완성 음식으로 같은 음식을 재생산하는 순환 조리법은 만들지 않는다.
- 재료와 인분은 정수로 표시한다. 소수 재료 할인 대신 추가 인분 방식부터 검토해 이해하기 쉽게 한다.
- 시설 보너스와 담당자 보너스는 별도 항목으로 보여준다. 속도는 곱연산 후 최종 시간만 한 번 반올림한다. 작업 중 담당자·시설이 바뀌어도 예약 시 확정한 조건을 몰래 바꾸지 않는다.
- 시간 예시: 기본 30분 × 빠른 손 0.8 × 시설 0.9 = 21.6분. 5분 단위 올림을 채택한다면 최종 25분이다. 반올림 단위도 후속 시간 설계에서 확정한다. 0분 간편식은 속도 보너스로 음수가 되지 않는다.
- 같은 대원은 원정·휴식·제작·조리·시설 공사 중 하나에만 배정한다. 전문 요리사를 원정에 데려가면 그동안 거점의 조리 이점도 포기한다.

## 4. 시설 레벨 — 1~3레벨을 우선 검토

모든 시작 시설은 1레벨에서 사용할 수 있다. 2·3레벨과 아래 효과는 제안이며 최대 레벨은 아직 확정하지 않는다. 아직 존재하지 않는 시설도 설치하면 1레벨부터 시작한다. 잠긴 구역에 보이는 물건은 사용 가능한 시작 시설로 세지 않는다.

| 시설 | 1레벨 기본 | 2레벨 제안 | 3레벨 제안 |
| --- | --- | --- | --- |
| 조리대 | 기본 식사·도시락 준비 | 여러 인분 조리법 확장 | 더 적은 연료를 쓰는 상위 조리법 |
| 작업대 | 기본 도구·보수 재료 제작 | 확장 공사에 필요한 부품 제작 | 고급 생활 도구와 시설 개선 재료 |
| 침대·휴식 시설 | 기본 휴식과 회복 | 같은 시간의 회복량 개선 | 회복 시간 또는 치료 연계 개선 |
| 공용 창고 | 기본 보관·입출고 | 정리 설비와 보관량 확장 | 더 많은 보관량과 분류 기능 |
| 물 처리 시설 — 후속 후보 | 기본 정수 | 한 번에 처리하는 물 증가 | 처리 시간 또는 연료 개선 |

창고의 실제 공용 용량 제한과 정수 기능은 아직 미확정/미구현이다. 이 표를 이유로 지금의 창고를 갑자기 제한하거나 기존 물자를 삭제하지 않는다. 출입구·계단 같은 이동 연결은 시설 레벨 대신 잠금/개방 상태로 관리한다.

### 업그레이드 흐름

시설 선택 → 현재 레벨과 다음 효과 비교 → 재료·담당자·공사 시간 확인 → 공사 예약 → 시간 진행 → 완료 후 새 효과 적용.

- 시설 자체의 `개선` 항목에서 진행한다. 제작대는 필요한 공사 재료를 만드는 역할도 가진다.
- 목재·못·고철·천 등 기존 파밍 재료를 먼저 쓰고, 특정 부품이 필요하면 획득처를 안내한다. 정확한 비용과 소요 시간은 미정이다.
- 공사 중 해당 시설은 새 작업을 받지 않는다. 진행/예약 작업이 있다면 먼저 완료하거나 명시적으로 취소해야 한다. 다른 시설의 작업은 계속된다.
- 같은 시설의 중복 업그레이드와 단계 건너뛰기를 막는다. 예약 재료는 다른 작업에서 쓸 수 없다.
- 초기 공사 취소는 기존 제작 규칙처럼 예약 재료 전부 반환을 기본안으로 한다. 이미 보낸 시간은 되돌리지 않는다. 완료 효과는 한 번만 지급한다.

## 5. 공간 해금과 수용량

초기 **2명 거주 / 최대 3명**. 원정 중인 대원도 정착민에 포함한다. 동시 휴식 자리 수, 원정 출발 인원, 정착민 최대 인원은 서로 다른 값이다.

아래 수용량 증가는 성장 흐름을 설명하는 예시이며 초기 최대 3명 외의 수치는 미확정이다.

| 단계 | 해야 할 일 | 수용 한도 예시 |
| --- | --- | --- |
| 초기 1층 기본 구역 | 기본 시설 1레벨 이용 | 3명 — 확정 |
| 옆방 거주 구역 | 막힌 문 개방 → 잔해 정리 → 거주 준비 | +2명, 합계 5명 |
| 계단 연결 | 계단의 통로 수리·정리 | 증가 없음 |
| 상층 거주 구역 | 계단 개방 후 방을 정리하고 거주 준비 | +2명, 합계 7명 |

각 정착지의 모습이 달라도 시작 한도는 3명으로 맞추는 안이다. 이후 확장 경로와 방별 용도는 배경에 맞춰 별도 설계한다. 모든 정착지에 같은 층수를 강요하지 않는다.

### 방 상태와 조건

`잠김 → 연결/진입 가능 → 정리 중 → 사용 가능`으로 구분한다. 거주 준비를 마친 방만 수용량에 더한다. 계단과 복도는 이동 공간이므로 기본 수용량 0이다. 작업실·창고 같은 비거주 방도 사람 수를 늘리지 않는다.

- 방/계단 오브젝트를 누르면 연결 구역, 필요한 선행 공사, 재료, 시간, 완료 후 효과를 보여준다.
- 일부 확장은 먼저 도구를 만들어야 가능하도록 탐험과 연결한다. 특정 희귀 재료가 없어서 초반이 영구히 막히는 구조는 피한다.
- 거주 공간 확대와 시설 개선은 서로 다른 투자다. 동료를 더 받을지, 현재 인원의 생활 효율을 올릴지 선택한다.
- 수용량이 찼을 때 영입 확정은 막고 부족한 자리와 확장 경로를 안내한다. 방문자 대화·거래까지 막지는 않는다. 대기/재방문 방식은 NPC 기획에서 정한다.
- 방문자는 정식 영입 전까지 정착민 수에 포함하지 않는다. 여러 영입이 겹칠 때 최종 수락 시 남은 자리를 다시 확인한다.
- 방 해금으로 인원이 자동 충원되지는 않는다. 새 정착민 합류는 별도 이벤트다.

## 6. 초반 성장 예시

1. 두 명으로 시작해 기본 식사를 준비하고 첫 원정을 나간다.
2. 요리에 강한 세 번째 대원을 만나면 영입과 식량 부담을 함께 판단한다.
3. 목재·못을 생활 시설 개선에 쓸지 옆방 개방에 쓸지 선택한다.
4. 옆방을 거주 가능하게 만들어 다음 영입 자리를 확보한다.
5. 사람이 늘면 필요한 식사도 늘어 조리대 업그레이드와 전문 담당자의 가치가 커진다.
6. 상층 진입을 위해 도구·부품을 구하며 새로운 탐험 목적을 얻는다.

순서와 이벤트는 예시다. 세 번째 대원 영입이나 시설 전체 업그레이드를 일일 필수 숙제로 만들지 않는다. 추가된 인원은 작업 분담이라는 이점과 생활 소비라는 부담을 함께 만든다.

## 7. 후속 UI와 구현 기준 — 이번에는 구현하지 않음

- 조리 담당자 행에 `빠른 손 · 시간 감소`처럼 해당 작업에 유효한 특성을 표시한다. 선택 시 기본 시간→최종 시간 또는 기본 인분→최종 인분을 비교한다.
- 시설 화면 제목에 레벨과 현재 효과를 표시하고 `개선`에서 다음 단계와 공사 조건을 확인한다.
- 정착민 표시를 `현재 인원 / 최대 인원`으로 분리한다. 기존 대원 목록 페이지 수를 수용 한도로 사용하지 않는다.
- 방과 계단은 기존 맵의 오브젝트 클릭 방식으로 연다. 잠금 사유와 실제 증가 인원을 표시한다. 현재 승인 배경의 전면 재생성은 별도 승인 없이 진행하지 않는다.
- 데이터는 시설 ID·레벨, 방 ID·연결·용도·상태·수용 증가량, 대원 특성 ID, 공사/조리 예약·예약 재료·남은 시간으로 나눈다. 표시 이름을 키로 삼지 않는다.
- 저장 시 시설/방 상태와 진행 중 작업을 함께 보존한다. 수용량은 사용 가능한 거주 구역으로 재계산하며 완료 효과를 중복 적용하지 않는다.
- 현재 `BedRepaired`, `BenchImproved` 단일 개선 상태를 이후 레벨 데이터로 이관해야 한다. 기존 효과를 중복 가산하거나 현재 데이터를 조용히 초기화하지 않는다.
- 개발 검수용 6명 대원 화면은 목록 확장 테스트였다. 초기 3명 규칙이 이미 게임에 구현되어 있다는 뜻이 아니다. 기존 저장의 초과 인원을 자동 추방하지 않고 영입 제한과 확장 안내로 처리하는 이관안을 별도로 마련한다.

후속 검수: 일반/전문 담당자 비교, 조리법 적용 범위, 수량별 정수 계산, 시설/대원 중복 배정, 공사 중 이용 제한, 취소·완료 중복 방지, 계단만 열었을 때 한도 불변, 거주 준비 완료 시 한 번만 증가, 원정 중 대원 포함, 3/3 영입 제한, 저장 복원.

# 튜토리얼 행동 안내와 시작 대원 제한

사용자 요청: 무엇을 눌러야 하는지 모르겠고 복잡한 튜토리얼을 다듬는다. 시작 대원은 2명만 보이고 다른 인물은 이후 만남·해금 대상으로 남긴다.

## 적용

- 새 게임 시작 대원은 윤서진(`scout`)·한해인(`medic`)이다. 두 사람은 미리 선택되고, 카드를 누르면 소개만 바뀐다. 불필요한 페이지 화살표와 나머지 네 인물의 카드·이름·초상을 숨겼다.
- `PartyCandidate.AvailableAtStart`로 시작 가능 여부를 분리했다. 시작 화면의 미리보기·선택·확정에서도 숨긴 후보를 거른다. 전체 명부는 유지하므로 기존 저장 대원과 방문자 영입은 계속 유효하다.
- 나머지 네 인물은 기존 방문자 시스템으로 만나 영입할 수 있다. 별도 계정 영구 해금이나 인물별 신규 퀘스트는 이번에 추가하지 않았다.
- 정착지에서는 왼쪽의 다음 행동 버튼을 유지하고, 휴식 단계에서는 침대 윤곽을 강조한다. 쉴 사람 선택 → 휴식 예약 → 다음 완료까지 → 시간 진행을 개별 클릭 단계로 안내한다.
- 팝업에는 종이 안내판과 클릭을 통과시키는 네 모서리 강조선을 추가했다. 창이 바뀌면 목표 버튼도 실제 상태를 보고 바뀐다. 숨겨진 내부 클릭 횟수를 저장하지 않아 저장 후 재개·창 닫기에도 현재 상태로 안내한다.
- 첫 원정의 목적지·두 사람 동행 선택·짐 확인·수색 담당자·수색 1턴·물품 수량·귀환을 안내한다. 짐 꾸리기/발견물 창은 하단 빈 공간에 안내를 놓고, 개인 가방은 대원 카드 오른쪽에 놓는다.
- 재료 정리 안내는 목표 레시피를 기준으로 한다. 창고가 차면 여분 물자를 가방으로 옮기고, 필요한 재료를 가진 대원과 해당 재료를 선택하도록 안내한다. 재료가 충분하면 복구로 넘어간다. 실제 재료가 부족하면 수색으로 안내한다.
- 처음부터 필요하지 않은 작업대·조리·방문자·거주 관리 진입을 점진적으로 표시한다. 안내 완료 뒤에는 안내판과 자동 강조가 사라진다.

## 검증

Unity 6.6 Play 모드에서 `VerifyTutorialClarity`로 검증했다.

- 시작 카드 2개, 숨긴 후보 직접 선택/미리보기 차단, 이름 클릭 시 선택 유지.
- 실제 화면 클릭으로 대원 확인 → 정착지 선택 → 첫 정착 → 휴식·시간·보관함 → 첫 원정 준비. 두 사람 모두 동행 선택.
- 도입 2단계에서 임시 디스크 저장·불러오기 후 올바른 다음 버튼으로 재개.
- 첫 수색, 실제 발견물 이동, 귀환, 다음 복구 목표.
- 귀환 후 안내된 버튼만 따라 창고·작업대 복구와 관리표 확인까지 진행(검수 상태 기준 27클릭).
- 재료 부족 시 수색 유도. 시작에서 숨긴 정비공의 실제 방문자 영입 및 불러오기 후 보존. 완료한 안내 재등장 없음.
- 안내 제목·본문 높이 검수와 실제 Unity 캡처. 검수 데이터는 `Temp/TutorialClaritySave`만 사용했다. 사용자 저장 슬롯은 쓰지 않았다.

원본 화면은 `Assets/Screenshots/TutorialClarity`에 있다. 구현은 `SettlementTutorialGuide` 및 기존 도입 컴포넌트, 프리팹 편집은 `AgentScripts/BuildTutorialClarity.cs`로 재현한다.

## 다음 범위

두 번째 탐험의 장소 판·괴물 대응 교육은 전투/탐험 담당 흐름을 유지하며 새 안내를 붙이지 않았다. 인물별 만남 퀘스트와 영구 시작 해금은 후속 콘텐츠다.

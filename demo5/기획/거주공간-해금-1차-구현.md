# 거주 공간 해금 1차

2026-09-23. 정착지 상단 **거주 공간 · 현재 / 한도** 버튼에서 옆방 공사를 관리한다. 기존 제작대 개선 화면·담당자·재료 안내·예약/취소 시스템을 재사용한다. 실제 옆방 이동 화면이나 영입 이벤트까지 완성한 것은 아니다.

## 상태와 임시 비용

| 단계 | 공사 | 비용 / 기본 시간 | 수용 한도 |
| --- | --- | --- | --- |
| 초기 | 없음, 옆방 잠김 | 없음 | 3명 — 기존 확정 방향 |
| 통로 연결 | 옆방 통로 연결 | 나무2·고철2 / 45분 | 3명 유지 |
| 거주 준비 중 | 연결된 옆방 정리 | 나무4·천3·못2 / 90분 | 3명 유지 |
| 사용 가능 | 거주 준비 완료 | 예약 재료 실제 소모 | 5명 — 추가2명은 임시값 |

통로가 연결되지 않으면 거주 준비를 예약할 수 없다. 통로 공사만 마치거나 거주 준비가 진행 중인 동안에는 한도를 늘리지 않는다. 각 단계의 취소는 해당 예약만 해제한다. 이미 완료한 통로 연결은 이후 거주 준비를 취소해도 유지한다. 같은 단계 중복 예약/재완료를 막는다. 담당자 중복과 재료 예약 보호는 기존 제작 규칙을 따른다. 작업대 Lv.2의 기존 시간 단축은 방 공사에도 적용된다.

정착민은 원정 중인 사람도 포함한다. 공간을 열어도 사람이 자동 생성되지 않는다. 현재/최대 표시는 상단 진입 버튼과 대원 목록 제목에 반영한다. `CanAcceptResidents(count)`는 추가 인원을 수용할 여유가 있는지 확인하는 공통 조건이며 실제 영입 이벤트 연결은 후속이다. 기존 저장의 인원이 한도를 초과하더라도 삭제/추방하지 않고 그대로 표시한다.

## 데이터와 편집

- `SettlementHousing.cs`: 연결/준비 완료 상태, 수용량 계산, 입주 여유 조건, 진입 버튼.
- `SettlementFacilityRules.cs`: 선행 조건과 상태/효과 설명.
- `CraftWorkPanel.prefab`: `open-side-room`, `prepare-side-room`의 비용/시간, `SideRoomPlaces` 추가 인원.
- `SettlementScreen.prefab`: 상단 거주 공간 진입 버튼. 기존 배경/시설 배치는 유지했다.
- 저장 버전 6: `SideRoomConnected`, `SideRoomReady`와 진행 중 공사·남은 시간·예약 재료 보존. 수용량은 완료 상태로 계산하고 누적 저장하지 않는다. v1~v5 기록은 방 미해금으로 이관하며 기존 주민과 시설 기록은 유지한다.
- 준비 완료인데 연결이 없거나, 선행 단계 없이 준비 공사가 예약되어 있거나, 이미 완료한 공사가 다시 예약된 저장은 거절한다.

## 검증

`VerifySettlement.Flow`, `VerifyHousing.Flow`, `VerifyHousing.Restart` 통과. 실제 raycast 클릭으로 두 공사, 선행 조건 차단, 중간 취소, 예약 재료 보호, 정확한 재료 소비, 완료 중복 방지, 단계별 표시를 확인했다. 재료20 지급은 검수 런타임 전용이며 새 게임 재고는 그대로다.

진행 중 75분이 남은 거주 준비를 별도 `Temp/HousingVerification`에 저장하고 Play 종료/재시작 → 시작 화면 계속하기로 복원했다. 완료 후 2/5명 유지, 완료 상태 재저장/재로드도 확인했다. 원정 중 동료를 인원에서 빼지 않으며 2/3에서 추가1명, 2/5에서 추가3명까지만 허용하는 조건을 검사했다. 구버전 4명 저장은 4/3으로 그대로 보존한다. 최초 구버전 검수용 데이터가 귀환 기록과 대원 최대 체력을 불일치시켜 거절된 것은 테스트 데이터 수정 후 재검증했다.

컴파일 오류와 이번 작업의 새 Unity 오류 없음. 사용자 저장 슬롯에는 쓰지 않았다. 실행 파일 빌드는 생략했다.

## 화면과 한계

기존 승인 제작 화면과 최신 공통 팝업 프레임을 유지했다. 신규 그림을 생성하지 않고 기존 종이 버튼/집 아이콘/제작 목록을 재사용했다. 목록이 길어져 거주 공간 버튼에서 진입하면 해당 공사가 보이도록 스크롤한다. 글자 높이·상단 버튼 간격·담당자/비용/남은 시간과 하단 버튼을 실제 1920×1080 캡처로 검수했다.

- `Assets/Screenshots/Housing/capacity-ready.png`: 정착지 현재2 / 최대5.
- `Assets/Screenshots/Housing/room-ready.png`: 사용 가능·한도5·재공사 차단.
- `Assets/Screenshots/Housing/room-pending.png`: 거주 준비 중·남은75분·한도3→5 예고.

**후속 범위:** 실제 옆방 배경/이동, 계단·상층 확장, 정착지별 다른 공간 구조, 신규 주민 영입과 최종 인원 재검증, 생활 특성. 현재는 세 정착지에 같은 1차 옆방 규칙을 적용한다. 방 배치 원화나 전체 공간 확장이 완성됐다고 보지 않는다. 다음 기능 단위는 방문자 영입을 이 수용 한도와 연결하는 것이다.

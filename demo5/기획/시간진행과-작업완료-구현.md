# 시간 진행과 작업 완료

2026-09-23. 비전투 우선 제작의 첫 단계. 전투 규칙과 효과는 변경하지 않았다.

## 실제 연결

- 정착지 상단 시간 진행 → 15분/30분/1시간/다음 완료 선택 → 완료 예정 확인 → 진행. 돌아가기는 시간 소모 없이 닫힌다.
- 진행 중인 휴식과 제작은 같은 경과 시간만큼 병행된다. 제작이 끝나면 예약 재료를 한 번 소비하고 공용 창고에 결과물을 지급한다. 완성한 지렛대도 개인 가방으로 옮길 수 있다.
- 휴식이 끝나면 생존 대원의 최대 체력 범위 내에서 회복한다. 이미 휴식 중인 대원을 침대 화면에서 선택하면 중단할 수 있다. 중단은 회복을 지급하지 않으며 지난 시간은 되돌리지 않는다.
- 제작 취소는 아직 소비하지 않은 예약 재료를 해제한다. 부분 진행 이후 취소도 동일하다. 시설 수리/개선은 수량 1이며 동일 시설을 다시 완료할 수 없다.
- 왕복 이동과 탐험 턴도 같은 시계에 반영된다. 거점에 남은 작업이 이동·탐험 중 완료된다. 시간 흐름을 프레임이나 말의 이동 애니메이션에 연결하지 않는다.
- 완료 기록은 시간 진행 화면에서 최근 6건을 보여준다. 작업/기록이 길면 스크롤되며 아래 내용이 남을 때만 작은 화살표를 표시한다.

## 임시 수치와 한계

- 짧은 휴식 30분/체력 +1, 수면 120분/+3. `SettlementWorkPanel` Inspector에서 조정한다.
- 침대 수리 후 새로 등록하는 휴식은 회복 +1. 작업대 개선 후 새 제작은 소요 시간 20% 감소, 분 단위 올림이다. 진행 중 주문을 소급 변경하지 않는다.
- 탐험 1턴은 임시 10분이며 `ExpeditionRoomNavigation.MinutesPerTurn`에서 조정한다. 수색·이동·기존 전투 결과가 호출하는 탐험 턴에 한 번 적용한다. 전투 개별 행동에 추가 시간은 붙이지 않았다.
- 지렛대는 제작·보관·휴대까지만 연결했다. 잠금 해제 효과는 다음 탐험 콘텐츠 단계에서 구현한다.
- 캠페인 저장/복원, 장소 재방문 상태 보존, 식사·허기·피로, 상세 귀환 정산은 아직 미구현이다. 현재 작업 상태는 플레이 세션 안에서만 유지된다.
- 완료 기록 시각은 해당 시간 진행이 끝난 시각이다. 구간 내부의 분 단위 사건 타임라인은 아직 별도로 제공하지 않는다.

## 편집과 검증

- `Assets/Prefabs/Settlement/SettlementTimePanel.prefab`: 화면, 분 선택, 확인/돌아가기, 스크롤을 Inspector에서 편집한다. 하단 버튼 밑선은 1920×1080 기준 y=1050이다.
- `CampaignState.TimeAdvanced`: 공통 경과 시간 통지. `SettlementController`가 휴식/제작을 갱신한다.
- `AgentScripts/BuildSettlementTime.cs`: 기존 종이 자산으로 프리팹 조립. 전체 정착지 프리팹을 초기화하지 않는다.
- `아트/시간진행-v1`: 분리 레이어 PSD와 기존 PNG 원본, 배치 정보. 글자와 수치는 Unity Text로 편집한다.
- `VerifySettlementTime.Preview` → `Flow`: 실제 버튼의 입력 차단/클릭, 미리보기 닫기, 동시 진행, 조기/중복 보상 방지, 재료 정산, 지렛대 이동, 부분 취소, 원정 중 거점 작업, 탐험 시계, 휴식 중단, 자정 날짜 변경 통과.
- `VerifySettlementTime.Facilities`: 검증용 재료를 런타임에만 공급하여 시설 중복/수량 제한, 침대 회복, 15분 제작의 12분 단축, 긴 기록 스크롤 검증. 이 재료 수치를 프리팹 시작값에 반영하지 않았다.
- UI 연결도 H10 추가, 50개 노드/190개 연결 검증 통과. 실행 파일 빌드는 생략했다.

# 낡은 탁자 나무 판자 회수 — 2026-09-23

제작대 재료 안내에서 확인한 나무 판자의 획득처 공백을 기존 오락실의 낡은 탁자로 연결했다. 승인 배경·탁자 이미지·핫스폿·수색 UI는 그대로 사용한다. 새 방이나 새 원화를 제작한 것은 아니다.

- Sites[1]에 wood ×2, 기본 확률 75% 추가. 기존 천 조각/못 후보는 유지.
- 빠른/보통/정밀 수색 및 협력 보정은 기존 공식을 사용. 예: 정밀 +15%p, 동료 협력 +10%p를 합치면 100%가 된다. 이는 기본 확률이 100%라는 뜻이 아니다.
- 탁자 설명을 헐거운 판자와 주변 천/못을 회수할 수 있는 맥락으로 수정.
- 재료 안내는 실제 후보를 읽으므로 나무 판자를 원정 계획으로 연결한다.
- 기존 수색 완료/남은 발견물/재방문 상태를 사용. 수색 완료 후에는 다시 굴리지 않으며 가져간 판자는 같은 플레이에서 재생성되지 않는다.
- 판자 수량/확률은 SettlementScreen.prefab → ArrivalPanel → Loot → Sites[1]에서 편집한다(ExpeditionLootPanel.prefab 값은 덮어써진다). 2026-09-24 밸런스 1차부터 보상표와 설명[1]은 `BuildBalance1.Run`이 맡는다. ConnectWoodSalvage.Run은 기본 프리팹만 고치고 설명을 더는 쓰지 않는다. 기존 그림과 아이콘을 재사용하므로 새 이미지/PSD 파일은 추가하지 않았다.

공급처 하나를 연결한 단계다. 무한 공급, 새 방 확장, 종료 후 상태 저장은 미구현이다. 다음 방 확장에서는 판자 등 주요 재료를 얻는 추가 경로와 재방문 정책을 설계해야 한다.

검증 스크립트: VerifyWoodSalvage.Preview / Complete. 실제 UI로 제작대→원정 준비→탁자 수색→회수→귀환→창고 입고→제작 재료 갱신, 재방문 재지급 방지를 확인한다. 완료 검증 중 전투 발생만 임시 차단하고 원래 설정을 복원하며 수색 보상 확률은 조작하지 않는다.

검증 결과: Preview와 Complete 모두 통과. 실제 원정 준비에서 시작해 정밀/동료 협력 수색 3턴(30분), 판자 2개 회수, 귀환 입고 후 기존2+회수2=4개, 제작 필요량 반영을 확인했다. 같은 탁자를 재방문해도 판자가 재지급되지 않았다. wood-salvage-preview.png와 wood-salvage-stock.png를 직접 검수했다.

# 침대 윤곽 하이라이트 수정

사용자가 지적한 침대의 각진 다각형 강조선을 침대 두 개의 실제 외곽에 맞춘 선택 마스크로 교체했다.

- 기존 `shelter-unlit.png`(1672×941), 정착지 배경과 가구 그림은 수정하지 않았다. 침대 원화를 배경에서 분리하거나 새로 생성한 작업은 아니다.
- 베개, 이불 끝, 프레임, 다리를 따라 133개 편집 가능한 윤곽점을 정의하고 Unity 거리 마스크로 구웠다. 원본은 `AgentScripts/BuildBedSilhouette.cs`, 런타임 자산은 `Assets/Art/Settlement/SelectionMasks/Beds.asset`이다. PNG/PSD 원화 납품이 아닌 선택 효과용 Unity 자산이다.
- `SettlementFacilityFocus`의 선택 마스크와 `SettlementSilhouette` 셰이더로 얇은 윤곽과 부드러운 가장자리를 표시한다. 호버·키보드 선택·Alt에서 표시하고, 해제하면 사라진다. 캐릭터보다 뒤에서 그린다.
- 클릭 판정도 같은 마스크를 사용한다. 침대 사이 바닥과 침대 아래 상자는 잠자리 클릭에서 제외한다.
- 기존 시설 재빌더가 침대의 새 마스크 좌표를 예전 다각형 좌표로 덮어쓰지 않도록 보호했다.
- 적용 범위는 침대 두 개다. 다른 시설의 기존 윤곽은 이번 수정 범위에 포함하지 않았다.

## 검증

Unity 6.6 C# 컴파일 및 셰이더 오류 없음. 실제 Play 모드에서 양쪽 침대가 휴식 창을 열고, 베개·이불·다리는 클릭되며 빈 바닥과 아래 상자는 제외되는 것을 검사했다. 호버 해제, Alt 누름/해제, 팝업 중 숨김, 캐릭터 뒤 렌더 순서를 확인했다.

1920×1080, 1280×1024, 2560×1080에서 선택 마스크와 배경의 대응 좌표 차이가 1픽셀 미만인지 검사했다. 원래 Game View 해상도는 검수 후 복원했다. 테스트는 임시 런타임 상태로 진행했고 실제 저장 슬롯은 쓰지 않았다.

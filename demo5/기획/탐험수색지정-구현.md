# 탐험 수색 지정 — 2026-09-22

후속 구현: [수색 진행과 발견물 분배](수색진행과-발견물분배-구현.md). 현재 확인 버튼은 배정 저장 대신 실제 1턴 진행으로 연결된다. 아래는 배정 UI만 있던 이전 단계의 기록이다.

오락실 물자 상자·탁자·오락기를 누르면 왼쪽 수색 패널을 연다. 승인 UI07의 종이 질감과 선택 순서를 사용한다. 정착지 이동은 변경하지 않았다.

## 현재 연결

사물 클릭 → 빠름/보통/정밀 → 실제 원정대 중 담당자 선택 → 동료 역할 → 배정 확인 → 저장. 담당자가 없으면 확인 버튼이 비활성이다. 방식과 사물을 변경해도 유효한 담당자를 유지한다. 확인 취소는 저장하지 않고, 이미 저장한 사물을 다시 열거나 방을 왕복하면 해당 선택을 복구한다. 새 원정에서는 초기화한다.

담당자 목록은 가로 스크롤이다. 동료 역할은 나머지 생존 동료 전체에 적용하는 검토안이며 함께 수색/망보기를 선택한다. 혼자면 망보기를 선택할 수 없다. 손전등 소유·배터리 연동 전이므로 조명 지원은 비활성이다. 캐릭터별 수색 특성 보너스는 아직 적용하지 않는다.

빠름 1턴/보통 2턴/정밀 3턴과 소음 높음/보통/낮음은 기존 기획의 검토용 표시다. 실제 턴·소음·물자 소비는 없다. 저장값은 사물별 선택 프리셋이며 실행 중인 작업 큐나 인력 예약이 아니다. 여러 사물에 같은 담당자를 저장할 수 있고, 실제 실행 단계에서 작업 중복과 지원 역할 충돌을 검증해야 한다.

## 검증과 시안 비교

VerifySettlement.Flow, VerifySearch.Flow 통과. 실제 UI 클릭으로 미선택 제한, 담당자 유지, 장비 비활성, 확인 취소·저장, 중복 저장 방지, 사물 변경과 방 왕복 복원, 턴·시각 비소모, 텍스트 영역을 확인했다. 실제 캡처는 Assets/Screenshots/Settlement/search-v1.png. 캡처에서 발견한 기존 안내 겹침을 수정하고 재검증했다. 빌드하지 않았다.

UI07과 비교하여 왼쪽 패널·종이 버튼·노란 선택·실루엣 담당자를 유지했다. 현재 방 연결 HUD를 보존하며 패널 시작을 아래로 옮겼다. 좌하단 돌아가기 규칙을 우선했다. 실제 선택 대원 두 명만 표시하며 허위 수색도·조우 확률·손전등 잔량은 생략했다. 원본 시안과 완전히 동일한 화면이라고 보고하지 않으며 시각 승인 대기다.

# 최신 UI 변경 — 2026-09-24

사용자 최신 지시를 반영해 아래의 초기 양쪽 가방 비교 방식을 대체했다.

- 인벤토리 위에 동행 대원 이름 탭을 표시한다. 선택 시 초상, 이름, 직업, 체력 칸, 상태, 특성, 습관·약점, 개인 가방이 함께 바뀐다.
- 가방은 하나만 표시한다. 물품 선택 → 수량 지정(기본 1개) → 받을 동료 이름 클릭으로 즉시 전달한다. 별도 전달 확인 버튼과 좌우 가방 선택은 제거했다.
- 사용 가능한 물품에만 대원 이름·행동이 적힌 사용 버튼을 표시한다. 예상 회복, 물품 소모량, 시간과 불가 사유를 함께 표시한다.
- 자기 자신은 받는 목록에서 제외한다. 인원이 많으면 이름 탭과 받는 목록을 스크롤한다. 혼자일 때는 동료 없음 안내를 표시한다.
- 기존 공통 제목, 강한 딤과 HUD 숨김, 좌측 하단 돌아가기 위치를 유지한다. 체력은 칸으로 표시한다.

구현: `ExpeditionBagPanel.cs`, `ExpeditionBagPanel.prefab`, `FieldBagOwnerTab.prefab`, `FieldBagRecipient.prefab`.
`BuildTabbedFieldBags.cs`는 기존 양쪽 가방 프리팹에서 전환한 일회성 마이그레이션 기록이다. 현재 프리팹이 편집 원본이며 기존 `BuildFieldBags` / `RedesignFieldBags` 재실행으로 덮어쓰지 않는다.

검증: Unity 컴파일 완료. `VerifyTabbedBags.Flow`로 실제 UI 클릭을 통한 탭 전환, 양방향 전달, 자원·시간·소음 보존, 치료 및 상태 갱신 확인. `Six`로 6명 탭/특성 정보, `EdgeCases`로 받는 목록 스크롤 후 마지막 동료 전달, 1명 상태, 최대/감소 수량 확인. 6명은 화면 검증용 임시 편성이며 이후 실제 2명 편성으로 복구했다. 실행 파일 빌드는 하지 않았다.

실제 Unity 화면: `Assets/Screenshots/Settlement/bags-tabs-profile-six.png`.

# 현장 가방과 동료 교환

2026-09-23. 기존 방 이동·사물 수색 구조를 유지한다. 검토했던 12×6 탐험 보드 전환은 적용하지 않는다.

탐험 HUD의 대원 가방 카드를 누르면 `ExpeditionBagPanel`을 연다. 왼쪽은 누른 대원, 오른쪽은 다른 동행 대원으로 시작한다. 각 가방 위 가로 스크롤 카드로 비교 대원을 변경한다. 같은 대원을 양쪽에 선택할 수 없다. 혼자 탐험할 때도 가방을 확인할 수 있지만 교환은 불가하다.

- 양쪽 물건 아이콘에서 선택하고 수량/최대를 지정한 뒤 반대쪽 대원에게 건넨다. 재고는 실행 시 재검증한다.
- 새 아이템 종류에는 빈 슬롯이 필요하다. 이미 가진 종류에는 기존 스택 규칙을 적용한다.
- 창고나 현장 보관함으로 연결하지 않는다. 공용 자원 총량, 거점 창고, 턴, 시간, 소음은 교환으로 바뀌지 않는다.
- 행동 불가능한 대원, 비동행 대원, 자기 자신, 부족한 수량, 0 이하 수량은 교환 대상이 될 수 없다.
- 지렛대를 건네면 실제 가방 소유권이 바뀌므로 다음 수색의 담당자 장비 판정에도 반영된다.
- 조우·수색·발견물 정리·이동 중에는 열리지 않는다. 돌아가기/Esc로 닫으면 현재 방에 복귀한다.

## 파일과 검증

- `Assets/Prefabs/Settlement/ExpeditionBagPanel.prefab`: 기존 발견물 패널의 승인 종이·아이콘 배치를 재사용. 슬롯과 대원 카드는 기존 개별 프리팹을 재사용한다.
- `Assets/Scripts/FrontEnd/ExpeditionBagPanel.cs`: 화면, 대원 선택, 양방향 교환.
- `SettlementInventoryPanel.ExchangeField`: 가방 간 원자적 이동. 자원 총량을 변경하는 발견물 획득 API와 구분한다.
- `AgentScripts/BuildFieldBags.cs`: Editor 프리팹 구성. `BuildLoot`와 도착 화면의 초기 builder를 재실행한 경우 이어 실행한다.
- `AgentScripts/VerifyFieldBags.cs`: 실제 UI 전량/일부/역방향 교환, 꽉 찬 가방, 기존 스택, 잘못된 수량, 자원·시간 불변, 혼자 탐험, 귀환/재방문, 글자 높이와 하단 버튼 크기 검증.
- `Assets/Screenshots/Settlement/field-bags.png`: 실제 Unity 1920×1080 화면.
- `아트/현장가방-v1`: 원본 PNG, 개별 PNG, 실제 레이어 PSD와 좌표. 글자는 Unity에서 편집한다.

저장은 아직 세션 내 상태만 유지한다. 새 방·조명 지원·생활 콘텐츠·캠페인 저장은 별도 후속 작업이다. 실행 파일 빌드는 생략했다.

# 작업대 · 제작/수리/개선

2026-09-22. 승인 시안 `아트/UI전체시안-v1/06-제작수리와진행작업-v2.png`를 기준으로 만든 다음 거점 화면.

### 글자 정렬 보완

`AgentScripts/AlignSettlementCraft.cs`로 기존 프리팹의 배치/텍스트 정렬만 보완했다. 종이 제목을 중앙에 놓고 상세 제목·설명·수량 안내의 왼쪽 여백을 통일했다. 작업자/재료 섹션 제목의 세로 중심, 예약 목록 제목/건수의 높이, 행 아이콘/이름/체크의 중심을 맞췄다. 수량 +/- 버튼 크기와 가운데 숫자의 간격도 대칭으로 조정했다. 폰트·그림·게임 데이터·기능은 유지했다. 글자는 PSD에 굽지 않으므로 Unity 프리팹이 정렬 기준이다. 최초 제작 builder 재실행 시에는 이 정렬 스크립트를 이어 적용한다.

### 목록 스크롤 보완

아이템 목록(346×236)과 필요 재료 목록(577×170)에도 독립 ScrollRect/RectMask2D를 적용했다. 담당자·예약 작업 목록을 포함하여 네 목록 모두 세로 스크롤된다. 각 목록 위에서 휠/드래그/스크롤바로 이동하며, 항목이 영역 안에 들어가면 스크롤바는 숨긴다. 제목과 확정 버튼은 움직이지 않는다. 분류 변경 시 아이템 목록, 아이템 변경 시 재료 목록을 맨 위로 돌린다. 화면 아래에 가려진 재료도 부족 판정에 포함된다.

재료가 많은 작업의 취소 확인에서도 반환 안내만 스크롤되며 유지/취소 버튼은 고정한다. `VerifySettlementCraft.ScrollLists`에서 아이템 12개·재료 8개를 임시로 넣어 실제 휠 입력, 마지막 아이템 선택, 숨겨진 재료 부족, 스크롤 초기화, 긴 반환 목록과 전량 반환, 짧거나 빈 목록의 스크롤바 숨김을 검증했다. 검증 데이터는 복구되며 실제 레시피에 추가하지 않았다.

스크롤 조립은 `AgentScripts/AddCraftScrolling.cs`다. 최초 builder 재실행 후에는 정렬 보완과 이 스크립트를 적용한다. PNG/PSD 원화는 변경하지 않았으며 런타임 클리핑·스크롤은 프리팹에서 편집한다.

## 연결과 동작

### 아래 항목 안내 화살표

`ScrollMoreHint.prefab`을 각 스크롤 영역 우측 하단에 배치했다. 제작 아이템·필요 재료·제작 담당자·예약 작업·취소 시 반환 안내·휴식 담당자 총 6곳에 공통 적용한다. 아래쪽에 가려진 내용이 2px 이상 있을 때만 옅은 둥근 화살표를 표시하며, 맨 아래에 도착하거나 내용이 영역 안에 들어가면 숨긴다. 클릭·휠·드래그를 가로채지 않는다.

위치와 크기(24×17), 색상·투명도는 프리팹에서 편집한다. 런타임은 벡터 Graphic을 사용하며, 편집 원본은 `아트/UI공통/스크롤안내/`의 SVG·개별 PNG·2레이어 PSD다. 조립 스크립트는 `AgentScripts/AddScrollMoreHints.cs`이며 전체 화면 재조립 시 스크롤 조립 이후 실행한다.

12개 아이템·8개 재료의 긴 목록으로 표시, 맨 아래 숨김, 다시 위로 스크롤 시 재표시, 짧은 목록 숨김과 입력 통과를 Unity Play에서 검증했다. `Assets/Screenshots/Settlement/craft-scroll-hint.png`는 임시 긴 목록을 넣은 시각 검수 화면으로, 실제 레시피 수를 늘린 것은 아니다.

정착지 작업대 아이콘 → 제작/수리/개선 탭 → 항목 → 수량 → 담당자 → 작업 시작 → 정착지.
작업대를 다시 열면 오른쪽에 실제 등록한 제작 예약을 볼 수 있다. 예약 취소를 누르면 재료 반환 안내가 한 단계 위에서 열리며, 유지/취소 중 선택한다. Esc는 취소 확인창부터 한 단계씩 닫는다.

- 필요한 재료가 없으면 붉게 표시하며 확정을 막는다. 표시 수량은 `사용 가능 / 필요`다.
- 수량 1~99에 따라 재료·예상 시간이 변한다. 탭/항목을 바꾸면 담당자 선택을 해제한다.
- 재료와 담당자는 등록 시 다시 검사한다. 재료를 예약하면 다른 작업의 가용 재료에서 제외한다.
- 휴식 예약이 있는 대원은 제작에, 제작 예약이 있는 대원은 휴식에 동시에 배정할 수 없다.
- 취소 확인에서 ‘유지’를 선택하면 상태를 바꾸지 않는다. ‘예약 취소’를 선택하면 재료 예약과 담당자 점유를 풀고 목록을 갱신한다.
- 닫기만으로는 등록한 작업을 없애지 않는다. 선택만 하다 닫으면 등록·소모하지 않는다.
- 작업자/예약 목록은 재사용 행 프리팹과 ScrollRect로 구성했다. 시안에 그려진 예시 3명을 상한으로 삼지 않는다.

## 현재 범위와 검토용 데이터

이번 구현은 화면 선택과 작업 예약 관리까지다. **시간 진행, 실제 생산, 수리/개선 효과, 저장·씬 이동 간 예약 유지**는 아직 연결하지 않았다. 오른쪽을 ‘예약한 작업’으로 표시하고 진행률을 가짜로 채우지 않는다.

`CraftWorkPanel.prefab`의 `Materials`와 `Recipes`는 Inspector에서 수정할 수 있는 검토용 데이터다. 시작 재료는 나무 판자 2 / 밧줄 3 / 못 0 / 고철 3 / 천 조각 2다. 기존 Campaign의 보급품·탄약과는 별도이며 통합 창고 시스템은 후속 작업이다. Play 재시작 시 초기화한다. 완성 아이템은 이번 단계에서 지급하지 않는다.

| 항목 | 분류 | 재료 | 시간 가정 |
| --- | --- | --- | --- |
| 간이 지렛대 | 제작 | 나무 판자 2, 밧줄 1, 못 2 | 30분 |
| 간이 못 | 제작 | 고철 1 | 15분 |
| 밧줄 | 제작 | 천 조각 2 | 20분 |
| 침대 수리 | 수리 | 나무 판자 2, 못 2 | 45분 |
| 작업대 개선 | 개선 | 나무 판자 4, 못 4, 밧줄 1 | 90분 |

수치는 밸런스 확정이 아니다. 고철과 천의 전용 아이콘은 아직 없어 공용 재료 상자 아이콘을 쓴다.

## 시각/편집 기준

기존 거점 배경과 상단 UI를 유지하며 시안의 아래쪽 작업 패널, 왼쪽 분류와 레시피, 우측 썸네일·수량, 아래 담당자·비용, 오른쪽 작업 목록 배치를 따른다. 등록 전에는 실제로 빈 목록을 표시한다. 원본의 합쳐진 가구 하이라이트는 고정 배경에 새로 그리지 않았다. 체력/피로 예시와 작업 진행률도 꾸며 넣지 않는다.

- `Assets/Prefabs/Settlement/CraftWorkPanel.prefab`: 화면 조립·취소 확인·데이터.
- `CraftRecipeRow.prefab`, `CraftWorkerRow.prefab`, `CraftCostRow.prefab`, `CraftOrderRow.prefab`: 개별 수정/재사용 단위.
- `Assets/Scripts/FrontEnd/SettlementCraftPanel.cs`: 선택·재료 예약·취소.
- `아트/제작수리-v1/개별-PNG` 및 `PSD/craft-work-layout.psd`: 분리 이미지와 3840×2160 레이어 배치 원본. 텍스트와 수치·강조 상태는 Unity UI에서 조정한다.
- 제작 스크립트: `AgentScripts/BuildSettlementCraft.cs`, 원본 내보내기: `tools/prepare_craft_work.py`. 최초 builder 재실행은 화면 프리팹을 덮어쓰므로 사용자 배치 수정 후에는 필요한 부분만 편집한다.

## 검증

`VerifySettlementCraft.Flow`에서 세 분류 전환, 수량 변경, 재료 부족, 항목 변경 시 담당자 해제, 정확한 재료 예약, 휴식과 제작의 양방향 점유 충돌, 중첩 확인창 입력 차단, 취소 거절 시 불변, 전량 반환과 재등록을 확인했다. 글자 높이와 기존 시간·보급품·탄약 미변경도 확인했다. Unity 실행 파일은 빌드하지 않았다.

# 정착 생활의 개연성·다양성·자율행동

2026-09-23 최신 사용자 방향. 다양성을 늘릴 대상은 **주민·동료와 정착지 둘 다**라고 확인했다. 아래의 이름·수치·행동 규칙은 설계 제안이며 실제 콘텐츠로 추가한 목록이 아니다. 이름 없는 역할명과 단순 자원 차이만으로는 몰입이 부족하다는 지적을 우선 반영한다.

## 1. 시작 재료가 어디서 왔는지 보여주기

현재는 `CampaignState.Settle`에서 보급품·탄약을 지급하고 제작 프리팹의 `Materials.Initial`에도 재료가 채워져 있다. 현장에서 발견하거나 가져온 과정 없이 공용 창고에 들어오는 문제가 있다.

권장 흐름: 동료가 가지고 온 작은 가방 → 빈 건물 진입 → 남은 물건 확인 → 첫 생활 작업 → 부족한 물자의 외부 수색.

| 출처 | 예시 | 획득 방식 |
| --- | --- | --- |
| 개인 소지품 | 마시던 물, 작은 공구, 비상식량 | 동료 선택에서 소지품을 보여주고 해당 동료의 가방으로 시작 |
| 건물 잔여물 | 주택 찬장의 식료품, 진료소 서랍의 거즈 | 미수색 `?`를 조사한 후 발견·수령 |
| 해체 가능한 물건 | 망가진 의자, 낡은 선반 | 대상·시간·필요 도구를 확인하고 목재나 부품으로 회수 |
| 직접 만드는 물건 | 정수한 물, 천을 가공한 붕대 | 확보한 재료를 소비해 작업 완료 시 지급 |

설명만 덧붙여 기존 재료를 지급하지 않는다. 실제 가방·수색·해체 기록과 연결해야 한다. 첫 필수 행동에 필요한 최소 물자는 확보할 수 있어야 하며 무작위 실패로 도입이 막히지 않게 한다. 침구를 해체하면 잠자리가 줄어드는 등 원래 용도와의 선택도 후속 검토한다.

기존 저장 데이터의 물자를 회수하지 않는다. 신규 게임 초기화만 변경하고, 도입 건너뛰기·저장 복원·재방문 때 중복 지급되지 않게 출처별 획득 상태를 저장한다.

## 2. 이름 있는 정착지와 서로 다른 생활 방식

아래 여섯 가지는 제작 후보다. 수를 한꺼번에 늘리기보다 기존 세 곳의 배경·시설·첫 문제를 먼저 구분한다. 현재 정착지 선택 후 내부 배경은 공통이므로 설명만 바꾸면 실제 차이는 생기지 않는다.

| 장소 후보 | 남은 장점 | 먼저 해결할 문제 | 생활 스타일 |
| --- | --- | --- | --- |
| 만복 정비소 | 공구·작업 공간 | 물과 잠자리 부족 | 회수·수리 중심 |
| 느티나무집 | 작은 부엌·침구 | 비좁은 창고·불안한 출입문 | 소수 인원 생활 중심 |
| 은하 의원 | 처치 공간·남은 의료 소모품 | 고장 난 급수·빈 식료품장 | 돌봄 중심 |
| 모퉁이 세탁소 | 물탱크·천·배관 | 동력 없는 설비·젖은 공간 | 정수·가공 중심 |
| 성문 인쇄소 | 넓은 작업장·종이 기록 | 어두운 내부·막힌 통로 | 제작·정보 수집 중심 |
| 옥상 관리실 | 빗물 모을 자리·전망 | 추위·운반 거리 | 소규모 자급 중심 |

상호명은 가안이다. 선택 화면에는 시작 자원 숫자만 나열하기보다 **현재 쓸 수 있는 시설 / 고장 난 부분 / 물자 출처 / 주변 탐색 여건**을 표시한다. 내부 조명도 실제 창문·전등·전력 상태에 맞춰 장소별로 달라져야 한다.

## 3. 주민 이름과 생활 개성

직업별 능력치보다 이름·말투·익숙한 일·불편해하는 상황·소지품을 묶어 작은 인물 원형부터 만든다. 아래는 가능한 스타일을 비교하기 위한 가안이다.

| 가명·배경 | 생활 성향 | 가져온 물건 예시 |
| --- | --- | --- |
| 정은 · 급식 조리원 | 남은 식재료부터 확인하고 사람을 챙김 | 도시락·작은 식칼 |
| 기섭 · 수리 기사 | 쉬는 동안에도 망가진 물건을 살펴봄 | 다용도 공구 |
| 해인 · 방문 간병인 | 남을 먼저 쉬게 하고 자기 피로는 숨김 | 거즈·작은 수첩 |
| 우진 · 택배 기사 | 출입구와 이동 경로를 먼저 확인함 | 손수레 끈·물병 |
| 미경 · 세탁소 운영자 | 천과 물자를 정리하며 마음을 진정시킴 | 작업 장갑·실 |
| 소담 · 도서관 직원 | 발견한 흔적을 기록하고 비교함 | 연필·접이식 지도 |

예시 이름은 아직 확정하지 않았다. 능력과 외형을 직업에 하나씩 고정하지 않고, 키·체형·연령대·자세·복장·색·실루엣도 구분한다. 동일 실루엣의 이름만 바꾼 것을 외형 다양성 완성으로 보지 않는다.

상세 무작위 생성은 기존 순서대로 비전투 기반 뒤에 구현하되, 첫 선택의 몰입을 위한 인물 원형 설계는 지금 함께 진행한다. 표시 이름과 영속 ID를 분리하고, 생성 결과와 소지품은 저장 후 불러올 때 재추첨하지 않는다.

## 4. 명령이 없을 때도 생활하기

권장안은 제한된 자율행동이다. 모든 사람을 매번 클릭하는 부담은 줄이되, 계획하지 않은 소비와 외출이 일어나지 않도록 방침을 둔다.

| 종류 | 예시 | 게임 규칙 |
| --- | --- | --- |
| 일상 연출 | 창밖 살피기, 의자 옆에서 쉬기, 자기 가방 점검 | 대기 중에도 보이지만 자원·체력·게임 시간에는 영향 없음 |
| 맡긴 생활 업무 | 물 정리, 조리, 수리 우선순위 | 시간 진행 시 기존 작업·예약 시스템으로 처리 |
| 제한이 필요한 소비 | 식사, 약품, 귀한 연료 | 허용 방침·비축 최소량을 만족할 때만 실행 |
| 직접 결정할 행동 | 외출, 영입, 위험한 수색 | 플레이어 지시로 진행 |

명령 우선순위는 직접 지시 → 진행 중인 작업 → 허용된 생활 업무 → 일상 연출. 팝업·메뉴·탐험 동안 거점의 자율 행동을 새로 시작하지 않는다. 움직임 연출을 실제 작업 완료로 간주하지 않는다. 부상·작업 예약·시설 점유를 확인하고 같은 자리에 겹치지 않게 한다.

현재 시간은 버튼으로 진행하는 구조이므로, 기본 권장안은 **일상 모습은 상시, 생산·회복·소비는 시간 진행 시**다. 실시간 생존으로 전환하려면 배속·일시정지·팝업 시간·자리 비움 처리를 별도로 설계해야 한다.

자율행동 구현 전 필요한 기반: 모든 거주민의 말 생성, 침대·조리대·창가 등 시설별 정지점, 시설 점유/대기, 현재 행동 표시, 직접 지시로 즉시 전환. 현재 말 이동은 두 명의 제작 이동 중심이며 이번에 자율 AI가 구현된 것은 아니다.

## 5. 이번 기술 수정과 남은 작업

- 정착지 카메라에 `WorldViewport`를 추가해 UI의 1920×1080 기준과 같은 비율로 전체 방을 맞춘다. 다른 비율은 여백을 유지한다. 화면을 잘라 채우거나 이미지를 늘리지 않는다.
- 실제 Game View를 1920×1080, 1280×1024, 2560×1080으로 바꿔 검수한다. 단순 캡처 크기 변경은 UI 재배치 검증으로 간주하지 않는다.
- 실내 전체광을 낮추고 차가운 색으로 조정하며 벽등·출입구 등은 따뜻한 광원으로 범위를 넓혔다. 1차 명암 조정이며 가구별 차폐·노멀맵·시간/전력 연동은 남았다.
- 제작 이동은 현재 위치에서 통로 진입 → 통로 따라 이동 → 시설 접근의 세 구간으로 수정하고 속도와 기울기를 줄였다. 충돌 회피나 모든 생활 시설 이동을 구현한 것은 아니다.
- 기존 원화의 픽셀 수는 늘리지 않았다. 특히 외부 탐험 배경은 1672×941 텍스처가 확인되어 큰 화면의 선명도는 별도 원본 보완이 필요하다. 화면 비율 대응과 고해상도 원화 제작을 구분한다.

다음 콘텐츠 연결은 시작 물자 출처와 첫 수색 → 거점 세 곳의 실질적 차이 → 모든 생활 시설 이동·일상 행동 → 방침에 따른 자율 작업 순서를 권장한다. 인물 이름과 원형 설계는 이와 병행한다.

검수 결과: 세 화면 크기 모두 카메라 크기와 주요 시설 버튼 범위 검사 통과. 제작 지시 후 통로 이동·정확한 발판 도착·취소 후 원점 복귀를 확인했으며, 다른 대원 위치와 게임 시간·보급품은 변하지 않았다. 최초 이동 검사는 0.07 유닛의 짧은 통로 진입이 이미 끝난 상황을 실패로 판정했으므로, 가로 이동 시 발판이 통로에 있는지 검사하도록 전제를 수정한 뒤 통과했다.

실제 캡처: `Assets/Screenshots/settlement-lighting-169.png`, `settlement-lighting-54.png`, `settlement-lighting-wide.png`. 원화 변경 없이 조명만 수정했으며, 전체 배경 재생성이나 새로운 거점 원화 제작은 하지 않았다.

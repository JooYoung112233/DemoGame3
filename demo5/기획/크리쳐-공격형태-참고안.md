# 크리쳐 공격 형태 참고안

기록일: 2026-09-24

사용자가 공격 형태 제안을 저장하도록 요청했고, 다른 에이전트가 현재 전투를 제작 중이라고 알렸다. 이 문서는 해당 작업에서 참고할 디자인 제안이다. 전투 구현·수치 확정 지시가 아니며 진행 중인 전투 구조를 일괄 교체하는 근거로 사용하지 않는다. 이번 작업에서는 전투 코드·씬·프리팹을 수정하지 않았다.

## 핵심 방향

우리 캐릭터는 납작한 종이 등신대 말이다. 복잡한 관절 공격 애니메이션보다 **공격 의도 예고 → 위치를 바꾸거나 환경을 이용해 대응 → 공격 후 빈틈**이 읽히도록 제안한다.

12종을 피해량만 다른 적으로 만들지 않고 직접 공격·위치 방해·공간 변화로 나눈다. 사물과 닮은 외형이 행동 이유로 이어지게 한다. 피해량, 행동 횟수, 거리, 예고 시간, 비용은 미정이다. 현재 전투가 사용하는 턴·행동 체계에 맞게 검토한다.

## 종별 제안

| 내부 ID | 가칭 | 공격·방해 형태 | 예고와 대응 |
|---|---|---|---|
| 01-door-bearer | 문지기 | 문을 세워 길을 막고 다음 행동에 앞으로 짧게 밀어붙임 | 문이 향한 방향을 표시. 옆으로 우회 |
| 02-listener | 귀기울임 | 큰 소리가 난 위치를 향해 긴 팔로 내려침 | 먼저 고개를 기울여 듣는 신호. 소음을 줄이거나 다른 위치로 유인 |
| 03-under-table | 식탁밑 | 몸을 낮춘 뒤 가까운 대상에게 짧게 도약 | 의자 다리가 오므라드는 예고. 거리를 벌림 |
| 04-seam-hound | 틈새개 | 좁은 직선 경로로 빠르게 돌진 | 돌진 선을 먼저 표시. 옆으로 비키면 지나친 뒤 빈틈 |
| 05-laundry | 널린것 | 천을 펼쳐 시야를 가리고 이동을 둔화 | 펼쳐지는 방향을 예고. 범위 밖으로 이동 |
| 06-meter-keeper | 계량원 | 전선으로 두 지점을 연결해 통과 시 감전 | 연결 직후에는 안전, 점멸 후 활성화. 경로 변경 |
| 07-moth-nest | 먼지둥지 | 주변을 맴돌며 집중·작업을 방해하고 가까이 뭉침 | 밀도가 높아지며 위험이 드러남. 흩어져 이동 |
| 08-puddle | 고인사람 | 바닥에 번져 발을 붙잡고 잠시 뒤 아래로 끌어당김 | 발밑에 물결을 먼저 표시. 번지기 전에 빠져나옴 |
| 09-stairback | 계단등 | 몸을 굳혀 장애물이 되었다가 한쪽으로 무너짐 | 기울어지는 쪽에 위험 표시. 반대편 이동 |
| 10-twin-coat | 겹친이웃 | 두 방향을 차례로 공격해 첫 회피 후 위치까지 위협 | 두 머리가 서로 다른 방향을 바라봄. 두 번째 방향까지 보고 이동 |
| 11-root-receiver | 수신목 | 소리로 주변 크리쳐를 불러 모으고 다른 위치에 가짜 소음을 만듦 | 방송 전 잡음·안테나 떨림. 먼저 차단할지 우회할지 선택 |
| 12-bellied-cart | 빈수레 | 직선으로 달리며 말과 바닥 물건을 밀어냄 | 바퀴 소리와 진행 방향 예고. 벽 충돌 후 잠깐 정지 |

## 등신대 연출

- 예고: 말이 뒤로 기울거나 천천히 돌아서고, 받침대 주변에 방향 표시.
- 실행: 짧은 돌진·회전·튕김에 그림자와 효과음 결합.
- 빈틈: 공격 후 잠깐 기울어진 채 정지해 대응할 시간을 표시.
- 위험을 색상만으로 구분하지 않고 방향·형태·소리로도 전달한다.

## 초기 검증 후보 — 구현 순서 확정 아님

문지기 / 귀기울임 / 틈새개 / 고인사람 네 종을 먼저 시험하는 것을 제안했다. 각각 길막·소음 반응·직선 돌진·바닥 위험을 검증할 수 있다. 기존 전투의 위치 이동과 소음 체계가 지원하는지 확인하고 채택한다. 나머지는 기본 규칙 검증 이후 확장한다.

평가 초점은 공격력보다 예고를 보고 대응할 수 있는지, 작은 말 크기에서도 서로 구별되는지, 공격 후 빈틈이 읽히는지다.

# 금례 재회 — 구현과 검수

## 정착지에서 전하는 소식 — 후속 구현

해인 미동행 원정대가 이번 방문에서 금례를 직접 목격한 경우 귀환 시 소식 전달을 예약한다. 귀환 보고·짐 정리가 열려 있는 동안 기다렸다가 정착지로 돌아오면 실제 방문 대원이 거처를 알리고, 해인이 안도하며 다음 동행을 이야기한다. 3줄 무료 대화이고 물자·시간·체력 보상은 없다. 이 대화만으로 금례와 해인의 직접 재회를 완료하지 않는다. 전해 들은 위치만 있는 경우, 이미 전달한 경우, 재회 완료 후에는 반복하지 않는다.

저장 v22의 `NewsMessengerId/NewsLine/NewsShared`로 대기·진행·완료를 보존한다. v21은 기존 목격과 재회를 유지하며 누가 전달했는지 소급 추측하지 않는다. 이전 저장에서도 이후 직접 방문하면 조건에 따라 전달할 수 있다.

`VerifyLaundryStoryVisit.Relay` PASS: 실제 단독 방문→목격→귀환 보고→대화 순서, 1920×1080·1280×800 경계와 육안 화면, 격리 슬롯에 대화 중간 상태 저장 후 읽던 줄 복원, 완료 후 재로드·중복 방지, 구버전 이행과 잘못된 줄 번호 거부를 검수했다. 중간 저장은 검수 API로 구성했으며 대화창에 저장 버튼을 추가한 것은 아니다. 기존 재회 검수는 새로운 소식 전달을 마친 뒤 다음 단계를 진행하도록 갱신했다.

결과는 `아트/리소스검토/geumrye-news-relay-runtime.txt`, 화면은 `geumrye-news-relay-*`다. 새 원화·UI 프리팹은 만들지 않았다.

## 재방문 안내 후속 마감

지도 현장 안내를 주소 확인·거처 확인·재회 대기·재회 완료 상태에 맞춰 갱신한다. 대원 선택 시 해인 동행 여부와 재회 대화 조건을 표시하되 다른 대원의 방문은 막지 않는다. 완료 후 방문 목적과 미란의 인사는 안부 방문으로 바뀐다. 금례의 안부 대사도 해인 동행 여부를 구분하며 다른 대원에게 해인인 것처럼 말하지 않는다.

`VerifyLaundryStoryVisit.Followup` PASS: 격리된 완료 저장을 읽고 지도 문구, 해인 선택/해제, 서진 단독 재방문을 실제 UI로 검수했다. 1920×1080·1280×800에서 문구 경계를 검사하고 지도 화면을 육안 확인했다. 지도 사진 아래 설명은 한 줄 크기에 맞춰 축약했다. 사용자 저장은 쓰지 않았으며 저장 형식은 v21을 유지한다. 결과는 `아트/리소스검토/laundry-followup-runtime.txt`, 화면은 같은 폴더의 `laundry-followup-*`다.

미란에게 금례의 거처를 물으면 같은 선택지가 ‘금례 씨 만나기’로 바뀐다. 기존 세탁소 탐험 HUD를 유지하며 새 원화나 수색 공간은 추가하지 않았다.

## 대화와 진행

- 해인 미동행: 대원들이 금례를 직접 보고, 해인에게 안부를 전해 달라는 부탁을 듣는다. 해인과의 재회 완료로 처리하지 않는다.
- 해인 동행: ‘쪽지 못 받았니?’에서 시작해 옛 사무소 수신함으로 간 쪽지가 닿지 않은 사정을 확인하고 현재 거처를 나눈다.
- 초대받은 것만으로 목격을 기록하지 않는다. 실제 만나는 서술 이후 거처 확인을 기록하고, 마지막 대사까지 표시한 뒤 재회 완료를 반영한다.
- 도중 귀환 시 확인한 사실만 남긴다. 완료 후 재방문은 안부 대화로 바뀌며 완료 기록을 중복 추가하지 않는다.
- 대화는 무료이고 기존 이동 시간만 적용한다. 체력·물자 보상이나 폐상가 수색 상태는 바꾸지 않는다.

## 저장

v21 `MissingPerson.MetGeumrye/ReunionComplete`로 직접 목격과 재회 완료를 분리한다. v20 저장은 기존 경로·미란 질문 진행을 유지하고 두 새 사실은 미완료로 이행한다. 재회 완료인데 직접 목격이 없는 저장은 거부한다. 기존 규칙대로 귀환 후 저장한다.

## 검수

`VerifyLaundryStoryVisit.Reunion` 실제 Play Mode 검수 PASS. 이전 검수 캠페인의 미란 방문 상태를 출발점으로 사용하고 재회 상태를 초기화한 명시적 검수 구성이다. 사용자 저장 대신 `Temp/LaundryStoryVerification`의 격리 슬롯을 사용했다.

해인 미동행·동행, 초대와 실제 목격 구분, 도중 귀환, 실제 디스크 저장·재로드, 무료 대화 시간, 재방문 중복 방지, v20 이행과 잘못된 상태 거부를 확인했다. 1920×1080·1280×800에서 대사·기록 경계를 확인하고 화면을 육안 검수했다. 컴파일 오류 없음.

결과: `아트/리소스검토/geumrye-reunion-runtime.txt`. 화면: 같은 폴더의 `geumrye-reunion-*` 및 `geumrye-reunion-record-*`.

남은 범위: 세탁소 전용 배경과 인물 원화, 현장 이동·수색. 현재는 지도 배경을 쓰는 대화 방문이다.

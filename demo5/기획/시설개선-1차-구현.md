# 시설 개선 1차 — 2026-09-23

침대·작업대·조리대의 기본 상태를 Lv.1, 한 번 개선한 상태를 Lv.2로 표시한다. 기존 침대/작업대 효과와 저장 기록은 유지한다. 거주 공간 확장·영입·담당자 생활 특성·3레벨은 이번 구현에 포함하지 않는다.

## 사용 흐름과 효과

침대/식량 준비 화면 우측 상단의 개선 버튼으로 해당 공사에 바로 진입한다. 작업대의 수리/개선 목록에서도 선택할 수 있다. 현재 레벨과 다음 효과, 재료, 담당자, 예상 시간을 확인하고 예약한다. 작업 완료 전에는 효과를 적용하지 않는다.

| 시설 | 기본 공사 비용 / 시간 | Lv.2 효과 |
| --- | --- | --- |
| 침대 | 나무2·못2 / 45분 — 기존 값 | 새 휴식 예약의 회복량 +1 — 기존 효과 |
| 작업대 | 나무4·못4·밧줄1 / 90분 — 기존 값 | 이후 제작 시간 −20% — 기존 효과 |
| 조리대 | 나무3·고철2·못2 / 60분 — 임시 값 | 이후 조리 시간 −20% — 임시 효과 |

기존 작업대 개선의 공사 시간 단축도 유지한다. 따라서 작업대 Lv.2에서 조리대 공사 시간은 48분이다. 조리 시간은 횟수까지 곱한 최종 값에 시설 비율을 적용하고 분 단위로 올림한다. 기존 0분 간편식은 0분으로 유지하며 산출량·비용은 늘리거나 줄이지 않는다. `CookerTimePercent`는 Inspector에서 조정할 수 있다. 담당자 속도/효율 특성은 아직 미구현이다.

## 작업 충돌과 취소

- 휴식이 남아 있으면 침대 공사, 일반 제작이 남아 있으면 작업대 공사, 조리가 남아 있으면 조리대 공사를 막는다.
- 공사 중인 해당 시설은 새 작업을 받지 않는다. 진행 중인 작업은 먼저 완료하거나 명시적으로 취소해야 한다. 다른 시설의 작업은 계속 진행한다.
- 같은 담당자는 다른 작업에 중복 배정할 수 없다. 같은 시설의 중복/완료 후 재공사를 막는다.
- 공사 수량은 1이다. 예약 중인 재료는 창고에서 소비하지 않고 사용 가능 수량에서 제외한다. 취소하면 예약만 해제하며, 경과 시간은 복구하지 않는다. 완료 때 재료와 효과를 한 번만 반영한다.
- 작업의 남은 시간은 예약 시 확정된 값으로 저장한다. 불러올 때 현재 시설 비율로 다시 계산하지 않는다.

## 저장와 편집

현재 저장 버전은 5다. `CookerImproved`를 추가하고 v4 이전 저장은 조리대 Lv.1로 이관한다. `BedRepaired`/`BenchImproved`는 보존하며 기존 상태에서 Lv.1/2를 파생한다. 아직 다단계 시설 레벨 테이블로 전환한 것은 아니다. 진행 중 공사는 기존 안정 ID `repair-bed`, `upgrade-bench`, `upgrade-cooker`와 예약 재료/남은 시간으로 저장한다.

- `SettlementFacilityRules.cs`: 시설 상태, 공사 충돌 조건, 조리 시간 계산.
- `SettlementCraftPanel.cs`: 공사 등록/취소/완료와 효과 안내.
- `SettlementWorkPanel.cs`, `SettlementCookingPanel.cs`, `SettlementCookingOrders.cs`: 시설별 진입/이용 제한/효과 적용.
- `CraftWorkPanel.prefab`: 조리대 개선 레시피와 비용·시간.
- `SettlementScreen.prefab`: 기존 휴식·조리 화면의 레벨 제목과 개선 버튼 연결.
- `AgentScripts/ConnectFacilities.cs`: Unity Editor API를 통한 재현용 연결 스크립트.

## 검증과 화면

`VerifySettlement.Flow`, `VerifyFacilities.Flow`, `VerifyFacilities.Restart` 통과. 초기 Lv.1, 공사와 작업의 양방향 충돌, 비활성 버튼의 리스너 직접 호출 시 재검증, 취소 재료 보존, 비용/효과 중복 방지, 공사 도중 파일 저장/씬 복원, 세 시설의 실제 효과, 다른 시설과 병행, v4 이관, 완료한 공사의 중복 저장 거절을 확인했다.

Play 종료·재시작 후 시작 화면 계속하기로 세 시설 Lv.2와 진행 중 조리를 복원하고 음식 산출이 한 번만 발생하는 것을 확인했다. 검증 파일은 `Temp/FacilityVerification`에 격리했으며 사용자 저장 슬롯을 사용하지 않았다. 테스트에서 지급한 재료20은 런타임 검수용이며 시작 재고를 변경하지 않았다. 새 Unity 오류 없음. 실행 파일 빌드는 생략했다.

기존 승인 시안 `05-생활작업지정-v2.png`, `06-제작수리와진행작업-v2.png`와 현재 공통 팝업 적용 화면을 비교했다. 기존 본문/행/버튼 배치를 유지하고 상단 개선 버튼, 레벨과 효과 문구만 추가했다. 설명 문구가 종이 영역을 넘친 최초 검수 실패는 두 줄로 줄인 뒤 재검증했다. 인물·아이콘의 기존 저해상도와 시안의 원래 질감/글꼴 차이는 그대로이며 새 원화를 만들지 않았다.

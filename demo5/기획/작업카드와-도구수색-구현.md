# 작업 카드와 도구 수색

2026-09-23. 귀환 화면의 카드·아이콘 구성을 다른 화면에 적용하고 다음 비전투 연결을 구현했다.

## 시간 진행

시간 진행의 긴 작업 설명을 `TimeWorkRow.prefab` 목록으로 교체했다. 각 행은 작업 아이콘, 작업명/수량, 담당자/현재 남은 시간, 진행 후 결과로 구성한다. 완료 예정·남은 시간을 구분하며 최근 완료 기록도 같은 카드로 표시한다. 목록이 넘치면 독립 스크롤과 하단 안내 화살표가 작동한다.

새 이미지를 생성하지 않고 기존 침대·제작물·완료 아이콘과 종이를 재사용했다. `아트/시간진행-v1/PSD/time-layout.psd`는 2개 작업 표시 상태의 13개 분리 레이어로 갱신했다. 글자는 프리팹에서 수정한다. 실제 화면은 `Assets/Screenshots/Settlement/time-cards.png`.

## 지렛대의 첫 탐험 사용처

기존 오락기의 닫힌 정비판을 최초 도구 사용처로 정했다. 물자 상자와 책상은 도구 없이 수색할 수 있어 지렛대 재료 확보 경로를 막지 않는다.

1. 작업대에서 못과 지렛대를 제작한다.
2. 지렛대를 탐험할 대원의 개인 가방에 넣는다. 창고에 있는 것만으로는 사용할 수 없다.
3. 오락기를 클릭하고 지렛대를 가진 대원을 담당자로 고른다.
4. 첫 수색 1턴에 정비판 개방이 포함된다. 개방만을 이유로 시간을 추가 차감하거나 지렛대를 소모하지 않는다.
5. 이후 중단·귀환·재방문 시 개방 상태와 수색 진척을 유지한다. 이미 열려 있는 정비판은 도구 없는 다른 대원도 이어서 수색한다.

수색 화면에는 도구 아이콘과 담당자 가방의 휴대 여부를 표시한다. 잘못된 담당자 선택은 실행 버튼을 비활성화하며 실행 코드에서도 동일 조건을 재검증한다. 취소/조회는 시간을 쓰지 않는다. 완료 뒤 재수색으로 보상을 다시 추첨할 수 없다.

`ExpeditionLootPanel.Site.RequiredTool`로 대상별 도구를 지정하고 `SearchState.Opened`에 개방 상태를 보관한다. 아직 디스크 저장/불러오기는 없으므로 세션 밖으로 유지되지는 않는다. 새 방 배경이나 연결 방 추가는 이번 범위에 포함하지 않았다.

## 수정 위치와 검증

- `SettlementTimePanel.prefab`, `TimeWorkRow.prefab`: 작업 카드와 시간 진행 UI.
- `ExpeditionLootPanel.prefab`: 오락기 사이트(index 2)의 `RequiredTool=prybar`.
- `ExpeditionSearchPanel.prefab`: 도구 아이콘·상태 문구, 수색 비용 문구 잘림 수정.
- `AgentScripts/ConnectSearchTool.cs`: 기존 프리팹을 보존하면서 도구 연결. 수색 화면을 재생성하면 마지막에 이 스크립트를 적용한다.
- `VerifySettlementTime.Flow`: 카드로 바꾼 뒤 시간/완료/취소/창고 지급 회귀 검증 통과.
- `VerifySearchTool.Preview`: 실제 못→지렛대 제작, 창고에만 둔 경우 차단, 휴대/담당자 선택, 도구 문구 크기 검증 통과.
- `VerifySearchTool.Flow`: 취소 무료, 개방 포함 1턴, 도구 유지, 귀환/재방문 후 도구 없이 재개, 결과 목록과 재추첨 차단 검증 통과. 전투 규칙을 테스트하지 않도록 마지막 조우 확률만 테스트 중 0으로 두고 원래 값으로 복구했다.

실제 도구 수색 화면: `Assets/Screenshots/Settlement/search-prybar.png`. 수색 PSD에도 지렛대 아이콘 레이어를 추가했다.

# 수색 후보와 확률 예측

2026-09-23. 기존 방·사물 탐험 구조를 유지하고 수색 지정 화면 오른쪽에 후보 물자 카드를 추가했다.

- 아이콘, 물건 이름, 성공 시 수량, 최종 발견 확률을 분리해서 표시한다.
- 빠름/보통/정밀 및 함께 수색/망보기를 선택하면 확률·남은 턴·분·턴당 소음이 갱신된다.
- 확률은 실제 획득 판정과 `ExpeditionLootPanel.ChanceFor`를 공유한다. 기존 수치인 방식 보정 −15/0/+15%p, 협력 +10%p, 0~100% 제한은 변경하지 않았다. 밸런스 확정 수치가 아니다.
- 물건별 독립 판정이며 수량은 발견 성공 시 받는 양이다. 목록을 조회하거나 취소해도 난수, 시간, 수색 진행, 발견물을 변경하지 않는다.
- 시작 후에는 기존 규칙에 따라 방식과 협력 보정을 유지한다. 다시 열면 남은 시간과 같은 확률을 표시한다.
- 목록은 세로 스크롤이며 하단에 내용이 남으면 공통 아래 화살표를 표시한다. 후보를 전부 획득한 것처럼 보이지 않도록 제목은 ‘발견 가능한 물건’으로 표시한다.

`SearchDropPreview.prefab`은 예측 패널, `SearchDropRow.prefab`은 개별 행이다. 기존 종이와 재료 아이콘을 재사용하며 텍스트는 Unity에서 수정한다. `BuildSearchPreview.Run`이 수색 화면에 연결한다. 초기 `BuildSearch`로 재구성했다면 이 builder를 이어 실행한다.

`VerifySearchPreview.Flow`에서 모든 수색 방식/동료 역할의 표시 확률, 조회 중 난수·시간 불변, 취소, 1턴 진행 후 재개, 텍스트 높이, 스크롤을 검증했다. 실제 화면은 `Assets/Screenshots/Settlement/search-preview.png`다.

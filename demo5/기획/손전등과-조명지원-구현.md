# 손전등과 조명 지원

2026-09-23. 기존 방 이동·사물 수색과 UI 배치를 유지한다.

## 구현

- 작업대에서 손전등 제작: 고철 2 + 못 1, 30분. 현재 검토용 수치다.
- 완성품은 공용 창고에 들어간다. 개인 가방에 넣고 출발해야 사용할 수 있다.
- 수색 담당자 외 살아 있는 동행 대원이 손전등을 휴대하면 조명 지원을 선택할 수 있다. 여러 명이면 참가 순서상 첫 유효 휴대자를 안내한다. 보너스는 중첩되지 않는다.
- 조명은 발견 확률 +20%p, 함께 수색은 기존 +10%p, 망보기는 기존 턴당 소음 -1이다. 조명에 협력 보너스를 중복 적용하지 않는다. `ExpeditionLootPanel.LightBonus`에서 조정한다.
- 손전등은 이번 단계에서 소모되지 않는 재사용 도구다. 가방에서 아이템 한 종류의 슬롯을 점유한다. 배터리 잔량·교체·충전과 실제 손전등 빛 연출은 아직 구현하지 않았다.
- 조회/취소는 시간과 아이템을 소모하지 않는다. 수색 한 턴을 확정할 때 지원자가 유효한지 다시 확인한다. 행동 불능·손전등 부재 시 진행하지 않는다.
- 도중에 중단하거나 귀환해도 기존 방식·보너스가 유지된다. 재개에는 다시 유효한 조명 동료가 필요하다. 도구를 보충하거나 가방 교환으로 담당자와 휴대자를 바꿀 수 있다.
- 현재 배터리 소모가 없어 조명은 장비 슬롯을 투자한 업그레이드 역할이다. 수색 밸런스는 확정하지 않았다.

## 원본과 파일

손전등은 기존 `Assets/Art/Inventory/flashlight.png`와 `아트/개별인벤토리-v1/PSD/flashlight.psd`를 재사용했다. 새 이미지 생성이나 변경은 없다. 제작/인벤토리 프리팹의 아이템 데이터를 추가했고 기존 수색 프리팹의 조명 버튼을 연결했다.

- `AgentScripts/ConnectLightSupport.cs`: 제작법·창고 물자·개인 가방 아이템 등록. 초기 제작/인벤토리 builder로 재구성한 경우 이어 실행한다.
- `ExpeditionLootPanel`: 지원 자격과 실제 보너스. 매 행동 시 조건 재검증.
- `ExpeditionSearchPanel`, `SearchDropPreview`: 선택 가능 상태, 지원자 이름, 최종 확률 및 시간 안내.
- `AgentScripts/VerifyLightSupport.cs`: 실제 제작, 창고만 보유/담당자 본인 휴대 차단, 현장 교환 후 지원 활성화, 확률 일치, 무료 취소, 도구 미소모, 행동 불능 차단, 수색 재개 및 글자 높이 검증 통과.
- `Assets/Screenshots/Settlement/search-light-support.png`: 실제 Unity 화면.

전체 캠페인 저장·새 방·생활 콘텐츠는 후속 작업이다. 실행 파일 빌드는 생략했다.

# 정착지 선택 UI 정렬 보완 — 2026-09-23

사용자 첨부 화면의 안내문/카드 수치/선택 체크와 하단 정보 정렬을 수정했다. 기존 종이·배경·인물·아이콘을 재사용한다.

- 화면 외곽 여백80px, 제목과 카드 상단60px, 하단 버튼 y974/높이76px로 통일.
- 제목 종이의 좁은 하단 영역 안으로 안내문 배치. 기존 종이 모양 유지.
- 세 정착지 카드400×380, 이미지·이름·자원·설명의 공통 기준선과 안쪽24px 여백. 선택 체크는 카드 안으로 이동.
- 자원 수치3열은 같은 폭으로 배치하고 아이콘의 비율 유지 기준을 중앙으로 변경.
- 동료 초상/이름의 중심선을 통일하고, 하단 세 영역 제목 높이를 맞춤.
- 시작 조건은 개별 아이콘/문구3행으로 구성. 미선택 시 기존 안내문을 표시하고, 선택 시 행별 값으로 전환.
- `AlignHomeSelection.Run`은 기존 생성/아이콘 적용 이후 마지막으로 실행. 배치는 HomeSelectionScreen 프리팹에 저장되며 런타임에서 위치를 덮어쓰지 않는다.

`VerifyHomeSelection.Flow` 통과: 대원 없음 진입 차단, 세 정착지의 실제 레이캐스트 클릭, 단일 선택 표시, 텍스트 높이, 시작 자원/대원 보존과 뒤로가기. 원래 검증 스크립트의 수동 Camera.Render 호출을 제거했다.

실제 Unity1920×1080 검수 캡처: `Assets/Screenshots/home-selection-aligned.png`. 작은 주택 선택 상태에서 카드 이름·수치·설명·선택 체크·종이 안쪽 여백과 하단 아이콘 행을 육안 확인했다. 실행 파일 빌드는 생략했다.

함께 요청한 후속 순서는 [랜덤 동료 제작 방향](랜덤동료-후속방향.md)에 기록했다. 이번 작업은 UI 수정과 계획 기록이며 랜덤 동료를 구현한 것은 아니다.

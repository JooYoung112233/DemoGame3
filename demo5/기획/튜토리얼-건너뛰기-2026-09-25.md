# 튜토리얼 건너뛰기

**최신 정정: 최초 도입 대화(beat 0·준비 step 0)에서만 제공한다. 이후 대화와 메뉴에는 표시하지 않는다.** 아래 메뉴·중간 진행 생략 검수 기록은 이전 구현 이력이다. 최신 검수는 첫 도입 생략과 이후 미노출·재로드 미노출을 기준으로 한다.

사용자 요청: “튜토 건너뛰기만들어줘”. 기존 프로젝트에서 작업한다.

## 이용 방법

- 첫 도입 화면 **우측 상단**의 **튜토리얼 건너뛰기**를 누른다. 사용자 위치 정정에 따라 대화 하단에서 옮겼으며, 자동 준비·시간 처리 설명도 버튼 아래에 둔다.
- 첫 도입을 지나면 이후 대화와 정착지 메뉴에서는 버튼과 설명을 숨긴다.
- 선택한 캠페인에만 적용하며, 새 게임은 다시 정상 튜토리얼로 시작한다.

## 생략 범위와 진행 보존

정착 대화, 다음 클릭 강조·화살표·어두운 덮개, 두 번째 탐험의 장소 판 설명, 첫 장소 괴물의 조작 학습 안내를 생략한다. 실제 전투 예고나 NPC 대화, 발견한 관리표와 밤 사건은 유지한다.

처음 세 행동을 아직 하지 않았다면 기존 행동 처리로 남은 준비를 자동 완료한다. 주변 살피기 10분, 상자 수색 10분, 바닥 정리 20분이며 이미 마친 행동은 반복하지 않는다. 상자 수색의 물 1·천 1·설정된 탄약(현재 2발)도 한 번만 지급한다. 대화에서 건너뛰면 남은 정리와 소요 시간이 자동 처리됨을 안내한다.

준비를 마친 캠페인에서는 체력·재고·시간·예약을 바꾸지 않는다. 생략 상태는 별도 저장 bool이며, 시설 복구·연구·동료 해금·탐험 방문·단서 발견·밤 사건을 완료로 위조하지 않는다. 실제 시설 조건은 계속 적용한다.

정착 초기의 화면 접근 제한을 풀고 바로 원정을 준비할 수 있게 한다. 기존 관리표 읽기·생활 기록·밤 사건은 실제 진행 조건이 충족될 때 기존 행동 버튼으로 계속 접근할 수 있다.

## 구현과 재적용

- 저장 v18 `SavedTutorialNarrative.Skipped` 추가. 구형 저장의 누락 필드는 false. Clone·Capture·Restore로 유지한다.
- `SettlementIntroduction`의 기존 준비 처리 공유. 건너뛰기 완료 단계는 10.
- `SettlementTutorialNarrative`가 대화·페이드·입력 잠금을 해제하고 생략 상태를 기록한다.
- 장소 판은 생략을 안내 확인으로 취급하되 실제 방문 상태를 만들지 않는다.
- `BuildTutorialSkip.Run`은 `BuildTutorialNarrative.Run` 및 메뉴 빌더 **뒤에** 실행한다. 기존 종이·글꼴을 사용해 대화와 메뉴 프리팹 및 정착 화면의 참조를 연결한다.

## 검수

`VerifyTutorialSkip.Run`으로 별도 테스트 저장 경로에서 실제 클릭·저장·재로드·왕복 이동을 검수한다. 검수 결과는 `아트/리소스검토/tutorial-skip-runtime.json`에 기록한다. 진행 중 부상·예약 상태의 보존은 명시적인 저장 fixture로 구분한다. 실제 화면 크기는 1920×1080, 1280×800에서 확인한다.

최종 검수 **PASS**: 컴파일 오류 0, 실제 UI 클릭·독립 저장/재로드·첫 탐험과 두 번째 방문·정상 새 게임 진행·진행 중 부상과 예약 보존·관리표 읽기까지 8개 확인 항목 통과. 1920×1080 및 1280×800의 대화/메뉴 화면에서 버튼·문구의 배치와 잘림을 직접 확인했다.

검수 중 발견한 관리표 읽기와 시설 복구 버튼의 중첩은 같은 안내판에서 한 버튼만 표시하도록 수정했다. 관리표를 읽은 뒤 남던 옛 안내도 해제하되 다른 작업 완료 알림은 덮어쓰지 않는다. 두 번째 방문의 NPC 발견 가능성을 확인했으며 이번 검수에서 전투 전체를 플레이한 것은 아니다.

# 징후와 조우 선택 — 2026-09-22

> 2026-09-23: 교전 버튼을 활성화하고 3×3 전투·결과·수색 복귀를 연결했다. 최신 범위는 [분리 진형 전투 구현](분리진형전투-구현.md)을 따른다. 아래 교전 미연결 표기는 최초 구현 이력이다.

수색 → 발소리 예고 → 후속 수색 턴의 조우 판정 → 기다리기/복도 후퇴 → 탐험 복귀를 연결했다. 교전은 전투 연결 전까지 비활성으로 명시한다. 승인 UI09의 왼쪽 사건 종이와 세 선택 구조를 사용하며 기존 오락실 배경을 유지한다.

## 현재 규칙 (시제품)

- 수색 실행 확인 때만 AfterSearch를 호출한다. 같은 탐험 턴은 중복 판정하지 않는다. UI 열기·취소·가방 확인으로 주사위를 다시 굴리지 않는다.
- 누적 소음 2 이상에서 발소리 배너를 먼저 표시한다. 예고가 처음 뜬 수색 턴에는 조우하지 않는다. 이후 수색에서 `min(70, 15 + 소음 × 7)%`로 조우한다. 프리팹에서 임계값과 확률을 변경할 수 있다.
- 감염자 수는 1~2명으로 표시하는 시제품 데이터다. 전투 적 구성과 연결되지는 않았다. 실제 발소리 음원은 아직 없고 텍스트로 예고한다.
- 조우 중에는 탐험 UI 입력을 막는다. Esc는 하위 행동 확인창만 닫으며 조우 자체를 무료로 해제하지 않는다.
- 숨어 기다리기: 1턴, 소음 2 감소(최저 0). 기본 이탈 확률 65%, 실패마다 다음 확률 15%p 감소, 최저 20%. 실패하면 조우 유지. 현재 부상·아이템 손실은 없고 비용을 확인창에 설명한다.
- 복도로 물러나기: 실제 방 이동 1턴을 사용한다. 별도의 조우 턴을 더 차감하지 않는다. 대원과 개인 가방을 유지하고 오락실의 수색도·발견물도 보존한다. 미방문 복도도 기존 이동 규칙에 따라 방문 처리한다.
- 해결 후 수색 2회 동안 조우 판정을 쉬고, 다음에는 다시 예고부터 시작한다. 이동·대기 자체에 별도의 새 조우 판정은 아직 없다.
- 기다리기 성공 시 중단했던 수색 화면으로 복귀하며, 수색이 이미 완료됐다면 발견물 분배 화면을 연다. 완료 보상은 기존 1회 판정 결과를 유지한다.

턴 비용은 기존 탐험 카운터를 사용한다. 분 단위 환산, 체력 피해, 밴딧, 전투, 장비와 직업별 회피 보너스, 위험 상태 파일 저장은 후속이다. 새 원정에서 예고와 재조우 유예는 초기화한다. 미연결 교전 버튼을 전투 완료로 보고하지 않는다.

# 사운드 제작과 Suno 사용 방향

기록일: 2026-09-24

## 사용자 확정 방향

사용자는 Suno를 한 달 구독하여 필요한 음원을 제작·다운로드하고 구독을 해지하는 방향을 확인한 뒤, 우선 기록만 요청했다.

1. 제작할 음원 목록과 프롬프트를 준비한다.
2. Suno Pro 월 결제로 한 달 구독한다.
3. 필요한 음원을 제작하고 선별한다.
4. 구독이 활성화된 동안 사용할 음원을 공식 다운로드 경로로 받아 보관한다.
5. 자동 갱신을 해지한다. 확보한 사용 권리를 바탕으로 이후 게임 제작·출시에 활용한다.

현재는 방향 기록만 완료했다. 구독·결제·음원 생성·다운로드·해지는 수행하지 않았다. 이번 요청은 해당 작업을 지금 실행하라는 지시가 아니다.

## 대화에서 확인한 조건

- 2026-09-24 공식 안내 확인 기준, Pro 월 결제는 US$10 + 세금. 월 $8 표시는 연간 결제 기준이다.
- 당시 Pro 안내는 월 생성 크레딧 2,500개와 곡 다운로드 20회였다. 생성 크레딧과 다운로드 한도는 별도다.
- 추가 크레딧만 구매하는 방식 대신 유료 구독을 사용한다. 추가 크레딧 사용에도 활성 구독이 필요하다.
- 유료 구독 중 공식 경로로 허용된 다운로드를 확보한 음원의 상업적 사용 권리는 구독 종료 후에도 유지된다는 안내를 확인했다. 단순 생성만으로 절차가 끝났다고 보지 않는다.
- 실제 구매·제작 시점에는 요금과 최신 약관을 다시 확인한다. 다른 사람의 곡을 리믹스하는 경우까지 같은 권리가 있다고 일반화하지 않는다.

## 제작 후보 — 세부 목록은 아직 미확정

- BGM: 정착지 / 탐험 / 이상현상, 우선 3종 제안.
- 정착지: 절제된 피아노와 낮은 현악기, 불안 속 작은 온기.
- 탐험: 낮은 지속음과 희미한 맥박, 환경음을 들을 여백.
- 이상현상: 익숙한 선율이 조금씩 어긋나는 변주.
- 특수 효과음: Suno Sounds의 One Shot / Loop로 크리쳐와 이상현상 소리를 실험한다. Pro에서도 사용할 수 있다는 공식 안내를 확인했다.
- 일반 효과음: 버튼·종이·발소리 등은 무료 CC0 리소스부터 검토한다. 개별 음원 청음과 최종 선별은 아직 하지 않았다.
- 게임 적용 전 반복 구간·음량·장면 전환을 편집하고 검수한다.

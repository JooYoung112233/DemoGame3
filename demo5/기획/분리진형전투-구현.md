# 분리 진형 전투 UI — 2026-09-23

> 2026-09-24 최신: 규칙·연출은 [전투 손맛 1차](전투손맛-1차.md)를 우선한다. 아래 임시 전투 규칙(근접 90%, 감염자 체력 3·물기 75%, 방어 피해 −1, 철수 확정 성공, 승리 소음 +2 등)은 당시 기록이다.

승인 UI10을 기준으로 조우의 교전 버튼 → 양 진영 3×3 전투 → 결과 → 수색/복도 복귀를 연결했다. 전투 아이템 선택은 다음 화면이며 현재 아이템 버튼은 비활성이다. 전체 전투 시스템 완성이 아니라 UI와 기본 교전 흐름을 검증하는 단계다.

## 화면 및 버튼

| 화면 | 입력 | 연결·효과 |
| --- | --- | --- |
| 조우 선택 | 교전 | 실제 동행 대원과 조우한 감염자 수로 전투 시작. 열기만으로 시간/탄약 차감 없음 |
| 전투 | 자기 진형의 빈 인접 칸 | 현재 대원 위치 변경. 차례당 최대 1회, 상하좌우 인접 칸만, 점유 칸 불가 |
| 전투 | 근접/사격 | 행동 종류와 명중률·예상 피해 미리보기. 선택만으로 비용 차감 없음 |
| 전투 | 적 칸 | 살아 있는 적 대상으로 변경 |
| 전투 | 하단 공격 확정 | 명중 판정 후 다음 대원 차례. 사격은 현재 대원 개인 가방의 탄약 1 사용. 빗나가도 탄약 사용 |
| 전투 | 방어 | 다음 자기 차례까지 받은 피해 1 감소, 행동 소모 |
| 전투 | 철수 | 확인창. 취소/ESC는 전투로 복귀하고 비용 없음 |
| 철수 확인 | 철수 · 1턴 | 결과 화면 → 실제 복도 이동. 현 시제품은 철수 확정 성공 |
| 결과 | 수색으로 돌아가기 | 기존 수색도·발견물 유지. 완료 컨테이너는 발견물 화면, 미완료는 수색 화면 |
| 전원 행동 불능 | 시작 화면으로 | 탐험 재개 없이 시작 화면으로 이동. 저장 불러오기는 아직 없음 |

상단은 실제 차례·인원 카드, 하단은 대원/대상/행동 세 영역이다. 현재 차례는 노란 카드와 받침대, 적 진형은 붉은 선으로 표시한다. 전투·결과 상태에서는 배경의 탐험 버튼과 ESC로 우회할 수 없다. 행동 처리 중 연속 입력과 결과 중복 확정을 막는다.

## 임시 전투 규칙

- 대원 순서 → 살아 있는 감염자 순서. 살아 있는 인물만 차례를 받는다.
- 근접 피해 2, 기본 명중 90%. 전열에서만 가능.
- 사격 피해 3, 기본 명중 75% + 대원 Aim. 후열 1칸마다 -5%p, 전선 간 차이마다 -5%p. 최종 20~95%.
- 감염자 체력 3, 명중 75%, 피해 1. 가까운 전열을 우선 공격한다.
- 체력 피해는 실제 Adventurer에 즉시 반영한다. 탄약도 개인 가방/전체 자원에 반영한다. 거점 탄약을 원격 사용하지 않는다.
- 승리 결과 확인 시 탐험 1턴, 소음 +2. 철수는 실제 복도 이동 1턴만 사용하여 이중 차감하지 않는다. 전투 라운드는 탐험 턴과 별도 표시한다.
- 승리 자체의 새 보상은 없다. 조우 직전 완료된 수색 보상을 다시 굴리거나 복제하지 않는다. 전투 종료 후 기존 재조우 유예 2회 적용.
- 엄폐·무기별 스킬·속도별 순서·4×3 확장·상태이상·전투 아이템·음향·세이브는 후속. 수치와 철수 성공 규칙은 시제품용이다.

## 시안 비교와 제한

UI10의 상단 차례, 두 개의 3×3 진형, 하단 대원/대상/행동 세 영역을 유지했다. 기존 펀플로 생존자 폰트와 종이 자산을 사용한다. 글자·숫자는 이미지에 합치지 않는다.

탐험 화면의 오락기와 상자 위에 전투판이 겹치는 문제를 줄이기 위해 교전 중에는 기존 `Assets/Art/Backgrounds/arcade-unlit-v1.png`의 넓은 폐상가 바닥 구도를 사용한다. 이는 같은 장소의 전투용 별도 구도이며 원래 오락실 그림과 완전히 동일한 배경은 아니다. 종료하면 원래 방 원화와 수색 상태를 복원한다. 실제 방 맞춤 전투 바닥 원화는 필요 시 후속 보완한다.

진형은 말 아래에 그리는 월드 메시, 캐릭터는 기존 Sprite Lit 프리팹으로 URP 2D 라이트를 받는다. 걷기/공격 스프라이트 애니메이션 없이 칸 위치 변경과 결과 표시로 동작한다. 투명 여백까지 발로 계산하지 않도록 이미지의 실제 알파 영역으로 접지 위치를 맞췄다.

시안과 다른 부분: 명확한 공격 확정 버튼을 하단에 추가했고, 실제 게임 데이터에 맞춰 피로 대신 개인 탄약/가방을 표시한다. 근접은 기존 쇠지렛대 아이콘, 철수는 기존 왼쪽 화살표, 방어는 벡터 방패를 사용한다. 감염자는 기존 77×116 임시 이미지로 큰 최종 원화가 아니며 대원과 테두리/해상도가 다르다. UI 배치와 전투용 배경 구도는 사용자 시각 검토 대상이다.

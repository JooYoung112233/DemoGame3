# UI03 원정 짐 꾸리기
2026-09-22. 승인 시안 03-원정짐꾸리기-v2와 최신 하단 버튼 규칙 적용.

## 연결
정착지 출입구 → 원정 계획(UI02) → 짐 꾸리기(UI03) → 준비 내역 확인.
원정 계획으로 돌아가면 목적지·참여 대원이 유지된다. 이미 옮긴 물자는 취소되지 않고 각 대원 가방에 남는다.
이 단계는 확인창까지 구현했다. 실제 출발·이동·조우·시간 차감은 아직 연결하지 않았다.

## 물자 규칙
SettlementInventoryPanel의 공통 소유 데이터를 사용한다. 보급품/탄약은 전체 보유량에서 가방 배분량을 빼서 창고 수량을 계산한다. 재료는 제작 예약분을 제외한 수량만 이동할 수 있다. 종류당 한 슬롯을 쓰며 동일 종류 추가 적재는 새 슬롯을 쓰지 않는다. 무게/수량별 스택 한도는 후속 규칙이다.
목적지에서 선택한 참가자만 상단에 표시한다. 인원이 많으면 가로 스크롤. 창고/가방은 세로 스크롤 및 하단 화살표.
보급품 없이도 준비 확인은 허용하되 경고한다. 가짜 물/치료/도구 수치를 넣지 않고 실제 보급품·탄약·빈 공간을 합산한다.
세션 내 유지이며 저장 파일 연동은 미구현이다.

## 편집 위치
Assets/Prefabs/Settlement/ExpeditionPackingPanel.prefab: 전체 화면.
ExpeditionPackingReview.prefab: 확인창. PackingItemSlot.prefab: 좁은 슬롯용 글자 20.
ExpeditionMemberCard.prefab: 공유 대원 카드. 기존 인벤토리 슬롯은 수정하지 않았다.
아트/원정짐꾸리기-v1/PSD/packing-layout.psd: 개별 패널·카드·슬롯·버튼 레이어.
공통 원화와 아이콘은 기존 승인 자산을 재사용했다. PSD 크기는 배치 편집용 확대이며 디테일 복원 아님.

## 검증
VerifyExpeditionPlan.Flow: 새 화면 연결, 선택자만 가방 표시, 의무관 초상 일치, 기존 개인 가방과 소유권 공유, 작업 예약 및 체력 제한.
VerifyExpeditionPacking.Flow: 실제 레이캐스트 클릭, 수량 증감·부분 반환, 대원 간 소유권 분리, 용량 초과 차단, 확인창 입력 차단, 돌아가기와 재진입, 텍스트 높이.
Unity Editor에서 검증했으며 실행 파일 빌드 생략.

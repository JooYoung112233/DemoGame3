## 실제 구현 흐름

1. 기존 빈 정착지 도입: 주변 확인 → 남은 헝겊/물 → 바닥 잠자리 → 휴식 → 임시 보관함.
2. 목표 버튼으로 첫 원정 계획을 연다. 폐상가 입구 상자에서 목재·고철·천을 회수한다.
3. 첫 귀환 후 창고(목재2/고철1), 작업대(목재3/고철2)를 차례로 안내한다.
4. 재료가 가방에 남으면 보관 화면으로, 작업을 예약했으면 시간 진행으로 연결한다. 창고를 먼저 복구하도록 시설 기본 선택도 변경했다.
5. 작업대 서랍에서 발견한 ‘접힌 관리표’ 사건: 폐상가 복도 끝 보관실의 비축 물자와 알 수 없는 경고. 관리표는 물품 보상을 주지 않는다.
6. 밧줄 → 못2개 → 지렛대 제작을 실제 재고로 안내한다. 제작 후에는 가방 휴대를 안내한다.
7. 보관실 비축 선반 수색 뒤 정착지 귀환을 확인하면 첫 생활 기록을 마무리한다. 수색 실패/고갈로도 진행이 막히지 않도록 특정 물품 획득 수량을 완료 조건으로 강제하지 않는다.
8. 이후 기존 시설 복구·연구 버튼을 다시 표시한다. 연구대 전용 버튼은 연구대 설치 후 표시한다.

목표를 따른다고 재료/시간을 자동 지급하지 않는다. 플레이어가 다른 시설부터 복구하거나 재탐험하는 행동을 금지하지 않는다. 관리표 경고는 첫 단서이며 실제 두드림 이벤트나 새 지역 구현은 다음 범위다.

## 사건 기록 열람 (2026-09-24)
- 메인 HUD의 기록 버튼에서 정착 기록·관리표·첫 생활·밤의 두드림을 다시 읽는 화면을 연다.
- 발견 상태에 따라 목록을 숨겨 미발견 사건의 제목/내용을 미리 공개하지 않는다. 기존 저장 플래그를 읽으며 저장 필드나 버전은 추가하지 않았다.
- 밤 사건은 실제 저장된 선택(15분 청취/30분 관찰)에 맞춘 단서만 표시. 미결이면 사건 이어서 확인 버튼으로 연결하고, 완료했다면 재실행 버튼은 제공하지 않는다.
- 최근 귀환 기록 버튼으로 기존 귀환 화면에 연결한다. 귀환 데이터가 없으면 해당 버튼을 숨긴다.
- 열람/화면 이동은 시간·물품·선택 상태를 변경하지 않는다.
- 별도 SettlementRecords.prefab: 왼쪽 목록, 오른쪽 본문, 기존 종이·먹색 팔레트, 공통 제목/강한 딤/좌측 하단 돌아가기.
- VerifySettlementRecords.Load/Run 통과: 저장된 밤 선택 복원, 4종 본문 높이, 미발견 목록 숨김, 열람 전후 시간/진행 불변, 귀환 화면 연결과 HUD 복원, 보류 사건 이어서 열기.
- 실제 캡처에서 짧은 제목·하단 상태 줄이 폰트 높이 때문에 사라진 점을 수정하여 최종 화면 확인. BuildSettlementRecords에 최종 치수 반영.
- 최신 화면: Assets/Screenshots/OpeningChapter/14-settlement-records.png.
- 전투·탐험 파일 변경 없음. 분리 작업본만 반영, 원본 미병합.

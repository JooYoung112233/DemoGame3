# 수색 진행과 발견물 분배 — 2026-09-22

기존 배정 저장 전용 단계를 실제 수색 1턴 진행으로 확장했다. 승인 UI08의 현장 보관함 / 개인 가방 / 상세와 수량 구성을 사용한다. 정착지 내부 이동은 변경하지 않았다.

## 흐름

사물 클릭 → 방식·담당자·지원 역할 → 1턴 확인 → 수색도 증가 → 완료 시 물건별 확률 판정 → 현장 보관함 → 대원과 수량 선택 → 가방에 넣기. 진행 중 닫거나 다른 방으로 이동해도 수색도를 유지한다. 완료된 사물은 이후 클릭 시 남겨둔 발견물 화면을 바로 연다. 빈 결과도 표시한다.

수색이 시작되면 해당 사물의 방식과 지원 역할을 고정한다. 완료 전 보상은 없으며 완료 시 한 번만 판정한다. 순차적으로 한 사물의 1턴을 실행하므로 병렬 작업 예약·일괄 턴 진행은 아직 없다. 담당자는 다음 턴에 교체할 수 있다.

## 시제품 규칙 — 조정 가능

- 빠름/보통/정밀: 총 1/2/3턴. 클릭해 확인할 때마다 1턴만 진행한다.
- 기본 발견 확률 대비 빠름 -15%p, 보통 그대로, 정밀 +15%p. 물건별 기본 확률과 수량은 ExpeditionLootPanel 프리팹의 Sites/Drops에서 편집한다. 확률은 0~100%로 제한한다.
- 시작 시 생존 동료가 함께 수색하면 +10%p를 고정한다. 망보기 동료가 있는 턴은 소음 -1. 기본 소음은 방식별 턴당 3/2/1이다. 이 망보기 효과는 검증용이며 조우 예고 체계가 생기면 재검토한다.
- 손전등·배터리·캐릭터 특성·조우 판정은 아직 연동하지 않았다. 소음은 누적값까지만 구현했다.
- 방 이동과 수색은 같은 탐험 턴 카운터를 사용한다. 1턴의 분 단위 환산은 미정이므로 생활 시계는 방 이동·수색으로 진행하지 않는다. 목적지 왕복 이동 시간은 기존대로 진행한다.

## 가방 및 현장 물건

기존 인벤토리와 같은 데이터다. 물건 한 종류가 한 슬롯을 사용하고 같은 종류는 기존 스택에 합친다. 스택 최대 수량·무게는 아직 없다. 빈칸이 없으면 새 종류 가져오기를 막으며 다른 대원을 선택하거나 가방 물건을 현장에 둘 수 있다. 수량 최소/최대/잔여량을 검사한다.

보급품·탄약의 캠페인 합계는 현장 획득 때 증가하고 현장에 내려놓을 때 감소한다. 개인 가방 보유량을 제외한 공용 창고 값은 이 과정에서 늘지 않는다. 제작 재료는 가방으로 들어가며 귀환 후 창고로 옮길 때 기존 제작 재료 재고에 합산한다. 귀환 HUD도 갱신한다.

남은 물건이 있으면 돌아가기/Esc에서 확인창을 띄운다. 계속 정리는 화면을 유지하고, 두고 나가기는 잔여량을 사물에 보존한다. 같은 Settlement 씬이 유지되는 플레이 세션에서는 귀환·재방문 후에도 수색 완료와 남은 물건이 유지되어 보상을 재생성하지 않는다. 씬 재생성·게임 재실행 후 저장 복원은 아직 없다. 현재 장소는 폐상가 하나이므로 사물 인덱스로 상태를 보관하며 장소 확장 시 장소 ID를 키에 포함해야 한다.

## 검증 및 실제 화면

VerifySettlement.Flow, VerifyLoot.Flow, VerifyLoot.Edges 통과. 실제 클릭으로 확인 취소, 한 턴만 소비, 확인 연타, 중단과 왕복, 조기 보상 방지, 수색 방식 고정, 완료 사물 재판정 방지, 가방 용량·동일 종류 합치기·수량·대원 전환, 현장 내려놓기/재획득, 귀환과 재방문, 자원 합계와 HUD, 남은 물건 확인, 빈 결과, 망보기 소음, 스크롤 하단 안내 표시/해제를 확인했다. 컴파일 오류 없음. 빌드는 생략했다.

Flow/Edges는 검증 중 확률을 100/0으로 임시 바꾸고 복원한다. 최종 loot-v1.png는 새 플레이에서 프리팹 기본 확률로 실행한 실제 게임 화면이다. 테스트 전용 loot-test-v1.png와 구분한다.

UI08과 비교해 세 영역과 상단 대원 선택을 유지했다. 실제 두 대원과 3슬롯 용량을 사용하고 최신 규칙대로 돌아가기는 좌하단에 배치했다. 기존 개별 종이·아이콘을 재사용하므로 원본 시안과 그림/테두리는 완전히 동일하지 않다. 실제 캡처에서 기존 안내가 뒤에 비치는 문제를 수정했다. PSD는 레이어/알파/좌표를 재검증한 배치 원본이며 확대가 디테일 복원은 아니다. 시각 승인 대기.

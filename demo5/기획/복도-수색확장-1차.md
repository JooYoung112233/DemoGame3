# 복도 수색 확장 1차 — 2026-09-23

기존 폐상가 복도에 배전함과 보관 상자 수색을 연결했다. 오락실 3곳 + 복도 2곳으로 총 5곳이며, 새 방 배경을 추가한 것은 아니다. 기존 배경의 배전함/상자 위치에 분리 UI 버튼과 상태 표시를 배치했다. 잠긴 철문과 닫힌 문은 기존 상태를 유지한다.

## 규칙과 임시 데이터

| 대상 | 조건 | 기본 후보 |
| --- | --- | --- |
| 복도 배전함 | 담당자 가방의 간이 지렛대. 첫 수색 때 개방하며 도구는 소모하지 않음 | 고철2/85%, 못2/80% |
| 복도 보관 상자 | 도구 없음 | 미정수 물2/85%, 천 조각2/75%, 통조림1/60% |

수색 방식·동료 역할에 따른 보정은 기존 시스템을 사용한다. 위 수량/확률은 임시 편집값이다. 배전함 개방 이후에는 도구 없이 진행을 재개할 수 있다. 이동은 기존 1턴/10분이며, 확인·취소는 시간을 쓰지 않는다.

다른 방의 수색/발견물 창은 열 수 없다. 방 이동·귀환·저장 뒤 재방문해도 진행도, 열린 덮개와 남긴 물품을 유지한다. 완료 대상은 다시 추첨하지 않는다. 복도 조우의 후퇴 목적지는 오락실이며 그에 맞는 확인 문구를 표시한다.

## 편집·저장

- `ExpeditionLootPanel.Site.Room`: 오락실0, 복도1, 이동 문 슬롯−1. 문은 수색 요약에서 제외한다.
- 기존 사물/저장 ID 및 문 인덱스3을 유지하고 복도 ID를 4·5에 추가했다. `CampaignPersistence.SiteIds`의 안정적인 ID를 사용한다.
- 저장 스키마는 기존 버전7 유지. 이전 저장의 오락실 진행을 보존하며 새 복도 대상은 미수색으로 시작한다.
- `ConnectCorridorSearch.Run` 다음 `ConnectSearchStatus.Run`으로 프리팹 데이터·버튼·상태 표시를 연결한다. 배치와 보상은 Inspector에서 편집 가능하다.
- 기존 아이콘·배경 재사용. 신규 원화는 제작하지 않았다.

## 검증

`VerifyCorridorSearch.Flow`, `Persistence`, `LegacyPreview` 통과.

- 실제 레이캐스트 클릭: 이동 취소/중복 확정, 방별 버튼 표시, 원격 수색 차단.
- 도구 없음 차단, 도구 비소모, 개방 뒤 도구 제거·방 왕복 후 재개.
- 완료/회수/고갈 표시 및 중복 추첨 방지, 상자 부분 진행.
- 격리 저장(`Temp/CorridorSearchVerification`) → 씬 복원 → 재방문, 조사 기록과 5곳 요약 유지.
- 복도 조우 → 오락실 후퇴 → 복도 재진입 시 완료 물품 유지. 조우 분기 검증 때만 실행 인스턴스 확률을100%로 고정했다.
- 확장 전 실제 v7 파일(`Temp/SearchStatusVerification`)의 고갈/부분 진행 유지 및 새 대상 초기화.
- 텍스트 높이 검증과 실제 1920×1080 화면 검수. 사용자 저장 변경과 실행 파일 빌드는 생략했다.

실제 화면: `Assets/Screenshots/SearchStatus/corridor.png`, `corridor-search.png`. 외곽 HUD/배경/대원 배치를 유지하고 신규 버튼을 소품 위치에 맞췄다. 다음 범위는 문 너머 연결 방과 반복 탐험 콘텐츠 확장이다.

2026-09-23 후속: 정식 제목 **이웃 아닌**. [비전투 완성 작업 목록](비전투-완성-작업목록.md)을 추가했다. 공통 메뉴·기본 설정·정착지의 3슬롯 파일 저장/불러오기·계속하기를 연결하고 검증했다. [현재 저장 범위와 한계](설정과-저장불러오기-구현.md). 아래 표의 저장 미구현 표기는 당시 상태이며 최신 설명을 우선한다.

2026-09-23 사용자 결정. 전투 방식·밸런스·이펙트·연출의 개선은 마지막에 진행한다. 먼저 비전투 콘텐츠로 반복 플레이 흐름을 확립하고, 그 자원·시간·대원 상태를 기준으로 전투의 재미를 조정한다.

## 제작 범위와 유지 기준

- 정착지 운영 → 원정 준비 → 탐험·수색 → 발견물 선택·분배 → 귀환 → 소비·제작·회복 → 다음 원정의 순환을 우선 완성한다.
- 현재 전투 시제품은 조우 진입, 결과, 탐험 복귀 연결을 유지한다. 진행을 막는 오류는 수정하되 전투 규칙 재설계·수치 조정·전용 연출은 뒤로 미룬다.
- 승인 그래픽과 개별 UI 프리팹을 유지한다. 새 이미지가 필요한 경우 개별 원본과 실제 분리 레이어 PSD를 제공한다.
- 화면 변경 후 실제 Unity 캡처를 공유한다. 외곽 여백, 상·하단 기준선, 글자·아이콘 비율, 인원/아이템 증가에 따른 스크롤과 페이지를 확인한다.
- 아래 세부 수치·추가 콘텐츠는 작업안이다. 아직 구현하지 않은 내용을 완료나 확정 규칙으로 표시하지 않는다.

## 코드 확인 결과

| 영역 | 현재 상태 | 필요한 작업 |

| 정착지 HUD·시설·대원 | 개별 프리팹, 목록 페이지 구현 | 시간·상태 변화와 표시 동기화 |
| 휴식 | 담당자와 시간 예약 | 시간 진행, 회복 결과, 완료·중단 |
| 제작·수리 | 담당자·수량·재료 예약과 취소 | 실제 재료 소모, 생산품 지급, 시설 효과, 완료 |
| 개인 가방·공용 창고 | 수량 이동, 용량 제한 구현 | 제작물 및 귀환 후 정리 흐름 연결 |
| 원정 | 대원·장소·짐 선택과 출발 | 체류 시간 및 거점 작업과 같은 시간 기준 사용 |

| 귀환 | 대원·가방 유지 및 정착지 복귀 | 결과 요약, 정리, 다음 탐험 목적 연결 |
| 시간 | 이동 시간과 탐험 턴이 별도 | 중복 차감 없이 공통 시간 처리 |
| 저장 | 설정만 저장, 캠페인 저장 없음 | 대원·물자·시간·예약·시설·장소 상태 복원 |

## 진행 순서와 완료 기준

### 1. 시간과 작업 완료

2026-09-23: 첫 구현 및 Unity 검증 완료. [실제 연결 범위·임시 수치·남은 항목](시간진행과-작업완료-구현.md). 저장은 아직 미구현이다.

가장 먼저 구현한다. 시간 진행 전에 경과 시간과 끝나는 작업을 알려준다. 휴식과 제작은 같은 경과 시간 동안 병행되며 남은 시간을 표시한다. 작업이 끝나면 담당자가 해제되고 회복·생산·수리 결과를 반영한다. 제작 예약 재료와 실제 소모를 구분해 취소·완료 시 중복 지급/차감이 없도록 한다.

완료 기준: 서로 다른 길이의 두 작업, 일부 진행 후 중단, 재료 부족, 날짜 변경, 원정 중 거점 잔류 작업까지 결과가 일치한다. 휴식 회복량·시설 효과는 조정 가능한 임시 데이터로 둔다.

### 2. 귀환과 물자 활용

2026-09-23: 귀환 비교·가방별 정리·전원 입고·최근 기록 재열람 구현. [검증 및 한계](귀환정산과-재방문-구현.md).

원정에서 가져온 물품과 소비량, 부상, 경과 시간을 요약한다. 개인 가방에서 창고로 정리하고 획득 재료로 도구 제작·시설 수리를 할 수 있게 연결한다. 결과창을 닫거나 다시 열어도 보상은 중복 지급되지 않는다.

완료 기준: 빈손 귀환, 가득 찬 가방, 중도 귀환, 제작 예약이 있는 창고를 모두 처리한다.

### 3. 탐험 콘텐츠 확장

2026-09-23 추가: 손전등 제작·휴대·현장 교환에 따른 조명 지원 활성화와 발견 확률 보너스 연결. [구현·임시 규칙·검증](손전등과-조명지원-구현.md). 배터리/빛 연출은 아직 미구현이다.

2026-09-23 추가: 수색 후보 아이콘·수량·최종 확률, 남은 시간과 턴당 소음 예측 연결. [표시 규칙·검증](수색후보와-확률예측-구현.md).

2026-09-23 추가: 기존 탐험 구조 유지. 현장 개인 가방 아이콘 화면과 동행 대원 간 양방향 물자 교환 구현. [흐름·검증](현장가방과-동료교환-구현.md). 12×6 탐험 보드 제안은 철회되어 구현하지 않는다.

2026-09-23: 오락기 정비판의 지렛대 사용, 담당자 가방 조건, 개방/수색 상태 유지 구현. [작업 카드와 도구 수색](작업카드와-도구수색-구현.md). 새 방 확장은 아직 남아 있다.

현재 폐상가 한 장소에서 연결된 방과 수색 대상의 차이를 먼저 만든다. 빠른/보통/정밀 수색의 시간·발견·소음 선택과 캐릭터 특성, 휴대 도구의 의미를 연결한다. 문·수색물·발견물 상태를 재방문에도 보존하고, 물자가 다시 생기는 경우는 별도 정책으로 표시한다. UI 확인이나 취소만으로 시간이 흐르지 않는다.

완료 기준: 같은 물체 반복 보상 방지, 진행 중 수색의 중단/재개, 귀환 길 확보, 가방 부족으로 무엇을 두고 올지 선택 가능. 기본 장소가 검증된 뒤 다른 장소와 배경을 추가한다.

### 4. 비전투 목적과 생활 콘텐츠

2026-09-23 성장 기획 추가: [정착지 성장과 생활 특성](정착지-성장과-생활특성-기획.md). 시작 시설은 1레벨, 초기 1층 기본 구역은 최대 3명이며 방·계단으로 연결된 거주 공간을 해금해 한도를 늘린다. 담당자별 요리 속도/효율과 시설 업그레이드를 설계했다. 사용자 요청에 따라 현재는 기획만 반영하며, 구체 보너스·확장 후 인원·최대 시설 레벨은 제안 수치다.

수리해야 할 시설, 부족한 도구와 물자, 대원의 상태가 다음 탐험 목적을 만든다. 조리·치료·정수·방문자/거래는 기존 생활 기획을 바탕으로 필요한 것부터 추가한다. 아직 확정되지 않은 허기·갈증·사기 게이지를 한꺼번에 추가하거나 새 소품을 이유로 승인 배경을 재생성하지 않는다.

완료 기준: 전투 없이도 지금 누구를 쉬게 할지, 무엇을 제작할지, 어디서 무엇을 가져올지 판단할 수 있다.

### 5. 저장·불러오기와 연속 플레이

저장 구조는 1단계부터 고려하고 실제 저장 UI는 핵심 상태가 갖춰진 뒤 연결한다. 대원 식별자는 표시 이름과 분리한다. 시간, 체력, 개인/공용 물자, 예약과 남은 작업, 시설, 탐험 장소의 상태를 함께 저장한다. 우선 안전한 저장 시점을 명시하고 저장 불가 상태를 허용하는 것처럼 표시하지 않는다.

완료 기준: 종료 후 이어하기로 동일 상태 복원, 손상/구버전 데이터 안내, 새 게임과 기존 저장 구분. 임시 데이터로 가짜 불러오기 성공을 만들지 않는다.

### 6. 비전투 전체 검수 후 전투 개선

새 게임부터 여러 번의 원정·귀환·생활·저장 복원까지 실제 UI로 연속 검수한다. 기능 연결과 자원 중복, 진행 막힘, 목록 증가, 화면 정렬을 먼저 해결한다. 비전투 흐름을 사용자와 확인한 다음 전투 방식 → 전투 밸런스 → 피드백·이펙트·연출 순으로 다듬는다.

## 이번 기록의 범위

계획 수립 후 1단계 시간 진행과 작업 완료를 구현했다. 2~6단계가 완료됐다는 뜻은 아니다. 귀환 결과와 물자 정리도 구현했다. 다음 구현 시작점은 **도구를 쓰는 수색 대상과 연결 방 확장**이다.


2026-09-23 추가: 구현된 주요 화면/순환 검수 및 정착지 응급 처치를 연결했다. [검수 범위·수정·임시 수치·한계](전체검수와-응급처치-구현.md). 연결 방 확장은 계속 미완료이며, 기존 천 조각을 쓰는 생활 기능을 먼저 작은 범위로 연결했다.

2026-09-23 추가: 제작대 재료 안내 카드와 가방/제작법/원정 계획 연결 구현. [범위와 검증](제작대-재료안내-구현.md). 나무 판자는 현재 수색 드롭에 없어 공급처 추가가 필요하다. 연결 방 확장 시 우선 연결한다.

2026-09-23 후속: [낡은 탁자 판자 회수](탁자-나무판자회수-구현.md)로 나무 판자 공급처를 연결했다. 기존 탁자 수색에서 2개/기본75%로 회수 가능하며 완료 후 재지급하지 않는다. 기존 '나무 판자 획득처 미확인' 기록은 이 변경 이전 상태다.

2026-09-23 후속: 제작대 획득처 안내에 미완료 수색 수/현장 잔여 물자/고갈 상태를 반영했다. 물자가 없는 곳으로 안내 버튼을 통해 다시 출발시키지 않는다. [검증 및 실행 세션 한계](제작대-재료안내-구현.md). 연결 방 확장과 종료 후 저장 복원은 여전히 남아 있다.

2026-09-23 후속: 물자비축을 식량 준비 UI로 분리했다. [조리/휴대식/간편식 UI 범위](식량준비-UI-구현.md). 현재 시안 재고로 조리법·담당자·횟수·구성 확인을 조작할 수 있으며 실제 조리 생산·재료 소비·배급은 후속 단계다.

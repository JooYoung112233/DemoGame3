# 전투 손맛 1차 — 2026-09-24

사용자 요청: 현재 인게임 전투를 파악해 의견을 내고 제작한다. 가장 중요한 것은 **전투하는 맛**이다. [비전투 우선 제작 계획](비전투-우선-제작계획.md)은 전투 개선을 마지막으로 미뤘지만, 이번 작업은 사용자가 직접 요청해 진행했다. 비전투 순서는 그대로 유지한다.

기존 분리 진형 UI(UI10)의 배치·프리팹·흐름(조우 → 교전 → 결과 → 수색/복도 복귀)을 그대로 두고, 규칙과 연출만 보강했다. [기존 구현 기록](분리진형전투-구현.md)

## 작업 전 진단

| 영역 | 기존 상태 | 문제 |
| --- | --- | --- |
| 타격감 | 결과가 하단 글 한 줄로만 나왔다. 말은 순간이동하고 효과음이 없었다. | 명중·빗나감·처치가 화면의 말에서 보이지 않았다. |
| 적 행동 | 감염자가 전열에 고정되어 가장 가까운 대원만 때렸다. 예고도 없었다. | 위치를 바꿀 이유가 약했다. |
| 수치 | 사격 3 = 감염자 체력 3이라 한 방에 끝났다. 물기 1은 방어 1로 완전히 막혔다. | 사격만 고르게 되었다. 방어는 항상 안전한 선택이었다. |
| 철수 | 확인만 하면 반드시 성공했다. | 빠질지 버틸지 고민할 필요가 없었다. |

손맛은 세 순간으로 나눠 보았다. (1) 누르기 전의 **기대**: 예측 정보. (2) 누르는 순간의 **타격감**: 연출과 소리. (3) 결과의 **파급**: 다음 선택에 주는 영향. 기존 전투에서는 세 가지가 모두 비어 있었다.

## 방향 (의견)

1. **예고가 있는 전투**: 감염자가 다음에 무엇을 할지 보여준다(위협선, 물기 확률). 이동하거나 방어하면 예고가 바로 바뀐다. 그래서 칸 이동이 실제 선택이 된다. For The King II의 진형 분리와 Into the Breach식 정보 공개를 섞었다.
2. **총은 확실하지만 시끄럽다**: 사격은 멀리서도 강하지만 탄약·소음·증원이라는 비용을 낸다. 근접은 조용하지만 전열에 서야 한다. 매 차례 “쏠까, 붙을까, 막을까”를 고른다.
3. **애니메이션 없는 타격감**: 최소 모션 규칙을 지킨다. 종이 말이 들리고, 기울고, 부딪히고, 쓰러지는 보드게임 동작과 짧은 멈춤, 번쩍임, 숫자, 소리로 전달한다. 프레임 애니메이션은 쓰지 않는다.
4. **결과가 탐험으로 이어진다**: 부상은 기존처럼 원정에 남는다. 총성은 탐험 소음 일부로 남아 다음 조우 확률을 올린다.

## 규칙 — 임시 수치

모든 값은 `ExpeditionBattlePanel` Inspector의 **Rules**(`FieldBattleRules`)에서 조정한다. 수치는 플레이 검증 전의 제안이다.

| 항목 | 규칙 |
| --- | --- |
| 등장 | 감염자 체력 4. 첫 감염자는 중열, 나머지와 증원은 후열에서 시작해 한 줄씩 다가온다(등장 줄은 Inspector 값). |
| 감염자 행동 | 전열이 아니면 전진한다. 앞이 막히면 앞칸이 빈 옆 줄로만 비켜 선다(왔다 갔다 하지 않음). 전열에서는 좌우 1줄 안의 **가장 앞에 선 대원**을 문다. 같은 줄 → 물기 쉬운 대원(방어하지 않은·앞줄) → 체력 낮은 대원 순으로 고른다. 닿지 않으면 옆 줄로 파고든다. |
| 물기 | 70%, 피해 1. 대상이 전열에서 한 줄 뒤에 있을 때마다 −10%p. 같은 줄 앞에 동료가 서 있으면 뒤 대원은 물리지 않는다. 적 차례 도중 앞선 물기로 체력이 바뀌어도, 예고했던 대상을 그대로 문다. |
| 근접 | 양쪽 모두 전열, 좌우 1줄 이내. 85%, 피해 2. 조용하다. |
| 사격 | 75% + 조준 − 줄 거리·가로 차이 보정. 피해 3, 탄약 1, **소음 +2**. 빗나가도 소모한다. |
| 급소 | 대원 공격만 10%, 피해 +1. 근접 급소(3)는 살아남은 감염자를 한 줄 밀어낸다. |
| 방어 | 다음 자기 차례까지 **물릴 확률 −40%p**(최소 20%). 피해를 없애지는 않는다. 방어 중 빗나간 물기는 “막음”으로 보인다. |
| 증원 | 전투 소음 4에 도달하면 다음 라운드 시작 때 감염자 1이 후열로 합류한다(전투당 1회, 동시에 최대 3). 마지막 감염자를 쓰러뜨린 총성이나 최대 수가 찬 상태에서는 예고하지 않는다. |
| 철수 | 전열에서 물 수 있는 감염자마다 등 뒤 공격 1회(50%, 피해 1). 체력 1은 남는다. 확인창에 마릿수·확률과 실제로 물러날 방(복도/오락실)을 표시한다. |
| 결과 소음 | 승리: 1 + 전투 소음의 50%. 철수: 전투 소음의 50%. 총을 한 번 쓴 승리는 기존과 같은 +2다. |

### 방어를 바꾼 이유

처음 안은 기존대로 “받는 피해 −1”이었다. 물기 피해가 1이라 방어한 대원은 사실상 무적이 되었다. 한 명이 방어로 모든 물기를 받고 다른 한 명이 공격하면 1마리 전투를 피해 없이 이길 수 있었다. 둘 다 방어만 해도 비용 없이 버틸 수 있었다. 그래서 방어를 **확률 감소**로 바꿨다. 감염자도 방어하지 않은 대원을 먼저 노린다. 아래 시뮬레이션에서 방어만 고집하는 방식은 오히려 불리하다.

## 균형 확인 — 시뮬레이션

`AgentScripts/SimulateFieldBattle.cs`로 실제 규칙 상태를 3,000회씩 돌렸다. 도입부 체력(2/3, 3/4)과 1인당 탄약 2발을 기준으로 했다. 대원 행동은 단순한 기준이므로 실제 플레이어보다 서툴다.

| 상황 | 방식 | 승리 | 누군가 쓰러짐 | 평균 잃은 체력 | 사격 | 탐험 소음 |
| --- | --- | --- | --- | --- | --- | --- |
| 감염자 1 | 사격 포함 | 100% | 0% | 0.09 | 3.0 | +4.0 |
| 감염자 1 | 근접만 | 100% | 0% | 0.20 | 0 | +1.0 |
| 감염자 1 | 방어 우선 | 89% | 12% | 0.62 | 2.9 | +3.8 |
| 감염자 2 | 사격 포함 | 99% | 7% | 0.57 | 3.9 | +4.9 |
| 감염자 2 | 근접만 | 100% | 9% | 0.79 | 0 | +1.0 |
| 감염자 2 | 방어 우선 | 51% | 50% | 2.65 | 3.8 | +4.3 |

- 1마리 전투는 가볍다. 2마리 전투는 체력이 원정 내내 남으므로 실제 부담이 된다.
- 총을 쓰면 피해는 줄지만 탄약을 거의 다 쓰고 탐험 소음이 +4~5로 늘어난다. 의도한 교환이다.
- 비교안으로 감염자 체력 5를 시험했다. 2마리 전투에서 6%가 전멸하고 17~33%가 누군가 쓰러져, 도입부 체력에는 과했다. 체력 4를 유지한다.

## 연출 — 사건별

| 사건 | 연출 |
| --- | --- |
| 이동 | 말을 들어 옮겨 놓는 짧은 호. 착지 때 받침이 눌리고 딸깍 소리가 난다. |
| 감염자 전진 | 앞으로 기울며 느리게 다가온다. 발소리는 낮게 낸다. |
| 근접 | 뒤로 젖혀 준비 → 상대 쪽으로 찌르기 → **히트스톱**(0.075초, 급소 0.16초) → 흰 번쩍임 후 붉게 식음, 할퀸/내리친 획, 종이 파편, 숫자, 뒤로 흔들림 → 제자리로 돌아온다. |
| 사격 | 조준 → 총성·총구 섬광·탄도선·반동 → 명중 연출. 빗나가면 탄도선이 옆으로 지나가고 대상이 몸을 피한다. |
| 처치 | 말이 받침에서 옆으로 **쓰러지고** 먼지와 함께 사라진다. “쓰러짐”은 발밑에 표시해 피해 숫자와 겹치지 않는다. |
| 대원 피격 | 흰 번쩍임, 붉은 숫자, 화면 가장자리의 옅은 붉은 번짐. |
| 방어 | 방패 표시와 “방어”, 받침이 옅은 초록색으로 바뀐다. 방어 중 빗나가면 “막음”. |
| 증원 | 총성 직후 “증원 접근”. 다음 라운드에 위에서 떨어져 착지하며 먼지와 울음소리를 낸다. |
| 차례 시작 | 받침이 한 번 부풀고 종이 넘기는 소리가 난다. |

화면 흔들림은 명중 3.5px, 급소 7px 수준(100px = 1유닛)으로 작게 유지한다. 전체 속도와 각 시간·세기는 `BattlePresentation` Inspector에서 조정한다.

결과는 **맞는 순간**에 공개한다. 버튼을 누를 때 하단 알림줄은 “윤서진 · 사격”처럼 행동만 보이고, 대상 정보 카드도 누를 때의 값으로 고정했다가 맞는 순간 체력이 바뀐다.

## 화면 정보 추가

- **머리 위 정보**: 이름과 칸으로 나뉜 체력(UI11 시안의 머리 위 이름·체력 방식). 피해를 입으면 잃은 칸이 크림색으로 남았다가 빠진다. 다른 말이나 상단 띠를 가리게 되면 머리 옆으로 비켜 선다.
- **감염자 의도 태그**: 전진 / 옆 줄로 / 물기 N%. 물기 대상까지 **점선 위협선**을 긋는다.
- **대원 위험 태그**: `! 70%`, 여러 마리가 노리면 `! ×2`. 해당 칸이 붉어진다. 방어하면 확률이 바로 낮아진다.
- **조준 태그**: 고른 적 위에 `명중 N%`. 예상 피해만큼 체력 칸이 깜빡인다. 처치 가능하면 대상 정보에 “처치 가능”이 나온다.
- **이동 미리보기**: 빈 칸에 마우스를 올리면 그 칸으로 옮겼을 때의 위협을 다시 계산해 보여준다.
- **소음 게이지**: 상단 라운드 표시 아래에 `소음 N / 4`. 증원이 확정되면 붉게 바뀐다.
- **빠른 공격**: 그 대원이 고른 적을 한 번 더 누르면 바로 공격한다. 다른 대원의 차례로 넘어가면 다시 한 번 골라야 한다. 기존 공격 확정 버튼도 유지한다.
- **결과창**: 라운드·처치·사격 수, 체력 감소를 붉은 `(−1)`로, 탐험 소음 증가를 표시한다. 4명 이상이면 빈 줄을 줄여 칸 안에 맞춘다.

- `Enter → BeginPreview → RetreatFlow`: 취소/Esc 무비용, 등 뒤 공격 안내, 아무도 쓰러지지 않음, 중복 확인 무시, 복도 이동 1턴과 소음. 통과. 결과창 5명 표시 높이 320/366px 확인.
- `Enter → BeginShowcase → Showcase`: 감염자 2마리 고정 검수용. 실제 속도로 사격·방어·전진, 근접 급소 처치·총성 증원, 방어·빗나감·물기를 녹화했다. 판정 굴림만 검수용으로 정했다.
- 코드 리뷰: 규칙/AI, 연출/패널, Unity, 규칙 준수 네 관점으로 검토하고 각 지적을 독립 검증자 2명이 반박 시도했다. 확인된 17건을 모두 고쳤다(위 방어·예고·증원·철수 방 이름·결과창·차례 카드·말 방향/그림자·캡처 방향 등).
- 새 게임의 도입부(최근 추가된 폐허 시작)는 창고 탄약이 0이다. 검수 스크립트는 도입부 잠금을 해제(`Introduction.Restore(10)`)하고, 출발 뒤 현장에서 탄약 2발을 줍는 경로(`TransferField`)로 준비한다. 실제 게임 규칙은 바꾸지 않았다.

## 승인 시안과 다른 점

- UI10의 상단 차례, 두 3×3 진형, 하단 대원/대상/행동 세 영역 배치는 그대로다.
- 추가: 머리 위 이름·체력(UI11 시안에 있음), 의도·위험·조준 태그, 위협선, 소음 게이지, 결과창 수치 줄. 모두 기존 종이 질감·색(크림, 황토 선택, 흐린 테라코타 위험, 세이지 확인)을 사용했다.
- 행동 카드 설명을 규칙에 맞게 바꿨다: 사격 “피해 3 · 소음 +2”, 방어 “물릴 확률 −40%p”. 철수 확인창 문구도 등 뒤 공격 규칙으로 바꿨다.
- 현재 차례 카드는 크기를 키우지 않고 황토색으로만 표시한다.
- 감염자 말은 여전히 77×116 임시 이미지다. 타격 도형은 벡터이고 전용 원화가 아니다.

# 도입부 참고와 개선안

2026-09-23. 사용자 지시: 정착지에서 느닷없이 시작하는 흐름을 개선하기 위해 기존 레퍼런스를 먼저 파악한다. 아래는 제안이며 도입부 런타임과 세계관의 구체 사건은 아직 변경·확정하지 않았다.

## 기존 레퍼런스

프로젝트 기록의 레퍼런스는 **This War of Mine**이다. 개발사 공식 소개에서 확인한 핵심은 민간 생존자의 부족한 식량·의약품, 거점에서의 제작·거래·돌봄, 외부 수색으로 이어지는 생활 주기다.

출처: [11 bit studios 공식 소개](https://ir.11bitstudios.com/en/news/twom-will-debut-on-the-next-hardware-platform/)

이 자료는 게임의 생활 순환을 뒷받침한다. 원작 첫 장면의 정확한 연출을 확인한 자료로 해석하지 않는다. 우리에게 필요한 것은 거점을 고르기 전후의 사정과 첫 행동의 이유를 연결하는 것이다. 원작의 전쟁 설정이나 낮 외출 제한을 그대로 채택하지 않는다.

## 제안: 오늘 머물 곳을 만드는 첫 3~5분

| 단계 | 플레이어가 하는 일 | 전달할 내용 |
| --- | --- | --- |
| 1. 함께 이동 중 | 짧은 대사와 주변 확인 | 두 사람이 함께 움직이며 쉴 곳이 필요하다. 장문의 세계관 설명은 생략한다. |
| 2. 머물 곳 발견 | 기존 세 정착지 후보 중 선택 | 시설과 남은 물자의 차이를 보고 당장 필요한 곳을 정한다. |
| 3. 첫 진입 | 미확인 표시가 있는 물건 하나 수색 | 아직 내 거점이 아니라 직접 확인해야 하는 장소라는 감각을 준다. |
| 4. 첫 생활 작업 | 쉬기·먹을 것 준비·간단한 정비 중 안내된 작업 실행 | 수색한 물건이 사람의 상태와 생활에 영향을 준다. |
| 5. 다음 필요 발견 | 부족한 물자 확인 후 첫 외부 수색 준비 | 튜토리얼 지시만으로 출발하지 않고 필요한 물자를 구하러 나간다. |

짧은 이동 상황 → 거점 발견 → 첫 수색 → 생활 작업 → 외출 목적의 흐름을 권장한다. 연출을 길게 늘리기보다 기존 수색·가방·작업 UI를 실제로 한 번씩 사용하게 한다.

이상현상은 첫 수색에서 작은 어긋남을 발견하는 정도의 후보로 남긴다. 도시 봉쇄, 밤마다 변화, 특정 재난 원인 등은 여기서 확정하지 않는다. 캐릭터 이름·성격·배경은 비전투 콘텐츠 완성 뒤 랜덤 동료 단계에서 구체화한다.

## 구현 시 확인할 조건

- 현재 동료 선택 → 정착지 선택 → 정착지 진입 사이에 도입 단계를 연결한다.
- 시작 보급품을 첫 수색 연출로 옮길 경우 기존 지급과 중복되지 않도록 한 번만 지급한다. 현재 지급 규칙은 유지 중이다.
- 도입 진행 상태 저장, 이어하기, 재시작, 건너뛰기의 보상·시간 처리를 함께 설계한다.
- 도입 전용 수색 기록과 기존 외부 탐험 수색 기록을 구분한다.
- 선택한 거점과 동료가 바뀌어도 성립하는 상황으로 만든다.

## 이번에 적용한 표시 개선

- 외부 탐험 수색 지점은 실제 첫 수색 전까지 원형 표식에 `?`를 표시한다. 창을 열기만 해서는 공개되지 않는다.
- 첫 수색 턴 이후 해당 지점의 사물 아이콘이 드러난다. 수색 상태 문구는 계속 표시한다.
- 수색 지점의 마우스·선택 이름표를 숨겨 `미수색` 상태표와 겹치지 않게 했다. 수색 팝업의 상세 정보 전체를 숨긴 것은 아니다.
- 필드 캐릭터 발판은 기존 타원 자산에 윗면·목·경사면·밑면·그림자를 분리한 SpriteRenderer로 두께를 추가했다. 인물 원화는 유지한다.
- 초기 물음표, 창 열기만 한 상태, 실제 첫 턴 공개, 다른 미수색 지점 유지, 저장 데이터의 진행도 복원, 이름표 중복 방지를 Unity Editor에서 확인했다. 이번 검수의 복원은 메모리 데이터 복원이며 저장 파일 왕복 검사를 새로 수행한 것은 아니다.

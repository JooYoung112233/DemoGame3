# 탐험·전투 밸런스 1차

> 상태: 2026-09-24 1차 적용입니다. 모든 수치는 임시입니다.
> 요청: "탐험, 전투 관련 플레이 해보면서 부족한부분이나 어색한거 찾아봐 그뒤에 밸런스 잡아보자 1차적으로 설정한 다음 적용해줘"

## 1. 한 줄 요약

- 첫 원정(도입)은 거의 확실하게 싸웠고, 적이 두 마리인 경우도 많았습니다. 이제는 세 곳을 다 뒤졌을 때 절반쯤 한 번 마주치고, 상대는 한 마리입니다.
- 두 번째 원정부터 보통 속도가 가장 시끄러웠고, 조용히 끝내는 정답 하나만 남아 있었습니다. 이제 보통·정밀은 조용하고 빠름만 시끄럽습니다. 큰 소리는 빠름을 고른 대가입니다.
- 쓰러진 대원이 영영 회복되지 않던 문제를 고쳤습니다. 거점에서 쉬면 체력 1로 돌아옵니다.
- 크리쳐 12종 중 예고만 읽으면 피해가 0이던 종들을 다듬었습니다. '그것'은 가장 쉬운 상대였는데 이제 제대로 된 상대입니다.

## 4. 시뮬레이션 결과

### 4-1. 첫 원정 조우 (2인, 2만 회, `SimulateFieldSite.FirstVisit`)

한 번 이상 마주칠 확률 / 두 번 이상 마주칠 확률입니다.

| 경로 | 이전 | 1차 |
|---|---|---|
| 상자만 | 빠름 0% · 보통 43% · 정밀 36% | 모두 0% |
| 상자+탁자 | 빠름 57% · 보통 92% · 정밀 92% | 빠름·보통 0% · 정밀 54% |
| 세 곳 | 빠름 87% · 빠름+망보기 75% · 보통 99%/30% · 정밀 99%/73% | 빠름 45% · 빠름+망보기 34% · 보통 53% · 정밀 91% · 두 번 이상 0% |

### 4-2. 두 번째 원정 · 운영 방식별 (`SimulateFieldSite.SecondVisit`)

2인, 도구 없이 뒤질 수 있는 세 곳(오락실 상자·탁자, 복도 상자)입니다. 이어받은 상태 5가지 (위험도, 게이지) = (0,0)(0,2)(1,1)(1,2)(2,0)의 범위입니다.

| 운영 | 이전 | 1차 |
|---|---|---|
| 조심(보통 + 필요할 때 숨죽이기) | 16~18턴, 조우 0, 숨죽이기 9~11번 | **10~12턴**, 조우 0, 숨죽이기 3~5번 |
| 대충(보통, 숨죽이기 없음) | 7~9턴, 조우 0~2 | 7~8턴, 조우 0~1 |
| 빠름 + 망보기 + 숨죽이기 | 7~9턴, 조우 0 | 7~9턴, 조우 0 |
| 빠름(대충) | 4~5턴, 조우 0~1 | 4~5턴, 조우 0~1 (5가지 중 4가지에서 1) |
| 정밀 + 숨죽이기 | 16~18턴, 조우 0 | 16~18턴, 조우 0 |

### 4-3. 가장 잘 풀었을 때 (`SimulateFieldSite.BestPlay`)

매 턴 가능한 선택을 모두 넓이 우선으로 훑어, **조우 없이** 도달할 수 있는 가장 빠른 턴을 찾았습니다.

- 굴 선반: 6~8턴. 세 곳 모두: 4~6턴.
- 조우 없이 선반을 챙기는 수순 예 (위험도 1, 게이지 2에서 시작):
  1. 오락실 상자를 빠름으로 뒤져 큰 소리를 냅니다(위험도 2, 오락실 기억).
  2. 숨죽이기 3번 → 그것이 복도를 지나 오락실로 들어오고, 숨죽인 원정대를 지나칩니다.
  3. 그것이 오락실에 머무는 동안 복도로 나가 선반을 뒤집니다.
- 처음 계산했을 때는 **그것이 굴로 들어오는 턴에 선반을 뒤지는 수순**도 조우 없이 통했습니다. 이것은 규칙 구멍이라 §2-16처럼 막았습니다. 막은 뒤에도 꾀어내기 수순은 그대로 성립합니다.

| 식탁밑 | 3.3 / 0.05 → 2.8 / 0.11 | 5% / 0.69 → 4% / 0.69 |
| 틈새개 | 1.6 / 0.01 → 1.5 / 0.02 | 1% / 0.23 → 0% / 0.25 |

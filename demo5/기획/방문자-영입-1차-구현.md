# 방문자 영입 1차 — 2026-09-23

## 사용 흐름

정착지 방문자 → 함께 지낼 의향을 묻는다 → 후보의 초상·기존 소개·체력·가방 용량·수용 여유 확인 → 합류 제안 확인 → 취소/확정.

- 기본 수용 한도 3명, 옆방 거주 준비 후 임시 5명. 정원이 찼어도 기존 물물교환은 가능하다.
- 방문마다 기존 명단에서 아직 합류하지 않은 첫 후보 한 명을 소개한다. 현재 후보 순서는 임시이며 개별 방문 사건/성격/확률은 미구현이다.
- 현재 합류 비용과 시간은 없다. 후보는 기존 데이터의 최대 체력과 빈 가방으로 합류하고, 이번 방문/거래는 끝난다. 방문자 재고는 창고에 지급하지 않는다.
- 확정 순간 방문 날짜·후보·중복 영입·수용 여유를 다시 검사한다. 취소하거나 방문이 바뀌면 이전 확인창으로 영입할 수 없다.
- 새 대원은 기존 대원 카드·가방·휴식/제작/조리 담당자 목록·탐험에 참여한다. 정착지 말은 6개 편집 슬롯을 준비하고 현재 인원만 표시한다. 실제 기본 정원은 5명까지다.

## 저장과 편집

- 저장 버전 7: 후보 ID와 합류/방문 종료 기록, 늘어난 대원과 가방·예약 작업을 보존한다. v1~v6 저장을 이관하고 기존 인원을 보존한다. 구버전 방문의 후보는 미합류 명단에서 지정한다.
- `SettlementRecruitment.cs`: 합류, 정원 검사, 후보 정보와 확인.
- `CampaignSaveData.cs`: v7 이관과 데이터 검사. 시작 화면의 프리팹 카탈로그에서도 대원 목록을 명시적으로 전달한다.
- `VisitorPanel.prefab`: 후보 페이지와 대화 선택지. `SettlementWorld.prefab`: 추가 말과 위치. `Settlement.unity`: 화면과 월드 참조 연결.
- `ConnectRecruitment.Run`: Editor API로 화면/말 슬롯을 구성한다. 재실행 시 기존 신규 슬롯 위치를 보존한다.

## 검증

`VerifyRecruitment.Fresh` → `Flow`, Play 종료/재시작 → `Restart`.

- 실제 레이캐스트 클릭으로 후보 확인, 취소, 확정, 중복 클릭 방지.
- 2→3 / 확장 후 3→4→5, 정원 도달 시 영입 차단 및 거래 유지.
- 확인창 이후 방문 변경과 수용 한도 변경에 대한 재검사.
- 물품 무상 지급 없음, 신규 가방 비어 있음, 개인 가방 이동, 조리 담당 선택, 신규 대원의 공사 배정.
- 공사 35분 남은 상태와 가방/후보/합류 기록의 파일 저장·씬 재로드.
- 신규 대원의 원정 출발과 귀환, 5명 표시·페이지 전환.
- v6 이관, 알 수 없는 후보·합류 기록 불일치 저장 거부.
- 새 Play 시작 화면 ‘이어하기’로 5명과 확장 거주 공간 복원.
- 기존 `VerifyVisitor.Flow`로 공용 확인창의 거래/취소/재고 보호 회귀 검증.
- 실제 사용자 슬롯과 분리한 `Temp/RecruitmentVerification` 사용. 실행 파일 빌드 생략.

## 화면 검수와 한계

`Assets/Screenshots/Recruitment/candidate.png`, `confirmation.png`, `five-residents.png`는 실제 1920×1080 Unity 캡처다. 제목 좌측 위, HUD 숨김/복원, 강한 딤, 좌측 하단 돌아가기, 확인창 취소/확정, 종이 안쪽 여백과 텍스트 높이를 확인했다.

기준 `아트/UI전체시안-v1/13-방문자거래.png`의 종이·실루엣 구성을 대조했다. 영입 전용 승인 시안은 없으며 후보 페이지는 기존 분리 자산으로 구성한 신규 기능 화면이다. 거래 시안의 완전 재현으로 보고하지 않는다. 초상은 기존 저해상도 임시 실루엣이고, 추가 대원 말도 탐험가 그림을 재사용한다. 개별 전용 원화/PSD 납품이나 생활 특성 효과 구현은 이번 범위에 포함하지 않는다. 추가 말의 작업 표시는 자기 위치에서 이루어지며 전용 작업 동선은 후속이다.

다음 기능 단위: 담당자 생활 특성의 실제 효과와 화면 안내 연결. 실제 옆방 이동·정착지별 확장·다양한 방문 사건도 남아 있다.

## 가독성 보완 — 사용자 요청
체력·개인 가방·소개·거주 인원을 별도 텍스트와 기존 스프라이트 아이콘으로 분리했다. 대화 선택·합류·돌아가기·취소/확정 버튼에도 아이콘을 추가했다. 체력/가방은 같은 행, 거주 인원과 합류 조건은 별도 영역이다. 후보와 확인창의 실제 클릭 및 텍스트 높이 검수 완료. 최신 실제 캡처: candidate-icons.png, confirmation-icons.png (Assets/Screenshots/Recruitment).

### 좌측 여백 보완
사용자 피드백에 따라 초상 아래로 이름·체력·개인 가방을 이동해 캐릭터 카드로 묶었다. 우측은 동료 소개와 거주/합류 조건으로 구분했다. 기존 정보만 재배치했으며 초상 비율과 외곽 패널·버튼 위치를 유지한다. 실제 클릭·텍스트 넘침 검사와 Unity 화면 검수 완료. 최신 캡처: Assets/Screenshots/Recruitment/candidate-card.png.

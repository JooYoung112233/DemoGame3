# UI 연결도

[클릭형 연결도 열기](index.html) · [전체 버튼 명세·다이어그램](버튼연결명세.md) · [연결 규칙](규칙과검토사항.md)

화면·팝업·처리/복귀 상태 49개와 버튼·자동 전이·확인창 조건 분기 187개를 정리했다. 전부 독립 팝업을 새로 만드는 의미가 아니며 20종 시안과 공통 컴포넌트 재사용 관계를 나타낸다.

현재 Unity 구현은 시작 화면 → 모험가 선택 → 정착지 선택 → 정착지 첫 화면, 침대 휴식 담당자 선택 및 작업대 제작·수리 화면까지 연결했다. 휴식/제작은 예약 등록과 제작 예약 취소까지 구현했고 시간·효과 처리는 후속 단계다. [시작 화면 구현 기록](../시작화면-구현.md), [휴식 담당자 구현](../휴식담당자-구현.md), [제작·수리 구현](../제작수리-구현.md)에 실제 범위를 기록했다. 나머지 연결도는 설계이며 구현 완료를 의미하지 않는다.

## 사용 방법

1. index.html을 로컬 브라우저에서 연다. 설치나 인터넷 연결 없이 동작하도록 만들었다.
2. 왼쪽에서 화면 또는 버튼 이름을 찾는다. 처음에는 H00 거점이 선택된다.
3. 연결도 좌우 노드 또는 버튼 표의 연결 대상을 눌러 해당 화면의 연결을 확인한다.
4. ‘연결된 시안 보기’를 누르면 관련 PNG가 열린다. 추가 제작이 필요한 화면에는 별도 상태가 표시된다.
5. 취소·수량·시간 등 실제 적용 규칙은 규칙과검토사항.md를 함께 확인한다.

## 검증 범위

명세 ID 중복, 모든 전이 목적지, 20종 PNG 참조, 비의도적 막다른 상태, HTML 내 JavaScript 문법을 검사했다. 실제 브라우저 조작과 Unity 런타임 검증은 수행하지 않았다.

## 편집

navigation-source.cjs에서 연결을 수정하고 `node generate-docs.cjs`를 실행한다. viewer-template.html은 열람 화면의 원본이다. navigation.json, 버튼연결명세.md, index.html은 생성 결과로 함께 유지한다.

문서 속 비용·조건은 설계 제안이며 최종 게임 수치가 아니다. 세부 이미지 제작과 Unity 프리팹 연결은 후속 단계다.
# 실제 구현 추가 · 2026-09-22

H00 침대 → H03 생활 작업 지정 중 휴식 화면을 연결했다. 실제 대원 선택, 등록 및 중복 배정 방지까지 구현했으며 작업 시간/효과 처리와 저장은 후속 단계다. 상세: [휴식 담당자 구현](../휴식담당자-구현.md).

## 실제 구현 추가 · 2026-09-23

원정 준비→출발→방 이동→수색/발견물→조우→3×3 교전/결과→수색 복귀까지 연결했다. [분리 진형 전투 구현](../분리진형전투-구현.md)에 버튼별 실제 동작을 기록했다. 연결도는 설계 전체를 유지하므로 전투 아이템·일시정지·저장/불러오기 등 남은 분기를 구현 완료로 보지 않는다. 다음 화면은 B02 전투 소지품, 그다음 R00 귀환 정산이다.

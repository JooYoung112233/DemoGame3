# 인간 캐릭터 역할과 밸런스 1차

사용자 요청: 대원마다 체력·상세 특징과 실제 플레이 차이를 주고, 시작 두 명 외에는 해금 방식으로 만난다. 짧은 피격으로 이탈하던 부담을 줄이는 초기 수치이며 최종 난이도 확정은 아니다.

| 인물 | 체력 | 가방 | 사격 명중 보정 | 실제 효과 |
|---|---:|---:|---:|---|
| 윤서진 · 기동 | 6 | 4 | 0 | 이동한 차례의 근접·사격 명중 +10%p |
| 한해인 · 치료 | 6 | 3 | −5%p | 자신이 사용하는 붕대 회복 +1. 전투에서는 동료 처치에도 적용 |
| 오정은 · 보급 | 7 | 4 | −10%p | 허용 요리 시간 −20%. 직접 사용하는 휴대식량·조리한 식사 회복 +1 |
| 강기섭 · 돌파 | 6 | 5 | −5%p | 일반 제작 시간 −20%, 연구 제외. 현재 장갑이 남은 적에게 근접 피해 +1 |
| 백소담 · 분석 | 5 | 3 | +5%p | 연구 시간 −30%. 빈틈 상태인 적에게 근접·사격 피해 +1 |
| 임태오 · 버팀 | 8 | 2 | 0 | 방어 중 물기·군집·예고 공격 피해 추가 −1. 회피·무적 효과는 없음 |

- 시작은 서진·해인만 유지한다. 추가 동료는 조건을 달성한 뒤 정착지 방문자로 만나 영입한다. 조건을 한 번 달성하면 해당 캠페인에서 해금이 유지된다.
- 체력과 가방만 높은 상위 인물을 만들지 않는다. 시작 대원은 기동·치료를 담당하고, 해금 대원은 조준·가방·체력과 특정 상황의 효과를 교환한다.
- 시작 부상은 기존 `최대 체력 −1` 규칙을 유지한다. 서진·해인은 5/6으로 시작하므로 2피해를 두 번 받아도 체력 1이 남는다. 여러 적의 집중 공격이나 큰 예고 공격을 안전하게 맞는다는 뜻은 아니다.
- 서진의 보너스는 해당 차례의 실제 이동 이후에만 생기며 다음 차례에 사라진다. 명중 상한은 기존 규칙을 따른다.
- 기섭은 장갑 계산 후 실제 방어력이 0인 목표에는 보너스를 받지 않는다. 빈틈으로 장갑이 사라진 상황은 소담의 역할이다.
- 해인·정은의 회복 특성은 아이템 사용자 기준이다. 정착지·현장에서는 자신에게 사용하고, 전투 붕대는 다른 대원에게도 쓸 수 있다. 정은이 식량을 제작했다는 이유로 다른 대원이 먹을 때 보너스가 붙지는 않는다. 현재 식량 ID는 `ration`, `meal`이다.
- 특성은 `PartyCandidate.Traits`에서 `CreateAdventurer()` 또는 저장 로드의 `ApplyTraits()`로 복사한다. 별도의 횟수·쿨다운·영구 상태는 없다. 표시만 있고 계산에 없는 효과는 추가하지 않는다.

## 구현·검증

- `BuildCharacterBalance.Run()`이 수치·소개·운용 설명·해금 메타데이터를 Inspector 자산에 적용한다. 그림, 표시 배율, 슬롯 파일은 변경하지 않는다.
- `FieldBattleState`의 명중 분해·예상 피해·아이템 미리보기·실제 처리·적 예고는 같은 효과 계산을 사용한다. 가방·정착지 사용 미리보기도 실제 회복 함수를 공유한다.
- 제작과 연구는 `research-` 레시피 ID로 구분하고 시설 배율과 담당자 배율을 곱한 뒤 마지막에 한 번만 분 단위 올림한다. 조리 특성의 기존 `WorkerSpeedAllowed` 제한은 유지한다.
- `VerifyCharacterBalance.Run()` 검증 스크립트 작성 완료. 여섯 수치·새 생성/기존 수치 보존·특성 복사·초기 생존 여유·이동 보너스 리셋·장갑/빈틈 실제 피해·아이템별 회복 및 소모·물기/군집/예고/철수 예측 일치를 검사한다.
- `VerifyCharacterUnlocks.Run()`은 저장 DTO·파일, `PlayMode()`는 새 게임→실제 귀환→해금 조건→방문자 네 명 영입→여섯 명 저장·장면 복원을 검사한다. 시설 완료·NPC 대화 완료 조건은 공개 API로 준비하는 테스트이며 재료 수급·제작 대기·대화 전체를 다시 플레이한 검증은 아니다. 슬롯은 `Temp/RoleBalanceSlots`에만 작성한다.
- **Unity 실행 검증 완료.** 실제 특성 계산·미리보기, 저장 v16 이관, 조건별 해금과 네 차례 방문 영입, 여섯 명 저장 후 장면 복원, 두 해상도의 프로필/전투/치료 UI 검수를 통과했다. [통합 검수 기록](역할밸런스-적용과검수-2026-09-25.md)과 실제 캡처를 함께 참조한다.

## 동료 해금과 거주 공간

| 동료 | 해금 조건 |
|---|---|
| 강기섭 | 원정 귀환 + 작업대 복구 |
| 오정은 | 원정 귀환 + 조리대 복구 |
| 임태오 | 원정 귀환 + 옆방 거주 준비 |
| 백소담 | 연구대 설치 + 장도윤 첫 대화 완료 후 귀환 기록 |

방문 후보는 조건을 만족한 미영입 대원 중 기섭→정은→태오→소담 순서다. 이미 소개한 방문자를 새 해금 때문에 교체하지 않는다. 합류 확정 시 빈 가방으로 들어오며 해당 방문의 거래는 종료된다. 시작 거주 정원 3명, 옆방 거주 준비 후 6명으로 기존 여섯 대원을 모두 영입할 수 있다.

## 이전 수치와 저장 연결

이전 HP/가방/조준은 서진 3/3/0, 해인 4/3/0, 정은 4/4/0, 기섭 3/4/0, 소담 3/3/0, 태오 4/4/0이었다. v15→v16 저장 이행은 각 수치가 이전 기본값과 맞을 때만 새 값으로 옮긴다. 최대 체력에서 이미 잃은 체력을 보존하고 행동 불능 0은 유지한다. 별도 수정된 수치는 보존하며 `ApplyTraits` 자체도 체력·최대 체력·조준·가방 수치를 덮어쓰지 않는다.

태오의 기존 가방에 새 2칸보다 많은 종류가 있으면 `새 정원과 현재 보유 종류 수 중 큰 값`을 해당 대원의 용량으로 보존한다. 과거 귀환 보고서의 체력 숫자는 당시 기록으로 유지한다. 기존 합류 대원과 이미 소개된 방문자는 새 해금 조건을 다시 요구하지 않고 v16 해금 목록에 넣는다. 신규 게임은 항상 시작 두 명부터다.

# 정착지 시설 v4 — 사용자 거절 / 통합 제외

2026-09-24. v2/v3는 사용자가 배경과의 화풍 차이를 지적하여 미채택. v4는 장면 시안을 참고하여 회색 작업대와 녹색 보관함으로 다시 제작했다. 사용자가 실제 Unity 적용 후에도 배경과 사물이 매우 어색하다고 다시 지적했다. 시각 검수 실패이며 최종 사용·통합 대상에서 제외한다. 기능 검증 통과를 미술 마감 완료로 해석하지 않는다.

## 적용 결과

- 연구대: 얇은 회색 상판/다리, 작은 책·종이·캔, 앞쪽 의자. 큰 붓자국을 줄인 면 표현.
- 창고: 회색 올리브색 보관함 2개. 기존 과장된 금속 모서리 및 겹친 보강선 제외.
- PNG 원본은 수정·확대하지 않고 Unity에서 비례 축소한다.
- 바닥 접지 그림자는 별도 편집 가능한 Unity Mesh로 제작. 원화에 굽지 않음.
- 실제 알파 윤곽으로 hover 강조 및 클릭 판정. 평소 외곽선 없음.
- 원래 배경 파일/다른 에이전트의 전투·탐험 코드 변경 없음. 분리 작업본만 적용.

## 재검토에서 확인한 문제

1. 원근: 앞쪽 새 연구대는 상판이 얕게 보이는 정면 중심 그림이다. 배경 바닥과 기존 작업대의 내려다보는 시점에 충분히 맞지 않는다.
2. 비례: 기존 뒷벽 작업대보다 전경 연구대가 작고 다리가 가늘다. 단순히 총 가로폭만 맞춰 소품 체적과 가구 간 상대 비율을 놓쳤다.
3. 렌더링: 실제 배경은 RuinedRoom의 CommonLitFragment(2D 조명)와 채도 .62/노출 .83/냉색 명암·질감 처리를 거친다. 신규 시설은 FacilityPaintedSprite의 unlit 샘플에 고정 RGB 배율(.62,.65,.66)만 곱한다. 같은 공간의 조명 반응이 아니다. 새 PNG 반복 생성만으로 이 차이가 해결되지 않는다.
4. 접지: 타원 그림자 추가만으로 각 다리 접촉점과 바닥 원근이 정합되지 않는다.

후속 순서: 배경 카메라/원근 및 가구 상대 치수 기준 설정 → 그 기준의 원화 1개만 제작 → 배경과 동일 2D 조명/색 처리 경로 연결 → 캐릭터가 포함된 실제 화면에서 나란히 검수. 전체 시설로 확대하기 전에 연구대 한 개의 일치부터 해결한다. 현재 원본 배경은 바꾸지 않는다.

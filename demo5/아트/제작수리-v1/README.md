# 제작·수리 화면 원본

승인 시안 06에서 지렛대·못·밧줄·판자·수리·개선 아이콘을 분리했다. 제작 망치 아이콘은 기존 분리 PNG의 투명 여백을 잘라 크기를 맞췄다. 종이 패널은 기존 개별 PNG를 재사용한다.

- `개별-PNG`: 원래 해상도의 아이콘과 종이 원본 복사.
- `PSD`: 각 소품 단일 레이어 PSD 및 요소별로 나눈 `craft-work-layout.psd` (3840×2160).
- 실제 텍스트·재료 수치·대원 초상·예약 목록·강조 상태는 Unity UI에서 조합한다.

아이콘은 작은 시안에서 분리한 자산이며 확대 보간으로 새 디테일을 복원하지 않았다. 단일 소품 PSD는 내부 부품 분리를 뜻하지 않는다. PSD 레이어/알파/위치/합성 결과는 내보내기 후 검증했다.

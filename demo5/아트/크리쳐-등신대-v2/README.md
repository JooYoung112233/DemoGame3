## 이번 수정

- 기존 12종 원본과 `Assets/Art/Settlement/standee-scout.png`를 직접 참조하여 내장 image_gen으로 각각 수정했다.
- 종마다 다른 실루엣과 사물 모티브를 유지하고, 명암·표면 세부를 줄였다.
- 아이보리 종이 외곽선과 납작한 인쇄 몸체, 붉은 계열의 낮은 원형 계단형 밑둥을 추가했다. 받침대 색과 세부 형태는 이번 제안이며 사용자 확정으로 간주하지 않는다.
- `원본/`에 개별 생성 원본 PNG 12개, `generation-manifest.json`에 실제 프롬프트와 참조를 저장했다. 기존 v1과 인게임 리소스는 보존했다.

## 실제 납품 상태 — 형태 확인용 시안

모두 **1086×1448 RGB PNG**이며 체크무늬가 이미지에 그려져 있다. 실제 투명 알파가 아니다. 생성 도구에 투명 배경을 요청했고 첫 몸체에 배경 제거 수정도 시도했지만 해당 문제가 지속됐다. 최종 투명 리소스라고 보고하지 않는다.

- 몸체·받침대·배경은 현재 한 평면에 합쳐져 있다. 독립 레이어 PSD와 Unity 투명 스프라이트 납품은 미완료.
- 완성된 시안을 그대로 한 레이어 PSD로 변환해 분리 가능한 원본이라고 주장하지 않는다.
- `validation.json`에서 모든 파일의 실제 크기와 모드를 확인했다. 고해상도 목표 미달이며 보간 확대하지 않았다.
- 05 널린것 등 일부는 내부 명암이 여전히 상대적으로 많고, 종마다 받침대 둘레의 종이 테두리 유무가 다르다. 공통 밑둥 자산으로 분리·통일하고 인게임 크기에서 검수하는 후속 작업이 남아 있다.
- v2의 형태 수정은 제작했으나 사용자 미술 승인, 인게임 교체, 투명도 해결, 리깅 완료를 의미하지 않는다.
- 전투 방식과 수치는 변경하지 않았다.

## 파일

- `index.html`: 원본을 직접 나열하는 비교용 문서.
- `overview.png`: 위 문서의 브라우저 캡처. 원화 수정·합성 원본을 대체하지 않는다.
- `원본/<id>.png`: 개별 수정 시안.
- `generation-manifest.json`: 프롬프트·소스 기록. 도구는 built-in image_gen.

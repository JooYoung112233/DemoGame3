# 휴식 담당자 패널

승인 시안 05의 좌측 작업 패널과 우측 선택 대원 카드 구성을 사용한다. 기존 개별 종이 이미지를 재사용하고 달·시계 아이콘을 원본 시안에서 분리했다.

- 개별-PNG: 기존 종이 원본 복사와 시안에서 분리한 아이콘.
- PSD/rest-work-layout.psd: 3840×2160, 패널·제목·탭·행·아이콘·확정 버튼·상세 카드 별도 레이어. 텍스트와 대원 초상은 게임 데이터로 조합하므로 이미지에 굽지 않았다.
- PSD/icon-sleep.psd, icon-clock.psd: 원본 크기 단일 소품 레이어. 자체 내부 요소까지 분리한 PSD는 아니다.

원본 크기가 작은 아이콘을 확대 배치했으며 고해상도 원화 완성이 아니다. 모든 PSD는 레이어 이름·채널·알파·합성 결과를 저장 후 재검증했다. 코드의 동적 강조·체력·스크롤·외곽선은 Unity 프리팹에서 편집한다.

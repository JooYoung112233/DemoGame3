# 정착지 시설 v3 — 미채택

사용자 피드백: v2는 배경과 묘사·원근이 다르고 상시 다각형 외곽선 및 창고 보강선이 어색함.

- 연구대·상자 각각 새로 생성. 평평하고 큰 붓질, 회색/올리브색, 정면 원근으로 단순화.
- 원본 2개 모두 1536×1024 RGBA. Unity에도 같은 원본을 사용. 확대 보간 없음.
- 평소 외곽선 숨김. 마우스/선택/Alt 강조 유지. 신규 소품은 실제 알파 윤곽과 알파 클릭 영역 사용.
- v2 위에 잘못 겹친 기존 창고 보강선 제거. 창고 1/2단계 기능은 유지하나 단계별 별도 원화는 미완료.
- 배경에 합쳐진 기존 시설의 마우스/Alt 윤곽은 수동 다각형이므로 정확한 픽셀 외곽선은 아직 아님.
- 배경 전체 및 UI 배치는 변경하지 않음. 분리 작업본에만 반영; 다른 에이전트의 전투·탐험 파일 변경 없음.
- 사용자가 배경과 화풍 차이가 크다고 명시적으로 거절한 시안. 최종 자산으로 사용하지 않음. 접지 그림자와 공간 배치는 추가 미술 검수 대상.

## 파일

`원본/research-desk-v3.png`, `원본/storage-crates-v3.png`.
`facilities-v3-native-layers.psd`: 3136×1024, 실제 크기 두 레이어. 책·종이는 책상에, 두 상자는 한 그룹에 합쳐져 있으므로 내부 소품별 독립 편집은 미완료. Pillow로 PSD 합성 크기/픽셀 일치 확인. Photoshop 열기 검증은 하지 않음.

## 제작

기본 내장 image_gen 도구. 프롬프트는 `prompts.md` 참고. reference를 사용한 첫 연구대는 RGB 체크무늬라 제외. 첫 상자는 기울어진 원근이라 제외.

## 검수

Unity 재컴파일 오류 없음. 실제 알파 빈 공간 클릭 거부, 물체 클릭, 창고/연구 팝업 열기/닫기 및 hover 확인 통과. 실제 화면: Assets/Screenshots/OpeningChapter/16-facilities-v3-preview.png.

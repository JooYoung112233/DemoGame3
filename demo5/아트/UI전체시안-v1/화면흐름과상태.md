## UI 재사용과 별도 제작

- 요리·정수·휴식·치료는 같은 TaskPanel을 이용한다. 예를 들어 조리대에서 레시피를 고르면 담당자·재료·시간·분배 대상 데이터가 바뀐다.
- 제작·수리·시설 개선은 목록과 상세·비용·담당자 패널을 공유한다.
- 3×3과 4×3 전투판은 셀과 위치 데이터로 확장한다. UI 패널 구조는 동일하게 유지한다.
- 전투 승리·도주·패배는 ResultLedger 공통 틀에 결과와 이어갈 행동을 바꾼다. 전멸 시에는 탐험 재개 버튼이 없어야 한다.
- 일반 방문자 대화·퀘스트 선택·조우는 EncounterChoice를 재사용한다. 물물교환만 거래 전용 패널로 진입한다.
- 낮 시간 진행과 야간 역할 배정은 설계 제안이다. 원작과 같은 실시간 제어를 도입했다고 간주하지 않는다.

## 데이터와 접근성

가방 소유자, 선택된 대원 ID, 아이템 종류·개수, 선택 수량, 시설 ID, 작업 ID, 재료 출처, 선택 대상 ID를 별도로 관리한다. 표시 이름 변경이 아이템 소유를 바꾸지 않는다.
폰트는 실제 Unity TextMeshPro에서 한글을 렌더링한다. 원화의 손글씨는 스타일 참고이며 그대로 잘라 쓰지 않는다. 버튼마다 hover/focus/pressed/disabled 상태와 비활성 이유를 제공한다. 선택·부상·위험은 색뿐 아니라 아이콘·문구로 표시한다.
설정의 UI 크기와 글자 크기는 미리보기 후 적용하고 되돌릴 수 있도록 한다. 작은 썸네일에만 필수 정보를 담지 않는다.

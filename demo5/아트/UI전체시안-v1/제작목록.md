# 인게임 UI 전체 시안 v1

개별 인벤토리와 원정 짐 꾸리기를 포함해 현재 논의된 게임 흐름을 덮는 20종 시안. 신규 시설/게임 규칙은 제안이며 사용자 승인 질감과 오브젝트 중심 조작을 공통 기준으로 한다. 기능 구현은 별도다.

| ID | 구간 | 화면 |
| --- | --- | --- |
| 01 | 거점 | 개인 가방과 공용 창고 |
| 02 | 출발 | 목적지와 원정대 선택 |
| 03 | 출발 | 가져갈 물건 배분 |
| 04 | 거점 | 오브젝트와 대원 상태 |
| 05 | 거점 | 휴식·요리·치료에 공통으로 쓰는 작업 패널 |
| 06 | 거점 | 제작·수리·업그레이드·작업 관리 |
| 07 | 탐험 | 사물을 눌러 수색 담당과 방법 선택 |
| 08 | 탐험 | 발견물 분배와 용량 초과 |
| 09 | 탐험 | 조우 전 경고와 교전·회피 |
| 10 | 전투 | 양 진영 3×3 보드와 턴 순서 |
| 11 | 전투 | 개인 소지품 사용·아군 대상 지정 |
| 12 | 귀환 | 대원별 회수물과 창고 입고 |
| 13 | 거점 | 방문자·물물교환 |
| 14 | 거점 | 다인원 명단·상태·치료 |
| 15 | 거점 | 원정 후 휴식·경계 역할 배분 |
| 16 | 거점 | 밤 결과·완료 작업·중요 알림 |
| 17 | 공통 | 목표·발견한 단서·장소 기록 |
| 18 | 공통 | 아이템 설명·수량·확인·오류·튜토리얼 |
| 19 | 공통 | 일시정지·설정·저장 불러오기 |
| 20 | 시작 | 시작 화면·모험가 선택·정착지 선택 |

01~17은 개별 상황 화면, 18~20은 여러 공통 상태를 묶은 검토 보드다. [전체 갤러리](index.html), 최종 생성 결과의 해상도·파일은 manifest.json, 검수와 한계는 README.md에 기록했다.

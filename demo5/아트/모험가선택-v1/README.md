# 모험가 선택 — 2026-09-22

기준은 [승인 시안 20번](../UI전체시안-v1/20-시작과정착지선택.png)의 가운데 행이다. 원본 실루엣 6명·가방·하트·체크와 종이 질감을 분리하여 Unity에 배치했다. 글씨는 이미지에 굽지 않고 Gaegu Bold/Regular로 표시한다.

- `개별-PNG/`: 인물, 종이, 아이콘, 선택 테두리의 투명 PNG.
- `PSD/candidate-*.psd`: 종이·인물·가방·하트의 실제 분리 레이어, 후보별 6개.
- `PSD/portrait-*.psd`: 인물만 있는 단일 오브젝트 문서. 얼굴/의상까지 분해된 그림은 아니다.
- `PSD/selection-state.psd`: 테두리와 체크 별도 레이어.
- `PSD/candidate-details.psd`: 하단 상세 패널의 기존 종이와 인물 6종 대체 레이어. 첫 인물만 표시되며 나머지는 숨김이다. 문구는 Unity Text에서 편집한다.
- `PSD/party-selection-art-layout.psd`: 3840×2160 배치용 편집 문서. 동적 문구와 숫자는 Unity에서 편집한다.
- 최신 실제 화면: `../../Assets/Screenshots/PartySelection/party-v3-details.png`.

## 해상도와 남은 보완

원본 시안은 1672×941이며 인물 추출본은 약 130×106이다. 현재 PNG와 PSD는 승인 그림을 그대로 사용하는 **배치 검수용**이다. 3840×2160 PSD는 배치 캔버스 확대이며 고해상도 디테일을 복원한 원본이 아니다. 최종 납품용 고해상도 인물·아이콘 보완은 남아 있다. 종이는 기존 큰 제목 종이의 질감을 재사용했다.

`tools/prepare_party_selection.py`로 추출·PSD 패키징을 재현한다. 체크 주변 잔여물은 인물과 연결된 영역만 남겨 제거했다. PSD 생성기는 저장 후 레이어 이름·좌표·픽셀·알파와 합성 미리보기를 다시 읽어 확인한다.

## 시안과 실제 화면의 차이

가로 6장, 왼쪽 안내, 노란 테두리·체크 구성은 유지했다. 원본 3단 보드의 가운데 행을 1920×1080 독립 화면으로 옮기며 위아래 여백과 하단 돌아가기/다음 버튼을 추가했다. 선택 전에는 0/2, 두 명 선택 시 2/2로 표시한다. 원본의 손글씨 대신 사용 허용된 실제 유사 서체를 썼고, 안내 종이와 단계 번호는 기존 분리 종이를 재사용했다. 따라서 원본 전체의 픽셀 단위 복제는 아니다.

후속 사용자 지시로 단계 번호 `02`를 제거하고 선택 영역을 210px 위로 이동했다. 아래에 특성·특징 상세 패널을 추가했으며, 위 설명의 단계 번호는 이전 버전 기록이다. 전체 배치 PSD도 이 최신 구성으로 갱신했다. 원본 종이·실루엣 PNG는 유지한다.

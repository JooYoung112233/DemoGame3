# 승인 시안 첫 화면 — 1:1 분리·재조립 기준

20번 승인 시안의 첫 행을 원래 1672×290 픽셀 그대로 분리했다. 환경, 제목 종이, 각 버튼의 종이·아이콘·글씨·화살표 등 19개 레이어를 재조립하면 **원본과 다른 픽셀 0개**다. `검수/원본-위-재조립-아래.png`로 비교할 수 있다.

`PSD/approved-start-exact.psd`는 실제 레이어 PSD이며 제목과 각 버튼 PSD도 따로 있다. `개별-PNG`와 `layers.json`은 원본 픽셀과 좌표를 보존한다. 글씨 레이어는 원본 그림을 분리한 래스터이며 입력 가능한 폰트가 아니다. 실제 Unity 문구는 사용자가 허용한 유사 서체 Gaegu로 작성한다.

이 자료는 **시각 일치 검증용 원본 크기 기준**이다. 작은 시안 추출물을 고해상도 최종 자산으로 취급하지 않는다. 가려진 배경은 원본에 존재하지 않아 해당 영역만 중립색 밑바탕으로 두었다. UI를 이동하거나 숨길 때 사용할 완성된 배경 클린 플레이트는 아니다. 해당 한계가 재조립의 픽셀 동일성 검증을 바꾸지는 않는다.

현재 Unity의 1920×1080 배치와 구분한다. 이 검수 자료의 0픽셀 차이를 실제 게임 화면이 시안과 완전히 같다는 의미로 보고하지 않는다.

기존 게임의 나무·고철·천·손전등 아이콘을 확인하고, 굵고 불규칙한 먹선과 저채도 색면을 사용한 물품 그림 8개를 개별 생성했다. UI·배경·이름표는 포함하지 않는다.

모든 PNG는 기본 image_gen 도구가 개별 출력한 **1254 × 1254 RGBA 원본**이다. 시트를 자르거나 확대하지 않았다. 물체의 긴 변은 모두 800px 이상이다. 게임용 `Assets/Art/EverydayGoods/{id}.png`는 대응하는 원본의 바이트 복사본이다. Unity 임포트 설정과 실제 인게임 판독 검수는 별도 개발 단계에서 진행한다.

배경은 실제 알파 0을 포함하며 네 귀퉁이는 완전히 투명하다. 물체 외곽이 캔버스에 닿지 않는다. 생성 결과의 미세 반투명 가장자리와 낮은 알파 흔적을 그대로 보존했고 코드로 배경 제거·색 보정·알파 정리하지 않았다. 불투명에 가까운 면에도 알파 252~253이 존재할 수 있다.

## PSD의 편집 범위

`everyday-goods-native-layers.psd`는 **물품별 독립 레이어 8개**를 포함한다. 각 레이어는 원본 전체 크기와 RGBA 픽셀을 보존한다. 같은 1254 × 1254 캔버스에서 항목별 가시성을 켜서 사용할 수 있으며, 최초 표시와 병합 미리보기는 연료통이다. 나머지 일곱 물품 레이어는 숨김 상태다.

물품 내부의 선·색·마모·부속품은 별도 레이어로 나뉘어 있지 않다. 따라서 이 PSD는 물품별 독립 편집을 제공하며, 물체 내부 요소까지 완전히 분리된 제작 원본이라고 주장하지 않는다. 각 독립 PNG도 함께 유지한다.

## 검증과 재현

- `prompts.json`: 개별 생성 프롬프트와 출력 경로.
- `package-icons.cjs`: 원본 PNG 픽셀을 바꾸지 않고 PSD 컨테이너로 패키징하는 스크립트. 기존 PSD PackBits 작성/검증 함수를 재사용한다.
- `validation.json`: 크기·실제 알파·물체 범위·원본/게임용 SHA-256 동일성·PSD 레이어별 모든 RGBA 채널 왕복 검증.
- PSD 파일 크기: **16,447,159 바이트**. 8개 레이어와 병합 이미지의 모든 RGBA 픽셀을 원본과 비교해 일치 확인.
- 독립 Pillow 판독에서도 PSD 1254 × 1254, RGBA, 8프레임으로 열렸고 병합 RGBA가 `fuel-source.png`와 정확히 일치했다.

이 납품 단계에서 Unity·게임 코드·임포터·메타 파일은 수정하지 않았다.

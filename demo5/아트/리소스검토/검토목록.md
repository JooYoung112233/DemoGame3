# 리소스 검토 — 2026-09-21

기능 개발은 중단하고 외형을 먼저 확정한다. 아래 이미지는 내장 image_gen으로 제작했으며 각각 폴더에 실제 사용 프롬프트를 저장했다. 기존 인게임 자산·코드 연결은 변경하지 않았다.

| 폴더 | 내용 | 상태 |
| --- | --- | --- |
| 01-배낭탐험가 | 배낭, 어두운 실루엣, 크림색 종이 외곽, 흰 받침대 | 사용자 외형 승인 |
| 02-생존지 | 기존 생존지 구도 유지, 평평한 종이 회화 질감, 소등된 광원 | 사용자 질감·화풍 승인 |
| 03-종이UI | 원정대 2인 카드 / 생존 정보 / 2×2 행동 카드, 상단 장소·시간 표지 | 사용자 질감 승인, 실제 배치·구성은 별도 |
| 04-손전등탐험가 | 묶은 머리, 작은 어깨가방, 꺼진 손전등, 동일한 흰 받침대 | 사용자 외형·질감 승인 |

배경과 UI 생성 원본은 각각 1672×941, 추가 캐릭터 원본은 1036×1518이다. 목표 3840×2160 원본에는 미달하며 확대 복원으로 간주하지 않는다.

이번 납품은 외형 검토용 단일 PNG다. UI 문구·수치·설명은 배치 예시이며 게임 규칙 확정이 아니다. UI가 그림에 포함되어 있어 실제 런타임 UI/분리 PSD가 아니다. 배경의 가구도 현재는 합쳐져 있다.

추가 캐릭터는 RGB 이미지에 체크무늬가 포함되어 있다. 실제 투명 PNG가 아니며 몸·받침대 분리와 알파 정리가 필요하다. 승인된 배낭 캐릭터도 같은 후처리가 남아 있다. 사용자 승인 후 해당 외형을 보존하며 제작용 분리 리소스를 정리한다.

## 최신 사용자 결정

개별 인벤토리·원정 짐 꾸리기·다인원 작업 지정 등을 포함한 [UI 전체 20종 시안](../UI전체시안-v1/index.html)을 추가했다. [설계와 검수 기록](../UI전체시안-v1/README.md)을 함께 참고한다. 신규 화면은 검토용이며 개별 승인은 아직 받지 않았다.

‘질감이 좋다’는 승인이다. UI 시안의 배치와 실제 기능을 그대로 확정한 것은 아니다. 생존지·탐색에서는 맵에 배치된 오브젝트를 클릭한 뒤 누가 무엇을 할지 지정하는 UI로 진행한다. 자세한 흐름은 `../../기획/오브젝트-중심-행동지정-UI.md`를 따른다. 기존 하단 행동 패널 구현이나 2×2 전투 버튼을 모든 상황에 강제하지 않는다.

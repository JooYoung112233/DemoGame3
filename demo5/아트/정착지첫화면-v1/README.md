# 정착지 첫 화면 리소스

시설 아이콘과 두 종이 말은 승인 UI 시안 04에서 분리했다. UI가 없는 배경은 기존 `Assets/Art/Backgrounds/shelter-unlit-v2.png`를 재사용한다. 원본 시안 04와 배경 구도가 완전히 같은 새 그림을 생성한 것은 아니다.

- `개별-PNG`: 1672×941 조명 없는 배경, 2종 전신, 흰 받침, 시설/시간/기록 아이콘.
- `PSD/shelter-native-layers.psd`: 배경과 2종 인물 분리. 배경 속 가구는 한 그림에 포함되어 있어 개별 레이어가 아니다.
- `PSD/standee-*.psd`: 인물별 단일 오브젝트 문서. 의상·머리 파츠 분리는 아니다.
- `PSD/interaction-icons.psd`: 7개 아이콘 별도 레이어.
- `PSD/settlement-art-layout.psd`: 3840×2160 배치용 편집 문서. 배경·인물·받침·종이·아이콘 분리. 글씨와 수치/게이지는 Unity에서 편집한다.
- `manifest.json`: 출처·추출 영역·현재 제한.

전신은 약 100×160, 아이콘은 약 30~40px의 기존 시안 추출본이다. 큰 PSD 배치 캔버스는 디테일 복원이 아니다. 원본 크기 PNG를 보존했고 확대용 고해상도 보완은 남아 있다. 두 전신 외 역할별 몸 이미지 역시 후속 제작 범위다. 모든 PSD는 저장 후 독립 리더로 레이어·알파·위치·합성 결과를 확인했다.

종이/초상/자원 아이콘의 기존 원본은 `../모험가선택-v1`과 `../정착지선택-v1`을 공유한다. 런타임 조명은 Unity URP Light2D에서만 적용한다.

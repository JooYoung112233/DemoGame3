# demo5 제작 규칙

## 승인 시안과 납품 — 2026-09-22 최신 사용자 지시

- **화면 공유:** 화면 수정·다음 화면 구현 후 실제 Unity 화면을 캡처하여 결과와 함께 사용자에게 보여준다. 설명만으로 완료 보고하지 않는다.
- **닫기 위치 통일:** 화면의 닫기/돌아가기는 좌측 하단 종이 버튼으로 통일한다. 인벤토리 우측 상단 X는 사용하지 않는다. 이후 화면도 이 규칙을 따르며, 수량 확인 같은 하위 확인창은 취소/확정 쌍을 유지한다.

- **제목 종이 선택:** 사용자가 직접 첨부한 계단형 찢어진 종이(`아트/시작화면-v2/원본/제목종이-계단형-미사용.png`, 파일명은 제작 이력)를 시작 제목 패널에 사용한다. 사각형으로 임의 대체하지 않는다. 제목 위치와 폭을 유지하며 종이 비율에 맞춰 높이와 내부 문구 배치만 조정한다. 현재 자산은 `title-paper-stepped.png`와 `title-paper-stepped.psd`다.
- **시작 화면 최신 정정:** 사용자는 현재 배경 구도와 UI 위치가 좋다고 확인했다. `시작화면-v1`/`StartMenu`의 배경 구도, UI 위치·크기, 버튼 수와 순서를 유지하고 리소스의 종이 질감·테두리·그림 마감만 승인 시안에 맞춰 교체한다. 3단 시안 첫 줄을 이유로 3버튼 배치로 재설계하지 않는다. 아래 미승인 표시는 리소스 마감·편집 원본 보완에 해당하며 현재 배치 거부로 해석하지 않는다.
- **추가 정정:** 사용자는 아이콘·글씨 크기·정렬 차이를 지적하고 시안의 100% 재현을 우선하도록 요청했다. 화면 바깥 배치 유지와 버튼 안 정렬 유지를 혼동하지 않는다. 아이콘은 승인 원본에서 분리하며, 버튼 내부 아이콘·문구·화살표 비율과 정렬을 시안에 맞춘다. 폰트만 유사한 실제 서체로 대체하는 것은 명시적으로 허용했다. 종이만 새로 생성한 뒤 시안 재현이라고 보고하지 않는다.
- 승인된 시안은 구현 기준이다. 분위기만 참고하여 새 디자인으로 재해석하지 않는다. 해당 화면의 승인 이미지와 구도·배치·비율·색·질감·캐릭터 형태를 직접 비교한다. 기능 구현이나 프리팹 분리를 이유로 시각 구성을 임의 변경하지 않는다.
- 화면별 기준은 `아트/UI전체시안-v1/manifest.json`의 최신 시안과 이후 사용자가 승인한 수정본이다. 기본 그래픽은 `아트/승인시안/README.md`를 함께 따른다. 시안의 예시 수치와 인원수를 게임 규칙으로 고정하지 않는다.
- 이미지 자산은 항상 사용자가 수정 가능한 개별 파일과 실제 레이어 PSD로 납품한다. PNG 원본 및 Unity용 투명 PNG도 보존한다. 배경·인물·소품·패널·버튼·아이콘 등 독립 수정이 필요한 요소를 분리하고 PSD 레이어에 명확한 이름을 붙인다.
- 합쳐진 PNG를 PSD에 한 장 넣거나 미리보기 이미지를 작은 조각으로 잘라낸 것만으로 편집 가능한 최종 리소스를 완성했다고 보고하지 않는다. 분리 불가능한 부분과 해상도 부족은 미완료로 기록한다. 큰 원본을 보관하며 확대를 디테일 복원으로 보고하지 않는다.
- 승인된 인게임 UI는 Unity에서 재사용 가능한 개별 프리팹으로 제작한다. 공통 버튼·패널·목록 항목·팝업과 화면 조립 프리팹을 적절히 나누고, 문구·이미지·배치를 Inspector에서 수정 가능하게 한다. 런타임 코드가 편집한 배치를 덮어쓰지 않도록 한다.
- UI 텍스트와 동적 수치는 이미지에 합치지 않는다. PSD는 이미지 편집 원본, Unity 프리팹은 인게임 UI 편집 단위로 함께 제공한다.
- 완료 보고 전 승인 시안과 실제 Unity 화면을 나란히 검수하고 차이를 기록한다. 클릭 동작 검증만으로 시안 재현이 완료됐다고 보고하지 않는다.
- 현재 `Assets/Scenes/StartMenu.unity`와 `아트/시작화면-v1`은 사용자에게 시안과 다르다는 지적을 받은 미승인 구현이다. PSD도 없으므로 최종 자산으로 취급하지 않는다. 다음 화면 확장보다 시작 화면의 시안 일치와 레이어 자산 보완을 우선한다.
- 사용자가 다시 요청하기 전까지 실행 파일 빌드는 생략하고 Unity Editor에서 검증한다.

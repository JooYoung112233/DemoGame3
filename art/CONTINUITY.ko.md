# 원화 공간 일관성 기준

사용자 피드백: 폴라로이드 연출의 흐름은 선호하지만, 캠핑카 전체 원화와 수혁·소이가 등장하는 대화 컷의 배경이 달라 보인다. 이후 제작에서 반드시 공간 일관성을 유지한다.

## 기준 배경

챕터 1의 현재 합성 베이스는 캠핑카 `chapter01/layers/camper-clean-base-v1.png`, 편의점 `chapter01/store/store-clean-base-v1.png`, 낡은 집 `chapter01/letter/old-house-clean-base-v1.png`다. 편의점은 물건 제거를 한 번 적용한 새 공통 베이스이며, 이후 물건 유무는 추출 레이어로만 바꾼다. 낡은 집은 첫 편지 장소를 위한 새 배치 시안이다.

캠핑카의 현 작업 기준은 scenes/01-camper/camper-mood-v1.png다. 분위기 기준인 concepts/camper-interior-v2.png의 구도를 계승한다. 앞으로 배경 수정본이 채택되면 기준 파일을 명시적으로 갱신하고 모든 파생 컷을 함께 확인한다.

## 제작 순서

최신 제작 규칙: [고정 베이스와 교체 레이어](chapter01/layers/README.ko.md)를 따른다. 소품을 제거한 베이스를 한 번 준비한 뒤 인물·소품·그림만 별도 합성한다. 날짜나 행동 상태마다 전체 장면을 재생성하지 않는다. `chapter01/layers/camper-clean-base-v1.png`는 새 베이스 후보이며 기존 기준 원화는 보존한다.

1. 기준 배경에서 사용할 화면 영역과 인물 위치를 먼저 정한다.
2. 같은 시점의 확대 컷은 기존 배경을 그대로 잘라 사용한다. 생성 도구에 배경 전체를 새로 그리게 맡기지 않는다.
3. 필요한 인물 포즈와 소품만 추가 또는 수정한다. 테이블 높이, 좌석 위치, 인물 크기와 가림 관계를 기준 배경에 맞춘다.
4. 별도 시점이 꼭 필요한 경우 창문·주방·식탁·좌석·침대·램프의 실제 상대 위치와 비율을 유지한다. 시점 변경은 새로운 가구 배치를 허용한다는 뜻이 아니다.
5. 완성 후보를 전체 화면과 나란히 비교하여 확인한다. 프롬프트에 유지 지시를 넣은 것만으로 일관성이 확보되었다고 판단하지 않는다.

## 확인 항목

- 창문, 주방, 식탁, 초록 벤치, 체크 침구, 아래쪽 침대, 램프의 위치와 개수.
- 가구의 모양, 크기, 높이와 서로의 거리. 임의로 의자나 창문을 추가하지 않는다.
- 수혁과 소이의 크기, 앉는 위치, 발과 손의 접촉, 가구 앞뒤 가림.
- 광원 위치와 색온도. 고정 행동 포즈는 해당 위치의 배경 조명에 맞춰 그린다.
- 이야기상 변하는 색연필, 그림, 음식 등은 의도한 소품 변화로 기록한다.

## 현재 시안 상태

story-moments/01-blue-pencil/blue-pencil-v1.png 및 blue-pencil-clean-v1.png는 연출 흐름을 보여주는 시안이며 공간 일관성 검수를 통과한 최종 자산이 아니다. 기존 폴라로이드 시제품의 연출 방식은 유지하되, 이후 게임용 제작에서 인물 컷 배경을 기준 원화에 맞춰 교정해야 한다. 이번 문서 추가로 이미지 교정이 완료된 것은 아니다.

`chapter00`, `chapter01`, `chapter00-01`은 장면별 제작 원본과 변경 이력입니다. 그 안의 옛 버전도 비교·재편집용으로 보존합니다. `style-reference`, `style-revision`은 참고/실험이며 현재 최종 사용 목록이 아닙니다. 그림 파일 경로는 콘티·레이어·매니페스트의 연결을 유지하기 위해 이번 문서 정리에서 이동하지 않았습니다.

새 그림은 기존 장면 폴더의 원본·레이어·검수 구분을 따르고 최신 사용 목록을 갱신합니다. 여기저기 같은 최종본을 복사해 두지 않습니다.

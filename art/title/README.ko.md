# 시작 화면 · 배경과 글씨 분리 패키지

2026-09-09. 실제 프로젝트에 사용할 수 있도록 배경, 로고, 동적 메뉴 글씨를 분리했다. 배경은 사용자 요청에 따라 A/B/C 선택 후보를 유지하며 최종 채택은 미정이다. Unity 프로젝트와 본편 연결은 아직 없다. 처음 만든 사실적인 `title-background-v1.png`는 보관용이며 현재 비교 화면에서 사용하지 않는다.

## 배경 후보

| 파일 | 방향 | 출력 |
| --- | --- | --- |
| `background-a-v2.png` | 따뜻한 빛, 책 위에 얹은 손, 비스듬한 구도 | RGB 1672×941 |
| `background-b-v2.png` | 위에서 본 책, 펼치기 전 멈춘 손 | RGB 1672×941 |
| `background-c-v2.png` | 낮은 시점과 어두운 주변, 손과 책의 작은 빛 | RGB 1672×941 |

세 PNG에 제목·메뉴·문자는 들어 있지 않다. 기존 캠핑카, 수혁 캐릭터, 스케치북을 스타일·소품 기준으로 내장 image_gen에서 생성했다. 사용한 프롬프트는 각 PNG와 같은 이름의 `.prompt.txt`에 있다. 새 원화이며 각 후보의 책·손 위치가 달라 최종 선택 후 해당 구도를 회상용 손 컷의 기준으로 삼는다.

4K 출력은 아니다. 원본 픽셀을 보존했다. 1080p 전체 화면의 선명도는 대상 디스플레이에서 최종 확인하고, 큰 확대용 손 원화는 별도 제작한다. 단순 확대 저장을 고해상도 원화라고 표시하지 않는다.

## 글씨

- `logo-v1.svg`: 투명 배경, 글꼴을 벡터 경로로 변환한 로고. 640×244 viewBox. 글꼴 설치 없이 표시 가능.
- `logo-v1.png`: 동일한 로고의 투명 RGBA 2560×976 버전. Unity UI에 직접 사용할 때 선택 가능.
- `logo-source.json`: 제목·부제·크기·자간·색·기준선 값. 로고 수정 후 `tools/build-title-type.py`로 재생성한다.
- `fonts/Live49MenuSerif-Regular.ttf`: 메뉴와 한국어 문자열용 정적 글꼴. 웹 UI는 함께 제공한 WOFF2를 로컬 로드한다. 메뉴 글씨는 이미지에 굽지 않았다.
- 원본 Noto Serif KR, Cormorant Garamond와 각 OFL 라이선스를 `fonts`에 보관했다. 파생 메뉴 글꼴은 Live49 Menu Serif로 이름을 바꿨다. 배포 시 해당 라이선스와 저작권 고지를 동봉한다.

글꼴 출처: [Noto Serif KR](https://github.com/google/fonts/tree/main/ofl/notoserifkr), [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond). 원본 글꼴은 로고 재생성을 위한 제작 소스이며 런타임에는 로고 이미지와 파생 메뉴 글꼴만 필요하다.

## 배치 기준

배경 → 선택적인 가독성 음영 → 로고 → 메뉴 텍스트 → 설정 창 → 전환용 암전 순서다. 로고나 메뉴를 배경에 합쳐서 사용하지 않는다.

기준 화면은 16:9다. 로고·메뉴 묶음은 화면 왼쪽 7.5%, 위 19%, 폭 30%를 기준으로 한다. 로고는 그 묶음의 폭에 맞추고 아래에 메뉴를 놓는다. 왼쪽 약 42%를 글씨 영역으로 사용하고 오른쪽의 책·손을 가리지 않는다. 정확한 웹 값은 `design/title/title.css`에 있다. 다른 화면비에서 중요한 대상이 잘리지 않도록 전체 16:9 화면을 맞추는 방식을 우선한다.

## 확인 화면 실행

저장소 루트에서 `node tools/serve-title.cjs` 실행 후 [배경 비교 화면](http://127.0.0.1:8785)을 연다. 위쪽 A/B/C 버튼은 비교용이며 실제 메뉴에 포함하지 않는다. ‘배경만 보기’로 로고·메뉴·가독성 음영을 숨기면 순수 배경을 볼 수 있다.

`design/title/title-screen.js`의 `mountTitle()`이 실제 재사용할 웹 UI 구성 요소다. 게임 저장 여부와 시작·이어하기·종료·설정 적용 콜백은 외부에서 넘긴다. 콜백이 없으면 해당 동작은 비활성화된다. 저장이 없으면 이어하기를 숨긴다. 비교 화면의 시작·종료 콜백은 입력을 화면 바깥에 확인해줄 뿐, 아직 없는 본편을 실행한 것으로 처리하지 않는다. 음량은 설정값을 전달하며 비교 화면에는 실제 오디오가 없다.

Unity 적용 시 배경과 로고는 각각 별도의 UI 이미지로, 메뉴는 텍스트와 버튼으로 구성한다. 제공한 정적 TTF와 폰트 라이선스를 함께 가져가며 본편 장면·저장·종료 연결은 Unity에서 구현한다. 이 패키지에 Unity 구현이나 검증이 포함된 것은 아니다.

## 확인한 내용

- 세 배경의 파일 크기·해상도와 로고 PNG 알파 채널 확인.
- 브라우저에서 A/B/C 교체, 로고·메뉴 합성, 설정 창, 키보드 시작 입력과 완료 후 메뉴 복귀 확인.
- 생성 원화의 글씨 없음과 기존 원화 대비 단순화된 선·명암을 시각 확인. 최종 화풍 채택은 사용자 검수 대상.
- 실제 장면 이동, 본편 저장, 애플리케이션 종료, 게임패드, 모든 화면비는 아직 검증하지 않았다.

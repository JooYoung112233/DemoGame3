# 도시 지도 원화 · 뭉갠 채색 v2

2026-09-12 사용자 요청: 낙원처럼 도로·건물이 보이는 도시 지도. v1 확인 후 “AI풍이 너무 티 나니까 일부러 그림들을 뭉개자. 갈 수 있는 곳은 따로 표시한다”는 피드백을 적용했다.

현재 Unity 연결본은 `city-map-soft-source-v2.png`다. 지붕·설비·잎·수면의 촘촘한 잔묘사를 줄이고 큰 붓면과 부드러운 경계로 다시 채색했다. 기존 게임 인물·배경 그림은 이 지도 수정에서 변경하지 않았다.

| 파일 | 실제 크기 | 용도 |
| --- | --- | --- |
| `layout-reference.png` | 3660×2376 | Unity 벡터 지형을 직접 렌더한 도로 배치 참조. 원화 해상도 복원본이 아님 |
| `city-map-source-v1.png` | 1556×1011 RGB | 처음 생성한 세밀한 지도 비교 원본 |
| `city-map-soft-source-v2.png` | 1555×1011 RGB | 사용자 피드백을 적용한 현재 원본 |
| `prompt.txt` | 텍스트 | 최초 생성 프롬프트 전문 |
| `prompt-soft-v2.txt` | 텍스트 | 현재 뭉갠 채색 수정 프롬프트 전문 |

두 그림 모두 **내장 imagegen**으로 생성·수정했다. 지도 자체는 본 프로젝트용으로 새로 만들었으며 낙원의 이미지 자산을 게임에 복사하지 않았다. 게임 지도 화면의 참고 방향은 [낙원 공식 페이지](https://nakwon.nexon.com/en/teaser)다.

## 원본과 표시 크기

- 실제 생성 원본을 확대·축소하지 않고 보관했다. 3840px급 출력을 요청했지만 실제 도구 출력은 위 치수다. 원화 규칙의 큰 원본 목표에 미달하며, 최대 확대에서 새 세부 묘사가 생기는 고해상도 납품본으로 취급하지 않는다.
- Unity 표시 좌표는 1220×792, 확대 범위는 100~250%다. 확대는 이 원본을 보간하므로 큰 배율에서는 더 부드러워진다.
- v2 SHA-256: `bb153b4d59923917fee39179f046d00ba52a770ebbbdd88544d77d5e85b7eb59`.
- Unity 파일: `Demo3/Assets/_Project/Resources/Live49/Maps/city-map-soft-v2.png`. TextureImporter에서 NPOT 변경 없음·비압축·mipmap 없음·Bilinear·Clamp로 원래 치수를 유지한다.

## 레이어와 좌표

배경은 불투명 **평면 PNG**다. 건물·나무·강을 독립 편집할 수 있는 분리 레이어나 PSD는 아직 없다. 이름·장소 핀·현재 위치·선택 테두리·경로·버튼은 그림에 합치지 않고 Unity UI에서 별도로 그린다.

`MapPaperGraphic`에 도로 배치 참조와 첫 이동 경로를, `FirstRegionMap`에 장소 좌표를 보관한다. 바탕 파일을 읽지 못하면 벡터 지형을 표시한다. 도로와 강은 이전 배치 참조를 따라 재채색했으며 최종 세계관 지리로 확정한 자료는 아니다.

주요 좌표: 편의점 `(734,395)`, 편의점 주차장 현재 위치 `(765,437)`, 최초 캠핑카 `(395,590)`. 첫 캠핑카의 주차 공간 → `(420,590)` → `(420,460)` → `(734,460)` → 편의점으로 경로를 그린다. 실제 이동 연결은 현재 첫 편의점 범위다.

실제 게임 화면과 동작 검수는 [도시 지도 적용 기록](../../../docs/08-UI연출/UNITY-CITY-MAP.ko.md)을 따른다.

# 캠핑카 배경 제작 기준

목표 환경: Unity 6.6 + URP 2D Renderer. 현재 분위기 기준은 camper-interior-v2.png이며, camper-interior-v3-base.png는 조명 분리 실험용으로 보관한다. 사용자는 v2의 분위기를 더 선호하므로 v3를 최종 화풍으로 채택하지 않는다. 두 파일 모두 단일 이미지 시안이며 레이어 분리나 충돌 구현이 완료된 게임 자산은 아니다.

## 후속 게임 자산 제작

- 기존 배경의 따뜻한 재질색과 은은한 입체 명암은 유지한다. 캐릭터와 함께 변해야 하는 발광, 빛 번짐, 강한 광원 색과 투영 그림자는 별도로 처리한다. 조명 분리를 이유로 배경을 과도하게 평평하게 만들지 않는다.
- 따뜻한 조명은 램프와 입구 위치의 별도 광원으로 제작하여 캐릭터와 배경에 함께 반영한다. 배경에만 노란 오버레이를 붙이는 방식으로 마무리하지 않는다.
- 바닥/후면 배경, 캐릭터를 가릴 가구/차체 전경, 램프 발광을 별도 자산으로 만든다. 분리할 때 가려졌던 바닥도 복원한다.
- 테이블, 수납 상자, 차량 아래쪽 벽은 캐릭터와 앞뒤 가림 관계를 검증한다. 큰 가구는 필요하면 부분 분리한다.
- 캐릭터의 발 위치를 이동 및 앞뒤 정렬 기준으로 사용한다. 상체 전체를 충돌 크기로 사용하지 않는다.
- 입구에서 러그와 주방 앞까지의 통로를 첫 이동 영역으로 삼는다. 침대, 테이블, 주방, 차체에는 충돌을 둔다. 테이블 아래를 보행 가능 바닥으로 오인하지 않도록 한다.
- 캐릭터 실제 크기를 정한 뒤 문, 주방 앞, 테이블 아래쪽 통로의 통과 여부를 검사하고 필요하면 가구 배치를 최소 조정한다.
- 최종 논리 해상도와 캐릭터 픽셀 크기는 함께 확정한다. 현재 생성물은 정밀한 단일 픽셀 격자를 보장하지 않으므로 최종 도트 정리가 필요하다.

## 후속 검증

같은 캐릭터를 주방 앞, 러그, 테이블 앞, 출입구에 배치하여 발 접지와 가림을 확인한다. 조명을 켜고 끈 상태에서 캐릭터와 바닥의 색온도가 함께 변하는지 확인한다. 현재는 엔진 프로젝트나 조작 테스트를 만들지 않았다.

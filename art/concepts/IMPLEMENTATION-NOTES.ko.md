# 캠핑카 게임 적용 기준

목표 환경: Unity 6.6 + URP 2D Renderer. 현재 분위기 기준은 camper-interior-v2.png이며, camper-interior-v3-base.png는 조명 분리 실험용으로 보관한다. 사용자는 v2의 분위기를 더 선호하므로 v3를 최종 화풍으로 채택하지 않는다. 두 파일 모두 단일 이미지 시안이며 레이어 분리나 충돌 구현이 완료된 게임 자산은 아니다.

## 현재 조작 방향

오브젝트 클릭 → 정해진 위치에 정지 행동 포즈 표시 → 말풍선/폴라로이드 대화/짧은 미니게임 → 결과 반영. 자유 이동, 경로 탐색, 걷기 애니메이션은 첫 제작 범위가 아니다.

- 배경의 따뜻한 재질색과 고정 조명을 유지한다. 각 포즈는 해당 위치의 빛과 그림자에 맞춰 제작한다.
- 실시간 캐릭터 조명은 필수가 아니다. 램프 깜빡임 같은 효과는 필요한 경우만 별도 추가한다.
- 테이블이나 차체가 캐릭터를 가리는 부분만 분리한다. 모든 가구를 미리 세분화하지 않는다.
- 인물 위치, 소품 상태, 대사 UI를 별도로 관리해 같은 배경에서 여러 행동을 보여준다.
- 폴라로이드 인물 컷도 원본과 같은 공간을 유지한다. [공간 일관성 기준](../CONTINUITY.ko.md)을 따른다.
- 고정 행동 지점에서 인물의 크기, 손과 발 접촉, 가구 앞뒤 가림을 확인한다.
- 최종 도트 규격은 배경과 캐릭터를 함께 비교해 정한다. 생성 이미지가 단일 픽셀 격자를 보장한다고 가정하지 않는다.

## 후속 검증

주방, 식탁, 수납함, 침대의 행동 포즈를 같은 배경에 놓고 확인한다. 미니게임과 대화 종료 후 올바른 포즈와 소품 상태가 남아야 한다. 현재 최종 자산 분리와 Unity 구현 검증은 완료하지 않았다.

전체 우선순위는 [챕터별 제작 계획](../../docs/00-제작관리/DEVELOPMENT-PLAN.ko.md)을 따른다.

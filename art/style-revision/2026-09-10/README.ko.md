# 반실사 화풍 전환 · 수혁 얼굴 첫 시안

기준: `docs/05-원화/ART-STYLE-DIRECTION.ko.md`, 승인된 엄마 초상. 2026-09-10 사용자가 기존 게임 원화 수정을 요청하여 수혁 얼굴부터 비교 가능한 시안으로 제작했다. 이 수혁 얼굴은 아직 사용자 승인 전이다.

`suhyeok-face-study-v1.png`: 원본 1024×1536. 머리와 목·가슴이 보이는 얼굴 디자인 시안이며 게임용 투명 대화 초상은 아니다. 불투명 배경을 포함한 한 장의 그림으로, 레이어 PSD나 표정 분리 완료를 주장하지 않는다. 원본과 생성 프롬프트, 참조 경로는 함께 보관한다.

유지한 설정: 짙은 갈색 흐트러진 짧은 머리, 베이지 셔츠, 기존 가벼운 턱수염, 차분하고 다정한 아버지 인상, 화면 오른쪽을 향한 시선. 바꾼 표현: 만화식 눈·코·턱 비율을 반실사 구조로 정리하고 피부까지 붓면을 적용했다. 다음 검토에서는 기존 수혁의 인상이 남아 있는지, 너무 젊거나 정형적인 미남으로 보이지 않는지 확인한다.

화풍 전환 순서: 수혁 얼굴 → 소이의 연령에 맞는 얼굴·신체 비율 → 두 사람의 대화용 분리 초상 → 가족사진·발·손 회상 컷 → 기존 구도 유지한 캠핑카/편의점 배경·소품. 배경의 새 화풍은 별도 장면 시안에서 확인한다.

현재 런타임 참조·기존 원화·고정 배경은 교체하지 않았다. 서연 얼굴 비공개와 화자 이름 공개 규칙도 그대로 유지한다. 얼굴 디자인을 잡은 뒤 큰 행동 포즈와 실제 분리 레이어를 제작한다.

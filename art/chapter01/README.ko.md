# 챕터 1 · 1차 시각 리소스 묶음

최신 [원화 원본·납품 규칙](../../docs/ART-ASSET-RULES.ko.md)을 적용한다. 원화 작업에서는 이름표 등 UI를 다듬지 않고, 수정 가능한 큰 원본·분리 레이어와 가능한 경우 PSD를 우선한다. 현재 작은 추출 PNG들은 배치 시안이며 새 고해상도 마스터로 간주하지 않는다.

고정 베이스에 투명 PNG를 얹어 상태를 바꾼다. 같은 장소의 조사·대화·클로즈업마다 배경을 다시 생성하지 않는다. 현재 범위는 원화와 연출의 1차 시안이다.

사용자 후속 검수에서 인물과 배경의 초점·화풍 불일치가 지적됐고, 주방 보정 방향을 승인받은 뒤 [전체 장면 보정 v2](focus-review/README.ko.md)를 적용했다. 원본 크기의 배경과 인물을 공통 캔버스에 합성하며 크기·접촉 그림자·가림·장소별 명암과 확대 구도를 조정했다. 미세한 작화 통일은 최종 원화 단계에 남는다.

## 만들어진 묶음

최신 사용자 피드백은 [장면 수정 v3](revision-v3/README.ko.md)에 반영했다. 수혁의 교감·서랍 확인·편지 읽기 전용 자세 3개, 편의점·집의 열린 앞면, 정리한 캠핑카 외부를 사용한다. 실내 가구와 소품 기준은 기존 픽셀로 유지한다.

| 폴더 | 내용 |
| --- | --- |
| `layers` | 캠핑카 클린 베이스, 식탁 가림, 책·컵·연필통, 앉기/그리기 분할 인물, 페이지 상태 |
| `kitchen` | 새 수프 냄비 원화와 투명 소품 |
| `shared-props` | 기존 시트에서 추출한 식재료·수프·약·저널·색연필 상자 |
| `extra-poses` | 기존 시트에서 추출한 수혁 요리·조사·앉은 휴식 포즈 |
| `dog` | 별똥이 외형 시안, 대기·경계·쉬기 3개 투명 포즈 |
| `store` | 기존 편의점에서 회수 물건을 뺀 고정 베이스, 원래 물건 4종의 투명 추출본 |
| `letter` | 낡은 집 고정 베이스, 분홍색 봉투·편지지, 생성 프롬프트 |
| `scene-qa`, `gallery-qa` | 합성 결과·브라우저 검수용. 게임에 직접 넣는 배경이 아니다 |

`design/chapter01/asset-catalog.json`은 사용 파일·치수·투명 영역·해시·참조 장면을 담는다. 원화 소스와 추출 스프라이트를 구별한다. 알파가 없는 생성 원본을 투명 스프라이트로 취급하지 않는다.

## 배치 규격

모든 장면 배치는 1672×941, 왼쪽 위 기준 픽셀 좌표다. 각 JSON의 `rect`는 `[x,y,width,height]`, `order`는 합성 순서다. Unity에 옮길 때 좌표·피벗·정렬값으로 변환한다. 스크린 좌표를 월드 좌표로 그대로 쓰지 않는다.

최신 통합 배치는 `design/chapter01/gallery-scenes.json`을 사용한다. 개별 기본 배치에 `visual-integration-v2.json`, `visual-revision-v3.json`을 차례로 적용한 결과로, 장소별 톤·접촉 그림자·가림 정보가 포함된다. 화면의 색 조정은 원본 텍스처를 덮어쓰지 않는다.

- 일반 식탁: 몸 20 → 식탁 30 → 소품 40 → 페이지 45 → 손 50.
- 주방: 요리 인물 40 → 식탁 가림 44 → 수프 그릇 46 → 앉은 인물의 손 50. 식탁이 요리 인물의 발을 가린다.
- 편의점: 물건 30 → 조사 인물 40. 소품은 기존 배경에서 잘랐기 때문에 기존 어두운 색을 유지한다.
- 낡은 집: 봉투가 열린 서랍 안에 들어가며 서랍 앞판을 덮지 않는 위치다.

인물은 그 자세에서 보이는 부분만 있는 리소스다. 걷기나 자유 배치에 쓸 완전한 캐릭터 모델이 아니다. 포즈의 최종 색 보정과 더 정교한 접지·가림은 Unity 배치 때 다듬는다.

## 통합 미리보기 재생성

Pillow, NumPy가 있는 Python에서 저장소 루트를 작업 위치로 실행한다. `preview-output`은 원하는 출력 디렉터리로 바꿀 수 있다.

```powershell
python tools/build-ch01-gallery.py preview-output
node tools/serve-camper-layer-preview.cjs preview-output/chapter-one.html 8775
node tools/check-ch01-gallery.cjs preview-output
```

첫 명령은 6개 장면·33개 상태를 한 미리보기로 만든다. 상단 선택은 제작 검수용이며 최종 게임의 행동 목록이 아니다. 플레이 화면에서는 해당 상황의 대상만 이름과 하이라이트를 표시한다. 미리보기는 저장·아이템 지급·날짜 진행·확률 판정을 실행하지 않는다. 축소 JPEG/WebP는 미리보기에만 사용하며 원본 PNG는 유지한다.

현재 검수 스크립트는 이 작업 환경에 설치된 Playwright와 Microsoft Edge를 사용한다. 다른 PC에서는 스크립트의 Playwright 경로를 설치 위치에 맞춰야 한다. 반복 생성 가능한 QA PNG는 Git에서 제외하며 로컬에는 유지한다. 검사 결과 JSON은 저장소에 포함한다.

개별 원화 배치 JSON은 `design/chapter01`, 첫 그림 9개 대사와 페이지 연결은 `design/interaction/ch01-first-drawing-v1.json`에 있다. 첫 편지의 8개 문단은 `design/chapter01/first-letter-text.json`에 사용자 원문 그대로 보존했다.

## 제작·검수 경계

내장 `image_gen`으로 만든 이번 새 원화는 냄비, 별똥이 포즈 시트, 편의점 클린 베이스, 낡은 집, 편지 소품 시트다. 옆의 `.prompt.txt`가 사용 프롬프트다. 투명 PNG 분리는 사용자가 허용한 로컬 이미지 처리로 수행했다. 원본은 보존한다.

별똥이의 작은 유기견 설정은 원문이며 털색·귀 모양은 새 시안이다. 낡은 집의 가구 배치, 편지 앞뒤의 짧은 대사, 음식·강아지·미획득 저녁 대사는 새 초안이다. 챕터 날짜와 상세 분기 대본은 확정하지 않았다.

이 묶음에는 음원, 최종 UI 아틀라스, 최종 전신 수면 포즈, 실제 경로 지도, 저장 기능, 미니게임·소음 확률·Unity 프로젝트가 없다. 휴식은 앉은 포즈, 이동 준비는 목적지 안내로 표현했다. 확대 선명도 작업은 사용자 요청대로 보류했다.

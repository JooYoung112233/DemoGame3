# 장면 수정 v3

사용자 피드백: 수혁의 같은 조사 자세 반복, 시야를 막는 건물 앞벽, 캠핑카 밖의 과밀한 잔디·돌·균열, 인물이 배경에서 떠 보이는 문제.

## 적용

- 별똥이 첫 교감: 바닥에 한쪽 다리를 접고 앉아 손 내미는 전용 포즈.
- 편지 발견: 서서 서랍을 확인하는 포즈 → 두 손으로 편지를 읽는 포즈. 편의점에만 기존 쪼그린 조사 포즈를 남긴다.
- 편의점·낡은 집: 카메라 앞쪽 입구 벽과 프레임을 없앤 열린 단면. 편의점 앞 창틀을 다시 덮던 가림 처리도 제거했다.
- 캠핑카 외부: 가드레일과 많은 돌·풀·균열을 줄이고 조용한 바닥 면과 드문 식생으로 정리했다.
- 새 포즈는 장면별 밝기·채도·대비와 접지 그림자를 적용한다. 확대 전 공통 캔버스에서 합성한다.
- 편의점 조사 인물도 240×306에서 195×249로 줄여 선반·머리 크기를 다른 장면과 맞추고, 손과 바닥 접촉 위치를 다시 조정했다.

## 고정 배치 보존

새 배경 전체를 그대로 교체하지 않았다. 편의점 가구 영역, 집 안의 책상·열린 서랍, 캠핑카 운전석과 생활 공간은 기존 픽셀을 복원했다. `*-preserved-region-v3.png`의 흰 영역은 기존 원본과 픽셀 단위로 같다. 가림 벽·전경과 캠핑카 외부 등 수정 영역은 새 생성본을 사용한다. 보호 영역의 경계와 범위는 `tools/prepare-ch01-revision-v3.py`에 기록했다.

원래 베이스, 생성한 수정 원본(`*-edit-source-v3.png`), 합성한 최종 베이스(`*-clean-base-v3.png`)를 따로 보관한다. 이 폴더의 프롬프트 파일은 생성 지시와 보존 조건이다. 소품을 다시 그리거나 위치를 옮기지 않는다.

포즈 시트는 알파가 없는 생성 원본이다. `suhyeok-*-v3.png` 세 파일만 실제 RGBA 스프라이트이며, 사용자에게 허용받은 배경 제거로 추출했다. 팔·다리 사이 배경도 제거했다. 편지를 쥔 손과 종이는 이 고정 읽기 포즈의 한 레이어로 사용한다.

## 사용·확인

기본 배치 → `visual-integration-v2.json` → `visual-revision-v3.json` 순서로 적용한 `design/chapter01/gallery-scenes.json`이 최신 배치다. 기존 v1/v2는 비교용으로 보존했다. 저장된 생성 원본만으로 추출·배경 보존 작업을 재실행할 수 있다.

```powershell
python tools/prepare-ch01-revision-v3.py
python tools/build-ch01-gallery.py preview-output
python tools/catalog-ch01-assets.py
node tools/check-ch01-gallery.cjs preview-output
node tools/check-ch01-integration.cjs preview-output/chapter-one.html
```

확대 및 전체 화면에서 새 자세의 손 위치·바닥 접촉·앞벽 제거를 시각 검수한다. 기능 검사 통과가 최종 화풍 확정을 뜻하지는 않는다. 남은 인물의 세부 붓결 통일과 고해상도 확대는 후속 다듬기 대상이다. 첫 편지 본문·날짜·미니게임 규칙은 변경하지 않았다.

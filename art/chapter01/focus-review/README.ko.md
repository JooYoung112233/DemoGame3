# 배경·인물 선명도와 배치 재검수

사용자 피드백: 캐릭터와 배경이 어울리지 않으며 초점도 다르다. 기존 기능·알파 검수가 시각적 통합의 완성을 뜻하지 않는다.

## 확인한 문제와 이번 수정

기존 통합 미리보기는 1672px 배경을 1000px JPEG로 낮추면서 인물은 상대적으로 높은 픽셀 밀도를 유지했다. 둘을 따로 CSS 확대해 인물의 윤곽이 더 선명하고 배경만 흐릿해지는 차이가 있었다.

현재 미리보기 빌더는 배경의 1672×941 해상도를 유지한다. 배경과 모든 활성 레이어를 같은 크기의 캔버스에 그린 뒤 하나의 화면으로 확대한다. 이미지 품질 차이가 강조되던 경로를 수정했으며 강제 블러나 새로운 배경 생성으로 가리지 않았다. PNG 원본은 보존했다.

주방 수혁은 `[740,245,130,262]`에서 `[725,230,156,314]`로 크기와 발 위치를 조정했다. 조리대·식탁·벤치 배치는 그대로다. 식탁의 가림 순서는 유지한다.

## 아직 남은 원화 문제

서로 다른 시트에서 추출한 인물은 배경과 선 굵기·단순화 정도·명암이 완전히 같지 않다. 특히 조사 포즈의 시점과 바닥 접촉, 밝은 소품의 공간 조명은 별도 검토가 필요하다. 이번 결과는 초점·배치 수정본이며 화풍 최종안이 아니다. 리소스 수량을 늘리기 전에 한 장면의 시각적 통합을 기준으로 확정해야 한다.

`qa/before.png`, `qa/after.png`는 같은 화면 크기·카메라에서 브라우저가 렌더링한 비교 캡처다. QA PNG는 로컬에만 유지한다. 미리보기 빌더 → `capture-focus-comparison.cjs` → `build-focus-comparison.py` 순서로 재생성할 수 있다. 비교 도구의 이전 화면 입력은 `preview-output/chapter-one-before-focus.html`이며 수정 전 화면을 보존한 로컬 파일이다.

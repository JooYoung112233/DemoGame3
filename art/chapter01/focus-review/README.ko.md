# 배경·인물 선명도와 배치 재검수

이 문서는 v2 보정의 이력이다. 현재 합성에는 [장면 수정 v3](../revision-v3/README.ko.md)를 이어서 적용한다. 편의점의 앞 창틀 가림은 제거했고, 별똥이·편지는 전용 자세로 교체했다. 최신 값은 `design/chapter01/gallery-scenes.json`을 따른다.

## 전체 장면 적용 · v2

사용자가 주방 보정을 승인한 뒤 동일 기준을 6개 장면·33개 상태에 적용했다. v2 보정 값은 `design/chapter01/visual-integration-v2.json`에 보존한다. 개별 `kitchen.json`, `store.json` 등은 원래 배치 생성값이며, 최신 통합 배치는 v2와 v3 프로필을 모두 적용해야 한다.

| 장면 | 적용 사항 |
| --- | --- |
| 주방 | 승인된 크기/발 위치 유지. 발밑 접촉 그림자와 음식 소품의 밝기·채도 조정 |
| 편의점 | 조사 인물 크기와 바닥 위치 조정. 앞 창틀이 인물의 아래쪽을 가림. 주변에 맞춰 밝기·채도·대비 완화 |
| 낡은 집 | 의자·책상에 맞춰 조사 인물 확대. 발밑 그림자, 봉투 밝기 조정. 이름표를 아래로 옮겨 얼굴 가림을 줄임 |
| 별똥이 | 야외 수혁을 캠핑카에 맞는 크기로 조정. 야외와 실내의 밝기 구분, 각 자세의 발밑 그림자 |
| 저녁·휴식 | 저널/약병 장면에서 머리가 잘리지 않도록 구도 변경. 쉬는 장면에 두 인물과 별똥이가 들어오게 조정 |
| 첫 그림 | 승인된 앉기·그리기 배치 유지. 동일 해상도의 합성 경로 적용 |

조사 포즈는 `suhyeok-investigate-v2.png`를 사용한다. 머리카락 틈과 팔 안쪽에 남았던 배경색 501픽셀의 알파만 제거했으며 RGB는 원본과 동일하다. v1도 보존했다.

`tone`은 `[밝기, 채도, 대비]` 순서의 화면 합성 값이다. 원본 PNG를 색 보정해 덮어쓰지 않는다. `contactShadow`는 `[중심X, 중심Y, 가로반경, 세로반경, 불투명도]`로 나타낸 부드러운 접촉 그림자이며 해당 인물이 보일 때만 표시한다. 창틀 가림은 클린 베이스의 같은 영역을 맨 위에 복원한다. Unity 적용 시 이 레이어 순서와 조정 값을 재현해야 한다.

검수는 736px/360px의 모든 상태, 전체·확대 구도, 편지 원문, 하이라이트를 대상으로 했다. 1672×941의 공통 합성 크기, 창틀 가림의 실제 출력 픽셀, 인물이 사라질 때 그림자도 사라지는 것을 별도 검사했다. 브라우저 검수로 갱신한 `scene-qa` PNG는 최신 합성 화면이다. 개별 준비 스크립트는 기본 배치만 출력하므로 실행 후 통합 빌더와 브라우저 검수를 다시 실행한다.

현재는 사용자에게 승인받은 주방 보정 방향을 전 장면에 확장한 상태다. 자세별 원화 선의 세부 형태·미세한 명암은 서로 완전히 같은 작화로 다시 그린 것이 아니며, 최종 원화 다듬기 항목으로 남긴다. 무리한 블러로 선을 뭉개지는 않았다.

## 이전 주방 비교 기록

사용자 피드백: 캐릭터와 배경이 어울리지 않으며 초점도 다르다. 기존 기능·알파 검수가 시각적 통합의 완성을 뜻하지 않는다.

## 확인한 문제와 이번 수정

기존 통합 미리보기는 1672px 배경을 1000px JPEG로 낮추면서 인물은 상대적으로 높은 픽셀 밀도를 유지했다. 둘을 따로 CSS 확대해 인물의 윤곽이 더 선명하고 배경만 흐릿해지는 차이가 있었다.

현재 미리보기 빌더는 배경의 1672×941 해상도를 유지한다. 배경과 모든 활성 레이어를 같은 크기의 캔버스에 그린 뒤 하나의 화면으로 확대한다. 이미지 품질 차이가 강조되던 경로를 수정했으며 강제 블러나 새로운 배경 생성으로 가리지 않았다. PNG 원본은 보존했다.

주방 수혁은 `[740,245,130,262]`에서 `[725,230,156,314]`로 크기와 발 위치를 조정했다. 조리대·식탁·벤치 배치는 그대로다. 식탁의 가림 순서는 유지한다.

## 아직 남은 원화 문제

서로 다른 시트에서 추출한 인물은 배경과 선 굵기·단순화 정도·명암이 완전히 같지 않다. 특히 조사 포즈의 시점과 바닥 접촉, 밝은 소품의 공간 조명은 별도 검토가 필요하다. 이번 결과는 초점·배치 수정본이며 화풍 최종안이 아니다. 리소스 수량을 늘리기 전에 한 장면의 시각적 통합을 기준으로 확정해야 한다.

`qa/before.png`, `qa/after.png`는 같은 화면 크기·카메라에서 브라우저가 렌더링한 비교 캡처다. QA PNG는 로컬에만 유지한다. 미리보기 빌더 → `capture-focus-comparison.cjs` → `build-focus-comparison.py` 순서로 재생성할 수 있다. 비교 도구의 이전 화면 입력은 `preview-output/chapter-one-before-focus.html`이며 수정 전 화면을 보존한 로컬 파일이다.

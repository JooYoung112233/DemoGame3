# 챕터 1 밴딧 첫 조우 원화 v1

2026-09-13. 원화 준비와 Unity Sprite 반입까지 완료했다. 실제 조우 발생 조건·선택 결과·귀환 반응은 아직 게임 진행에 연결하지 않았다.

기존 인게임의 부드럽게 뭉갠 그림 느낌을 기준으로 골목 배경과 두 인물을 제작했다. 왼쪽 전경은 주인공 및 대화 연출을 위한 여백으로 남겼다. 인물은 모두 왼쪽을 바라본다.

## 원본과 편집 파일

- `sources/`: 내장 이미지 생성 도구가 반환한 원본 PNG. [생성 지시문과 참조 이미지](prompts.json)를 함께 보관한다.
- `layers/`: 체크무늬 배경을 제거한 실제 RGBA 인물 PNG와 독립 접지 그림자 PNG.
- `psd/alley-native.psd`: 원본 배경 1개 레이어. 건물과 소품 내부는 분리되어 있지 않다.
- `psd/bandit-lead-native.psd`, `psd/bandit-lookout-native.psd`: 투명 인물과 숨겨진 생성 원본을 분리한 2개 레이어. 팔다리·옷은 별도 레이어가 아니다.
- `psd/encounter-editing-master.psd`: 원본 픽셀 크기를 유지한 배경·두 인물 편집 마스터. 인물 레이어는 초기 숨김이다.
- `psd/first-encounter-placement.psd`: 배경·두 인물·두 그림자를 분리한 5개 레이어 배치 시안. 배치용 인물은 축소되어 있으므로 확대 작업에는 native 원본을 사용한다.
- `review/first-encounter.png`: 배치 합성 검수본. dark/warm 파일은 투명 경계 검수본이다.
- [manifest.json](manifest.json): 크기, 알파 영역, 좌표, 원본 해시와 제한 사항.
- [validation.json](validation.json): 29개 검증 결과.

이미지 생성 도구가 실제 알파 대신 체크무늬를 그려 반환하여, 사용자의 ‘로컬 처리로 배경만 제거’ 승인에 따라 로컬 처리했다. 인물 원본의 RGB 값은 유지하고 알파만 변경했다. 외곽과 좁은 내부 틈의 체크무늬 및 테두리 잔여 픽셀을 정리했다. 재현 스크립트는 `tools/prepare-bandit-art-v1.py`이다.

## 해상도와 검수

배경 원본은 1672×941, 인물 캔버스는 각각 1024×1536이다. 알파가 있는 실제 인물 크기는 lead 695×1501, lookout 530×1491이다. 확대용 제작 목표에는 미달하므로 이번 결과는 1차 원화·배치 자산으로 보존한다. 단순 확대를 적용하지 않았다.

PNG 알파와 원본 RGB 보존, PSD 레이어 이름·가시성·채널 및 합성 픽셀을 스크립트로 확인했다. Photoshop 앱에서 직접 열어 검수한 것은 아니다. Unity에서 별도 Sprite 5개를 불러와 실제 런타임 합성 화면을 확인했다.

Unity 반입 위치: `Demo3/Assets/_Project/Resources/Live49/Encounters/Bandit/`.

반입·임시 검수 도구: `Demo3/AgentScripts/ImportBanditArt.cs`. 검수 캔버스는 종료 시 제거하며 새 씬을 추가하지 않는다. 실제 캡처: `Demo3/Screenshots/BanditArt/01-separated-layers.png`.

## 다음 구현 순서

1. 필수 초반 탐색을 방해하지 않는 조우 조건과 장소 연결. 캠핑카 위치를 고정 전제로 두지 않는다.
2. 조우 전 저장, 선택 결과의 자원·상태 반영, 중복 발생 방지 및 결과 저장.
3. 귀환 후 반응과 재진입·불러오기 검수. 대사·음악 추가 범위는 별도로 관리한다.

정신력 미니게임은 이 원화 패키지에 포함하지 않았다. 기존 이야기의 소이 인식 규칙과 화자 이름 공개 규칙을 이후 이벤트 연결에서도 유지한다.

# 챕터 1 · 고정 베이스와 교체 레이어

사용자 피드백에 따라 장면 전체를 상태마다 재생성하는 작업을 중단한다. 배경을 한 번 정리하고 같은 파일 위에 인물·소품·그림·UI를 별도로 합성한다. 기존 전체 장면 시안은 인물 위치와 분위기 참고용이다.

## 이번 제작물

### 추가 완료 · 그림 상태와 첫 대화 연결

[빈 책·그리는 중·완성 그림](pages/README.ko.md)의 3개 RGBA 자산과 대화 초안 9개를 연결했다. 같은 캠핑카 합성 장면을 폴라로이드로 확대하고 아래 대화 UI를 표시한다. 완료 후 현재 미리보기에서 그림이 남는다. 재로드 저장과 날짜·인벤토리 연결은 아직 없다.

### 추가 완료 · 인물 포즈 분리

[수혁·소이 정지 포즈](characters/README.ko.md)를 추가했다. 수혁 앉기, 소이 앉기·그리기 3개 포즈를 각각 몸/식탁 위 팔·손으로 나눠 실제 RGBA 6개로 저장했다. 같은 베이스와 소품 위에서 소이의 자세만 교체하며 식탁 전경으로 몸을 가린다. 736px·360px에서 표시 전환과 배경·소품 유지, 앞뒤 레이어를 검수했다. 페이지 그림 변화는 아직 없으며 확대 선명도는 후속 작업이다.

### 추가 완료 · 기존 원화에서 직접 분리

사용자가 로컬 코드로 기존 원화를 잘라 사용하는 방식을 허용했다. `tools/extract-camper-table.py`가 수동으로 지정한 윤곽에 알파를 적용하며, 소품의 원본 RGB 픽셀은 변경하지 않는다. 이번 분리 작업에는 이미지 생성 도구를 추가로 사용하지 않았다.

[배치 데이터](../../../design/interaction/camper-layers-v1.json)에 공통 좌표와 3개 검수 상태를 기록했다. 베이스만 / 소품 배치 / 스케치북 사건 상태는 같은 파일·위치를 공유한다. 검수 화면은 전체 장면과 식탁 확대를 전환하며, 확대에 UI 글자 크기가 따라 커지지 않는다. 날짜별 사건 시스템 자체는 미구현이다.

검수: 소품 3개의 실제 알파 최솟값 0·최댓값 255와 원본 RGB 보존을 확인했다. 밝은 배경·어두운 배경·실제 식탁 합성으로 윤곽을 확인했다. 736px·360px 브라우저에서 이미지 로드, 소품 0/3개 전환, 사건 하이라이트, 확대, 가로 넘침과 스크립트 오류를 검사했다. `qa/`의 확대 이미지는 검수용이며 게임 자산으로 사용하지 않는다.

원본에서 추출한 크기가 작아 큰 폴라로이드 확대용 고해상도 자산으로 간주하지 않는다. 외곽의 긴 바닥 그림자는 추출하지 않았으며 필요하면 별도 접촉 그림자 레이어로 준비한다.

### 이전 제작물

- [camper-clean-base-v1.png](camper-clean-base-v1.png): 식탁의 책·연필통·컵·종이와 주방의 이동 소품을 제거한 베이스 후보. 기존 인물 없는 캠핑카 원화를 편집했다. 가구·시점·조명은 육안 비교 시 대체로 유지되지만 원본과 픽셀 단위로 동일한 편집은 아니다. 이 후보로 배치 검토를 시작하며 기존 공간 기준 파일은 덮어쓰지 않는다.
- [sketchbook-open-blank-v1.png](sketchbook-open-blank-v1.png): 빈 책 단독 디자인 참고. 투명 PNG를 요청했으나 RGB로 생성되어 체크무늬가 실제 픽셀이다. 바로 합성할 수 있는 스프라이트가 아니다. 제본 표현도 기존 책과 달라 후속 보정 필요. 반복 생성으로 해결됐다고 취급하지 않는다.
- 각 파일 옆 `.prompt.txt`에 최종 입력 프롬프트를 보관했다. 내장 image_gen 사용.

화분·벽 사진·침구·램프 등 상태가 바뀌지 않는 장식은 베이스에 남겼다. 보관함과 가방도 이번 단계에서는 고정이다. 나중에 열림/닫힘이 필요하면 해당 부분만 한 번 분리하고 전체 베이스 변경은 버전으로 관리한다.

## 합성 순서

1. 고정 베이스: 벽·가구·바닥·외부와 변하지 않는 장식.
2. 인물 몸: 벤치에 앉은 수혁·소이 등 위치별 정지 포즈.
3. 전경 가림: 몸을 가려야 하는 식탁의 상판·앞면. 동일 베이스에서 분리한 픽셀을 사용하며 새 식탁을 그리지 않는다.
4. 소품과 접촉 그림자: 책·컵·색연필·요리 도구. 소품과 그림자가 제거될 때 함께 사라진다.
5. 페이지 그림: 같은 빈 책 위에서 미완성/바다 그림만 교체한다.
6. 손·도구: 실제로 책 위에 놓이는 손이 필요한 포즈만 위쪽 부분을 분리한다. 포즈별 가림 관계를 먼저 확인한다.
7. UI: 활성 대상의 이름·하이라이트, 폴라로이드 테두리, 대사, 선택 버튼.

위 순서는 식탁 장면의 초안이다. 주방 등 다른 자리의 가림 관계는 해당 자리에서 따로 정한다. 모든 포즈를 일괄적으로 같은 앞뒤 순서에 넣지 않는다.

## 위치와 상태의 기준

- 장면 기준 좌표는 1672×941, 원점은 왼쪽 위다. 화면 크기 변화에는 베이스와 모든 레이어를 한 묶음으로 확대·축소한다.
- 각 소품은 표시 크기·기준점·위치를 고정하고 상태 이미지만 교체한다. 생성 이미지의 여백이 바뀌었다고 물체 위치가 움직이면 안 된다.
- 책의 제본·페이지 외곽과 색연필 상자의 닫힘/열림 크기를 공통 원본으로 맞춘다. 상태마다 다른 디자인을 생성해 교체하지 않는다.
- 소품의 존재와 클릭 가능 여부는 별도다. 책이 놓여 있어도 오늘의 사건이 없으면 하이라이트가 뜨지 않을 수 있다.
- 폴라로이드 확대는 합성된 같은 장면의 카메라 크롭으로 만든다. 확대용 방 전체를 별도로 생성하지 않는다. 대사·확률·버튼은 사진 아래 별도 UI다.
- 실제 알파 소품 3종과 식탁 전경, 인물 3포즈의 몸/앞쪽 6개 레이어를 준비하고 고정 식탁 자리에서 합성 검수했다. 다른 자리의 포즈는 후속이다.

## 다음 작업 순서

1. 완료: 책·연필통·컵을 기존 원화에서 실제 투명 PNG로 분리하고 공통 좌표에 배치.
2. 완료: 수혁·소이 몸/식탁 위 팔·손 포즈를 분리하고 준비한 식탁 전경과 함께 가림 관계 검수.
3. 인물 표시/소이 자세 교체 시 같은 배경·소품이 유지됨을 검수했다. 소품 제거와 손의 동시 상태 변경은 해당 사건을 연결할 때 확인한다.
4. 빈 페이지/미완성/바다 그림 및 색연필 상자 상태 추가.
5. 같은 방식으로 주방과 편의점 냉장고를 제작한다. 챕터 1 후반의 별똥이·편지 1은 등장 장면에 맞춰 추가한다.

완료 기준은 전체 그림 수량이 아니라 같은 베이스에서 사건별 상태가 어긋남 없이 바뀌는 것이다.

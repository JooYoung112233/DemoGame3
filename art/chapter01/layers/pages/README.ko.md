# 첫 바다 그림 · 페이지 레이어와 대화

기존 원화의 종이 질감과 바다 그림을 잘라 재사용했다. 배경·인물·책 전체를 새로 생성하지 않았다. 확대 선명도는 사용자 요청대로 후속 작업이다.

## 리소스

- [sketchbook-blank-v1.png](sketchbook-blank-v1.png): 기존 책의 표지·외곽·알파를 유지하고 내부 선 그림만 종이 질감으로 정리한 공통 책. 102×73 RGBA.
- [sea-started-overlay-v1.png](sea-started-overlay-v1.png): 첫 바다 선 부분을 표시하는 페이지 내부 레이어. 같은 크기와 원점.
- [sea-complete-overlay-v1.png](sea-complete-overlay-v1.png): 기존 원화에서 가져온 바다·해·두 사람 그림. 같은 크기와 원점.

그림 두 상태는 공통 책 위에 순서 45로 올라가며 소이의 손·연필(50) 아래에 놓인다. 그리는 중 상태는 고정된 부분 이미지이며 실제 필획 애니메이션은 아니다. 페이지는 이전 시제품보다 단순하게 정리했고 세부 접힘·색조 보정은 후속이다.

제작 스크립트: `tools/prepare-sketchbook-pages.py`. 단독 책 시안의 종이 부분만 질감으로 활용했으며 체크무늬 픽셀은 가져오지 않았다. 바다 그림 출처는 `art/chapter01/01-camper-evening/camper-drawing-v2.png`의 페이지 안쪽이다. 같은 책 외곽에 맞춰 잘라 크기를 조정한 상태다.

## 연결된 장면

색연필을 가져온 저녁을 가정한다. [대화 초안](../../../../design/interaction/ch01-first-drawing-v1.json)은 이번 제작에서 쓴 새 대사이며 최초 기획서의 원문 인용이나 확정 대본이 아니다.

스케치북 선택 → 빈 페이지와 두 사람 대화 → 소이 그리기·첫 파란 선 → 바다 그림 완성 → 같이 바다에 가자는 약속 → 그림 남기기 → 캠핑카 복귀.

- 대사 9개를 클릭으로 진행한다. 자동 넘김은 없다. 이전/처음부터를 지원한다.
- 같은 합성 장면을 두 사람/책 중심으로 확대한다. 대사와 버튼은 사진 아래 별도 UI다.
- 모든 대사마다 사진 진입 효과를 재생하지 않고 장면 묶음이 바뀔 때만 짧게 전환한다. 동작 줄이기 설정에서는 효과를 끈다.
- 완료 후 현재 미리보기 안에서는 그림이 남고 '바다 그림'으로 다시 볼 수 있다. 다시 보기로 원래 자산을 변경하거나 보상을 중복 생성하지 않는다.
- 브라우저 재로드 시 초기화된다. 실제 날짜·인벤토리·기억 저장·목적지 시스템에 연결한 것은 아니다. 색연필을 가져오지 않은 분기는 후속이다.

## 검수

[페이지 검수 결과](page-validation.json): 공통 책의 알파와 페이지 마스크 바깥 픽셀 보존 확인. 밝은 종이 영역과 완성 그림 확대를 육안 확인했다.

736px·360px에서 9개 대사와 페이지 상태, 이전/처음부터, 완료 후 그림 유지와 재열기, 고정 배경·책·컵 파일/위치 유지, 스크립트 오류와 가로 넘침을 검사했다. 폴라로이드 인물·소품 컷 모두 동일 캠핑카 합성 장면에서 나온다.

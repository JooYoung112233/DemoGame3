# 챕터 0 · 캠핑카 준비에서 취침까지

추가 검수: [Unity 제외 원화 검수](../../../docs/05-원화/CHAPTER00-ART-REVIEW.ko.md). 손전등 합성의 인물 가림과 PSD 병합 미리보기를 수정했다. 대표 8개 외에 물만/담요만 준비한 검수 상태 2개를 추가했다. PSD의 숨은 레이어를 포함한 RGBA 일치도 확인했으며 Photoshop 앱 검수는 미실시다.

2026-09-10. 기존 회상 묶음에 이어 현재 대화, 물·담요 준비, 소등, 손전등 조사, 연결 고정, 복구, 책·기록 정리, 마지막 소등을 1차 원화 상태로 연결했다. Unity 플레이나 최종 원화 완료가 아닌 제작용 리소스 묶음이다.

## 고정 배경과 조명

밝은 상태는 `../../chapter01/revision-v3/camper-clean-base-v3.png`를 그대로 사용한다. 새 소품은 별도 레이어로 배치하고 원래 가구·차체를 덮어쓰지 않는다. 전원부 위치는 주방 하부장 앞면의 새 소품 배치 제안이다.

생성된 소등 그림은 조명 참고본으로 보관한다. 그 그림의 가구 획을 직접 교체하지 않고, 완만한 색·밝기 비율을 원래 v3 픽셀의 같은 좌표에 적용해 `camper-outage-stable-v1.png`를 만들었다. 복구는 원래 밝은 베이스로 돌아간다. 손전등 조사에서는 같은 배경의 전원부 부근만 마스크로 드러내고 약한 반사광을 더한다. Unity 라이트·셰이더 구현은 아직 아니다.

원래 식탁·수혁/소이 앉기·책·컵의 배치와 가림을 재사용했다. 소이가 물건을 건네거나 수리하는 그림, 강아지, 첫 편지는 챕터 0에 넣지 않았다. 취침은 마지막 소등 상태 뒤 암전으로 연결하는 안이며 새로운 수면 전신 포즈나 빈 침대의 의미를 추가하지 않았다.

## 편집 파일과 검수

- `camper-light-states-v1.psd`: 원래 밝은 배경 / 같은 배치의 소등 배경 / 선택적 손전등 반사광, 실제 3레이어. 기본 표시는 밝은 배경이다. 국소 조사 마스크는 별도 PNG로 제공한다.
- `power-panel-states-v1.psd`: 헐거움 / 고정, 실제 2레이어. 두 상태는 동시에 켜지 않는다. 같은 원본 치수를 유지했다.
- PSD를 Pillow PSD 디코더로 다시 열어 레이어 수·이름·캔버스·병합 이미지 픽셀 일치를 확인했다. PNG 알파도 검사하고 밝고 어두운 배경 위에서 검수했다. Photoshop 앱에서의 직접 호환성 검수는 미실시다.
- RGBA로 생성된 물통·손 컷·손전등은 원래 알파를 유지했다. 체크 배경으로 생성된 그림은 사용자가 허용한 로컬 분리 방식으로 배경과 팔·끈 사이의 틈을 제거했다.
- 점검 인물은 도구를 포함한 한 레이어다. 몸·손·손전등을 모두 독립 편집 가능한 것으로 표시하지 않는다. 열린 저널 역시 책·연필 한 레이어다.
- 신규 소품은 긴 변 약 1277~1502px이며, 인물 실제 높이 1315px와 배경 1672×941은 설정한 최종 목표보다 작다. 기존 앉기·책·컵도 작은 배치 시안이다. 단순 확대본을 원본으로 바꾸지 않았으며 얼굴·가구 확대의 최종 선명도 보강은 남아 있다.

## 연결 확인

`review/camper-state-contact-sheet-v1.jpg`는 위에서 아래로, 각 줄 왼쪽→오른쪽 순서로 8개 상태를 보여준다. `review/preparation-outage-restoration-v1.jpg`는 준비→소등→조사→복구의 핵심 4장이다. 작은 합성 이미지와 잘라낸 근접 검수본을 확대용 원본으로 사용하지 않는다.

정확한 원본·배치·상태 기록은 `../../../design/chapter00/camper-assets-v1.json`, 전체 콘티 연결은 `../../../design/chapter00/RESOURCE-CUES.ko.md`를 따른다.

재생성: 프로젝트 루트에서 Python으로 `tools/prepare-ch00-camper.py` 실행. 원본 생성 API를 다시 호출하지 않고 분리·배치·검수 PNG·PSD·기록만 만든다.

음향, 대사 타이밍, 입력, 실제 물자 획득/저장, 몽타주 재생, 마지막 암전과 날짜 전환은 Unity 제작 단계에 남는다. 원화 작업에서 이름표·버튼·하이라이트·HTML 미리보기 UI는 추가하지 않았다.

# 챕터 1 리소스 제작 진행판

최신 수정: [장면 수정 v3](../art/chapter01/revision-v3/README.ko.md). 조사 자세 반복을 줄이기 위해 교감·서랍 확인·편지 읽기 3포즈를 새로 만들었다. 건물의 앞벽을 제거하고 캠핑카 외부의 반복 디테일을 줄였으며, 실내 고정 배치·소품 레이어는 유지했다.

후속 사용자 검수: 초점·화풍 불일치가 지적된 뒤 주방 보정 방향을 승인받았다. 이를 6개 장면 전체에 확장해 배경 해상도·공통 합성·크기·발 위치·접촉 그림자·가림·장소별 톤과 확대 구도를 조정했다. 세부 작화의 최종 통일은 후속 항목으로 유지한다. [전체 보정 v2와 검수](../art/chapter01/focus-review/README.ko.md).

2026-09-09 · 사용자 요청에 따라 중간 확인을 기다리지 않고 챕터 1의 1차 시각 리소스 묶음을 제작했다. 기존 원화와 고정 베이스·개별 투명 레이어를 유지했다. 미니게임 상세 규칙, 확대 선명도 개선, Unity 프로젝트 구현은 합의대로 보류했다.

완료는 이 장의 **1차 리소스 묶음**이 동일 배경에서 합성·상태 전환 가능하고 파일·배치·미완료 사항이 정리되었음을 뜻한다. 최종 게임·최종 화풍·49일 전체 대본 완료를 뜻하지 않는다.

신규 원화가 꼭 필요한 경우에만 image_gen으로 만들고, 원본 잘라 쓰기와 배경 제거는 사용자가 허용한 로컬 이미지 처리 방식으로 수행한다. 같은 베이스에서 날짜·사건별 활성 대상만 바뀌게 한다. 모든 후보를 동시에 클릭 가능한 상태로 만들지 않는다.

## 검수한 것

- 스프라이트의 실제 RGBA와 투명/불투명 픽셀, 파일 경로와 캔버스 안 배치를 검사했다. 상세 결과는 `design/chapter01/asset-catalog.json`.
- 같은 장면의 상태를 바꿔도 베이스 파일이 바뀌지 않는지 확인했다.
- 736px/360px에서 33개 상태의 이미지 로드, 레이어 표시, 이름 하이라이트, 확대, 대사, 편지 페이지를 검사했다. 가로 넘침과 스크립트 오류 없음.
- 편지 1의 사용자 원문 8개 문단이 읽기 화면의 4페이지에 순서대로 유지되는지 비교했다.
- 실제 렌더링을 보고 주방 식탁의 인물 가림/수프 순서, 편의점 소품 색상, 이름표 겹침, 사진 바깥이 드러나는 확대를 수정했다.
- 검수 화면과 기록은 `art/chapter01/gallery-qa`, 재생성 방법은 `art/chapter01/README.ko.md`.

# 탐색 미니게임 v2 · Unity 연결

2026-09-13. [승인된 v2 시안](../02-게임시스템/SEARCH-MINIGAME-V2.ko.md)의 간헐적 원형 판정을 실제 현장 탐색에 연결했다. 별도 테스트 씬은 만들지 않았다. 기존 장소 그림 위 공유 HUD 안에서 실행한다. 새 원화·대사·음악은 제작하지 않았다.

## 실제 플레이

- 편의점 냉장고·식품 선반, 다른 장소의 두 확인 지점에서 빠른 탐색과 집중 탐색을 선택한다.
- 빠른 탐색: 게임 시간 5분. 기본 물자·길 확인과 추가 물자 추첨을 한 번 처리한다.
- 집중 탐색: 시작 10분. 약 14초 동안 3회 판정이 불규칙한 시각에 등장한다. 각 판정은 0.8초 시각 예고 후 시작하며 기본 1.25초, 여유 속도 1.9초다. 판정 밖에서는 원과 판정 버튼을 감춘다.
- 원의 초록 구간에서 클릭 또는 스페이스로 판정한다. 금색은 추가 물자 확률 +10%p, 최대 +20%p. 실패·시간 초과는 소음 반응 위험 +25%p, 최대 95%다. 일반 성공은 위험을 더하지 않는다.
- 두 번째 판정 후 기본 물자와 길 확인을 확정한다. 여기서 끝내면 확보한 것만 유지한다. 계속하면 5분을 한 번 더 쓰고 세 번째 판정 뒤 추가 물자를 추첨한다.
- 소음 반응이 있으면 머무르기 또는 캠핑카 귀환을 선택한다. 머무르면 이후 기본 소음 위험 +10%p, 기본 위험 상한 65%. 귀환은 실제 주차 위치로 걸어 돌아가며 캠핑카 위치·연료를 이동시키지 않는다. 소음 반응을 강제 전투나 밴딧 발생으로 연결하지 않았다.

## 본편 진행을 보호한 차이

브라우저 시안의 확률표를 필수 서사 물자에 그대로 적용하지 않았다. **첫 생수 2개·포장 식량 2개, 주유소의 기존 연료 2, 길 확인은 판정 성공 여부와 무관하게 확보한다.** 색연필·공구 가방·첫 사진은 기존 이야기 행동으로 유지한다. 따라서 타이밍 실패로 첫 식사·그림·다음 지역이 봉쇄되지 않는다.

추가 물자는 임시 조정값으로 첫 항목 45%, 두 번째 30%에 대성공 보너스를 더한다. 냉장고는 추가 생수·간편식, 식품 선반은 추가 포장 식량·식재료, 수리점은 수리 부품·천, 나머지는 천·식재료다. 장소별 세부 드롭과 반복 탐색의 경제 효과는 후속 플레이에서 조정한다. 이 임시 표를 최종 확정 밸런스로 취급하지 않는다.

## 일시정지·저장·중단

- ESC는 탐색 시간을 멈추고 기존 메뉴를 연다. 설정과 저장·불러오기를 사용할 수 있다. 재개하면 같은 시점에서 조작을 이어간다. 앱이 비활성화되어도 판정 시계는 진행하지 않는다.
- 시작, 각 판정, 중간 확보, 추가 탐색 선택, 최종 결과, 소음 선택 후 자동 저장한다. 빈번한 판정 저장은 알림을 생략한다.
- **불러오기는 재개와 다르다.** 진행 중이던 탐색은 종료하고 이미 확보한 물자와 사용한 시간만 유지한다. 판정 전 저장을 반복해서 불러와 추가 물자를 재추첨하지 않는다.
- 중간 확보 전 그만두거나 불러오면 물자는 지급하지 않는다. 그 지점의 집중 탐색은 다시 제공하지 않지만 빠른 탐색으로 필수 물자·길을 확인할 수 있다. 중간 확보 후에는 확보한 물자와 확인 지점이 유지된다.
- 저장 실패 시 탐색을 정지하고 ‘저장 다시 시도’를 표시한다. 재시도는 현재 상태만 저장하며 비용·물자를 다시 적용하지 않는다.
- 기존 저장에 새 `search` 정보가 없어도 읽을 수 있다. 탐색 중의 저장 슬롯에는 해당 지점과 물자 유지 설명을 표시한다. 튜토리얼에도 진행 중 탐색 안내를 연결했다.

## 코드와 검수

- `Core/SearchSession.cs`: 단계, 사전 추첨값, 필수 물자·길 확인, 추가 보상, 중단·소음 처리.
- `UI/SearchPanel.cs`: 기존 장면 위 선택·예고·원형 판정·중간 확보·결과·소음 화면. `SearchDial`은 코드로 그린 벡터 UI다.
- `C0Journey`와 `C0RegionExploration`: 실제 현장 버튼 및 불러오기 연결. HUD의 다른 행동과 지도 이동은 탐색을 마친 뒤 사용한다.
- `AgentScripts/VerifySearchRuntime.cs`: 모델 및 Unity 실시간 검수. 첫 물자·시간·보너스·소음·중복 지급·중단 복구·저장 유효성·주유소 연료·지도 해금 확인.
- 실시간 검수: 편의점 버튼 → 판정 → 중간 확보 → 실제 저장 재로드, 빠른 식량 탐색, 소음 후 다른 위치에 주차한 캠핑카 귀환, 잡화점의 여유 속도 3회 판정 전체 완료, 저장 실패와 재시도 확인.
- 화면 검수에서 원형 판정의 렌더러 누락을 발견해 수정했고, 단계 갱신 시 삭제된 이전 버튼을 참조하던 문제도 수정한 뒤 재검수를 통과했다.
- 1920×1080 텍스트 넘침 검사와 화면 확인. 결과는 `Demo3/Screenshots/SearchRuntime/verification.txt`, 캡처는 같은 폴더에 있다. CLI 검수는 실제 패널의 `Tick`을 호출해 시간을 진행시켰으며 사람의 손으로 느끼는 난도를 검증한 것은 아니다.
- 실제 자동저장 파일은 변경하지 않도록 별도 테스트 슬롯을 사용하고 원본 바이트가 유지되는지 검사했다.

# 첫 지역 · 10곳 탐색과 분기 해금

2026-09-12 사용자 요청: 현재 지역에 탐색 장소 약 10개를 넣고, 한 곳을 탐색하면 다음 두 곳이 열리는 방식으로 진행한다.

**후속 구현 적용:** [이동 거점과 탐색 UI](JOURNEY-POLISH-2026-09-12.ko.md). 아래 고정 주차·공통 탐색 버튼 설명과 ‘미구현’ 제안 목록은 초기 기록이다. 현재는 차량 재주차, 장소별 두 확인 지점, 발견·도착 연출, 날짜별 요약과 지역 전환 기반을 적용했다. 다음 지역의 실제 출발은 기존 그림·사진·길 정보 사건 연결이 남아 있다.

## 최신 제작 방향 · 캠핑카 위치

후속 사용자 지시: 캠핑카 위치는 이동에 따라 계속 변경되어야 한다. 편의점 앞을 영구 거점으로 두지 않는다. 아래의 편의점 고정 주차 설명은 현재 임시 구현 상태이며, 최종 제작 방향이 아니다.

후속 구현에서는 차량의 주차 위치와 인물의 탐색 위치를 각각 보관하고, 차량 이동 시 지도 핀·HUD의 주차 장소·귀환 목적지·저장 데이터를 함께 갱신한다. 도보 탐색만으로 차량이 옮겨진 것으로 처리하지 않는다. 차량 이동과 도보 탐색을 선택하는 구체적인 흐름은 구현 시 정리한다.

## 다음 다듬기 제안 · 미구현

1. 캠핑카 이동과 귀환 위치부터 일반화한다. 지도에서 차량과 인물 위치를 구분하고 편의점으로 고정된 문구와 조건을 제거한다.
2. 장소별 탐색 행동을 차별화한다. 현재의 공통 완료 버튼을 선반·정비대·게시물 등 장소에 맞는 확인 지점과 짧은 발견 내용으로 발전시킨다.
3. 새 장소 해금 시 해당 핀으로 시선을 유도하고, 처음 확인할 때까지 새 발견 표시를 유지한다. 모든 장소를 미리 노출하지 않는다.
4. 이동 전 소요 시간과 자원 비용, 이동 후 도착 장소가 명확하게 이어지도록 전환 연출과 안내를 다듬는다.
5. 하루 마무리에 오늘 탐색한 곳·발견한 길·확보한 물품을 요약한다.
6. 여러 지역을 위한 지역 선택과 출입구 연결을 만든다. 지역별 탐색 진행과 캠핑카 위치를 저장하고 기존 저장 호환을 검증한다.

## 해금 구조

| 탐색 완료 조건 | 새로 열리는 곳 |
| --- | --- |
| 편의점에서 물·식량 모두 확인 | 주유소, 잡화점 |
| 주유소 | 수리점, 공영주차장 |
| 잡화점 | 낡은 집, 세탁소 |
| 수리점 또는 낡은 집 | 강변 쉼터, 약국 |
| 강변 쉼터와 약국 모두 | 고갯길 |

편의점을 포함해 총 10곳이다. 수리점과 낡은 집은 같은 두 장소로 합류하므로 중복 해금하지 않는다. 주차장·세탁소는 선택 탐색이며, 고갯길을 열기 위해 10곳을 모두 완료할 필요는 없다.

## 실제 진행

- 처음에는 편의점만 지도에 표시한다. 기존 저장에서 물·식량 확인이 끝났다면 주유소·잡화점이 바로 표시된다.
- 도착과 탐색 완료를 구분한다. 편의점은 기존 물·식량 행동을 사용하고, 나머지는 ‘주변 살펴보기’ 확인으로 완료한다. 취소하면 진행하지 않는다. 재방문에서는 탐색 기록을 다시 볼 수 있다.
- 처음 편의점까지 캠핑카 이동은 연료 1·20분이다. 이후 지역 내 이동과 귀환은 도보 10분, 탐색은 10분으로 둔 초기 조정값이다. 캠핑카는 편의점 앞에 남는다.
- 외부에서는 요리·하루 마무리 전에 캠핑카 귀환을 안내한다. 지도·가방·기록은 계속 사용할 수 있다.
- 미발견 장소는 핀을 숨기고, 완료한 장소에는 완료 표기를 붙인다. 지도와 기록장에 완료 수를 표시한다. 이동선은 주요 도로 그래프를 따라 그린다.
- 탐색 완료 시 자동 저장한다. 기존 수동 저장·불러오기에도 탐색 위치와 완료 상태가 포함된다.

## 데이터와 그림

`RegionExploration`이 장소와 선행 조건을 정의하고 `FirstRegionMap`이 지도에 표시할 정보로 변환한다. `JourneyState.regionId`와 `exploringPlace`를 차량의 `location`과 분리했다. 완료 키는 `region01.explored.<장소 ID>`이며, 편의점은 기존 물·식량 플래그를 사용한다. 예전 저장의 누락 필드는 허용하고, 잠긴 장소나 알 수 없는 탐색 위치는 저장 검증에서 거부한다.

편의점과 기존 지역 6곳은 보관 중인 배경 원화를 사용한다. 주차장·세탁소·약국은 부드럽게 뭉갠 도시 지도 확대와 위치 테두리로 보여준다. 세 곳의 실내 원화를 새로 제작한 것은 아니다.

이번 연결은 주변 확인·길 발견·기록까지다. 신규 전리품 경제, NPC 대화, 수리·제작 기능은 추가하지 않았다. 고갯길은 현재 지역에서 발견하는 장소이며, 다른 지역으로의 전환은 아직 연결하지 않았다. 게임 씬은 기존 두 개를 유지한다.

## 검증

`VerifyRegionExploration`에서 초기 1곳, 두 갈래 해금, 다른 경로 합류, 최종 AND 조건, 중복 완료 방지와 JSON 저장을 확인했다. 실제 플레이에서 10곳을 방문·탐색하고 취소·귀환·자동 저장·재로드·연료 유지·텍스트 넘침·씬 수를 확인했다. 이름표와 위치 표시 조정 후 `ReviewRegionLayout`으로 전체 지도·주차장·주유소 화면을 다시 검수했다.

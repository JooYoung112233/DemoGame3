# 밴딧 첫 조우 · 실제 진행 연결

기존 밴딧 v2의 배경·두 인물·접지 그림자를 Unity에서 별도로 배치하고, 조우 → 선택 → 결과 → 캠핑카 귀환 확인을 연결했다. Title/Game 기존 씬을 사용한다. 새 대화 대본이나 음원은 추가하지 않았고 사건 설명과 선택 UI 문구만 넣었다.

## 발생 조건과 진행

- 첫 동네에서 편의점의 물·식량 확보와 첫 그림을 완료하고, 발견한 공영주차장 `L8`을 **도보로 탐색**할 때 한 번 발생한다. 주차된 캠핑카 안에서는 발생하지 않는다. 주차장에서 내리거나 다른 장소에서 걸어 도착해도 같은 조건을 사용한다.
- 장소 발견은 기존 지도 해금 규칙을 따른다. 색연필·공구 가방·카메라를 얻는 필수 장소에서는 발생하지 않는다. 첫 주에 준비하지 못한 기존 저장도 이후 조건을 충족하면 경험할 수 있도록 특정 날짜로 만료시키지 않았다.
- 선택하는 동안 지도·생활 행동·하루 마치기는 막고, ESC 메뉴의 설정과 저장·불러오기는 유지한다. 외부 모델 호출로 이동·다른 사건·물자 확보를 실행해도 사건을 건너뛰지 못하도록 핵심 진입점에서도 확인한다.

| 선택 | 비용 | 결과 |
| --- | --- | --- |
| 포장 식량 건네기 | 포장 식량 1, 5분 | 골목을 지나 주차장 탐색 계속 |
| 생수 건네기 | 생수 1, 5분 | 거리를 유지하며 통과 |
| 돌아가는 길로 우회 | 20분, 물자 없음 | 우회해 주차장 탐색 계속 |

비용은 이번 구현의 조정 가능한 값이다. 물자·연료가 없어도 우회를 선택할 수 있다. 캠핑카 주차 위치와 연료, 색연필·가방·카메라 같은 이야기 소지품은 조우 결과로 바꾸지 않는다. 같은 장소를 다시 방문해도 반복 발생하지 않는다.

결과 확인 후 캠핑카로 돌아오면 주변과 소지품을 확인하는 화면이 한 번 표시된다. 실제 주차 위치 이름을 사용하며, 다른 날에 돌아와도 이어진다. 사건 결과와 귀환 확인을 활동 기록에 남겨 기존 ‘오늘 남길 한 장’의 선택지로 사용할 수 있다. 정신력 수치·미니게임·강제 전투는 추가하지 않았다.

## 저장과 복구

`JourneyState.bandit`에 `started`, `stage`, 시작 날짜, 장소, 결과를 보관한다. 단계는 선택(0), 결과(1), 귀환 대기(2), 귀환 확인(3), 완료(4)다. 이 데이터가 없거나 시작하지 않은 이전 저장도 유효하다. Unity JsonUtility가 null을 빈 객체로 직렬화하는 경우를 고려해 명시적 시작 여부로 구별한다.

- 선택 화면 진입, 결과 확정, 결과 확인 완료, 귀환 화면 진입·완료 때 자동 저장한다.
- 물자·시간·결과 단계를 함께 반영하므로 같은 버튼을 두 번 눌러도 중복 차감하지 않는다.
- 선택·결과·귀환 확인 단계의 저장을 불러오면 해당 화면을 복원한다. 저장 슬롯에도 진행 단계와 조우 배경을 표시한다.
- 저장 실패 시 현재 화면에 재시도를 제공한다. 결과를 재계산하지 않고 저장만 재시도한다. 설정의 수동 슬롯도 사용할 수 있다.
- 잘못된 결과·장소·날짜·단계 및 다른 사건/요리와 동시에 진행되는 저장은 거부한다.

## 코드와 검수

- 규칙: `Demo3/Assets/_Project/Scripts/Core/BanditEncounter.cs`
- 장면·선택 화면: `Demo3/Assets/_Project/Scripts/Chapter00/C0BanditEncounter.cs`
- 검수: `Demo3/AgentScripts/VerifyBanditEncounter.cs`
- 검수 기록·화면: `Demo3/Screenshots/BanditEncounter/`

검수는 별도 저장 경로를 사용한다. 발생 선행 조건, 세 가지 주차 위치 × 세 가지 선택의 정확한 비용, 원래 이야기 소지품 보존, 재진입, 무자원 우회, 잘못된 저장 거부를 모델 검사로 확인했다. 실제 Unity에서 지도 도보 이동에 따른 발생, ESC 설정과 수동 저장, 선택·결과·귀환 재로드, 중복 클릭, 저장 실패·재시도, 저녁 기록 연결 및 텍스트 넘침을 확인했다. 실제 플레이어 자동저장 파일은 바이트 단위로 변경되지 않았는지 검사한다.

전체 챕터 최종 QA나 확정 난이도 조정을 끝냈다는 의미는 아니다. 기존 첫 주의 그림·세진·가방·카메라·사진 모델 검사도 회귀 확인한다. 최신 실행 결과는 위 검수 기록을 따른다.

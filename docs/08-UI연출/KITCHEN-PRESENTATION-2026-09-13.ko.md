# 요리 화면 · 냄비와 화력 다이얼

2026-09-13. 탐색 v2 연결 다음 순서로 기존 요리 화면을 개선했다. 버튼 세 개와 냄비 아이콘 중심의 화면을 기존 투명 냄비 원화, 가스레인지 면, 드래그 다이얼, 불꽃·기포·김으로 바꿨다. 별도 씬과 새 대사·음악은 추가하지 않았다.

## 조작과 표시

- 캠핑카의 주방에서 조리를 시작한다. 복구되지 않은 요리대와 재료 부족 차단은 유지한다.
- 다이얼을 클릭하거나 끌어 약불·중불·강불을 선택한다. 키보드 1·2·3도 유지한다. 기존 레시피와 맞는 세 단계이며 연속 화력 수치를 새로 도입하지 않았다.
- 화력을 바꾸면 불꽃 크기는 바로 반응하고 냄비 열기는 기존 모델에 따라 서서히 변한다. 기포와 김은 냄비 열기에 반응한다.
- 숫자 열기 대신 미지근함·잔잔한 기포·끓음·거센 끓음과 단계별 조절 안내를 표시한다. 작은 열기 막대는 적정 구간과 같은 위치에 ‘잔잔함’을 표시한다.
- 잠시 멈춤과 창 닫기 후에는 다이얼·조리 시간이 멈춘다. 다시 열거나 불러오면 ‘이어서 조리’를 선택해야 한다. 앱 포커스를 잃을 때도 조리를 멈추고 저장한다.
- 완료하면 불을 끄고 식사 1개가 가방에 들어갔다고 표시한다. 잘 만든 식사와 일반 완성의 기존 판정은 유지한다.

## 진행과 저장

가스 1·식재료 1·게임 시간 25분을 시작할 때 한 번 적용한다. 공용 차량 연료는 소모하지 않는다. 불을 바꾸거나 저장을 다시 시도할 때 추가 비용이 없다. 기본 식사는 조작 성공과 무관하게 1개를 지급한다. 부족한 익힘은 남은 조리를 마무리한 것으로 설명한다.

기존 조리 저장 구조를 사용한다. 시작·화력 변경·일시정지·주기 저장·완료에 자동 저장한다. 저장 실패 시 조리를 멈추고 재시도 버튼을 표시한다. 저장 재시도 성공은 조리 자동 재개와 분리한다. 닫기 저장에 실패해도 창을 닫지 않고 재시도할 수 있게 한다.

## 자산과 구현

- 기존 `art/chapter01/kitchen/soup-pot-v1.png`는 714×523의 투명 PNG다. 같은 파일을 Unity Sprite로 복사했으며 그림·해상도·원본을 수정하지 않았다. 화면에서 660×483으로 표시한다.
- Unity 리소스: `Assets/_Project/Resources/Live49/Kitchen/soup-pot.png`.
- `UI/ActivityKitchen.cs`: 요리 화면 배치·상태 안내·저장 실패 처리.
- `UI/KitchenVisual.cs`: 세 단계 포인터 다이얼, 가스레인지 면, 불꽃·기포·김을 그리는 코드 기반 UI.
- `UI/ActivityPanel.cs`: 기존 공용 창과 조리 갱신 연결. 생활 탭의 전자레인지는 기존 가열 방식으로 유지한다.
- `AgentScripts/ImportKitchenPot.cs`: 원본을 변경하지 않는 Sprite 반입·크기 확인.

이 변경은 요리 조작 표현의 1차 개선이다. 가스레인지 세부 질감과 자연스러운 끓음 효과, 실제 점화·끓음 음원, 더 큰 확대용 원화는 후속 완성도 작업이다. 코드로 그린 불꽃을 새 원화 납품으로 집계하지 않는다.

## 검수

`AgentScripts/VerifyKitchenPresentation.cs`로 별도 저장 슬롯을 사용해 Unity 실시간 검수를 수행했다.

- 수리 전 시작 차단, 원본 Sprite 크기와 1920×1080 텍스트 넘침 검사.
- 실제 EventSystem 포인터 누르기·드래그로 세 화력 선택.
- 일시정지 중 입력·열기 변화 차단, 불 변경 후 열기가 즉시 점프하지 않는지 확인.
- 창 닫기 → 실제 저장 읽기 → 장면 재로드 → 명시적 재개.
- 실제 게임 프레임으로 조리 완료까지 진행, 재료·25분 1회 차감, 식사 1개만 지급, 차량 연료 유지, 완료 시 불 꺼짐.
- 저장 실패 시 멈춤 및 재시도 후 재료 중복 차감·자동 재개 없음.
- 기존 실제 자동저장 파일 바이트가 유지되는지 확인하고 원래 세션을 복원했다.

결과와 화면은 `Demo3/Screenshots/KitchenPresentation/`에 있다. 사람이 느끼는 조작 난도·반복 피로와 모든 화면 비율을 검증한 것은 아니다.

# 이동 거점과 탐색 UI 후속 작업

사용자 지시: 캠핑카 위치는 이동할 때마다 바뀐다. 캠핑카 이동·장소별 탐색·새 발견 표시·이동 연출·하루 요약·지역 연결을 순서대로 진행한다.

## 적용한 동작

1. **이동하는 캠핑카:** 캠핑카 안에서 지도를 열면 차량으로 이동하고 새 목적지에 주차한다. 내려서 탐색 중이면 도보 이동한다. 차량 주차 핀과 인물 위치 핀을 구분했다. 귀환 문구·도착 장소·HUD·저장 상태는 실제 주차 위치를 따른다. 차량이 주유소에 있어도 편의점을 걸어서 방문하고 주유소로 돌아올 수 있다. 같은 장소에서 내리기·차에 타기는 이동 시간을 차감하지 않는다.
2. **장소별 확인 지점:** 편의점의 물·식량 행동은 유지한다. 나머지 첫 지역 9곳에 각각 다른 두 확인 지점을 넣었다. 한 지점당 5분이며 중간 상태를 자동 저장한다. 두 지점을 모두 확인해야 탐색 완료와 분기 해금이 일어난다. 반복 확인은 시간이나 보상을 다시 지급하지 않는다. 주유소 정비 구역의 차량 연료 +2는 한 번만 지급하는 조정용 보상이다.
3. **새 발견:** 지도에서 아직 선택하지 않은 미탐색 장소에는 ‘새 발견’을 붙인다. 지도 진입 시 순서대로 부드럽게 나타나며, 선택하면 확인 상태를 저장한다. 미발견 장소는 계속 숨긴다.
4. **출발·도착:** 지도 카드에 차량/도보 방식·시간·연료와 주차 위치 변화를 안내한다. 확인 후 암전 → 도착 장소명 → 현장 화면으로 전환한다. 이동 완료 후 자동 저장한다.
5. **하루 요약:** 방문 장소·새로 열린 장소·챙긴 물품 및 연료를 날짜별로 기록한다. 하루 마무리와 기록장에서 당일 내용을 보여준다. 다음 날에는 새 기록을 시작하되 이전 기록 데이터와 주차 위치는 유지한다. 예전 저장에 날짜별 로그가 없으면 과거 행동을 임의로 당일 실적으로 채우지 않는다.
6. **지역 전환 기반:** 지도 상단의 지역 선택에서 첫 동네와 고개 너머 진입 구간을 선택한다. 현재 지역 선택은 지도로 돌아오고 다른 지역은 출발 조건을 안내한다. 캠핑카로 지역을 건너며 소지품·날짜·양쪽 탐색 기록을 유지한다. 다른 지역의 핀을 로컬 이동으로 선택해 순간 이동할 수 없다.

## 지역 출발의 남은 연결

**2026-09-13 후속 적용:** 아래의 미연결 상태는 당시 기록이다. 현재는 [첫 주차 이야기 연결](FIRST-WEEK-RUNTIME-2026-09-13.ko.md)에서 첫 그림·세진의 길 정보·첫 사진과 앨범 확인을 실제 플레이에 연결했다.

기존 사용자 제작 기준은 **첫 그림, 첫 사진·앨범 확인, 세진의 길 정보 이후 지역 출발**이다. [제작 방향](../02-게임시스템/GAMEPLAY-DIRECTION-2026-09-09.ko.md)과 [E25 출발 조건](../03-콘티/챕터1/CHAPTER01-EVENT-QUEST-DRAFT.ko.md)을 유지했다.

`RegionTravel.Drawing`, `Photo`, `Route`는 해당 사건이 완료됐을 때 받을 상태 키다. 현재 플레이에는 그 사건들의 완료 동작이 아직 연결되지 않았으므로 일반 진행의 다음 지역 출발은 잠겨 있다. 탐색 버튼으로 이야기 완료를 대신하지 않는다. 다음 작업은 첫 그림·사진·길 정보 사건의 실제 완료와 이 키를 연결하는 것이다.

다음 지역은 **진입로 1곳과 왕복·저장 연결만 있는 초안**이다. 이름은 ‘고개 너머’라는 임시 구간명이며, 별도 도시 지도나 챕터 2 사건을 확정·제작한 것이 아니다. 지도는 코드로 그린 간단한 진입 도로이고 현장에는 기존 고갯길 배경을 재사용한다. 첫 지역의 부드러운 도시 원화와 10개 장소는 유지한다.

차량 이동 20분·연료 1, 도보 10분, 지역 이동 40분·연료 1은 현재 조정값이다. 거리 측량이나 최종 연료 경제는 아니다. 새 대화 원화·NPC 대사·그림/사진 튜토리얼·새 씬은 이 작업에 포함하지 않는다.

## 저장과 검증

`JourneyState.location`은 차량, `inStore`/`exploringPlace`는 인물, `regionId`는 현재 지역이다. 장소 ID는 두 지역에서 겹치지 않는다. 완료/부분 확인 키는 지역별로 구분하고, 지역 이동 시 이전 지역의 주차 위치도 기록한다. 날짜별 방문·발견·획득 로그는 `days`에 보관한다. 기존 버전 1 저장을 읽을 수 있고, 잘못된 지역·주차 위치 조합은 거부한다.

검수 스크립트는 `Demo3/AgentScripts/VerifyCamperTravel.cs`, `VerifyJourneyPolish.cs`, `VerifyRegionTravel.cs`다. 실제 HUD 버튼을 통해 차량 재주차, 다른 장소 도보 방문, 귀환, 중간 탐색 저장·불러오기, 중복 보상 방지, 해금, 도착 안내, 하루 취소·진행, 지역별 왕복과 기록 보존을 확인한다. 넓은 범위의 하루 요약과 텍스트 넘침도 검사한다.

검수는 별도 슬롯과 이야기 완료를 설정한 **검수용 진행**을 사용한다. 실제 저장 파일을 덮어쓰지 않고, 종료 시 기존 진행을 복원한다. `Demo3/Screenshots/JourneyPolish/progress.txt` 및 번호별 PNG에 결과를 보관한다. `12-restored-current-map.png`는 기존 진행의 복원 화면이다.

위 세 검수의 모델·실제 플레이 검사와 컴파일이 통과했다. 기록장에는 이전/다음 기록 버튼을 두어 날짜별 기록과 첫 기록을 다시 볼 수 있다. 이전 단계의 `VerifyRegionExploration` 등 공통 완료 버튼을 대상으로 한 검수 스크립트는 당시 구현의 기록이며, 현재 탐색 검수는 `VerifyJourneyPolish`를 사용한다.

# 공통 HUD · Unity 시안

**지도 최신 수정:** 사용자 요청으로 종이 개략도를 도로·건물이 보이는 도시 지도로 교체하고 드래그·확대·현재 위치 복귀를 연결했다. 이후 지도 바탕의 잔묘사를 뭉개는 화풍 수정은 [도시 지도 적용](UNITY-CITY-MAP.ko.md)을 따른다.

**최신 진행:** 사용자가 단계마다 멈추지 말고 남은 작업을 계속하도록 요청했다. 후속 요리·첫 지도 이동·취침·기록·저장/불러오기 연결은 [Unity 생활 UI와 진행 연결](UNITY-LIFE-LOOP.ko.md)을 따른다. 아래 1·2단계의 ‘미연결’ 표기는 당시 구현 범위 기록이며 최신 상태는 위 문서와 검수 보고서를 우선한다.

2026-09-12 사용자 요청: 캠핑카의 지도·요리 등 생활 기능으로 연결되는 예쁜 HUD를 제시하고, 전체 게임에서 Esc로 재개·설정·종료를 사용할 수 있게 한다.

## 1단계 · 실제 캠핑카 탐색 연결

사용자는 6개 후속 단계를 한 번에 진행하지 않고, 1단계씩 완성 화면을 확인하기로 선택했다. 이번 범위는 대화에서 탐색으로 전환하고 캠핑카 상호작용을 연결하는 단계다.

- 마지막 ‘내일도 여기 있어?’를 읽고 진행하면 대화창·컷인이 퇴장하고 배경 블러가 풀린 뒤 HUD가 열린다.
- 소이·주방·침대·스케치북 위에 작은 마름모 표시를 둔다. 대상에 마우스를 올렸을 때만 이름을 표시한다. 클릭 영역은 연출 캔버스의 입력 차단 영향을 받지 않도록 공통 HUD에 배치한다.
- 소이는 기존 콘티의 두 답변 선택지로 이어지고, 대화를 끝내면 스케치북 살펴보기로 목표가 바뀐다. 책 대화도 기존 콘티 문구를 따른다. 취소는 진행 상태를 바꾸지 않는다.
- 주방은 현재 이용 조건 안내, 침대는 하루 마치기 조건 확인으로 연결한다. 지도는 기존 패널을 연다. 실제 요리·이동·날짜 변경은 후속 단계다.
- 대화 중에는 탐색 입력을 숨기고, 창이 열린 동안에는 시간과 대사 진행을 멈춘다. Esc·돌아가기·선택 확정 뒤 시간과 입력을 복원한다.

이번 연결은 스케치북 관찰까지이며, 다음 `camp_radio`와 출발 준비를 건너뛰지 않는다. 대화 상태는 메모리에만 유지하며 저장·불러오기는 후속 작업이다. 새 씬이나 원화를 추가하지 않았다.

검수: `AuditOpeningPacing`, `VerifyCamperExploration`, `VerifyCamperAlternateReply`. 실제 타이틀에서 게임으로 진입해 정상 대사 속도, HUD 전환, 클릭 영역과 마름모 표시, 양쪽 답변 분기, 책 대화, 선택 취소·중복 실행 방지, 실제 Esc 입력과 정지 복원을 확인한다. 화면과 결과는 `Demo3/Screenshots/CamperExploration/`에 기록한다.

## 디자인 제안

### 2단계 · 가방과 인물 상태

2026-09-12 사용자 ‘이어서 하자’에 따라 다음 단계인 가방·인물 상태 UI를 실제 캠핑카 HUD의 가방 버튼에 연결했다. `BagPanel`은 같은 공통 캔버스 안에서 열리며 새 씬을 만들지 않는다.

- 왼쪽: 전체 / 식량·물 / 생활용품 / 소중한 물건 분류. 한 페이지에 6종을 표시하고 이전·다음으로 이동한다. 물건 선택 시 설명과 보유 수량을 보여준다. 수량이 0인 항목은 숨기며 데이터 갱신 후 유효하지 않은 선택은 해제한다.
- 오른쪽: 수혁·소이 각각 허기·수분·체력·스태미너. 각 인물·항목의 현재값과 최대값을 따로 받는다. 미확인 값은 점선과 `—`로 표시하여 0이나 가득 찬 상태와 구분한다. 이름은 기존 이름 공개 처리에서 제공한다.
- 창을 열면 생활 HUD와 상호작용을 접고 게임 시간·오디오를 정지한다. 닫기·Esc로 캠핑카에 복귀하며 원래 배율과 오디오 정지 상태를 복원한다. 키보드 방향키와 UI 제출, 마우스 선택을 지원한다.
- `GameHud.ConfigureBag(BagContents)`로 표시 데이터를 공급한다. 초기 물자 수량·생존 수치가 미정이므로 현재 챕터 0은 ‘소지품 확인 전’과 미확인 게이지로 시작한다. 배경에 놓인 소품을 가방에 지급한 것으로 처리하지 않는다.

이번 단계는 열람 UI와 데이터 표시 연결이다. 물품 획득·사용·전달·소비 및 회복 효과, 자동 생존 수치 소모와 저장은 아직 연결하지 않았다. 정신력·행복도·추가 피로 게이지를 임의로 추가하지 않았다. 다음 UI 단계는 요리다.

검수: `AgentScripts/OpenBagForReview.cs`, `AgentScripts/VerifyBagPanel.cs`. 실제 타이틀→캠핑카→가방 진입, 분류·2페이지 이동, 수량 0 갱신, 비어 있는 가방, 미공개 이름, 개별 최대치, 실제 InputSystem Esc, UI 제출 닫기, 0.75 시간 배율과 오디오 상태 복원, 클릭 영역, 텍스트 넘침 없음, 기존 씬 수 유지, 실행 오류 0개를 확인했다. `Screenshots/BagReview/01-opening-bag.png`는 실제 도입부 상태이고 `02-fixture-items.png`는 임시 검수 수량·게이지를 공급한 화면이다. 해당 수치는 시작 자원이나 생존 밸런스로 채택한 값이 아니며 검수 뒤 제거했다.

기존 갈색·크림색 대화 UI와 같은 글꼴을 사용한다. 짙은 반투명 바탕, 황동색 가는 선, 독립 아이콘으로 원화를 가리는 면적을 줄인다. 모든 문구와 아이콘은 Unity UI이며 원화 PNG는 수정하지 않았다.

- 왼쪽 위: 현재 장소와 시간대. 날짜·재고 등 실제 데이터가 없는 수치는 표시하지 않는다.
- 왼쪽 아래: 현재 목표 하나. 목표가 없으면 영역을 숨긴다.
- 오른쪽 아래: 지도·요리·가방·기록. 호버·키보드 선택은 얇은 선으로 표시한다.
- 생활 버튼 바로 위: 달 아이콘의 **하루 마치기**. 확인창에서 오늘의 마무리 내용을 읽고 더 둘러보기/하루 마치기를 고른다. 남은 필수 일이 있으면 이유를 보여주고 확정 버튼을 비활성화한다. Esc는 캠핑카로 바로 돌아간다.
- 오른쪽 위: 메뉴. Esc로도 접근한다.
- 대화·연출 중: 장소·목표·생활 버튼은 접고 메뉴만 남긴다. 타이틀에서 게임으로 넘어가는 동안은 메뉴를 잠시 숨긴다.

1920×1080 기준 고정 뷰포트와 Expand 스케일러를 사용한다. 아이콘은 `HudIcon`이 정점으로 그리는 벡터 UI다. PSD·새 원화 납품 작업은 아니다.

## 실제 동작

Esc 메뉴에는 **재개 / 설정 / 타이틀로 / 게임 종료**가 있다. 메뉴가 열리면 기존 Time.timeScale과 AudioListener.pause를 보관하고 게임 시간·소리를 멈춘다. 대사 입력도 차단한다. 메뉴 전환과 설정 미리보기는 실제 시간으로 동작한다. 재개할 때는 이전 시간 배율·소리 상태를 복원한다.

설정에서 Esc → 일시정지 메뉴, 일시정지 메뉴에서 Esc → 재개. 종료 확인에서 Esc → 메뉴. 위·아래와 Enter는 Unity EventSystem의 버튼 선택·제출을 사용한다. 버튼을 누르는 최초 마우스 입력이 대사 전체 출력이나 다음 대사로 전달되지 않도록 `FreshInput`에서 UI 버튼 히트를 거른다.

현재 저장 시스템이 없으므로 타이틀 이동·게임 종료에는 진행이 저장되지 않는다는 확인을 표시한다. 타이틀로 돌아가면 공통 HUD를 제거한다. Editor의 게임 종료는 플레이 모드를 종료하고, 플레이어 빌드에서는 Application.Quit을 호출한다.

## 연결 범위

- 실제 도입부: `C0OpeningDirector`에서 `GameHud.Ensure(font)`로 공통 HUD를 생성하며 Esc 메뉴를 사용할 수 있다. 마지막 질문 이후 연결은 아래 1단계 탐색 항목을 따른다.
- **최신 정리:** 사용자 요청으로 별도 HUD 프리뷰 씬과 전용 생성·실행 스크립트를 제거했다. 실제 타이틀·게임 씬을 사용한다. HUD·지도·하루 마치기 코드는 보존하며, 지도 초기 데이터는 `FirstRegionMap.Create()`에서 제공한다.
- 탐색 진입: `GameHud.Instance.SetExplorationContext(place, timeOfDay, objective)`를 호출한다. 대화 진입은 `SetNarrativeMode()`를 사용한다. HUD는 게임 씬 사이에 유지된다.
- 지도는 기존 HUD 안의 `MapPanel`, 가방·인물 상태는 `BagPanel`로 연결했다. 요리·기록 상세 기능과 실제 물자 소비는 미구현이다. `BindAction(ActionId, Action)`으로 실제 기능을 연결하며 미연결 버튼은 현재 사용할 수 없다는 짧은 안내만 표시한다. 기능 연결은 해당 게임 씬을 활성화한 뒤 수행한다.
- 하루 마치기는 `ConfigureDayEnd(summary, blockedReason, finish)`로 연결한다. 조건 확인 함수는 불가 사유 또는 빈 문자열을 반환하고, 확정 및 창 퇴장 후에 다시 확인한다. 완료 콜백은 시간·오디오가 복원된 뒤 한 번만 실행한다. 새 날짜에서 다시 연결해야 한다. 실제 소등·다음 날 스토리는 미구현이며 HUD가 날짜를 임의 증가시키지 않는다. 시안은 소이와의 대화 미완료 상태로 표시한다. `VerifyGameHud.DayEnd`는 테스트 콜백으로 가능 상태·조건 변화·취소·중복 실행 방지를 검증한다.
- 상태 게이지와 인물별 수치는 기존 계획을 유지하되 이번 시안에 임의 수치를 넣지 않았다.

## 후속 지도 UI · 씬 추가 없음

지도는 HUD 내부 패널로 구현했다. 초기 검수에 사용한 프리뷰 씬도 후속 요청으로 제거했으며 UI마다 별도 씬을 만들지 않는다. 지도를 여는 동안 생활 HUD를 숨기고 닫으면 복원한다.

왼쪽은 접힌 종이 느낌의 개략 지도, 오른쪽은 목적지 정보 카드다. 기존 `design/ui/day01-v1/review/D1-02-map.jpg`의 구성을 Unity 그래픽과 독립 텍스트로 구현했다. 장소 선택 시 경로·마커·카드가 바뀐다. 미발견 장소는 이름·마커를 숨기고 선택도 막는다. 7곳의 명칭은 `design/chapter01/event-quest-catalog-v2.json`을 따르며 시안에는 편의점만 공개했다. 캠핑카는 별도 이동 목적지가 아니라 현재 위치로 표시한다.

`GameHud.ConfigureMap(places, blockedReason, travel)`으로 현재 장소 정보·이동 조건·실제 이동 처리를 제공한다. `MapPanel.Discover(id)`가 장소를 공개한다. 출발은 목적지 선택 → 출발 확인 → 확정 순서이며 Esc는 확인창에서 장소 선택으로, 지도에서는 캠핑카로 돌아간다. 지도 체류 중 게임 시간은 멈추고 이동 콜백은 창을 닫아 정지를 해제한 뒤 한 번 실행한다.

현재 도로 좌표·경로는 UI 배치용 개략선이며 최종 지리나 길찾기 결과가 아니다. 확정된 거리·소요 시간이 없어 ‘미확인’으로 표시한다. 실제 이동·자원 차감·저장은 이번 범위에 없다. 현재 시안은 소이와의 대화가 남은 상태라 출발을 막는다. 회복·연료·일수 비용은 임의로 추가하지 않았다.

검수: `AgentScripts/VerifyMapPanel.cs`. 기존 HUD 버튼 진입, 씬 수 유지, 미발견 장소 숨김/선택 차단, 발견 후 선택, 실제 Esc 복귀, 출발 확인/취소, 조건 재검사와 단일 콜백을 플레이 모드에서 검증했다. `Demo3/Screenshots/MapReview/`에 시안과 보고서가 있다.

# 첫 그림부터 첫 사진·지역 출발까지

후속: [생활 기능 연결](CAMP-LIFE-RUNTIME-2026-09-13.ko.md)에서 첫 식사·분배를 책 펼치기 앞에 연결했다. 이전 검수의 ‘책 펼치기부터 시작’ 안내는 당시 상태이며, 현재 기존 진행은 캠핑카 식탁에서 첫 식사를 준비하면 이어진다.

## 현재 연결

편의점 물·식량 확보 → 캠핑카에서 책 펼치기 → 잡화점 색연필 → 캠핑카에서 도구 놓기·첫 그림 → 주유소에서 세진 소개와 길 정보 → 공구 가방 부탁 수락 → 수리점에서 가방 회수 → 주유소에서 카메라·첫 필름 수령 → 강변 촬영 → 앨범 확인을 실제 플레이 행동으로 연결했다.

수혁이 그림을 그리고 소이는 옆에서 함께 보는 최신 제작 방향을 따른다. 바다는 앞으로 보고 싶은 풍경이다. 세진은 소이의 실재를 확인하는 말을 하지 않으며, 소개 대사를 확인한 뒤 `?`에서 이름으로 바뀐다.

색연필을 먼저 챙겨도 되고 기존 `colored_pencils`/`pencils`가 있으면 다시 구할 필요가 없다. 책은 기존 것을 사용한다. 부탁 수락 전 수리점에서는 가방 위치만 기억하며, 회수는 수락 이후 가능하다. 부탁 수락은 수리점을, 카메라 수령은 강변을 발견 상태로 만든다. 각 장소의 두 확인 지점과 탐색 완료는 별도로 유지한다.

카메라·사진을 얻었다는 이유만으로 출발하지 않는다. 첫 그림의 마지막 반응, 첫 사진의 앨범 확인, 세진의 길 정보를 마친 뒤 고갯길 탐색과 캠핑카 주차 조건까지 충족해야 다음 지역으로 이동할 수 있다. 조건 키는 기존 `RegionTravel.Drawing`, `Photo`, `Route`를 사용한다.

## 대사와 원화의 상태

[실행 대사 데이터](../../design/chapter01/first-week-runtime-v1/story.json)는 기존 E05~E11 콘티를 연결하기 위한 **구현용 대사 초안**이다. 대사집의 해당 구간이 미작성 상태이므로 최종 승인된 대사로 취급하지 않는다. 이후 문장을 교체할 수 있도록 사건·대사·효과를 별도 JSON에 두었다.

새 원화는 생성하지 않았다. 기존 최신 `art-polish-v1/review`의 E05~E09와 L4/L6 원화, 첫 사진 style-v2 원본, 투명 앨범·세진·색연필 레이어를 Unity AssetDatabase로 가져왔다. 원본 경로는 `Demo3/AgentScripts/ImportFirstWeekArt.cs`에 기록한다. 앨범은 투명 원본 위에 실제 첫 사진을 Unity에서 배치하며, 체크무늬가 포함된 검수 합성 이미지를 사용하지 않는다.

원본 해상도는 그대로 유지한다. 1672×941 장면 및 1448×1086 사진 등을 1920×1080 게임 화면에 표시하는 것이며, 새 고해상도 원본을 만든 작업은 아니다. 기존 두 씬을 사용하고 프리뷰 씬을 추가하지 않았다.

## 진행·저장·다시 보기

- `weekEvent`와 `weekLine`은 현재 사건 및 다음에 읽을 대사를 저장한다. 대사 확인마다 자동 저장하며 불러오면 그 지점부터 이어진다. 기존 버전 1 저장에서 새 필드가 없어도 읽을 수 있다.
- 세진 이름은 소개 확인 시 저장한다. 카메라 전달은 가방 소비·카메라·필름 획득·확인 위치를 한 체크포인트에 저장한다.
- 셔터 문장을 확인하면 첫 필름을 사용하고 사진을 얻는다. 첫 촬영 필름이 없는 이전 상태에서도 첫 촬영을 막지 않도록 보장한다. 촬영 완료와 앨범 확인은 별도 상태다.
- 마지막 대사 직후의 체크포인트도 복구할 수 있다. 중복 획득과 시간 중복 차감을 막으며, 장소·선행 조건·가방 보유와 맞지 않는 사건 저장은 거부한다.
- 캠핑카의 ‘그림과 사진 다시 보기’는 이미 끝낸 장면을 다시 보여 주며 시간이나 보상을 추가하지 않는다.
- HUD의 현재 목표와 기록창의 여섯 진행 항목에 이 흐름을 반영한다. 대화 전환에는 기존 계속 표기·좌우 이름표·암전과 텍스트 페이드를 사용한다.

## 검수

`Demo3/AgentScripts/VerifyFirstWeek.cs`가 선획득·기존 색연필, 가방 사전 확인, 이름 공개 시점, 중간 체크포인트 유효성, 카메라 교환, 첫 촬영 필름 보장, 사진과 앨범 조건 분리, 중복 보상 방지를 확인한다. 실제 플레이 검수는 HUD 버튼과 대화 넘김으로 사건을 이어가고 카메라 전달·촬영 도중 저장을 다시 불러온다. 이후 장소 탐색, 지역 이동과 재로드까지 확인한다.

검수는 별도 슬롯에만 저장하며 플레이어의 기존 진행으로 복원한다. 결과는 `Demo3/Screenshots/FirstWeek/progress.txt`, 화면은 같은 폴더의 PNG다. 대사 데이터의 초안 상태와 다음 지역이 진입로 하나인 범위는 그대로 남는다.

2026-09-13 모델 검사·전체 실제 플레이·마지막 전환 회귀 검사와 Unity 재컴파일을 통과했다. 카메라·사진 중간 재로드 후 수량은 각각 1개였고, 실제 다음 지역 출발 및 재로드까지 성공했다. 대화 종료의 인물 잔상과 색연필을 남겨 두고 다른 장소로 이동할 때 소품이 따라오는 경우도 수정·검증했다. 종료 시 기존 2일 차 편의점 앞 캠핑카 진행과 실제 저장 경로를 복원했으며, ‘소이와 책 펼쳐 보기’부터 시작할 수 있다.

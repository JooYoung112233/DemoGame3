# 챕터 1 생활과 동행 기능

사용자 요청: 남은 작업 가운데 대사·음악을 제외하고 제작. 기존 대사 JSON·대사집·음원은 수정하지 않았다. 이번 범위는 첫 식사, 설비·자원 운영, 저녁 기록, 강아지 동행과 일부 생활 수리다.

## 플레이 연결

- 캠핑카의 **식탁 · 설비 · 오늘의 한 장**에서 생활 화면을 연다. 식탁/설비와 수리/전력/오늘 남길 한 장/동행을 구분한다. 장소에서는 **주변 물자와 생활 흔적**을 이용한다.
- 생수 1과 포장 식량 또는 따뜻한 식사 1로 두 자리의 식사를 준비한다. 수혁이 준비하며 하루 한 번만 차감한다. 첫 식사를 마치면 기존 책·색연필 이야기로 이어진다. 이미 시작한 그림 이야기를 이전 저장에서 불러온 경우 되돌려 막지 않는다.
- 편의점: 식재료 3·간편식 2, 잡화점: 가스 3·천 4, 수리점: 수리 부품 2·수동 발전 장치 1. 이 보급품은 장소별 한 번만 지급한다. 탐색 완료의 두 확인 지점과 별개다.
- 요리대 확인 → 부품 1로 복구 → 기존 가스레인지 조리에 연결한다. 조리용 가스와 식재료는 각각 1, 시간은 25분이다. 기존 약불/중불/강불 조리를 유지하며 완성 식사는 한 번만 지급한다.
- 전자레인지: 간편식 1·배터리 10·게임 시간 5분. 약 3초의 가열 진행 표시 후 따뜻한 식사 1을 지급한다. 별도 조작 미니게임은 없다.
- 발전기: 차량과 같은 `fuel` 1·15분으로 배터리 최대 40 충전. 배터리 용량은 100, 이전 저장의 최초 전력은 30이다. 사용 전 남을 연료·실제 충전량·선택한 지역 내 목적지의 이동 여력을 보여준다. 다른 지역의 이전 목적지를 이동 가능한 곳으로 안내하지 않는다.
- 수동 발전 장치를 연결하면 30분으로 배터리 10을 충전한다. 공용 연료 0일 때 주유소 또는 다음 지역 진입로에서 도보 60분으로 연료 2를 확보할 수 있다. 식수·식량이 부족하면 편의점에서 45분 추가 수색으로 최소 한 끼를 확보한다. 확률 실패로 복구를 잠그지 않는다.
- 찬장 고정·카메라 주머니·강아지 깔개는 각각 천 1을 사용하며 완료를 유지한다. 카메라 주머니는 카메라를 받은 뒤 표시한다.

## 강아지와 오늘의 기록

낡은 집에서 살펴보기 → 물 또는 먹을 것 1 놓기 → 떨어져 기다리기 → 동행 선택 → 캠핑카에서 천으로 자리 마련을 분리했다. 중간에 떠나거나 저장을 불러와도 돌봄 비용을 다시 요구하지 않는다. 동행 이후 낡은 집에 같은 강아지를 남기지 않는다. 이름을 부르는 대사를 이번 범위에서 추가하지 않았으므로 **강아지**로 표시한다. 동행과 자리 마련은 지역 출발의 필수 조건이 아니다.

저녁 후보는 당일 실제로 획득한 물품·방문 장소·수행한 생활 활동에서 만든다. 얻지 않은 사진을 보여주지 않는다. 한 가지를 남겨도 인벤토리 물자는 소비하지 않는다. 하루 마무리에서 기록 화면으로 갈 수 있고, 기록 없이 바로 쉬어도 추가 비용이나 불이익이 없다. 이전 날짜의 선택은 기록장의 이전/다음 페이지로 확인한다. 새 독백·서사 대사는 작성하지 않았다.

## 저장과 검수

`CampLifeState`는 배터리·가열 잔여 시간·발전 비교 목적지를 보관한다. `CookingProgress`는 조리 단계·열기·경과·품질 상태를 보관한다. 시작과 완료, 조리 중 약 1초마다, 창을 닫을 때 저장한다. 중간 불러오기는 재료 비용을 다시 차감하지 않는다. 가스레인지 재개는 별도 입력을 기다리고, 전자레인지는 생활 화면을 다시 열면 이어진다. 미완료 조리·가열이 있으면 하루 마무리를 막는다. 기존 버전 1 저장에서 새 필드는 없어도 유효하다.

`VerifyCampLife.Model/Run`으로 조건·중복 지급·기존 저장·실제 버튼 흐름, 요리와 가열 중 재로드, 강아지 돌봄 중 재로드, 저녁 후보 페이지, 다음 날 및 이전 기록을 검사했고 통과했다. `Finish`는 연료 0에서 도보 복구, 타 지역 목적지 안내, 기록을 생략하고 쉬는 경로를 검사한다. 결과는 `Demo3/Screenshots/CampLife/progress.txt`와 PNG에 보관한다. 검수 슬롯은 별도이며 기존 2일 차 진행과 실제 저장 경로를 복원한다.

## 이번 범위의 한계와 후속

수치와 소요 시간은 조정용이다. 발전 소음은 주변 확인 행동과 저장 상태까지이며 실제 소리·위협 연출을 넣지 않았다. 날씨·누수·젖은 침구, 배달·추가 공구·보관 메모 같은 나머지 선택 사건, 탐색 미니게임과 장면 안의 직접 조작 개선은 남아 있다. 챕터 1 전체 제작 완료로 취급하지 않는다.

이미지는 최신 `art-polish-v1/review`의 기존 15개 원본을 AssetDatabase로 가져와 사용했다. 새 그림·음악·씬을 만들지 않았다. 원본 크기를 유지하며 고해상도 원화 보강을 완료한 작업은 아니다. 현재 UI는 작업 대상과 결과를 카드 안에서 보여주는 구현이고, 조리·돌봄의 연속 동작 애니메이션은 아니다.

# 챕터 0 → 첫 주 · 연속 제작 인계

> 2026-09-11 우선 적용: [캠프 목적·소이의 진실 콘티 수정](CH00-01-TRUTH-REVISION-STORYBOARD.ko.md). 기존 대사는 보존하고 `book → camp_radio → departure`를 추가했다. 첫 보급·세진의 길 정보·지역 이탈은 캠프행 여정에 연결한다. 아래 이전 ‘다음 풍경’은 가는 길의 경험으로 읽는다.

추가 인계 정보: `camp_broadcast_heard`, `travel_goal_known`. 캠프 안내를 들었다는 사실과 실제 캠프의 위치·안전 확인은 구분한다. 첫날 독립 검토는 이 정보를 이미 들은 문맥으로 시작하며 실제 페이지 간 저장 연결은 미구현이다. 수혁은 초반 비감염이고 중간 강제 감염 사건의 날짜는 아직 미정이다.

E06의 실제 그림 작성자는 수혁, 현재 소이 그리기는 수혁의 주관적 체험으로 구분한다. E11의 첫 사진은 기존 풍경 사진을 유지한다. 물자 배정과 실제 섭취를 구분하며 소이의 독립적 현실 행동을 새로 추가하지 않는다. 엔딩 회수에 필요한 객관적 행동 원화는 후속 제작이다.

현재 원화와 사건 사이를 잇는 실행 전 콘티다. 정식 대사는 대사집에서 작성하며, 아래 반응은 문장 대신 의도를 기록한다. 모든 시간은 후보이고 게임 플레이 시간 실측값이 아니다. 실제 파일 목록은 [첫 주 연결표](../../design/chapter01/week01-art-coverage-v1.json), 추가 사진 정리는 [원화 manifest](../../art/chapter00/photo-care-v1/manifest.json)를 사용한다.

## 첫 주 순서와 볼륨

1일 낮은 E01~E05의 요청까지다. 색연필 확보와 그림까지 당일에 끝내도록 의무화하지 않는다. 이후 기본 순서는 첫 그림 → 세진 만남 → 가방 부탁 → 카메라 → 첫 사진 → 출발이다. 날짜는 연출을 위한 기준이며 늦게 시작한 튜토리얼을 자동 실패시키는 기한이 아니다.

선택 사건은 중심 사건 사이에 한 번씩 관심거리를 더한다. 누수는 비가 왔을 때, 침구 건조는 실제 젖었을 때, 조리는 요리대가 수리됐을 때, 주머니는 카메라를 받은 뒤에 열린다. 강아지와 교환처 부탁은 독립 경로다. 첫 주를 길게 만들기 위해 같은 장소를 빈 이유로 다시 방문시키거나 고정 대기 시간을 늘리지 않는다.

현재 콘티의 볼륨은 사건과 연결 컷 단위로 확보한 상태다. 대사집과 실제 클릭·탐색 시간이 정해지기 전에는 ‘플레이 몇 분’으로 확정하지 않는다.

## 재진입·조건 검수표

| 상황 | 기대되는 장면 |
| --- | --- |
| 쪽지를 안 읽고 귀환 | E03에서 쪽지 내용이나 대피 지명을 알지 못함 |
| 색연필을 먼저 챙김 | L3 강제 재탐색 없이 전달 단계 |
| 가방만 회수하고 게임 종료 | 빈 선반 유지, 가방 재획득 없음 |
| 카메라 인수 결과 저장 후 재개 | 카메라 추가 지급 없이 인수 반응/촬영 안내 |
| 추가 공구 거절 | 카메라·첫 촬영 진행 가능 |
| 강아지 돌봄 후 유보 | 그릇과 돌봄 기록 유지, 물자 반복 납부 없음 |
| 배달 부탁을 안 받음 | L5와 강아지 발견 가능, 꾸러미만 없음 |
| 비가 없거나 침구가 안 젖음 | 젖음·건조 사건을 발동하지 않음 |
| 임시 누수 대응만 끝냄 | 젖은 침구는 유지, 영구 수리와 별도 기록 |
| 요리대가 아직 고장 | 찬 물자 분배만 가능, 조리 포즈와 따뜻한 음식 결과 금지 |
| 탐색 도중 소음 후보 발생 | 탐색 결과·비용을 먼저 확정하고 소음 대응. 결과 재굴림 없음 |
| 첫 그림/사진만 진행하고 선택 사건 전부 건너뜀 | 책·사진 회고와 출발이 성립. 없는 강아지·NPC 약속 언급 금지 |
| 첫 주를 늦게 진행 | 필수 튜토리얼 안내를 유지. 날짜 때문에 출발 조건을 우회하거나 자동 실패하지 않음 |
| 오래된 저장에 사진 바람 플래그 없음 | 사진기사와 첫 촬영 진행 가능 |

위 표는 Unity 구현 전 수락 기준이다. 현재 브라우저 초안에서 챕터 0의 분기·화자 이름은 별도 검사했지만 이 표 전체를 실행하는 Unity 저장 시스템은 아직 없다.

# 2026-09-13 작업 마감 및 다음 착수

사용자 요청으로 현재 제작 상태를 Git에 보존하고 오늘 작업을 마감한다.

## 현재 구현

- Unity 6.6 프로젝트는 저장소 안 `Demo3/`. 기본 화면 1920×1080. CLI 제어에는 `--project-path E:/personalProject/Demo3/Demo3`를 지정한다. 다른 Unity 프로젝트도 함께 열려 있으므로 대상을 생략하지 않는다.
- 기존 HUD, 지도·지역 탐색, 캠핑카 이동, 생활·요리·저녁 기록 흐름과 첫 주 사건 연결을 제작했다. 세부 완료 범위와 검수 이력은 `docs/08-UI연출/`의 개별 작업 기록을 따른다.
- 저장·불러오기는 ESC 메뉴의 설정 안에 배치했다. 수동 슬롯과 진행 지점 자동저장, 중복 저장 방지 및 실패 처리를 연결했다.
- 세진 대화 초상화는 수혁에 맞춰 얼굴 크기·눈높이를 조정했고, 오른쪽 배치에서 상대를 바라보게 했다. 원래 왼쪽을 보는 소이는 유지한다. 화자 이름 공개 규칙은 계속 적용한다.
- 밴딧 골목 배경·두 인물·접지 그림자를 분리했다. 사용자가 너무 착해 보인다고 지적해 눈매·입매·손의 긴장을 강화한 **v2**를 Unity 리소스에 반입했다. 기존 v1은 보존한다.

## 아직 남은 작업

1. 밴딧 **실제 이벤트 로직은 아직 미연결**이다. 다음 시작점은 v2 원화를 사용한 조우 조건·장소 연결이다. 필수 초반 탐색을 막지 않고, 캠핑카 위치가 달라져도 동작하도록 한다.
2. 선택 결과의 자원·상태 반영, 중복 발생 방지, 조우 전/결과 확정 후 저장을 연결한다. 이어서 귀환 반응과 불러오기 검수를 한다.
3. 새 대사·음악 제작은 이전 사용자 제외 범위를 유지한다. 소이를 다른 NPC가 객관적으로 확인하는 대사·행동을 임의로 넣지 않는다.
4. 정신력 미니게임은 구현하지 않았다. 기존 ‘오늘 남길 한 장’과 별도로 필수 반복 미니게임을 추가하지 않는다.
5. 밴딧 원본은 배경 1672×941, 인물 캔버스 1024×1536이다. 확대용 해상도 보강은 남아 있으며 단순 확대하지 않았다.

## 확인한 결과

- 세진 크기·시선과 소이 방향 유지, 이름 공개 전 `?`, 반복 등록 시 변환 누적 방지를 Unity에서 확인했다.
- 밴딧 v2 투명 PNG·PSD 파일 검증 29개 통과. 배경·두 인물·두 그림자 Sprite를 Unity에서 합성 검수했다.
- 검수용 임시 캔버스는 제거했고 Unity는 플레이가 멈춘 편집 상태로 돌려놓았다.
- 저장·생활·첫 주 검수의 상세 결과는 각 작업 문서 및 `Demo3/AgentScripts/`에 있다. 이번 마감이 전체 챕터 최종 QA 완료를 뜻하지 않는다.

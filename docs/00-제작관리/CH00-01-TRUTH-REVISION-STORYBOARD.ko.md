# 챕터 0~첫 주 초반 · 캠프 목적과 소이의 진실 반영

> 후속 원화 작업 완료: [현재 원화 검수·수정 기록](../05-원화/CH00-01-NARRATIVE-ART-REVIEW.ko.md). 현재 수혁·소이 앉기와 수혁 그리기 원본을 제작했다. E06은 수혁이 그리고 소이가 지켜보는 화면으로 다듬었으며, 실제 상황 회수용 무소이 변형도 별도 저장했다. 아래 ‘수혁 그리기 미제작’은 이 후속 작업 이전의 기록이다. 기존 대사는 그대로다.

2026-09-11 사용자 요청에 따라 [49일 서사 개편안](../01-세계관/STORY-49DAYS-TRUTH-REVISION-2026-09-11.ko.md)을 현재 콘티에 적용한다. 이번 적용은 사건의 이유·연출·실제 행동 주체와 검토용 진행 데이터다. **기존 대사와 대화 선택 문구는 그대로 보존**했으며 대사집 작성 시 고칠 의도를 따로 표시했다. 아래 실제 사건은 제작용 스포일러로, 초반 인게임 해설에 출력하지 않는다.

## 적용한 흐름

기존 가족 기억 → 현재 소이와의 응답 → 기존 책 관찰 → **캠프 라디오** → 출발 약속 → 물·담요 준비 → 소등·수혁의 복구 → 가족사진 고정 → 책·저널·취침 → 첫날 물 보급 → 분배·요리대 암시 → 색연필 부탁 → 첫 그림 → 캠프 방향의 길을 물으러 세진 방문 → 카메라 → 첫 풍경 사진.

첫날 낮은 기존대로 색연필 부탁까지다. 첫 그림과 세진·사진은 이후 첫 주 연결 구간이다. 편의점 첫 수색을 강제 감염 사건으로 바꾸지 않는다. 시작 수혁은 비감염, 감염은 중간 강제 사건, 증상 이후 변형 시작까지 평균 약 30일을 유지한다.

## 신규 라디오 구간의 구현용 연출

- 진입: `book`의 기존 마지막 대사 확인 뒤 `camp_radio`. 두 초기 답변 모두 이 구간을 지난다.
- 화면: 같은 캠핑카 구도 유지, 별도의 폴라로이드나 라디오 근접 컷 없음. 대화 초상·패널은 방송 문장이 없는 현재 검토판에서 숨김.
- 음향 후보: 실내 환경음 유지 → 0.3~0.5초 수신 전환 → 캠프 안내 → 수혁 반응 여백 0.6~1초. 방송 길이는 대사집 후 결정. 모든 수치는 후보.
- 정보: 생존자를 받는 캠프가 있다는 안내를 들었다는 사실만 전달. 캠프의 현재 안전과 방송 진위·정확한 경로는 이후 확인한다.
- 감염 기간 방송은 이 구간에 필수로 겹쳐 넣지 않는다. 평균 약 30일 안내의 배치는 후속 위험 소개 장면에서 검토한다.
- 대사·음성·자막: 이번에 작성/녹음하지 않았다. `vo_radio_survivor_camp_pending_script`는 실제 음원 파일이 아닌 제작 cue다. 인게임에서는 대사집의 방송 문장과 자막이 필요하다.
- 현재 검토판: 연출 설명과 ‘방송 확인 후 출발 준비로’라는 검토용 진행 버튼으로 구간을 확인한다. 이것을 완성된 라디오 재생이나 인게임 선택지로 보고하지 않는다.
- 완료: 확인 시 `camp_broadcast_heard`, `travel_goal_known`를 한 번 기록하고 `departure`로 진행. 인벤토리 지급·감염·이름 공개는 없음.
- 기존 북마크: 이미 방송 이후 지점에 저장된 검토 기록은 강제 되감지 않는다. 개발 인계에서 캠프 정보를 들은 문맥으로 보완한다. 첫날 독립 검토는 챕터 0 완료 문맥을 가정하며 실제 페이지 간 저장 연결은 아직 아니다.

## 사진 분기와 첫 그림의 처리

첫 풍경 사진의 촬영과 앨범 확인을 하나의 고유한 경험으로 남긴다. 재열람·재진입으로 촬영 개수를 늘리지 않는다. 첫 튜토리얼만으로 진실 엔딩을 확정하거나 사진이 적다고 노멀 엔딩을 즉시 잠그지 않는다. 고유 사진 사건과 현실 확인의 누적 조건은 이후 챕터에서 설계한다.

E06은 수혁이 그린 그림을 소이와 함께 완성했다고 경험하는 구성을 채택해 작업한다. 그리기 방법을 아는 이유와 손의 행동은 후속 대사집·객관적 원화에서 연결한다. 현재 수혁이 조용히 앉아 있고 소이가 그리는 컷은 수혁의 체험이며 CCTV 같은 객관 시점으로 사용하지 않는다. 엔딩에서 공개하려면 **수혁의 실제 그리기 자세와 올바른 손·연필·페이지 접촉**이 필요하다. 단순 소이 레이어 삭제로 완성할 수 없다.

생존 UI의 소이 상태는 기존처럼 수혁의 돌봄 인식을 보여주는 시안으로 남긴다. 물자 배정 이후 실제 보관·소비·처리와 물리적인 재고 감소의 관계는 후속 생존 설계에서 명시해야 한다. 이번 콘티 수정으로 실제 인벤토리 시스템이 해결됐다고 보고하지 않는다.

재생성 순서: 기존 자산/콘티 생성 작업 이후 `tools/apply-ch00-01-narrative-revision.mjs`, 이어 `tools/build-ch01-event-catalog.mjs`를 실행한다. 챕터 0 기본 생성기는 manifest가 있으면 라디오·목적 패치를 읽어 적용한다. 오래된 기본 생성기만 실행한 결과를 현재 전체 자산 인계본으로 취급하지 않는다.

## 남은 서사 결정

현재 작업은 초반의 캠프 목적과 주관/객관 행동을 맞춘 것이다. 가족 사망일과 게임 1일 차의 달력 대응, 중간 물림 사건, 노멀 엔딩의 실제 현장, 사진 분기의 임계값·정신력 역할은 아직 정하지 않았다. 대사집 전 원화 전체를 다시 만들거나 초반에 반전 설명을 추가하지 않는다.

## 이번 검증 결과

- 챕터 0: 352개 경로, 13,673개 상태 단계. 모든 출발 경로에서 라디오 확인 기록이 유지되고 각 경로의 방송 완료는 한 번이다. 기존 문장 수는 경로당 80~82로 동일하다.
- 첫날: 355개 도달 상태, 색연필 보유/미보유 두 종료 경로. 조기 귀환 시 물자 상태 유지, 선택 쪽지 미열람 정보 보호, 선확보 색연필 인정. 브라우저 오류 없음.
- 신규 구간: 실제 브라우저에서 라디오 검토 진입·확인·북마크 이어보기 통과. 실제 방송 음원 재생은 미구현이다.
- 기존 대사 37개 노드·선택 문구·저널과 첫날 행동 분기 21개 구간 보존. UI 문구·기억 대사·동결 오프닝을 포함한 보호 파일 218개 해시 동일. 새 대사 0줄.
- 화자 공개 회귀 검사 19개 통과. 문서 참조 16개 확인. Unity 실행·최종 원화·음성 검수는 수행하지 않았다.

# 1차 제작 정리 · 튜토리얼 구조 · 남은 과제

> 후속 갱신: [첫 여정 1차 마감·연속 검수](FIRST-PASS-COMPLETE-2026-09-13.ko.md) 완료. 탐색 v2·요리 개선·L8/L9/L10 현장 배경을 연결하고 새 게임부터 10곳 탐색·다음 지역 출발·설정 저장 복원까지 검수했다. 아래 검수 이력과 제작 현황은 1차 정리 당시 범위로 보존하며 최신 완료 여부는 마감 기록을 우선한다.

2026-09-13 최신 상태. 첫 지역의 기본 진행을 안내하는 구조를 Unity에 연결했다. 이 문서는 구현 여부와 이번 검수 범위를 구분한다. 챕터 1의 최종 완성 또는 전체 게임 QA 완료 선언은 아니다.

## 튜토리얼 구조

상시 우측 메뉴 버튼은 제거한 상태를 유지한다. **ESC → 플레이 안내**, 또는 기존 하단 **지금 할 일 · 안내** 카드에서 다시 읽는다. 자동 팝업으로 플레이를 중단하지 않는다. ESC는 안내 → 일시정지 메뉴 → 게임 순서로 한 단계씩 닫는다.

| 순서 | 안내 범위 | 완료 판단 |
|---|---|---|
| 1. 첫 밤의 준비 | 도입 대화, 주변 인물·책·라디오, 첫 밤 | 첫날 아침 도달 |
| 2. 물과 식량 | 지도에서 편의점 이동, 하차, 물·식량 확인 | 두 확인 지점 완료 |
| 3. 식탁과 첫 그림 | 실제 캠핑카로 귀환, 첫 식사, 책, 색연필, 그림 | 첫 그림 완료 |
| 4. 길에서 만난 사람 | 길 묻기, 부탁 확인, 공구 가방 회수·전달 | 카메라 전달 완료 |
| 5. 첫 사진과 앨범 | 강변 촬영, 사진을 앨범에서 확인 | 앨범 확인 완료 |
| 6. 다음 지역으로 | 강변·약국·고갯길 탐색, 차량 귀환·이동, 지역 출발 | 다음 지역 진입 |

별도 ‘생활 · 조작 · 저장’ 탭에서 ESC, 설정 안 저장·불러오기, 요리, 연료, 하루 마치기를 설명한다. 요리·강아지 동행·저녁 기록·밴딧 조우를 필수 지역 출발 조건으로 추가하지 않았다.

진행은 `JourneyTutorial`이 기존 저장 상태에서 계산한다. 안내 탭을 눌러도 진행·물자·보상이 바뀌지 않으며 새 튜토리얼 저장 플래그가 필요하지 않다. 진행 중인 이야기·조우·조리가 있으면 그 행동을 먼저 안내한다. 잠긴 목적지는 먼저 탐색할 수 있는 연결 장소를 안내한다. HUD와 저장 슬롯의 진행 설명도 같은 목표를 사용한다.

## 이번에 바로 보완한 부분

- 목표가 너무 포괄적이던 부분을 현재 행동으로 세분화했다. 주차와 하차, 장소 방문과 두 지점 탐색, 이야기 물품 회수와 지도 해금, 촬영과 앨범 확인을 구분한다.
- 캠핑카가 도보 이동을 따라오지 않는 규칙을 명시하고 실제 주차 위치로 귀환하도록 안내한다. 고갯길에 걸어 도착해도 차량 출발 준비가 끝난 것으로 처리하지 않는다.
- 첫 식사에 필요한 재고가 부족하면 편의점의 추가 물자 수색을 안내한다. 이미 가진 색연필을 다시 구하도록 요구하지 않는다.
- 연료가 없을 때는 도보 탐색·주유소 비상 연료 경로를 안내한다. **첫 출발 지점에서는 하차할 수 없어 연료 0 상태가 막히던 예외**를 수정했다. 생활 → 전력의 ‘출발 지점 주변에서 비상 연료 찾기’로 60분을 써 연료 2를 확보한다. 연료가 남아 있으면 이 행동이 나타나지 않는다.
- 저장 미리보기 그림이 없는 장소를 저장 파일 오류처럼 표시하던 문구를 수정했다. 정상 저장은 장소와 탐색 기록을 표시하고 실제 읽기 실패만 오류로 구분한다.

| 49일·엔딩 | 날짜 처리 존재 | 전체 49일 사건 구성·최종 엔딩 완성 검수는 남음 |
| 대사·음악·정신력 | 기존 내용 유지 | 새 대사·음악 제작은 사용자 제외 범위. 정신력 반복 미니게임 미구현 |

현재 빌드 활성 씬은 Title와 Game 두 개다. 장소별 UI와 원화 전환이 별도 빌드 씬 증가를 의미하지 않는다. 과거 시안과 비활성 자산을 이번 정리에서 삭제하지 않았다. 원화 해상도 보강은 별도 작업으로 남기며 단순 확대를 원본 개선으로 간주하지 않는다.

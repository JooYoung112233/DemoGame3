# 다음 작업 인계 — Unity 제작으로 전환

2026-09-11 사용자 결정: 여기서 기획·독립 시안 확장을 멈추고 Unity에서 실제 플레이 흐름을 제작하며 다듬는다. 엔진 Unity 6.6, 기본 화면 1920×1080. 이번 커밋은 준비 자료 보존이며 Unity 구현 완료를 뜻하지 않는다.

## 최신 승인 사항

- 탐색: 진행 중 불규칙한 순간에 원형 판정이 짧게 등장. 판정판 상시 노출은 본편에서 제외한다. [V2 규칙](../02-게임시스템/SEARCH-MINIGAME-V2.ko.md), `design/minigames/search-v2/`.
- 요리: 가스레인지에서 냄비를 데우고 잔잔하게 익히는 흐름. 본편은 버튼형 시안을 개선해 장면 속 조작으로 만든다. 다이얼 드래그·불꽃·기포·소리 중심 표현은 구체화 후보이며 아직 구현하지 않았다. [요리 시안](../02-게임시스템/COOKING-MINIGAME-PROTOTYPE.ko.md).
- 간편식: 전자레인지 가열 연출, 미니게임 없음. 가스레인지는 가스/식재료, 전자레인지는 배터리 전력/간편식 사용.
- 차량 이동·발전기 공용 연료. 충전과 이동 중 사용자가 선택한다. 수동 발전은 시간을 쓰는 최소 전력 대안. 도보 비상 연료 확보 경로로 진행 막힘을 예방한다. [에너지 운영](../02-게임시스템/CAMPER-ENERGY-AND-COOKING.ko.md).
- 저녁 정신력 게임은 제외. 당일 실제 경험의 사진·물건·기록에서 하나를 일기장에 남기는 선택형 활동. 바로 잠들기도 가능. [오늘 남길 한 장](../02-게임시스템/EVENING-MEMORY-ACTIVITY.ko.md).
- 대사는 사용자가 [대사집](../06-대사/DIALOGUE-BOOK-CH00-01.ko.md)에서 수정. 음악은 사용자가 Suno로 제작하며 [프롬프트](../07-음악과미니게임/SUNO-MUSIC-PROMPTS.ko.md)를 사용한다. 음원 제작 완료 아님.

## 후보로 남긴 것 — 확정 구현 범위 아님

- 저녁을 귀환 사건 → 오늘 남길 한 장 → 내일 선택으로 확장.
- 사진·강아지·생활 사건을 며칠간의 연속 이야기로 연결. 특별한 저녁 3~5분 제안.
- 라디오 주파수 맞추기, 호수/바다 낚시. 아직 시안 제작하지 않았다.
- 수동 발전의 반복 조작 미니게임 여부. 우선 이벤트/시간 선택으로도 표현 가능.
- 모든 자원 소모량·조리 시간·품질 효과는 임시. 기존 데이터와 연결 전에 재조정한다.

`design/minigames/fire-v1/` 화덕·부채질은 미채택 실험, `search-v1/`은 이전 비교 시안으로 보존한다. 정식 기능으로 착각하여 연결하지 않는다.

## 실제 제작 순서 제안

1. Unity 프로젝트 상태를 확인하고 없으면 6.6 기반으로 구성. 시작부터 C0 현재 복귀까지 장면·대화·저장 흐름을 먼저 연결한다.
2. [콘티와 원화 연결표](CH00-01-STORYBOARD-ASSET-MAP.ko.md), [시작 인계](UNITY-OPENING-HANDOFF.ko.md), 최신 원화 [장면 매니페스트](../../art/chapter00-01/art-polish-v1/scene-manifest.json)를 대조해 사용 자산을 선정한다. 고정 보관 `design/unity-handoff/opening-v1/`은 과거 스냅샷으로 유지한다.
3. 챕터 1 첫날의 지도 → 편의점 탐색 → 귀환 → 분배 → 색연필 목표까지 실제 플레이 가능한 한 줄기를 완성한다.
4. 시간·인벤토리·퀘스트 상태를 연결하고 탐색 결과/중단/저장의 중복 지급을 막는다. 시안의 로컬 저장 정책을 그대로 정식 저장으로 취급하지 않는다.
5. 요리대 복구, 가스 확보, 전자레인지 전력, 공용 연료 발전/이동 선택을 연결한다. 필수 서사가 자원 고갈로 영구 봉쇄되는지 검증한다.
6. 저녁 기록 활동을 하루 흐름에 넣고 첫 주를 확장한다. 플레이 시간·반복 피로·서사 밀도를 보고 후보 이벤트를 채택한다.
7. 사용자 수정 대사와 확정 음원을 적용하며 장면 속 인터랙션·연출을 다듬는다. 새 원화는 실제 화면에서 필요한 것부터 제작한다.

위 순서는 다음 착수용 제안이다. 이 문서를 저장하는 시점에는 Unity 개발을 시작하지 않는다. 다음 지시에서 진행한다.

## 시안 실행과 검증

- 탐색: `node tools/serve-search-minigame-v2.cjs 8796`
- 요리: `node tools/serve-cooking-minigame.cjs 8798`
- 순수 규칙: `node tools/test-search-minigame-v2.mjs`, `node tools/test-cooking-minigame.mjs`
- 원화의 실제 해상도 한계와 검증 범위는 [전체 보완 기록](../05-원화/ART-POLISH-2026-09-11.ko.md)에 남아 있다. 모든 이미지를 최종 고해상도 납품으로 보고하지 않는다.

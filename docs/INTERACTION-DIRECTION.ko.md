# 상호작용과 탐색 위험 · 제작 방향

2026-09-09 대화 반영. 미니게임 상세 규칙은 보류한다. 아래 사건과 대상별 행동은 제작 후보이며 확률·행동력·횟수를 확정하지 않는다. 기존 타이밍 시제품은 조작과 표시 확인용으로 보관한다.

## 탐색: 진행과 위험이 함께 남는다

한 번의 판정으로 탐색 전체가 끝나는 구조보다, 대상을 살펴보고 손대는 동안 진행 상황과 주변 상황이 달라지는 방향으로 잡는다. 모든 물건에 여러 번의 조작을 강제하지는 않는다.

예시: 걸린 계산대 서랍을 조금 연다 → 안쪽 물건을 꺼내려다 금속 소리가 난다 → 밖에서 발소리가 들린다 → 더 찾기 / 잠시 멈춰 듣기 / 돌아가기 중 선택한다. 발소리가 누구의 것인지, 실제 사건으로 이어지는지는 장소와 이야기 진행에 따라 달라질 수 있다.

- 소음은 실패뿐 아니라 서랍을 억지로 열기, 물건을 떨어뜨리기 등 행동에서도 생길 수 있다. 성공했더라도 소리가 날 수 있다.
- 소음·체류·현재 장소의 상황이 후속 사건의 가능성에 영향을 준다. 소음이 날 때마다 적이 반드시 나타나는 규칙으로 고정하지 않는다.
- 가능 사건은 주변 인기척, 누군가의 접근, 탐색 중단을 고민하게 하는 상황 등이다. 소음과 관계없는 병세·차량 문제까지 같은 판정에 억지로 연결하지 않는다.
- 소리와 짧은 문장으로 징후를 먼저 전달하고 다음 선택을 준다. 확률만으로 설명 없이 손해를 주는 연출은 피한다.
- 이미 열어 둔 서랍이나 발견한 단서 등 진행 상태를 남기는 안을 검토한다. 재시도마다 처음부터 되풀이하는 규칙은 아직 정하지 않는다.
- 필수 서사는 조건을 갖춘 장면으로 관리하고, 우연한 사건은 탐색의 긴장과 기억을 더한다. 세진·하은의 핵심 만남을 순수 무작위 추첨에만 맡기지 않는다.

정확한 확률, 위험 누적·감소 방식, 시도 횟수, 중단 비용, 미니게임 입력과 보상은 후속 기획 대상이다. 현재 코드에는 소음 카운터만 있고 사건 발생 시스템은 없다.

### 추가 방향: 냉장고의 아이템별 회수 확률

사용자 제안: 아이템마다 기본 획득 확률이 있고 미니게임에 성공하면 그 확률이 올라간다. 냉장고를 첫 적용 후보로 삼는다. 구체적인 수치와 판정 방식은 아직 정하지 않는다.

- 보이는 물건을 꺼내 오는 **회수 확률**로 설명하는 안을 우선 검토한다. 물건이 존재하는 확률과 회수에 성공할 확률을 겹쳐 판정하지 않는다.
- 예를 들어 손이 쉽게 닿는 물과 무너진 선반 뒤의 음료는 회수 가능성이 다를 수 있다. 어려움은 원화 속 위치와 짧은 설명으로 납득할 수 있게 한다.
- 미니게임 결과는 회수 가능성을 높이는 데 사용한다. 성공해도 획득에 실패할 수 있다는 점과 보정 후 가능성을 플레이어가 알 수 있게 한다. '미니게임 성공 = 획득 완료'라고 표시하지 않는다.
- 도전은 원하는 물건을 얻을 가능성과 더 시도할 때의 소음·시간 부담 사이에서 생기도록 한다. 희귀도만 낮은 확률로 설정해 반복 시도를 요구하는 구조는 피한다.
- 손쉬운 물건의 확정 회수 또는 좋은 조작 결과의 확정 회수는 좌절감을 줄이는 비교 후보다. 아직 채택한 규칙은 아니다.
- 소음에 따른 외부 사건은 물건 회수와 별도 상황 변화다. 회수 실패가 곧 적 등장으로 이어지는 고정 연쇄는 두지 않는다. 핵심 서사 진행을 위한 물건을 반복 확률 실패에만 묶지 않는다.

한 물건을 먼저 골라 시도할지, 한 번의 조사 결과로 여러 아이템의 가능성을 바꿀지, 보정이 재시도에도 남을지는 상세 기획 때 비교한다. 현 단계에서 전리품 추첨이나 확률 시스템을 구현하지 않는다.

### 조사 화면도 폴라로이드의 시각 문법을 공유한다

권장 구성: 편의점 전체 화면에서 냉장고 선택 → 냉장고 확대 사진 한 장 → 사진 아래 아이템·회수 가능성·행동 UI → 같은 사진을 유지하며 조작과 결과 표시 → 계속 조사 또는 닫기.

| 용도 | 사진의 사용 | 하단 내용 |
| --- | --- | --- |
| 일반 조사 | 대상 확대 사진 한 장을 유지 | 아이템 선택, 회수 가능성, 소음 징후, 행동 버튼 |
| 미니게임 진행 | 같은 사진과 화면 위치를 유지 | 선택 UI를 조작 UI로 교체 |
| 일반 결과 | 같은 사진에서 소품·문구만 필요한 만큼 변경 | 얻은 것과 상황 변화, 다음 선택 |
| 중요한 발견·대화 | 기존처럼 사진을 교체하거나 쌓으며 연출 | 짧은 대사와 선택 |

종이 테두리·팔레트·글꼴·여백을 공통으로 쓰되 매 클릭마다 사진이 날아오거나 새 컷으로 넘어가는 연출은 생략한다. 단순 물품 확인은 작은 안내로 끝낼 수 있다. 조사 사진 모두를 추억 앨범에 저장하지 않고 이야기상 의미 있는 장면만 기록하는 안을 권장한다.

확률·이름·버튼·대사는 이미지에 굽지 않는다. 작은 화면에서는 하단 UI를 세로로 배치하고 미니게임 중 대화가 조작 영역을 가리지 않게 한다. 냉장고 확대는 기존 배경의 부분 확대를 우선 사용하며, 필요한 보정도 선반·문·시점의 일관성을 유지한다. 일반 조사마다 새 인물 원화를 요구하지 않는다.

## 캠핑카: 날짜와 사건에 따라 상호작용이 달라진다

현재 시제품의 주방·스케치북 2곳은 표시와 조작을 확인하기 위한 범위다. 아래 10곳은 전체 이야기에서 사용할 수 있는 후보 목록이며 동시에 활성화할 버튼 목록이 아니다. 날짜·시간대·사건·관계·획득 물건에 따라 그 순간 의미 있는 상호작용만 열린다. 날짜가 지날수록 버튼이 계속 누적되는 방식도 피한다.

한 장면에서 주요 상호작용 2~3개 정도를 먼저 시험하되 고정 개수나 행동력 규칙으로 확정하지 않는다. 조용한 날은 더 적고 특별한 날은 달라질 수 있다. 활성 대상을 무작위로 바꾸기보다 서사와 현재 상황을 이유로 정한다.

| 상황 예시 · 날짜 배정 미정 | 그때 열리는 상호작용 후보 | 장면의 이유 |
| --- | --- | --- |
| 출발 전 | 소이와 대화, 운전석의 지도 | 소이의 바람을 듣고 목적지를 정한다 |
| 색연필을 가져온 저녁 | 스케치북, 소이와 함께 그리기 | 탐색에서 가져온 것이 저녁의 기억으로 이어진다 |
| 식재료를 가져온 저녁 | 주방, 식사 대화 | 그날 확보한 재료로 가능한 행동이 생긴다 |
| 편지를 발견한 밤 | 서연의 편지, 블랙 저널 | 과거를 읽고 수혁의 반응을 남긴다 |
| 별똥이가 창밖에 반응할 때 | 별똥이, 창문 | 반응이 주변을 살펴볼 이유가 된다 |

같은 소이도 어떤 날은 그림을 보여주고 어떤 날은 먼저 말을 건다. 같은 오브젝트에서 사건에 맞는 행동과 대사가 바뀌게 한다. 아무 사건이 없는 가구는 배경으로 남기고 잠금 아이콘이나 상시 이름표를 늘어놓지 않는다. 열린 대상에는 시선·자세·소품 변화 같은 작은 단서를 주고, 선택 가능한 영역에만 하이라이트와 이름을 표시한다.

읽은 기록·소지품 확인은 공용 메뉴로 접근할 수 있게 하는 안을 검토한다. 취침·출발처럼 다음 단계로 넘어가는 행동은 상황에 맞는 경로를 남겨 진행이 막히지 않게 한다. 선택하지 않은 대화의 유지·만료 여부는 사건별로 정하고, 필수 서사에는 다시 접근할 경로를 둔다. 이 활성화 구조는 기획이며 현재 시제품에는 아직 구현하지 않았다.

| 대상 / 위에 뜨는 이름 | 짧게 살펴보기 | 시간을 쓰거나 장면으로 이어질 행동 후보 | 필요한 자산·상태 |
| --- | --- | --- | --- |
| 소이 | 지금의 반응 | 이야기 나누기, 약속하기 | 기존 앉기·고개 들기 포즈, 대화 가능 표시 |
| 별똥이 | 상태와 짧은 반응 | 쓰다듬기, 함께 쉬기 | 합류 후 등장, 대기·교감 포즈 |
| 작은 주방 | 재료와 식사 확인 | 요리하기 | 기존 요리 포즈, 준비 전/조리 중/완성 소품 |
| 소이의 스케치북 | 지금 그림 다시 보기 | 함께 그리기, 다음 바람 듣기 | 그림 전/후, 소이 그리기 포즈 |
| 블랙 저널 | 지난 기록 읽기 | 오늘의 기록 남기기 | 닫힌 책/펼친 페이지, 별도 본문 |
| 서연의 편지 | 발견한 편지 목록 | 편지에 담긴 기억 장면 | 발견한 편지만 활성화, 봉투/편지/별도 본문 |
| 물품 보관함 | 식량·약 등 확인 | 챙길 물건 선택 | 닫힘/열림, 물품 아이콘; 관리 행동의 시간 비용은 미정 |
| 침대 | 쉴 수 있는지 확인 | 쉬기, 하루 마치기 | 휴식 포즈, 낮/밤 안내 문구 |
| 운전석·지도 | 현재 위치와 목적 확인 | 다음 행선지 선택, 출발 | 기존 운전석 영역, 지도 UI, 출발 조건 안내 |
| 창문 | 밖의 날씨·인기척 | 소이와 바깥을 보며 짧은 대화 | 기존 배경 확대, 상황별 소리·대사 |

단순 확인과 주요 행동을 구분한다. 무료 확인 범위와 시간·행동력 소모량은 이후 정한다. '상호작용 대상 수'와 '한 타임에 가능한 주요 행동 수'는 별개다. 물건이 없거나 아직 만나지 않은 인물은 이름만 떠 있는 빈 버튼으로 노출하지 않는다.

하이라이트와 이름은 원화에 굽지 않고 별도 표시한다. 대상의 비활성·활성·선택·완료 상태를 공통 UI로 처리한다. 비활성 대상은 클릭과 표시를 끄고 배경으로 남긴다. 현재 사건상 보여야 하지만 조건이 부족한 행동만 선택 시 이유를 안내한다. 작은 물건은 넉넉한 클릭 영역을 두되 겹치는 후보를 동시에 선택하지 않도록 배치한다. 인물·책·편지의 실제 위치는 기준 원화 위 배치 검수 후 확정한다.

## 첫 탐색 장소: 편의점

현재 작은 매장 규모를 유지하고 장소 명칭을 **편의점**으로 바꾼다. 기존 파일 경로와 내부 키의 `mart`는 링크 호환을 위해 유지한다. 구급 물품장은 편의점에 맞는 소형 상비약 코너 후보로 정리하고, 약의 종류와 진열 형태는 후속 원화 보정 시 검토한다.

기존 시제품의 조사 대상은 계산대 서랍·식품 선반·상비약 코너·문구 선반이다. 냉장고를 아이템별 회수 확률과 폴라로이드 조사 화면을 검토할 추가 대상으로 삼는다. 출입구와 창은 주변 징후를 보여주는 연출 지점으로 활용할 수 있다. 조사 대상마다 미니게임을 배정할 필요는 없다.

## 다음 리소스 작업

1. 첫 3일의 장면별 활성 대상과 등장·완료 조건을 먼저 정하고, 필요한 대상부터 캠핑카 기준 원화에 위치와 이름 기준점을 잡는다. 기존 가구 배치를 유지한다.
2. 저널·편지·보관함 등의 닫힘/열림과 발견 전/후 상태를 우선 정리한다. 별똥이와 편지는 합류·발견 시점에 맞춰 제작한다.
3. 편의점은 기존 원화를 유지하며 명칭과 소품 적합성을 보정한다. 인기척은 동일 배경 확대·효과음·짧은 대사로 먼저 시험한다.
4. 미니게임 전용 판정 UI 추가 제작과 확률 수치 조정은 상세 기획 때 진행한다.

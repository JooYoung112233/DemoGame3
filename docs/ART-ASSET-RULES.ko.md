# 원화 원본·납품 규칙

2026-09-09 · 사용자 지정: Unity에서 개발하므로 원화 작업 중 이름표 같은 UI에는 시간을 쓰지 않는다. 이미지는 이후 수정하기 충분한 해상도로 준비하고, 가능하면 PSD도 제공한다.

## 작업 범위

지금은 배경·인물·소품·연출용 이미지와 수정 가능한 원본을 제작한다. 이름표, 버튼, 하이라이트, 폰트, 클릭 영역, HTML 미리보기 반응형 배치는 사용자의 별도 요청이 있을 때만 다룬다. UI는 그림에 구워 넣지 않고 Unity에서 조합한다.

원화 확인용 합성은 사용할 수 있다. 검수는 색·크기·시점·가림·접지·고정 배경 일관성과 알파·해상도를 중심으로 한다. 기존 브라우저 UI 검사 스크립트는 이력으로 보존하며, 원화만 바꿀 때 자동으로 UI 개선 작업까지 넓히지 않는다.

## 신규 원본 크기

아래는 사용자 요구를 적용하기 위한 기본 제작 목표다. 실제 게임에서 가장 크게 표시되는 크기와 사진 확대 연출을 먼저 확인하고, 그보다 1.5~2배의 선형 픽셀 여유를 둔다. DPI 수치만 높이는 것은 해상도 확보가 아니다.

| 종류 | 기본 원본 목표 | 제작 방법 |
| --- | --- | --- |
| 전체 배경 | 가로 장면은 장변 3840px 수준 | 승인된 화면 비율·구도 유지. 배치 데이터 좌표계는 별도로 보존 |
| 주요 인물의 행동 포즈 | 한 포즈의 실제 인물 높이 1536~2048px 수준 | 여러 포즈를 한 작은 시트에 몰아넣지 않고 개별 제작 우선 |
| 일반 분리 소품 | 실제 물체의 긴 변 512~1024px 수준 | 큰 여백을 포함한 캔버스 크기로 충분하다고 판단하지 않음 |
| 책·편지·색연필 등 확대 중심 소품 | 긴 변 1024~2048px 수준 | 화면 속 가장 큰 표시 크기를 기준으로 확보. 페이지 상태도 같은 크기·외곽 공유 |

생성 도구가 목표 크기를 직접 출력하지 못하면 최대 크기의 실제 원본을 보관하고, 목표 미달을 명시한다. 필요하면 부분별 큰 원본 제작·부분 재작화 방식으로 확보한다. 확대 보간만 한 파일을 새 디테일이 있는 고해상도 원화로 취급하지 않는다. 도구 출력 한계를 이유로 승인된 그림의 구도나 화풍을 임의로 바꾸지 않는다.

Unity용 축소 PNG와 검수용 WebP/JPEG는 원본에서 별도로 만든다. 원본은 축소본으로 덮어쓰지 않는다. 배경 해상도를 바꿀 때도 기존 1672×941 배치 좌표와 새 원본 사이의 변환 관계를 기록해 소품이 어긋나지 않게 한다.

## 편집 가능한 파일

- 원본 PNG, 실제 RGBA 분리 PNG, 배치·원본 치수 정보는 계속 보관한다.
- 가능하면 PSD를 함께 제공한다. 배경 / 전경 가림 / 인물 몸 / 손·도구 / 소품 / 페이지 상태 / 접지 그림자를 필요에 따라 독립 레이어로 둔다.
- 레이어 이름과 원본 대응 관계, 사용 상태를 기록한다. 서로 배타적인 포즈·소품 상태는 동시에 켜지지 않도록 정리한다.
- 소스의 실제 픽셀을 보존한다. 배치 크기로 줄인 래스터 레이어만 있는 PSD를 유일한 마스터로 쓰지 않는다. 원본 크기의 레이어 또는 원본을 유지하는 스마트 오브젝트를 사용하고, 별도 PNG 원본도 남긴다.
- 한 장으로 생성된 배경의 가구·벽·장식을 모두 독립 편집할 수 있다고 가정하지 않는다. 실제로 분리한 영역만 레이어 편집 가능하다고 표시한다.
- PSD 납품 시 다시 열어 레이어·알파·크기·합성 결과를 확인한다. 아직 만들지 않은 PSD나 검증하지 않은 호환성을 완료로 보고하지 않는다.

## 기존 챕터 1 자료

현재 배경 3개는 1672×941이다. 책은 102×73, 컵은 53×52, 연필통은 46×68, 편의점 음료 병은 17×32 등 일부 추출본이 작다. 현재 장면 배치와 스타일 확인용으로 보존하며, 확대·세부 수정용 최종 원본으로 간주하지 않는다.

다음 교체에서는 확대에 직접 쓰이는 책·컵·연필 소품부터 우선 확인하고, 인물과 배경도 사용 크기에 맞춰 순차적으로 보완한다. 이번 규칙 지정은 기존 원화를 모두 즉시 재생성하라는 뜻이 아니다. 이미 승인된 v3 구도·화풍을 기준으로 부분 개선한다.

현재 저장소에는 PNG 원본과 분리 레이어가 있으며 편집용 PSD는 아직 없다. 앞으로 PSD를 제공할 때는 위 레이어 기준을 적용한다.

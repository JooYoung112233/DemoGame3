# 챕터 1 E07~E11 · 길을 묻고 새 사진을 남기기

> 2026-09-11 적용: [최신 콘티 R12~14](../../00-제작관리/CH00-01-TRUTH-REVISION-STORYBOARD.ko.md). 길 질문은 캠프 방향을 확인하는 목적이다. 세진은 소이 소개 후 한 번 짧게 머뭇거리는 반응 후보를 두되 수혁에게 답한다. 첫 사진은 기존 style-v2 풍경을 유지하고 즉시 진실을 드러내지 않는다. 정확한 소개·반응 대사는 사용자 대사집 작업으로 남긴다.

2026-09-10 제작 콘티 초안. [25개 이벤트](CHAPTER01-EVENT-QUEST-DRAFT.ko.md)의 번호를 따른다. 첫 그림에서 생긴 다음 장소에 대한 관심과 챕터 0의 사진 바람을 연결한다. 아래 시간은 연출 후보이며 구현·플레이 시간 실측값이 아니다. 대사는 의도만 기록하고 문장·표정은 대사집에서 확정한다.

## 재진입·저장 계약

- 가방 선발견: 위치 기억만 보관. Q08 수락 후 같은 선반에서 회수하며 새 가방을 생성하지 않는다.
- 가방 회수 후 이탈: L4는 빈 선반을 유지. 인벤토리와 회수 기록을 함께 저장한다. 추가 탐색 때문에 가방을 다시 찾게 하지 않는다.
- 인수 중 중단: 카메라 지급 전 저장이면 전달 직전부터, 지급 완료 저장이면 인수 반응부터 재개한다. 가방만 사라지거나 카메라가 두 개가 되는 중간 상태를 저장하지 않는다.
- 첫 촬영 중 중단: 촬영 전이면 안내부터, 사진 생성 후면 사진 확인부터 재개한다. 같은 튜토리얼 사진·필름 차감을 중복 처리하지 않는다.
- 앨범 확인 후: Q10 완료 상태로 장면만 다시 볼 수 있다. 사진을 반복 생성하거나 보상을 재지급하지 않는다.
- 출발 E25는 첫 그림·첫 사진·길 정보 조건을 확인한다. 추가 공구·강아지·생활 사건을 모두 해야 떠날 수 있게 만들지 않는다.

이 계약은 개발 명세 초안이다. 실제 저장 트랜잭션·이벤트 처리 코드나 세이브 호환성 검증을 완료한 상태는 아니다.

## 후속 제작 항목

세진 기본 외형 후보·정비 차량·수혁 촬영 자세·첫 사진/앨범 상태를 제작했다. 외형/사진 구도 최종 검토, 세진 정비/전달 자세, 수혁 가방 회수·카메라 인수 자세는 후속이다. 세진이 부탁하는 구체 경위와 카메라를 건네는 사정은 대사집 작업에서 검토한다. 이 미확정 사항을 새 인물 관계나 사건 사실로 임의 고정하지 않는다.

## 최신 원화 납품 기록

[세진·차량 기본 합성](../../../art/chapter01/sejin-v1/README.ko.md)과 [수혁 촬영·첫 사진·앨범 상태](../../../art/chapter01/first-photo-v1/README.ko.md)를 추가했다. 원본 PNG/실제 PSD·좌표·치수를 각 manifest에 저장했다. 풍경만 담는 사진은 구도 제안이며 최종 확정이 아니다. 앨범 그림을 만들었다고 새 획득 퀘스트나 UI를 구현한 뜻은 아니다. 인수 동작과 실제 저장 로직은 여전히 후속이다.

첫 사진은 사용자 화풍 수정 요청에 따라 `first-photo-v1/photo-selection.json`의 style-v2를 현재 검토본으로 사용한다. 구도는 유지하고 묘사 밀도를 줄였으며, 기존 v1은 비교용으로 보존한다. 앨범/인화 PSD에도 같은 수정본을 적용한다.

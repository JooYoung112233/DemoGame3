# E05 전달 → E06 첫 그림 → E07 길 정보

> 최신 원화: [서사 반영 원화 v1](../../05-원화/CH00-01-NARRATIVE-ART-REVIEW.ko.md). 현재 E05~06은 새 소이 앉기, 수혁 앉기·그리기 자세를 사용한다. 수혁이 연필을 잡고 소이는 곁에서 지켜본다. 같은 실제 그림 동작에 소이가 없는 엔딩용 변형도 제작했으며 초반에는 노출하지 않는다. 아래 v2 경로는 원본 이력이다.

> 2026-09-11 적용: [주관/객관 콘티 R11](../../00-제작관리/CH00-01-TRUTH-REVISION-STORYBOARD.ko.md). 실제 첫 그림은 수혁이 그리며 소이와 그리는 현재 네 컷은 수혁의 체험으로 유지한다. 엔딩 회수용 수혁 그리기 자세는 별도 제작이 필요하다. 다음 길은 캠프 방향이고 바다는 가는 동안 보고 싶은 풍경이다. 기존 대사 문장은 이번에 바꾸지 않았다.

2026-09-10 연속 제작 초안. 기존 책과 캠핑카를 유지하고 새 수혁 전달 자세·그림 레이어·네 장면 합성을 추가했다. 정식 대사집과 Unity 실행은 후속이다.

## 컷별 흐름

| 컷 | 화면 / 입력 | 연출 의도와 다음 단계 |
| --- | --- | --- |
| 01 전달 | [색연필을 놓는 장면](../../../art/chapter01/first-drawing-v2/review/01-delivery.png) | 귀환 뒤 소이를 선택. 0.2~0.35초 정도의 짧은 전환으로 수혁이 몸을 숙여 손을 내민 정지 자세. 기존 책 왼쪽에 색연필을 놓은 직후를 표현한다. 물건을 공중으로 이동시키는 애니메이션 없이 종이 케이스 소리와 자세 교체. 새 음향은 미제작 |
| 02 준비 | [도구가 준비된 식탁](../../../art/chapter01/first-drawing-v2/review/02-ready.png) | 수혁의 전달과 소이의 반응을 확인하면 Q05 완료. Q06의 현재 목표는 첫 그림 시작. 새 스케치북을 요구하지 않으며 준비 상태를 저장한다. 사용자가 다음 입력을 할 때까지 기다림 |
| 03 시작 | [그림을 시작한 장면](../../../art/chapter01/first-drawing-v2/review/03-started.png) | 소이의 기존 그리기 정지 자세와 오른쪽 페이지의 첫 파도 흔적. 수혁의 주관적 장면이며 다른 인물이 관찰해 소이의 존재를 확인하는 연출은 없다. 실제 손 그리기 애니메이션·미니게임은 추가하지 않음 |
| 04 완성 | [완성 후 함께 보기](../../../art/chapter01/first-drawing-v2/review/04-complete.png) | 같은 식탁에서 페이지 그림만 바뀐다. 결과를 확인하고 두 사람의 반응까지 읽은 뒤 Q06 완료. 그림이 생겼다는 이유만으로 대화 확인 전에 완료하지 않음 |
| 05 다음 길 | 위 완성 화면을 유지 | 대사집 의도: 바다 그림을 계기로 앞으로 가 보고 싶은 풍경을 떠올린다 → 수혁은 그쪽 길이 통하는지 알아볼 필요를 느낀다 → 주유소에서 지역 길 정보를 구하는 Q07로 연결. 연료 부족·세진의 이름을 미리 설명하지 않음 |

기존 시안의 바다 그림을 **앞으로 가 보고 싶은 장소**라는 내용으로 보강한 검토안이다. 이미 바다에 다녀왔다고 말하지 않는다. 가족사진·실종·엔딩을 그림 안의 사람 수로 확정하지 않는다. 정식 그림 내용과 대사는 사용자 검토 이후 확정한다.

## 화면과 원본

- [원화 manifest](../../../art/chapter01/first-drawing-v2/manifest.json): 네 상태의 PNG·배치 PSD, 원본 치수, 재사용 자세와 새 자세 구분.
- 수혁: 새 전달 자세 1086×1448 원본. [실제 분리 PNG](../../../art/chapter01/first-drawing-v2/layers/suhyeok-place-pencils-native.png)와 [원본 PSD](../../../art/chapter01/first-drawing-v2/psd/suhyeok-place-pencils-native.psd). 목표 인물 높이에는 미달한다. 식탁 가림용 손 복사 레이어 별도.
- 그림: 1254×1254 실제 알파 생성 원본. [그림 상태 PSD](../../../art/chapter01/first-drawing-v2/psd/sea-drawing-states-native.psd)에 시작·완성을 상호 배타적인 레이어로 보관한다. 시작은 같은 완성 원본에서 첫 파도 영역만 남긴 파생본.
- 책: 챕터 0의 1536×1024 원본을 유지한 [페이지 상태 PSD](../../../art/chapter01/first-drawing-v2/psd/book-page-states-native.psd). 빈 책 위에 그림 레이어만 얹는다. 별개 책으로 다시 생성하지 않았다.
- 조용히 앉아 있는 수혁과 소이의 자세, 소이 그리기 자세는 기존 시안 재사용이다. 모든 인물 포즈를 새로 만들었다고 보고하지 않는다.
- 전체 장면은 1672×941 기존 배경을 사용한다. 물·담요·전원 복구 상태 등 식탁 바깥 영역은 기존 후속 장면과 같은 픽셀이다. 새 배경 조명으로 아침을 완성한 것이 아니다.

그림/책 원본의 큰 합성은 편집 검토용이다. 인게임에서 책을 배경 위에 크게 띄우는 새 연출로 확정하지 않는다. 실제 장면은 고정 식탁을 유지하고, 1.04~1.08배 정도의 소폭 시선 이동만 후보로 둔다. 더 큰 식탁 근접 컷에는 별도 큰 배경 원본이 필요하다.

## 상태 계약

Q05 색연필 보유 → 전달 확인 → Q06 준비 → 시작 → 완성 → 반응 확인 → Q07 길 알아보기. 아이템 전달·도구 보유 갱신·진행 단계는 중복되지 않게 확정한다. 최초 도구는 첫 그림 완료 전에 다른 제작으로 사라져 진행을 막지 않게 한다. 중단·저장 후에는 마지막 확인 단계부터 이어서 안내한다.

첫 그림은 한 번만 보상 기록하며 추가 그림은 선택 활동이다. 날짜가 바뀌어도 튜토리얼을 자동 실패/자동 완료시키지 않는다. 현재 원화 파일과 콘티는 이 흐름의 참고 자료이며 게임 로직 구현은 아니다.

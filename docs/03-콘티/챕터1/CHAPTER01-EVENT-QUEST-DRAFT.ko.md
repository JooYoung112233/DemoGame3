# 챕터 1 · 이벤트 25개와 퀘스트 연결표

2026-09-10 사용자 요청에 따라 첫 주 후보를 **25개 이벤트 / 21개 퀘스트 / 이동 장소 7곳 + 캠핑카 거점**으로 정리했다. 기존 사건을 최신 첫날 흐름에 맞춰 재구성한 초안이다. 25개를 전부 수행해야 하는 일정표가 아니다. 대사·보상 수치·미니게임 규칙·정확한 날짜는 후속 콘티에서 확정한다.

## 중심 흐름과 선택 서사

첫날 낮: **E01 물·식량 확보 → E03 귀환·분배 → E04 요리대 고장 암시 → E05 소이의 색연필 부탁**. E02 쪽지와 다른 진열대 탐색은 선택이다. 수리 완료나 첫 그림을 첫날 낮의 필수 분량에 넣지 않는다.

그 이후: **E05 색연필 전달 → E06 첫 그림 → E07 길을 물으러 간 주유소에서 세진 만남 → E08 가방 회수 → E09 카메라 인수 → E11 첫 사진·앨범 확인 → E25 지역 출발**. 색연필 선확보면 전달부터, 첫 사진 장소를 이미 방문했으면 현재 단계부터 이어 간다.

강아지: **E12 발견·물/먹을 것 두고 기다리기 → E13 경계 완화·동행 선택 → E14 캠핑카 자리**. 별똥이는 배달 퀘스트를 하지 않아도 만날 수 있다. 한 번 클릭으로 영입하거나 같은 물자를 반복 납부하는 구조는 아니다. 지역 안에서는 동행 유보 후 다시 교감할 수 있다.

생활 변화: E04 수리 → E17 요리, E15 누수 → 실제 젖은 경로만 E16 잠자리, E18 찬장 정리, E21 카메라 주머니. 해결한 결과는 캠핑카 소품·소리·정지 자세로 남긴다.

선택 인연: E19 물건의 주인 확인 → 교환처 대화 → E20 꾸러미. 교환처 인물은 세진과 별개의 선택 NPC 후보 1명이며, 추가 인물 제작 부담을 장소 배경 재사용으로 줄인다. E10 추가 공구와 E23 주유는 세진의 카메라 보상을 막지 않는다.

위험: E22 탐색 소음은 결과와 비용을 확정한 뒤 별도 대응 사건으로 연결한다. 미니게임 실패에 고정 연결하지 않고, 최초 탐색 안내가 끝나기 전에는 보류한다. 확률·시간은 미정이며 소리의 정체·감염자 전투를 새로 확정하지 않는다.

## 이벤트별 트리거·장면·퀘스트 변화

### E01 · 오늘 쓸 물

- **발생:** 챕터 0 취침 완료, 첫날 아침, 최초 1회
- **장소 / 유형:** 캠핑카 내부·작은 편의점 / 중심
- **장면:** 캠프행 여정의 첫 보급: 전날 준비 상태를 이어받아 지도에서 편의점 선택 → 암전·정차음 → 물과 식량 탐색.
- **퀘스트:** Q01 생성 → 확보 단계 진행 → 결과 확인으로 완료
- **완료 확인:** 첫 확보 결과를 확인
- **남는 변화:** Q03 귀환·분배로 연결. 캠핑카는 편의점 앞에 주차.
- **분기·예외:** 전날 물이 남은 상태를 인정. 빠른/집중 탐색 선택, 필수 확보분 보장 방식은 밸런스 초안.
- **원화:** HUB·L1 기존 배경, 지도·물자 소품 재사용; 이동은 암전·음향.

### E02 · 지워진 대피 안내

- **발생:** 편의점 계산대 쪽지를 직접 선택
- **장소 / 유형:** 작은 편의점·주유소 정비·주차 구역 / 선택
- **장면:** 지워진 감염자 관련 글과 오래된 지역 대피 안내를 읽는다. 캠프 방송과 같은 시설인지 확정하지 않고 세진에게 유효성을 물을 수 있다.
- **퀘스트:** Q02 읽으면 생성 → 세진의 답을 확인하면 조사 단계 완료
- **완료 확인:** 추가 질문과 아는 범위의 답 확인
- **남는 변화:** 안내의 현재 상태는 미확인으로 남김. 읽은 경로만 귀환 독백에서 언급.
- **분기·예외:** 쪽지를 안 읽어도 세진·다음 지역 진행 가능. 주민센터는 가칭, 별도 배경/확정 대피소를 열지 않음.
- **원화:** 기존 종이·글자·지워짐 분리 PSD; L2 대화 배경 공유.

### E03 · 돌아와 나누는 첫 식사

- **발생:** 첫 편의점 귀환. 물·식량 확보 조건 충족 때 분배 가능
- **장소 / 유형:** 캠핑카 내부 / 중심
- **장면:** 문소리·짧은 암전 → 이동과 안전에 대한 독백 → 수혁이 두 자리 몫을 배정하고 남은 재고 확인. 소이의 독립적 섭취 장면은 만들지 않는다.
- **퀘스트:** Q03 귀환 시 생성 → 분배·반응 확인 후 완료
- **완료 확인:** 분배 결과와 식사 반응 확인
- **남는 변화:** 요리대 고장 암시와 소이의 부탁이 순서대로 가능해짐.
- **분기·예외:** 조기 귀환은 보충 안내만. 물자 상태 유지, 편의점 재입장에 차량 이동 시간을 다시 부과하지 않음.
- **원화:** 기존 물통·통조림과 앉은 인물로 분배 확정 후의 찬 식사 결과 컷 제작. 요리대는 꺼진 상태. 분배 손 애니메이션 대신 확인 뒤 결과로 전환.

### E04 · 불이 붙지 않는 요리대

- **발생:** 첫 분배 뒤 고장 암시. 수리 목표는 요리대를 직접 조사하면 생성
- **장소 / 유형:** 캠핑카 내부·철물·전기 수리점 / 선택
- **장면:** 짧게 고장을 확인하고 이후 수리점 부품으로 손본다. 작동 확인으로 다음 식사의 가능성을 보여 준다.
- **퀘스트:** Q04 고장 조사로 생성 → 부품 확보 → 수리·작동 확인으로 완료
- **완료 확인:** 수리 후 작동 확인
- **남는 변화:** kitchen_repaired=true; E17 조리 가능.
- **분기·예외:** 1일 차 낮에는 암시까지만. 이미 챙긴 재료 인정. 정확한 고장·레시피·비용은 후속.
- **원화:** 고정 요리대 꺼짐 상태와 수리 완료 후 조리 결과 컷 연결. 고장 원인·수리 레시피는 미정, 화염·김은 Unity 효과.

### E05 · 그림을 그리고 싶은 소이

- **발생:** 첫 분배와 요리대 암시 이후 소이를 선택
- **장소 / 유형:** 캠핑카 내부·작은 편의점·생활 잡화점 / 중심
- **장면:** 부탁을 듣고 어제 챙긴 책을 떠올린다. 필요한 것은 색연필뿐이다.
- **퀘스트:** Q05 부탁으로 생성 → 보유 검사 → 전달로 완료
- **완료 확인:** 수혁이 색연필을 전달한 상태 확인
- **남는 변화:** E06 첫 그림 안내 활성. 첫날 낮 콘티는 부탁/다음 목표 제시에서 닫고 전달은 다음 구간.
- **분기·예외:** 선확보면 바로 전달. 미보유면 L3 확정 확보 후보 안내; L1 확률 탐색 재방문 강제 없음.
- **원화:** L3 색연필 소품·획득 전후와 HUB 새 수혁 전달 자세·식탁 준비 상태 제작. 큰 원본과 배치 PSD는 분리 보존.

### E06 · 빈 페이지에 남기는 오늘

- **발생:** 색연필 전달 완료, 기존 책 보유
- **장소 / 유형:** 캠핑카 내부 / 필수 튜토리얼
- **장면:** 수혁이 기존 책에 그리는 행동 → 소이와 함께 보는 체험 → 완성 페이지 확인. 소이는 옆에서 지켜보며 연필·페이지를 독립적으로 움직이지 않는다.
- **퀘스트:** Q06 첫 그림 안내 생성 → 완성·반응 확인으로 완료 / Q07 첫 그림 반응 확인 뒤 길 정보를 찾는 목표 생성
- **완료 확인:** 완성 그림과 소이 반응 모두 확인
- **남는 변화:** 캠프 방향으로 여행을 이어갈 길 정보를 알아보러 L2로 갈 동기를 제시. 바다 그림은 가는 길에 보고 싶은 풍경으로 유지.
- **분기·예외:** 첫 그림은 무작위 재고·미니게임 성공에 잠그지 않음. 추가 그림은 선택.
- **원화:** 새 수혁 그리기 자세·새 소이 앉기와 기존 책/색연필/배경. 실제 상황 회수용 무소이 변형은 초반 비노출.

### E07 · 떠나지 못한 사진기사

- **발생:** 첫 그림 이후 길 정보 안내를 따라 주유소에서 세진을 선택
- **장소 / 유형:** 주유소 정비·주차 구역 / 중심
- **장면:** 수혁은 캠프 방향으로 통하는 길을 묻다가 세진의 카메라에 관심을 보인다. 소이를 소개하는 지점에는 세진이 한 박자 늦게 수혁에게 답하는 작은 반응 후보를 두며, 공구 가방 부탁으로 연결한다.
- **퀘스트:** Q07 지역 밖 길 정보 단계 진행 / Q08 공구 가방 부탁을 수락하면 생성
- **완료 확인:** 길 정보와 부탁 내용을 확인
- **남는 변화:** L4 목적지·공구 가방 목표. 챕터 0 사진 바람을 되받는 반응.
- **분기·예외:** 부탁은 나중에 수락 가능. 먼저 방문했으면 소개만 하고 진행 시 대화 재개. 차량을 오래 비울 수 없는 구체 사정은 대사집 전 확정 필요.
- **원화:** 같은 L2 차량·새 세진 정비 자세·별도 큰 중립 대화 초상 제작. 외형은 검토 후보, 표정은 대사집 이후.

### E08 · 작업대 아래의 공구 가방

- **발생:** Q08 진행 중 가방을 선택. 선발견은 위치를 기록
- **장소 / 유형:** 철물·전기 수리점 / 중심
- **장면:** 세진이 설명한 가방을 확인하고 회수한다. 같은 작업대에서 생활 수리 재료도 살필 수 있다.
- **퀘스트:** Q08 가방 확인·회수 단계 진행
- **완료 확인:** 가방 회수 결과 확인
- **남는 변화:** 세진에게 돌아가 전달할 수 있음. 선택적으로 E10 추가 공구.
- **분기·예외:** 필수 가방은 확정 배치. 주변 추가 재료의 탐색 확률과 분리. 선발견 상태 유지.
- **원화:** 같은 L4 가방 회수 전/후와 새 가방 든 수혁 정지 자세 제작. 행동 컷에서 선반 가방은 제거.

### E09 · 가방 대신 건네받은 카메라

- **장소 / 유형:** 주유소 정비·주차 구역 / 중심

- **남는 변화:** L6 첫 촬영 목표, E21 보관 주머니 선택 가능.
- **분기·예외:** Q09 추가 공구 미완료여도 보상. 재접속/대화 재열람으로 중복 지급 금지.
- **원화:** 같은 카메라를 세진이 건네고 수혁이 받는 두 손 근접 원화·PNG/PSD 제작. 팔은 화면 양쪽에서 들어오는 인서트.

### E10 · 가방에서 빠진 하나

- **발생:** 가방 회수 후 목록을 선택해 확인
- **장소 / 유형:** 철물·전기 수리점·주유소 정비·주차 구역 / 선택
- **장면:** 남은 공구를 더 찾거나 세진에게 현재 가방부터 가져가 대안을 듣는다.

### E11 · 새로운 첫 사진

- **발생:** 카메라·첫 필름 인수 완료, 강변 쉼터 방문
- **장소 / 유형:** 강변 쉼터·캠핑카 내부 / 필수 튜토리얼
- **장면:** 풍경 촬영 안내 → 수혁의 첫 촬영 → 실제 풍경 사진을 앨범에서 확인. 소이와 함께 본 체험과 사진에 무엇이 찍혔는지는 구분한다.
- **퀘스트:** Q10 촬영·앨범 확인으로 완료 / Q07 첫 사진 조건 충족 기록
- **완료 확인:** 첫 사진과 앨범 확인 모두 기록
- **남는 변화:** 첫 주 회고·지역 출발의 중심 조건 충족.
- **분기·예외:** 이미 L6면 그 자리에서 안내. 첫 필름 보장. 현재 style-v2 풍경 사진을 유지하고 첫 장에서 소이 부재를 추리하게 만들지 않는다. 촬영 경험은 이후 현실 확인 서사의 씨앗이며 재열람으로 사진 수를 늘리지 않는다.
- **원화:** L6 촬영 자세·강변 사진 내용·빈 앨범·첫 사진 등록 상태 PNG/PSD 제작. 사진은 풍경만 담는 검토안이며 최종 구도 미확정. 대사/UI/음향 후속.

### E12 · 문밖의 작은 발소리

- **발생:** 낡은 집에서 생활 흔적을 살핀 뒤 작은 소리가 나고 강아지를 선택
- **장소 / 유형:** 낡은 집 / 선택
- **장면:** 별똥이가 거리를 둔다. 수혁이 물그릇이나 먹을 것을 놓고 물러나 기다린다.
- **퀘스트:** Q11 직접 관심을 보이면 생성 → 돌봄·거리 두기 단계 진행
- **완료 확인:** 물을 두거나 먹을 것을 두고 기다린 행동 확인
- **남는 변화:** dog_care_offered=true; 차분해진 뒤 E13 가능.
- **분기·예외:** 지나쳐도 주요 진행 영향 없음. 필요한 돌봄 물자는 최소 확보 경로 제공; 소중한 필수 식량 전량을 요구하지 않음.
- **원화:** 경계·물 놓는 새 수혁 자세·물러난 결과·먹이 대안 제작. 같은 그릇 외곽을 유지하고 내용물만 교체.

### E13 · 한 걸음 가까워진 별똥이

- **발생:** E12 돌봄 후 별도 관찰/다른 행동이 끝나고 다시 교감 선택

- **장면:** 그릇 가까이 온 별똥이가 수혁을 덜 경계한다. 기다려 주기 → 동행 여부 선택 → 캠핑카 입구의 강아지 정지 컷.
- **퀘스트:** Q11 신뢰 반응 확인 → 동행 수락이면 완료, 유보면 보류

- **분기·예외:** 클릭 연타로 신뢰 수치 반복 적립하지 않음. 날짜 강제/같은 먹이 반복 요구 없음. 유보 후 지역 내 재교감 가능.
- **원화:** 새 안심하고 앉는 개별 원본 및 물그릇 유지 합성 제작. 동행 확인 연출은 콘티로 기록; 걷기 애니메이션 없음.

### E14 · 별똥이의 자리

- **발생:** 동행 후 캠핑카에서 별똥이를 선택

### E18 · 덜컹거리는 찬장

- **장소 / 유형:** 캠핑카 내부·생활 잡화점 / 선택

- **완료 확인:** 보관 소품 상태 확인
- **남는 변화:** 캠핑카에 사진을 찍는 생활의 흔적이 남음.
- **분기·예외:** 미제작 때문에 카메라 무작위 파손 없음. 사진 튜토리얼을 막지 않음.
- **원화:** 빈 천 주머니·카메라 수납 상태와 앞쪽 천 가림 레이어 제작. 개별 카메라 원본 유지.

### E22 · 선반 너머에서 난 소리

- **발생:** 탐색 비용·결과를 확정한 뒤 소음 조건이 충족, 이번 장소 사건 미처리; 최초 탐색 튜토리얼 완료 이후
- **장소 / 유형:** 작은 편의점·생활 잡화점·철물·전기 수리점 / 조건
- **장면:** 물건 부딪치는 소리 뒤 바깥의 불분명한 반응. 잠깐 기다릴지 출입구 밖으로 물러날지 선택한다.
- **퀘스트:** Q20 상황 발생으로 잠깐 대응 목표 생성 → 재탐색 가능 상태 확인으로 완료
- **완료 확인:** 기다리기/물러나기의 대응 확인
- **남는 변화:** 일부 탐색 시간·접근 순서를 고민하는 사건. 감염자 정체나 전투는 확정하지 않음.
- **분기·예외:** 미니게임 실패마다 강제 발생 아님. 확률·추가 시간 후속. 물자 재추첨 금지, 필수 물자 영구 소실 금지.
- **원화:** 기존 장소 배경과 암전·효과음·정지 반응 포즈 공유. 별도 적 원화 불필요.

### E23 · 다음 길의 여유 연료

- **발생:** 주유소에서 연료 설비를 직접 확인
- **장소 / 유형:** 주유소 정비·주차 구역 / 선택
- **장면:** 남은 연료와 계획을 비교하고 원하면 보충한다.
- **퀘스트:** Q21 설비 확인으로 선택 목표 → 보충을 택한 경우 결과 확인으로 완료
- **완료 확인:** 선택한 보충 결과 확인
- **남는 변화:** 다음 이동 여유.
- **분기·예외:** 시작 연료는 충분. 거절·보류해도 사진·세진·지역 출발을 잠그지 않음. 연료 수치 후속.
- **원화:** L2 연료 용기 유무 선택 상태 제작. 조기 연료 부족 설정 없음, 주유 동작은 소리/가림 후보.

### E24 · 이제는 빈 페이지가 아니다

- **발생:** 첫 그림·첫 사진 이후 저녁, 책/사진을 선택, 최초 1회
- **장소 / 유형:** 캠핑카 내부 / 선택 서사
- **장면:** 처음의 빈 책과 새 그림·사진을 천천히 본다. 별똥이 동행 여부, 요리대·누수 보수 등 실제 겪은 일만 짧게 되받는다.
- **퀘스트:** 생성하지 않음. 이 사건을 본 상태만 기록.
- **완료 확인:** 회고를 본 상태만 기록
- **남는 변화:** 다음 풍경으로 떠날 감정적 연결. 새 수집 숙제를 만들지 않음.
- **분기·예외:** 강아지 미동행이면 그 자리는 비워둠. 겪지 않은 사건을 회상하지 않음. 건너뛰어도 출발 가능.
- **원화:** 실제 첫 그림과 첫 사진을 함께 보는 HUB 상태, 강아지 동행 조건 변형 제작. 미경험 사건을 회상하지 않음.

### E25 · 다음 동네로 가는 길

- **발생:** 첫 그림·첫 사진 완료, 세진의 길 정보 보유, 출발 시점 선택
- **장소 / 유형:** 고갯길 입구·캠핑카 내부 / 중심
- **장면:** 캠프 방향으로 계속 이동하기 위한 고갯길 통제 안내 확인 → 알려진 우회로 선택 → 미완료 선택 사건과 준비 상태 확인 → 암전·출발.
- **퀘스트:** Q07 도로 확인·실제 다음 지역 진입으로 완료
- **완료 확인:** 다음 지역 진입과 이어갈 상태 저장
- **남는 변화:** 그림·사진·소지품·수리 상태·동행을 다음 챕터로 유지.
- **분기·예외:** Q02 안내·강아지·수리·주유·배달 전부 완료 요구 금지. 날짜만으로 미완료 튜토리얼 자동 실패시키지 않음.
- **원화:** L7 고정 배경에 오르막 차단물 분리. 왼쪽 우회로 유지. 출발 이동은 암전·음향 후보.

## 인게임 연결 규칙 · 구현 전 계약

1. **이벤트 상태와 퀘스트 상태 분리.** 이벤트는 잠김 → 발생 가능 → 재생/행동 중 → 처리 완료, 퀘스트는 미발견 → 제안 → 진행 → 완료를 기본으로 삼는다. 유보·거절은 완료와 구분한다. 거절 후 재제안은 Q11 등 허용된 퀘스트에만 적용한다. 일시 대응과 지속 수리는 별도 결과 상태다.
2. **발견과 수락 구분.** 소리를 들었다고 선택 수리·배달 퀘스트를 모두 자동 등록하지 않는다. 직접 조사하거나 부탁을 수락한 시점에 생성한다. 첫 그림·첫 사진은 필수 안내지만 사용자 입력과 결과 확인을 기다린다.
3. **현재 행동으로 이어지는 목표.** 색연필을 이미 갖고 있으면 '구하기' 단계를 충족시키고 '건네기'를 제시한다. 이미 가 본 장소라도 필요한 사건을 수행했는지는 별도로 검사한다. 퀘스트 생성 때도 현재 재고·완료 상태를 재검사한다.
4. **지급·차감·완료는 중복되지 않게 저장.** 가방 전달, 카메라 인수, 첫 그림/사진 획득 등은 하나의 확정 작업으로 기록한다. 중간 종료 후 지급만 반복하거나 재료만 여러 번 사라지지 않게 한다. 대사 다시 보기와 보상 실행을 분리한다.
5. **한 번에 새 주요 사건 하나.** 대화·분배·촬영이 진행 중이면 새 사건은 끝난 뒤 제안한다. 첫날 낮에는 요리대 수리 의뢰를 바로 길게 띄우지 않고 고장 암시 뒤 소이에게 집중한다. 같은 대기 사건은 중복 등록하지 않는다.
6. **유동적인 상호작용.** 완료한 탐색은 소진 상태, 수리한 요리대는 조리, 동행 후 강아지는 휴식·교감으로 바뀐다. 장소의 모든 소품에 항상 느낌표를 달지 않는다. 현재 집중 목표 1개와 선택 관심거리 1개 정도를 시작 기준으로 검토하되 나머지 수락 목표를 삭제하지 않는다. UI 배치는 Unity 단계다.
7. **조건 사건은 조건이 사라지면 재검사.** 누수가 해결됐다면 누수 대화를 재생하지 않는다. 소음 사건은 탐색 확정 후 제안하되 첫 탐색 튜토리얼을 끊지 않고, 일시 이탈 뒤에도 물자 결과·비용을 유지한다. 장소당 최초 사건 처리 여부를 저장한다.
8. **지도 해금과 단서 확신 구분.** 쪽지의 가칭 대피구역은 안전한 목적지가 아니다. 쪽지·배달을 생략해도 기본 생활 지도와 세진의 정보로 주요 장소를 방문할 수 있다. 세진 미소개 시 이름표는 ?, 이름을 알게 된 뒤 세진으로 바꾼다.
9. **소이와 기억의 표현 유지.** 제3자가 소이를 확인하는 새 연출을 넣지 않는다. 서연의 편지는 챕터 3으로 유지하고, 공개 안내·보관 메모와 섞지 않는다. 가족사진의 얼굴·지지직 효과를 모든 사건에 반복하지 않는다.
10. **첫 주 종료 조건.** 첫 그림·첫 사진·길 정보가 중심 조건이다. 강아지, 수리, 날씨, 선택 NPC, 주유, 쪽지 완료는 필수가 아니다. 날짜 초과로 튜토리얼을 자동 실패시키지 않는다. 지역 이탈 전 미완료 선택 기회를 알려주며 이후 재방문 정책은 아직 미정이다.

숫자 밸런스, 이동·탐색 시간, 반복 생활 행동의 비용, 재료 레시피, 실제 저장 구조는 확정 전이다. 위 JSON의 문장형 조건을 런타임 판정식으로 간주하지 않는다.

## 다음 제작 순서

첫 그림 네 상태·신규 장소 다섯 빈 베이스·공구 가방/카메라/필름을 제작했다. 세진 기본 인물·정비 차량 시안, 별똥이 개별 세 자세·물그릇·깔개, 첫 촬영 자세·사진/앨범 상태까지 추가했다. 다음은 건네고 받는 손, 수혁의 물 놓기, 생활/출발 소품과 최종 해상도를 보강한다. 장소 배경은 [제작표](../../05-원화/CH01-LOCATION-ART-PLAN.ko.md)의 빈 베이스를 먼저 고정하고, 사건 소품과 인물을 얹는다. 이벤트 기획 전체의 Unity 구현은 후속이다. 원화 납품 상태는 장소 제작표를 따른다. L3 빈 베이스·가림용 PSD와 색연필 분리 원화·획득 전후 합성은 별도로 제작했다. 수혁 전달 자세·첫 그림 페이지·식탁 네 상태를 추가했다. [세진 사건 상세 콘티](CH01-E07-11-PHOTOGRAPHER-STORYBOARD.ko.md)에 부탁·회수·인수·첫 촬영의 전환과 저장 계약을 추가했다. 다른 생활 소품은 후속이다.

## 원화와 적용 기준

[원본 PNG·레이어 PSD·치수](../../../art/chapter01/dog-v2/README.ko.md), [정확한 상태별 좌표](../../../art/chapter01/dog-v2/manifest.json)를 사용한다. 모든 좌표는 고정 1672×941 원본 기준이며 Unity 기준 화면은 1920×1080이다. 변환은 개발 단계에 적용한다. 배경 → 바닥 그림자 → 깔개/그릇 → 강아지 접촉 그림자 → 강아지 순서로 필요한 레이어만 켠다.

[새 물 놓기 자세](../../../art/chapter01/completion-v1/review/E12-L5-place-water.png)와 [먹이 대안](../../../art/chapter01/completion-v1/review/E12-L5-food-alternative.png)을 추가했다. 손을 놓은 정지 자세 다음에는 기존 물그릇 유지 컷에서 수혁을 빼 거리 두기를 표현한다. 기존 조사 자세를 모든 컷에 반복해서 얹지 않는다. 움직임 없이 위치를 교체할 때는 짧은 가림과 반응을 사용하되 실제 타이밍은 Unity에서 조절한다.

## 재진입과 분기

- 물자를 갖고 있지 않으면 나중에 돌보기로 남기고 기본 생존에 필요한 재고 전량을 요구하지 않는다. 최소 확보 경로는 물자 밸런스와 함께 연결한다.
- 물을 놓은 뒤 떠나면 같은 그릇·돌봄 기록을 유지한다. 다시 선택하는 것만으로 자원을 반복 차감하지 않는다.
- 동행 확인 전 중단은 D06, 동행 확정 후 중단은 귀환/생활 상태에서 재개한다. 집과 캠핑카에 동일 강아지가 동시에 남지 않게 한다.
- 이미 천을 가지고 있으면 직접 마련 단계로 진행한다. 정해진 상점 재방문을 강제하지 않는다.
- 강아지를 만나지 않은 경로에서는 자리·강아지 대사·이름을 먼저 노출하지 않는다.
- 물 대신 먹을 것을 놓는 분기는 completion-v1의 먹이 상태를 사용한다. 기존 그릇 외곽을 유지하고 내부만 교체하며 물과 먹이를 동시에 요구하지 않는다.

이 문서는 사건/저장 설계이며 실제 코드·타이머·확률·음향을 구현한 것은 아니다.

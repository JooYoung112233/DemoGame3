2026-09-10 **검토용 상세 콘티 v1**. 현재 시안의 “내일도 여기 있어?” 다음 구간이다. 대사 근거는 `CHAPTER00-STORYBOARD-v02.ko.md` 컷 09~11. 아래 시간·입력·화면 연결은 신규 초안이다. 기존 실행 시안에 아직 연결하지 않았다.

장면의 역할: 소이의 질문에 플레이어가 처음 자신의 말투로 답한다. 빈 페이지를 함께 보고 떠날 이유를 만든 뒤 내일 가져갈 물건 준비로 이어진다. 바다나 특정 목적지를 여기서 확정하지 않는다.

## 진입·공통 규칙

- 진입: `C0-03-D02` 소이 “내일도 여기 있어?”를 끝까지 읽은 상태. 수혁·소이는 앞선 대사로 이름이 공개되어 있다.
- 같은 캠핑카와 좌석을 계속 사용한다. 서연 초상·사진·지지직·새 회상을 끼워 넣지 않는다.
- 텍스트는 기존 0.055초/글자를 시작값으로 사용하고 설정값을 우선한다. 출력 중 입력은 문장 완성만, 완성 뒤 새 입력으로 다음 단계. 대사를 자동으로 넘기지 않는다.
- 선택 시간 제한 없음. 선택지 출현과 선택 확정에 같은 입력을 재사용하지 않는다. 스페이스/클릭 연타가 다음 대사까지 넘기지 않게 소비한다.
- 모든 시간은 해당 단계 진입 기준의 제안값. 읽기 대기는 고정 초로 계산하지 않는다. 움직임 줄이기에서는 카메라 이동을 생략하고 0.15초 내외 디졸브로 대체한다.

첫 선택은 말투 차이다. 두 선택 모두 소이의 바람을 듣고 같은 준비 단계로 이어진다. 수치 보상·정답 표시·한 선택에만 좋은 부모처럼 반응하는 차이는 넣지 않는다. 추가 후속 대사를 지어 분량을 늘리지 않고 기존 대사를 먼저 연결해 본다.

## 상태·재개·합류

- 선택 확정 시 `opening_reply = curiosity | destination`. 미선택은 `null`. 엔딩 수치나 관계 점수에 연결하지 않는다.
- 책 대화 두 문장을 모두 확인한 뒤 `blank_page_seen = true`.
- 출발 결정의 마지막 대사를 확인한 뒤 `departure_decided = true`와 `preparation_unlocked = true`를 같은 완료 경계에서 기록한다.
- 현재 `cut_id`, `line_id`, 이미 확정한 선택, 확인 완료된 문장을 저장한다는 구현안. 선택 화면에서 재개하면 미선택 유지, 선택 후 재개하면 선택 결과 대사부터 이어 간다. 이때 선택을 다시 요구하거나 완료 상태를 중복 반영하지 않는다.
- 두 분기는 03에서 합류. 양쪽 모두 동일 책·준비 단계에 도달한다. 준비 진입 시 물·담요가 남아 있고 책은 아직 식탁에 있어야 한다.
- 본편 1일 차 목표는 준비 때 확인할 물 재고에서 생긴다. 이 구간에서 갑자기 긴급 연료 부족이나 새로운 위협을 만들지 않는다.

검토 후 다음 묶음은 **물·담요를 챙기는 순서 두 가지와 두 번째 물건을 챙긴 뒤 한 번 꺼지는 실내등**이다. 상세 시간·연출·대사 초안은 개별 검토를 거쳐 연결한다.

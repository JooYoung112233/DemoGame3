# C0-02 · 멈춘 발소리에서 대화로

> **현재 우선 규칙:** [서연 초상 비표시·현재 대화](C0-PRESENT-DIALOGUE.ko.md), [소개 전 화자 이름표 ?](../../06-대사/SPEAKER-IDENTITY-RULES.ko.md). 아래 이전 초상·실명 표시 설명보다 우선한다.


> **최신 실행 흐름:** [사진 회상 실행 콘티](C0-PHOTO-MEMORY-IMPLEMENTATION.ko.md). 사진 진입→엄마의 질문·소이의 답→같은 사진 복귀→서연 얼굴 소실·짧은 지지직→현재 소이 “아빠?”까지 시안 제작. 아래 이전 마지막 대사·현재 복귀 미제작 표기는 이 문서로 대체한다.


> 후속 논의안: [폴라로이드 → 산책 회상 → 선명한 같은 사진](C0-PHOTO-MEMORY-REVISION.ko.md). 사용자가 사진을 회상의 계기로 추가하고, 돌을 뺀 서연의 질문과 소이의 답을 넣자고 제안했다. 아직 현재 브라우저에는 반영하지 않았다.

사용자 채택: “발멈출때 … 밑에 나레이션처럼 대사창 … 배경은 유지한채로 다이얼로그 … 미연시처럼” → “그방향으로 진행해보자”. **같은 배경과 하단 창으로 나레이션에서 인물 대화로 이어지는 흐름을 채택**했다. 아래 문구·초 단위 수치·새 인물 외형·UI 세부 배치는 현재 검토 시안이다.

이전의 서연·소이 전신 즉시 공개 시안은 이 흐름으로 대체한다. 기존 모녀 원화는 삭제하지 않고 참고 자료로 남긴다. 카메라 3.5%/1.2초, 첫 부름 딤 0.4초와 글자 간격 0.11초는 채택값을 유지한다.

문장마다 읽기 대기는 무제한이다. 타이핑 중 새 클릭/Space는 현재 문장 전체 표시까지만 하고, 다음 새 입력으로 다음 문장에 진입한다. 인물/창 진입 시간과 회상 전환 중 입력은 다음 대사로 통과시키지 않는다. Space 반복 입력은 소비한다. 처음으로/다시 재생은 타이틀로 돌아가며, 진행 막대는 현재 구간 또는 현재 문장 시간을 검토한다.

모든 문구·이름표·타이핑·블러·페이드·카메라 움직임은 **Unity 6.6에서 실행할 요소**다. 브라우저는 배치·순서를 확인하는 참고용이다. 원화에 문구나 대사창을 굽지 않았다. 음성·발소리는 미제작이다.

## 검증·다음 검토

`tools/build-memory-dialogue-assets.py`: PSD 재읽기, 실제 채널·레이어·좌표·가시성, 투명 모서리·인물 내부 검사 24개 통과. `tools/test-memory-dialogue.mjs`: 나레이션 대기·글자 경계·진행 표시·화자 데이터 검사 25개 통과. Photoshop 앱과 Unity 실행 검증은 아직 하지 않았다. 밝고 어두운 바탕의 알파 검수 이미지도 원화 폴더에 저장했다.

우선 확인할 것은 **발 배경에서 나레이션을 읽고 같은 창으로 서연과 대화가 이어지는 느낌**이다. 서연 외형, 두 초상의 크기와 시선, 나레이션 문구는 이 시안을 보고 다듬는다. 기존 `opening-v1` 고정 보관본은 수정하지 않는다.

합성 검수 이미지: `design/ui/ch00-01/review/C0-02-narration.png`, `C0-02-seoyeon.png`, `C0-02-response.png`(모두 1920×1080). 원화 레이어를 배치한 참고 이미지이며, 분리 원본을 대체하지 않는다.

## 손잡기 구도 수정 v2

사용자 피드백: 기존 세 손 포개기 컷이 손을 건네받기보다 세 사람의 화이팅처럼 보임. 대화 이후 수혁과 소이 두 손만 자연스럽게 잡은 결과 컷으로 변경했다. 서연은 손을 놓고 화면 밖에 있으며, 건네는 중간 동작은 생략한다. 새 정지 컷은 `hands-held-review-v2.png`, 실제 분리 원화는 `hands-held-v2.png`, 원본은 `hands-held-source-v2.png`, 편집 파일은 `hands-held-layers-v2.psd`(모두 `art/chapter00/memory/dialogue-v1/`)다. PSD는 원본 숨김·기존 길 배경·두 손 접촉 그룹의 3레이어이며 손가락별 분리는 아니다. 원본 1672×941이며 큰 원본 목표에는 미달한다. 기존 세 손 원화는 이력으로 남기지만 현재 재생에서는 쓰지 않는다. 새 두 손 컷은 사용자 검토 대기다.

## 다음 구간 · C0-02-D04 “됐어. 이제 가자.”

사용자 “다음해볼까”에 따라 기존 글 콘티 컷 04를 연결했다. 이번 구현은 서연의 마지막 대사까지이며, 현재 캠핑카로 돌아오는 컷은 아직 연결하지 않았다. 타이밍·새 배치는 사용자 검토 대기다.

1. 수혁의 “응.”을 읽고 새 클릭/Space를 입력한다.
2. 수정한 두 손 컷이 0.3초 동안 드러나고, 0.8초 동안 대사창·초상 없이 유지된다. 전체 1.1초. 이 무대사 구간은 자동으로 이어진다.
3. 같은 손 이미지를 유지하며 하단 공통 패널이 0.25초, 기존 오른쪽 서연 초상이 0.3초 동안 다시 나타난다. 배경 블러 5px도 0.3초 동안 적용한다. 손 그림 자체를 다시 만들거나 확대 이동하지 않는다.
4. 0.3초부터 서연의 “됐어. 이제 가자.”를 0.055초 간격으로 출력한다. 신발의 돌 때문에 멈춘 앞선 행동을 마무리하는 수정 대사다.
5. 글자 출력 중 새 입력은 문장 완성만 한다. 완성 후에는 서연과 잡은 손 배경을 그대로 유지하며 이번 시안을 종료한다. 아직 다음 컷이 없으므로 진행 화살표를 숨겼다. 추가 클릭으로 대사가 재시작되거나 현재 장면으로 넘어가지 않는다.

기존 서연 기본 초상을 재사용했다. ‘웃는 표정’ 새 원화를 제작한 것은 아니며, 표정·시선 보강은 대사집과 외형 확정 후 작업한다. 새 PNG/PSD 원본은 필요 없고, 기존 분리 원화와 `C0-02-dialogue.psd`를 그대로 사용한다. 문구·연출은 Unity 6.6 런타임에서 구현한다.

- 실제 문구/배치: `design/ui/ch00-01/memory-dialogue.json`의 `C0-02-D04`.
- 합성 참고: `design/ui/ch00-01/review/C0-02-closing.png`(1920×1080), 재생 시안은 기존 URL.
- 재현: `tools/render-memory-closing-preview.py`. 기존 원화의 표시용 합성이며 신규 고해상도 원본이 아니다.
- 검토 페이지의 **이번 구간 보기**는 두 손 컷부터 바로 재생한다. 게임 안의 버튼이나 건너뛰기 기능을 확정한 것이 아니다.

다음 검토는 서연 대사 뒤 현재의 책 위 손으로 돌아오는 전환이다. 수정한 손 컷은 기존 현재 손과 팔 방향이 다르므로 정확한 형태 일치 전환으로 확정하지 않는다. 해당 구도를 함께 확인한 뒤 연출을 정한다.

### 대사 인과 수정

사용자가 소이가 칭얼거리거나 걷기를 힘들어한 적이 없는데 “조금만 더 걷자”가 갑작스럽다고 지적했다. 기존 글 콘티의 해당 문장을 그대로 연결한 것은 현재 장면의 멈춘 이유와 맞지 않았다. “됐어. 이제 가자.”로 수정하고, 손 클로즈업 동안 서연이 화면 밖에서 신발의 돌을 해결한 뒤 말하는 흐름으로 기록한다. 소이의 칭얼거림이나 피로를 새로 추가하지 않는다. 신발 동작·소리 자산을 새로 제작한 것은 아니다. 수정 문구는 사용자 검토 대기다.

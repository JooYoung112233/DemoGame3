# Live49 · 시작 화면과 챕터 0 v0.4

> 최신 연결 검토: [챕터 0 개연성·볼륨 보강](CH00-CONTINUITY-AND-VOLUME.ko.md). 현재 질문 뒤 첫 응답→준비→정전·복구→책·저널→취침→1일 차 아침까지 후속 검토판을 연결했다. 아래 미연결/미작성 서술은 이전 제작 이력이며, 새 대사는 아직 사용자 확정 전이다. 실제 원화 보강·음향·Unity 구현은 남아 있다.

> 2026-09-10 개편: [챕터 0~1 감염자 개편안](../../05-원화/CH00-01-INFECTED-REVISION.ko.md)을 함께 적용한다. 손 회상·소등·복구·취침은 유지하며 감염자의 상세 설정은 사용자 작성 대기다. 시작 화면은 아래 후속 연출 기준을 유지한다.

> 시작 화면 후속 수정: 여행을 미리 드러낸다는 사용자 피드백에 따라 아래 캠핑카 전경·‘새 여행’·외관 기반 엔딩 메뉴 변형안은 보류한다. 최신 시작 화면 제안과 가능한 연출은 [연출 정리](../../08-UI연출/DIRECTION-TOOLKIT.ko.md)를 따른다. 소등 사건의 방향은 유지한다.

> 편집 배치 추가: 시작 입력의 소리 선행, 회상에서 현재로 돌아오는 손 매치 컷, 물·담요 준비 완료 몽타주를 우선 제작 후보로 둔다. 소등 대화의 분할 화면은 비교 시안, 담요의 추가 기억 삽입은 본편 후보로 보관한다. 컷 구성·필요 자산·입력 규칙은 [연출 정리 6절](../../08-UI연출/DIRECTION-TOOLKIT.ko.md#6-컷을-연결하는-편집-연출--적용-후보)을 따른다. 아직 구현된 효과는 아니다.

2026-09-09. 사용자 승인 방향: 캠핑카 실내등이 꺼지는 사건을 넣어 실제 첫 플레이 약 15분을 목표로 한다. 의미 있는 시작 화면도 함께 설계한다. 아래 대사·소등 원인·메뉴 연출은 신규 제안이며 글 콘티 단계다. 기존 v0.3 시간 배분을 대체한다.

## 하나로 이어지는 세 장면

시작 화면에서는 멀리 보이는 캠핑카 불빛이 머물 곳처럼 보인다. 프롤로그에서는 그 불이 꺼져 플레이어가 직접 다시 켠다. 잠들 때는 자신의 선택으로 불을 끈다. 같은 어둠이 처음에는 불안, 마지막에는 쉴 수 있는 밤이 된다.

서연에게 소이의 손을 건네받는 회상과 엔딩의 손 구도는 유지한다. 손은 인물 관계를, 불빛은 그 관계가 머무는 공간을 맡는다. 서연의 얼굴 등장은 도입의 짧은 기억에 한정한다.

## 시작 화면 · 아직 불이 켜져 있는 곳

밤의 길가에 멈춘 캠핑카를 멀리서 본다. 차는 화면 오른쪽 아래, 창의 작은 주황빛이 중심이다. 왼쪽 어두운 여백에 ‘Live49’, 그 아래 ‘마지막 여름’과 메뉴를 둔다. 내부 인물 실루엣과 인원수는 보여주지 않는다. 첫 화면부터 두 별·빈 의자·추모 문구를 강조하지 않는다.

움직임은 풀과 커튼의 미세한 흔들림 정도. 바람, 차체의 작은 소리, 실내에서 새어 나오는 낮은 생활음이 들린다. 도입 회상과 같은 짧은 음악 동기를 사용할 수 있으나 실제 음악은 미제작이다. 49를 감소시키는 숫자 효과는 없다.

| 메뉴 | 행동 |
| --- | --- |
| 이어하기 | 저장이 있을 때만 표시. 현재 저장의 안정된 장면으로 복귀 |
| 새 여행 | 저장이 없으면 가장 먼저 선택됨. 메뉴가 사라지고 불빛으로 천천히 접근한 뒤 암전. 서연의 ‘수혁아’로 회상 시작 |
| 설정 | 음량·글자 크기·텍스트 속도·움직임 줄이기. 설정을 닫으면 선택 위치 유지 |
| 종료 | 게임 종료 |

‘새 여행’은 이름만 시적으로 바꾸되 기능은 명확하게 유지한다. 기존 저장을 덮어써야 할 때만 확인하고, 초기 선택은 취소에 둔다. 가능하면 새 저장 슬롯을 사용한다. 메뉴 진입에는 대기를 요구하지 않으며 연출 전환은 건너뛸 수 있다. 음소거 상태에서도 서연의 첫 말은 자막으로 보인다.

### 이야기를 마친 뒤의 화면

엔딩 미완료 상태에서는 기본 밤 화면을 유지한다. 완료 후 그 엔딩의 화면을 해금하는 제안이다. 게임 진행 중의 엔딩 가능성을 메뉴 변화로 누설하지 않는다.

| 완료한 이야기 | 해금 화면 | 의미 |
| --- | --- | --- |
| 내일을 위한 씨앗 | 같은 구도의 새벽. 캠핑카 창에 아침빛이 닿고 여행의 스케치북은 보관된 소품으로 가까이 보임 | 남겨진 기억과 이어지는 시간 |
| 영원한 여행 | 같은 구도의 밤. 실내등은 꺼져 있고 길과 차에는 자연광이 남음 | 여행이 멈춘 뒤에도 남는 장소. 가족의 사망 순간이나 환영을 메뉴에서 반복하지 않음 |

여러 엔딩을 완료했다면 설정에서 해금된 배경을 고른다. 기본 밤 화면도 유지한다. 메뉴 밝기·가독성은 배경 변화와 무관하게 보장한다. 엔딩 화면은 본편 사건을 대신하는 추가 결말이 아닌 상징적 메뉴 그림이다.

## 프롤로그 사건 순서

1. 기존 컷 01~05: 서연의 기억과 손을 건네받는 행동.
2. 현재 캠핑카: 컵을 잡는 손, 서연의 부재, 소이와 짧은 대화. 창문·약병은 선택 조사로 줄여 도입의 필수 클릭을 과도하게 늘리지 않는다.
3. 소이의 책을 살펴보고 내일 떠나기로 결정한다.
4. 물과 담요를 챙기던 중 실내등이 꺼진다. 스케치북은 아직 식탁에 있다.
5. 빛을 확보하고 원인을 확인한 뒤 실내등을 다시 켠다.
6. 밝아진 식탁에서 책을 챙기고 저널을 쓴다.
7. 소이에게 아침에 함께 보자는 약속을 하고, 플레이어가 램프를 꺼 취침한다. 1일 차로 연결한다.

## 소등 사건 · 돌아오는 불빛

소등은 두 번째 준비 물건을 챙긴 뒤 한 번 발생한다. 물과 담요 순서는 자유다. 우연 확률이나 실패 판정이 아니다. 원인은 노후한 실내등 전원 연결이 헐거워진 것으로 제안하며, 수혁이 간단히 확인 가능한 캠핑카 저전압 조명 설비라는 설정이다. 위치와 장치 외형은 기존 배경 검토 후 정한다.

| 단계 | 플레이·장면 | 대사 초안과 결과 |
| --- | --- | --- |
| 1. 꺼짐 | 불이 한 번 약해졌다 꺼진다. 반복 점멸 없음. 창밖의 약한 빛으로 공간 윤곽과 UI가 보인다 | 소이 “아빠?” 수혁 “여기 있어.” 효과음은 짧은 딸깍 소리, 놀라게 하는 폭음 없음 |
| 2. 먼저 대답하기 | ‘소이에게 말하기’ 선택. 대사 뒤 수납함이 조사 가능해진다 | A “움직이지 마. 내가 불 켤게.” → 소이 “응. 여기 있을게.” / B “놀랐지? 잠깐만 기다려.” → 소이 “갑자기 안 보여서.” 둘 다 정상 진행 |
| 3. 작은 빛 | 수납함 확인 → 손전등 꺼내기 → 켜기. 위치는 텍스트와 표시로 안내 | 수혁 내면 “여기 뒀는데… 있다.” 손전등 빛이 좁게 켜져 다음 조사 대상을 찾을 수 있음 |
| 4. 어디가 문제인가 | 손전등으로 실내등 스위치와 조명 전원부를 조사. 순서는 자유. 스위치만 누르면 즉시 해결되지 않음 | 스위치: “스위치는 괜찮아.” 전원부: “이쪽 연결이 헐거워졌네.” 두 조사 결과가 ‘전원 연결 확인’ 행동으로 합쳐짐. 드래그로 작은 부품을 찾는 정밀 조작 없음 |
| 5. 어둠 속의 대화 | 수혁이 전원을 끈 상태에서 연결을 확인하는 정지 포즈. 소이에게 답하는 동안 행동은 화면에 유지 | 소이 “엄마도 어두운 거 싫어했어?” 수혁 “잘 때도 작은 불은 켜 뒀어.” 소이 “무서워서?” 수혁 “네가 깨면 얼굴 보려고.” 소이 “그럼 아빠도 보였겠다.” 수혁 “응. 나도.” |
| 6. 확인 | ‘연결 고정하기’ 클릭 → 정리된 상태. ‘실내등 켜기’ 클릭 | 타이밍 판정·실패·물품 소모 없음. 관계 대사를 읽은 뒤 바로 조작 가능. 실제 회로 퍼즐로 확장하지 않음 |
| 7. 돌아온 공간 | 같은 베이스의 따뜻한 조명 복귀. 소이가 앉은 식탁 쪽 구도로 전환 | 소이 “이제 보여.” 수혁 “뭐가?” 소이 “아빠 얼굴.” 수혁 “아까도 여기 있었어.” 소이 “알아.” |
| 8. 준비 재개 | 손전등을 수납함에 돌려놓고 식탁의 책을 챙긴다 | 수혁 내면 “아침에 한 번 더 봐야겠다.” 본편에 확인 메모만 남김. 반복 수리 과제를 자동으로 추가하지 않음 |

이 사건의 결과는 점수보다 공간의 변화다. 처음에는 넓고 따뜻하던 실내가 좁은 손전등 빛으로 바뀌고, 다시 익숙한 자리로 돌아온다. 소이는 현재 물건을 건네거나 전원을 켜지 않는다. 모든 물리적 조작은 수혁이 수행하므로 두 엔딩의 시점 규칙을 유지한다. 서연은 이 대화에서 기억되지만 새로운 환영으로 나타나지 않는다.

## 끝에서 다시 끄는 불

불이 켜진 뒤 스케치북을 챙기는 기존 대사를 유지한다. 저널에는 선택한 첫 문장과 함께 “실내등 연결을 확인했다. 물과 담요, 스케치북을 챙겼다.”가 남는다. 선택은 엔딩 수치에 영향을 주지 않는다.

> 소이: “아빠가 먼저 일어나면 깨워줘.”
> 수혁: “알았어.”
> 소이: “혼자 먼저 보지 말고.”
> 수혁: “같이 보자.”

목적이 ‘불을 끄고 쉬기’로 바뀐다. 플레이어가 끄면 주변 윤곽이 부드럽게 사라진다. 고장 때와 달리 대사·환경음이 편안하게 이어진다. 내면 “아직, 같이 가고 싶은 곳이 있다.” 이후 작품명·1일 차로 전환. 타이틀 메뉴로 돌아가지 않는다.

## 실제 15분 검증 계획

기존의 물건 세 개 챙기기 4분 등 시간 배분은 폐기한다. 기존 초안의 6~9분 예상과 신규 사건 분량 모두 실측하지 않았다. 사건을 넣었다는 이유만으로 실제 15분을 달성했다고 보지 않는다.

클릭 가능한 시안에서 메뉴의 ‘새 여행’ 입력부터 1일 차 진입까지 측정한다. 설정·메뉴 체류·앱 비활성 시간은 따로 기록한다. 첫 플레이의 자연스러운 읽기와 탐색 시간을 포함해 13~17분을 목표로 삼는다. 빠른 넘김 경로를 강제로 늘리지 않는다.

구간별로 회상, 현재 대화, 준비, 소등 사건, 기록·취침의 진입·종료 시각을 기록한다. 첫 플레이 관찰에서는 실제 체류와 막힘을 구분한다. 분량이 짧으면 준비·수리 과정의 발견과 관계 반응을 보강하고, 길면 조사 중복과 길 찾기 혼란부터 줄인다. 강제 타이머·느린 텍스트·불필요한 실패 반복은 사용하지 않는다. 본 문서 대사는 핵심 대본이며 전체 15분 대본과 시안 검증은 후속 작업이다.

## 제작·저장 기준

- 시작 화면은 외관 신규 구도 후보 1개가 필요하다. 기존 캠핑카 외형과 창 위치를 기준으로 제작하고 엔딩 변형은 같은 구도로 만든다.
- 실내는 기존 공통 베이스를 유지한다. 낮은 밝기·손전등·복구 후 상태, 수납함과 전원부 확대, 조사 포즈, 손전등·연결 상태 레이어가 추가된다.
- 상태: `departure_decided` → `water_blanket_packed` → `outage_triggered` → `flashlight_on` → `power_checked` → `connection_secured` → `light_restored` → `book_packed` → `journal_written` → `night_complete`.
- 스위치·전원부 조사 상태는 독립 저장하고 둘 다 확인한 뒤 고정 행동을 연다. 소등 이벤트는 재진입해도 재발생하지 않는다. 준비한 물건은 그대로 유지한다.
- 복구 후 자동 저장, 저널 완료 후 자동 저장을 둔다. 중간 저장을 지원한다면 손전등·조사 상태도 복원한다. 프롤로그 스킵은 추후 기능이며 도입 상태 초기화 규칙 없이 추가하지 않는다.
- 확인할 경로: 물건 조사 순서 두 가지, 응답 두 가지, 조사 재클릭, 소등 중 재개, 복구 후 재개, 음소거·움직임 줄이기. 현재 문서 단계로 실행 검증은 하지 않았다.

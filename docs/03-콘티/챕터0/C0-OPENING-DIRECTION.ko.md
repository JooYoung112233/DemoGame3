## 이전 구간 검토 이력

### 후속 피드백 · 인물 공개 전 도입 컷 검토

사용자: “바로 서연, 소이 나오니까 아쉬운데 다른 서사 화면을 좀더 넣어볼까”. 현재 브라우저의 모녀 즉시 등장은 재검토 대상이다. 아래는 새 제안이며 원화 제작·시안 반영·사용자 채택 전이다. D00~D04 채택값은 유지한다.

| 순서 | 제안 화면 | 서사·연출 역할 | 자산 상태 |
| --- | --- | --- | --- |
| 첫 부름 뒤 A | 노을빛 산책길 바닥과 나뭇잎 그림자. 얼굴은 화면에 없음. 1~2초 여백 | 발소리가 멎는 소리 후보로, 사람이 드러나기 전에 함께 걷던 순간을 전달 | 기존 `art/chapter00/memory/memory-path-base-v1.png`에서 구도 검토 가능. 1672×941이므로 확대 원본은 별도 보강 필요. 소리 미제작 |

무대사 여백은 합계 3~5초 안팎부터 검토하되 대사 읽는 시간은 제한하지 않는다. 매 컷 암전 대신 첫 회상 진입만 기존 페이드 후보를 쓰고, 회상 내부는 정지 그림의 컷 전환으로 연결하는 안이다. 글자·소리·카메라·페이드는 실제 Unity에서 처리하며 원화에 굽지 않는다. 새 인물·세계관 설명·편지 공개를 추가하는 제안은 아니다.

### 현재 브라우저 구현 상태

사용자 피드백 **“기본이 좋네”**로 D00~D02 기본안을 채택했다. 카메라 3.5% 확대·1.2초, 시작 지연 0.15초, 메뉴 퇴장 0.08~0.48초를 보존한다. 이전 비교 후보 2%/1.5초와 5%/1초는 채택하지 않았다. 최종 배경 교체 시 초점 검토는 여전히 필요하다.

사용자 피드백 **“좋다”**로 D03~D04 딤·첫 부름의 타이밍도 채택했다. 카메라가 1.35초에 멈춘 뒤 딤이 0.4초에 걸쳐 나타나고, 1.75초부터 `수` → `수혁` → `수혁아` → `수혁아.`를 0.11초 간격으로 출력한다. 문장은 2.08초에 완성된다.

[로컬 미리보기](http://127.0.0.1:8791/design/ui/ch00-01/opening-motion.html)는 **D00~D08 시각 연출**을 재생한다. 새 검토 범위는 다음과 같다.

- 문장 완성 뒤 진행 표시와 `클릭 또는 Space로 계속` 안내가 0.15초 동안 나타난다. 2.23초부터 완전히 보이며 읽기 대기는 무제한이다.
- 타이핑 중 클릭/새 Space는 문장 전체 표시까지만 한다. 새 입력을 다시 받아야 회상 전환이 시작된다. 최초 시작 입력·길게 누른 Space 반복·전환 중 입력이 다음 장면으로 통과하지 않게 한다.
- 읽기 완료 후 새 입력을 기준으로 0~0.35초 검정 페이드아웃, 0.35~0.45초 완전 암전, 0.45~1초 회상 페이드인을 재생한다. 곡선은 smoothstep이다. 문장과 딤도 화면 전체 검정에 함께 가려진다.
- 회상 이미지는 시작 전에 로드·디코딩하고 0.35초의 완전 암전에서만 노출 대상으로 교체한다. 타이틀 카메라 배율을 넘기지 않고 회상은 원본 전체 구도로 표시한다.
- 회상 첫 화면에 도착하면 멈춘다. 회상 대사·후속 컷·음성은 이번 구현 범위에 없다. **진행 표시·페이드 길이·회상 첫 구도는 아직 미채택**이다.

회상 표시 파일은 `art/chapter00/review/01-memory-family-v1.png`(1672×941)다. 기존 평면 합성 검수본을 화면 전체에 비율 유지(contain)로 표시한다. 신규 고해상도 원화나 레이어 PSD를 만든 것이 아니다. 실제 배경·모녀·접지 원본 경로는 [장면별 원화 색인](../../00-제작관리/CH00-01-STORYBOARD-ASSET-MAP.ko.md)의 C0-02a를 따른다. 책·손 배경도 기존 임시 원화다.

검토 도구는 게임 화면 바깥에 있다. 다시 재생/처음으로는 타이틀까지 되돌리고, 진행 막대는 현재 구간(부름 0~2.23초 또는 전환 0~1초)을 이동한다. 일시정지/계속은 현재 구간을 유지한다. JSON 저장은 후속 타이밍 승인을 뜻하지 않는다. 창 비활성 시 재생을 멈추고 복귀하면 이어간다. Unity 구현과 실제 게임 저장/로드는 별도다.

## 같이 정하는 순서

1. 시작 클릭에 대한 반응과 카메라 움직임.
2. 딤·첫 글자·호출 소리의 등장 순서와 속도.
3. 글자 출력 중 입력과 읽기 완료 후 입력.
4. 회상으로 넘어갈 때 페이드 방식과 길이.
5. 회상 첫 화면의 구도·대사·원화와 다음 컷.

한 구간을 설명하고 시안으로 확인한 뒤 사용자 피드백을 반영한다. 다음 구간 전체를 임의로 확정하지 않는다. 문서에는 제안/채택/수정/미제작/실행 검증 여부를 구분하여 남긴다.

## 채택한 카메라의 정확한 의미

- 기준은 1920×1080의 배경 표시 컨테이너다. 화면 전체 UI Canvas를 확대하지 않는다.
- 임시 초점은 화면 정규 좌표 `(0.66,0.52)`, 즉 `(1267.2,561.6)` 부근이다. 책·손의 세부 묘사보다 장면이 살짝 가까워지는 느낌을 목표로 한다.
- 초점 주위로 배경을 `1.0→1.035` 확대한다. 이미지의 왼쪽 위를 기준으로 구현할 경우 종료 오프셋은 약 `(-44.35,-19.66)`px다. 별도의 이동값을 이중 적용하지 않는다.
- 시간 곡선은 smoothstep(`3t²-2t³`)으로, 시작과 끝의 속도가 0이 된다. 과도한 화면 흔들림이나 손의 독립 애니메이션을 추가하지 않는다.
- 최종 배경을 바꾸면 같은 좌표를 무조건 재사용하지 않고 초점·잘림을 재검토한다. 화면 바깥이 드러나지 않게 배경 경계를 확인한다.

## 글자 출력과 입력 제안

- 한글은 자모가 아닌 화면에 보이는 글자 단위로 완성해서 출력한다. `ㅅ→수` 방식은 사용하지 않는다. 실제 문자열의 결합 문자도 중간에 끊지 않는다.
- 완성된 문장의 폭을 기준으로 정렬하고 글자만 순서대로 드러낸다. 매 글자마다 다시 가운데 정렬해 문장이 좌우로 흔들리지 않게 한다.
- 첫 시작 클릭은 메뉴에서 소비한다. 클릭을 계속 누르거나 Space를 누른 상태가 다음 동작을 연속 실행하지 않게 새 입력만 받는다.
- 타이핑 중 첫 입력은 문장 전체 표시, 그 다음 입력은 장면 진행. 한 입력으로 두 동작을 동시에 하지 않는다.
- 전체 표시 설정일 때는 문장을 바로 보여주되 읽기 대기는 유지한다. 기존 움직임 줄이기 설정의 구체 대응은 검토 항목이며, 카메라 이동을 생략해도 같은 장면·대사 순서를 보존해야 한다.
- 일시정지·창 비활성에서 연출 시간이 계속 흘러 복귀하자마자 장면이 지나가지 않게 한다. 실제 저장/로드 재개 단위는 구현 설계 때 결정한다.

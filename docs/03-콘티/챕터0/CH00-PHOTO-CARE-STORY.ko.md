# 챕터 0 · 같은 사진을 돌보는 작은 사건

2026-09-10 사용자 요청: 대사 퇴고는 대사집에서 하고, 필요하면 아이템을 써서 챕터 0 서사를 조금 보강한다. 도입의 사진을 다시 활용한다. **아래 사건은 새 검토안이며, 기존 대사 87개는 수정하거나 늘리지 않았다.**

## 이번에 더하는 이야기

도입에서 사진은 수혁의 기억을 불러왔다. 현재에서는 출발 준비 중 그 사진을 고정한 테이프가 들뜬 것을 발견한다. 불이 꺼지면 먼저 소이에게 답하고 조명을 복구한다. 불이 돌아온 뒤 수혁은 사진 모서리를 다시 눌러 붙이고, 미뤄 둔 소이의 책을 챙긴다. 마지막 소등에도 사진은 원래 자리에 남는다.

과거의 기억을 더 설명하기보다 **다음 날을 준비하면서 오래된 물건도 돌보는 행동** 하나를 남긴다. 새 회상이나 긴 가족사를 삽입하지 않는다. 사진이 떨어지거나 사라지는 놀람, 뒤에서 발견되는 편지, 갑자기 밝혀지는 날짜·지명은 추가하지 않는다.

## 세 번의 등장

### 사진기사 NPC로 이어지는 바람 · 최신 추가

사용자 요청으로 사진 고정 뒤 **앞으로의 여행도 사진으로 남기고 싶다는 장면**을 추가한다. 사진을 돌보는 행동에서 새로 남길 사진으로 관심이 이어진다. 대사집에는 문장 대신 다음 발화 목적을 전달한다.

- 소이: 앞으로 가는 곳의 풍경도 지금의 사진처럼 남기고 싶다는 바람을 꺼낸다.
- 수혁: 이번 여행에 새 사진을 남기고 싶다는 마음을 받아 둔다. 당장 촬영할 수는 없으므로 기회가 생기면 방법을 찾으려 한다. 내일 반드시 촬영한다고 약속하지 않는다.
- 연출: 고정한 사진 앞에서 잠깐 머문 뒤 기존 책 챙기기로 이어진다. 새 회상·지지직·사진 뒤 편지·촬영 실패는 넣지 않는다.

`photo_care → photo_wish → book_pack`. `wants_new_photos=true`는 서사 연결 상태다. 이때 카메라·필름·앨범을 지급하거나 새 필수 퀘스트 UI를 열지 않는다. 기존 사진이 마지막 사진이라고 단정하거나 카메라 분실·휴대폰 고장 같은 경위를 새로 만들지 않는다.

챕터 1에서는 첫 그림 뒤 지역 밖 길을 알아보러 주유소에 들러 **사진기사 세진**을 만난다. 세진의 카메라가 보이면 수혁이 먼저 촬영할 방법에 관심을 보인다. 직업·이름은 그 대화에서 드러나며 프롤로그부터 세진을 알고 찾는 이야기는 아니다. 기존 공구 가방 부탁·전달로 교류한 뒤 여분 카메라와 필름을 받으면, 챕터 0의 바람을 실천할 수 있게 된다. 세진이 알려 준 쉼터에서 첫 촬영·앨범 확인으로 이어진다.

첫 사진의 인물·구도는 기존 엔딩 시점과 대조한 뒤 확정한다. 세진에게 소이와 사진을 찍어 달라고 하거나 세진이 소이를 직접 알아보는 장면을 자동으로 추가하지 않는다. `wants_new_photos`가 없는 옛 저장도 첫 사진 튜토리얼을 막지 않으며, 만남 대화에서 촬영 관심을 짧게 보충한다. 첫 촬영 뒤에는 ‘프롤로그에서 원했던 새 사진이 생겼다는 것을 확인하는 반응’을 대사집 요구사항으로 남긴다.

| 구간 | 플레이어가 보는 것·하는 일 | 사건의 의미·조건 |
| --- | --- | --- |
| 도입 사진 | 기존 사진 → 회상 → 같은 사진 복귀 | 기존 승인 연출 유지. 서연 얼굴 가림과 단발 지지직도 그대로 |
| 준비 중 선택 관찰 | 가족사진을 선택하면 시선이 같은 벽 위치로 이동. 사진을 붙인 테이프 끝이 말려 있다는 작은 상태를 발견 | `photo_observed`. 물·담요를 모두 챙기기 전 선택 가능. 관찰하지 않아도 정상 진행. 이 단계에서는 추가 회상·물건 획득 없음 |
| 불 복구 뒤 짧은 행동 | 손전등을 제자리에 둔 뒤 사진 모서리를 눌러 고정. 이어 기존 책 챙기기로 복귀 | `family_photo_secured`. 앞서 관찰했다면 미뤄 둔 정리, 안 봤다면 이때 처음 발견하고 정리. 한 번의 행동으로 마무리 |

취침은 네 번째 조사 장면이 아니다. 같은 전체 구도에서 사진이 남아 있는 채 불이 꺼지는 정도로 끝낸다. 사진만 별도로 반짝이거나 다시 확대하지 않는다. 새 ‘사진 관리’ 퀘스트·반복 일과도 만들지 않는다.

## 원화 콘티

1. **준비 중 발견**: 현재 캠핑카의 벽 사진 위치를 유지한다. 시선 이동 1.0→1.08배 후보. 물·담요 진행은 멈춘 채 선택 관찰 1회. 최종 원화에서는 사진 하단의 기존 테이프 모서리가 조금 떠 있는 모습으로 표현한다. 현재 근접 컷은 photo-care-v1의 들뜬 상태를 사용한다. 전체 캠핑카 베이스는 변경하지 않았다.
2. **복구 뒤 사진 정리**: 따뜻한 조명이 돌아온 같은 장소. 앞서 봤다면 같은 모서리로 곧바로 시선을 잇고, 처음이면 먼저 들뜬 부분을 보여준다. 최종 컷은 사진 하단·벽·수혁의 손만 담는다. 얼굴을 크게 보여줄 필요가 없다.
3. **고정 동작**: ‘들뜬 테이프를 눌러 사진 고정하기’ 한 번 → 손이 닿은 정지 포즈 1장, 들뜬 테이프/눌린 테이프 상태 교체. 짧은 종이·테이프 마찰음 후보. 새 테이프를 구하는 미니게임·재료 소모 없음. 같은 위치·벽 접촉·손가락 압력이 보여야 한다.
4. **앞으로 남길 사진**: 고정이 끝나면 소이가 새로운 여행도 사진으로 남기고 싶다는 뜻을 전하고 수혁이 받아 둔다. 정식 문장은 대사집에서 작성한다. 새 회상이나 카메라 획득 없이 전체 식탁 구도로 복귀해 기존 책 챙기기로 이어진다.

위 초 단위 값과 손 자세는 검토안이다. **들뜸·누르는 손·고정 결과 원화 3개와 분리 PSD를 제작했다.** 브라우저는 들뜸/고정 결과의 정지 이미지를 사용하며, 중간 손 컷의 시간 전환은 Unity용 art_sequence에 기록했다. 자동 대기 시간을 추가해 분량을 채우지 않는다.

## 소품과 설정의 범위

| 요소 | 취급 |
| --- | --- |
| 가족사진 | 시작에 등장한 바로 그 사진. 새 사진 지급이나 앨범 해금 없음. 계속 같은 벽 위치에 남음 |
| 사진을 붙인 테이프 끝 | 고정 방식을 설명하기 위한 새 소품 시안. 기존 테이프를 눌러 붙이는 표현이며 인벤토리 아이템이 아님 |
| 서연 얼굴 | 확대가 필요하면 기존 얼굴 마스크 필수. 고정 동작에서 원본 얼굴이 잠깐 노출돼도 안 됨. 그림 복원 퍼즐 아님 |
| 기억의 흔들림 | 도입에서 이미 제시한 정도를 유지. 물건을 만졌다고 기억이 치료되거나 새 사실이 떠오르지 않음 |
| 책 | 챕터 0의 기존 스케치북 보유를 유지. 사진을 책에 끼워 옮기지 않음. 챕터 1 퀘스트는 색연필만 |
| 편지·카메라 | 서연 편지는 챕터 3, 카메라와 첫 촬영은 기존 챕터 1 계획. 이번 장면으로 앞당기지 않음 |
| 소이 | 사진을 직접 떼거나 고정하지 않음. 물리 행동은 수혁에게만 배정. 새 생존 증거·제삼자 인지는 추가하지 않음 |

추가 제작은 **동일 벽의 사진 하단 근접 베이스 + 들뜬/눌린 테이프 레이어 + 수혁의 누르는 손 1포즈**로 제한한다. 받침 벽·사진 테두리·테이프의 겹침·접촉 그림자를 분리하고 원본 크기를 확보한다. 전체 가족사진·배경을 다시 그리지 않는다. [photo-care-v1 원화 목록](../../../art/chapter00/photo-care-v1/manifest.json)에 새 소스 4점·장면 3개·PSD 7개를 저장했다. 사진은 원래 하단을 재사용하고 얼굴은 모든 근접 컷 밖에 있다.

## 검토와 다음 단계

브라우저 [후속 콘티](../../../design/ui/ch00-01/chapter0-continuation.html)에서 첫 응답→출발 준비의 사진 관찰, 또는 불 복구 뒤 사진 고정으로 확인한다. 기존 북마크가 이미 해당 구간을 지났다면 ‘첫 응답부터 다시’로 새 사건을 볼 수 있다. 오래된 북마크를 강제로 되감지 않는다.

이번 검토 포인트는 사진 정리가 가족 설명 없이 수혁의 애착을 전하는지, 복구 뒤 책 챙기기와 비슷한 동작이 연달아 나와 늘어지지 않는지다. 늘어지면 대사를 추가하는 대신 사진 동작과 책 챙기기를 한 짧은 정리 컷으로 묶는다. 장면 방향을 검토한 뒤 필요한 원화를 만들고, 실제 문장은 대사집에서 다듬는다.

최신 연속 인계: [챕터 0 → 첫 주](../../00-제작관리/CH00-WEEK01-CONTINUOUS-HANDOFF.ko.md). 새 근접 벽은 같은 색감의 시안이며 작은 배경을 복원한 4K 원본은 아니다.

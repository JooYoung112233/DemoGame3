# MG-02 냄비 한 끼 — 조작 시안

2026-09-11 사용자 요청으로 가스레인지 요리 시안을 제작했다. [에너지 운영 결정](CAMPER-ENERGY-AND-COOKING.ko.md)을 따른다. 화덕/부채질 시안과 별개다. 정식 원화 대신 CSS로 만든 냄비·기포·불꽃을 사용하며, 이번 작업은 새 원화 납품이 아니다.

- 실행: `node tools/serve-cooking-minigame.cjs 8798` → http://127.0.0.1:8798
- 코드: `design/minigames/cooking-v1/`
- 규칙 검증: `node tools/test-cooking-minigame.mjs`
- 클릭 또는 숫자 1/2/3으로 약불/중불/강불 선택. 유지 입력·순간 스킬 체크 없음.

## 시안 규칙

테스트 재고 가스 3, 식재료 3에서 시작한다. 시작 시 가스 1·식재료 1·게임 시간 25분을 한 번 적용한다. 모두 임시 게임 단위다. 중불로 시작하며 강불을 쓰거나 실수해도 추가 비용은 없다.

데우기 단계에서 충분히 가열되면 끓음 상태로 기록한다. 최소 5초 뒤 익히기로 전환하며, 계속 약불로 방치한 경우에도 10초 후 자동 전환한다. 익히기는 10초이며 냄비 열기 62~78 구간의 유지 시간을 센다. 수치는 섭씨 온도나 현실 조리 지침이 아닌 게임 수치다. 불 변경 즉시 냄비 열기가 바뀌지 않고 서서히 반응한다.

끓음 경험 + 적정 열기 6초 이상 + 거센 끓음 1.2초 미만이면 품질 보너스 표시를 준다. 그 외에는 일반 완성이다. 두 경우 모두 식사 1개를 지급하고 자동으로 불을 끈다. 부족한 익힘은 결과 화면에서 남은 조리를 자동 마무리했다고 설명하며, 덜 익힌 음식을 그대로 완성했다고 표현하지 않는다. 품질 효과와 실제 자원 경제는 미연결이다.

일시 정지, 창 포커스 이탈, 탭 숨김 시 멈추고 사용자가 이어서 하기를 눌러 재개한다. 다시 준비/한 번 더 만들기는 테스트 재고까지 초기화한다. 저장을 구현하지 않았으므로 새로고침도 초기화된다. 정식 인벤토리나 퀘스트에 연결된 시안이 아니다.

소리 켜기는 임시 합성음이며 실제 끓음·가스 점화 음원은 아직 없다. 색 외에도 단계명·상태 문구를 표시한다. OS의 움직임 감소 설정을 따른다.

## 검증

자동 테스트: 조절 플레이의 좋은 품질 완성(약 15초), 약불/강불 고정의 일반 식사 보장, 비용 1회 처리, 비용 부족 차단, 열기 지연 반응, 완료 후 중복 지급 방지. 실제 재미·난도는 사용자 플레이로 확인한다.

브라우저 검증: 시작 화면 전체 캡처, 클릭과 숫자 키의 강불 전환, 강불 유지 후 15초 일반 완성, 식사 1개 지급과 가스/식재료 각 1개만 차감, 일시 정지와 재개, 초기화를 확인했다. 오류 로그 없음. 완료 화면에 남던 데우기 안내를 조리 완료 문구로 수정했다. 검수 후 초기 상태로 열어 두었다.

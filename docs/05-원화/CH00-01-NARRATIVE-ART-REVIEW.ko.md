# 챕터 0~1 초반 원화 검수·수정 — 2026-09-11

검수 범위는 현재 콘티의 캠핑카 상태, 사진 정리, 첫 분배·그림, 편의점과 세진·첫 사진 연결이다. 전체 게임의 모든 원화를 새로 제작하거나 최종 승인한 결과는 아니다. 대사·UI 배치·동결 오프닝은 수정하지 않았다.

실제 인물 높이는 목표 1536~2048px보다 작다. 기존 작은 소이 추출본의 보간 확대가 아니라 새로 그린 원본이지만, 목표 해상도 달성이나 디테일 복원 완료로 보고하지 않는다. 전체 장면은 고정 베이스의 1672×941이며 4K 새 배경이 아니다.

네이티브 PSD 3개는 생성 원본 숨김 레이어·투명 인물·앞팔 가림용 복사 레이어를 포함한다. 팔 복사는 같은 픽셀을 가림 순서에 맞춰 재사용하는 것이며 손가락·관절 리깅이나 가려진 신체 복원이 아니다. 장면 PSD 17개는 보존된 배경, 인물, 필요한 식탁·책·소품·앞팔 레이어를 포함한다. 일부 배경과 기존 소품은 보존 장면에 합쳐져 있으므로 모든 가구가 분리돼 있다고 보고하지 않는다. 장면용 축소 레이어와 별도로 위 큰 PNG·PSD를 유지한다.

## 연결한 파일

- 챕터 0 [진행 데이터](../../design/chapter00/continuation-v1/story.json)의 현재 장면 10개를 새 합성으로 연결. 사진 근접 2개는 기존 그대로 사용한다.
- 챕터 1 [이벤트 데이터](../../design/chapter01/event-quest-catalog-v2.json)와 [원화 연결표](../../design/chapter01/week01-art-coverage-v1.json)의 E03·E05·E06 원화 참조를 교체했다.
- 엔딩용 `C0-current-truth`, `E06-drawing-truth`는 manifest에서 `early_game_allowed: false`. 초반 장면 경로에 노출하지 않는다.
- 기존 PNG와 이전 PSD는 보존했다. 교체 전 경로는 `scene-baseline.json` 및 이벤트의 이전 자산 필드로 추적할 수 있다.
- 대사창이 구워진 기존 첫날 UI 검토 이미지는 이전 화면 배치 참고자료로 남는다. 이번 결과는 UI 없는 원화이며 UI 합성본 전체를 다시 만든 것은 아니다.

재생성은 `tools/prepare-ch00-01-narrative-art.py` → `tools/integrate-ch00-01-narrative-art.mjs` → `tools/build-ch01-event-catalog.mjs` 순서다. 이전 서사·자산 생성기를 다시 실행했다면 마지막에 이 원화 연결 단계를 실행한다.

## 검증과 한계

[원화 검사 168개](../../art/chapter00-01/narrative-art-v1/validation.json)가 통과했다. 생성 원본 RGB 보존, 알파 존재, 원본 PNG 해시 보존, 수정 허용 영역 밖 배경 픽셀 동일, PSD 레이어 채널·이름·합성 결과를 검사했다. 첫 그림의 두 변형은 소이 영역 밖 픽셀이 동일하며 같은 책·그림·수혁의 행동을 유지한다.

현재 장면·어두운 상태·색연필 전달·새 그리기·알파를 눈으로 확인했다. 머리와 팔 사이에 남았던 체크 무늬는 발견 후 제거했다. Photoshop 앱에서의 편집 및 Unity 임포트·실제 조명·확대 연출은 아직 검증하지 않았다. 다른 행동 포즈 전체의 마모 강도 통일, 대사집의 표정 세트, 4K 배경과 최종 확대용 마스터는 후속 범위다.

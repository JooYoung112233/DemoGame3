## 이번에 채운 부분

수혁의 가방 회수·물그릇 놓기, 두 손 카메라 인수, 세진의 정비 자세와 큰 중립 대화 초상, 이름 미정 선택 NPC 후보를 추가했다. 공구·먹이·젖은 침구·보수 천·말리는 천·따뜻한 음식·꾸러미·보관함·카메라 주머니·연료 용기·도로 차단물도 개별 원본으로 만들었다.

E03은 요리대 수리 전이므로 찬 물자 분배 결과로 연결했다. 수리 후 E17에 따뜻한 음식을 사용한다. 회고에는 실제 첫 그림과 첫 사진을 놓고, 강아지는 동행과 자리 마련이 끝난 경우만 추가한다. 대사·미니게임 규칙을 임의로 확정하지 않고 장면의 의도와 입력·결과·재진입 조건을 기록했다.

## 직접 보고 수정한 문제

| 발견 | 수정 |
| --- | --- |
| 가방 손잡이·팔 사이, 렌치 구멍, 카메라 끈, 머리카락 틈에 체크 배경 잔존 | 연결된 배경만 알파로 제거. 그림 RGB 보존. 갈색 불투명 배경 합성으로 재확인 |
| 물그릇을 놓는 손이 그릇에서 벗어나고 신발과 겹침 | 수혁 위치를 그릇 기준으로 조정. 놓은 직후의 정지 자세 → 인물을 뺀 기다림 컷으로 연결 |
| 요리 자세의 발이 식탁 위에 올라간 것처럼 보임 | 기존 식탁 앞면을 인물 위에 합성해 먼 쪽 발을 가림 |
| 천의 기울기가 벤치와 다름 | 분리 천을 9도 회전해 상판 방향에 맞춤. 바닥에 떠 있는 판처럼 놓지 않음 |
| 카메라 인수 컷의 팔이 화면 중간에서 잘려 떠 보임 | 소매가 화면 양쪽에서 들어오는 근접 구도로 수정. 분리 원본과 고정 배경은 별도 유지 |
| 보관함 속 꾸러미·주머니 속 카메라의 앞뒤 관계 | 나무 앞벽·주머니 앞천 복사 레이어를 내용물 위에 둠. 확대 합성으로 확인 |
| 메모·사진이 탁자 위에서 정면 판처럼 보임 | 배치본만 상판 시점에 맞춰 납작하게 조정. 큰 종이·사진 원본은 보존 |
| 새 생활 장면에서 챕터 0의 준비 물자가 빠져 보임 | 물통·담요를 같은 좌표의 조건 레이어로 유지. 분배 중 꺼낸 물통은 수납 자리에서 중복 표시하지 않음 |
| 가방 획득 후에도 선반 가방이 남을 가능성 | 회수 행동 컷에는 선반 소품 제거. 가방과 손은 한 정지 행동 원화이며 중복 지급과 별도 |
| 생활 사건과 회고가 미경험 사건까지 전제할 가능성 | 실제 젖음·수리·분배·보유 사진·강아지 동행 조건을 콘티에 명시 |

이전 첫 사진 화풍 수정본 `first-photo-v1/sources/riverside-photo-style-source-v2.png`을 계속 사용한다. 처음 만든 사진으로 되돌리지 않았다. 서연 편지는 챕터 3 후보로 남기고 이번 25개 사건의 획득 원화에 연결하지 않았다.

## 파일·합성 검증

새 묶음에는 **48개 PSD**가 있다. 개별 소스/알파 마스터 17개, 장면 PSD 29개, 먹이 상태·카메라 수납 상태 PSD 2개다. 장면 PSD의 배치 크기 레이어와 별도의 큰 개별 원본을 함께 보관한다. 숨겨진 원본 + 분리본만 있는 PSD를 관절별 편집 원화로 부르지 않는다.

- [새 원본·합성 검증](../../design/chapter01/completion-v1-validation.json): 400개 검사. 알파·원본 RGB·PSD 구조/병합 픽셀·캔버스 내부 배치·레이어 밖 배경 보존.
- [최신 전체 연결·HUB 연속성 검증](../../design/chapter01/week01-art-coverage-validation.json): 이벤트별 참조 파일과 실제 장면 레이어 검사. 검사 개수는 이 보고서의 현재 값을 따른다.
- [추가 내부 틈 알파 검증](../../design/chapter01/completion-alpha-fixes-validation.json): 잔존 체크무늬를 고친 구멍 좌표 재확인.
- [최종 전달 파일 검증](../../design/chapter01/completion-final-review-validation.json): 329개 검사 통과. 29개 장면의 고정 배경·보유 물자 조건·단일 물통 위치·내부 틈 알파·문서 링크를 최종 파일에서 확인.
- `tools/build-ch01-event-catalog.mjs`: 25개 이벤트·21개 퀘스트·8개 장소 및 등록된 원화 경로 유효성 확인.

합성은 새 29개 상태, 기존 첫 그림·촬영·강아지 상태와 25개 이벤트 대표 화면을 순서대로 검토했다. 라벨이 있는 검수 JPEG는 게임용 이미지가 아니다. 실제 실행 분기·자원 차감·퀘스트 저장을 테스트한 보고서는 아니다.

| 동결 오프닝 | `design/unity-handoff/opening-v1/` 변경 없음. 챕터 0의 선택 추가안까지 이번 챕터 1 완료 범위에 합산하지 않음 |

현재 참조 우선순위는 이 검수표 → 전체 원화 연결표 → 개별 manifest → 이전 제작 차수 문서다. 같은 이름의 오래된 HTML 시안이 모든 새 상태를 재생하는 것은 아니다. Unity에서는 manifest의 분리 PNG·좌표·상태 조건으로 조합한다.

재생성 순서는 `tools/prepare-ch01-completion-v1.py` → `tools/complete-ch01-art-index.py` → `tools/build-ch01-event-catalog.mjs` → `tools/review-ch01-completion-v1.py`다. 첫 스크립트는 생성 도구를 호출하지 않고 보관된 소스로 분리 원본·합성을 만든다. 마지막 두 단계는 최신 이벤트 문서와 검수 이미지를 갱신한다.

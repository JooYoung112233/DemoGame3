## 납품과 일관성

- [원화 원본·납품 규칙](ART-ASSET-RULES.ko.md)과 [최신 화풍](ART-STYLE-DIRECTION.ko.md)의 최상단 승인 기준을 따른다. 부드럽게 뭉개진 손맛과 기존 비율을 유지하며 실사·과도한 후처리로 전환하지 않는다.
- 게임은 1920×1080. 신규 전체 배경 원본 목표는 3840×2160 수준, 일반 소품 긴 변 512~1024px, 확대 핵심 소품 1024~2048px, 주요 인물은 실제 인물 높이 1536~2048px 수준. 도구가 목표를 못 내면 실제 출력 크기와 부족분을 명시한다.
- 획득하는 물자, 움직이는 차량, 인물, 동물, 안내판의 글자와 효과는 베이스에 굽지 않는다. 건물 구조·고정 가구는 베이스로 유지하되 인물을 가리는 앞면은 필요할 때 분리한다.
- 같은 장소의 낮/저녁/비·수리 전후를 매번 새 배경으로 생성하지 않는다. 고정 베이스에 조명·날씨·소품 상태를 조합한다. 멀리 보이는 풍경 등 실제 바뀌는 요소만 별도 제작한다.
- 새 장소도 기존 편의점·낡은 집의 시점과 인물 표시 크기를 참조한다. 각 작업대/바닥의 받침 면·그림자·가림 순서를 먼저 표시한 뒤 소품을 배치한다.
- PNG 실제 원본과 분리 PNG를 보관하고 가능한 경우 실제 레이어 PSD를 제공한다. 하나의 평면 배경을 PSD로 저장한 것을 구조물까지 편집 가능한 원본으로 표기하지 않는다. 실제 납품 레이어 수와 픽셀 범위는 각 manifest·README를 따른다. 분리 계획 전체가 완료된 뜻은 아니다.
- 자산을 만든 뒤 원본 경로·치수·최대 표시 크기·분리 상태·사용 이벤트 ID를 원본 데이터에 등록하고 합성으로 접지·가림·알파를 검수한다.

## 연속 제작 상태

L2 주유소·L4 수리점·L6 쉼터·L7 고갯길의 원본과 가림/표면 복사 PSD를 각 장소 폴더에 저장했다. [첫 그림 콘티](../03-콘티/챕터1/CH01-E06-FIRST-DRAWING.ko.md)에 새 수혁 전달 자세·페이지 상태·다음 장소 연결을 기록했다. 공구 가방·카메라·필름 분리 원본과 선반 회수 전후 상태를 추가했다. [세진~첫 촬영 콘티](../03-콘티/챕터1/CH01-E07-11-PHOTOGRAPHER-STORYBOARD.ko.md)에 연결했다. [강아지 E12~14 콘티](../03-콘티/챕터1/CH01-E12-14-DOG-STORYBOARD.ko.md), [세진·차량 시안](../../art/chapter01/sejin-v1/README.ko.md), [첫 촬영·앨범 시안](../../art/chapter01/first-photo-v1/README.ko.md)을 추가했다. 이후 생활 상태·추가 자세는 completion-v1 묶음과 전체 연결표를 따른다. 원본 크기와 실제 분리 범위는 각 manifest에서 확인한다.

## L3 첫 납품 기록

[잡화점 원화 기록](../../art/chapter01/general-store-v1/README.ko.md)에 PNG·프롬프트·원본 크기·세 레이어 PSD를 보관했다. PSD는 전체 그림 1장과 가구 앞뒤 가림용 원본 복사 2장이다. 가구를 옮긴 뒤의 바닥을 복원한 독립 가구 자산은 아니다. [색연필 원화와 발견 전후](../../art/chapter01/colored-pencils-v1/README.ko.md), [E05 발견 콘티](../03-콘티/챕터1/CH01-E05-PENCILS-DISCOVERY.ko.md)를 추가했다. 색연필은 실제 투명 PNG와 별도 접촉 그림자를 제공한다. 선택 천·소유자 메모·교환처 인물 후보는 completion-v1 묶음에 추가했다.

## 현재 전체 연결

[25개 이벤트 원화 연결표](../../design/chapter01/week01-art-coverage-v1.json)와 [최종 차수 검수](CH01-WEEK01-ART-REVIEW.ko.md)를 현재 제작 범위의 기준으로 사용한다. 생활·선택 인연·회고·출발은 [E15~25 상세 콘티](../03-콘티/챕터1/CH01-E15-25-LIVING-DEPARTURE-STORYBOARD.ko.md)에 연결했다. 아래 묶음은 단계 구분이며 미제작 목록이 아니다. 해상도 보강·최종 대사/표정·Unity는 후속이다.

## 제작 묶음

1. **첫 그림까지:** L3 베이스 + 색연필/책 상태. 기존 HUB·L1 사용.
2. **세진과 부탁:** L2·L4 베이스 + 세진 + 가방/카메라/필름. 대화와 전달은 같은 배경 사용.
3. **강아지:** L5 기존 베이스 검수 + 그릇/자리 + 강아지 개별 포즈. 새 낡은 집 전체 재생성 없이 연결.
4. **첫 사진과 출발:** L6·L7 베이스 + 사진/앨범/안내판. 이동은 암전·효과음.
5. **선택 생활:** 고정 장소에 누수·침구·요리·찬장·꾸러미 상태 추가. 별도 장소를 늘리지 않는다.

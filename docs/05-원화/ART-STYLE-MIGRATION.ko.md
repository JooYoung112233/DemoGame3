> **최신 상태:** 사용자가 ‘수혁이는 기존께 훨나은것 가긴도하네’라고 평가하여 수혁 대화 초상은 기존 `suhyeok-response-v1.png`로 복귀했다. 반실사 v2 원본·투명 PNG·PSD는 비교용 보관이다. 아래 교체·검사 내용은 제작 이력이며 현재 인게임 사용을 뜻하지 않는다. 수혁을 다시 다듬을 때는 기존 얼굴 비례와 부드러운 표정을 우선 비교한다. 이 피드백만으로 전체 화풍 기준을 폐기하거나 다른 인물을 자동 변경하지 않는다.

2026-09-10. 사용자 ‘조금 다듬으면 될것같은데 일단 우리 인게임원화를 하나씩 수정해보자’. [승인 반실사 화풍](ART-STYLE-DIRECTION.ko.md)을 인게임 자산에 한 장씩 적용한다. 각 장의 세부 품질은 검토하면서 조정한다.

## 01 · 수혁 대화 초상

현재 회상 응답과 캠핑카 대화에서 사용하는 수혁 초상만 교체했다. 단순히 얼굴 시안을 크게 붙인 것이 아니라, 기존 자세·셔츠·시선에 맞춰 반신~허벅지 그림을 새로 제작했다. 이미지 생성 후 기존 사용자 허용 범위에서 체크 배경을 제거했다.

| 구분 | 실제 파일 |
| --- | --- |
| 생성 원본 | `art/chapter00/memory/dialogue-v1/suhyeok-response-semi-source-v2.png` |
| 실제 투명 인게임 PNG | `art/chapter00/memory/dialogue-v1/suhyeok-response-semi-v2.png` |
| 편집 PSD | `art/chapter00/memory/dialogue-v1/suhyeok-response-semi-layers-v2.psd` |
| 치수·알파·검증·참조 | `art/chapter00/memory/dialogue-v1/suhyeok-response-semi-v2.json` |
| 밝음/어두움 위 검수 | `art/chapter00/memory/dialogue-v1/suhyeok-response-semi-alpha-review-v2.jpg` |
| 이전 원화 보관 | `art/chapter00/memory/dialogue-v1/suhyeok-response-v1.png`와 기존 PSD |
| 실제 사용 데이터 | `design/ui/ch00-01/memory-dialogue.json`의 `portraits.suhyeok` |
| 화면 합성 | `design/ui/ch00-01/review/C0-02-response.png`, `C0-03-response.png`, `C0-03-soi-question.png` |
| 재현 | `tools/prepare-suhyeok-semi-v2.py`, `tools/render-dialogue-review.py` |

좌표는 기존 `[100,50,720,1080]` (1920×1080 기준)를 유지했다. 이름표·대사·효과·입력은 수정하지 않았다. 서연 초상 비공개와 이름 공개 규칙을 유지한다. Unity 구현 완료가 아니라 게임 제작용 자산과 현재 연출 시안의 참조 교체다.

원본은 **1024×1536**, 인물 알파 범위 `[92,19,967,1536]`, 실제 세로 높이 1517px이다. 인물 세로 1536~2048 목표보다 작으며 단순 확대하지 않았다. 머리와 양손은 그림 안에 있고 아래는 의도한 허벅지 크롭이다. PSD에는 **숨김 생성 원본 / 투명 인물** 두 RGBA 레이어가 실제로 들어 있다. 얼굴·손·의상을 각각 움직이는 내부 파츠나 표정 레이어로 분리한 것은 아니다.

원본 크기, 주변 알파, 얼굴·셔츠·바지·양손 불투명성, PSD 레이어/합성 채널 재읽기 총 11개 검사 통과. 밝음·어두움 위 가장자리와 현재 대화 합성도 시각 검토했다. Photoshop 앱·Unity 직접 검수는 미실시다. 얼굴과 피부의 최종 붓질·인상은 사용자 피드백을 받는 1차 수정본이다.

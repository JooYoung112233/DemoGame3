# 챕터 0~1 원화 검수 — 2026-09-11

> 후속 작업: 이 검수 뒤 요청받은 [전체 원화 보완 결과](ART-POLISH-2026-09-11.ko.md)에 대화 알파 수정·인물 재작화·장면 재합성·편집 레이어를 정리했다. 아래 수치와 결함은 보완 전 검수 이력이다. 최신 상태는 후속 기록과 `art-polish-v1/validation.json`을 확인한다.

**판정: 콘티 검토는 계속할 수 있다. 최종 게임용 원화 납품 완료로 판정하지 않는다.**

최근 승인된 주택 장면의 인물·공간 통합감은 유지할 기준이다. 다만 그 결과가 다른 장면에 적용되지 않았고, 현재 대화용 수혁 PNG에는 실제 불투명 체크무늬 잔여물이 있다. 이번에는 원화를 수정하거나 재생성하지 않고 문제와 근거를 기록했다.

## 검수 범위와 방법

- `art/` 전체의 과거 버전을 포함한 PNG 1,160개, PSD 170개, JPG 80개를 읽었다. 합계 1,410개 모두 합성 이미지 디코딩 성공.
- PSD는 합성 이미지와 레이어 레코드·이름·가시성·채널 기록을 확인했다. 모든 개별 레이어의 압축 데이터를 독립적으로 풀거나 Photoshop/Unity에서 열어 본 검사는 아니다.
- 원화 manifest, 챕터 콘티 JSON, 오프닝 자산 JSON 등에서 해석한 파일 참조 1,950건은 모두 존재했다. HTML/JS/문서 전체의 모든 링크를 검사했다는 뜻은 아니다. 과거 검증 로그의 링크는 그 로그가 검사했던 문서를 기준으로 해석했다.
- 챕터 0 후속 장면 목록과 챕터 1 E01~E25 리소스 목록에서 중복을 제외한 PNG **61개**를 새 비교 시트로 만들고 시각 검수했다. 해당 목록은 콘티 리소스 목록이며 Unity 런타임 선택 결과는 아니다.
- 오프닝 대화 관련 자산 6개, completion 패키지 native 17개, 기존 soft-storybook/native 알파 검수 시트, 최신 배경 조화 v2의 17장면과 승인 주택 시안을 추가 확인했다. 모든 과거 파일 1,410장을 개별 확대해 미술 승인한 것은 아니다.
- UI 배치·이름표·버튼·하이라이트 조정, 대사 개작, Unity 구현은 범위에서 제외했다.

기계 검사: [요약](../../design/audit/art-2026-09-11/summary.json), [파일별 크기·알파·PSD 레이어 기록 및 검수 시트 목록](../../design/audit/art-2026-09-11/inventory.json).

### 1. 수혁 대화 PNG의 실제 알파 결함

현재 [memory-dialogue.json](../../design/ui/ch00-01/memory-dialogue.json)이 연결하는 파일:

- [suhyeok-response-soft-v3.png](../../art/chapter00/memory/dialogue-v1/suhyeok-response-soft-v3.png)
- 대응 원본 패키지: [sprites/suhyeok-dialogue.png](../../art/style-revision/soft-storybook-v1/sprites/suhyeok-dialogue.png), [PSD](../../art/style-revision/soft-storybook-v1/psd/suhyeok-dialogue.psd)

1024×1536 이미지의 화면 오른쪽 팔 안쪽 `(775,1100)`은 RGBA `(255,255,255,255)`, `(790,1190)`은 `(203,203,204,255)`다. 투명 영역이어야 하는 곳에 흰색/회색이 실제로 들어 있다. 외곽 알파의 최솟값이 0인 것만으로 이 문제를 찾을 수 없다.

### 2. 인물과 배경 통합

[승인 주택 비교](../../art/chapter00-01/scene-integration-v1/review/house-before-after.jpg)에서 개선된 점은 인물의 단순 흐림이 아니라 **가구 대비 크기, 주변색을 받은 피부·옷, 발과 무릎의 접지, 배경과 비슷한 경계 강도**다.

- 수리점 E08: 쪼그린 수혁이 작업대와 방 크기에 비해 작은 인상을 준다. [현재 장면](../../art/chapter01/completion-v1/review/E08-L4-retrieve.png).
- 강변 E11: 촬영 자세의 수혁이 난간·벤치에 비해 작고 밝게 분리되어 보인다. [현재 장면](../../art/chapter01/first-photo-v1/review/L6-first-shoot.png).
- 주유소 E07 및 첫 만남: 차량의 강한 윤곽, 세진의 피부 밝기, 주변 바닥의 채색 밀도가 다르다. [배경 수정 후에도 남은 차이](../../art/chapter00-01/background-harmony-v2/review/L2-sejin-meeting.png).
- 주택 E12/E13: 기존 강아지는 눈·외곽선이 특히 또렷해 배경보다 스티커처럼 보인다. 승인된 통합 시안의 채색과 접지를 기준으로 이어갈 대상이다.
- 캠핑카 C0/E06: 탁자 가림과 행동 의미는 읽히지만 얼굴·셔츠의 선명도가 가구와 다르다. 정전 상태에 밝기 변화가 들어간 점은 유지하고, 주변 조명에 맞춘 인물 마감을 추가한다.

위 평가는 시각 판단이다. 주택에서 사용한 1.35배/1.2배를 모든 장소에 일괄 적용할 근거는 없다.

### 3. 승인 시안의 편집 범위

[house-integration-review.psd](../../art/chapter00-01/scene-integration-v1/psd/house-integration-review.psd)는 3개 레이어다: 이전 장면(숨김), 고정 빈 배경, 바닥을 포함한 국소 패치. 인물별 분리 PSD가 아니다.

[manifest](../../art/chapter00-01/scene-integration-v1/manifest.json)의 패치는 `[330,340,345,295]`, `includes_background: true`다. 독립 캐릭터 추출과 전체 장면 적용은 미완료로 정확히 기록되어 있다. 승인 파일 자체는 보존할 기준이며, 지금 별도 캐릭터처럼 잘라 옮기면 바닥까지 따라간다.

전체 PSD 중 단일 레이어는 5개다. 4개는 소품 수거 후 빈 배경 상태(E10/E23의 기존판·배경 수정판), 1개는 생성 주택 원본이다. 이 자체가 파일 손상은 아니다. 다만 가구나 인물을 따로 수정할 수 있는 파일로 설명해서는 안 된다. 나머지 165개도 레이어가 여럿이라는 이유만으로 모든 물체가 독립 편집된다고 판단하지 않았다.

### 4. 버전 혼용

새 인물 장면은 [narrative-art-v1](../../art/chapter00-01/narrative-art-v1/manifest.json)에 연결되어 있지만 [E17 식사](../../art/chapter01/completion-v1/review/E17-HUB-warm-meal.png)와 [E24 기억](../../art/chapter01/completion-v1/review/E24-HUB-memories.png)에는 이전 앉은 인물 레이어가 남아 있다. 특히 소이의 눈·머리 경계가 새 장면보다 또렷하다. 완성 원화 교체 시 이 상태들도 함께 점검해야 한다.

배경 조화 v1/v2와 승인 주택 파일은 현재 C0 후속 장면/E01~E25 리소스 목록에 전면 교체되지 않았다. 이는 후보를 바로 납품본으로 바꾸지 않은 현재 작업 상태다. **배경 8종 생성 완료와 전체 장면 통합 완료는 다른 상태**로 유지한다.

[prepare-scene-integration-review.py](../../tools/prepare-scene-integration-review.py)의 manifest 출력에는 아직 `single-scene-review-not-approved-global-style`이 고정되어 있다. 재실행하면 현 manifest의 `user_approval`이 빠진다. 이번에는 재출력하지 않았다. 후속 수정 전에 보존 로직부터 고쳐야 한다.

## 유지할 부분과 오탐 제외

- 부드러운 동화풍 인물의 인상·의상, 공간의 고정 구도, 책·색연필·카메라·필름·공구 등 분리 자산 구성은 이어서 사용한다. 실사/반실사 방향으로 돌아가지 않는다.
- 현재 손잡기 장면은 [hands-held-review-v2.png](../../art/chapter00/memory/dialogue-v1/hands-held-review-v2.png)다. 과거의 세 손이 모인 시안을 현재 오류로 분류하지 않았다.
- 현재 회상 대화 데이터에서 서연의 발화는 빈 초상화 목록이며, `memory-dialogue.mjs`의 이미지 로딩 목록에도 서연 초상화가 없다. 얼굴이 그려진 보관 원화가 존재하는 것 자체를 화면 노출 오류로 판단하지 않았다. Unity에서의 실제 가림 효과 검증은 별도다.
- 첫 그림은 수혁이 그리고 소이는 지켜보는 형태다. 첫 사진은 강변 풍경이다. 검사한 C0 후속 장면/E01~E25 리소스 목록에는 `-truth` 이미지 연결이 없었다. 전체 엔딩/런타임 분기 검증은 이번 범위가 아니다.
- completion 패키지의 카메라 끈 안쪽, 세진 다리 사이, 수혁 돌봄/회수 자세의 빈 공간, 렌치 구멍은 지정 표본 5개 모두 알파 0이다. [새 native 검수 시트](../../design/audit/art-2026-09-11/current-native-alpha.jpg)와 [표본 수치](../../design/audit/art-2026-09-11/alpha-sample-checks.json)를 기준으로 삼는다. 이전 `alpha-contact.jpg`를 최신 결과로 보지 않는다.
- 강아지 이벤트의 창문·책상 위치가 달라 보인다는 초기 시각 추정은 **철회했다**. 경계/물 놓기/놓는 자세/안심 4장면의 같은 가구 영역 `[550,80,1100,380]`을 비교한 결과 픽셀이 동일했다. [비교 이미지](../../design/audit/art-2026-09-11/house-fixed-furniture-comparison.png), [수치](../../design/audit/art-2026-09-11/house-fixed-region-checks.json).

## 다음 원화 수정 순서

1. 수혁 대화 원화의 닫힌 빈 공간 알파를 수정하고 대응 PNG·PSD를 맞춘다.
2. 승인 주택 장면의 느낌을 유지한 독립 인물·강아지·그림자 제작을 마무리한다.
3. 캠핑카 C0/E03/E05/E06 → 후반 E17/E24 → 수리점 → 주유소 → 강변 순으로 실제 장면 안에서 통합한다.
4. 각 장면이 정리될 때 큰 원본, 독립 레이어, 실제 해상도, 채택 파일과 이전 파일 관계를 함께 기록한다.

이번 결과는 **검수 완료 / 수정 항목 미해결**이다. 원화·활성 콘티·기존 PSD·동결 Unity 인계 폴더를 변경하지 않았다. 새로 만든 것은 감사 스크립트, 검수 시트와 이 보고서다.

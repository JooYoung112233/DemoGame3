# 화자 이름 공개 규칙

2026-09-10 사용자 정정 반영. 이후 모든 인게임 대화에 적용한다.

**이름과 인물이 연결되기 전에는 `?`, 대사에서 누구인지 알게 되면 그때부터 이름을 표시한다.** 별도 자기소개만 기다리지 않는다. 호명·다른 인물의 대사·설명도 이름 공개 계기가 된다.

| 이름을 알게 되는 대사 | 이후 이름표 |
| --- | --- |
| 사진 진입의 ‘수혁아.’ | 수혁. 회상에서 첫 ‘응.’부터 현재 대화까지 실명 표시 |
| 서연의 ‘소이 손 좀 잡아줘.’ | 소이. 뒤의 ‘아니. 아빠 손 잡을래.’와 현재 질문에 실명 표시 |
| 현재 수혁 내면의 ‘서연이 없는 밤은 아직도 낯설다.’ | 이후 서연 발화가 있으면 서연. 이전 회상 대사로 소급하지 않음 |

- 서연의 기존 회상 발화는 그 시점에 이름을 알기 전이므로 `?`. 초상도 기존 요청대로 숨긴다. 나레이션은 이름표 자체를 표시하지 않는다.
- 이름이 포함되었다는 이유만으로 엉뚱한 인물까지 공개하지 않는다. 대본에서 그 이름과 인물이 연결되는 순간을 `speaker_id`에 지정한다. 자기소개 전까지 무조건 숨기는 기존 해석은 폐기한다.
- 이름이 드러나는 문장을 읽고 확인한 뒤 다음 발화부터 적용한다. 이후 대화에서는 다시 `?`로 되돌리지 않는다.
- 내부 ID·파일명·제작 콘티 화자명과 플레이어 표시 이름은 분리한다. Unity에서는 이름 인지 상태를 저장하고 저장/로드에도 유지한다. 실제 게임 저장 구현은 후속 작업이다.
- 브라우저의 `names_known_on_entry`는 사진의 부름을 이미 확인한 **회상 대화 진입 상태**다. 게임 시작부터 모든 이름을 아는 설정이 아니다. `name_reveals`는 대사 확인 후 추가로 알게 되는 이름을 기록한다. 직접 구간 보기는 그 앞의 대사를 거친 상태를 재현한다.

구현: `design/ui/ch00-01/speaker-identity.mjs`, 데이터 `memory-dialogue.json`. 합성 검수 PNG도 동일 규칙으로 갱신한다. 원화에 화자명을 구워 넣지 않는다.

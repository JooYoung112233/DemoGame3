# 챕터 0~1 미니게임·음악·효과음 공동 구상

## 최신 운영 결정 · 2026-09-11 후속

저녁 정신력 게임을 대체하는 선택형 서사 활동 **오늘 남길 한 장**을 사용자가 승인했다. 당일 경험의 사진·물건·기록 중 하나를 일기장에 남기고, 바로 잠들기도 허용한다. [저녁 활동 기록](../02-게임시스템/EVENING-MEMORY-ACTIVITY.ko.md)을 따른다. 점수 판정 미니게임이나 매일 필수 과제로 만들지 않는다.

가스레인지는 가스·식재료를 쓰는 요리 미니게임, 전자레인지는 전력·간편식을 쓰는 가열 연출로 구분한다. 차량 이동과 발전기는 공용 연료 재고를 사용하고 수동 발전은 시간을 쓰는 최소 전력 대안으로 둔다. 사용자 확정 사항과 요리 MG-02의 새 구상은 [캠핑카 에너지 운영과 요리](../02-게임시스템/CAMPER-ENERGY-AND-COOKING.ko.md)에 기록했다. 아래 초기 MG-02의 누르기/놓기 조작은 새 냄비 불 조절 구상의 이전안이며, 화덕 시안은 본편에 채택하지 않는다.

탐색은 [V2 진행형 시안](../02-게임시스템/SEARCH-MINIGAME-V2.ko.md)까지 제작했다. 실제 게임에서는 판정판을 상시 노출하지 않고 탐색 중 불규칙한 순간에 짧게 등장시키는 사용자 후속 방향을 따른다. 아래 MG-01의 단발 판정 설명과 미구현 표기는 초기 기록이다.

후속 사용자 결정: 음악 생성은 사용자가 Suno AI에서 진행한다. [Suno 곡별 프롬프트](SUNO-MUSIC-PROMPTS.ko.md)에 대표곡과 장면별 6개 입력안을 저장했다. 미니게임은 MG-01 탐색을 첫 구현 후보로 추천한 상태이며 아직 선택·구현 완료가 아니다.

2026-09-11. **검토 초안이며 수치·악기·곡 수를 확정한 명세가 아니다.** 대사는 사용자가 대사집에서 집필한다. 여기서는 게임 행동과 음악의 역할을 함께 결정한다. 음악·음원 파일은 아직 제작하지 않았다.

## 음악의 중심 · 사용자 방향

사용자: “기억에 남는 은은한 생활 감의 음악 느낌? 음악을 들으면 이게임이 떠오르게”. 배경에서 사라지는 무색한 음악보다는 작은 고유 선율이 일상과 함께 쌓이는 방향이다. 음악을 가족·사진 장면에만 제한하는 앞선 A안은 기본안으로 채택하지 않는다.

제안: **한 개의 기억하기 쉬운 주제 선율과, 같은 선율을 공유하는 생활·여행·기억 변주.** 보컬·강한 드럼보다 조용히 흥얼거릴 수 있는 4~6음의 짧은 동기가 좋겠다. 모든 장면에서 같은 구절을 계속 반복하지 않고, 중간에는 반주만 남기거나 다른 악기가 이어받는다. 실제 음정·박자·멜로디는 청취 시안에서 결정한다.

악기 후보는 부드러운 업라이트 피아노가 선율, 나일론 기타가 생활 리듬, 낮은 첼로 또는 얇은 공기감이 밤의 여운을 맡는 구성이다. 피아노가 너무 감상적으로 들리면 기타를 선율로 바꿔 비교한다. 무조건 단조·느린 슬픔으로 채우지 않는다. 희미한 기계음·천·종이 소리는 현장 효과음으로 두고 음악 트랙에 고정하지 않는다.

우선 MUS-01 45~60초 청취 시안에서 대표 선율을 고른 다음 생활·여행·기억 3개 버전을 비교하자. 전체 곡을 여섯 개 먼저 만들어 놓으면 정체성이 갈라질 수 있다. 상용 작품의 선율을 따라 쓰지 않고, 새 동기를 만든다. 전투 전용곡·엔딩 완성곡은 실제 해당 콘티에 맞춰 후속 결정한다.

장면용 반복곡은 90~150초 후보, 긴장 층은 20~40초 후보. 처음 10초만 좋은 곡보다 5분 이상 들어도 대사를 방해하지 않는 구성이 중요하다. 곡 사이의 연결을 위해 같은 조성 또는 연결 가능한 종지, 공통 악기 음색을 사용한다. 무음은 음악이 없는 기본 상태가 아니라 정전·기억 단절 같은 특정 순간의 대비로 쓴다.

## 미니게임 · 기존 방향과 새 제안 구분

기존 콘티 후보: 탐색은 빠른 탐색 **총 5분**, 집중 탐색 **총 15분**, 미니게임 성공 시 **+20%p**, 실패 시 기본 확률 유지. 수치는 시안이다. 각 물자의 확률을 따로 보여 주고, 확정 보급분과 추가 추첨을 구분한다. 첫 생수 확보와 이야기 필수 가방·튜토리얼 사진은 확률 실패로 막지 않는다.

### MG-01 조심스럽게 꺼내기 · 탐색

- 발생: L1 냉장고·식품 선반·생활용품 상자, E05 문구대, E10 추가 공구처럼 **일반 확률 탐색**에서 집중 탐색을 고른 경우. 지도 열기·쪽지 읽기·필수 공구 가방 회수에는 붙이지 않는다.
- 제안 입력: 왕복하는 표시가 안전 구간에 왔을 때 한 번 멈춘다. 실제 조작 6~10초 이내, 한 탐색당 한 판. 연속 성공 콤보·세 번 반복은 우선 제외한다. 음악 박자를 맞추는 게임이 아니라 물건을 조심히 빼는 행동이다.
- 처리 후보: 안전 구간 성공은 각 추가 물자에 `min(100, 기본 확률 + 20)%`. 실패해도 기본 확률 그대로. 예: 45% 생수 → 성공 65%, 30% 음료 → 성공 50%. 첫 확정 생수는 항상 100%다.
- 집중 총 15분에는 조작 시간이 포함된다. 빠른 탐색 5분 뒤 다시 집중 15분을 더하는 구조가 아니다. 실제 화면 조작의 몇 초와 게임 세계의 분을 구분한다.
- 각 추가 물자는 독립 추첨하는 안. 같은 지점의 결과는 한 번 확정하고 다시 누르거나 불러오기만으로 재추첨하지 않는다. 기본 확보분 → 추가 결과 → 소음 후속 반응 순서로 보여 준다.
- 취소는 조작 시작 전까지 자유. 시작 후 취소는 ‘중단’ 확인을 거쳐 시간 비용을 유지하고 기본 확률로 한 번 확정하는 후보. 저장·종료로 결과를 다시 뽑지 않게 탐색 시작과 결과 저장 시점을 결정해야 한다.
- 난이도 후보: 초반 넓은 구간과 느린 속도. 후반은 구간·물체 소음 위험으로 차별화한다. 좁은 구간을 무작위로 계속 바꾸기보다 화면에서 먼저 예측하게 한다. 느린 모드 또는 미니게임 생략 대안도 고려한다.

**소음은 보상 판정과 분리**한다. 기본안은 장소·대상에 정해진 소음 위험을 탐색 전에 낮음/보통/높음으로 알리고 별도로 판정하는 것이다. ‘성공=무조건 안전, 실패=즉시 전투’로 만들지 않는다. 실패가 위험을 조금 높이는 안은 별도 선택지이며 아직 채택하지 않았다. 집중은 이미 시간이 더 들므로 빠른 탐색보다 무조건 위험하게 만들지는 않는다.

소음 사건 제안: 떨어진 캔 → 먼 인기척 → 계속 찾기/지금 귀환의 판단. 매번 공격으로 끝나지 않아야 실제 위협이 살아난다. 확정한 획득물을 소음 연출 때문에 취소하지 않는다. 초반 튜토리얼에서는 대응을 배우는 예고 사건만 쓰고 강제 감염을 배치하지 않는다.

### MG-02 불 조절 · 요리

- 발생: E04 요리대 수리 이후 E17 첫 따뜻한 식사. 재료·레시피 선택은 조작 시작 전에 한다.
- 제안 입력: 누르는 동안 열이 오르고 놓으면 내려간다. 약 8~12초 동안 적정 구간에 머문 정도로 판정한다. 탐색의 ‘한 번 멈추기’와 다른 행동이지만 같은 작은 게이지 구성과 입력을 활용한다.
- 기본 요리와 직접 조리를 모두 제공하는 안. 기본 요리는 먹을 수 있는 식사 보장, 직접 조리 성공은 맛·만족도 등 한 종류의 작은 보너스. 실패는 보너스 없음이며 재료 전체 소멸이나 굶주림 강요는 하지 않는 방향을 제안한다.
- 시간은 기본 20분 / 직접 조리 총 25분을 비교용 후보로 두되 낮의 행동량과 함께 조정한다. 기존 확정 시간이 아니다. 성공 보너스의 종류·수치도 미정이다.
- 첫 요리는 안내와 넓은 판정 구간. 미니게임이 대화를 끊지 않도록 조리 → 불 끄는 소리 → 식탁 결과 → 사용자 대사 순서. 같은 레시피를 반복할 때 자동 조리 가능.
- 소이가 직접 젓거나 객관적으로 음식을 조작하는 원화·독립 효과음은 넣지 않는다. 분배 수치와 실제 자원 처리 방식은 진실 설정을 기준으로 후속 검토한다.

### 이번에 늘리지 않을 조작

사진은 구도 확인 → 셔터 → 사진 확인이라는 짧은 체험을 우선한다. 실패로 필름을 잃는 미니게임으로 서사 사진을 막지 않는다. 강아지는 거리·먹이·기다림 선택과 반응으로 충분하다. C0 전원 수리는 가르쳐 주는 클릭 튜토리얼로 두고, 요리·탐색 외에 새 퍼즐을 동시에 늘리지 않는다.

감염자·밴딧 조우는 별도 설계 회차에서 정한다. 현 단계 연결안은 징후 → 상황 확인 → 대응 선택 → 정지 원화·소리·결과다. 전투 방식·피해·도주 확률은 미정이며 미니게임 실패 하나에 중간 강제 물림 사건을 배정하지 않는다. 저녁 심리 전투를 다시 추가하지 않는다.

이 표의 ID는 음원 **묶음**이며 파일 19개라는 뜻은 아니다. 재질·방향·변형마다 여러 파일이 필요하다. 우선순위는 C0 완주(SFX-01~07, 공통 UI) → 첫 보급(SFX-08~12) → 사진·강아지·생활 확장이다. 전투 공격·피격·도주 효과음은 전투 규칙이 정해진 뒤 추가한다.

소이 관련 소리는 기억·주관적 체험과 객관적 환경음을 구분한다. 과거 회상에서는 함께 걷던 소리를 쓸 수 있지만 현재 NPC가 반응하는 독립 발소리·접촉음을 무심코 추가하지 않는다. 오히려 이를 노골적인 무음 장치로 강조해 초반에 정답을 알려 주지도 않는다. 음성 연기를 할지는 미정이며 ‘수혁아’, ‘아빠?’도 현재는 게임 텍스트 연출로 구현 가능하다.

## 함께 정할 순서

1. 음악 주제 시안: 은은하지만 기억에 남는지, 피아노 중심과 기타 중심 중 어떤 쪽이 우리 게임다운지 먼저 듣기.
2. 탐색: 한 번 멈추기 방식이 좋은지, 소음이 미니게임 성공과 얼마나 연결될지 결정.
3. 요리: 기본 요리 병행 여부, 조작 성공 보너스와 시간 비용 결정.
4. 실제 C0 장면에 음악·환경·효과음을 얹어 타이밍 검토. 모든 소리가 동시에 나오지 않게 조정.
5. 첫 주 플레이 시간·자원 경제가 나온 뒤 분·확률·반복 빈도 조정. 아직 수치로 난이도를 확정하지 않는다.

납품 목표 초안: 음악은 루프 가능한 WAV와 선율/반주 분리본, 환경음은 안정된 루프, 효과음은 잘리지 않은 짧은 WAV와 변형. 동일 음원의 사용 범위·제작 출처도 기록한다. 특정 외부 음원 구매·작곡 의뢰·유료 생성은 아직 진행하지 않는다.
# 탐색 조작 시안 구현 (2026-09-11)

첫 탐색 미니게임의 독립 브라우저 시안을 제작했다. 실행과 현재 규칙, 검증 범위는 [탐색 프로토타입 기록](../02-게임시스템/SEARCH-MINIGAME-PROTOTYPE.ko.md)을 참조한다. Unity 연결 전 조작감 검토용이며, 요리·전투·퀘스트 연동은 아직 구현하지 않았다. 기존 제안 수치는 확정 밸런스가 아니다.

# 첫 여정 1차 제작 마감 · 연속 플레이 검수

2026-09-13. 이번 요청의 남은 순서였던 **L8·L9·L10 현장 배경 보강 → 새 게임부터 첫 지역 출발까지 연속 검수**를 마쳤다. 앞서 연결한 튜토리얼·탐색 v2·요리 화면과 함께 첫 여정의 1차 제작 범위를 닫는다. 다음 지역 전체 콘텐츠, 49일 사건·엔딩, 최종 대사·음악 완성을 뜻하지 않는다.

## 이번 변경

- 공영주차장·작은 세탁소·동네 약국을 지도 확대 화면에서 개별 현장 배경으로 교체했다. 탐색과 저장 미리보기에서 같은 자산을 쓴다. 주차장 밴딧 조우는 별도 골목 원화로 진행하고 일반 탐색으로 돌아온다.
- 캠핑카를 새 배경에 고정하지 않았다. 도보 중에는 기존 주차 위치를 유지하며, 차량으로 이동해야 주차 위치가 바뀐다.
- 위치 카드의 달 아이콘 고정을 보완했다. 첫 밤에는 달, 낮의 캠핑카 안에서는 차량, 바깥 탐색에서는 지도 아이콘을 쓴다. 하루 마치기 버튼의 달 아이콘은 유지한다.
- PNG 원본·동일 크기 PSD·생성 지시·SHA-256·검증 매니페스트를 보관했다. [원화 연결 기록](../08-UI연출/REGION-SITES-RUNTIME-2026-09-13.ko.md).

## 실제로 이어서 확인한 경로

`Demo3/AgentScripts/VerifyFirstPassJourney.cs`를 Unity CLI/Pipeline으로 실행했다. 첫 게임 시작부터 출발까지 자원이나 진행 플래그를 주입하지 않고, 실제 버튼·선택·대화 진행을 사용했다.

1. 타이틀의 새 게임 → 책·회상·현재 복귀 → 소이에게 대답 → 책·라디오·출발 준비.
2. 물·담요 준비 → 정전·실내등 복구 → 사진 정리·스케치북 보관 → 일기·첫 밤 → 첫날 아침.
3. 편의점으로 차량 이동·하차 → 물과 식량 탐색·주방 식품 확보 → 캠핑카 귀환·첫 식사.
4. 책 → 잡화점 색연필·생활 물자·두 지점 탐색 → 귀환·도구 전달·첫 그림.
5. 주유소에서 세진을 만나 부탁 수락 → 수리점 가방·보급품·두 지점 탐색 → 주유소에 전달·카메라 획득.
6. 주차장 밴딧 조우에서 우회 → 정상 주차장 화면·두 지점 탐색 → 실제 캠핑카 귀환·사건 마무리 → 자동저장 불러오기.
7. 수집한 부품으로 요리대·수동 발전 장치 연결 → 수동 충전 → 수집한 가스·식재료로 실제 프레임 경과에 따라 요리 완성 → 저녁 기록 → 다음 날 → 불러오기.
8. 세탁소·낡은 집 탐색 → 강변 첫 촬영·앨범·탐색 → 약국·고갯길 탐색. 첫 지역 **10/10곳** 완료.
9. 편의점의 캠핑카로 돌아온 뒤 차량을 고갯길로 이동 → 다음 지역 출발 → 자동저장 불러오기.
10. ESC → 설정 → 수동 슬롯 1 저장 → 불러오기. 카메라·첫 사진·밴딧 완료·튜토리얼 6단계가 유지되는지 확인.

첫 밤 이후 한 번 하루를 마친 경로이며, 최종 상태는 **2일 차 / 당일 사용 시간 180분 / 연료 2 / 고개 너머 진입로**였다. 카메라·사진 보상이 중복 지급되지 않았고, 요리는 가스·식재료를 각각 한 번 쓰고 식사 한 개를 지급했다. 실제 플레이어 자동저장의 SHA-256은 검수 전후 동일했다. 마지막에는 테스트 슬롯 연결을 해제하고 타이틀로 복원했다.

- 최종 화면 회귀 검수는 완주 상태의 복사본으로 장소를 선택해 확인하는 별도 검사다. 세 장소의 실제 Sprite와 저장 미리보기 Sprite가 일치하는지 검사한다. 자원 주입 없는 연속 플레이와 구분한다.
- 긴 CLI 작업은 기본 30초 응답 제한 뒤에도 Unity에서 계속 실행된다. 중복 실행하지 않고 진행 로그로 완료를 확인했다. 첫 밤 검수 입력은 숨겨진 선택 버튼 대신 현재 대화 모드를 확인하도록 보완했다. 게임 진행 오류로 집계하지 않는다.
- 대화의 타이핑 완료 입력을 자동화했으므로 이 실행 시간을 사람의 독서 속도나 체감 플레이 시간으로 해석하지 않는다. 연속 경로는 빠른 탐색·밴딧 우회 한 갈래다. 집중 탐색·판정·중간 저장·저장 실패 및 요리 중단·복원은 앞선 전용 검수 기록을 따른다.

## 다음 제작 범위

첫 여정의 연결을 다시 만드는 대신 다음 지역의 장소·사건 확장과 여러 날의 자원·사건 밀도 조정으로 이어간다. 다양한 화면 비율·입력 환경, 사람 기준 체감 속도, 전체 49일·엔딩은 후속 검수다. 대사와 음악은 사용자가 정리하는 범위를 유지한다.

새 배경의 생성 원본은 **1672×941**이며 3840px 확대용 목표에는 미달한다. PSD도 고정 배경 한 레이어로, 가구·벽·소품 내부는 분리되지 않았다. 이를 고해상도·분리 원화 납품 완료로 보고하지 않는다.

이번 작업은 로컬 작업 트리에 보관했다. 과거 원격 푸시 차단 건을 재시도하지 않았다.

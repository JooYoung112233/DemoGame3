## 완료의 의미

각 구간에 진입 이유 → 화면과 원화 경로 → 화자·대사 → 카메라·페이드·글자 출력 → 사용자 입력과 선택 → 결과와 다음 장면을 기록한다. 분기 합류, 중단 재개, 미제작 자산과 임시 자산도 표시한다. 대사·시간·새 연출은 초안과 채택을 구분한다. 원화가 존재한다고 그 장면 콘티가 완성된 것은 아니다.

기본 1920×1080, Unity 6.6, 일반 대화는 흐린 배경과 좌우 인물·하단 창. 텍스트·블러·하이라이트·지지직은 실행 시 분리한다. 부드러운 동화풍 인물은 [최신 원화 기록](../05-원화/ART-SOFT-STORYBOOK-PASS.ko.md)을 따른다.

## 챕터 1 · 1~7일 연결 골격

아래는 상세화를 위한 기준 경로다. 하루마다 같은 버튼을 모두 누르거나 모든 후보 사건을 수행하는 일정표가 아니다. 날짜 배치는 검토안이며 선행 사건을 중심으로 이어진다.

| 구간 | 이어받는 이유 → 중심 사건 → 저녁에 남는 것 | 선택·조건 사건과 다음 연결 | 상태 |
| --- | --- | --- | --- |
| 1일 | 물 필요 → 지도·편의점 → 선택 탐색·대피 쪽지 → 바로 앞 캠핑카 귀환 → 물·식량 분배 | 고장 난 요리대 암시 → 소이의 부탁. 기존 책 사용, 색연필만 퀘스트. 선확보 인정 | [낮 상세 콘티·UI 검토판](../03-콘티/챕터1/CH01-DAY01-NOON-STORYBOARD.ko.md) 제작. 낮 이후 대기 |
| 2일 | 첫 귀환에서 생긴 그림 도구 필요 → 이미 챙겼으면 전달, 없으면 잡화점 안내 → 함께 그리기 시작 | 필요한 생활 물자를 한 번에 확보. 재료 선확보 인정 | 사건 골격 있음 |
| 3일 | 첫 그림 완성·소이 반응 → 다음 길을 알아볼 이유 → 주유소에서 세진 | 긴급 연료 부족 없이 방문. 부탁을 듣고 수리점으로 이어짐 | 사건 골격 있음 |
| 4일 | 세진의 공구 가방 부탁 → 회수·전달 → 카메라와 필름 | 추가 공구·생활 수리는 선택. 카메라 획득을 무작위 성공에 잠그지 않음 | 사건 골격 있음 |
| 5일 | 세진이 알려준 쉼터 → 첫 촬영 → 앨범에서 첫 사진 확인 | 비·누수 대응, 낡은 집·별똥이 만남을 조건에 맞춰 삽입 | 사진 속 구도·인물 검토 필요 |
| 6일 | 함께 남긴 그림·사진과 현재 미완료 목표 → 동네에서 더 할 일 또는 쉬기 | 별똥이 관계·생활 수리·선택 부탁. 없을 때도 쓸 짧은 저녁 연결 필요 | 공통 연결 대사 미작성 |

날짜를 맞추려고 의미 없는 재방문을 넣지 않는다. 7일 차 출발의 정확한 시간 처리와 필수 튜토리얼을 늦게 시작한 경로는 첫 주 상세 콘티를 연결한 뒤 함께 확정한다. 위 표만으로 자동 실패·강제 스킵·날짜별 강제 발동을 도입하지 않는다.

고정 기준: 첫 편지 챕터 3 이연, 첫 그림·첫 사진은 완료까지 안내하는 필수 튜토리얼, 초반 연료는 긴급 부족 아님, 감염자·전투 보류, 별똥이·날씨·선택 부탁은 필수 경로를 막지 않음. 사건 근거는 [첫 지역 이벤트 초안](../03-콘티/챕터1/CHAPTER01-EVENT-QUEST-DRAFT.ko.md).

## 작업 순서

최신 요청 “챕터 1 가보자”에 따라 **1일 차 낮의 인과관계와 선택 분기 검토**로 진행한다. 챕터 0은 연속 검토 초안을 유지하고, 대사 퇴고는 대사집 단계로 남긴다.

1. [첫날 서사 검토판](../../design/ui/day01-v1/story.html)에서 물 확보 → 자유 탐색 → 귀환 → 식사 → 소이 부탁을 검토한다.
2. 쪽지 열람 여부, 색연필 선확보, 재료 확인, 조기 귀환을 반영한다. 고정 UI 이미지와 실제 게임 상태 구현은 구분한다.
3. [첫 주 서사 연결표](../03-콘티/챕터1/CH01-FIRST-WEEK-STORY.ko.md)의 색연필 확보 → 첫 그림 구간부터 다음 상세 컷을 만든다.
4. 길 정보 → 세진 → 공구 가방 → 카메라 → 첫 사진 순서로 동기·선택·연출을 상세화한다. 날짜는 강제 조건이 아니다.

소품 보완은 장면별로 받치는 면, 크기·시점, 접촉 그림자, 앞뒤 가림을 함께 본다. 확대 책·쪽지도 흐린 전체 배경 위에 잘라낸 이미지가 떠 있는 느낌인지 별도로 확인한다. 이름표·버튼 재설계나 승인된 배경 전체 재생성으로 범위를 넓히지 않는다. **이번 상태 정리에서 소품 그림을 수정 완료한 것은 아니다.** 각 장면을 다시 만들 때 기존 원본을 보존하며 보완한다.

## 이번 연결 검토 추가

[개연성·볼륨 보강 콘티](../03-콘티/챕터0/CH00-CONTINUITY-AND-VOLUME.ko.md)에 사진 사건을 더해 37개 진행 단위를 기록했다. **대사 퇴고는 대사집 단계로 미루며 기존 87개 발화/나레이션은 그대로 유지했다.** 실제 한 경로는 80~82개이며 도입 회상은 별도다. 양쪽 응답·준비/조사 순서·선택 관찰·저널·사진 관찰 유무 352개 조합의 상태 검사를 통과했다. 문장 수를 플레이타임이나 완성도 지표로 취급하지 않는다.

[사진을 돌보는 작은 사건](../03-콘티/챕터0/CH00-PHOTO-CARE-STORY.ko.md): 준비 중 같은 사진의 들뜬 테이프 발견(선택) → 불 복구 뒤 수혁이 모서리를 눌러 고정 → 기존 책 챙기기. 새 편지·회상·사진 획득·카메라 해금 없이 기존 물건에 대한 행동으로 서사를 보탠 검토안이다. 현재는 원래 배경·선택·연출 메모로 연결되며 손과 테이프 전후 원화는 미제작이다.

사진 고정 뒤 `photo_wish` 추가: 소이와 수혁이 앞으로의 여행도 사진으로 남기고 싶어 한다. 챕터 1에서 세진의 카메라에 관심을 보일 동기로 이어지며 기존 대사는 그대로 유지한다. 첫 촬영 뒤 이 바람을 되받는 반응을 대사집에서 작성한다.

[장소별 배경 제작표](../05-원화/CH01-LOCATION-ART-PLAN.ko.md)는 이동 장소 7곳과 캠핑카를 대상으로 기존 3개/신규 5개 빈 베이스 시안을 구분한다. 신규 베이스는 제작했고 실제 1672×941로 해상도 보강이 필요하다. 상세 대사·컷과 실제 Unity 이벤트 시스템은 후속이다.

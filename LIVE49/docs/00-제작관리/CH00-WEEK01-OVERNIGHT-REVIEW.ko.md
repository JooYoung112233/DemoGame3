## 이번 추가 작업

- 챕터 0 사진 정리용 새 소스 4점과 정지 장면 3개, 실제 레이어 PSD 7개를 제작했다. 사진은 기존 원본의 하단을 재사용해 가족 얼굴이 프레임에 들어오지 않는다.
- 테이프의 왼쪽 고정부는 두 상태에서 같은 픽셀로 유지하고 오른쪽 끝만 바뀐다. 손·테이프·사진·벽·접촉 그림자를 분리했다.
- 손과 사진의 크기·접촉점을 조정하고, 팔이 화면 안에서 잘려 보이지 않도록 1448×815 근접 구도로 정리했다. 원본 벽과 손은 별도로 보존한다.
- `photo_observe`/`photo_care`에 들뜬 상태, `photo_wish`에 고정 상태를 연결했다. 중간 손 컷은 Unity용 `art_sequence`에 등록했다. 기존 대사를 추가·퇴고하거나 새 클릭 단계를 강제하지 않았다.
- 첫 주 데이터에 남은 ‘세진·차량·강아지 후속’이라는 오래된 표기를 현재 제작 상태로 수정했다.
- 챕터 0의 `book_packed`와 첫날의 기존 책 보유 표현, 준비 물자·이름 공개 정보가 이어지는 기준을 인계 문서에 명시했다. 새로운 게임 저장 시스템을 구현한 것은 아니다.
- 원본 치수와 1.5배 여유 기준의 표시 크기를 [해상도 계획](../../design/audit/ch00-week01/resolution-plan.json)에 기록했다. 작은 그림을 확대해 고해상도 원본으로 바꾸지 않았다.

원본별 크기·파일 용량·SHA-256·PSD 레이어 수는 [파일 전수 목록](../../design/audit/ch00-week01/file-inventory.json)에 저장했다. 파일 정상 읽기는 화풍 승인을 뜻하지 않는다. 시각 검토는 현재 사용하는 챕터 0의 장면들과 챕터 1의 사건별·상태별 합성, 새 사진 정리 컷에서 크기·가림·접지·연속성을 확인했다. 과거에 보존한 모든 시안을 다시 승인하지 않았다.

검증은 로컬 이미지/파일과 콘티 데이터 기준이다. Photoshop 앱 직접 열기, Unity 임포트·실제 조명·음향·클릭 반응·퀘스트 저장은 아직 검사 대상이 아니다. 동결된 오프닝 인계 폴더는 변경하지 않았다.

# 부드러운 동화풍 · 대화와 수혁 행동 원화 1차 수정

2026-09-10 사용자 승인: “좀 뭉개니까 AI 느낌 많이 빠진다. 전체적으로 그렇게 하자. 기존 대화 원화부터 수정하고 그다음 수혁 챕터 0~1 원화”. 기준은 `art/style-revision/2026-09-10/suhyeok-storybook-face-study-source-v6.png`다. 실사 원화는 미채택. 얼굴의 뚜렷한 선과 완벽한 마감을 줄이고, 부드러운 색면·부분적으로 사라지는 윤곽·손으로 그린 불균일함을 살린다.

총 **11개 개별 원화**다. 신규 표정·대사집을 만든 것은 아니다. 손·발 클로즈업, 가족사진과 배경에 들어 있는 인물, 초기 캐릭터 시트, 미채택 구버전까지 모두 다시 그린 범위는 아니다. 이번 묶음은 기존 대화 인물 3명과 수혁의 독립 행동 원화 전종을 대상으로 한다. 배경·소품은 고정 원본을 유지했다.

## 실제 파일과 찾는 방법

루트: `art/style-revision/soft-storybook-v1/`.

- `sources/{id}.png`: 내장 image_gen 생성 원본, 확대·축소하지 않음. 같은 이름의 `.prompt.txt`에 전체 생성 요청 보관.
- `sprites/{id}.png`: 원본 캔버스 크기의 실제 RGBA 분리 인물.
- `sprites/{id}-trim.png`: 행동 포즈의 투명 여백만 자른 배치용 파일. 원본 스케일의 픽셀을 유지하며 작은 시트 컷을 확대한 파일이 아님.
- `psd/{id}.psd`: 숨김 생성 원본 / 보이는 분리 인물, **실제 2개 레이어**. 얼굴·손·옷 내부 파츠별 PSD는 아님.
- `psd/suhyeok-seated-split.psd`: 식탁 뒤 몸 / 식탁 위 팔의 **실제 2개 레이어**. 같은 원본에서 상호 배타적인 알파로 나눴고 재합성을 검사했다.
- `jobs.json`: 이전 원화·새 소스·용도·배경 제거용 확인 좌표.
- `{id}.json`: 실제 치수·알파 범위·SHA-256·검사 결과·PSD 범위·해상도 목표 충족 여부.
- `replacement-map.json`: 이전 PNG → 새 PNG와 원본·PSD 대응표.
- `review/`: 밝음·어두움 알파 검수, 챕터 0 상태 10개와 챕터 1 참고 상태 33개.
- `previous-composites/`: 이번 수정 전 챕터 0 상태 합성 보관. 기존 원화 PNG·PSD도 삭제하지 않음.

대화의 실제 연결 PNG는 기존 제공 경로를 유지하기 위해 `art/chapter00/memory/dialogue-v1/suhyeok-response-soft-v3.png`, `soi-answer-soft-v3.png`, `seoyeon-speaking-soft-v3.png`에 동일 픽셀로 복사했다. 수정 원본·PSD는 위 묶음이 기준이다.

## 검수와 한계

- 개별 원화 11개에서 원본 치수·투명 외곽·불투명 인물·RGB 보존·PSD 합성/레이어 재읽기 각 8개 검사를 통과했다. 식탁 분리는 추가로 알파 중복 없음·합성 복원을 확인했다.
- 생성된 체크 배경과 팔·머리카락 내부 빈틈은 기존 사용자가 허용한 로컬 배경 제거로 정리했다. 얼굴의 흰자·입 안과 밝은 옷을 전부 배경으로 제거하지 않도록 영역을 보호했다.
- 대화 합성, 캠핑카 낮/정전 상태, 주방의 손·냄비 관계, 강아지 접근 자세를 시각 검토했다. 33개 상태를 렌더링한 사실과 33개 모두를 개별 시각 검수한 것은 구분한다.
- 장면 합성 좌표·소품 위치·식탁 가림 순서·대사·화자 공개 규칙을 유지했다. Unity 6.6 실행 검수는 아직 하지 않았다. HTML 레이아웃이나 상호작용은 수정하지 않았다.
- 생성 원본은 주로 1024×1536이며, 탐색 1122×1402, 강아지 접근 1254×1254, 식탁 앉기 1070×1470이다. 인물 실제 높이는 **1223~1514px**로 기본 1536~2048px 목표에 못 미친다. 세부가 있는 새 원본이지만 목표 크기의 최종 마스터라고 보고하지 않는다. 단순 확대본은 만들지 않았다.
- 식탁 원화는 상반신 크롭이며 일부 셔츠 외곽이 캔버스 경계에 닿는다. 가려진 하체나 바깥쪽 몸이 복원된 전신 원화는 아니다.
- 작은 장면에서 소이 행동 원화는 아직 이전 원본이다. 이번 소이 수정은 대화 초상이며, 수혁과 함께 놓인 작은 행동 포즈까지 수정했다고 하지 않는다.
- `design/unity-handoff/opening-v1/` 보관본은 수정하지 않았다. 신규 Unity용 참조는 현재 제작 데이터와 `replacement-map.json`을 따른다.

재현: `tools/prepare-soft-storybook.py` → `tools/integrate-soft-storybook.py` → `tools/review-soft-storybook-scenes.py` → `tools/render-dialogue-review.py`. 이미 생성된 원본을 사용하며 추가 이미지 생성 호출은 하지 않는다.

참고 게임의 3D 제작 방식·공포 설정을 우리 게임의 새 요구사항으로 추가하지 않는다. 현재 2D 분리 원화와 Unity 실행 연출 구조에서 현실적인 비율·재질·빛의 일관성을 검토한다.

## 우리 게임 적용 제안 · 세부 승인 전

1. 얼굴과 몸의 실제 비율, 덜 과장된 눈, 자연스러운 표정. 수혁은 차분한 아버지 인상, 소이는 실제 어린이 비율, 서연은 성인 여성의 인상을 구분한다. 모두 같은 미형 얼굴로 만들지 않는다.
2. 얼굴 전체가 빛나는 초상화식 조명보다 현재 공간의 빛에 맞춘 음영. 옷은 섬유와 두께·중력에 맞는 주름, 피부는 과도한 미용 보정을 줄이는 방향.
3. 인물과 공간의 선명도·대비·광원 방향을 함께 판단한다. 반실사 인물만 만화 배경에 붙인 합성으로 최종 방향을 결정하지 않는다.
4. 따뜻한 아포칼립스의 정서는 노란 피부나 귀여운 비례를 필수로 삼지 않고 캠핑카의 작은 생활 조명·서로 바라보는 자세·대화로 표현한다. 불필요한 상처·주름·먼지를 추가하지 않는다.
5. 다음 검토 단위 제안은 기존 캠핑카 구도를 유지한 수혁·소이 장면 한 컷이다. 전체 인게임 자산 일괄 재생성 전에 조화와 몰입감을 비교한다. 실제 생성 지시·교체 승인은 별도로 구분하며 이 문서 작성으로 새 장면이 만들어진 것은 아니다.

기존 원본과 소품 위치, 투명 PNG·실제 레이어 PSD·큰 원본 규칙은 유지한다. 서연 얼굴 비공개, 대사로 이름을 알게 되면 이름표 공개, 텍스트와 화면 효과를 Unity에서 구현하는 규칙도 유지한다. 현재 런타임은 기존 수혁 v1이며 새 현실적 방향의 최종안으로 확정된 것이 아니다.

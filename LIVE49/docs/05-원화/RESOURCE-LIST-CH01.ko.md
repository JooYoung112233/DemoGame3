## 이미 있는 것

### 최신 제작 방식 · 레이어 분리

[챕터 1 레이어 제작물과 검수](../../art/chapter01/layers/README.ko.md)를 추가했다. 식탁·주방 소품을 비운 베이스 후보를 만들었다. 책 단독 시안은 RGB 체크무늬 배경이므로 실제 투명 스프라이트는 미완료다. [인물 배치 전체 장면 3장](../../art/chapter01/01-camper-evening/README.ko.md)은 참고용으로 보관하며 상태 전환에 사용하지 않는다. 이후 제작의 우선순위는 고정 베이스 → 실제 알파 소품·인물·가림 분리 → 같은 장면 합성 검수다.

후속 완료: 사용자 허용에 따라 기존 캠핑카 원화에서 책·컵·연필통을 직접 잘라 실제 RGBA 3종을 확보했다. 기존 체크무늬 책 시안은 사용하지 않는다. 같은 베이스에서 소품 표시와 스케치북 사건 표시를 바꾸는 화면을 검수했고, 식탁 전경도 분리했다. 인물·손 레이어와 빈 페이지/바다 그림 상태는 남아 있다.

추가 완료: [수혁 앉기·소이 앉기/그리기](../../art/chapter01/layers/characters/README.ko.md)를 기존 장면에서 추출해 몸과 식탁 위 팔·손 RGBA 6개로 저장했다. 고정 베이스에서 인물 숨김/앉기/그리기 전환과 식탁 가림을 검수했다. 페이지 그림 변화·대사 연결·요리 포즈는 다음 작업이다. 확대 선명도 개선은 보류한다.

추가 완료: [첫 바다 그림의 페이지 상태와 대화](../../art/chapter01/layers/pages/README.ko.md)를 준비했다. 빈 책 1개와 그림 오버레이 2개, 대화 초안 9개를 같은 레이어 장면에 연결했다. 캠핑카 복귀 후 그림 유지까지 미리보기에서 검수했다. 실제 저장·조건 연결과 색연필 미획득 분기, 요리 장면은 남아 있다.

## 편의점 조사 지점 제안

1. 왼쪽 앞 계산대 서랍: 열리는 진행과 소음·인기척을 연결할 후보. 세부 조작은 보류.
2. 왼쪽 뒤 식품 선반: 기본 물자 발견.
3. 오른쪽 뒤 상비약 코너: 필요한 약의 확보 여부를 판단. 기존 구급 물품장 원화를 편의점 규모에 맞게 검토.
4. 오른쪽 앞 문구 선반: 색연필 발견, 가방과 남은 탐색 여건을 고려해 선택.

가운데 냉장 진열대와 뒤쪽 문은 기존 시제품에서는 장식이다. 다음 제작에서는 냉장고를 아이템별 회수 확률과 폴라로이드 조사 화면의 검토 대상으로 추가한다. 기존 배경의 확대 사진 한 장, 별도 아이템 표시, 사진 아래 공통 UI를 준비하고 미니게임 수치·규칙은 보류한다. 출입구·창의 인기척 연출도 후보로 검토한다. 실제 클릭 범위는 적용 화면에서 정한다.

## 검수 기록

- 캐릭터 시트 1536×1024 RGB: 수혁과 소이 각각 앞 3/4·옆·뒤 3/4 외형 확인. 단일 격자나 실제 배경 크기에 맞춘 최종 포즈는 아직 아니다.
- 편의점 1672×941 RGB: 4개 조사 대상이 구분되며 캠핑카와 유사한 높은 시점·팔레트를 사용한다. 최종 실사용 배경으로 채택된 것은 아니다.
- 소품 1671×941 RGB: 8종의 구분을 확인했다. 투명 배경을 요청했으나 체크 패턴이 실제 픽셀로 그려져 있다. 이미지 생성 도구로 한 번 더 배경 제거를 요청했으나 그 결과도 RGB였다. 반복 생성은 멈추고 원본 v1을 디자인 참고로 보관한다. 투명 자산으로 사용하지 않는다.
- 소품의 크기는 시트 가독성을 위한 표시 크기이며 실제 물체 간 비율이 아니다. 색연필 상자 무늬와 그림 디자인은 최종 선택 후 기존 편의점·대화 컷에도 일치시켜야 한다.
- 현재 원화는 내장 image_gen으로 제작했다. 각 파일 옆에 프롬프트를 저장했다. Unity 적용, 포즈 배치, 개별 분리, UI 구현, 최종 화풍 확정은 미완료다.

## 다음 제작 묶음

첫 3일의 장면별 활성 상호작용을 정리하고 해당 대상부터 기준 원화에 배치한다. 저널·편지·보관함은 실제 등장 장면에 맞춰 상태별 자산을 준비한다. 공통 하이라이트·이름 표시는 활성 대상에만 적용한다. 행동 포즈는 기존 식탁·주방 위치에 맞춘다. 획득한 물건이 사라지는 상태와 폴라로이드 연결도 준비한다. 편의점은 현재 공간 규모를 유지하며 소품을 검토한다.

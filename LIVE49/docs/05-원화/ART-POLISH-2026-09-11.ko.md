# 챕터 0~1 원화 전체 보완 기록

2026-09-11 · 사용자 요청: “원화 전체 보완해줘”. 현재 콘티에서 사용하는 원화를 대상으로 작업했다. 과거 폐기 시안의 전면 재생성은 포함하지 않는다. 새 결과물의 사용자 최종 미술 승인은 별도이며, 기존 주택 통합 시안을 비율·접지 참고로 사용했다.

## 적용 결과

- 인물·강아지·차량 16개 원본을 개별 재작화했다. 수혁의 앉기·그리기·전달·수리·조사·요리·공구 회수·사진 촬영·물그릇 놓기, 소이 앉기, 세진 서기·수리, 강아지 3자세, 차량이다. 기존 인물 설정·의상·행동을 유지하며 강한 외곽선, 광택, 주황빛 피부와 옷의 과한 대비를 줄였다.
- 수혁 대화 원화 1개는 RGB를 유지하고 팔과 손가락 사이의 불투명 배경만 수정했다. 다른 승인 대화 원화는 보존했다.
- 캠핑카·편의점·주유소·잡화점·수리점·주택·강변·갈림길의 기존 부드러운 배경 8종을 기준으로 장면 60개를 재합성했다. 이 숫자에는 상태별 변형, 기존 공급품 유무 비교, 엔딩 전용 진실 변형 2개가 포함된다. 새로운 사건 60개를 뜻하지 않는다.
- 주택은 승인 비율을 적용하고 수혁·강아지·그릇·접지 그림자를 각각 분리했다. 승인 시안에 포함된 바닥 패치를 인물 스프라이트로 사용하지 않는다. 수리점·강변·주유소는 해당 장소에 맞춰 크기와 그림자를 조정했다.
- 후반 식사·기억 장면에도 같은 새 앉은 인물 원본을 연결했다. 책 위로 나오는 팔, 테이블 가림, 소품의 앞뒤 순서를 분리했다.
- 흰 테두리와 거의 투명한 외곽 잔여물을 알파에서 제거했다. 강변 촬영 원화는 이 잔여물 때문에 실제 인물이 가로로 눌리던 합성 문제도 수정했다.

장면 PSD는 1672×941 배치 좌표계다. Unity 1920×1080 화면에 맞출 때 장면 전체에 동일한 변환을 적용한다. 인물만 따로 확대하거나 PNG의 투명 여백을 인물 폭으로 계산하지 않는다. 정밀 편집은 `*-native.psd`와 native PNG를 사용하고, 장면 레이어를 원본으로 역추출하지 않는다.

원본 PSD 17개는 숨겨진 입력 원본과 표시되는 분리 대상의 실제 래스터 레이어를 갖는다. 몸의 각 부위나 들고 있는 도구까지 모두 분해된 리깅 파일은 아니다. 장면 PSD 60개는 실제 사용 배경·인물·소품·가림·그림자 레이어를 담는다. 물건을 모두 얻고 난 빈 배경 장면은 1개 배경 레이어만 있을 수 있다. 평면 배경 안의 모든 가구가 분리된 것은 아니다.

## 유지하는 연출과 서사

- 소이는 주관적 체험 장면에서 함께 보이지만, NPC와 물리적으로 상호작용하거나 독립적으로 그림을 그리지 않는다. 실제 그림 행동은 수혁이 담당한다.
- `C0-current-truth`, `E06-drawing-truth`는 엔딩 회수 전용이다. 초반 현재 장면 목록에는 넣지 않는다.
- 첫 사진의 내용, 대피 안내 종이, 카메라 전달 클로즈업, 세진 대화 원본, 챕터 0 사진 돌보기·기억 연출 원본은 검수 후 유지한다.
- 물·담요 보유 조건을 유지한다. 장면 PNG는 특정 상태의 예시이며, Unity에서는 manifest의 `condition` 및 `source_metadata`를 사용한다.
- 서연의 기억 속 얼굴 비공개, 이름을 알게 된 뒤 공개하는 화자 규칙, 편지의 챕터 3 이관, 기존 책을 사용하는 색연필 퀘스트를 변경하지 않는다.
- 기존 UI가 구워진 화면 연구 이미지와 고정 배포본 `design/unity-handoff/opening-v1/`은 과거 자료로 보존한다. 최신 깨끗한 원화는 이 문서의 manifest를 따른다.

## 검수와 한계

최종 자동 검증 통과: 새 묶음 이미지 639개 디코딩, 원본 17개 RGB·알파·치수, 장면 60개 독립 레이어 재합성, PSD 77개 합성 일치, 현재 데이터 파일 참조 319건 존재 확인. 원본·장면 생성기의 개별 PSD 채널 검증도 통과했다. 초반 목록에 진실 변형이 노출되지 않으며 두 진실 변형의 픽셀 차이는 소이 영역에만 있다. 콘티 참조 110곳을 갱신했고 변경 내역과 이전 내용을 별도 저장했다.

원화별 알파 배경 합성, 장면 60개 전체 비교 시트, 주요 인물의 접지·손과 책의 겹침을 확인했다. 자동 검증은 실제 `validation.json` 결과를 따른다. PSD 생성기는 합성 이미지뿐 아니라 각 레이어 채널의 압축 데이터를 독립적으로 풀어 입력과 대조한다. Photoshop 및 Unity 앱에서의 렌더링·색 관리 호환성 검증은 아직 수행하지 않았다.

생성 도구에 큰 개별 원본을 요청했으나 출력은 대체로 약 1K~1.5K 크기에 머물렀다. 각 파일의 실제 캔버스와 인물 영역 치수를 native manifest에 기록했다. **배경 3840px와 주요 인물 실제 높이 1536~2048px 목표를 모두 충족한 최종 납품본은 아니다.** 기존 구도를 보존하기 위해 배경을 단순 확대해 새 고해상도 원본으로 표시하지 않았다. 큰 확대 연출을 확정할 때 해당 컷의 부분 재작화가 필요하다.

재생성 순서: `tools/prepare-art-polish-native.py` → `tools/prepare-art-polish-scenes.py` → 그림 검수 → `tools/integrate-art-polish-v1.py` → `tools/validate-art-polish-v1.py`. 과거 원본과 참조 백업을 보존한다.

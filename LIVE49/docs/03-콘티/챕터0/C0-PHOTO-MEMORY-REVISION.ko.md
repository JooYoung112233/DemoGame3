# C0 · 폴라로이드로 들어갔다 돌아오는 회상 제안

> **2026-09-10 갱신:** 아래는 논의 당시 기록이다. 사용자의 ‘좋다 이렇게 정하고 다음 진행하자’로 방향을 확정하고 원화·PSD·실행 시안을 제작했다. 현재 적용 순서·시간·경로는 [사진 회상 실행 콘티](C0-PHOTO-MEMORY-IMPLEMENTATION.ko.md)가 우선한다. 아래의 ‘미확정/아직 미반영’ 상태는 역사 기록이다.

## 최신 사진 표현 논의 · 서연 얼굴의 기억 소실

사용자가 노을을 보는 가족 뒷모습 사진을 제안한 뒤, 너무 뻔한 표현을 피하고 서연의 얼굴을 모자이크/안면인식처럼 표현해 수혁이 점점 기억을 잃어가는 느낌을 주자고 제안했다. **새 서사·시각 방향 논의이며 확정 원화·실행 효과는 아직 없다.** 아래 본문의 ‘동일 사진이 모두 선명하게 돌아온다’는 설명은 이 제안에 따라 재검토 대상이다.

- 구도 제안: 노을을 보는 수혁과 소이는 뒤를 향하고, 서연만 소이/카메라 쪽으로 고개를 약간 돌려 얼굴 일부가 보인다. 완전한 뒷모습에서는 얼굴 소실을 식별하기 어렵기 때문이다. 구도는 아직 사용자 채택 전이다.
- 현재 사진에 돌아왔을 때 풍경·옷·다른 가족은 선명해지지만 서연 얼굴의 눈·코·입 부분만 초점이 맺히지 않는 표현을 검토한다. 얼굴이 보이는 각도와 시점은 새 사진 원화 단계에서 확인한다.
- 모자이크/안면인식의 구체 방식은 미확정이다. 제안은 화풍에 맞는 작은 색면의 어긋남·국소 초점 실패이며, 인식 사각형·숫자·경고문·스캔 소리 등 실제 기계 UI는 기본안에 넣지 않는다. 얼굴 영역을 구분하는 작은 효과가 기술 장치로 오독되지 않도록 검토한다.
- 첫 회상은 익숙한 동작·말은 떠오르는데 얼굴은 붙잡히지 않는 단서로 제한하는 후보. 이후 챕터에서 소실이 진행되는 규칙은 별도 기획이 필요하며, 현재 게임 전체에 기억 상실/질환 설정을 확정한 것으로 보지 않는다.
- 기본 사진과 서연 얼굴 영역 마스크/별도 레이어를 보관하고, 시점에 따른 국소 블러·색면 효과는 Unity에서 조합하는 후보다. 영구 훼손된 단일 사진만 제작하지 않는다.
- 같은 사진에서 인물이 사라지거나 다른 인물로 바뀌는 효과와는 구분한다. ‘사진 자체의 손상’인지 ‘수혁의 지각/기억 표현’인지 플레이어가 어떻게 받아들이는지 연출 검토가 필요하다.

이전 제안은 아래에 보존한다. 이번 변경에 대한 코드·새 이미지 제작은 아직 시작하지 않았다.

사용자 제안: 일기장 위 손에서 캠핑카 안 폴라로이드(사진 블러)를 보여주고, 페이드로 산책과 기존 회상 대화에 진입한다. 서연이 돌을 뺀 뒤 다시 엄마 손을 잡을지 묻고 소이가 답한다. 다시 페이드하여 처음의 폴라로이드를 선명하게 보여준다.

**상태: 새 흐름 논의안 기록. 현재 브라우저에는 아직 반영하지 않았다.** 기존 손잡기·일반 대화창·원본 분리 규칙은 유지한다. 이 안에 들어가는 새 사진의 정확한 내용·위치·추가 대사·초 단위 연출은 미확정이다.

## 연결안

| 순서 | 화면 | 대사·인과 |
| --- | --- | --- |
| P01 현재의 일기장 | 캠핑카 식탁의 일기장에 수혁의 손이 놓여 있음 | 현재 시점의 출발점. 기존 책·손 그림은 임시 배경이며 실제 일기장/캠핑카 일관성 검토 필요 |
| P02 회상의 계기 | 수혁의 시선이 향한 캠핑카 안 폴라로이드로 컷/카메라 이동. 사진 속 내용만 약하게 블러, 종이 테두리·주변은 식별 가능 | 수혁이 사진을 보며 기억하는 흐름. 현재에서 실제로 들려오는 목소리와 혼동하지 않도록 ‘수혁아.’를 사진에서 회상으로 들어가는 소리/자막 선행 후보로 검토 |
| P03 산책 | 페이드 뒤 기존 발 멈춤 배경. 일반 하단 창으로 나레이션 → 서연의 신발 속 돌 이야기 | 기존 나레이션/대화 구조 유지. 전체 회상을 사진 프레임 속 대화로 바꾸는 안은 아님 |
| P04 아빠에게 손을 맡김 | ‘소이 손 좀 잡아줘.’ → 수혁 ‘응.’ → 수정한 수혁·소이 두 손 컷 | 서연은 돌을 빼기 위해 손을 놓는다. 세 손 포개기 컷은 다시 쓰지 않는다 |
| P05 돌을 뺀 뒤 | 같은 회상 배경에서 서연 대화 | 제안: ‘됐어. 다시 엄마 손 잡을래?’ 손을 맡긴 이유가 해결됐음을 알림 |
| P06 소이의 답 | 소이 대화 일러스트가 등장하고 같은 하단 창 사용 | 제안: ‘아니. 아빠 손 잡을래.’ 그러면 수정한 두 손 그림을 유지할 수 있고, 아이가 아빠 손을 계속 잡기로 선택한 기억이 됨. 사용자 대사 확정 전 |
| P07 기억의 마무리 | 서연의 짧은 반응, 손을 잡은 상태 잠깐 유지 | 선택 대사 제안: ‘그래. 그럼 가자.’ 추가 대사 유무는 함께 결정 |
| P08 현재의 사진 | 페이드하여 P02와 같은 위치·구도·같은 사진으로 돌아옴. 사진 내용은 이제 선명함 | 사진이 교체되거나 사람이 사라지는 반전 효과 없음. 앞서 본 가족의 기억을 현재의 사진에서 알아보게 함 |
| P09 현재 소이 | 사진을 잠깐 읽을 여백 뒤 소이 ‘아빠?’ → 현재 캠핑카 대화 | 회상과 현재를 구분하고 다음 날 준비로 연결. 이 다음 구간의 대사는 별도 검토 |

사진 내용은 **산책하던 날 세 사람이 함께 찍은 가족사진**을 우선 후보로 제안한다. 아직 해당 사진 자산이 존재한다고 보지 않는다. 선명한 원본 하나를 만들고, 흐린 상태는 Unity 블러로 처리해 앞뒤 내용·인물·구도가 달라지지 않게 한다. 사진 블러는 기억이 흐릿했다거나 기억 자체가 거짓이라는 설정으로 확정하지 않는다.

‘수혁아.’를 현재 책 위에 출력하는 이전 시안은 위치 재검토 대상이다. 사진을 본 뒤 산책에 들어가기 직전으로 옮기면 사진을 보고 회상이 시작된다는 인과가 읽힌다. 기존 타이핑/딤의 채택 수치를 그대로 적용할지는 사진 배치와 함께 검토한다. 아직 실행 코드나 기존 승인 데이터를 덮어쓰지 않았다.

## 필요한 자산·구현 구분

- 캠핑카 내부의 폴라로이드 위치와 일기장에서 사진으로 향하는 구도: 새 콘티 검토 필요.
- 선명한 가족사진 원본, 종이 프레임, 배경/고정 클립 등 필요한 물체는 분리한다. 낮은 해상도 합성 확대를 최종 원본으로 삼지 않는다.
- 소이의 회상 대화 초상 1개 필요. 현재 서연·수혁 초상과 화풍·비례를 맞춘다. 최종 표정 세트는 여전히 대사집 후 제작한다.
- 기존 발·길·수혁과 소이 두 손 PNG, 하단 대사창 PSD는 재사용 가능하다.
- 글자·이름·사진 블러·화면 페이드·캐릭터 등장/화자 전환은 실제 Unity 6.6에서 처리한다. 사진 원화에 글자나 블러를 굽지 않는다.
- 대사 읽기 대기는 플레이어 입력을 따른다. 무대사 여백과 페이드는 짧은 자동 연출 후보이며 시간은 아직 정하지 않았다.

현재 구현 파일과 수정 전 자산 경로는 [회상 대화 콘티](C0-MEMORY-DIALOGUE.ko.md)를 참조한다. 새 흐름을 채택해 제작할 때 이 문서의 각 컷을 실제 파일·상태·타이밍에 연결한다.

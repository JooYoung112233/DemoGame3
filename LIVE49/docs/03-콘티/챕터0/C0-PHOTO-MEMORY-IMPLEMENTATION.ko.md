# C0 · 사진에서 시작된 기억

> 현재 생활에서의 후속 활용: [사진 모서리를 다시 고정하는 작은 사건](CH00-PHOTO-CARE-STORY.ko.md)을 검토안으로 추가했다. 도입 연출과 기존 대사는 유지하며, 새 회상·지지직·얼굴 복원을 반복하지 않는다. 손·테이프 원화는 미제작이다.

> 최신 후속: [서연 얼굴 비표시와 현재 대화](C0-PRESENT-DIALOGUE.ko.md), [소개 전 화자 `?` 규칙](../../06-대사/SPEAKER-IDENTITY-RULES.ko.md). 아래 회상 초상 사용 문구와 P09 종료 표기는 대체된다. 현재는 서연 초상 없이 회상을 진행하고 ‘아빠?’ 확인 후 현재 대화까지 이어진다.

2026-09-10 사용자 ‘좋다 이렇게 정하고 다음 진행하자’로 사진→회상→동일 사진 복귀, 서연 얼굴의 기억 소실과 짧은 지지직을 제작 방향으로 확정했다. **새 원화·초 단위 효과·추가 대사 문구는 실행 시안이며 세부 검토 대상**이다. 이전 ‘사진 전체가 선명해짐’, ‘됐어. 이제 가자.’, 회상 직후 책 위 손 복귀안을 대체한다.

기준 1920×1080, Unity 6.6. 실제 글자·블러·페이드·모자이크·화면 어긋남은 Unity 런타임 구현 대상이다. HTML은 연출 검토용이다. 일반 대화는 기존 하단 창·좌우 인물 구성을 유지한다.

## 순서·시간·입력

시간은 각 구간 진입부터 계산한다. 문장을 읽는 시간은 사용자 입력에 따라 달라진다.

| ID | 화면·대사 | 시간·다음 조건 |
| --- | --- | --- |
| P01 | 기존 책·손, 시작 메뉴 사라짐 | 메뉴 .08~.48초, 카메라 .15~1.35초 1→1.035. 채택값 유지. 1.35초에 사진으로 자동 진입 |
| P02 | 책에서 캠핑카 벽 사진으로 디졸브 | 0~.45초. 사진만 13px 블러, 종이 선명. 전환 중 입력 무시 |
| P02 확대 | 작은 벽 사진을 중앙 상세 컷으로 확대 | .45~1.70초. 캠핑카 배경 최대 4px 블러와 46% 딤. 사진 내용 흐림 유지 |

| P06 | 소이 ‘아니. 아빠 손 잡을래.’ | 소이 초상 .30초 등장. 같은 손 배경 유지. 읽고 입력 |
| P07 | 서연 ‘그래. 그럼 가자.’ | 서연 초상 .30초 등장. 읽고 입력하면 암전 .40초 |
| P08 복귀 | 처음과 같은 사진·프레임·최종 위치 | 0~.50초 암전에서 등장. 얼굴 마스크는 처음부터 적용하여 온전한 얼굴 순간 노출 방지 |

| P08 지지직 | 화면의 가는 수평 띠가 어긋나고 약한 주사선 | **1.42~1.58초, 0.16초 단발**. 종료 후 화면 정상, 얼굴은 계속 불분명 |
| P09 | 현재 소이의 화면 밖 부름 ‘아빠?’ | 지지직 뒤 약 1.5초 여백. 딤 2.70초 시작. 글자 3.10초 시작, .11초/글자, 3.32초 완료. 3.60초 정지 |

부름의 장소와 시작 시점은 새 시안이다. 과거 책 화면 1.75초 시작의 승인과 구분하며, 기존 글자 리듬·폰트·색감만 재사용한다. 글자 출력은 최종 문장 폭을 고정한다. 시작 클릭을 다음 대사로 넘기지 않으며 전환 입력과 Space 반복 입력은 무시한다. 앱 비활성 중 시간을 멈춘다.

## 그림과 의미

노을을 보는 뒷모습: 왼쪽 서연, 가운데 소이, 오른쪽 수혁. 서연만 소이 쪽으로 고개를 돌려 옆얼굴이 보인다. 인물을 지우거나 교체하지 않는다. 얼굴을 알아보려 할 때 초점이 맺히지 않는 느낌이다. 인식 박스·수치·경고 UI는 넣지 않는다.

익숙한 동작과 말은 떠오르지만 얼굴은 붙잡히지 않는 첫 단서다. 게임 전체 질환명이나 기억 소실 진행 규칙까지 확정하지 않았다. 회상 대화에서 서연 초상은 표시하지 않으며 발·손 배경과 대사만 보여준다.

캠핑카는 [`camper-clean-base-v3.png`](../../../art/chapter01/revision-v3/camper-clean-base-v3.png) 그대로 재사용한다. 책과 캠핑카는 다른 카메라 각도이므로 디졸브 컷으로 연결한다. 한 장의 연속 카메라 이동으로 보고하지 않는다.

프레임 좌표(1920 기준): 작은 상태 `[1442,269,44,28.34]` → 상세 상태 `[300,70,1320,850.16]`. 사진 비율 유지. 기존 벽의 작은 가족사진 위치를 덮는 검토 배치다. Unity 실내 최종 배치 시 별도 벽 사진 스프라이트로 연결하고 기존 그림이 테두리 밖에 남지 않는지 확인한다.

얼굴 영역 대략 `[610,265,110,100]` (사진 원본 기준). 브라우저는 76×43 샘플을 최근접 확대해 얼굴 마스크로 제한한다. Unity에서는 사진 UV를 셀 단위로 양자화하고 마스크 알파로 혼합한다. 마스크와 프레임은 원본과 별도 보관한다.

사진 **네이티브 1672×941**, 소이 **1024×1536**으로 큰 최종 원본 목표에 미달한다. 단순 확대를 4K 디테일 원화로 보고하지 않는다. 확대 디테일·초상 간 화풍 통일은 후속 보강 대상이다. PSD는 채널 재읽기로 검사했으며 Photoshop 앱·Unity 직접 검수는 미실시다.

## 서연 얼굴 비공개

- 모든 회상 대사에서 서연 초상을 표시하지 않는다. `?` 이름표와 대사만 기존 하단 창에 표시한다. 발·잡은 손 배경은 그대로 유지하며 추가 얼굴 모자이크를 대화 중 반복하지 않는다.
- 수혁 ‘응.’에서도 서연 초상은 함께 나타나지 않는다. 소이 답변 초상은 유지한다.
- `memory-dialogue.json`의 `suppressed_portraits: [seoyeon]`와 각 문장의 `portraits` 목록 모두 적용한다. HTML에도 서연 이미지 기본 숨김을 지정하고 원본 초상을 런타임에서 로드하지 않는다.
- 기존 `seoyeon-speaking-*.png/psd`는 원본·편집 참고로 보관한다. 파일 존재가 이 장면 사용 허가를 의미하지 않는다. 사진의 얼굴 마스크와 0.16초 지지직은 유지한다.
- 현재 사용 중인 나레이션·서연·수혁 응답·마무리 합성 검수 PNG도 원본 데이터에서 다시 출력하여 얼굴 공개가 남지 않게 했다. 이전 고정 인계본 `opening-v1`은 역사 기록으로 유지한다.

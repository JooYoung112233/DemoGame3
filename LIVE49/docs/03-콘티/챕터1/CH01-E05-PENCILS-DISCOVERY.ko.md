# E05 · 잡화점 색연필 발견 → 소이에게 전달

2026-09-10. 잡화점 원화와 분리 색연필을 사용한 **발견·획득 전후 원화 및 연출 초안**. 실제 Unity 이벤트 실행과 정식 대사는 후속이다. 캐릭터 이동 애니메이션·UI 시안 작업은 이번 범위에 넣지 않았다.

## 진입과 분기

- 첫날 낮의 소이 부탁으로 Q05가 진행 중이고 색연필이 없다면 지도에서 생활 잡화점 L3를 안내한다. 기존 책은 챕터 0에서 챙긴 것을 쓴다.
- 편의점에서 이미 색연필을 얻었다면 다음 목표는 바로 **소이에게 건네기**다. L3 방문·중복 탐색을 요구하지 않는다.
- L3의 첫 그림용 색연필은 눈에 보이는 확정 확보분으로 제안한 설계를 따른다. 이 물건에는 추가 확률 미니게임을 붙이지 않는다. 같은 장소의 선택 생활용품은 별도 탐색 대상이다.
- L3를 먼저 둘러보는 경로에서도 선확보는 인정한다. 부탁을 아직 듣지 않았다면 획득만 기록하고, 나중에 Q05가 생성될 때 보유 여부를 재확인한다. 아래 원화는 현재 물건이 남은 경우와 회수한 경우를 구분한다.

표의 전환 시간과 카메라 배율은 초안이다. 강제 대기로 분량을 늘리지 않는다. 현재 배경은 1672×941이므로 상판을 화면 전체로 확대하는 연출은 더 큰 배경 원본 확보 전 사용하지 않는다. 색연필 자체는 아래 큰 원본을 사용한다.

원본 색상은 그대로 두고 이전 사용자 승인에 따라 배경만 로컬 처리로 제거했다. 획득 전후 합성에서 바뀌는 영역은 소품과 그림자 범위뿐이다. PSD의 채널·위치·합성을 파일 리더로 다시 확인했다. Photoshop 앱·Unity 실행 검증은 아직 하지 않았다.

## 저장·중복 방지 기준

물건 확인/대사 재열람과 획득 확정은 분리한다. 획득 확정 후 재접속해도 중복 지급하지 않는다. 취소했으면 물건이 남는다. 이미 보유했거나 소이에게 전달했다면 첫 그림 안내를 다시 잠그지 않는다.

첫 튜토리얼 도구를 획득한 뒤 임의 판매·제작 소모로 첫 그림이 막히지 않게, 첫 그림 완료까지 이 묶음을 보호하는 방안을 제안한다. 실제 아이템 분류·소모 규칙은 후속 확정한다. 두 번째 색연필 묶음을 얻는 선택 탐색과 이 최초 도구 상태를 혼동하지 않는다.

## 다음 원화

수혁이 기존 책 곁에 색연필을 놓는 손/팔 → 도구가 준비된 같은 식탁 → 첫 그림의 시작·완성 페이지. 소이는 수혁의 시점에서 대화하며 물건을 직접 옮기는 새 동작을 추가하지 않는다. 첫 그림 내용과 대사는 별도 검토한다.

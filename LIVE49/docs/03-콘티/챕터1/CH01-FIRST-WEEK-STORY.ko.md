## 챕터 0에서 이어받는 것

어제 챙긴 물·담요·기존 책은 유지한다. 물을 갑자기 전부 잃거나 다시 짐을 챙기는 튜토리얼은 없다. 오늘 생활하고 이동하려면 추가 물이 필요하다는 이유로 출발한다. 초반 연료는 긴급 부족이 아니다.

벽의 가족사진을 돌본 뒤 생긴 “앞으로의 여행도 사진으로 남기고 싶다”는 바람을 유지한다. 첫날 아침에는 물·식량에 집중하고, 카메라 퀘스트를 동시에 열지 않는다. 세진의 촬영 장비를 보았을 때 관심을 보이는 동기로 되받는다. 옛 저장에 `wants_new_photos`가 없어도 카메라·첫 사진 진행을 막지 않는다.

소이의 존재 표현은 수혁의 시점에 머문다. 물건을 놓고 옮기는 동작은 수혁이 수행한다. 세진이 소이를 직접 확인하거나 사진 속 인물을 통해 새로운 사실을 확정하는 연출은 넣지 않는다. 첫 사진의 구도는 별도 검토한다.

## 1일 차 낮 · 사건마다 남는 이유

| 구간 / 검토판 ID | 행동과 연출 | 다음 사건을 여는 이유 |
| --- | --- | --- |
| 아침 `morning` | 전날 정리 상태를 이어받은 캠핑카. 오늘 쓸 물을 더 구하기로 한다. | 어제의 출발 약속이 구체적인 목적지 선택으로 바뀐다. |
| 지도 `map` | 편의점 선택 → 소요 시간 카드 → 출발 확인. 취소하면 아침으로. | 가까운 가게를 먼저 확인하는 선택에 근거를 준다. |
| 도착 `travel` | 짧은 암전 → 엔진 정지·주차 브레이크·문소리 → 편의점. | 캠핑카는 편의점 바로 앞에 주차했다는 정보. 실제 음향은 미제작. |
| 자유 탐색 `store` | 물·식량을 안내하되 나머지 지점은 선택. 가리킨 대상 하나만 강조한다. | 오늘 필요한 것과 유저가 궁금한 것을 함께 살필 공간. |
| 냉장고 `fridge` | 물품별 확률·총시간 → 빠른 탐색 또는 집중 탐색 → 결과. | 첫 분배용 확보분과 추가 물자를 분리한다. 확정분을 둘지는 현재 밸런스 초안이다. |
| 식량 `food` | 같은 탐색 패널 재사용. 바로 먹을 식품 확보. | 고장 난 요리대를 먼저 고치지 않아도 식사가 가능하다. |
| 생활 재료 `materials` | 부품·천·테이프 확인은 선택. 레시피 전체를 설명하지 않는다. | 귀환 뒤 요리대 수리 암시를 이해하는 선행 경험이 된다. |
| 문구대 `stationery` | 부탁 이전에도 색연필을 발견할 수 있다. 미확보·선확보 사례를 나눠 검토. | 선행 탐색의 가치를 소이의 부탁에서 인정한다. |
| 쪽지 `notice` | 계산대의 공공 안내. 감염자 주변 글이 지워져 있고 안내의 유효성은 불명. | “어디가 안전할까”라는 질문. 서연의 편지와 분리한다. |
| 조기 귀환 `early_return` | 물·식량 확인이 덜 된 경우 문 앞 캠핑카에서 부족분을 안내. 재입장 가능. | 확보 상태를 유지하고 분배만 미룬다. 재이동 시간을 부과하지 않는다. |
| 귀환 `return` | 짧은 전환 후 캠핑카. 이곳에 머물지 고민한다. | 쪽지를 읽었다면 안내의 유효성도 떠올린다. 안 읽었다면 해당 정보를 말하지 않는다. |
| 분배 `ration` | 수혁이 두 자리 몫을 식탁에 놓는다. 남겨 둘 재고도 보여 준다. | 탐색 보상이 함께 보내는 생활로 이어진다. |
| 요리대 `kitchen` | 고장 상태를 짧게 살핀다. 수리·요리 기능은 아직 열지 않는다. | 다음에는 따뜻한 식사를 준비하고 싶은 작은 목표. 재료를 살핀 경로만 그 경험을 되받는다. |
| 부탁 `soi` | 식사 뒤 소이의 느낌표 하나 → 선택 → 그림을 그리고 싶은 바람. | 급한 필요를 해결한 뒤 아이의 바람을 들을 여유가 생긴다. |
| 낮 마무리 `quest_search / quest_owned` | 기존 책은 이미 있다. 색연필 미보유면 찾기, 보유면 건네기. | 다음 구간의 목적을 하나 남기고 낮 콘티를 닫는다. |

쪽지·문구대·재료를 전부 누르는 것이 필수 경로가 아니다. 검토판은 임시 분기 상태만 보관한다. 이미지 안의 수량·문구는 이전 UI 시안이며 실제 확률, 물자 지급, 시간 계산을 실행하지 않는다. 색연필 보유 분기의 카드 문구 교체는 후속 UI 상태 작업이다.

## 첫 주 · 하루를 넘길 때 남기는 목표

날짜는 분량 배치를 위한 예시다. 사건 완료 상태로 연결하며, 달력 날짜만으로 강제 발동·자동 실패시키지 않는다. 빨리 확보한 물건 때문에 의미 없는 재방문을 요구하지 않는다.

| 배치 예시 | 사건의 연결 | 끝에 남기는 질문 / 다음 행동 | 상세화 상태 |
| --- | --- | --- | --- |
| 1일 낮 | 물 확보 → 식사 → 소이의 색연필 부탁 | 이미 있으면 건네기, 없으면 구할 곳 확인 | 이번 분기 검토판 연결 |
| 1일 오후~2일 | 색연필 전달 → 기존 책에 첫 그림 → 함께 보기 | 그림으로 남긴 풍경 너머에는 무엇이 있을까 | 아래 확보 경로 초안. 그림 세부 컷 후속 |
| 3일 전후 | 다음 길 정보를 얻으려 주유소 L2 방문 → 세진과 대화 | 그의 카메라에 관심 → 공구 가방 부탁 | 기존 사건을 연결. NPC 대사·장면 미제작 |
| 4일 전후 | 수리점 L4에서 공구 가방 회수 → 세진에게 전달 | 여분의 즉석카메라·필름과 촬영할 장소 정보 | 카메라 보상은 추가 공구 선택 퀘스트와 분리 |
| 5일 전후 | 강변 쉼터 L6 → 첫 촬영 안내 → 앨범에서 확인 | 챕터 0의 사진 바람을 실제 새 기록으로 되받음 | 카메라/필름 원화 제작. 촬영 자세·풍경 사진·앨범 상태 시안 제작. 최종 구도 검토 후속 |
| 6일 전후 | 그림·사진을 돌아보고 생활 수리 또는 선택 부탁 | 머무를 이유와 다음 길로 나갈 준비 | 별똥이·날씨는 조건에 맞춰 삽입. 상세화 후속 |
| 7일 전후 | 확보한 길 정보 → 고갯길/우회로 확인 → 다음 지역 출발 | 기록과 소지품, 약속을 다음 챕터로 가져감 | 출발 조건·늦은 진행 처리 후속 |

물자를 모았다는 이유만으로 다음 날을 넘기지 않는다. 그림은 함께 보고 싶은 풍경을, 세진은 그 풍경으로 갈 길과 사진을 남길 수단을, 첫 사진은 떠나기 전 챙길 기억을 남기는 연결이다. 공공 대피 안내는 선택 단서로 남기며, 미열람 경로에서도 주유소에서 길 정보를 구할 동기는 성립해야 한다.

## 바로 다음 구간 · 색연필과 첫 그림 초안

1. **이미 보유:** 부탁 응답 → 수혁이 기존 책 곁에 색연필을 놓는다 → 첫 그림 안내로 연결. 추가 탐색을 강제하지 않는다.
2. **미보유:** 물품을 찾을 만한 잡화점 L3를 지도 후보로 안내한다. 발견 이유는 주변 상점 안내/지도 표기 중 후속 컷에서 확정한다. 쪽지를 읽어야만 열리게 하지 않는다.
3. **첫 그림을 막지 않는 확보:** 잡화점에 눈에 보이는 색연필 한 묶음을 두고 확인 행동으로 확보하는 방안을 제안한다. 기존 편의점의 확률 탐색은 유지한다. 이 보장 방식·소요 시간은 아직 사용자 검토 전 초안이다.
4. **귀환과 그리기:** 기존 책을 다시 꺼내고 색연필을 준비 → 첫 그림 필수 안내 → 완성된 페이지를 함께 본다. 그림 결과를 소모품 확률이나 미니게임 실패로 잠그지 않는다.
5. **다음 길로:** 그림을 보는 장면에서 새로운 풍경을 찾아갈 동기를 만든다. 곧바로 세진이 나타나거나 모든 지도 지점이 열리는 전개는 피하고, 길을 알아볼 주유소를 다음 목표로 삼는다.

## 원화 재사용과 미제작 항목

이번 변경은 콘티·검토판이며 기존 PNG/PSD를 다시 만들지 않았다. 장면별 실제 파일 경로는 [manifest](../../../design/ui/day01-v1/manifest.json)의 `preview`, `psd`, 레이어 목록과 [자산표](CH01-DAY01-NOON-STORYBOARD.ko.md)를 함께 사용한다. 참고 JPG를 편집 원본으로 삼지 않는다.

- 캠핑카·편의점: 기존 v3 고정 배경과 소프트 인물, Day1 UI 패키지 재사용. 새 아침 조명·상태별 정확한 소품 접지는 후속 검수.
- 계산대 쪽지: 기존 종이·분리 글자·지워짐 레이어 사용. 주민센터 명칭은 가칭이며 안전이 확인된 장소가 아니다.
- 첫 그림: 기존 책과 소품 배치 자료는 있으나 작은 잘라내기 시안은 최종 확대 원본으로 쓰지 않는다.
- 잡화점: [빈 베이스 v1](../../../art/chapter01/general-store-v1/README.ko.md) 구도 시안과 가림용 3레이어 PSD를 제작했다. 원본 1672×941로 목표 해상도 보강 필요.
- 주유소·수리점·강변 쉼터·고갯길: 빈 베이스와 일부 가림/표면 복사 PSD 제작. 모든 새 장소는 1672×941 구도 시안이며 최종 확대 원본 보강 필요.
- 가방·카메라·필름 독립 원본과 회수 전후 상태를 제작했다. 세진 기본 서기·차량 시안도 제작. 외형 확정·인수 자세는 후속. [세진~첫 촬영 콘티](CH01-E07-11-PHOTOGRAPHER-STORYBOARD.ko.md) 참조. [첫 그림 상세 콘티](CH01-E06-FIRST-DRAWING.ko.md)에는 전달 자세·페이지 상태·Q07 연결을 추가했다.
- 글자 한 글자 출력, 배경 블러, 화자 강조, 전환·음향의 정확한 타이밍은 장면별 상세화 단계에서 확정한다. 현재 검토판의 버튼은 개발용 장면 이동이며 인게임 UI 확정안이 아니다.

[별똥이 만남~자리 마련 상세 콘티](CH01-E12-14-DOG-STORYBOARD.ko.md)와 개별 원화 3자세·그릇/깔개를 추가했다. [첫 사진 원화](../../../art/chapter01/first-photo-v1/README.ko.md)는 기존 강변의 풍경만 담는 검토안이며 인물 존재를 확정하지 않는다.

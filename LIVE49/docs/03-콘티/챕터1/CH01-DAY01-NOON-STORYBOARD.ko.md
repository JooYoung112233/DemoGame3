## 공통 연출과 입력

1920×1080, Unity 6.6. 기존 v3 편의점·캠핑카 구도 유지. 일반 대화는 배경 블러 5px 상당 + 좌우 인물 + 하단 대사창을 기준으로 한다. 이번 화면 패키지는 UI 배치를 보는 합성이라 대화용 큰 인물은 매 장면 다시 합성하지 않았다. 실제 초상은 아래 기존 원본을 쓴다. 서연은 이 구간에 등장하지 않는다. 수혁·소이는 챕터 0에서 이름을 들었으므로 실명을 표시한다. 챕터 선택 진입도 해당 이름 공개 상태를 복원해야 한다.

UI 등장 0.20초, 퇴장 0.15초. 한글 기본 0.055초/문자 시안. 텍스트 출력 중 첫 입력은 문장 완성, 다음 **새 입력**이 다음 문장으로 진행. 선택·분배 확정에 직전 입력이 전달되지 않도록 한다. 대기 시간은 연출용 짧은 구간에만 쓰며 실제 탐색 5분/15분을 실시간으로 기다리게 하지 않는다. 접근성 설정에서 타이핑·블러·짧은 암전 효과를 줄여도 대사 순서가 유지된다.

소리 경로는 아직 실제 파일이 없는 **제작 예정 cue ID**다: `amb_camper_morning`, `sfx_engine_start`, `sfx_engine_stop`, `sfx_parking_brake`, `sfx_camper_door`, `amb_store_roomtone`, `sfx_shelf_rattle`, `sfx_bag_place`. 최종 녹음·믹싱 미완료. 검토판은 소리를 재생하지 않고 설명만 제공한다. 소리만으로 필수 정보를 전달하지 않는다.

## 탐색·시간·선택의 연결

다음 숫자는 모두 조정 가능한 예시다. 사용자 확정 밸런스가 아니다. 일정한 낮 구간 안에서 네 물자 지점을 전부 집중 탐색해도 이동 포함 80분 수준인 샘플이지만, 실제 날짜 전환 시각과 미니게임 체감 길이는 아직 정하지 않았다. ‘낮 구간 끝’이라는 서사 경계가 무조건 12시로 시간을 점프한다는 뜻은 아니다.

| 지점 | 한 번 판정하는 후보 | 목적 |
| --- | --- | --- |
| 냉장고 | 눈에 보이는 생수 2개 100%, 추가 생수 1개 45%, 밀봉 음료 1개 30% | 첫 분배 진입 보장안 + 추가 물자 선택 |
| 식품 선반 | 눈에 보이는 포장 식량 2개 100%, 통조림 1개 50% | 고장 난 요리대 없이 먹을 식량 확보 |
| 생활용품 상자 | 쓸 만한 부품 1개 55%, 천 조각 1개 65%, 테이프 1개 35% | 추후 제작·수리의 재료 후보. 레시피 확정 아님 |
| 문구대 | 색연필 1개 40%, 천 조각 1개 40% | 부탁 이전 선확보 인정. 실패하면 후속 퀘스트에서 확정 확보 경로 안내 |
| 계산대 쪽지 | 확률 판정 없는 열람 | 세계 단서, 선택 사건 |

품목별 독립 판정이다. 확률 합을 100으로 맞추는 보상 추첨표가 아니다. 성공 보너스는 20**%p**를 더하고 100%에서 제한한다. 보너스가 확정 품목을 추가 지급하지 않는다. 각 행의 정해진 수량을 성공 시 한 번 지급한다. 두 생수 행은 같은 인벤토리 아이템 ID로 합산한다.

행동 확정 전 닫기는 무료. 확정할 때 시간·방식·난수 토큰을 저장하고 중단 후 같은 시도를 복원한다. 미니게임에서 나가도 시간을 돌려주거나 새 주사위를 주지 않는다. 이어 하거나 기본 확률 정산을 고른다. 완료 지점은 소진 상태라 미획득 품목 재추첨이 불가능하다. 저장·로드로 결과가 바뀌지 않도록 Unity에서 원자적으로 처리할 계약이다. 현재 HTML에는 이 게임 시스템이 들어 있지 않다.

물·식량 두 곳 이외의 탐색은 필수가 아니다. 계산대 쪽지를 안 읽으면 복귀 독백은 일반적인 안전 고민만 한다. 색연필을 이미 챙겼으면 새로 찾으러 보내지 않는다. 못 구한 상태에서는 첫 그림 튜토리얼을 확률 실패로 영구 차단하지 않도록 **후속 확정 확보 경로를 다음 구간에서 설계해야 한다.**

## 다음 작업과 완료 경계

이번 묶음은 C0 첫 선택/빈 페이지 인서트와 D1 낮의 UI·종이·상세 콘티 시안이다. 기존 오프닝 재생 파일과 동결된 `design/unity-handoff/opening-v1/`은 바꾸지 않는다. 기존 첫 주 계획에서 **1일 차 즉시 요리**, **새 스케치북 요구**, **색연필을 미리 챙겨도 다시 찾기**는 이 문서로 대체한다.

C0 물·담요~취침 구간은 연속 초안으로 연결했다. 색연필 확정 확보 경로는 첫 주 연결표에 제안했으며 검토 전이다. 미완료: 첫 그림/사진·NPC를 잇는 2~7일 상세 콘티, 미니게임 상세 규칙, 소음 사건 확률, 실제 사운드, 최종 지도 지리·지명, 상태 저장·인벤토리·분배 로직, Unity/Photoshop 앱 직접 검수. 장면들이 모두 실행되는 게임으로 보고하지 않는다.

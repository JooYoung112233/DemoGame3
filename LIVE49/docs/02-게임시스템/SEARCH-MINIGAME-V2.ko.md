# 탐색 V2 — 진행형 스킬 체크 검증 시안

2026-09-11. 사용자 요청: 단발 판정보다 발전기 수리처럼 진행 중 간헐적 판정이 등장하는 방식을 검증한다. 이전 V1은 비교용으로 보존한다. 최종 Unity UI나 확정 밸런스가 아니다.

- 실행: `node tools/serve-search-minigame-v2.cjs 8796` → http://127.0.0.1:8796
- 소스: `design/minigames/search-v2/` (장소 데이터는 V1 core에서 재사용)
- 자동 검증: `node tools/test-search-minigame-v2.mjs`

## 규칙

빠른 탐색은 게임 시간 5분, 모든 물자에 기본 확률을 한 번 적용한다.

집중 탐색은 시작 시 10분을 사용한다. 실제 조작 약 14초에 3회의 스킬 체크를 배치하되, 중간 선택의 대기 시간은 제외한다. 시작 시 판정 등장 시각과 성공 구간 위치를 작게 무작위화한다. 각 판정은 0.8초의 시각 예고와 선택적으로 켠 합성 예고음 뒤 시작한다. 기본 회전 1.25초, 여유 모드 1.9초. 판정 밖 입력은 무시하고 한 판정에는 한 번만 입력받는다.

초록 구간은 소음 없이 통과한다. 금색 대성공은 아직 판정하지 않은 물자의 획득 확률에 +10%p, 최대 +20%p를 누적한다. 실패 또는 시간 초과는 소음 위험 +25%p, 최대 95%로 올린다. 성공해도 기존 장소의 기본 소음 추첨은 남는다. 따라서 화면의 확률은 확정 조우가 아니라 탐색 종료 후 인기척 반응 확률이다.

앞의 두 판정 뒤 첫 물자를 즉시 추첨해 가방에 보관한다. 냉장고 생수 2개는 첫 튜토리얼 보장 물자다. 다른 장소의 첫 물자는 확률에 따라 없을 수 있으며 화면에서 구분한다. 중간 선택에서 끝내면 보관한 물자만 유지하고, 계속하면 게임 시간 5분을 추가 지불하고 세 번째 판정 후 나머지 물자를 추첨한다. 이미 확보한 물자의 확률을 소급 변경하지 않는다.

탐색 종료 후 소음 추첨에 걸리면 머무르기/귀환 선택. 머무르면 다음 장소 기본 소음 위험 +10%p (기본 위험 상한 65%). 전투는 미연결이다.

## 중단과 저장

별도 V2 로컬 저장 사용. 탭이 가려지면 조작 시간은 정지한다. 새로고침 시 이미 확보한 물자와 사용한 시간만 보존하고 해당 장소 탐색은 종료한다. 중간 확인 전에는 확보 물자가 없으므로 아무것도 지급하지 않는다. V1과 다른 중단 정책이며 화면 결과에 표시한다. 다중 탭 충돌 방지는 미구현이다.

## 검증과 판단할 점

자동 검증: 단계별 물자 확보, 중간 종료, 추가 시간 1회 차감, 대성공 보너스, 실패 소음, 중단 복구, 중복 지급 방지, 빠른 탐색, 위험 후 귀환.

사용자 플레이에서 확인할 점: 대기 시간이 지루한지, 0.8초 예고가 충분한지, 중간 선택이 실제 고민을 만드는지, 반복 탐색에서 세 번의 판정이 피곤한지. 일반 성공만으로는 확률 보너스가 없으므로 집중 탐색의 비용 대비 매력도 함께 검토한다. 아직 재미가 검증됐다고 단정하지 않는다.

음악과 물건을 뒤지는 실제 효과음은 미포함. 소리 켜기를 누르면 판정 예고/결과용 임시 합성음만 재생한다. 원화 추가 제작 없이 기존 편의점 그림을 사용한다.

### 브라우저 검증 결과

원형 판정 대기 화면의 전체 캡처를 검수했다. 실제 클릭 입력과 시간 초과 실패가 각각 판정 1회로 기록되고 소음 위험이 증가했다. 냉장고 중간에서 생수 2개 확보 → 계속 선택으로 10분에서 15분 → 세 번째 판정 후 최종 보상까지 진행했다. 다음 식품 선반에서는 중간 식량 확보 후 종료해 추가 5분이 차감되지 않았고, 소음 반응 → 귀환에서도 가방이 보존됐다. 브라우저 오류 로그는 없었다. 검증 후 초기 상태로 돌렸다. 성공/대성공 경계 및 복구는 자동 규칙 테스트로 검증했으며 사람의 손으로 느끼는 난도는 사용자 플레이 확인이 필요하다.

# 저녁 활동 — 오늘 남길 한 장

2026-09-11. 사용자가 저녁 정신력 게임을 대체할 활동으로 승인한 방향을 기록한다. 이번 작업은 기획 기록이며 Unity·콘티 데이터에는 아직 연결하지 않았다. 주인공 이름은 수혁이다.

## 승인한 방향

낮에 겪은 일을 밤에 사진·물건·짧은 기록으로 돌아보고, 그중 하나를 골라 일기장에 남긴다. 정답·실패를 판정하거나 정신력 점수를 시험하는 미니게임으로 만들지 않는다. 플레이어가 자신의 여행과 기억을 쌓는 짧은 서사 활동이다.

- 후보는 오늘 실제로 획득하거나 경험한 것만 보여 준다. 미발생 사건·미획득 사진이나 물건은 등장시키지 않는다.
- 사진: 자세히 바라보는 연출과 짧은 독백. 사진기사와 진실을 마주하는 기존 흐름에 연결한다.
- 물건: 그날 사용하거나 주운 물건을 매개로 사건의 뒷이야기를 보여 준다.
- 기록: 오늘의 생각이나 내일의 목표를 일기장에 남긴다.
- 하나를 골라 남기는 체험은 약 30초~1분을 목표로 한다. 평범한 날은 짧게, 특별한 사건이 있던 저녁은 더 길게 구성한다.
- 매일 강제하지 않으며 바로 잠들기를 제공한다. 생략했다고 정신력을 깎는 방식으로 사실상 강제하지 않는다.
- 선택에 따라 수혁의 독백과 이후 반응이 달라지는 방향이다. 확정 대사는 사용자가 대사집에서 집필한다.

## 첫날 연결 예시 — 대사·배치 미확정

간편식을 실제로 먹었다면 빈 포장을 계기로 그날의 식사를 돌아볼 수 있다. 소이의 그림 요청이 발생했다면 기존 책을 펼쳐 색연필을 구하고 싶다는 기록으로 이어질 수 있다. 해당 사건을 보지 않았다면 후보를 만들지 않는다. 스케치북을 새로 구하는 목표를 다시 넣지 않으며 기존 책과 색연필 확보 설정을 따른다.

## 후속 설계 시 지킬 연결 원칙

- 선택하지 않은 물건이나 사진을 인벤토리에서 없애는 의미로 해석하지 않는다. 일기장에 오늘의 초점을 남기는 선택이다. 실제 소비·보관 규칙은 별도 결정한다.
- 기존 퀘스트가 있다면 저녁 기록은 그 목표를 상기시키는 역할을 한다. 같은 퀘스트를 중복 생성하지 않는다. 새 목표 생성은 해당 사건의 조건을 따로 정의한다.
- 사진을 통한 진실 접근은 기존 엔딩 방향과 맞춘다. 저녁 선택 하나로 엔딩을 강제하거나, 사진 선택 횟수를 새로운 분기 점수로 임의 확정하지 않는다. 촬영·관찰·기억의 연동 방식은 후속 설계가 필요하다.
- 현재 시점 소이가 객관적으로 물건을 붙이거나 옮기는 행동을 추가하지 않는다. 일기장을 정리하는 행동은 수혁이 수행한다.
- 바로 잠들기를 선택해도 서사 필수 정보가 영구적으로 누락되지 않도록 필수 사건과 선택 회고를 구분한다.
- 밤마다 새로운 원화를 의무적으로 만들기보다 획득 사진·소품과 일기장 구도를 재사용하는 방향을 우선 검토한다. 구체적인 화면과 조작은 아직 미정이다.

## 남은 결정

첫날에 실제로 제시할 후보, 선택 후 일기장 표현, 다음 날 반응, 특별한 저녁의 길이를 정한다. 본 활동은 승인된 개념이며 구체적 대사·보상·엔딩 수치·화면은 아직 확정하지 않았다.

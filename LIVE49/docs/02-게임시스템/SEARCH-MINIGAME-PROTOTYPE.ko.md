# 탐색 미니게임 1차 조작 시안

실행: `node tools/serve-search-minigame.cjs 8795` → `http://127.0.0.1:8795`.

위치는 `design/minigames/search-v1/`. Unity 6.6 구현 전에 입력·보상·시간·소음 분기를 검토하는 독립 브라우저 시안이다. 기존 콘티 페이지와 대사집을 변경하지 않는다. 새 원화는 제작하지 않았고 기존 편의점 원화를 사용한다.

## 이번에 조작 가능한 범위

- 냉장고·식품 선반·생활용품 상자·문구대 4곳. 물자별 획득 확률 확인.
- 빠른 탐색: 총 5분, 기본 확률로 즉시 결과.
- 집중 탐색: 총 15분, 8초 안에 움직이는 표시를 초록 구간에서 멈추기. 클릭 또는 Space. 성공하면 추가 물자마다 +20%p, 최대 100%. 실패·시간 초과는 기본 확률 유지.
- 느린 조작: 더 느린 이동과 넓은 구간. 보상과 시간은 동일하다.
- 첫 냉장고 생수 2개는 확보 보장. 다른 물자는 독립 추첨. 한 지점의 탐색은 한 번으로 종료.
- 결과 확인 후 소음이 났다면 인기척 → 계속 탐색/귀환. 소음과 미니게임 판정은 독립이다. 계속 탐색하면 이후 소음 확률 +10%p, 최대 65%라는 임시 규칙을 적용했다.
- 소음이 나도 확보 물자는 유지. 전투·피해·강제 감염은 구현하지 않았다. 귀환 화면 뒤 실제 분배·퀘스트 연결도 후속이다.
- 기본 소음 확률은 냉장고 25%, 식품 선반 18%, 생활용품 30%, 문구대 15%. 모두 조작 검토용 후보 수치다.
- 소리는 기본 꺼짐. 켜면 작은 합성 판정음이 나온다. 실제 생활 효과음·Suno 음악을 넣은 상태는 아니다.

## 상태와 저장

`explore → playing → result → warning 또는 explore → returned`.

시작 시 시간 비용·각 물자 난수·소음 난수를 한 상태로 저장한다. 완료 시 획득과 탐색 완료를 함께 반영한다. 중복 완료 요청은 추가 지급하지 않는다. 소음 확인 중 다른 탐색을 시작할 수 없다.

브라우저 저장 키는 `live49-search-prototype-v1`. 조작 중 새로고침은 이미 저장한 난수로 기본 확률 결과를 확정하며 다시 조작하지 않는다. 탭을 숨기면 실제 조작 타이머는 일시 정지하고 돌아오면 이어간다. 결과·귀환 상태도 유지한다. 처음부터 버튼은 시안 진행을 초기화한다. 저장 공간을 사용할 수 없으면 화면에 알리고 현재 창에서만 진행한다. 다중 탭 동시 조작이나 저장 파일 변조에 대한 보호는 제공하지 않는다.

## Unity로 옮길 부분

`core.mjs`의 순수 규칙과 SPOTS 데이터를 기준으로 C# 상태·물자 데이터·저장 처리로 이식한다. `app.mjs`의 HTML 표시·localStorage·임시 음원은 Unity 구현물이 아니다. 게임의 1920×1080 기준 UI, Sprite 배치, Input System, 실제 Save 시스템과 연결은 후속이다.

필수 색연필 퀘스트를 무작위 실패로 잠그지 않도록 전체 게임에서는 대체 확보 경로를 연결해야 한다. 이 시안은 획득 조작만 실험하므로 그 퀘스트의 진행을 판정하지 않는다. 소음 후 실제 감염자/밴딧 조우 역시 별도 사건 설계가 필요하다.

## 같이 볼 포인트

1. 8초 안에 한 번 멈추는 조작이 너무 짧거나 단순한가?
2. +20%p를 얻으려고 10분을 더 쓰는 선택에 의미가 있는가?
3. 소음 뒤 계속 탐색/귀환의 판단이 긴장감을 주는가?
4. 실패가 부담스럽거나, 반대로 보상이 약하게 느껴지는가?

자동 검증: `node tools/test-search-minigame.mjs`. 결과·보장 물자·시간·재추첨 방지·소음 독립·중단 복구·분기·4곳 완료를 확인한다. 실제 밸런스 평가는 플레이 후에 한다.
# 브라우저 검증 기록 (2026-09-11)

- 루트 주소 진입 시 CSS·모듈 경로를 수정하고 정상 렌더링을 확인했다.
- 빠른 탐색 5분 → 집중 탐색 Space 입력 후 누적 20분 → 다른 집중 탐색 중 새로고침 후 누적 35분을 확인했다. 중단 복구 시 기존 물자와 시간이 중복 적용되지 않았다.
- 귀환 시 획득 물자 유지와 종료 화면을 확인하고 새 탐색으로 초기화했다.
- 전체 화면 캡처에서 장소 선택, 확률 표, 조작 버튼과 가방의 표시를 검수했다.
- 성공 보너스·독립 소음·계속 탐색의 경계 상승·중복 방지 분기는 순수 규칙 자동 테스트로 검증했다. 이번 브라우저 플레이에서는 소음 분기가 추첨되지 않아 해당 화면의 실조작 검증은 별도다.

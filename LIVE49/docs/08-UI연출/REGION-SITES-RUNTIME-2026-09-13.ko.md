# 첫 지역 현장 배경 연결

2026-09-13. 공영주차장(L8), 작은 세탁소(L9), 동네 약국(L10)의 지도 확대 대체 화면을 각각 장소 배경으로 교체했다. 기존 잡화점 배경과 시점·팔레트를 맞췄고, 캠핑카를 배경에 고정하지 않았다.

| 장소 | Unity 리소스 | 표현 |
|---|---|---|
| L8 공영주차장 | `Live49/Stages/region-L8` | 주차 구획, 관리 부스, 출입로·옆 골목 |
| L9 작은 세탁소 | `Live49/Stages/region-L9` | 세탁기, 긴 의자, 계산대·옆길 |
| L10 동네 약국 | `Live49/Stages/region-L10` | 조제대, 진열장, 고갯길 쪽 도로 |

`RegionExploration.Site.Art`를 연결해 일반 현장 화면, 탐색 패널과 저장 슬롯이 동일한 장소 자산을 사용한다. L8 밴딧 조우는 기존 골목 원화를 사용하고 조우 결과를 확인하면 일반 주차장 화면으로 돌아간다. 빌드 씬은 기존 Title/Game 두 개를 유지한다.

## 원본과 검증

- [원본·PSD·프롬프트·검증 매니페스트](../../art/chapter01/region-sites-v1/README.ko.md)
- 이미지 도구 반환 크기 1672×941. 요청한 3840px 배경 목표에 미달하므로 확대용 최종 원본은 후속 보강 대상이다. 단순 확대는 하지 않았다.
- PSD는 동일 크기의 고정 배경 한 레이어다. 가구·건물 내부 분리는 제공하지 않는다.
- PNG 원본/Unity 복사본 바이트 동일, PSD 합성·레이어 복원 픽셀 동일성 총 12개 검사 통과.
- `AgentScripts/ImportRegionSites.cs`로 SpriteSingle, mipmap 없음, 무압축, 최대 2048로 등록했고 Unity 재컴파일이 성공했다.
- 실제 플레이 화면·검수 기록은 `Demo3/Screenshots/FirstPassJourney/`에 누적한다. 최종 연속 검수 범위는 제작관리의 후속 보고서를 따른다.

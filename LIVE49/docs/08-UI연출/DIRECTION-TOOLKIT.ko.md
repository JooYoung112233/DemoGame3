# Live49 · 사용할 연출 정리

> 2026-09-10 대화 화면 최신 결정: 일반 대화는 약한 배경 블러 + 좌우 캐릭터 일러스트 + 하단 대사창을 사용한다. 아래 폴라로이드 대화 설명은 이전 후보 기록이다. [채택 시안·제작 순서](../../design/dialogue/README.ko.md)를 우선하며, 대화용 표정·행동 원화는 대사집이 나온 뒤 제작한다. 사진 수집·앨범의 서사 기능은 유지한다.

2026-09-09. 현재 방식은 고정 2D 배경, 분리 인물·소품, 클릭과 정지 행동 포즈다. Unity 게임 구현은 아직 없으며, 기존 로컬 미리보기에서 확인한 방식과 앞으로 제작할 효과를 구분한다. 아래는 사용할 수 있는 수단의 목록이며 모든 장면에 전부 적용하는 규칙은 아니다.

## 1. 기존 자산과 방식으로 구성하기

| 연출 | 화면에서 일어나는 일 | 적합한 순간 | 현재 범위·주의 |
| --- | --- | --- | --- |
| 전체 → 부분 확대 | 같은 원화에서 식탁·손·책으로 시선을 좁힘 | 중요한 물건 발견, 대답 전 망설임 | 확대 미리보기 경험 있음. 큰 확대는 원본 선명도 확인 필요 |
| 같은 화면 오래 유지 | 그림은 유지하고 대사와 작은 상태만 변경 | 가족 대화, 짧은 침묵 | 대사마다 새 그림 불필요. 읽기는 사용자 입력으로 진행 |
| 정지 포즈 교체 | 앉기 → 조사 → 다시 앉기로 전환 | 컵 확인, 물건 챙기기 | 해당 포즈가 있는 행동에 적용. 걷는 중간 동작은 생략 |
| 소품 전후 상태 | 빈 페이지에 그림이 생기거나 물건이 사라짐 | 획득, 요리, 준비 완료 | 레이어 합성·상태 전환 미리보기 있음. 영구 저장은 별도 구현 |
| 인물과 가구의 가림 | 식탁 뒤에 몸, 식탁 위에 손을 배치 | 앉아서 그리기·대화 | 분리 레이어 활용. 접촉과 그림자 검수 필요 |
| 사진 한 장과 여러 대사 | 폴라로이드 형태의 컷을 유지하며 대화 | 중요한 교감과 발견 | 연출 틀로 사용. 모두 실제 촬영된 사진이라는 뜻은 아님 |
| 클릭 후 반응 | 대상을 누르면 포즈·문구·상태 변화 | 책 챙기기, 서랍 확인 | 하이라이트·이름 표시 경험 있음. 클릭과 결과를 같은 대상에 연결 |

## 2. 추가 효과 구현으로 넓히기

| 연출 | 쓰임새 | 필요한 작업 |
| --- | --- | --- |
| 암전·겹쳐 전환 | 밤 마무리, 기억과 현재 연결 | 화면 전환과 입력 처리. 대사를 읽기 전에 강제 전환하지 않기 |
| 같은 형태로 장면 연결 | 과거의 잡은 손 → 현재 책 위의 손 | 위치·크기를 맞춘 두 컷. 해당 손 원화는 신규 필요 |
| 밝기 변화 | 소등, 복구, 취침을 구분 | 어두운 상태와 조명 레이어. 화면 전체를 검게 만드는 것만으로 최종 조명 처리 완료라 보지 않음 |
| 손전등 빛 | 어둠 속에서 조사 범위를 좁힘 | 밝은 영역 마스크와 조사 지점. 지정 지점에 빛을 옮기는 방식부터 시험 |
| 소리가 먼저 들림 | 화면 밖에서 서연이 부름, 차체 소리로 현재 복귀 | 음향·자막 타이밍. 음성 녹음 없이 자막과 환경음으로도 시안 가능 |
| 소리가 다음 컷까지 남음 | 회상의 온기와 현재의 단절 연결 | 음량 전환과 재생 구간 관리 |
| 음악을 멈춤 | 고장이나 중요한 질문에 집중 | 짧은 음악과 환경음 분리. 매 장면 긴장 효과로 남용하지 않기 |
| 미세한 움직임 | 커튼, 먼지, 빛의 작은 변화 | 분리 레이어나 효과. 인물 전체를 늘였다 줄여 호흡처럼 보이게 하지 않기 |
| 대사 뒤의 짧은 여백 | 대답을 망설이거나 표정을 읽게 함 | 입력 가능한 여백. 기다리는 시간을 분량으로 계산하지 않기 |
| 읽은 말·기록의 변화 | 선택이 저널과 다음 반응에 남음 | 대사 조건·기록 상태·저장. 현재 미리보기의 문구 변경과 실제 영구 저장은 별개 |

## 3. 새 그림이 있어야 하는 순간

- 서연의 얼굴과 가족 회상: 서연 디자인, 회상 배경, 손을 건네는 두 상태.
- 시작 화면의 책과 손: 공간을 특정하지 않는 전용 근접 구도. 기존 배경의 과도한 확대만으로 대체하기 어려움.
- 실제로 붙잡거나 안겨주는 장면: 인물 간 접촉이 맞는 전용 포즈. 독립 인물 두 장을 겹치는 것으로 끝내지 않기.
- 손전등을 든 수혁과 조명 전원부: 기존 캠핑카 배치에 맞는 포즈·소품·확대 컷.
- 큰 표정 변화: 별도 얼굴·손 레이어. 웃음·고개 돌리기·눈 감기 등이 필요할 때만 제작.

신규 그림도 같은 장소라면 창·식탁·좌석 배치를 유지한다. 컷마다 배경을 다시 생성하지 않는다.

## 4. 이야기 구조로 만드는 연출

| 방식 | 이번 작품 적용 |
| --- | --- |
| 처음과 끝에 같은 구도 | 서연에게 소이의 손을 받음 → 엔딩에서 돌봄을 건네거나 빈자리를 마주함 |
| 같은 행동의 의미 변화 | 갑자기 꺼져 불안했던 불 → 직접 끄고 쉬는 불 |
| 나중에 의미가 생기는 사물 | 시작 화면에서는 이름 없는 책과 손 → 플레이 후 누구의 물건인지 이해 |
| 선택 후 작은 반응 | 말투 선택에 소이의 대답이 달라지고 이야기의 큰 흐름은 합류 |
| 행동이 끝난 뒤 남는 흔적 | 짐칸에 챙긴 물건, 고친 조명, 저널 한 문장 |
| 주관적 장면과 객관적 증거 구분 | 수혁이 경험한 소이의 모습과 실제 사진·제삼자의 확인을 구분해 두 엔딩의 모순을 점검 |

반전 때문에 화면을 아무 때나 거짓으로 만들지 않는다. 가족 회상은 과거의 기억으로 유지하고, 현재의 시점 규칙은 본편까지 일관되게 적용한다.

## 5. 시작 화면과 챕터 0에 먼저 사용할 조합

최신 사용자 피드백: 시작부터 여행을 공개하지 않는다. 캠핑카 전경과 ‘새 여행’ 문구는 초기 화면안에서 제외한다. 닫힌 책·손의 근접 구도는 현재 제안이며 최종 원화로 확정된 상태는 아니다.

| 장면 | 먼저 사용할 연출 |
| --- | --- |
| 시작 화면 | 작은 빛 아래 닫힌 책과 손, 공간을 숨긴 구도. 메뉴 ‘시작 / 이어하기 / 설정 / 종료’ |
| 시작 입력 | 메뉴 사라짐 → 서연의 호출과 자막 → 과거의 손으로 전환 |
| 서연 회상 | 반신 정지 컷, 표정 1회 변화, 손 교체, 짧은 환경음 |
| 현재로 복귀 | 비슷한 위치의 손을 연결하고 실내 전체를 처음 공개 |
| 캠핑카 준비 | 고정 배경, 조사 확대, 정지 포즈, 소품 전후 상태 |
| 소등 사건 | 한 번의 밝기 저하, 환경음 변화, 손전등 조사, 어둠 속 대화 |
| 불 복구 | 원래의 넓은 구도로 돌아오며 따뜻한 빛 복귀, 짧은 대화 |
| 프롤로그 마무리 | 저널 문장, 사용자 입력으로 소등, 날짜 전환 |

엔딩 후 시작 화면의 변화는 시작 원화와 본편 연출을 확정한 뒤 설계한다. 기존 캠핑카 외관을 전제로 한 밤·새벽 메뉴 변형안은 현재 보류한다.

## 6. 컷을 연결하는 편집 연출 · 적용 후보

사용자가 말한 ‘편집스러운 연출’에 해당하는 목록이다. 단순 줌 인·아웃과 구분한다. 연결할 정지 원화가 준비되면 코드로 컷 순서·길이·전환·화면 분할·소리의 선행을 제어할 수 있다. 현재 아래 편집을 구현하거나 검증한 것은 아니다. 새 장면과 대사는 연출 제안이며 확정 원문이 아니다.

| 연출 | 들어가면 좋은 시점 | 컷 구성·의도 | 필요한 원화·소리 | 우선순위 |
| --- | --- | --- | --- | --- |
| 매치 컷: 같은 형태 연결 | 챕터 0 서연 회상 → 현재 복귀 | 과거의 잡은 손 → 같은 위치·크기의 현재 책 위 수혁 손. 짧은 전환으로 시간 차이를 느끼게 함 | 두 장의 손 방향·화면 위치·크기를 맞춘 컷. 자연스러운 손동작 애니메이션은 필요 없음 | 챕터 0 우선 |
| 소리 선행: 다음 장면을 먼저 들려주기 | 시작 메뉴에서 ‘시작’을 누른 직후 | 메뉴가 사라진 책·손 화면에 서연의 “수혁아”가 먼저 들린 뒤 과거 얼굴 컷으로 전환. 여행을 설명하지 않고 사람을 궁금하게 함 | 시작 근접 컷, 서연 얼굴 컷, 호출 음성. 음성이 없는 시안은 화면 전환 전 자막으로 타이밍만 확인 | 챕터 0 우선 |
| 행동 생략 몽타주: 준비의 리듬 | 물·담요 위치를 직접 확인한 뒤, 짐 넣기 완료 순간 | 물병을 쥔 손 → 가방 안의 담요 → 정리된 짐. 각 동작의 중간 과정을 생략해 준비가 진행됨을 보여줌 | 손·물병, 가방 속 담요, 짐 완료 상태 3컷. 천·물건 놓는 소리 | 챕터 0 우선 |
| 기억 삽입: 현재 행동 사이에 과거 한 컷 | 담요를 확인하는 순간 | 현재 담요의 접힌 모서리 → 서연이 담요를 덮어주던 과거 → 현재 수혁의 멈춘 손. 사물이 기억을 부름 | 현재 담요 컷, 과거 서연·담요 접촉 컷, 수혁 손. 과거 사건은 신규 설정 후보 | 본편 확장 후보 |
| 분할 화면: 동시에 일어나는 일 | 챕터 0 소등 후 전원 연결을 확인하는 대화 | 왼쪽은 작업하는 손, 오른쪽은 소이 쪽의 어두운 좌석. 수혁이 소이에게 답하면 손 화면을 걷어내고 소이 화면만 남김 | 전원부·손 컷, 소이 좌석 컷, 손전등 빛 상태. 현재 소이는 수혁의 체험이라는 시점 유지 | 소등 장면 비교 시안 |
| 소리 잔류: 이전 장면을 잠깐 남기기 | 회상이 끝나 현재로 돌아온 직후 | 과거의 바람이나 옷 스치는 소리가 현재 손 컷에 짧게 남았다가 차체 소리로 바뀜 | 별도 재생 가능한 과거·현재 환경음 | 매치 컷 보조 |
| 반복 컷의 변화 | 마지막 언덕·엔딩 | 프롤로그 손 구도를 다시 사용. 생존 엔딩은 하은에게 돌봄을 건네는 손, 반전 엔딩은 허공을 향한 손으로 의미 회수 | 프롤로그 구도를 기준으로 만든 엔딩별 전용 접촉·빈자리 컷 | 엔딩 제작 때 |

### 챕터 0에 실제로 배치할 편집 순서 제안

1. 시작 화면: 공간을 특정하지 않는 책과 손. ‘시작’ 입력 후 **소리 선행**으로 서연의 호출 → 얼굴 컷. 메뉴에서 캠핑카·여행을 먼저 공개하지 않는다.
2. 짧은 서연 회상: 손을 건네받은 뒤 **매치 컷**으로 현재 수혁의 손에 연결한다. 기존 콘티의 컵 옆 손보다 책 위 손을 우선 후보로 삼고, 시작 원화 확정 시 두 구도를 맞춘다.
3. 소이와의 대화·스케치북 확인: 이 구간은 한 화면을 유지해 대사를 읽을 여유를 준다.
4. 물·담요 챙기기: 플레이어가 물건을 확인하고 챙기기를 선택한 뒤 **3컷 몽타주**로 완료한다. 조사 과정을 자동 영상으로 대체하거나 같은 행동을 다시 클릭하게 하지 않는다. 마지막 짐 컷 뒤 실내등이 꺼진다.
5. 소등 사건: 손전등 확보·조사는 기존 클릭 방식. 어둠 속 대화에서만 **분할 화면**을 짧게 비교 시험한다. 읽기 어려우면 손 컷 → 소이 컷의 순차 편집으로 대체한다.
6. 복구와 취침: 전체 구도로 돌아온 뒤 책 챙기기·저널·대화를 진행한다. 마지막 소등은 사용자가 누르는 한 번의 행동으로 마친다.

담요의 기억 삽입은 목록에는 보관하되 챕터 0 기본안에는 넣지 않는다. 도입 회상 직후 또 서연을 보여주면 짧은 등장의 여운을 반복 설명할 수 있다. 본편에서 담요를 다시 꺼내는 조용한 밤이나 두 번째 편지 이후의 기억 장면에 검토한다. 해당 편지의 기존 발견 장소·본문은 변경하지 않는다.

### 편집 길이와 입력

- 매치 컷은 순간 교체 또는 아주 짧은 전환을 우선 비교한다. 길게 겹치면 손이 중복되어 보일 수 있다.
- 몽타주는 무대사 컷당 약 0.6~1.2초를 출발값으로 시험한다. 컷마다 클릭을 요구하지 않고 묶음 전체 건너뛰기를 제공한다. 이 값은 검증 전 후보이며 플레이타임을 늘리는 수단이 아니다.
- 기억 삽입은 내용을 알아볼 정도로 보여준다. 알아보기 어려운 한 프레임 점멸이나 반복 섬광은 사용하지 않는다.
- 대사가 있는 화면은 읽기 완료 입력을 기다린다. 분할 화면은 동시에 두 대사를 출력하지 않는다. 작은 화면에서는 순차 컷으로 바꾼다.
- 편집을 건너뛰어도 짐 획득·소등 트리거 같은 사건 결과는 한 번만 반영한다. 편집 도중 다시 불러올 때의 복원 지점도 함께 정의한다.
- 폴라로이드 연출과 달리 컷이 반드시 실제 촬영 사진을 뜻하지 않는다. 객관적 사진 증거와 수혁의 기억 이미지를 혼동시키지 않는다.

첫 제작에서는 **소리 선행 + 손 매치 컷 + 준비 몽타주** 세 가지부터 확인한다. 분할 화면과 추가 기억 삽입은 리듬을 본 뒤 결정한다. 필요한 원화의 존재 여부, 화면 연결, 소리 타이밍을 실제 시안으로 검증하기 전에는 구현 완료로 표시하지 않는다.

## 7. 현 단계에서 범위를 넓히지 않을 것

자유 이동과 걷기 애니메이션, 장시간 전신 연기, 3D 카메라 회전, 정교한 물리적 포옹, 전체 음성 녹음, 실시간 조명에 따른 모든 인물 그림자, 전용 영상 컷신은 현재 자산과 구현 범위를 넘는다. 필요하면 나중에 개별 장면 단위로 검토한다.

장면마다 핵심 변화 하나를 정하고 나머지는 절제한다. 시선 이동은 확대, 사건 변화는 소품·빛, 감정은 손·대사·소리로 나누어 조합한다. 실제 15분은 연출 목록이나 효과 개수로 보장하지 않으며, 전체 대본과 클릭 가능한 시안으로 측정한다.

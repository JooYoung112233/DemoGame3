# 저장·불러오기 화면

사용자 요청: 게임에서 사용할 로드·세이브 제작. 기존 단일 자동 저장 파일을 유지하고 수동 슬롯과 명확한 진입 UI를 추가했다.

- 게임에서는 **ESC 또는 메뉴 → 설정 → 저장·불러오기**로 공통 화면을 연다. 사용자 피드백에 따라 HUD의 저장/불러오기 버튼과 F5/F9 직접 진입을 제거했다. 설정 화면에서 마지막 자동 저장 시각을 확인할 수 있다.
- 자동 저장 1개와 수동 슬롯 3개를 분리했다. 수동 저장 UI에서는 자동 슬롯을 덮어쓸 수 없다. 빈 수동 슬롯은 바로 저장하고, 기존 슬롯은 확인 후 덮어쓴다. 취소하면 파일과 현재 진행이 유지된다.
- 슬롯은 날짜·장소·저장 시각을 보여주며 선택하면 진행 목표 또는 대화·조리 재개 상태를 확인할 수 있다. 그림은 저장 상태에 해당하는 기존 장면 원화이며 실제 프레임 캡처를 보관하는 기능은 아니다.
- 타이틀에 **불러오기**를 추가했다. **이어하기**는 읽을 수 있는 자동·수동 슬롯 중 저장 시각이 가장 최근인 기록을 연다. 저장이 없어도 불러오기 화면은 열리며 빈 슬롯을 표시한다.
- 불러오기는 확인 후 새 게임 씬과 HUD를 구성한다. 날짜·차량/인물 위치·아이템·퀘스트·이름 공개·생활·기록·조리 진행은 기존 JourneyState 전체로 복원한다. 조리 중단 상태도 수동 저장할 수 있으며 비용을 다시 차감하지 않는다.
- 대화나 화면 이동 중에는 수동 저장을 잠근다. 이때 설정의 저장·불러오기는 불러오기 탭부터 연다. ESC는 **확인 취소 → 슬롯 화면 → 설정 → 일시 정지 메뉴 → 게임** 순서이며 마지막 단계에서만 게임 시간이 다시 흐른다.

## 플레이 흐름에 맞춘 자동 저장

- 초반 연출이 끝나 처음 캠핑카를 조작할 때, 소이에게 대답하거나 스케치북을 확인한 뒤의 조작 가능 지점.
- 이어지는 이야기의 노드 진입과 대사 확인, 첫 주 이벤트의 시작·대사 확인·완료. 보상과 퀘스트 상태를 포함해 기록하며 대사마다 저장 알림을 띄우지는 않는다.
- 차량/도보 이동 완료, 캠핑카에서 내리기·돌아오기, 지역 이동 완료.
- 물자 획득, 조사 지점 확인, 장소 완료와 다음 장소 해금, 생활 행동·수리·식사·기록 확정.
- 조리/가열 시작·완료·창 닫기. 진행 중에는 1초 간격의 조용한 복원 체크포인트를 유지한다.
- 하루 종료 연출을 마치고 다음 날 조작이 가능해지는 시점.
- 일시 정지 메뉴에서 타이틀/게임 종료를 확인할 때, 수동 저장 가능한 진행은 먼저 자동 저장한다. 실패하면 게임에 남아 다시 시도하거나 돌아갈 수 있다. 저장할 수 없는 연출 중에는 마지막 체크포인트부터 이어진다는 안내를 한다.

같은 상태의 중복 저장은 생략하므로 메뉴를 열고 닫기만 해서는 저장 시각과 복구본이 바뀌지 않는다. 단순 불러오기만으로 자동 슬롯을 다시 기록하지 않는다. 주요 행동의 저장 성공 후에만 오른쪽 위에 작은 완료 표시를 약 3초간 보여주며 대화·설정·지도 등 모달 화면 위에는 표시하지 않는다. 저장 실패는 완료로 표시하지 않고 설정에서도 확인할 수 있다. 자동 저장이 수동 슬롯을 변경하지 않는다.

## 파일과 복구

자동 저장 경로는 기존 `Application.persistentDataPath/Live49/journey-v1.json`을 유지한다. 수동 파일은 같은 폴더의 `journey-v1-manual-1.json`부터 `-3.json`까지다. 기존 버전 1 체크섬·임시 파일 쓰기·교체·이전 파일 `.bak` 보관을 재사용한다. 손상되거나 빈 슬롯을 정상 저장처럼 불러오지 않는다. 원본을 읽을 수 없고 유효한 `.bak`가 있으면 명시적인 복구본 확인을 제공한다. 이후 자동 저장은 정상 진행에 따라 갱신된다.

## 검증

초기 슬롯 기능은 `Demo3/AgentScripts/VerifySaveSlots.cs`로 확인했다(진입 경로 개편 이전 검수).

- 자동/수동 파일 분리, 세 수동 슬롯, 빈 슬롯 저장, 덮어쓰기 확인·취소와 이전 파일 보관.
- 불러오기 취소 시 진행 유지, 지정 슬롯의 날짜·자원·상태 복원, 조리 재개 상태와 재료 차감 보존.
- 당시 HUD·ESC·타이틀 진입, 타이틀의 지정 슬롯 로드 및 최신 슬롯 이어하기, 저장 없는 타이틀.
- 손상 슬롯 차단, 유효한 복구본 로드, 실패 시 현재 진행 보존, 메뉴의 일시 정지 복원.
- 1920×1080에서 슬롯 화면·확인창·타이틀 배치와 글자 넘침.

컴파일과 실제 플레이 검수가 통과했다. 파일 조작은 `Demo3/Screenshots/SaveLoad/run-*`의 별도 검수 슬롯에서만 수행했다. 기존 저장 파일의 검수 전후 내용 일치를 확인하고 저장된 플레이어 진행을 복원했다. 화면과 결과는 `Demo3/Screenshots/SaveLoad/`에 보관한다. 새 씬·대사·음악은 추가하지 않았다.

현재 진입 경로와 자동 저장 정책은 `Demo3/AgentScripts/VerifySavePolish.cs`에서 실제 UI 콜백으로 검수한다. 설정 진입·ESC 단계·수동 저장/불러오기/취소, 캠핑카 하차 → 물/식량 획득과 해금 → 귀환 → 식사 → 다음 날 → 타이틀 → 이어하기, 저장 실패 시 이탈 차단, 초반 조작 지점 저장을 확인한다. 검수 파일과 화면은 `Demo3/Screenshots/SavePolish/`에 분리하고 검수 전의 실제 플레이 상태를 복원한다.

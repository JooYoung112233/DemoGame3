# 도시 지도 · Unity 적용

최신 탐색 연결: [첫 지역 10곳과 분기 해금](REGION01-EXPLORATION.ko.md).

후속 적용: [캠핑카 재주차·발견 연출·지역 선택](JOURNEY-POLISH-2026-09-12.ko.md).

2026-09-12 사용자 요청: 낙원처럼 실제 도시의 도로와 건물이 보이는 지도. 이어서 AI풍의 촘촘한 묘사를 일부러 뭉개고, 갈 수 있는 곳은 별도 표시하도록 수정했다.

## 화면과 조작

- 종이 개략도를 도시의 항공 시점 바탕으로 교체한다. 주요 도로·골목·건물·강·교량·녹지를 구분한다. 지형은 이 게임을 위한 배치 제안이며 실제 측량 지도나 확정된 지역 설정이 아니다.
- `MapPanel`은 기존 공통 HUD에서 열린다. 1920×1080 화면 안에 지도 1220×792와 목적지 정보 카드 490×792를 배치한다. 별도 프리뷰 씬은 없다.
- 휠 또는 +/−로 100~250% 확대, 드래그로 이동, ‘현재 위치’로 135% 확대하여 캠핑카에 복귀한다. 경계 밖 빈 공간이 드러나지 않도록 이동을 제한한다.
- 확대해도 장소 핀과 이름의 화면 크기는 유지한다. 오른쪽 가장자리에서는 이름을 핀 왼쪽에 표시한다. 이름표도 클릭 가능하며 드래그는 장소 클릭으로 처리하지 않는다.
- 편의점 선택 시 건물 윤곽, 기존 편의점 원화, 설명, 이동 조건을 함께 표시한다. 최초 이동 경로는 캠핑카 주차 공간에서 도로로 나와 동서 도로를 따라 편의점에 도착한다.
- 발견 상태는 기존 게임 데이터를 따른다. 아직 발견하지 않은 장소의 이름·핀은 숨긴다. 현재 플레이에서 실제로 이동 가능한 목적지는 기존 첫 편의점 연결 범위를 유지한다.
- 지도 열람은 시간을 멈춘다. Esc는 출발 확인 취소 → 지도 닫기 순서로 작동하며 닫기 뒤 시간을 복원한다. 출발은 조건을 다시 확인하고 닫기 완료 후 한 번만 전달한다.

## 데이터와 원본

`FirstRegionMap`의 장소 좌표, `MapPaperGraphic`의 경로와 지형 참조, `MapViewport`의 화면 이동을 분리한다. 배경 원화 위에 이름·핀·현재 위치·선택 윤곽·경로를 Unity UI로 그린다. 원화에 UI를 합성하지 않는다.

원본·프롬프트·실제 해상도와 레이어 상태는 [지도 원화 기록](../../art/ui/city-map-v1/README.ko.md)을 따른다. 생성 도구의 원본을 보존하며 단순 확대를 새 고해상도 묘사로 취급하지 않는다.

## 검수

`AgentScripts/VerifyCityMap.cs`, `Screenshots/CityMapReview/report.txt`:

- 네이티브 UI 클릭과 휠·드래그 이벤트, 포인터 기준 확대, 핀 크기 유지, 현재 위치 복귀, 최대·최소 배율과 경계 제한
- 미발견 이름 숨김, 현재 위치 출발 차단, 출발 확인·취소·조건 재검사·콜백 한 번 실행
- 실제 InputSystem Esc 키로 시간 복원, 텍스트 영역 넘침 없음, 씬 수와 플레이 진행 상태 보존
- 실제 플레이 콜백·발견 상태로 복원하고 최종 지도를 열어 둠

`01-city-map.png`는 실제 현재 진행 화면, `02-city-map-detail.png`는 확대 화면이다. `03-route-contract-fixture.png`는 출발 콜백 계약 검수용 임시 구성이다. 실제 플레이를 출발 전으로 되돌리거나 이동을 실행한 사진이 아니다. 실사용 저장 파일은 덮어쓰지 않았다.

최종 화풍 v2 적용 뒤 `FinalCityMapScreens`로 1555×1011 원본 로딩, 기본·150% 확대, 텍스트 영역을 재확인했다. `04-soft-map-final.png`가 최종 기본 화면이며 `art-review.txt`에 통과 결과를 보관한다. 최종 Unity 실행 오류 0개, 타이틀·게임 씬 2개를 유지한다.

# 대화 초상 비율과 시선

사용자 요청: 세진의 대화 초상 비율을 주인공과 맞추고 오른쪽 인물이 상대를 바라보도록 한다.

## 적용

- 기존 세진 PNG 원본은 보존한다. 세진 원본은 1086×1448, 수혁은 1024×1536이며 캔버스 대비 얼굴의 크기가 다르다.
- `DialogueView.AddPortrait`에서 세진의 표시 영역을 700×1050에서 910×1213.333으로 조정하고, 1920×1080 기준 왼쪽 위 좌표를 (1005,125)로 둔다. 실제 PNG 종횡비를 유지하며 얼굴 크기와 눈높이를 수혁에 맞춘다. 새로운 고해상도 원화를 만든 작업은 아니다.
- 수혁의 원본 시선은 오른쪽, 세진은 오른쪽, 소이는 왼쪽이다. 원본 방향과 대화 위치를 구분해 세진만 오른쪽 자리에서 수평 반전한다. 이름표나 대사 텍스트는 반전하지 않는다.
- 반전 기준점을 이미지의 가로 중앙에 두고 화면상의 사각형 위치를 보존한다. 반복 등록으로 배율·위치·방향이 누적되지 않는다.
- 새 인물 등록은 `AddPortrait(id, sprite, sourceFacesLeft)`로 원본 방향을 지정할 수 있다.

## 검수

Unity CLI에서 재컴파일을 통과했다. `Demo3/AgentScripts/VerifyPortraitFacing.cs`가 실제 첫 세진 대화를 별도 슬롯에서 재현해 수혁 오른쪽·세진 왼쪽 시선, 소이의 기존 방향 보존, 중복 등록 안정성, 자기소개 대사를 확인하기 전 `?` 표시를 확인했다. 검수 전후 실제 플레이어 저장 파일이 같음을 확인했다.

비교 화면은 `Demo3/Screenshots/PortraitFacing/00-before-sejin.png`, 수정 화면은 `01-sejin-facing-and-scale.png`, 소이 검수는 `02-soi-facing-preserved.png`이다. 세진의 이름 공개·대사 내용·기존 PNG 픽셀은 바꾸지 않았다.

# 02 · 편의점

[편의점 내부 v1](mart-interior-v1.png)은 캠핑카와 같은 계열의 높은 시점과 팔레트로 만든 첫 후보이다.

왼쪽 앞 서랍, 왼쪽 뒤 식품 선반, 오른쪽 뒤 구급 물품장, 오른쪽 앞 문구 선반을 조사 대상으로 제안한다. 아래쪽 입구를 귀환 선택 지점으로 사용한다. 냉장 진열대와 뒤쪽 문은 첫 시제품에서 장식이다.

현재 공간 규모에 맞춰 장소 명칭을 편의점으로 정리했다. 파일 경로의 mart는 기존 참조를 유지하기 위해 보존한다. 구급 물품장은 소형 상비약 코너에 어울리도록 후속 검토한다. 냉장 진열대 조사와 출입구·창의 주변 징후 연출은 추가 후보이며 세부 규칙은 보류한다.

단일 배경 이미지이며 별도 전경과 수혁 포즈 배치는 아직 없다. [클릭 영역과 하이라이트 시제품](../../../design/interaction/README.ko.md)은 별도로 제작했다. 물건을 획득했을 때 해당 소품이 사라지는 상태 이미지 또는 분리가 필요하다. 이 공간이 채택되면 이후 확대 컷도 같은 배치로 유지한다.

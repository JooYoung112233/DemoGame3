# 기존 사진 모서리 정리 · 챕터 0

들뜬 테이프 → 수혁이 누르는 손 → 손을 뗀 고정 결과의 3개 정지 컷이다. [연결 미리보기](review/photo-care-sequence.jpg) · [원본·좌표](manifest.json).

새 생성 소스는 벽 근접 시안, 누르는 손, 눌린 테이프, 들뜬 테이프 4점이다. `sources/`에 원본 PNG·프롬프트를 보관하고 `layers/`에 분리 PNG, `psd/`에 네이티브 원본 PSD 4개와 장면 PSD 3개를 보관했다.

사진은 기존 `family-polaroid-clean-review-v1.png`의 `[0,700,1784,1149]` 하단만 사용한다. 가족 얼굴은 세 컷 모두 프레임 밖에 있으며 원래 사진 내용을 다시 생성하지 않았다. 이 범위 밖으로 카메라를 이동해 원본 얼굴을 드러내지 않는다. 원본 하단 크롭도 별도 보관했다.

왼쪽 테이프 고정부는 두 상태에서 같은 픽셀을 유지하고 오른쪽 끝만 바뀐다. 손과 테이프·사진·벽·접촉 그림자는 분리 레이어다. 손의 관절별 편집 원본이나 배경 벽 전체의 복원본은 아니다.

벽 소스 1448×1086에서 최종 구도는 **1448×815**로 잘랐다. 게임 기본 1920×1080에 가까운 비율이며 팔이 화면 가장자리로 나간다. 큰 원본은 보존했지만 4K나 확대 복원으로 보고하지 않는다. 사진 자체도 원래 해상도를 넘는 디테일을 새로 만든 것이 아니다.

`story.json`의 `photo_observe`/`photo_care`는 들뜬 상태, `photo_wish`는 고정 상태에 연결했다. 중간 누르는 손 컷은 `art_sequence`에 등록했으며 브라우저에서 새로운 애니메이션을 구현한 것은 아니다. 실제 전환·종이 마찰음·대사는 Unity 및 대사집 작업으로 남긴다.

재생성: `tools/prepare-ch00-photo-care.py`. PSD 구조와 병합 픽셀, 원본 RGB, 테이프 고정부 보존, 사진 크롭 보존 49개 검사를 통과했다. Photoshop 앱 직접 검수는 하지 않았다.

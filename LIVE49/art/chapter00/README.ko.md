## 검수와 제한

- 서연의 외형은 새 디자인 시안이며 사용자 승인 전이다. 낮게 묶은 갈색 머리, 크림 상의와 차분한 초록 치마로 구분했다. 소이의 단발·주황 상의·갈색 치마는 기존 기준을 참고했다. 최종 v3 화풍 일치 승인을 대신하지 않는다.
- 인물·손을 어두운 바탕과 밝은 바탕에 합성하고 팔·옷 사이의 투명 틈을 확인했다. 사람/손의 실제 알파와 치수는 `../../design/chapter00/opening-assets-v1.json`에 기록한다.
- 두 손 상태는 배경을 다시 그리지 않고 동일 베이스에 합성한다. 상태 교체 시 두 손 레이어를 동시에 표시하지 않는다. 재생성한 두 상태의 세부 선은 완전히 동일한 애니메이션 프레임이 아니므로 짧은 컷 교체용 시안이다.
- PSD는 Pillow의 PSD 디코더로 다시 열어 3레이어 이름·캔버스·병합 이미지의 픽셀 일치를 확인했다. Photoshop 앱에서 직접 여는 호환성 검수는 미실시다. 개별 손가락이나 인물 몸·옷까지 나뉜 PSD는 아니다.
- 현재 출력은 배경 장변 3840px, 인물 실제 높이 1536~2048px 목표에 미달한다. 생성된 실제 원본을 보관했으며 단순 확대 파일을 고해상도 완성본으로 납품하지 않는다. 확대 최종용 디테일 보강은 후속 작업이다.
- 손에서 현재로 돌아오는 컷은 손이 들어오는 방향을 연결한 후보다. 접촉 중심과 크기까지 정확히 맞춘 매치 컷, 전환 시간·음향은 아직 구현·검증하지 않았다.
- 기존 타이틀과 캠핑카 v3 베이스는 교체하지 않았다. 서연은 과거 회상에만 등장하며 편지 내용과 현재의 생존을 입증하는 사진은 추가하지 않았다.

재생성: 프로젝트 루트에서 Python으로 `tools/prepare-ch00-memory.py` 실행. 원화 재생성 없이 배경 제거·검수 합성·PSD·치수 기록을 재작성한다.

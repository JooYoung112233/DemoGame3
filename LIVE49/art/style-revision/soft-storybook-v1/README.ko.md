# 부드러운 동화풍 · 1차 제작 묶음

승인 기준: [수혁 v6](../2026-09-10/suhyeok-storybook-face-study-source-v6.png).

기존 대화 3장 + 수혁 독립 행동 8장. 생성 원본 11개, 실제 투명 PNG 11개, 2레이어 PSD 11개와 식탁 몸/팔 분리 PSD 1개를 보관한다. 파일 ID는 `jobs.json`, 이전/새 경로 연결은 `replacement-map.json`, 각 원화 치수와 검증은 같은 이름의 JSON을 확인한다.

[현재 대화 합성](../../../design/ui/ch00-01/review/C0-03-response.png) · [전체 장면 배치 검토](review/scene-contact-sheet.jpg) · [제작 범위·검수·해상도 한계](../../../docs/05-원화/ART-SOFT-STORYBOOK-PASS.ko.md).

원본은 생성 도구가 출력한 실제 크기로 보관했다. 4K/목표 인물 높이 완료본이 아니며, 평면 소스의 체크 배경은 실제 RGBA `sprites/`와 구분한다. `psd/`의 인물은 하나의 그림 레이어이고, 얼굴·머리·의상을 각각 분리한 PSD가 아니다. `suhyeok-seated-split.psd`만 몸/식탁 위 팔을 분리했다.

소이의 작은 행동 포즈, 배경, 손·발 클로즈업, 가족사진은 이번 묶음의 수정 대상에 포함하지 않았다. 서연은 회상에서 계속 숨기며 편지 읽기 자산의 존재가 편지 이벤트를 챕터 1로 앞당기지 않는다.

# 챕터 0~1 초반 서사 반영 원화 v1

내장 image_gen으로 새 인물 원본 3장을 만들고 사용자 허용에 따라 로컬 배경 분리·레이어 합성을 수행했다. [검수 기록](../../../docs/05-원화/CH00-01-NARRATIVE-ART-REVIEW.ko.md)과 [manifest](manifest.json)를 함께 사용한다.

- `sources/`: 실제 생성 PNG와 최종 프롬프트. 원본 캔버스 1086×1448 또는 1159×1356. RGB 원본의 체크무늬 배경은 사용하지 않는다.
- `layers/*-native.png`: 같은 원본 크기의 알파 분리 인물. 앞팔 파일은 가림용 복사 레이어다.
- `psd/*-native.psd`: 큰 원본 레이어. 인물의 모든 관절을 따로 편집할 수 있는 형식은 아니다.
- `review/`: 1672×941 장면 PNG 및 검수용 축소 JPEG. 장면 합성 확대는 새 디테일을 만들지 않는다.
- `psd/`: 네이티브 3개 + 장면 17개, 총 20개 실제 레이어 PSD.
- `scene-baseline.json`: 수정 전 챕터 0 경로·PNG 해시. 원본은 덮어쓰지 않았다.

현재 게임용은 `C0-*` 중 `-truth`가 없는 10개, `E03-rations`, `E05-delivery`, `E06-ready`, `E06-drawing`, `E06-complete`다. `C0-current-truth`, `E06-drawing-truth`는 엔딩 회수 전용 검토 원화이며 초반에 표시하지 않는다.

수혁은 초반 비감염 상태다. 현재 얼굴·옷의 사용감은 감염 증상이 아니다. 소이는 수혁 곁에서 지켜보고 실제 첫 그림은 수혁이 그린다. 과거 가족사진과 서연의 얼굴 가림은 이번 차수에서 변경하지 않았다.

원본 인물 높이 목표에는 미달한다. 검사 도구로 PSD 채널과 합성 결과는 확인했지만 Photoshop 앱·Unity에서 검증한 것은 아니다. 대사·UI·음성은 포함하지 않는다.

| [02-참고용이미지](02-참고용이미지/README.md) | 장면 합성 결과 확인용. Unity에 통째로 넣을 이미지가 아님 |

[이미지분류표](이미지분류표.json)에 원본 경로·용도·파일 해시를 기록했습니다. **이번 묶음은 현재 60개 보완 장면 중심이며 전체 Unity 자산 납품이 아닙니다.** 회상·타이틀·UI·일부 소품은 최신 콘티에서 추가 선별해야 합니다. 미수록 파일을 전부 폐기본으로 판단하지 않습니다.

장면별 좌표·가림 순서·조건은 [원본 장면 매니페스트](../art/chapter00-01/art-polish-v1/scene-manifest.json)를 참고합니다. 서연 얼굴 비표시와 소이의 주관적 체험 조건을 무시하고 모든 레이어를 동시에 표시하지 않습니다.

기존 `art/`는 제작 이력·원본의 보관 위치로 유지해 콘티와 시안 연결을 보존했습니다. 게임용 후보를 찾을 때는 이 폴더부터 보세요. 수정은 원본에서 진행하고 `python tools/build-unity-image-pack.py`로 이 묶음을 다시 갱신합니다. 복사본만 수정해 원본과 어긋나지 않게 합니다. 동일 파일은 Git LFS가 내용 기준으로 중복 저장을 줄입니다.

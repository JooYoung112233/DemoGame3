# 챕터 0부터 이어지는 UI · 첫 화면 화풍 비교

2026-09-10. **사용자가 A(활자와 얇은 선)를 채택했다.** A를 후속 UI의 공통 화풍으로 적용하고 B는 비교 이력으로 보존한다. [선택 기록](selection.json). 다음 검토 대상은 [C0-01 서연의 부름](C0-01.ko.md)이다. 챕터 0부터 각 장면 안에서 필요한 UI를 하나씩 만들고 선택한다. 챕터 1 전체 UI가 완성된 패키지가 아니다. [전체 장면 순서와 필요한 UI](../../../docs/08-UI연출/UI-CH00-01-PLAN.ko.md)를 기준으로 이어간다.

## A/B 비교

A 채택 이후 시작 연출의 **D00~D08 움직이는 시안**을 추가했다. [로컬에서 열기](http://127.0.0.1:8791/design/ui/ch00-01/opening-motion.html). [재실행 방법·연출 타임라인](../../../docs/03-콘티/챕터0/C0-OPENING-DIRECTION.ko.md). 시작부터 첫 부름, 읽기 대기, 입력 후 회상 페이드까지 재생한다. 카메라·딤·글자 타이밍은 채택했고 진행 표시·회상 페이드는 검토 중이다. 음성과 회상 첫 대사는 후속 단계다.

| 후보 | 느낌 | 첫 시작 화면 | 저장이 있을 때 |
| --- | --- | --- | --- |
| A | 활자와 얇은 선. 메뉴 상자는 생략하고 선택 표시를 절제 | [합성 화면](review/C0-00-A-first-start.jpg) · [레이어 PSD](psd/C0-00-A-first-start.psd) | [합성 화면](review/C0-00-A-returning.jpg) · [레이어 PSD](psd/C0-00-A-returning.psd) |
| B | 붓 질감과 거친 선. 메뉴마다 낮은 채도의 갈색 바탕 | [합성 화면](review/C0-00-B-first-start.jpg) · [레이어 PSD](psd/C0-00-B-first-start.psd) | [합성 화면](review/C0-00-B-returning.jpg) · [레이어 PSD](psd/C0-00-B-returning.psd) |

두 안은 배경·로고·글꼴·메뉴 위치가 같다. 현재 초점은 ‘시작’, 저장이 있는 화면은 ‘이어하기’다. 처음에는 이어하기를 숨긴다. 오른쪽 책과 손 위에 UI를 얹지 않는다. 평상시 날짜·상태 HUD는 아직 등장하지 않는다. 첫 화면에서 본편 여행·엔딩 정보를 추가로 드러내지 않는다.

UI 화풍을 고른 뒤 다음 장면은 **암전 속 서연의 부름 → 가족 회상**이다. 대사집 전에는 화자 공개 시점이나 새 표정·행동 원화를 임의로 확정하지 않는다. 설정 창 등 시작 메뉴의 보조 화면은 공통 화풍 선택 후 해당 흐름에서 검토한다.

## 편집·인게임 사용

기본 게임 해상도는 사용자 지정 **1920×1080**이다. 화면 배치와 글자 크기의 기준이며, 3840×2160 PSD는 2배 편집 원본이다. C0-01부터 `runtime/1920x1080/`에 문자 없는 게임용 UI PNG를 별도 출력한다. 전체 화면 딤은 1920×1080, 작은 진행 표시는 해당 배치 크기로 제공한다. 텍스트는 문자열로 조합한다.

- `psd/`: 전체 UI 4개와 버튼 상태 마스터 2개, 총 6개 PSD. 배경이 없는 진짜 투명 UI 문서다. 로고·가독성 음영·각 버튼 바탕·각 메뉴 글씨·조작 안내가 별도 레이어다.
- `sprites/A`, `sprites/B`: 문자 없는 720×128 RGBA 버튼 4상태(기본/포커스/눌림/비활성). 같은 크기·위치를 공유한다. 상태 PSD에서는 포커스만 기본으로 켜고 나머지는 숨겼다. A의 기본/비활성 바탕은 의도적으로 투명하며 글자 색과 입력 가능 여부로 구분한다.
- `layers/`: 각 PSD와 대응하는 실제 배치 레이어 PNG. 로고 외 문자는 검수용 래스터 레이어이며 **Photoshop 라이브 텍스트가 아니다.** 문장을 바꾸려면 문자열 원본을 수정해 재출력하거나 Unity의 텍스트로 대체한다.
- `manifest.json`: 레이어별 원본 좌표, 논리 좌표, 피벗·앵커 제안, 버튼 클릭 영역, 9-slice 경계, 런타임 글씨 색, 원본 경로와 SHA-256.
- `strings.ko.json`: 메뉴·안내 문구. 글씨는 인게임용 버튼 PNG에 포함되지 않는다. `review/*-ui.png`는 텍스트까지 합친 검수본이다.
- `review/`: 배경과 합친 PNG/JPEG, [4화면 비교](review/C0-00-style-and-save-states.jpg), [버튼 상태 비교](review/C0-00-button-states.jpg). A/B 글자는 비교표에만 있고 게임 레이어에는 없다.

UI 도형·질감·문자는 3840×2160 캔버스(1920×1080 논리 좌표의 2배)에 직접 그렸다. 로고는 기존 2560×976 투명 원본에서 표시 영역을 잘라 축소해 재사용했다. 배경은 기존 1672×941 원화를 화면 크기에 맞춘 **합성 검토용 확대**이며 신규 고해상도 배경이 아니다. 기존 원본 파일은 그대로 보존했다.

실제 가져갈 때 버튼·로고는 Image로, 메뉴 문구는 별도 텍스트로 조합한다. `art/title/fonts/Live49MenuSerif-Regular.ttf` 및 기존 OFL 파일을 재사용한다. 조작 안내의 비교 렌더링에는 시스템 맑은 고딕을 사용했고 해당 폰트 파일은 패키지에 복사하지 않았다. 런타임 안내는 프로젝트 글꼴로 렌더링한다. 터치·컨트롤러 등 입력 장치가 바뀌면 안내 문구도 교체한다.

9-slice는 원본 픽셀 기준 왼쪽/아래/오른쪽/위 `[100,24,100,24]` 제안이다. 타이틀 메뉴는 우선 원래 비율을 유지한다. 긴 문구나 다른 화면비에서의 검증은 실제 해당 화면 제작 때 한다. Unity 프로젝트·입력 코드·텍스트 에셋·저장 연결은 이 PSD 납품에 포함하지 않았다.

## 검수

PSD 병합 RGBA, 숨겨진 버튼 상태를 포함한 모든 레이어 RGBA, 배치 좌표·가시성, 납품 PNG로 재조합한 결과를 검사했다. **68개 검사 통과**. [검수 기록](qa.json). Photoshop 프로그램에서 직접 열고 저장하거나 Unity에 가져오는 검사는 아직 하지 않았다.

재생성은 프로젝트 루트에서 `tools/build-ui-title-styles.py`를 실행한다. UI는 코드로 직접 그린 것이며 이번 비교를 위해 이미지 생성 API나 새 캐릭터 원화를 사용하지 않았다.

### 첫 부름까지 연결한 움직임 시안

카메라는 사용자 피드백 “기본이 좋네”로 3.5%/1.2초를 채택했다. 같은 `opening-motion.html`에서 하단 딤과 “수혁아.” 타이핑까지 확인할 수 있다. 딤·글자 타이밍도 사용자 “좋다”로 채택했다. 현재 회상 페이드까지 연결했고, 음성과 회상 첫 대사는 아직 없다. 세부 타임라인은 `docs/03-콘티/챕터0/C0-OPENING-DIRECTION.ko.md`를 따른다.

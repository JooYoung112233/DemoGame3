# 좌우 인물 대화창 시안 v1

## 2026-09-10 사용자 채택 · 대화 화면 제작 기준

사용자가 시안의 느낌을 채택했다. `dialogue-layout-v1.png`를 후속 대화 화면의 시각 기준으로 보존한다. 약하게 블러 처리한 장소 배경, 좌우의 큰 캐릭터 일러스트, 하단 이름·대사창 구성을 따른다. 수혁·소이 대화의 기준 배치는 왼쪽 수혁 / 오른쪽 소이다. 세부 수치·화자 강조 정도·표정 목록까지 확정한 것은 아니다.

**대화용 캐릭터 원화는 대사집이 나온 뒤 제작한다.** 지금 임의로 표정·행동 세트를 양산하지 않는다. 기존 장면용 정지 포즈와 별도로 필요한 자산으로 제작 계획에 남긴다.

제작 순서:

1. 대사집의 장면·대사 ID와 화자, 등장 인물을 확인한다.
2. 각 대화 구간에 필요한 감정·표정·시선·행동을 정리한다. 좌우 배치와 손·소품 접촉도 기록한다.
3. 여러 대사에서 공유할 기본 자세와 별도 원화가 필요한 변화를 구분하여 목록을 만든다. 표정 수를 미리 고정하지 않는다.
4. 해당 목록을 기준으로 큰 대화용 인물 원본과 필요한 표정·행동 변형을 제작한다. 기존 작은 장면 인물을 확대한 파일로 대체하지 않는다.
5. 배경·인물·UI를 분리해 조합하고 대사와 연결하여 검수한다. PNG와 실제 분리 레이어를 보관하고 가능하면 레이어 PSD를 제공한다.

이 결정은 일반 대화의 표시 방식에 적용한다. 사진 수집·앨범·기억 사건 자체를 폐기한다는 의미는 아니다.

## 시안 파일 정보

사용자 요청: 캠핑카 배경을 약하게 흐리고 왼쪽·오른쪽에 대화 인물 일러스트, 하단에 대사창 표시. 폴라로이드 연출을 사용하지 않는다.

- 시안: `dialogue-layout-v1.png`, 실제 생성 크기 1672×941. 내장 image_gen 사용, 단순 확대 없음. 3840×2160을 요청했으나 실제 출력은 목표보다 작다.
- 왼쪽 수혁, 오른쪽 소이. 기존 캐릭터 레퍼런스와 v3 캠핑카를 참고한 대화 화면 제안이다. 배경은 생성 참고 합성이므로 기존 배경과 픽셀 단위로 동일한 원본으로 취급하지 않는다.
- 표시 대사: 소이 “아빠가 먼저 일어나면 깨워줘.” 기존 챕터 0 취침 대본의 문장이다.
- 화면 구성 검토용 평면 PNG이며 UI·인물·배경이 분리된 납품 자산이나 실행 화면이 아니다. 최종 제작에서는 큰 인물 원본, 기존 배경과 블러 효과, 이름·대사 UI를 각각 분리한다. PSD 없음.
- 이름·문장의 한글 출력과 좌우 배치, 얼굴 가림 여부를 확인했다. 듣는 수혁의 밝기 차이는 작아 실제 화자 전환 시안에서 강조 정도를 조정할 수 있다.
- 생성 프롬프트: `dialogue-layout-v1.prompt.txt`.

기존 문서의 폴라로이드 대화 방식은 이전 검토 이력이며, 일반 대화 화면은 위 최신 사용자 채택 기준을 우선한다.

# Live49 · 플레이 방향 대화 기록

## 2026-09-10 · 챕터 0부터 상황별 UI 제작

- 사용자 지정 게임 기본 해상도는 **1920×1080(16:9)**이다. UI 배치·글자 크기·합성 검수 화면은 이를 기준으로 하고, 편집용 PSD 3840×2160과 인게임용 PNG를 구분한다.
- C0-01의 간결한 대사·진행 표시 구성은 긍정했고, 하단 딤을 보강해 가독성을 높이도록 요청했다. 반영 완료. 사실적인 손 배경은 최종 채택이 아닌 임시 검수 배경이며 후속 교체한다.

- 사용자 요청: 챕터 1까지 필요한 UI를 인게임 조합이 가능한 PNG·레이어 PSD로 만들고, 보여줄 때는 실제 장면과 합성한다.
- 진행 방식 명확화: 챕터 0부터 이어지는 화면을 보면서 UI가 어디 들어가고 어떻게 구성되는지 파악하고 **하나씩 제작·선택한다.** 기능별 UI를 한꺼번에 만들거나 캠핑카 HUD부터 시작하는 순서가 아니다.
- UI 화풍은 [시작 화면 A/B 비교](../design/ui/ch00-01/README.ko.md)에서 **A(활자·얇은 선)를 사용자 채택**했다. B는 이력으로 보존하고 A의 크림색 활자·절제한 선을 후속 화면에 적용한다. 이후 각 장면의 구성까지 일괄 승인한 것은 아니다.
- [장면 순서와 UI 계획](UI-CH00-01-PLAN.ko.md)을 따른다. 대화 인물의 표정·행동 원화는 기존 결정대로 대사집 이후 제작한다.

## 2026-09-10 · 좌우 인물 대화 화면 채택과 원화 제작 순서

- 사용자 채택: [대화 화면 시안 v1](../design/dialogue/dialogue-layout-v1.png)의 느낌으로 진행한다. 장소 배경에 약한 블러를 적용하고 좌우에 캐릭터 일러스트, 하단에 화자 이름·대사를 표시한다. 일반 대화는 폴라로이드 방식 대신 이 구성을 기준으로 한다.
- 대화용 캐릭터 원화가 별도로 필요하다. **대사집이 나온 뒤 장면별 표정·행동을 정리하고 제작한다.** 현재 임의로 표정 수나 행동 세트를 확정하거나 제작하지 않는다.
- 시안은 1672×941 평면 PNG이며 최종 분리 원화가 아니다. 큰 인물 원본, 배경, UI는 후속 제작에서 분리한다.
- 상세 기록과 제작 순서는 [대화 화면 기준](../design/dialogue/README.ko.md)에 보관한다. 사진 수집·앨범·서사 사건의 기존 결정은 유지한다.

> 첫 주 이벤트 구체화: [장소 7곳·이벤트와 다음 지역 연결](CHAPTER01-EVENT-QUEST-DRAFT.ko.md). 아래 최신 사용자 수정 사항을 반영했다. 나머지 개별 사건·보상·날짜는 검토안이다. 기존 엔딩을 유지하고 감염자 도입은 보류한다.

## 2026-09-10 · 첫 편지 연기와 첫 그림·사진 튜토리얼

- 사용자 지정: 초반 발견으로는 충분히 몰입하기 어려우므로 서연의 첫 편지를 챕터 3 무렵으로 미룬다. 정확한 날짜·장소·발견 동기는 후속 콘티에서 정한다. 편지 원문과 기존 원화는 보존한다.
- 기존 챕터 2의 두 번째 편지는 첫 편지보다 먼저 나오지 않도록 재배치가 필요하다. 정확한 새 배치는 미정이며 후속 편지의 내용을 이번 결정으로 바꾸지 않는다.
- 첫 그림과 첫 사진은 안내에 따라 반드시 진행하는 최초 이벤트 튜토리얼이다. 도구 확보·전달·그림 완성, 카메라 확보·촬영·앨범 확인까지 안내한다. 기존의 선택 분류보다 이 지시를 우선한다.
- 이미 확보한 색연필은 그대로 인정한다. 필수 도구·첫 촬영 필름은 확보를 보장하고, 중단 시 남은 단계부터 재개하며 첫 지역 출발 전에 두 튜토리얼을 완료한다. 이후 그림·사진은 선택 활동으로 유지한다.
- 연료는 시작부터 당장 모자라지 않는다. 긴급 주유와 소이의 부탁을 경쟁시키지 않으며, 연료 보충은 선택적 준비다. 세진·카메라·첫 사진 진행을 주유 완료에 연결하지 않는다.
- 연결 초안: 첫 그림 뒤 다음 지역의 길 정보를 얻기 위해 주유소에 방문 → 세진의 부탁 → 카메라와 필름 → 첫 사진. 방문 대사와 구체적인 부탁은 후속 검토한다.
- 사진 5장으로 여는 추가 에필로그와 기존 엔딩 분기 기준은 그대로 둔다. 이번 변경은 로컬 기획 문서 반영이며 실행 구현은 아니다.

> 엔딩 최신 사용자 지시: 기존 엔딩 뼈대를 유지한다. 오늘 대화에서 나온 엔딩 변경은 적용하지 않고 참고 아이디어로만 보관한다. 아래의 ‘반전의 진실’ 승인 표현을 포함하여 엔딩 변경을 확정한 듯한 기록은 이 지시로 정정한다.

## 2026-09-10 · 엔딩 변경 보류 — 기존 뼈대 유지

- 사용자 명시: “엔딩도 아까 이야기한거로 바꾸진말고 일단 참고만해줘 뼈대는 그대로 두자.”
- 기존 엔딩 뼈대를 유지하며, 이번 대화로 엔딩 수·진실·결말·분기 조건을 변경하지 않는다.
- 세 엔딩(해피·노말·반전), 수혁과 소이의 동시 생존, 반전 이후 수혁 생존과 치료 방송, 모든 루트에서 소이가 이미 죽었다는 해석, 단서 탐색 중심으로 엔딩 진입 조건을 교체하는 안은 모두 참고 아이디어로 보관한다. 구현 및 콘티 수정의 확정 요구사항으로 쓰지 않는다.
- 앞서 제시한 서로 다른 과거의 루트 해석 역시 제안에 불과하며 채택하지 않는다. 기존 정신력과 이벤트 경험에 따른 엔딩 구조를 이번 논의만으로 대체하지 않는다.
- 감염자 보류 및 서연의 원인 모를 병 방향은 별도 최신 논의로 유지하되, 이를 이유로 엔딩 뼈대를 자동 수정하지 않는다.

> 최신 우선 기준: 감염자 도입은 보류한다. 아래 감염 중심 개편과 감염 시한부 확정 문구는 이전 논의 이력이다. 주인공들은 재난의 원인을 모르는 상태이며, 감염자는 필요할 때 보조 소재로 재검토한다. 서연은 원인 모를 병으로 사망한 방향으로 변경한다. 수혁의 시한부 원인은 이번 변경에 맞춰 미정으로 두며, 간암으로 자동 복귀하거나 감염으로 확정하지 않는다.

## 2026-09-10 · 이벤트 중심 진행과 감염자 보류

- 사용자는 제작 규모와 분위기를 이유로 감염자를 현재 주력 게임에서 보류했다. 감염자 전투·유형·전파 규칙·필수 조우를 지금 제작할 요구사항으로 두지 않는다. 나중에 적합하면 보조 소재로 활용한다.
- 주인공들은 아포칼립스가 발생한 원인을 모른다. 실제 원인이 감염이라는 사실 자체도 이번 발화로 확정하지 않는다.
- 서연의 사인은 기존 지병·유전병 확정 대신 원인 모를 병으로 사망한 방향이다. 재난의 원인과 같은 병인지, 전염성인지, 소이에게 유전되는지 임의로 연결하지 않는다.
- 수혁의 감염 시한부, 반전 마지막 치료 방송 등 감염에 의존하는 이전 제안은 후속 정리가 필요하다. 이번 보류를 이유로 기존 간암을 자동 복원하거나 새 사인을 만들지 않는다.
- 현재 핵심은 상황 이벤트가 할 일을 만들고, 탐색·재료 확보·제작 등의 대응이 후속 변화로 이어지는 진행이다. 백여 가지 이벤트 초안을 검토하되 단순 물건 이름 교체가 아니라 발생 상황부터 목표·대응·결과까지 연결한다. 아직 백 개의 상세 이벤트를 제작 완료한 것은 아니다.
- 감염자 보류가 과거의 매일 밤 내면 전투·49층안을 자동 부활시키지는 않는다. 직접 이동·걷기 애니메이션도 채택된 필수 범위가 아니다.
- 이번 수정은 로컬 기획 기록이며 기존 원화·실행 게임·원본 Google 문서를 변경하지 않았다.

> 2026-09-10 후속 사용자 확정 변경: 수혁의 시한부 원인을 간암 말기에서 감염으로 대체한다. 아래와 기존 문서의 간암·유전병 유지 서술은 이전 설정 이력이며, 최신 기준은 본 문서의 ‘감염으로 시한부 원인 변경’ 항목을 따른다. 감염 상세는 사용자 작성 대기다.

> 2026-09-10 최신 개편 기준: [챕터 0~1 감염자 개편안](CH00-01-INFECTED-REVISION.ko.md). 낮의 감염자 조우·탐색과 밤의 돌봄으로 구성하고 상시 내면 전투·49층은 기본 진행에서 제외하는 개편안이다. 감염자의 상세 설정은 사용자가 직접 작성하므로 임의로 정하지 않는다. 아래 이전 밤 전투 기록은 논의 이력이다.

사용자가 좋다고 평가한 내용과 현재 검토 중인 내용을 구분한다. 기존 콘티 전체를 확정하거나 구현 완료로 취급하지 않는다.

## 사용자가 긍정한 방향

- 낮은 텔테일 워킹 데드처럼 상황 안에서 대사·행동 선택을 하고 인물 반응을 보는 방향. 고정 배경, 분리 포즈, 확대 컷으로 제작 규모를 제한한다.
- 밤은 SKYHILL을 참고한 인물 표시형 방 탐색과 간단한 턴제 전투 방향. 기존 격자 시제품은 원하는 주력 게임 형태가 아니다.
- 낮의 탐색·소이와의 교감·위기 경험이 밤의 능력과 정신력 유지에 영향을 준다. 죄책감과 미안함은 장면과 형상으로 은은하게 표현한다.
- 정신력에 따라 경험하는 이벤트가 달라지고, 해당 이벤트 누적이 엔딩 루트를 형성한다. 마지막 날 정신력 숫자 하나로 판정하는 구조로 오해하지 않는다.
- 수혁의 마음은 소이를 잃는 공포만이 아니라 자신이 먼저 떠난 뒤 아이가 살아갈 준비와 연결한다. 안전한 동행 장면에서 소이에게 길을 찾아보게 하는 대화 방향을 긍정함. 정확한 배치는 미정.
- 챕터 0 이후 물 부족을 계기로 지도 열기 → 편의점 목적지 선택 → 캠핑카 이동을 배우는 첫날 도입 방향.
- 편의점까지 캠핑카로 함께 가되, 내부 탐색은 수혁 혼자 하는 방향. 소이는 가까이 세운 캠핑카에서 기다리고, 출발 전 두 번의 노크를 신호로 약속한다. 귀환 시 같은 신호를 회수하는 장면을 긍정함.

## 추가 승인 · 낮 활동과 이벤트 중심 진행

사용자가 음성 대화에서 아래 방향을 좋다고 평가하고 기록 후 게임에 적용하도록 요청했다. 이는 제작 기준 반영이며 실행 게임에 구현 완료된 상태는 아니다.

### 시간과 하루의 선택

- 지도에서 목적지까지의 거리와 연결된 캠핑카 이동 소요 시간을 사전에 보여준다. 실제 기다림이 아니라 게임 속 시간으로 처리한다.
- 낮 활동은 물자 확보·여행 준비, 소이와의 교감, 수혁의 휴식·자기 돌봄이라는 세 축으로 구성한다. 모든 날에 같은 세 버튼을 의무적으로 제시하는 구조로 고정하지 않는다.
- 시간은 모든 활동을 다 할 수 없게 만들어 우선순위를 고르게 하는 자원이다. 냉장고 한 번 열기 같은 작은 조사마다 큰 시간 비용을 붙이지 않는다.
- 이동 외의 시간은 한 차례 수색, 소이와 보내는 시간, 휴식처럼 의미 있는 활동 단위에 붙인다. 대사를 읽는 실제 시간은 비용으로 차감하지 않는다. 정확한 비용·표시 단위는 미정이다.
- 짧은 외출 한 번을 했다는 이유만으로 자동으로 저녁까지 넘기지 않는다. 선택한 활동에 맞게 시간이 흐르며, 오전·오후를 억지로 채우기 위해 반복 조작이나 사건을 추가하지 않는다.
- 사용자의 시간 관련 우려는 짧은 실제 플레이에 비해 게임 속 몇 시간이 지나가는 체감의 간극이었다. 목적지 시간 안내와 의미 있는 활동의 선택·결과를 함께 사용한다.

### 사건과 결과

- 소이의 상태·요구, 현재 상황, 환경, 탐색, NPC와의 만남에서 이벤트가 발생하고, 사용자가 무엇을 우선할지 결정한다.
- NPC와 유대를 쌓거나 지나치는 선택, 약탈자와 싸우거나 죽일지 여부를 고민하는 선택 등도 사건 후보로 포함한다. 첫날에 살상 사건을 반드시 넣거나 특정 전투 조작을 확정한 것은 아니다.
- 사건 결과는 수혁의 정신력, 소이의 행복도·상태, 피로, 물자, NPC 관계, 후속 사건에 반영한다. 모든 이벤트가 모든 수치를 동시에 바꾸지는 않는다.

# 챕터 0 원화 검수 · Unity 제외

2026-09-10. 판정: **전체 흐름을 검토할 1차 조합은 확보, 최종 원화 납품은 보완 필요.**

현재 콘티, 연출 정리 6절, 원본·납품 규칙을 기준으로 확인했다. 회상→현재→준비→소등→조사→복구→기록→마지막 소등을 비교했다. 88개 이미지 파일을 디코딩하고 원본 치수·알파·자산 참조를 확인했으며, PSD 3개 총 8레이어의 RGBA 데이터와 기본 표시 합성을 대조했다. 자동 검사 58개 통과, 실패 0개다. 이 수치는 파일·정적 상태 검사 결과이며 그림의 최종 품질이나 게임 진행 검증을 의미하지 않는다.

| 회상 제작 스크립트를 재실행하면 캠핑카·QA 파일까지 회상 자산 목록에 포함될 수 있음 | 회상·현재·회상 소스 폴더만 목록에 포함하도록 제한. 기존 9개 회상 목록 유지 |
| 캠핑카 목록에 재사용한 작은 인물·책·컵의 원본 경로가 빠짐 | 재사용 자산 경로를 명시하고 실제 파일까지 검사 |

[수리 장면 수정 비교](../art/chapter00/qa/repair-before-after-2x.png): 왼쪽 수정 전, 오른쪽 수정 후. 결함 확인을 위해 2배로 표시한 검수 이미지이며 고해상도 원본이 아니다.

[물·담요 순서별 비교](../art/chapter00/qa/preparation-orders.jpg): 왼쪽 위 준비 전, 오른쪽 위 물만, 왼쪽 아래 담요만, 오른쪽 아래 모두 준비. 실제 이벤트 트리거·재진입 처리는 검사 범위 밖이다.

## 유지되는 부분

- 가구·차체·식탁은 기존 v3 배치 좌표를 유지한다. 소등은 같은 좌표의 색·밝기 변환이며 복구는 원래 밝은 배경이다. 새 소품으로 가려지는 영역은 있다.
- 소이는 같은 좌석을 유지하고 물자·전원부를 직접 다루지 않는다. 수혁이 점검할 때 앉아 있는 수혁을 중복 표시하지 않는다. 발과 무릎은 러그 영역에 놓이며 접지 그림자가 있다.
- 스케치북은 복구까지 식탁에 남고 이후 정리된다. 고정한 연결부는 기록·마지막 소등까지 유지한다. 손전등은 조사 중 수납 위치에서 사라지고 복구 뒤 돌아온다.
- 물·담요·책 등은 별도 PNG로 유지된다. 전원부 두 상태는 연결부 교체 영역 밖의 픽셀이 동일하다.
- 신규 소품 8개 모두 실제 투명 영역과 불투명한 물체 영역이 있다. 밝은/어두운 배경의 검수본에서 외곽과 팔·끈 틈을 확인했다. 이것이 모든 확대 배율에서 가장자리가 완벽하다는 뜻은 아니다.

## 최종 원화 전에 남은 항목

| 우선순위 | 발견 사항 | 필요한 보완 |
| --- | --- | --- |
| 높음 | 수리 포즈의 들어 올린 손은 패널의 위쪽 스위치 부근을 향한다. 연결 고정 장면에서도 같은 포즈여서 실제 연결부를 잡거나 누르는 접촉이 없다 | 조사 포즈는 유지하고, 연결 고정 순간만 손·팔 접촉 컷을 보강. 단순 전체 이동으로 발 접지를 무너뜨리지 않기 |
| 높음 | 준비 몽타주의 ‘가방 안 담요’가 단독 담요 그림으로 대체되어 있고 정리된 짐 컷은 200×175 배치 크롭이다 | 콘티의 3컷을 유지하려면 가방·담요 접촉 및 정리된 짐의 큰 원본 필요. 현재 배치 컷을 최종 확대 컷으로 사용하지 않기 |
| 높음 | 현재 앉은 수혁·소이는 각각 109×155 / 112×132 PNG다. 몸과 손이 같은 작은 캔버스에 나뉘어 있다 | 폴라로이드 대화·표정 확대에 쓰기 전 승인된 비례와 자세를 유지한 큰 원본 확보 |
| 중간 | 회상 손을 받는 컷과 현재 책 위 손은 위치뿐 아니라 손바닥/손등 방향도 다르다 | 현재 상태는 연상 전환 후보. 정확한 매치 컷을 원하면 손 구도·각도부터 맞춘 후 크롭을 확정 |
| 중간 | 회상 전신, 큰 손, 수리 포즈는 현재 앉기 인물보다 비례·명암·선 묘사가 세밀하다 | 색감만으로 완전 일치했다고 판단하지 않기. 기존 v3 인물의 비례와 붓질을 기준으로 필요한 컷만 다듬기 |
| 중간 | 전원부 PNG는 연결부의 헐거움/고정 2상태만 있다. 조명 복구·마지막 소등에도 스위치 레버 그림은 동일하다 | 스위치를 근접해서 보여줄 경우 ON/OFF 상태 추가. 원거리 합성의 밝기 전환만으로 스위치 원화 완료라고 표시하지 않기 |
| 중간 | 배경·회상 현재 컷은 1672×941, 서연/소이 접촉 그룹 높이 1364, 수리 인물 높이 1315다 | 배경 장변 3840, 주요 인물 실제 높이 1536~2048 목표에 미달. 확대가 필요한 부분부터 보강 |
| 중간 | 소등/복구의 소이 표정과 저널 장면의 수혁은 기존 앉기 자세를 공유한다 | 감정 변화나 실제 기록 동작을 보여줄 컷이 필요한지 연출에 맞춰 선별. 현재 저널은 빈 페이지 단품이며 글쓰기 포즈가 아님 |
| 별도 제작 | 저장소에서 WAV/MP3/OGG/FLAC 음향 파일을 찾지 못함 | 호출·물건 놓기·스위치·전원·공간음의 실제 음원 제작 또는 선정 필요. 타이밍 검증 이전의 리소스 공백 |

해상도 부족은 사용자가 후속 보강으로 둔 사항이므로 이번 검수에서 승인된 원화를 재생성하거나 단순 확대한 파일로 교체하지 않았다. 신규 일반 소품은 대체로 긴 변 1277~1502px로 확보되어 있다. 책 102×73, 컵 53×52의 기존 시안은 신규 큰 저널과 구분해야 한다.

## 편집 가능성의 실제 범위

| PSD | 검증한 레이어 | 제한 |
| --- | --- | --- |
| `memory-hands-layers-v1.psd` | 손 건네기 / 받은 손 / 회상 배경 3개 | 현재 책 위 손은 평면 PNG, 서연·소이는 별도 접촉 그룹 PNG |
| `camper-light-states-v1.psd` | 반사광 / 소등 배경 / 원래 밝은 배경 3개 | 가구가 개별 레이어인 캠핑카 전체 PSD가 아님. 조사 마스크와 인물·소품은 별도 PNG |
| `power-panel-states-v1.psd` | 연결 고정 / 헐거움 2개 | 실제 투명 알파 유지. RGB 병합 미리보기만 검정 바탕. 레버는 별도 상태가 아님 |

숨겨진 레이어까지 RGBA 바이트를 PNG와 대조하고, 표시 플래그·크기·기본 합성 결과를 확인했다. Photoshop 프로그램에서 직접 열고 저장하는 호환성 검사는 하지 않았다. 수리 인물의 몸·손·손전등, 저널의 책·연필, 회상의 모녀는 각각 접촉 그룹이며 구성 요소가 전부 독립 레이어인 것은 아니다.

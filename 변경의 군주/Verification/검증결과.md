# Demo8 월드맵·내정 검증

2026-10-04 · Unity 6000.6.0f1 · 최종 에디터 조작 및 검증 경로: Unity MCP (`unity-mcp` 1.0.0-beta.9, stdio).

- 컴파일 성공, 최종 Unity 콘솔 오류 0 / 경고 0.
- `VerifyWorldCampaign.Rules`: 38개 규칙 검사 통과. 지역 연결, 복수 군단, 건설·모집, 지형 이동 비용, 보급 단절, 진지·강습, 세율·방침·연구, 휴전, 승패, 저장 구조 및 장기 시뮬레이션.
- `VerifyWorldCampaign.Playthrough`: 자원 보정 없이 일반 명령으로 진행하여 13턴째 12지역 유지 승리. 턴별 결과는 `world-playthrough.txt`.
- `VerifyCampaignInput.Run`: 실제 Input System 마우스·키보드 입력 21개 검사 통과. 건설·모집·지도 선택·전투 확인/취소·행군 시작/도착·구휼·턴 종료·내정 화면·세율·연구·재시작·WASD·Home·Tab. 검증 중에만 게임 뷰로 입력 전달을 강제하고 기존 입력 설정과 장치를 복원한다.
- `VerifyWorldCampaign.Runtime`: 복수 군단과 내정 정책을 포함한 실제 디스크 저장/불러오기 동일성, 손상 저장 거부 확인. 기존 저장 파일과 백업이 있으면 검증 후 원상 복원한다.
- 전체 지도, 내정 화면, 군단 근접 시점 캡처 검수 완료: `world-map.png`, `domestic.png`, `army-close.png`.

사용자 지시대로 실행 파일을 빌드하지 않았다. 최종 상태는 `Assets/Scenes/Campaign.unity`를 Unity Editor에서 Play 중이며 군단 근접 시점이다. 규칙 코드의 전투 해결은 자동이며 개별 병사 전장 전투는 이번 구현 범위가 아니다.

# Demo8 — 영토 전략 기획 1차

작성일: 2026-10-04 · 상태: 준비 초안, 플레이 기능 미구현

## 사용자 지정 방향

- 신규 데모 번호는 8번이다.
- 삼국지 토탈워처럼 세력을 운영하고 영토를 넓히는 게임을 만들고 싶다.
- 개발 환경은 Unity 6.6이다.

아래 세부 구성은 이 방향을 시험하기 위한 제안이다. 삼국지 세계관, 실시간 전투, 최종 화풍이 승인된 것으로 해석하지 않는다.

## 플레이의 중심

플레이어는 한 세력을 맡아 도시의 수입과 식량을 관리하고 군대를 편성한다. 이웃 세력의 땅을 차지할 수 있지만 군대 유지비와 점령지의 불안 때문에 무작정 확장할 수는 없다. 어디를 먼저 개발하고 어느 길로 진군할지 판단하는 재미를 우선 확인한다.

한 턴의 흐름은 현황 확인 → 내정·모집·군대 이동 명령 → 전투 및 점령 결과 확인 → 턴 종료 → 다른 세력 행동과 수입·유지비 결산으로 잡는다.

## 첫 캠페인 제안

| 항목 | 1차 제안 |
| --- | --- |
| 지도 | 서로 연결된 지역 12개, 지역당 중심 도시 1개 |
| 세력 | 플레이어 1개, 경쟁 세력 2개, 나머지는 독립 지역 |
| 시작 | 플레이어 도시 2개와 군대 1개 |
| 자원 | 금, 식량 / 지역 상태는 치안 |
| 내정 | 농지·시장·병영의 건설 및 개선 |
| 군대 | 지휘관 1명과 보병·궁병·기병 편성 |
| 이동 | 인접 지역 이동, 군대별 턴당 행동 제한 |
| 전투 | 출정 전 예상 전력·피해 안내 후 자동 해결 |
| 점령 | 소유권 변경, 병력 손실, 치안 하락, 주둔 필요 |
| 외교 | 첫 내정·점령 검증 후 전쟁·휴전부터 확장 |
| 목표 | 예시: 지역 6개를 확보하고 3턴 동안 유지 |
| 패배 | 보유 도시를 모두 잃음 |

지도는 실제 역사 지리를 확정하기 전까지 임시 지역명과 도형으로 구성한다. 지역 수와 목표는 첫 플레이 결과에 맞춰 조정한다.

## 운영에서 생기는 선택

- 농업 지역은 더 큰 군대를 먹여 살리지만 즉시 금 수입은 적다.
- 상업 지역은 모집과 건설 자금을 마련하지만 식량 생산지를 지켜야 한다.
- 길목 지역을 점령하면 적의 접근 경로를 제한할 수 있다.
- 군대를 크게 만들면 전투는 유리해지지만 매 턴 지출이 커진다.
- 점령지에 병력을 남기면 치안은 안정되지만 다음 공격의 전력이 줄어든다.

첫 버전에서는 금·식량의 이번 턴 변화와 다음 턴 예상치를 항상 보여준다. 자원이 부족한 행동은 실행 전에 이유를 설명한다. 점령만 반복하는 플레이와 내정만 하는 플레이 사이에 선택이 생기는지 확인한다.

## 전투의 단계

첫 목표는 캠페인 운영과 점령의 연결을 검증하는 것이다. 자동 전투는 병력·병종·지형·방어 상태를 반영하고 예상 우세와 손실 범위를 보여주는 방향으로 설계한다. 같은 저장 상태와 같은 명령은 재현 가능한 결과를 갖게 한다.

실시간 부대 지휘는 별도 후속 단계다. 추가한다면 소규모 전장에서 이동·대형·측면 공격·사기·퇴각을 먼저 검증하고 캠페인의 병력 손실과 연결한다. 대규모 병사 시뮬레이션, 공성전, 장수 결투를 첫 준비 범위로 확정하지 않는다.

## Unity 구성 방향

- 렌더링 기반: Universal 3D, 캠페인 지도용 상공 카메라.
- `Core`: 세력·도시·군대·자원·턴 진행·전투 결과 규칙.
- `Game`: 지도 선택·카메라·도시 및 군대 화면.
- `Data`: 지역 연결과 세력·시설·병종 정의.
- `Tests`: 자원 결산, 이동 제약, 점령, 승패, 저장 복원 검증.

규칙과 화면을 분리해 자동 전투를 나중에 실제 전투로 교체해도 캠페인 데이터를 이어 쓸 수 있게 한다. 위 코드 구조와 저장 기능은 아직 구현하지 않았다.

## 제작 순서와 통과 기준

1. **지도와 턴:** 지역 선택, 소유 세력 표시, 인접 관계, 턴 종료를 구현한다. 갈 수 없는 지역과 이동 가능한 지역을 구분할 수 있어야 한다.
2. **내정과 군대:** 시설·모집·수입·유지비를 연결한다. 돈과 식량이 왜 늘거나 줄었는지 플레이어가 설명할 수 있어야 한다.
3. **점령과 경쟁:** 자동 전투·소유권 변경·점령지 치안·적 세력 행동을 구현한다. 첫 점령 후 수 턴을 더 운영하며 확장의 대가를 체감해야 한다.
4. **한 판 완성:** 승패·재시작·저장을 연결한다. 도중 저장을 불러와 같은 상태에서 계속할 수 있어야 한다.
5. **확장 판단:** 운영의 재미를 확인한 뒤 외교·지휘관·직접 전투의 우선순위를 정한다.

## 아직 정하지 않은 것

- 실제 삼국지 시대와 인물을 쓸지, 독자적인 시대·세력을 만들지.
- 턴제 캠페인을 유지할지, 일시정지 가능한 실시간 운영을 선호할지.
- 전투를 직접 지휘하는 비중과 한 전장에 등장할 부대 수.
- 지도·건물·인물의 화풍과 화면 구성.
- 최종 게임명, 캠페인 분량과 난이도.

# 변경의 군주 (가제)

Unity 6.6 (`6000.6.0f1`) / Universal 3D 기반의 에디터용 영토 전략 프로토타입입니다. 삼국지 토탈워를 참고한 운영·군대 지휘·영토 확장을 시험합니다. 지명과 세력은 가상이며 최종 세계관·화풍은 미정입니다.

## 실행

Unity에서 `변경의 군주` 폴더(이전 `demo8`)의 `Assets/Scenes/Campaign.unity`를 열고 Play를 누릅니다. 사용자 요청에 따라 실행 파일은 빌드하지 않습니다. 씬 재생성은 `Demo8/캠페인 씬 만들기` 메뉴로 가능합니다.

## 구현 내용

- 48개 지역의 월드맵: 평야·숲·산지, 도시, 이동 경로, 소유 세력, 확대와 지도 이동.
- 세력 3개와 독립 지역. 플레이어는 청하와 남곡에서 시작합니다. 적 세력도 모집·이동·점령합니다.
- 최대 3개 군단을 따로 지휘합니다. 지도에 병사 대형과 깃발이 보이며 이동 명령 뒤 목적지까지 행군합니다.
- 군대별 행동력 기본 2. 평지·숲 이동 1, 도로 없는 산지 2. 전투는 남은 행동을 모두 사용합니다.
- 기동·진지·강습 태세, 지형별 병종 효율, 수비대·성벽·치안과 보급 상태를 반영한 자동 전투. 공격 전에 예상 전력과 손실을 확인합니다.
- 수도에서 우리 영토로 이어지는 보급망. 연결이 끊기면 공격력 -30%와 매 턴 병력 손실이 발생합니다.
- 별도 내정 화면: 세율, 도시 방침, 농법·상업·병참 연구, 보유 도시 현황, 도로와 성벽.
- 도시 개발: 농지·시장·병영·도로·성벽 각 3단계. 도시마다 턴당 시설 하나를 즉시 개선합니다.
- 점령지 치안, 구휼, 수비대 증원, 반란. 국고·식량 부족 시 병력 이탈.
- 금 250으로 경쟁 세력과 3턴 휴전. 해당 기간에는 서로 공격할 수 없습니다.
- 12개 지역을 확보해 3턴 유지하면 승리, 모든 도시를 잃으면 패배. 저장·불러오기·재시작.

## 조작

| 입력 | 동작 |
| --- | --- |
| 지역 클릭 | 지역 정보와 출정 대상 선택 |
| 좌측 군단 버튼 | 지휘 군단 선택 및 근접 시점 |
| WASD / 마우스 휠 버튼 드래그 | 지도 이동 |
| 마우스 휠 | 확대·축소 |
| Home | 선택 군단에 접근 |
| 전체 지도 버튼 | 월드맵 전체 시점 |
| Tab | 월드맵 ↔ 내정 |
| Space / 턴 종료 | 다른 세력 행동과 결산 진행 |
| F5 / F9 | 저장 / 불러오기 |
| Esc | 전투·재시작 확인 취소 |

우리 도시에서 병력을 모집하면 주둔 군대를 보충합니다. 군대가 없는 병영 도시에서는 창설비 금 150을 추가로 내고 새 군단을 만듭니다. 각 군단은 최대 800명이며 한 지역에 아군 군단 하나만 주둔할 수 있습니다.

## 전략 선택

- 경감 세율은 금 수입 -20% 대신 턴당 치안 +5, 중과는 수입 +20% 대신 치안 -8입니다.
- 농업 방침은 식량 +35%, 상업은 금 +30%와 치안 -3, 군정은 치안 +5와 수비대 +8입니다.
- 농법 연구는 단계마다 식량 +15%, 상업은 금 +10%. 병참은 고립 손실을 줄이고 2단계부터 행동력을 1 늘립니다.
- 도로는 산지 이동 비용을 1로 줄이며 수입을 늘립니다. 성벽은 수비대 방어력을 단계마다 20% 높입니다.
- 진지 태세는 군대 방어력 +30%지만 이동 불가, 강습은 공격력 +15% 대신 손실이 증가합니다.

저장은 `Application.persistentDataPath/demo8-campaign-v2.json`에 기록됩니다. 이전 12지역 시안의 v1 저장과 분리하며 손상된 저장은 현재 게임에 적용하지 않습니다.

## 범위

병사는 도형으로 만든 지도상 군단의 표현이며, 전투는 아직 자동 해결입니다. 실시간 전장 지휘·공성전·장수·복잡한 외교·안개 전쟁·최종 원화는 구현하지 않았습니다. 국가 연구와 시설 개발은 현재 즉시 완료되는 시험 규칙입니다.

코드는 `Assets/Scripts/Core/Campaign.cs`(게임 규칙), `Assets/Scripts/Game/CampaignView.cs`(지도·행군·화면), `Assets/Editor/CampaignSetup.cs`(씬 생성)에 있습니다. 검증 도구는 `AgentScripts/VerifyWorldCampaign.cs`와 `AgentScripts/VerifyCampaignInput.cs`입니다. 최초 1차 기획은 `기획/영토전략-기획-1차.md`, 최신 변경 방향은 `기획/월드맵-내정-2차.md`를 참고합니다.

검증: 규칙 38개·실제 입력 21개 통과, 정상 명령으로 13턴째 승리, 실제 저장 복원과 콘솔 오류 0건을 확인했습니다. 자세한 결과는 [검증 기록](Verification/검증결과.md)에 있습니다. 최종 에디터 조작은 Unity MCP로 수행했습니다.

# 이스트 트레인 (Demo7)

Unity 6.6 (`6000.6.0f1`) / Universal 2D 기반 프로토타입입니다.

얼어붙은 세계에서 한 사람이 낡은 열차를 직접 운전·수리하며 동쪽으로 향합니다. 폐역에서 차량기지까지 가는 프롤로그를 구현했습니다. 핵심 반복은 **운전 → 기관실 확인 → 연료 보충 → 이상 발생 → 수리 → 다시 운전**입니다.

## 현재 저장 상태 · 2026-10-03

- **이미지와 최종 화풍은 미정입니다.** 사용자 요청으로 생성 이미지·시안·PNG·PSD·스크린샷과 Unity 이미지 연결 자산을 삭제하고 커밋에서 제외했습니다.
- 현재 실행 화면은 기본 도형으로 구성한 기능 확인용 화면입니다. 최종 미술·내부 배치 승인을 뜻하지 않습니다.
- 원래 1인 직접 조작 기획을 유지합니다. 여러 사람에게 일을 지시하는 실험 코드는 비활성 상태로 보존하며 기본 플레이에 사용하지 않습니다. NPC·식량은 미정입니다.
- 이미지 관련 확장·스크린샷·사용자 참고 이미지는 `demo7/.gitignore`에서 제외합니다. 새 원화는 시안을 확인한 뒤 별도로 진행합니다.
- 원화 연결·제작용 AgentScripts는 이전 실험 도구이며, 삭제한 이미지 원본 없이 실행하지 않습니다.

## 실행

Unity에서 `demo7` 프로젝트를 열고 `Assets/Scenes/EastTrain.unity`에서 Play를 누릅니다. 기존 `Main.unity`는 빈 시작 씬으로 보존했습니다.

상시 HUD와 설비 이름표는 숨깁니다. 근처 조작 안내는 잠깐 나타난 뒤 사라지고, Tab을 누르는 동안 다시 확인할 수 있습니다. 수리 타이밍 계기는 수리할 때만 표시됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| A/D 또는 좌우 화살표 | 이동 |
| W/S 또는 위아래 화살표 | 사다리 오르내리기 |
| E | 근처 연료·화실·냉각 밸브·작업대·운전석·문 사용 |
| G | 들고 있는 연료 내려놓기 |
| 운전 중 W/S | 출력 조절 |
| 운전 중 Space | 제동 전환 |
| 수리 중 Space | 초록 구간에 맞춰 수리 |
| E / Esc | 운전·수리 중단 |
| 열차 밖 E 길게 | 눈더미 제설 또는 비상 땔감 수집 |
| 마우스 휠 / 휠 버튼 | 확대·축소 / 기본 시점 복원 |
| Tab | 현재 조작 안내 |
| Ctrl+R | 프롤로그 재시작 |

처음에는 왼쪽 선반에서 연료를 들어 화실에 넣고, 오른쪽 작업대에서 타이밍 수리를 세 번 성공시킵니다. 사다리로 운전실에 올라가 운전석에서 E를 누른 뒤 제동을 풀고 출력을 올립니다. 운전 중이거나 열차가 움직이면 전방 연료와 장애물을 볼 수 있도록 카메라가 넓어집니다.

연료 소모·잡동사니 연소·과열과 화재·냉각·추위 감속·눈길 제설·철판 탈락·수리와 도착을 구현했습니다. 거대한 나무, 끊어진 철로, 진행에 따른 객차 확장, 저장은 후속 작업입니다. 무전은 로컬 합성 임시 음성입니다.

## 검증

- `VerifyEastTrain.Rules`: 열차 상태 규칙과 전체 프롤로그 진행.
- `VerifyEastTrainInput.Run`: 실제 키 입력으로 이동·운전·연료·타이밍 수리·제설·도착 확인.
- `VerifyEastTrainPresentation.Run`: 상시 글자 제거, Tab 안내, 수리 계기, 원래 1인 기본 도형 화면 확인.
- `VerifyEastTrainZoomLayout.Run`: 휠 확대와 주행 시 전방 시야 확인.

검증은 플레이 상태를 변경하므로 끝나면 Play를 껐다 켭니다. 자세한 원기획은 [기획 문서](기획/이스트-트레인-기획-1차.md)를 참고합니다.

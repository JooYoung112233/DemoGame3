# 시작 화면 리소스 v2

2026-09-22. **리소스 교체 검토본이며 사용자 시각 승인 대기.**

사용자가 현재 배경 구도와 UI 위치가 좋다고 정정했다. v1의 1920×1080 바깥 배치, 버튼 5개와 순서, 제목 위치를 유지한다. 이후 아이콘·크기·정렬 차이를 다시 지적하여 **버튼 내부는 승인 원본의 아이콘과 비율로 수정**했다. 폰트만 유사한 실제 서체로 대체하는 것을 허용했다.

현재 적용: 제목 종이는 사용자가 직접 지목한 **계단형 원본**이다. `title-paper-stepped.png`를 사용하며 위치 (110,80), 폭 670은 유지하고 원본 비율에 맞춰 높이를 약 348로 조정했다. 설명 문구는 아래 왼쪽 종이에 두 줄로 둔다. 버튼 종이와 아이콘은 승인 원본 20번/19번에서 직접 분리, 글씨는 Gaegu Bold/Regular다. 시안과 100% 동일한 전체 게임 화면이라고 보고하지 않는다. 별도 1:1 재조립 검증 자료의 픽셀 차이 0은 현재 Unity 화면의 픽셀 일치를 뜻하지 않는다.

문구는 이미지에 구워 넣지 않았다. PSD는 이미지 자산 편집용이며, 글자·문구·활성 색상·제목의 1.3도 회전은 Unity에서 적용한다. 배치 PSD는 종이 레이어를 편하게 수정하도록 회전하지 않은 상태이며 실제 게임 캡처와 구분한다. 종이 표면의 개별 섬유와 도시의 각 건물을 모두 분리한 것은 아니다.

## 원본 크기와 분리 방식

- 현재 계단형 제목 종이: 1469×763. 체크무늬를 제거한 실제 알파 PNG다. 사각 제목 종이 1936×566는 팝업에만 유지한다. 생성 공통 버튼 1886×294는 이력으로 보존하며 현재 메뉴에는 사용하지 않는다. 현재 버튼은 승인 원본의 397×71/74 이미지, 아이콘은 원본 약 27~57px 범위다. 시안 일치 우선의 추출본이며 고해상도 최종 원본이 아니다. 기존 글자 자리는 같은 원본의 빈 종이 질감으로 메웠다.
- 도시 원본: 1672×941. 모자 인물: 210×246, 묶은 머리 인물: 151×178. 기존 배경의 원래 픽셀을 잘라 분리했으며, 작은 인물 파일을 고해상도 신규 원화로 보고하지 않는다. 크게 확대할 때 쓸 최종 인물 원본은 아직 아니다.
- 두 인물 아래 가려진 영역만 imagegen의 제거 결과로 채웠다. 그 외 도시 픽셀과 두 인물 픽셀은 기존 원본을 보존한다. 3개 레이어 재합성은 기존 배경과 픽셀 단위로 동일하다.
- 원래 배치 보존을 위해 인물 가장자리에 소량의 원래 주변 픽셀이 남는다. 다른 배경이나 먼 위치로 옮기는 범용 캐릭터 자산은 아니며, 그 용도로 사용할 때는 가장자리를 추가 정리해야 한다.
- 3840×2160 PSD는 **배치 편집용 큰 캔버스**다. 기존 배경 확대가 디테일 복원을 의미하지 않는다. 원래 크기의 PNG와 PSD를 별도로 보관한다.
- 생성 종이는 RGB로 반환되어 원본의 크로마 배경을 로컬 처리로 제거했다. 투명도를 생성 도구가 직접 제공했다고 보고하지 않는다.

## 글씨와 라이선스

시안 글씨는 생성 이미지 안의 그림이며 식별 가능한 폰트 파일이 아니다. 처음 시도한 Nanum Pen Script는 사용자 피드백으로 교체했다. 이번 실제 UI는 **Gaegu / 개구체 Bold와 Regular** 원본 TTF를 사용한다. 시안의 글씨를 그대로 복제하거나 전용 한글 폰트를 새로 제작한 것은 아니다.

- 파일: `Assets/Art/FrontEnd/Fonts/Gaegu/Gaegu-Bold.ttf`, `Gaegu-Regular.ttf`
- 라이선스: 같은 폴더의 `OFL.txt`, SIL Open Font License 1.1.
- 상업 소프트웨어에 포함할 수 있으며 배포할 때 저작권 고지와 라이선스를 함께 제공한다. 폰트 자체 단독 판매는 금지된다. 폰트 파일은 수정하지 않았다.
- 출처: [Google Fonts 원본](https://github.com/google/fonts/tree/main/ofl/gaegu), [라이선스 원문](https://raw.githubusercontent.com/google/fonts/main/ofl/gaegu/OFL.txt).

## 재현과 검수

`tools/package_title_resources.py`가 개별 PNG, PSD와 배치 정보를 만든다. `tools/psd_layers.py`는 PSD를 쓴 뒤 다시 열어 합성, 모든 레이어의 픽셀·알파·이름·좌표·표시 상태를 검사한다. Photoshop 앱에서 직접 열어 확인한 것은 아니다.

`tools/extract_approved_title.py`는 승인 원본 1:1 재조립 자료를 만든다. `tools/prepare_stepped_title.py`는 사용자가 지목한 계단형 종이를 분리한다. `tools/approved_title_controls.py`는 원본 아이콘·종이와 현재 배치 PSD를 만든다. 재현 순서는 package_title_resources → extract_approved_title → prepare_stepped_title → approved_title_controls이다.

`AgentScripts/ReplaceTitleResources.cs`는 기존 5개 UI 프리팹의 바깥 RectTransform을 기록하고 동일함을 검사한다. 버튼 내부 Label·Icon·화살표 이미지의 정렬은 사용자의 추가 지시에 따라 변경하며 검사 예외를 명시했다. 프리팹을 새 디자인으로 재생성하지 않는다. 원본 생성 프롬프트는 [제작 기록](제작-프롬프트.md)에 보관했다.

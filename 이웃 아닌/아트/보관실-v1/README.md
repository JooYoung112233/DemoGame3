# 보관실 배경·편집 파일

imagegen 스킬의 기본 내장 도구로 생성. 참조: `Assets/Art/ExpeditionArrival/corridor.png`의 카메라/종이 질감/청록·회색·붉은색 배색. 기존 복도는 수정하지 않았다.

프롬프트: 같은 폐상가의 작은 물자 보관실. 정면에서 약간 높은 시점, 회색과 붉은 체크 타일, 거친 종이 질감. 왼쪽 열린 금속 문, 뒤쪽65% 지점 물·통조림 선반,85% 지점 판자와 공구함. 하단45% 이동 공간과 상단20% HUD 여백. 인물·텍스트·아이콘·버튼·UI·강조광 제외. 16:9 최대 네이티브3840×2160 요청.

실제 생성 원본은 **1672×941**이다. 목표3840×2160에는 미달하며, 현재 인게임 배치용 원본으로 보존한다. 확대 배치는 디테일 복원이 아니다.

- `원본/storage.png`, `개별-PNG/storage.png`: 생성 원본 픽셀 보존.
- `PSD/storage-background.psd`: 원본 크기 단일 배경 레이어. 벽·문·선반·소품은 아직 개별 분리되지 않았다.
- `PSD/storage-layout.psd`: 3840×2160 배치 참고 파일. 배경/날짜/장소/턴/경로/돌아가기/3개 상호작용 위치를 각각 분리했다. 원화 디테일 원본은 위 PNG다. 실제 글자·아이콘·상호작용 배치는 Unity 프리팹에서 편집한다.
- `tools/prepare_storage.py`: PSD 작성 후 레이어 이름·위치·RGBA·합성 픽셀을 다시 읽어 검증한다.

기존 복도와 배색·시점·바닥 타일 연속성을 비교했으며 실제 인게임 캡처는 `Assets/Screenshots/SearchStatus/storage-room.png`다. 이번 배경은 새 방의 첫 구현용으로, 전체 소품 레이어 분리와 원본 해상도 보완은 남아 있다.

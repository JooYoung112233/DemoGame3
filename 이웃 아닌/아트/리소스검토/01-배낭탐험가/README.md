# 배낭 탐험가 — 검토용 v1

2026-09-21. 기능 구현을 중단하고 리소스를 하나씩 사용자 확인 후 확정하는 단계.

- 참고: `demo5/ArtSources/approved-reference.png` 및 `Assets/Art/Tokens/scout-body.png`.
- 생성: 내장 image_gen 도구. 기존 파일과 Unity 연결은 교체하지 않았다.
- 어두운 실루엣, 배낭, 종이 외곽선, 흰 받침대의 한 방향 시안.
- 아직 사용자 승인 전. 몸과 받침대가 합쳐진 단일 이미지이며 분리 레이어/PSD가 아니다.
- 생성 결과의 체크무늬 배경은 투명 배경으로 보장되지 않는다. 납품용 투명 PNG로 취급하지 않는다. 승인 후 몸/받침대 분리와 알파 정리가 필요하다.
- 원본보다 머리 옆모습과 배낭 구획이 구체적이고 받침대 두께가 두꺼워졌다. 이 차이는 검토 대상이며 원본과 정확히 일치한다고 보고하지 않는다.

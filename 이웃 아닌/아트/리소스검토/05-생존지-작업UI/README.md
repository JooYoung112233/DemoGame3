# 생존지 작업 UI 시안

2026-09-21 사용자 요청: This War of Mine을 참고해 내부 활동 UI도 구성.

내장 image_gen으로 기존 승인 배경과 종이 UI 질감을 참조한 합성 검토 이미지다. 1672×941 평면 PNG이며 인게임 프리팹·분리 레이어·실행 코드가 아니다. 기존 Unity 구현은 변경하지 않았다.

- 좌상단 날짜·시간, 우상단 간단한 물자 요약.
- 맵 물체 위 작은 상호작용 표식. 선택한 작업대만 테두리 강조.
- 작업대 클릭 시 왼쪽 작업 패널: 작업 선택 → 담당자 → 예상 시간·재료 → 실행.
- 우하단 대원 두 명의 상태 카드. 상시 하단 3열 패널 대신 장소를 더 넓게 보여주는 제안이다.
- 패널을 닫으면 거점 전경과 상태 카드만 남는 방식으로 제안한다. 닫힌 화면 자체는 이번 파일에 포함하지 않았다.
- 간이 지렛대, 제작 시간, 재료 수치는 배치 예시이며 규칙 확정이 아니다. 재료 표기는 실제 구현에서 ‘보유 / 필요’를 명시해야 한다.
- 생성 합성 속 인물은 승인 캐릭터 원본과 세부 형태가 달라 최종 캐릭터 리소스로 쓰지 않는다. UI 구성을 검토하기 위한 자리 표시다.

원작 참고: https://store.steampowered.com/app/282070/This_War_of_Mine/
사용자 승인: 현재 시안의 작업 UI 구성과 질감이 좋다고 확인했다. 단, 담당자 수가 늘어날 수 있으므로 두 명 고정 구조로 구현하지 않는다. 시안의 두 명은 예시이며 최대 인원이 아니다.

확장 설계안: 왼쪽 담당자 영역은 일정 높이의 스크롤 목록으로, 우하단 대원 상태 카드는 가로 스크롤 목록으로 구성한다. 선택된 담당자의 이름·상태는 목록을 넘겨도 별도로 확인할 수 있게 한다. 구체적인 한 화면 표시 인원과 최대 인원은 미정이다. 이번 기록은 설계 기준이며 UI 코드를 변경한 것은 아니다.

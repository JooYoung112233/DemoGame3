# 캐릭터·크리쳐 공통 규격 적용

2026-09-25. 사용자 요청 “다 수정해줘”에 따라 **대원 6명, NPC 3명, 감염자 1종, 크리쳐 12종 — 총 22종**의 게임 표현과 편집용 납품을 같은 규격으로 맞췄다. 이 문서는 [수정 전 검수](캐릭터-공통규격-검수-2026-09-25.md)의 후속 적용 기록이다.

## 적용한 표현

- 몸체는 공통 검정 잉크 `#111413`, 종이 가장자리는 `#A69E8C`를 사용한다. 월드 테두리는 공통 재질의 화면 픽셀 기준 두께 `2.5`로 관리한다. 개체의 원본 해상도나 몸체 크기에 따라 별도 색·두께를 생성하지 않는다.
- 기존 `FieldPawn`의 받침대 구조를 재사용한다. 상면·목·옆면·그림자는 Unity에서 분리된 요소이며, 아군·적 구분색은 유지한다. 새 몸체 PNG에는 받침대를 그려 넣지 않는다.
- 기존 윤서진·한해인의 PNG는 보존한다. 원본에 그려진 밝은 종이 가장자리는 해당 두 스프라이트에 한해 공통 셰이더에서 제외하고 같은 테두리를 그린다.
- 크리쳐 12종은 **V1 원본의 알파 외곽을 사용해 Unity에서 검정 몸체로 렌더링**한다. V1 PNG에 남아 있는 얼굴·옷·금속 등의 RGB 묘사를 게임에서 그대로 표시하지 않는다. 원본 픽셀을 덮어쓰거나 12종을 새 고해상도 원화로 재제작한 작업은 아니다.
- **V2의 RGB 체크무늬 시안은 사용하지 않는다.** 기존 제작 이력으로 보존하며 공통 화풍 마스터로 취급하지 않는다.
- UI 초상도 공통 검정 잉크 재질을 사용한다. 실제 초상 이미지에만 적용하며 종이 카드, 아이템 아이콘, 글씨의 색과 배치를 변경하지 않는다.

공통 재질: [PaperStandee.mat](../../Assets/Settings/PaperStandee.mat), [PaperPortrait.mat](../../Assets/Settings/PaperPortrait.mat). 몸체와 테두리의 수정은 개별 PNG 재생성보다 공통 재질에서 먼저 검토한다.

새 대원·NPC·감염자는 원본 PNG를 자르지 않고 Unity 스프라이트 영역만 실제 알파 경계와 작은 여백으로 설정했다. 몸체 높이와 발 위치는 투명 캔버스 크기 대신 보이는 몸체 경계로 계산한다. 좌우 반전 중 전신을 바꿀 때도 중심과 발 위치를 유지한다. 기존 두 대원의 승인된 임포트 영역은 유지한다.

## 편집 원본과 해상도

22종마다 다음 파일을 제공한다. **독립 레이어 PNG 66개, 합성 PNG 22개, 실제 3레이어 PSD 22개**이며 동일 ID의 네 PNG와 한 PSD가 대응한다.

| 파일 | 내용 |
|---|---|
| `standee-<id>-ink-layer.png` | Unity가 렌더링한 검정 몸체, 실제 알파 |
| `standee-<id>-paper-layer.png` | 공통 종이 테두리만 분리한 실제 알파 |
| `standee-<id>-base-layer.png` | 공통 받침대 구성과 그림자 묶음, 실제 알파 |
| `standee-<id>-composite.png` | 같은 Unity 배치의 완성 형태 |
| `standee-<id>-native-layers.psd` | **Body Ink / Paper Rim / Shared Base의 실제 독립 레이어 3개**와 완성 미리보기 |

PSD는 한 장짜리 합성 이미지를 넣은 파일이 아니다. 다만 몸체 내부의 머리·팔다리·의복을 각각 분리한 리깅 원본은 아니며, 받침대의 세부 구성요소도 PSD에서는 하나의 `Shared Base` 레이어다. 개별 받침대 요소는 Unity 프리팹에서 편집한다.

## 검증 근거

- [레이어 내보내기 목록](standee-common-layer-exports.json): 22종의 원본 경로, 스프라이트 영역, 내보내기 크기, PNG별 연결 기록.
- [PSD 레이어·채널 검증](standee-common-psd-validation.json): PSD 22개, 레이어 이름과 순서, 각 레이어 RGBA 채널 및 합성 RGBA의 PNG 일치 확인. PackBits 경계 사례 32개 통과. 원본 픽셀을 포장 과정에서 수정하지 않음.
- [독립 PSD 판독 검증](standee-common-psd-independent-validation.json): 별도 PSD 판독기로 22개 합성 RGBA를 PNG와 바이트 단위로 비교하여 일치. 해당 검증은 이미지 파일을 쓰지 않은 읽기 검사.
- [신규 대원 4명 제작·알파 기록](party-body-silhouettes-2026-09-25.json), [NPC·감염자 생성 프롬프트와 원본 경로](standee-common-generation.json).
- 최종 `ApplyPaperPortraits.Verify`: 초상 61개 통과, 아이템·아이콘·종이 이미지에 잘못 적용된 공통 초상 재질 없음.
- `VerifyPartyStandeeBodies`: 서로 다른 대원 전신 6개, 이전 데이터·알 수 없는 ID의 대체 처리, 알파 기준 높이·접지·좌우 반전 시 중심, 반복 갱신 위치 유지, 정착지 전신 전파와 전투 경계 정보 일치 통과.
- 최종 `VerifySharedPaperStandeeStyle.Run`: 두 셰이더 지원·컴파일 오류 없음, 동적 스프라이트 교체, 투명도·반전·정렬·변환 보존, 기존 종이 가장자리 허용 목록, 비활성화 시 재질 복구, UI 클리핑 속성, 공통 몸체 렌더러 7개와 받침대 연결 통과.

이 검증은 자산·렌더링·연결 범위의 결과다. 전체 게임 플레이 검수, 모든 전투 연출의 사용자 승인, 전체 저장소의 `git diff --check` 통과를 뜻하지 않는다.

## 남은 콘텐츠 연결

숨은 NPC는 이번에 리소스와 프리팹까지 준비했다. 탐험지에 단서만 보이는 단계, 관찰 후 인물 등장, 이름 공개, 대화 선택, 재방문 결과, 퀘스트·저장 연결은 [숨은 NPC 발견 시나리오](../../기획/탐험지-숨은NPC-발견시나리오-2026-09-24.md)에 따른 후속 작업이다. 이번 자산 교체로 전투 수치나 출현 규칙을 바꾸지 않았다.

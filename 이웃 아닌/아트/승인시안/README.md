# demo5 그래픽의 유일한 승인 기준

2026-09-21 최신 사용자 지시: **우리 시안 이미지 그대로 해줘.**

`폐상가-보드게임-원본.png`는 최초 승인된 이미지의 바이트 단위 동일 복사본이다. 새로 생성하거나 확대·보정하지 않았다. 원본 해상도는 1672×941이다. 이 그림은 UI·캐릭터·배경이 합쳐진 시안이며 분리된 인게임 리소스나 레이어 PSD가 아니다.

- 정면에서 조금 높게 내려다보는 폐상가 구도와 원근을 유지한다. 마름모 등각투영 보드로 바꾸지 않는다.
- 캐릭터는 얼굴 디테일이 거의 없는 어두운 실루엣 종이 말, 종이 테두리와 색 받침대다. 사실적인 얼굴·의복·신체 묘사를 추가하지 않는다.
- 배경의 단순화 정도, 어두운 청록·회색, 거친 종이 질감과 하단 종이 카드 UI를 그대로 기준으로 한다.
- 이후 필요한 분리 작업은 이 원본의 픽셀과 형태 보존을 우선한다. 새 해석으로 전체 장면을 재생성하지 않는다. 원본에서 뽑은 작은 요소를 고해상도 완성 원화로 보고하지 않는다.
- 뒤에 생성한 정비소 다이아몬드 바닥 배경과 얼굴이 묘사된 여성 캐릭터 말은 미채택이다.
- 현재 코드의 DiamondImage 기반 쿼터뷰는 잘못 해석한 중간 구현이다. 승인된 화면으로 간주하거나 최종 그래픽이라고 보고하지 않는다.
- 모험가 2명 선택 → 정착지 선택 → 원정·귀환이라는 게임 흐름과 최소 모션은 유지한다. 원본 시안의 세 캐릭터를 최종 인원 규칙으로 가져오지 않는다.
- 사용자 요청으로 실행 파일 빌드는 중단한다. 이후 검증은 Unity Editor에서 한다.

## UI 배치 재검토 — 2026-09-21

사용자가 캐릭터뿐 아니라 UI 배치도 원본과 다르다고 지적했다. 현재 구현은 미승인 상태이며, 단순 사각 패널을 최종 시안 재현으로 보고하지 않는다.

- 원본의 하단 띠 시작은 941px 중 약 640px(1920×1080 기준 약 734px)이다.
- 하단은 원정대 / 생존 정보 / 조우의 세 영역을 유지한다.
- 조우는 2×2 큰 카드(방어·유인·사격·철수)로 복원한다. 이동·탐색·근접과 턴 종료는 하단 띠 위에 별도 보조 조작으로 둔 임시 구현이다. 이 추가 배치는 아직 사용자 승인 전이다.
- 생존 영역은 빛·소음 게이지와 오른쪽 소지품 칸으로 복원한다.
- 원본의 종이 질감, 불규칙한 테두리, 아이콘, 인물 카드의 초상·체력 바는 아직 추가 보완이 필요하다. 현재 저해상도 캐릭터 추출본 역시 최종 원본이 아니다.

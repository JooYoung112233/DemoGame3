# 시작 화면 원본

> **미승인 임시 자산**. 승인 시안과 다르다는 사용자 피드백이 있으며, 개별 요소와 실제 레이어 PSD 납품도 미완료다. 다음 화면 제작 기준으로 사용하지 않는다. [제작 규칙](../../AGENTS.md)에 따라 보완한다.

2026-09-22. 내장 imagegen으로 제작. 기준: UI전체시안-v1의 20번 시작·선택 흐름 시안 중 첫 장면.

| 파일 | 실제 크기 | 용도 |
| --- | --- | --- |
| 시작배경-원본.png | 1672×941 | 도시를 바라보는 두 모험가, UI 없는 배경 |

고해상도 목표에 미달하는 원본을 확대 복원으로 보고하지 않는다. 배경은 인물과 환경이 합쳐진 단일 PNG다. UI 요소는 Unity에서 별도 프리팹으로 구성했다. PSD는 아직 없다.

Unity 사용 사본: `Assets/Art/FrontEnd/title-rooftop-v1.png`, `paper-ivory-v1.png`. 원본 PNG를 재인코딩/축소하지 않고 복사했다. 버튼 문구는 그림에 포함하지 않았다.

# 정착지 선택 원본

기준: `../UI전체시안-v1/20-시작과정착지선택.png`의 마지막 행. 승인된 그림을 추출하여 사용하며 새 화풍으로 재생성하지 않았다. 폐정비소 추출 범위에서는 원본 체크 표시 가장자리를 제외했다.

- `개별-PNG/garage.png`, `house.png`, `clinic.png`: 원본 크기로 보관한 장소 그림.
- `PSD/*-native.psd`: 장소별 단일 그림 레이어. 건물·소품 내부는 분리되지 않았다.
- `PSD/*-card.psd`: 종이·장소 그림·자원 아이콘 3종이 분리된 카드별 PSD.
- `개별-PNG/icon-*.png`, `PSD/home-icons.psd`: 상자·사격 표식·하트·위치 핀의 투명 PNG 및 4개 독립 레이어 PSD. 상자는 UI 시안 01, 사격 표식은 10, 핀은 20에서 분리했다. 하트는 기존 모험가 선택 자산을 재사용한다. 추출 원본은 약 31~77px로 확대용 최종 원본은 아니다.
- `PSD/home-selection-art-layout.psd`: 3840×2160 배치용 PSD, 종이·각 장소·예시 동료 등 독립 레이어. 글씨와 수치는 Unity 프리팹에서 편집한다.
- `manifest.json`: 원본 파일과 추출 영역, 해상도 기록.
- 기존 종이·인물 원본은 `../모험가선택-v1/개별-PNG`를 재사용한다.

장소 추출본은 약 224~250×102~106px다. PSD의 큰 캔버스나 배치 확대는 새 디테일을 복원한 고해상도 원본이 아니다. 현재는 배치 검수용이고 확대용 원본 보완은 남아 있다. 원본 PNG를 별도로 유지한다.

`tools/prepare_home_selection.py`로 패키지를 재현한다. PSD를 저장한 뒤 독립 리더로 레이어 이름·위치·픽셀·알파 및 합성 이미지를 검증했다.

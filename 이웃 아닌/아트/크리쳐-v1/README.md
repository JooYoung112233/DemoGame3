## 납품

- 내장 image_gen으로 각 종을 독립 생성. 개별 RGBA PNG 12개. 작은 시트를 잘라 만든 자산이 아님.
- `원본/`: 생성 원본 바이트 그대로 보관, 각 1086×1448. 실제 높이 1536~2048 목표 미달이며 보간 확대하지 않음.
- `../../Assets/Art/Creatures/V1/`: Unity 프로젝트용 동일 PNG 사본. 배치·스폰·전투·애니메이션은 연결하지 않음.
- `PSD/`: 4종씩 묶은 PSD 3개. 종마다 원본 해상도의 독립 RGBA 레이어. 처음 종만 표시되어 있으며 나머지는 레이어 표시를 전환해 편집.
- PSD의 분리 단위는 **크리쳐 한 몸 전체**다. 머리·팔다리·융합된 소품의 내부 분리와 리깅은 아직 없음. 그 부분을 최종 애니메이션 원본으로 보고하지 않는다.
- `index.html`: 원본을 직접 표시하는 전체 비교 자료. 게임 화면이나 실제 개체 크기 비율이 아님.
- `generation-manifest.json`: 전체 프롬프트, 가칭, 내부 ID, 생성 원본 경로.
- `validation.json`: 치수, 알파, 원본 SHA-256, 주요 불투명 영역 경계 확인.

## 미술 검수와 후속 범위

- demo5 승인 기준인 어두운 종이 말, 얼굴 묘사 절제, 청록·회색 계열을 방향으로 생성했다. 기존 작은 말보다 내부 질감과 소품 묘사가 많으므로 완전한 화풍 일치나 사용자 채택을 주장하지 않는다.
- 전체 몸체와 팔다리 끝을 육안 검토. RGBA의 실제 투명 영역 확인. 일부 낮은 알파 가장자리 픽셀은 캔버스 끝에 닿지만 주요 불투명 영역은 경계 내부에 있는지 별도 기록.
- PSD는 기존 프로젝트 직렬화 도구로 저장 후 다시 읽어 합성 RGBA, 레이어 이름, 가시성, 좌표, 각 레이어 채널을 원본과 대조했다.
- 인게임 배경 위 실제 표시 크기, 가장자리 색 번짐, 받침대·접지, 기존 생존자와의 묘사 밀도 비교는 미실시. 다음 Unity 배치 단계에서 확인한다.
- 이번은 종별 정지 포즈 외형 1차 제작이다. 받침대, 접지 그림자, 이동/피격/공격 포즈, 팔다리별 분리, 등장 조건, 수치, 공격 방식은 미제작·미확정.
- 도구: built-in image_gen. 원본 복사와 PSD 컨테이너 포장만 수행했고 생성 이미지의 재색칠·리사이즈·배경 제거는 하지 않았다.

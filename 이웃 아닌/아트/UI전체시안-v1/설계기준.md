# UI 전체 설계 기준

## 승인과 제안의 범위

사용자 확정: 종이 질감, 오브젝트 클릭 후 작업·담당자 선택, 여러 대원 지원, 개별 인벤토리, 출발 전 휴대품 선택. 전투는 For The King II를 참고한 양 진영 분리 진형.
이번 UI는 위 방향에 필요한 화면을 먼저 제안한다. 숫자, 슬롯 수, 시설 기능, 야간 역할, 거래·세이브 세부 규칙까지 확정한 것은 아니다. 게임 코드나 Unity 씬은 이번 작업으로 변경하지 않는다.

## 소지품 소유와 이동

1. 거점 공용 창고, 대원 개인 가방, 현장 보관함, 방문자 물품을 다른 소유 공간으로 표시한다.
2. 선택한 대원의 이름·가방 여유를 항상 표시한다. 대원 전환 후 기존 대상 선택은 재확인한다.
3. 거점에서 공용 창고와 가방 사이 이동. 현장에서는 동행 대원의 가방과 현장 물품만 이용한다. 원격 거점 창고 접근은 없다.
4. 아이템을 다른 칸·가방으로 옮길 때 출발지에서 차감하고 도착지에 추가한다. 장비 슬롯은 같은 물건의 장착 상태로 취급하며 복제하지 않는다. 장착품의 가방 칸 점유 여부는 추후 결정한다.
5. 가방 칸 수, 묶음 수, 무게 규칙은 데이터로 둔다. 화면의 6·12·16칸과 표시 수량은 디자인 샘플이다. 실제 게임에서는 동일 대원의 용량을 모든 화면에서 같은 데이터로 표시한다. 무게와 칸 제한을 동시에 확정하지 않는다.
6. 이동·사용·버리기를 명확히 구분한다. 수량 선택과 수용 가능량을 표시하며 부족할 때 자동 폐기하지 않는다. 버리기와 남겨두기에는 대상·수량과 결과를 확인시킨다.
7. 귀환 시 개인 가방에서 창고로 입고한 물품은 원래 가방에서 제거한다. 장비 유지와 소모품 입고를 따로 선택한다. 같은 귀환 결과를 다시 열어도 보상을 중복 지급하지 않는다.

## 탐험 준비

목적지 → 원정 대원 → 각자의 짐 → 최종 출발 확인.
목적지는 예상 편도 시간, 알려진 자원·위험, 미확인 정보를 구분한다. 남아 있는 물자의 정확한 수량을 정찰 없이 보장하지 않는다.
대원은 현재 상태·작업과 참여 불가 사유를 표시한다. 특정 대원의 가방이 비었다고 자동으로 출발을 막지 않으며, 꼭 필요한 도구 조건과 권장 준비물을 구분한다. 물·치료품·도구 부족 경고는 한 번에 모아 보여준다.

## 다인원 확장

초기 모험가 2명과 거점 최대 인원은 별개다. 리스트는 데이터 기반으로 스크롤/필터를 지원한다. 시안의 6명은 많은 인원일 때의 예시이며 상한이 아니다. 선택 대상의 요약은 목록을 넘겨도 유지한다.
대원 작업·휴식·원정 상태, 이용 가능한 장비, 배정 가능 여부를 텍스트와 아이콘으로 함께 표시한다. 색만으로 구분하지 않는다. 대원 카드의 초상들은 예시이며 승인된 신규 캐릭터 원화가 아니다.

## 오브젝트 작업과 시간

맵 물체 선택 → 가능한 작업 → 담당자/지원 역할 → 소요 시간·필요품·결과 확인 → 실행.
메뉴 열기, 탭 변경, 목록 스크롤, 인벤토리 조회만으로 시간이 진행되지 않는다. 배치 시안의 ‘시간 진행’은 명시적 사용자 실행 버튼 제안이다. 동시 작업과 중단 시 소비·반환량은 게임 규칙 확정 후 UI에 반영한다.
작업 UI는 같은 컴포넌트를 활용해 침대·요리·치료·정수·제작·수리·시설 개선에 대응한다. 모든 시설을 첫 버전에 구현하는 의미는 아니다.

## 필수 상태

각 패널에 기본/선택/비활성 사유/진행 중/완료/빈 목록/부족 상태를 둔다. 파괴적 선택은 대상과 결과를 명시하고 취소 가능한 경로를 제공한다. 일괄 이동은 수용 가능한 만큼만 처리하고 남은 수량을 보여준다.
전투 중 가방은 현재 행동 대원의 소지품을 기본으로 하며 장거리 교환, 사용 비용, 치료 대상은 확정 규칙에 따른다. 시안은 확인/취소, 대상 강조, 명중/피해 예상만 정의한다.

## 공통 편집 구조

기본 화면 기준 1920×1080, 편집용 목표 3840×2160. 생성 원본이 목표보다 작으면 그대로 보관하고 한계를 명시한다.
향후 Unity 프리팹 분리 단위: PaperPanel, PaperButton, SurvivorCard, SurvivorPicker, ItemSlot, InventoryGrid, ItemTooltip, QuantityDialog, ObjectMarker, TaskPanel, ResourceCostRow, ProgressRow, DestinationCard, EncounterChoice, TurnStrip, TargetPreview, ResultLedger, ConfirmDialog, Toast, JournalPanel, PausePanel.
문구·슬롯 수·아이템 데이터·시간과 수량은 코드/데이터로 지정한다. 생성 시안의 글씨를 잘라 게임에 직접 사용하지 않는다. 이번 평면 PNG는 UI 배치 검토본이며 PSD/프리팹 납품본이 아니다.

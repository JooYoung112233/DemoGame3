# 정착지 시설 표식 수정안

2026-09-24. 사용자가 시설 위 말풍선이 어색하다고 지적하고 수정안을 보여달라고 요청했다. 실제 Unity 개발 변경이 아니라 비교용 이미지 제작이다.

- 기준: `Assets/Screenshots/development-world.png`의 기존 정착지 화면.
- 이미지: `시설표찰-제작대호버.png` — 내장 image_gen 편집 시안.
- 평소: 큰 원형 말풍선을 없애고 침대 프레임·상자·책상 앞면·계단 옆 벽에 작은 표찰을 부착.
- 제작대 호버 예시: 시설 외곽의 은은한 강조와 `제작대 / 제작 · 수리` 이름표 한 개.
- 클릭 영역은 표찰 크기로 줄이지 않고 시설 전체를 사용하는 방향. 이는 아직 미구현.
- 구현 검토 시 작은 표찰 판독성과 시설 발견 가능성을 확인하고, 필요하면 시설 표식 일괄 표시 기능을 검토한다.
- 생성 과정에서 원본 일부 픽셀과 가구 세부가 달라질 수 있다. 배경 재제작 승인이나 픽셀 단위 구현 결과가 아니다.
- 단일 평면 비교 시안이며 개별 UI 리소스·레이어 PSD 납품이 아니다. 게임 코드·씬·프리팹과 다른 에이전트의 전투 작업은 수정하지 않았다.
- 사용자 승인 전. 실제 UI는 Unity에서 별도 구현한다.

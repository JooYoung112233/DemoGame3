# 오브젝트 중심 행동 지정 UI

2026-09-21 사용자 확정 방향. 기능 구현은 재개하지 않고 기획과 리소스 기준만 기록한다.

## 확정

- 최신 생존지·UI·추가 캐릭터 시안의 종이 질감과 화풍을 기준으로 삼는다.
- UI 시안의 실제 배치·문구·버튼 수는 확정이 아니다.
- 생존지와 탐색 화면에서는 맵에 배치된 오브젝트를 먼저 클릭한다.
- 선택한 오브젝트에 대해 누가 무엇을 할지 지정하는 UI를 사용한다.
- 탐험과 별도로 전환되는 전투는 앞서 정한 분리 진형 방향을 유지한다.
- 후속 작업대 선택 시안(`아트/리소스검토/05-생존지-작업UI`)은 사용자 승인. 담당자가 늘어날 수 있으므로 담당자 선택과 대원 상태 표시를 2명 고정으로 설계하지 않는다. 초기 모험가 2명 선택과 최대 거점 인원은 별개다.

## 인원 증가 대응 제안

패널을 인원수에 따라 계속 키우지 않는다. 담당자는 고정 높이 스크롤 목록, 우하단 상태 카드는 가로 스크롤 방식으로 확장한다. 선택된 담당자는 별도 요약으로 유지한다. 작업 중·휴식 중 등 현재 상태와 배정 가능 여부를 함께 표시하는 안을 검토한다. 최종 최대 인원, 동시 배정 인원, 전투 참여 인원은 이번 승인으로 확정하지 않는다.

## 화면 흐름 제안 — 세부 확정 전

오브젝트 선택 → 해당 물체의 가능한 작업 표시 → 담당자 및 필요한 지원 역할 지정 → 예상 시간·소모품·주요 위험 확인 → 실행.

예를 들어 생존지 침대를 클릭하면 휴식할 대원, 작업대를 클릭하면 작업과 담당자를 지정한다. 탐색 장소의 상자를 클릭하면 수색 담당자, 빠름·보통·정밀 방식, 동료 지원 역할을 고른다. 이 예시는 방향 설명이며 작업 종류나 규칙 전체가 확정된 것은 아니다.

- 오브젝트를 고르거나 담당자를 바꾸는 것만으로 시간이 지나지 않도록 한다. 실행 시 시간을 진행하는 안을 유지한다.
- 오브젝트별 UI는 같은 종이 패널을 재사용하되 가능한 작업과 역할만 달리 보여주는 안을 우선 검토한다.
- 패널 위치(오브젝트 옆 / 하단 등), 동시 작업 여부, 자동 반복, 취소·중단 규칙은 추후 사용자 방향을 듣고 결정한다.
- 현재 화면에 있는 상시 수색 방식·역할 버튼은 임시 구현이다. 최종 배치 기준으로 간주하지 않는다.

## 리소스 제작에 반영

앞으로 배경과 클릭 가능한 물체의 형태·위치 대응을 유지한다. 작업 패널, 종이 카드, 선택 강조를 분리 제작하고 문구·게이지·아이콘을 배경에 굽지 않는다. 현재 합쳐진 배경 시안은 아직 개별 오브젝트 레이어로 분리된 상태가 아니다.

# 정착지 선택 — 2026-09-22

최신 연결: `이곳에서 시작`은 이제 새 `Settlement` 첫 진입 화면으로 간다. [거점 첫 화면 기록](정착지첫화면-구현.md). 좌우 하단 버튼은 둘 다 410×78이며 이전/시작의 y=944 정렬을 유지한다. 아래 NightExpedition 직접 연결은 이전 구현 기록이다.

승인 UI 시안 20번의 마지막 행을 기준으로 정착지 선택 화면을 추가했다. 최신 승인된 모험가 화면처럼 번호 배지 없이 상단에 선택 영역을 두고 Gaegu Bold를 사용한다. 그림은 원본의 폐정비소·작은 주택·옛 진료소다.

## 최신 수정: 아이콘과 하단 시작 버튼

사용자 요청으로 카드의 자원 글자 제목을 **아이콘 + 숫자**로 교체했다. 보급품은 승인 시안 01의 상자, 탄약은 시안 10의 사격 표식, 회복은 기존 하트다. 아래 시작 조건에는 같은 아이콘과 설명을 함께 표시하여 의미를 구분한다. 동료 제목·이전 버튼에도 기존 아이콘을 사용했다.

`이곳에서 시작`은 **x=1450, y=944, 410×78**로 이동했다. 왼쪽 이전 버튼과 같은 높이이며 시안 20의 위치 핀을 분리해 넣었다. 선택 영역과 그림은 그대로다. 정착지 미선택 상태에서는 시작 조건 아이콘을 숨기고 기존 안내를 표시한다.

새 공통 프리팹은 `ResourceIconValue.prefab`이며 기존 카드·상세·시작/이전 버튼 프리팹에 반영했다. `PolishHomeIcons.Apply`는 이번 보정 재현용이다. 최신 실제 캡처는 `Assets/Screenshots/HomeSelection/home-v2-icons.png`. 아이콘 원본 PNG와 분리 PSD, 전체 배치 PSD도 갱신했다. 세 장소의 클릭·선택 전환·하단 시작 버튼 Raycast·자원 적용·이전 화면 복귀를 다시 통과했다.

## 흐름

시작 → 모험가 2명 선택 → **HomeSelection** → 장소 선택 → 이곳에서 시작 → 기존 NightExpedition의 정착지 생활 화면.

- 첫 진입은 장소 미선택이며 시작 버튼은 비활성이다.
- 카드를 누르면 노란 테두리·체크와 하단 설명이 바뀐다. 동시에 한 장소만 선택한다.
- 선택된 두 동료의 실루엣·이름을 하단에서 확인한다.
- 모험가 다시 선택: 두 명의 선택을 유지한 채 이전 화면으로 돌아간다.
- 장소 선택 후 시작: 선택한 두 명과 시작 자원을 유지하며 기존 정착지 화면으로 이동한다.
- HomeSelection 씬을 직접 Play하면 동료가 없는 검수 상태다. 장소 정보만 볼 수 있고 시작은 막는다. 전체 흐름은 StartMenu 또는 PartySelection에서 시작한다.

## 실제 적용값

| 장소 | 보급품 | 탄약 | 휴식 회복 |
| --- | --- | --- | --- |
| 폐정비소 | 2 | 6 | +2 |
| 작은 주택 | 4 | 3 | +2 |
| 옛 진료소 | 2 | 3 | +3 |

기존 CampaignState 규칙을 그대로 사용했다. 시안의 목재·부품·물 자원 규칙은 아직 없으므로 실제 적용되는 보급품·탄약·회복 항목에 맞는 아이콘과 수치를 사용한다. 휴식 회복은 기존 시스템의 생존 대원 대상이며 체력 최대치를 넘지 않는다. 현재 역할별 특성/조합 시너지 구현은 별도다.

## 검증 및 남은 범위

Unity 6.6 재컴파일 통과. `VerifyHomeSelection.Flow`에서 실제 버튼 Raycast 클릭으로 3곳 선택 전환, 한 곳만 체크, 동료 이름 표시, 시작 전 선택 제한, 세 장소 각각의 실제 보급품·탄약·회복값과 두 명 보존, 뒤로 가기를 확인했다. 카드/패널 텍스트 높이도 검증했다. 실행 파일 빌드는 하지 않았다.

실제 캡처는 `Assets/Screenshots/HomeSelection/home-v1.png`. 원본의 왼쪽 안내·가로 3카드·오른쪽 시작 버튼 구성을 유지하고, 최근 승인된 화면과 연결되도록 하단 동료/조건 패널을 추가했다. 시각 승인은 사용자 검토 대기다.

**정착 후 생활 화면은 기존 프로토타입이다.** 장소별 실제 생존지 배경·배치·시설 기능은 이번에 새로 제작하지 않았다. 장소 그림도 작은 승인 시안 추출본이므로 확대용 고해상도 원본 보완이 남아 있다.

# 생활 특성 1차 — 2026-09-23

## 구현 범위

기존 대원 설정에 맞춰 요리사와 정비공의 생활 작업 시간 차이를 연결했다. 누구나 기본 작업은 가능하며 아래 20%는 Inspector에서 변경할 수 있는 임시 밸런스 값이다.

| 담당자 | 적용 작업 | 현재 효과 |
| --- | --- | --- |
| 요리사 | 따뜻한 한 끼, 넉넉한 스튜 | 조리 시간 −20% |
| 정비공 | 제작대의 제작·정수·붕대·수리·시설 개선·공간 공사 | 작업 시간 −20% |
| 나머지 대원 | 기존 작업 | 기본 시간 |

도시락 포장과 통조림 개봉에는 요리사 특성이 적용되지 않는다. 기존 조리대 시설 효과는 유지한다. 추가 인분·재료 할인·의무관 치료 특성·연구/경계 특성은 이번 범위에 포함하지 않는다.

## 계산과 화면

- 기본 시간 × 수량 × 시설 시간 비율 × 담당자 시간 비율, 마지막에 정수 분으로 한 번만 올림한다. 0분 조리법은 그대로 0분이다.
- 20분 식사: 일반 담당20 / 요리사16 / 조리대 Lv.2 + 요리사13분.
- 15분 간이 못 3개: 기본45 / 작업대 Lv.2 + 정비공29분.
- 담당자 행은 적용 가능한 경우 `시간 −20%`, 작업 중이면 `배정됨`을 표시한다. 선택 시 시계 아이콘 옆에 기본→최종 시간, 옆 열에 시설/담당 효과를 각각 보여준다.
- 재료와 완성 수량은 동일하다. 예약할 때 최종 시간을 확정하고, 진행·취소·완료는 기존 작업 시스템을 사용한다.
- 저장 버전7의 기존 남은 시간 필드를 그대로 사용한다. 소급 재계산하지 않으므로 특성 도입 전 작업도 원래 남은 시간을 보존한다. 대원 특성은 안정적인 대원 ID로 카탈로그에서 찾으며 표시 이름에 의존하지 않는다.

## 편집 위치

- `Assets/Data/PartyRoster.asset`: 각 대원의 `CookingTimePercent`, `CraftTimePercent`. 100은 기본, 80은 20% 단축.
- `CookingPanel.prefab` 조리법의 `WorkerSpeedAllowed`: 담당자 조리 시간 효과 적용 여부.
- `SettlementLifeTraits.cs`: 안정적인 대원 조회, 곱연산/올림, 시간 비교와 효과 문구.
- `ConnectLifeTraits.Run`: 현재 두 특성과 기존 UI 하단 시계/효과 열 구성. 새 원화 없이 기존 분리 스프라이트 사용.

## 검증

- 시설+담당 중첩의 단일 올림, 제작/수리 효과.
- 중복 배정 금지, 취소 시 재료 보존, 동시 조리/제작 예약.

## 실제 화면 검수

`Assets/Screenshots/LifeTraits/cook.png`, `mechanic.png`는 실제 Unity 1920×1080 캡처다. 기존 조리/제작 화면과 비교해 외곽 패널·하단 버튼·목록 위치를 유지하고 하단 여백에 시간 비교와 시설/담당 효과를 추가했다. 담당자 행의 2줄 효과, 텍스트 높이, 아이콘 정렬과 클릭을 확인했다. 종이/초상/아이콘은 기존 자산을 재사용한다.

다음 기능 단위는 반복 탐험 콘텐츠 확장이다. 나머지 대원의 생활 효과, 실제 옆방 이동, 다양한 방문 사건과 장기 자원 균형은 남아 있다.

## 정렬·크기·스크롤 대비 보완 — 사용자 요청
조리/제작 화면의 담당자 특성은 26px 한 줄로 표시하고 시간 비교28px·효과26px로 정리했다. 담당자 목록 높이를200px로 줄여 하단 시간 영역과 분리했다. 목록 콘텐츠와 오른쪽 스크롤 레일을 독립 영역으로 구성하고 진한 배경·금색 손잡이·금색 위/아래 버튼을 적용했다. 버튼으로 약 한 화면씩 이동하며 양 끝에서는 해당 방향 버튼만 비활성화한다. 내용이 전부 보이면 레일과 화살표를 숨긴다.
검증: VerifyWorkScrolling.Cooking/Craft에서 5인 목록의 실제 레이캐스트 클릭, 위/아래 이동, 양 끝 상태, 짧은 목록 표시 숨김, 제작법/담당자 독립 스크롤, 대원 선택, 텍스트 높이 통과. 최신 실제 화면은 Assets/Screenshots/LifeTraits/cook-aligned-scroll.png 및 craft-aligned-scroll.png. 편집 스크립트는 PolishWorkScrolling.Run이며 기존 화면 생성/정렬 스크립트 이후 마지막으로 적용한다. 기존 저대비 ScrollMoreHint는 이 두 화면의 Workspace 목록에서 교체했으며 다른 화면과 취소창은 기존 표시를 유지한다.

## 스크롤 잘림 추가 수정 — 최신
사용자 첨부 화면의 얇은 화살표 테두리를 제거하고 목록과 레일·오른쪽 이미지 사이 간격을 확보했다. 제작법 행324×72/간격10/표시 높이236, 담당자 행408×61/간격8/표시 높이199로 각각 세 행이 온전히 보인다. 담당자 초상·선택 표시도 행 중심에 맞췄다. 위/아래 버튼은 행 단위로 이동하고 휠/드래그 정지 후에는 행 경계에 정렬한다. 위의200px 및 이전 캡처 표기는 이 수정으로 대체한다.

VerifyWorkScrolling.Cooking/Craft 통과. 최신 실제 캡처는 Assets/Screenshots/LifeTraits/craft-scroll-fixed.png이며 목록 중간에서도 세 행이 완전히 표시됨을 확인했다. PolishWorkScrolling.Run을 기존 생성·정렬 스크립트 뒤 마지막으로 적용한다.

# 생활 물자 — 정수·붕대 제작·치료

2026-09-23. 식량 준비 다음 비전투 제작 단위. 기존 작업대·창고·현장 가방·휴식 화면을 활용했다. 방문자·거래·시설 성장까지 완료한 것은 아니다.

## 플레이 흐름

- 작업대의 **제작** 목록을 내려 **물 정수**, **붕대 제작**을 선택한다. 재료·담당자·횟수·시간을 확인하고 예약한다.
- 제작·조리·휴식과 같은 담당자 잠금 및 공용 재료 예약 규칙을 쓴다. 시간 진행으로 완료한 결과는 창고에 들어간다. 중도 취소는 예약만 해제하고 이미 흐른 시간은 유지한다.
- 정수한 물은 기존 `water` 재고에 합쳐져 조리와 붕대 제작에 모두 쓰인다. 별도 물 게이지를 추가하지 않았다.
- 붕대는 창고 또는 개인 가방에서 선택한 뒤 **치료**로 사용한다. 탐험에서는 현장 가방의 **치료 · 1턴** 버튼을 사용한다.
- 현장 치료는 선택한 가방 주인에게 적용된다. 다른 대원을 치료하려면 먼저 붕대를 그 대원에게 건넨 뒤 해당 가방에서 사용한다. 가방 간 건네기는 기존대로 시간 0이다.
- 수색한 미정수 물은 발견물 목록에서 가방에 담고, 귀환 후 창고로 옮겨 정수 재료로 쓴다. 완료한 수색은 저장 복원·재방문으로 재추첨되지 않는다.

## 임시 데이터

최종 밸런스가 아니다. 재료비·시간·회복량은 프리팹 Inspector에서 조정할 수 있다.

| 작업/물자 | 재료·비용 | 시간 | 결과 |
|---|---|---|---|
| 물 정수 | 미정수 물 1, 나무 판자 1 | 기본 20분 | 물 1 |
| 붕대 제작 | 천 조각 1, 물 1 | 기본 15분 | 붕대 1 |
| 붕대 치료 | 선택한 보관 위치의 붕대 1 | 정착지 10분 / 현장 1턴 | 체력 +2, 최대치 제한 |
| 미정수 물 초기 재고 | 새 게임에 2 | — | 기존 저장에는 추가 지급하지 않음 |
| 오락실 상자 수색 후보 | 미정수 물 3, 기본 확률 85% | 기존 수색 방식 | 방식·동료 보정 적용 |

작업대 개선이 완료되어 있으면 기존 제작 시간 감소가 정수·붕대 제작에도 적용된다. 별도 정수 시설 레벨은 아직 없다. 물을 그냥 마시는 기능, 갈증·오염 게이지, 소모품 부패는 추가하지 않았다. 천 조각 2개로 하는 기존 정착지 응급 처치도 유지한다.

## 소비와 회복 보호

- 만피·행동 불능 대원은 붕대를 소비하지 않는다. 부활 기능이 아니다.
- 정착지에서 다른 작업에 배정된 대원은 작업이 끝나기 전 치료할 수 없다.
- 현장에서는 자기 가방에 실제 붕대가 있어야 한다. 이동·수색·조우·다른 확인창 중에는 사용하지 못한다.
- 사용 성공 시 물자·회복·시간은 한 번만 반영하며, 현장 치료의 소음 증가는 0이다. 현장 대원 카드의 체력 표시도 갱신한다.
- 회복 기능을 가진 현장 물품은 `UseVerb`에 따라 음식은 먹기, 붕대는 치료로 표시한다.
- 휴식 화면은 기본 회복량 대신 실제 부족 체력까지의 회복량을 표시한다. 만피일 때 `체력 +0 / 회복 불필요`로 표시하며 새 휴식 예약을 막는다. 이미 진행 중인 휴식의 중단은 유지한다. 시간만 보내려면 시간 진행 화면을 이용한다.

## 저장 버전 3

신규 물자 `raw-water`, `bandage`를 포함한다. 정수와 붕대 제작은 기존 제작 예약 형식으로 남은 시간·수량·예약 재료·담당자를 저장한다.

버전 1 → 2 → 3, 버전 2 → 3 이관을 지원한다. 이전 저장에 없는 새 물자만 0으로 추가하고 기존 조리·제작·가방·재료·귀환 기록은 유지한다. 기존 기본 재료가 누락된 손상 파일을 이관으로 덮어주지 않는다. 불러오기만으로 원본 파일을 다시 쓰지 않는다.

- `InventoryPanel.prefab`: 신규 물품 분류·회복량·비용·사용 동사·현장 사용 허용. 현재 미정수 물과 붕대는 재료 탭에 표시한다.
- `ExpeditionLootPanel.prefab`: 상자의 미정수 물 수색 후보.
- `SettlementWorkPanel.cs`: 실제 휴식 회복량 및 만피 예약 방지.
- `FieldFoodUse.cs`: 음식·치료품 공통 현장 사용 검증/처리. 기존 도시락 호출은 호환 메서드로 유지한다.
- 재적용: 정지한 Editor에서 `AgentScripts/ConnectLifeSupplies.cs`의 `ConnectLifeSupplies.Run`, 이어서 `BuildBalance1.Run`(수색 보상표). 미저장 씬은 보호한다. 원본 이미지나 씬 YAML을 직접 수정하지 않았다.

## 검증

Unity 6000.6.0f1 Editor, `VerifyLifeSupplies`의 실제 UI 레이캐스트 클릭으로 확인했다. 테스트 상태의 부상은 검수용 주입이며 새 게임 시작 체력을 바꾸지 않았다.

1. `Flow`: 정수/붕대 예약·재료 잠금·담당자 충돌·중도 취소, 여러 작업 동시 진행, 저장 왕복 전체 상태 일치, 예약 재고 부족 저장 거절.
2. 실제 이전 버전 1·2 파일을 읽어 새 물자 0 이관 및 원본 파일 미변경 확인.
3. 정착지/현장 붕대 치료의 소유자·수량·시간·소음·최대 체력·만피/행동 불능/작업 중/모달 보호 확인.
4. 휴식의 실제 회복량·만피 차단·중단·완료 확인.
5. `WaterSupply`: 수색 → 발견물 분배 → 가방 → 귀환 → 창고 → 저장 복원·재방문, 고갈 상태 유지 확인.
6. `SaveRestartFixture` / `Restart`: Play 종료 후 새 Play의 시작 화면 이어하기로 정수·붕대의 부분 진행을 복원하고 비용/결과를 한 번만 반영.
7. 기존 `VerifyCooking.Flow`도 재실행해 식사·도시락·저장·현장 음식 사용 회귀 검사 통과.

테스트 저장은 `Temp/LifeVerification-*`, `Temp/LifeRestartVerification` 등 격리 경로를 사용했다. 플레이어 저장 파일은 수정하지 않았다. 컴파일 성공, 이번 검증 구간 신규 Unity 오류 없음. 실행 파일 빌드는 생략했다.

## 화면 검수와 한계

기존 작업대 캡처 `Assets/Screenshots/Settlement/popup-craft-aligned.png`와 비교해 외곽 패널·탭·목록·담당자/재료 열·하단 버튼 위치를 유지했다. 신규 제작법은 기존 스크롤 목록에 추가했다. 정수 설명의 세 줄 넘침을 두 줄 문구로 수정했으며, 치료/휴식 화면의 실제 수치가 들어간 상태에서도 글자 높이와 클릭 영역을 검증했다.

실제 화면은 `Assets/Screenshots/LifeSupplies/`의 `purification.png`, `bandage-craft.png`, `settlement-treatment.png`, `field-treatment.png`, `rest-recovery.png`에 보관했다. 기존 물방울·천 아이콘을 재사용하며 신규 전용 원화·PSD 완성으로 보고하지 않는다.

미정수 물 공급은 현재 상자 수색과 새 게임 초기 재고로 제한된다. 반복 물자 경제·방문자·물물교환은 아직 미완료이며 다음 제작 단위다. 독립 정수 시설·직업 치료 보너스·부활·치료 대상 전용 선택창·생존 게이지도 후속 범위다.

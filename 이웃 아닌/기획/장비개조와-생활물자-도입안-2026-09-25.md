# 장비 개조와 생활·교환 물자 도입안

작성: 2026-09-25. **원래 도입안. 이후 사용자 요청으로 생활 물자 8종·수색·거래·대체 제작법을 적용했다.** 실제 범위는 [생활 물자 적용 기록](생활물자-8종-적용과검수-2026-09-25.md)을 우선한다. 이 문서의 무기 장착·개조·발전기·현장 전원·기호품 생활 사건은 후속 제안이다.

사용자 방향: 총·근접무기 등 장비 다양성에 개조를 더하고, 담배·건전지·기름처럼 생활과 거래에 쓰이는 물자를 늘린다. 아래 품목별 효과·슬롯·수치·순서는 제안이며, 사용자가 각각 확정한 규칙으로 취급하지 않는다.

## 1. 목표

탐험에서 찾은 물건이 정착 생활, 장비 준비, 다른 생존자와의 교환으로 이어지게 한다. 같은 물자를 어디에 쓸지 선택하고, 필요한 물자의 출처를 알게 되면 다음 탐험 목적지를 고를 수 있게 한다.

예: 정비소에서 연료통을 발견한다 → 조리용으로 보관 / 발전기 복구 이후 사용 / 연료를 찾는 방문자에게 붕대와 교환. 이 선택은 해당 시설·거래 콘텐츠가 구현된 단계부터 제공한다.

## 2. 현재 구현과의 차이

- 실제 인벤토리에는 탄약, 목재, 고철, 천, 못, 밧줄, 지렛대, 손전등, 식재료, 물, 미정수 물, 통조림, 식사, 도시락, 붕대가 있다. 같은 기능의 새 ID를 중복 추가하지 않는다.
- 손전등은 현재 재사용 도구다. 새 건전지 아이템을 넣었다는 이유만으로 기존 손전등 사용을 갑자기 막지 않는다.
- 개인별 무기 장착·개조는 없다. 먼저 장비 소유·장착·교환·저장 기반이 필요하다.
- 방문자는 품목별 고정 가치와 한정 재고를 가진다. 현재 거래는 한 종류를 주고 한 종류를 받으며, 품목 표시 수는 고정 UI 슬롯에 묶여 있다. 품목만 추가하면 뒷부분이 안 보일 수 있다.
- 가방은 현재 물건 종류마다 한 칸이다. 사용자가 결정한 **재료 5개당 한 칸**은 아직 미적용이다. 새 물자 확장 때 가방·모두 담기·전달·출발 검사·저장 변환을 함께 연결한다. 탄약·치료품·장비의 묶음 수는 별도 설계 대상이다.
- 창고는 재료 개수 합계로 용량을 검사한다. 새 품목을 넣을 때 보관 용량과 기존 재료 수급을 함께 검토한다.

## 3. 물자 후보와 실제 쓰임

| 물자 | 주요 사용처 제안 | 교환·서사 연결 | 등장 단계 |
|---|---|---|---|
| 기름·연료통 | 호환 버너의 조리, 후속 발전기 가동 | 연료가 부족한 거점·상인의 수요 | 기본 거래 이후, 소비처와 함께 |
| 윤활유 | 작업대에서 장비 개조·정비에 쓰는 재료 | 정비공의 물물교환·정비 부탁 | 장비/작업대 단계 |
| 건전지 | 현장 라디오·잠시 켜는 단말기, 후속 조명 장비 | 전자기기를 고치는 생존자의 수요 | 현장 전원 상호작용과 함께 |
| 담배 | 1차에는 교환품, 일부 인물에게 건네는 대화 선택 | 그 인물의 습관·과거·부탁을 드러냄 | 기본 거래 단계 |
| 커피 | 교환품·차를 함께 마시는 생활 사건, 후속 기호품 | 인물별 선호와 대화 | 생활 사건 단계 |
| 소독용 알코올 | 기존 붕대를 만드는 대체 제작법·의료 사건 | 치료소 물자 요청 | 의료 제작 단계 |
| 전기 부품 | 라디오·조명·후속 발전 설비의 복구 | 전기 수리 부탁 | 연구·설비 단계 |
| 무기 부품 | 무기 제작·개조 | 장비를 취급하는 상인·회수 의뢰 | 장비 단계 |

기름은 연료와 윤활유만 구분한다. 초반부터 휘발유·경유·등유·엔진오일을 모두 별도 아이템으로 늘리지 않는다. 연료 소비 시설은 해당 연료에 맞는 버너/발전기로 표현한다.

각 물자는 구현된 소비처 또는 거래 상대가 최소 하나 있어야 전리품에 넣는다. 커피·담배를 체력 회복약으로 만들지 않는다. 기호품 자동 소비·중독·부족 페널티는 이번 도입 범위에 포함하지 않는다. 기존 붕대 제작과 기본 조리 경로는 유지하고 새 재료를 쓰는 대체법을 추가해 필수자원 병목을 피한다.

건전지는 처음에는 선택형 현장 전원 행동 한 건과 연결한다. 소비 수량과 결과를 선택 전에 표시하고, 취소·불러오기·재입장으로 중복 소비/보상을 만들지 않는다. 기존 손전등에 충전 규칙을 붙이는 확장은 별도 밸런스 검토 후 한다. 연료 역시 실제 작업을 할 때 소비하며 대기 시간에 몰래 차감하지 않는다.

## 4. 장비 개조

기본 무기 후보는 이전 제안인 지렛대·칼·쇠창 / 권총·소총·산탄총이다. 기본 피해는 우선 근접 2·사격 3을 중심으로 검토하고, 현재 체력·방어·대원 특성과 함께 검증한다.

개조는 처음에 **무기 하나당 선택형 개조 한 칸**으로 시작한다. 작업대에서 담당자와 재료·시간을 정하고, 연구로 다음 방식을 발견한다. 여러 개조를 전부 붙여 누적시키는 구조는 뒤로 둔다.

| 개조 방향 예시 | 플레이 선택 | 주의점 |
|---|---|---|
| 정밀 조준 | 정지해서 쏠 때 더 정확 | 이동한 턴의 사격 제약 등 비용을 가진다. 원래 이동 사격이 불가능한 무기에는 같은 제약을 대가로 계산하지 않는다 |
| 기동 조준 | 이동 후 사격 명중 보완 | 서진의 이동 특성과 합산되는 실제 명중률을 검수한다 |
| 소음 억제 | 사격 소음을 줄여 탐험 부담 완화 | 유효거리 등 다른 성능과 교환한다. 총성이 사라지거나 귀기울임의 총성 반응을 무조건 무효화하지 않는다 |
| 근접 손잡이 보강 | 근접 명중 보완 | 기섭의 방어형 추가 피해와 중첩해 피해까지 무조건 올리지 않는다 |
| 긴 자루 | 뒤쪽에서 닿는 근접 범위 | 가까운 거리의 운용 제약과 묶고, 기본 쇠창의 정체성과 겹치면 제외한다 |

이는 게임 효과 후보이며 실제 개조 수치와 무기별 호환 목록은 미확정이다. 내구도, 탄종 분리, 부위별 다중 슬롯은 첫 도입 이후 검토한다. 윤활유를 쓰기 위해 고장 스트레스 시스템부터 추가하지 않는다.

장착한 무기·개조는 인물에게 종속된 수치가 아니라 **그 물건의 상태**로 보존한다. 다른 대원에게 전달하거나 창고에 넣어도 같은 개조가 유지되어야 한다. 같은 종류 무기 두 자루에 서로 다른 개조를 구분할 수 있어야 한다.

## 5. 거래와 탐험 장소

- 상인별 선호를 사전에 보여준다. 예: 정비공은 윤활유·무기 부품, 전기 수리공은 건전지·전기 부품, 치료소 사람은 붕대·알코올을 더 찾는다. 인물 이름과 서사는 기존 NPC 설정을 확인한 뒤 연결한다.
- 첫 도입은 현재 한 종류 대 한 종류 교환을 유지할 수 있다. 먼저 전체 재고를 볼 수 있게 목록을 확장하고, 선호 물건 표식·실제 제안 가치·거래 후 수량을 표시한다. 여러 종류 묶음 교환은 그 다음이다.
- 선호는 누구에게나 통하는 판매 배수로 쓰지 않는다. 구매·판매·재구매를 반복해 물건이 증식하지 않도록 방향별 평가와 방문 중 수요량을 함께 검사한다.
- 제작으로 부가가치를 만드는 것은 가능하되 시간·재료·판매처 재고가 비용이 된다. 무한 즉시 왕복 거래와 구분한다.
- 일반 거래로 진행 필수 단서·고유 퀘스트 물건을 처분하지 않도록 별도 취급한다. 일반 생활품을 특정 사건에서 썼다는 이유만으로 전부 퀘스트 물건으로 만들지는 않는다.

| 후속 탐험지 후보 | 주로 찾는 물자 | 선택 상황 |
|---|---|---|
| 편의점 | 담배·커피·건전지·식량 | 먹을 것을 챙길지 교환 가치가 있는 것을 챙길지 |
| 정비소 | 연료·윤활유·고철·부품 | 무거운 재료와 장비 준비 물자 사이의 가방 선택 |
| 약국·진료소 | 붕대·알코올·의료 관련 기록 | 자기 치료와 현장 생존자의 부탁 |
| 주택·전파상 | 건전지·전기 부품·라디오 관련 단서 | 단말기에 전원을 쓸지 건전지를 가져갈지 |

이 장소들은 배치 후보이며 현재 개방되어 있다는 뜻이 아니다. 편의점은 기존 결정대로 도입 장 이후 콘텐츠 완성 시 개방한다. 폐상가에 신규 물자 전체를 몰아넣거나 튜토리얼 필수 재료를 밀어내지 않는다.

## 6. 제안 구현 순서와 완료 기준

1. 장비 소유·장착·전달·저장 기반 + 기본 무기. 장비와 가방 물자의 차이를 기존 대원 탭에서 확인한다.
2. 재료 묶음 규칙과 거래 목록 확장. 여섯 대원, 꽉 찬 가방, 옛 저장에서 수량이 유실되지 않아야 한다.
3. 담배·건전지·연료의 발견 → 사용 또는 교환 → 귀환 → 저장까지 각 한 경로 완성. 사용처가 준비된 것부터 배치한다.
4. 작업대 개조 + 윤활유·무기 부품. 개조 미리보기와 실제 명중·소음·범위가 같아야 한다.
5. 전기 부품·알코올·커피와 새 장소·NPC 요청을 차례로 추가한다.

처음부터 모든 품목과 개조법을 노출하지 않는다. 첫 획득/관련 시설 복구/정보를 얻는 대화를 통해 하나씩 배운다. 기존 종이·잉크 UI, 보유 물건만 표시, 대원 이름 탭, 좌측 하단 닫기 규칙을 지킨다. 이 문서에는 새로운 UI 승인 시안이 포함되어 있지 않다.

구현 시 개조 무기의 저장 왕복, 제작 예약 중 재료 이중 소비 방지, 상인 재고·가방 한도, 거래 왕복 증식, 필수자원 없이 돌아오는 경로, 현재 대원 특성 및 소음 반응과의 상호작용을 검수한다. 이번 작업은 문서만 작성했으므로 해당 기능 구현·플레이 검수를 완료했다고 보고하지 않는다.

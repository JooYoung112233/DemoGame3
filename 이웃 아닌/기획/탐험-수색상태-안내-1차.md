# 탐험 수색 상태 안내 1차 — 2026-09-23

기존 폐상가 수색 대상 3곳에 미수색 / 수색 중(진행도) / 물품 남음(종류 수) / 비어 있음을 표시한다. 출발 계획의 폐상가 정보에는 각 상태의 대상 수를 두 줄로 요약한다. 다른 목적지의 기존 안내는 유지한다.

## 동작과 편집

- `ExpeditionSearchStatus.cs`: 기존 수색 기록을 읽어 상태를 분류한다. 표시만으로 수색 상태를 만들거나 보상을 추첨하지 않는다.
- 현장 표시판은 대상 버튼 아래에 붙으며 입력을 가로채지 않는다. 남은 물품은 금색, 고갈은 회색으로 구분한다.
- `ExpeditionPlanPanel.UnknownHeading`: 폐상가에서는 수색 기록, 나머지는 현장 안내. 두 줄 높이84px/글자22px로 표시한다.
- `ConnectSearchStatus.Run`: 기존 프리팹에 표시판과 계획 화면 참조를 연결하는 Editor 스크립트.
- 저장 버전7의 기존 수색 기록을 사용한다. 새 저장 필드나 보상 재생성 규칙은 없다.

## 검증과 실제 화면

`VerifyRecruitment.Fresh` → `VerifySearchStatus.Flow` → `PlanPreview` 통과. 실제 UI 클릭으로 물품 회수·귀환·계획 화면 진입, 파일 저장 후 씬 복원 및 재방문을 확인했다. 완료 대상의 재수색·재추첨이 없고 부분 진행과 남겨둔 상태가 보존된다. 검증 저장은 `Temp/SearchStatusVerification`으로 격리했다.

`Assets/Screenshots/SearchStatus/field.png`, `plan.png`는 실제 Unity 1920×1080 캡처. 기존 배경과 외곽 UI 배치를 유지했고 현장 버튼 아래 표시, 계획 요약 두 줄과 제목을 육안 확인했다. 새 원화 없이 Unity Text/Image를 사용했다. 실행 파일 빌드는 생략했다.

이번 범위는 기존 장소의 진행·고갈 안내다. 연결 방, 수색 대상 추가, 장기 반복 공급과 이상현상 기믹은 후속이다.

## 정보 패널 정렬 보완
자원 아이콘의 pivot을 중앙(0.5,0.5)으로 바꿨다. preserveAspect가 좌상단 pivot을 기준으로 좁은 물 아이콘을 왼쪽에 붙이던 문제를 해결하여 모든 목적지의 아이콘과 이름 중심이 일치한다. 두 자원 이름의 높이와 기준선을 통일하고, 두 번째 구분선 y490 → 제목 y501 → 본문 y546으로 간격을 확보했다. 본문 높이는 최신76px이며 두 줄 모두 표시된다. 실제 Unity 캡처 Assets/Screenshots/SearchStatus/plan-aligned.png로 검수했다.

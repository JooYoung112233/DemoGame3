# 랜덤 동료 시스템 — 후속 제작 방향

2026-09-23 사용자 지시: **비전투 콘텐츠와 시스템을 먼저 완성한 뒤**, 캐릭터별 이름과 개성을 만들고 랜덤 동료 시스템으로 발전시킨다. 현재 역할명 중심 대원은 개발용 구성을 유지한다.

## 확정 방향

- 구현 순서: 비전투 콘텐츠 완성·연속 플레이 검수 → 동료 개성 설계 → 랜덤 동료 시스템.
- 동료에게 개성 있는 이름과 여러 특징을 부여한다. 영입·생활·탐험에 연결하는 랜덤 동료를 목표로 한다.
- 이번 UI 수정에서 동료 이름이나 무작위 생성 규칙을 임의로 확정하지 않는다.

## 후속 설계 항목 — 아직 미확정

이름 풀, 성격과 배경, 외형 조합, 장점·단점, 생활 특성, 말투·관계, 방문·영입 조건을 함께 검토한다. 무작위 조합 범위·등장 확률·중복 방지·성장 방식은 그 단계에서 정한다.

저장은 표시 이름과 고유 동료 ID를 분리하고 생성된 결과를 보존하는 방향으로 설계한다. 불러오기 때 다시 추첨하거나 같은 이름을 같은 사람으로 취급하지 않도록 한다.

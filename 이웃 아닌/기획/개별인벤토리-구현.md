# 공용 창고·개인 가방 — UI01

기준: `아트/UI전체시안-v1/01-개별인벤토리.png`. 기존 정착지 배경 위에 상단 대원 카드, 좌측 창고/분류, 중앙 개인 가방, 양방향 이동 버튼, 우측 손 도구 영역과 물건 상세를 배치했다. 화면 수정 결과는 실제 Unity 1920×1080 캡처를 사용자에게 공유한다.

## 최신 정렬 보완

**v5 용량 표기:** `2 / 3칸`에서 단위 `칸`을 제거했다. 용량 텍스트는 가방 제목과 같은 30px 글자/높이(y=269, h=65), 패널 오른쪽 안쪽 선(x=1376)에 우측 정렬한다. 캡처는 `Assets/Screenshots/Settlement/inventory-v5-capacity.png`. 이미지에 구워 넣지 않은 Unity Text 변경이므로 PSD 그림은 변경하지 않는다.

**v4 최종 정정:** 상단 정렬 대상은 대원 리스트가 아니라 DAY 배경이다. 대원 카드 시작 x=386과 기존 확장 구조는 유지한다. 패널 원화의 투명 여백 때문에 RectTransform만 같아도 테두리가 안쪽으로 들어가 보이던 부분을 보정했다. DAY 배경과 아래 창고의 보이는 왼쪽 선이 맞도록 창고 종이 Rect를 x=74·폭=652로 조정했고, 콘텐츠의 기준선은 유지했다. 가운데 가방의 논리 영역은 x=776·폭=624로 24px 넓혔다. 내부 슬롯/제목과 하단 안내 시작점도 함께 맞췄다. 최종 화면은 `Assets/Screenshots/Settlement/inventory-v4-final.png`이며 v3보다 이 항목을 우선한다. 프리팹과 레이어 PSD에 반영했다.

**v3 사용자 재검토 반영:** 요소마다 다른 왼쪽 선을 쓰던 문제를 수정했다. 날짜/장소 종이·창고 외곽·돌아가기의 x=80, 중앙 가방/하단 안내의 x=800, 오른쪽 도구/하단 안내의 끝 x=1840을 공통 기준으로 고정한다. 세 패널 y=248, 내부 좌우 여백 24, 제목 y=264, 첫 슬롯 y=432, 하단 버튼/안내 y=952·높이 78을 사용한다. 슬롯 아이콘은 가로 중앙 앵커, 수량은 우측 앵커로 설정하여 창고/가방 슬롯 너비 차이에도 내부 정렬이 유지된다. 최종 캡처는 `Assets/Screenshots/Settlement/inventory-v3-grid.png`다. 아래 v2 설명보다 이 수치를 우선한다.

사용자 요청으로 우측 상단 X를 없애고 기존 화면과 같은 좌측 하단 410×78 `돌아가기` 버튼으로 바꿨다. 배경 딤은 20%에서 62%로 높였으며 새 화면 날짜/장소는 딤 위에 별도 배치하고 기존 거점 정보는 열려 있는 동안 숨긴다. 날짜·시간/장소 종이의 왼쪽 선을 창고 패널에 맞추고, 세 패널의 제목(262px)과 첫 슬롯(432px) 높이를 통일했다. 슬롯 아이콘·수량·이름, 도구 칸·문구, 하단 안내의 여백과 정렬도 맞췄다.

프리팹 보완 스크립트는 `AgentScripts/AlignSettlementInventory.cs`다. 최초 조립 스크립트를 다시 실행했다면 이후 이 스크립트를 실행한다. 최신 PSD도 동일한 배치로 갱신했다. 실제 화면: `Assets/Screenshots/Settlement/inventory-v2-alignment.png`. Unity에서 돌아가기·수량 이동·용량·예약 재료 보호와 글자 영역을 재확인했다.

## 진입·입력

정착지 보관함/비축 물자 → 창고·첫 대원 가방. 하단 대원 가방 버튼 → 해당 대원의 가방. 대원 카드는 6명 단위 페이지이며 실제 동료 수만 표시한다. 창고는 전체/식량/도구/재료 분류, 창고와 가방은 각각 스크롤과 공통 하단 안내 화살표를 사용한다. 닫으면 기존 정착지 표시와 입력을 복원한다.

슬롯 선택 → 좌우 화살표 또는 우측 이동 버튼 → 수량 확인(+/-/최대) → 옮기기. 수량창을 취소하면 소유량을 바꾸지 않는다. Esc는 수량창부터 한 단계씩 닫는다. 한 화면 전체가 아닌 공통 슬롯·대원 카드·화면 조립 프리팹으로 구성했다.

## 물자와 용량

- 새로운 물자를 지급하지 않는다. 보급품/탄약은 선택한 정착지의 기존 Campaign 수량에서 개인 배정분을 제외하여 창고에 표시한다. Campaign 수치는 전체 보유량으로 유지된다.
- 나무/밧줄/못/고철/천은 기존 CraftPanel의 재료와 연결한다. 개인 가방으로 옮기면 공용 제작 재료에서 빠지고 반환하면 다시 사용 가능하다. 예약된 재료는 가용량에서 제외하여 이동을 막는다.
- 임시 슬롯 규칙: 같은 종류는 수량과 관계없이 한 칸을 차지한다. 새 종류는 빈 칸이 있어야 들어간다. 최종 무게·겹치기 상한은 미확정이다. 실제 대원의 BagCapacity를 사용하므로 시안 예시 12칸을 강제하지 않는다.
- 대원 전환이나 창 닫기/재열기 동안 개인 소유가 유지된다. 현재 상태는 Settlement 화면 세션에만 존재한다. 저장/불러오기·씬 이동·외부 원정의 RunState 인벤토리 통합은 아직 구현하지 않았다. 새 원정 UI 연결 전에 이 데이터를 옮기는 단계가 필요하다.

## 현재 구현 범위와 시안 차이

시안의 배치와 종이 질감을 따른다. 시안의 예시 6명·채워진 가방 대신 실제 두 대원과 시작 물자를 표시한다. 가독성을 위해 슬롯에 아이템 이름을 추가했다. 상단 거점 버튼/자원/기록은 이 화면에서 숨겨 대원 카드·닫기 버튼과 겹치지 않는다. 날짜/장소는 유지한다.

손 도구 두 칸은 위치를 잡은 빈 UI다. 장착/해제·배터리·아이템 사용/폐기·전체 종류 일괄 이동은 미구현이며 사용 버튼은 비활성이다. 우측 이동 버튼은 동작한다. 빈 도구 슬롯을 실제 장비 보유 상태로 취급하지 않는다.

## 편집 파일

- `InventorySlot.prefab`, `InventoryMemberCard.prefab`: 재사용 슬롯·대원 선택 카드.

- `AgentScripts/BuildSettlementInventory.cs`: Unity Editor에서 프리팹 조립. 수동 배치 수정 후에는 불필요하게 재실행하지 않는다.
- `아트/개별인벤토리-v1/`: 개별 PNG와 실제 분리 레이어 PSD. 3840×2160 배치 원본은 텍스트가 합쳐져 있지 않다. 아이콘은 시안의 작은 원본 픽셀에서 분리한 것으로 고해상도 완성 원화가 아니다.

## 검증

Unity Play에서 실제 버튼 레이캐스트로 보관함/개인 가방 진입, 대원별 소유, 수량 취소·일부·최대 이동, 빈 슬롯/가득 찬 가방 판정, 기존 종류 합치기, 분류, 제작 예약 재료 제외·취소 반환·총량 보존, 모달 입력과 텍스트 영역을 확인했다. 검증 스크립트는 `AgentScripts/VerifySettlementInventory.cs`다. 실행 파일 빌드는 하지 않았다.

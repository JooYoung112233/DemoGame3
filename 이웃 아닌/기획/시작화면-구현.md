# 시작 화면 구현 — 2026-09-22

> 최신 정정: 사용자는 **현재 배경 구도와 UI 위치를 유지하고 리소스만 교체**하길 원한다. v1의 버튼 수와 순서를 유지하고 v2 종이 자산·손글씨 폰트를 적용한다. [리소스 v2와 레이어 PSD](../아트/시작화면-v2/README.md)는 시각 승인 대기이며, 아래 기존 기능 검증 결과가 시각 승인을 뜻하지 않는다. 기준: [demo5 제작 규칙](../AGENTS.md).

## 추가 수정 결과

최신 제목 정렬: 사용자의 마지막 범위 지정에 따라 좌측 상단 ProjectLabel·제목·설명만 수정했다. 제목 72pt, 보조 표기 24pt, 설명 34pt/줄 간격 1.12다. 보조 문구의 왼쪽 여백은 64px, 제목은 첫 글자의 옆 여백을 고려해 60px로 보정했다. 설명 시작 y=168. 배경·종이·버튼은 그대로 유지했다. 검수 캡처는 `Assets/Screenshots/TitleMenu/title-v6-type.png`다.

사용자가 아이콘·글씨 크기·정렬 차이를 지적하여, 현재는 승인 시안 20/19번의 버튼 종이와 아이콘을 직접 분리해 적용했다. 버튼 내부의 아이콘 64×64, 글씨 시작점 166px, 글씨 42pt, 화살표 여백을 맞췄다. 바깥 버튼·팝업 위치와 크기, 버튼 수는 유지했다. 폰트 대체는 명시적으로 허용되어 Gaegu Bold/Regular와 원문 OFL을 프로젝트에 포함했다. Inspector에 지정한 개별 폰트를 런타임이 덮어쓰지 않게 수정했다.

캡처는 `Assets/Screenshots/TitleMenu/title-v3.png`. 레이어 PSD는 `아트/시작화면-v2/PSD`에 있다. 실제 시작 화면의 시각 승인은 대기 중이다. 원본 1:1 분리 자료는 검수용이며 현재 Unity 화면 전체가 픽셀 단위로 동일하다는 의미가 아니다. 제목 종이는 아직 생성 리소스이고, 시안 추출 아이콘은 작은 원본이므로 고해상도 최종 제작 완료로 보고하지 않는다.

재컴파일 완료, 아이콘 추가 후 버튼 클릭·모달 입력 차단·음량 취소·종료 취소를 다시 통과했다. 마지막 크기 보정 후 캡처를 갱신했다. 빌드는 수행하지 않았다.

첫 실제 UI 구현 단계. Unity 6.6에서 시작 씬과 편집 가능한 프리팹을 생성했다. 이후 화면의 완성 여부와 구분한다.

## 실행과 수정 위치

- 시작 씬: `Assets/Scenes/StartMenu.unity`. 열고 Play한다. 빌드 설정의 첫 씬으로 등록했다.
- 전체 메뉴 프리팹: `Assets/Prefabs/FrontEnd/TitleMenu.prefab`.
- 공통 버튼: `Assets/Prefabs/FrontEnd/PaperButton.prefab`.
- 개별 팝업: `SettingsDialog.prefab`, `LoadDialog.prefab`, `ConfirmDialog.prefab`.
- 로직: `Assets/Scripts/FrontEnd/TitleMenuController.cs`.
- 1920×1080 배치와 화면비 보존: `Assets/Scripts/FrontEnd/TitleViewport.cs`.
- 배경·종이 스프라이트: `Assets/Art/FrontEnd`.

버튼의 Label 자식에서 문구·글자 크기를, RectTransform에서 위치·크기를 수정한다. 팝업은 각각의 프리팹에서 편집한다. TitleMenuController의 필드는 씬/프리팹의 실제 버튼과 연결되어 있다. 각 버튼 이벤트는 Awake에서 연결하므로 Inspector onClick에 같은 이벤트를 중복 등록하지 않는다.

현재 Canvas와 EventSystem은 씬에 있고 TitleMenu는 메뉴 전체 프리팹이다. 프리팹만 다른 씬으로 옮긴다면 Canvas·GraphicRaycaster·InputSystemUIInputModule·TitleViewport도 필요하다.

## 연결

| 버튼 | 현재 실제 동작 | 명세 대응 |
| --- | --- | --- |
| 새 게임 | 입력 잠금 → 짧은 검은 페이드 → 새 PartySelection 씬 | S00 → S01, [새 모험가 선택](모험가선택-구현.md)으로 교체 |
| 계속하기 | 비활성. 아직 여정 저장 서비스 없음 | 저장 연결은 후속 단계 |
| 불러오기 | 저장된 여정이 없다는 팝업 → 돌아가기 | C04 빈 상태만 구현 |
| 설정 | 전체 음량 미리보기, 전체 화면 선택, 적용/취소 | C02 |
| 적용 | PlayerPrefs에 설정 저장, 화면 모드 적용, 메뉴 복귀 | 설정 저장만. 게임 진행 저장과 무관 |
| 취소 / 설정에서 Esc | 이전 음량 복원, 설정 미저장 | C02 취소 |
| 게임 종료 / 메인에서 Esc | 종료 확인. 기본 선택은 돌아가기 | P02 Quit |
| 종료 확인 | 실행본에서는 종료, Editor에서는 Play 종료 | QUIT |

모달이 열려 있으면 뒤쪽 메뉴의 클릭/선택을 차단한다. 닫을 때 호출 버튼으로 선택을 돌려준다. 페이드 중 입력·중복 씬 전환을 막는다. 실제 여정 저장·덮어쓰기·이어하기·불러오기 복원은 이번 구현에 포함하지 않는다.

## 시각 및 원본

20번 시안 상단의 두 모험가와 도시 구도를 기준으로 글자 없는 배경을 새로 제작했다. 시작 배경과 UI 종이 질감은 내장 imagegen으로 생성했으며 [원본·프롬프트 기록](../아트/시작화면-v1/README.md)에 보관했다.

배경의 인물과 도시가 한 PNG에 합쳐져 있다. UI 글자·버튼·팝업은 Unity 개별 요소다. 실제 레이어 PSD를 제작한 것은 아니다. PNG 원본은 둘 다 1672×941이며 3840×2160 목표에 미달한다. 1920×1080 캡처는 게임 화면 검수본이지 원화 해상도 복원이 아니다.

한글은 현재 설치된 OS 폰트를 사용하는 uGUI Text로 렌더링한다. 개발 명세의 최종 TMP/배포용 한글 폰트 구성을 완료한 상태는 아니다. Windows에서 검증했으며 다른 OS/배포 전 라이선스가 확보된 폰트와 TMP 적용이 필요하다. TitleViewport.FontOverride로 별도 폰트를 지정할 수 있다.

## 검증 결과

- 재컴파일 완료, C# 오류 없음.
- 씬과 5개 프리팹 참조, 시작 씬 순서, 기존 프로토타입 목적지 유지 확인.
- GraphicRaycaster로 버튼 중앙의 최상위 클릭 대상을 검사하고 PointerClick을 전달해 동작 검증.
- 설정 열기·메뉴 입력 차단·음량 미리보기·취소 복구 통과.
- 설정 적용·저장값·재열람 통과. 검증 후 기존 사용자 설정 복원.
- 비활성 계속하기·빈 불러오기·종료 확인·취소 통과. 실제 앱 종료는 수행하지 않았다.
- 새 게임의 페이드/입력 잠금 후 NightExpedition의 Party 단계 진입 확인.
- 시작 화면과 설정창 1920×1080 캡처 확인. 슬라이더 크기 오류 수정 후 재검증.
- 실행 파일 빌드는 하지 않았다. Editor는 StartMenu 씬의 편집 모드로 남겼다.

캡처: `Assets/Screenshots/TitleMenu/title-v1.png`, `settings-v1.png`.

## 재생성 주의

`AgentScripts/BuildTitleMenu.cs`는 최초 배치 재현용이며 같은 경로의 프리팹/씬을 다시 생성한다. 사용자가 Inspector에서 수정한 뒤에는 무심코 재실행하지 않는다. 일반 수정은 해당 프리팹/컴포넌트에서 진행한다.

검증 스크립트는 `AgentScripts/VerifyTitleMenu.cs`. Inspect는 편집/실행 모드에서 참조를 검사하며 PlayFlow·SettingsCommit·NewGame은 Play 모드용이다. NewGame은 씬을 전환하므로 마지막에 실행한다.

다음 작업은 승인된 20번 시안의 모험가 2명 선택 화면이다. 현재 연결된 선택 화면은 이전 프로토타입이며 아직 새 시안대로 재구성하지 않았다.

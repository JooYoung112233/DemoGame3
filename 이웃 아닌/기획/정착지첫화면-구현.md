# 정착지 첫 진입 화면 — 2026-09-22

- 기존 구성과 배경은 유지. 시설 5개 아이콘을 가구 상단에 재정렬하고 클릭 영역을 84×84로 통일했다. 실제 불투명 그림의 긴 변을 42px에 맞춰 투명 여백에 따른 크기 차이를 줄였다.
- 발판을 발끝 밑으로 6px 올리고 상판·옆면·접지 그림자를 별도 SpriteRenderer로 구성했다. 공통 흰색 PNG를 사용하므로 각 색을 Inspector에서 바꿀 수 있다.
- Gaegu Bold 서체를 유지하고 UI Bold 스타일도 적용했다. 시간 40, 자원 38, 도착 제목 38/본문 30, 대원 이름 31/상태 32, 팝업 본문 34px로 조정했다. 위치명에는 얇은 어두운 외곽선을 적용했다.
- 수정은 `AgentScripts/PolishSettlement.cs`에서 개별 프리팹에 적용했다. 최초 builder 전체 재실행 시에는 이 보완 스크립트를 이어 적용해야 한다.
- `settlement-art-layout.psd`의 발판 레이어·시설 위치를 갱신했다. 발판 색/알파, UI 외곽선과 실제 텍스트는 Unity 프리팹이 기준이다. 원본 래스터 해상도를 복원한 작업은 아니다.
- 수정 캡처: `Assets/Screenshots/Settlement/settlement-v2.png`.

승인 UI 시안 04의 배경 중심 구성, 시설 위 원형 아이콘, 상단 시간·자원, 우측 하단 대원 카드를 기준으로 제작했다. 정착지 선택 화면의 좌우 하단 버튼도 410×78로 통일했다.

## 현재 연결

StartMenu → PartySelection → HomeSelection → **Settlement**.

세 정착지 중 선택한 이름과 실제 보급품·탄약·대원 정보를 전달한다. 공통 첫 진입 내부를 보여주며 **장소별 서로 다른 내부 배경은 아직 아니다**. 시설 배치는 기존 `shelter-unlit-v2.png`를 그대로 사용했다. 조명은 URP의 Global/Point Light2D 3개로 설정하고 배경 PNG에 굽지 않았다.

- 침대·비축 물자·작업대·보관함·출입구: 마우스를 올리거나 키보드로 선택하면 이름 표시, 클릭하면 시설 정보.
- 대원 카드: 현재 체력·상태와 역할 설명 확인.
- 가방 아이콘: 해당 대원의 가방 용량 확인. 개별 아이템 이동/인벤토리 화면은 후속 작업.
- 기록: 실제 선택된 이름과 정착지의 도착 기록.
- 시간 진행: 현재는 작업이 없다는 안내. 시간이 흐르거나 자원을 소모하지 않는다.
- 정보 창이 열리면 뒤 UI 입력을 막고, 닫기/Esc로 복귀한다.

현재 시간 `09:00`은 첫 진입 표시용이다. 작업 배정·진행·완료, 휴식/제작 효과, 목적지 지도와 출발 준비는 아직 연결하지 않았다. 이번 범위는 거점 첫 화면 및 살펴보기다. 작업 완료 알림을 가짜로 표시하지 않고 실제로 일어난 `정착 완료`를 보여준다.

- 개별 UI: DayPanel, ResourceHud, AdvanceButton, JournalButton, FacilityHotspot, ArrivalNotice, MemberCard, RosterStrip, InformationPopup.
- 배치/폰트: 각 프리팹 RectTransform/Text. 대원 목록은 HorizontalLayoutGroup으로 정렬한다.
- 실행 연결: `Assets/Scripts/FrontEnd/SettlementController.cs`
- 대원 초상/이름/특성: `Assets/Data/PartyRoster.asset`
- PNG·PSD: [원화 기록](../아트/정착지첫화면-v1/README.md)

대원은 선택한 2명만 표시하며, 카드는 한 페이지 4개까지 지원하도록 구성했다. 전체 몸 그림은 원본 시안에서 분리한 탐험가/의무관 2종이다. 현재 의무관 외 역할은 탐험가 몸을 임시 공유하고 카드 초상·이름은 실제 후보를 사용한다. 다른 역할의 일관된 전신 원본 보완이 필요하다.

`BuildSettlement.Build`는 최초 제작/재현용이며 다시 실행하면 해당 프리팹을 초기화한다. 사용자 배치 편집 이후에는 필요한 요소만 수정한다.

## 검증

Unity 6.6 컴파일 통과. `VerifySettlement.Flow`에서 하단 양쪽 버튼 동일 크기, 모험가→정착지→거점 데이터 전달, 두 카드와 두 말 표시, 실제 5개 시설 및 기록/시간/대원/가방 버튼 Raycast, 정보창 입력 차단·닫기, 글자 넘침, 조회 시 물자 미소모를 확인했다. 조명 오브젝트 3개도 확인했다. 업데이트된 `VerifyHomeSelection.Flow`는 3개 정착지 각각의 데이터가 이 화면에 도착하는지 검사한다.

실제 캡처: `Assets/Screenshots/Settlement/settlement-v1.png`. 원본 시안과 비교하면 기존 깨끗한 배경의 침대 2개·가구 배치를 유지했고, 없는 수분/식량/피로 수치를 추가하지 않아 실제 자원·체력만 표시한다. 기존 원본 해상도 한계는 유지되며 별도 고해상도 복원을 했다고 보지 않는다. 실행 파일 빌드는 하지 않았다.

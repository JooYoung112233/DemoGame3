# 캐릭터 방향 전환 안정화

2026-09-24. 사용자가 캐릭터가 너무 자주 좌우 반전한다고 보고했다.

## 확인한 구조와 수정

기존 PawnFacing은 매 프레임 가로 변위가 0.0005를 넘으면 즉시 방향을 바꿨다. 작은 움직임도 반전시킬 수 있는 구조였으며, 실제 사용자 화면의 움직임 원인을 재현했다고 주장하지 않는다.

- 반대 방향으로 연속된 가로 이동이 0.12 월드 단위 이상 누적될 때만 반전.
- 가로 변화가 세로 변화의 35% 미만이면 세로 이동으로 간주해 방향 유지.
- 정지·미세 이동·방향 변경·순간이동·ResetTracking 시 미확정 이동량 초기화.
- Face(bool)로 명시적으로 지정하는 방향은 즉시 적용하고 이전 이동 추적을 초기화.
- 몸체 SpriteRenderer.flipX만 수정하며 받침대와 정렬 순서 계산은 유지.
- Inspector의 TurnDistance, HorizontalIntentRatio로 조정 가능.

## 확인 결과

`AgentScripts/VerifyPawnFacingStandalone.ps1`에서 실제 PawnFacing.cs를 최소 Unity API 대체 타입과 함께 컴파일하고 이동 경로를 재생했다. 좌우 미세 흔들림 600회, 세로 이동 중 가로 편차, 15/30/60/144 샘플 좌우 이동, 정지 후 재출발, 순간이동, 원화 기본 방향 반대 설정, 추적 초기화 검사를 통과했다.

Unity MCP 상태 요청은 타임아웃, 프로젝트 경로를 지정한 CLI는 demo5 Pipeline 인스턴스가 없다고 응답했다. 실제 Unity 통합 컴파일·Play Mode 재현 검수는 미완료다. 다른 에이전트의 전투 코드·씬은 변경하지 않았다.

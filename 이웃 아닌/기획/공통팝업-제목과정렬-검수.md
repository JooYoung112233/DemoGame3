# 공통 팝업 제목과 정렬 검수

2026-09-23 사용자 요청: 팝업 좌측 위에는 현재 화면 이름을 표시하고 배경 HUD는 보이지 않게 한다. 수색 화면의 정렬 기준을 다른 비전투 화면에도 적용한다.

## 이번 검수 범위

수색, 현장 개인 가방, 발견물 정리, 원정 귀환 보고, 시간 진행의 5개 화면을 실제 UI로 열고 닫으며 검수했다. 나머지 시작/선택/설정/제작/휴식/전투 UI를 전부 검수했다는 의미는 아니다.

- 제목은 공통 `PopupHeading.prefab`: x80/y32, 540×72, 실제 Unity Text. 각 화면 이름은 프리팹 인스턴스에서 편집한다.
- `PopupBackgroundHud`는 배경 Main CanvasGroup의 alpha를 숨기고 종료 시 원래 값을 복원한다. 원화 배경은 유지하며 97% 검은 딤을 적용한다. 팝업 자체의 시간/아이템 정보는 유지한다.
- 하단 버튼은 y974/높이76, 끝선1050, 좌우 여백80으로 통일했다. 두 주요 버튼의 크기는 화면 내에서 동일하다. 3개 버튼인 귀환은 가방 정리 버튼을 오른쪽 확정 옆에 배치했다.
- 수색의 두 패널 사이 24px과 공통 상하 기준선을 유지했다. 가방/발견물의 세 열은 기존 간격을 유지한다.
- 발견물 안내문을 덮던 위험 알림을 x850/y32의 상단 우측으로 이동했다. 실제 알림은 계속 보이고 내용 영역을 덮지 않는다.

## 실제 검증

`VerifyPopupFrames`의 Time → Search → Bags → Loot → Return → Close가 통과했다. 실제 클릭과 수색 완료/귀환을 통해 제목 표시, 배경 HUD alpha=0, 닫은 뒤 alpha 복원, 활성 글자의 높이, 하단 끝선을 검증했다. 다섯 화면 캡처를 직접 확인했다. 위험 알림 겹침 수정 후 발견물 화면도 다시 캡처했다.

`Assets/Screenshots/Settlement/popup-time.png`, `popup-search.png`, `popup-bags.png`, `popup-loot.png`, `popup-return.png`가 이번 실제 화면이다.

## 편집 원본과 재적용

- `StandardizePopupFrames.Run`은 5개 화면에 공통 제목과 딤/하단 기준을 적용한다.
- `AlignPopupAlert.Run`은 도착 화면에 연결된 경고 배너를 옮긴다.
- 기존 화면 builder 재실행 후에는 화면별 정렬 스크립트, `CompactSearchLayout`, `StandardizePopupFrames`, `AlignPopupAlert` 순으로 적용한다.
- `아트/공통팝업프레임-v1/PSD`에는 5개 화면의 제목 종이와 하단 버튼만 별도 레이어로 저장했다. 내부 그림 원본은 기존 화면별 PSD를 사용한다. 이번 공통 프레임 좌표가 과거 화면 PSD의 제목/하단 좌표보다 우선한다.
- 새 그림 생성은 없다. 종이 원본 픽셀은 그대로 보관하며 텍스트와 배경 딤은 Unity에서 편집한다.

## 추가 적용: 창고·제작대·휴식

공통 프레임을 InventoryPanel, CraftWorkPanel, RestWorkPanel에 확대하여 총 8개 화면에 적용했다. 창고의 중복 날짜/장소를 숨기고 6개 대원 슬롯과 페이지 화살표가 겹치지 않도록 배치했다. 제작대는 기존 내부 요소를 유지하면서 패널을 위로 이동해 하단 버튼과 시간 안내의 겹침을 제거했다. 휴식의 닫기/등록 버튼도 좌우 하단으로 분리했다.

VerifySettlement.Flow 및 VerifySettlementFrames의 Inventory → Craft → Rest → Register를 통해 제목, 배경 HUD 숨김/복원, 실제 포인터 클릭, 텍스트 높이, 하단 기준선, 휴식 주문 등록을 확인했다. 제작대 위치 보정 후 Inventory/Craft를 재검증했다. 제작 레시피·재료 소비 규칙은 수정하지 않았다.

추가 캡처: Assets/Screenshots/Settlement/popup-inventory.png, popup-craft.png, popup-rest.png.
추가 PSD: 아트/공통팝업프레임-v1/PSD/inventory-chrome.psd, craft-chrome.psd, rest-chrome.psd. 제목/하단 공통 종이만 레이어로 제공하며 내부 요소 원본은 기존 화면 PSD를 사용한다. 최종 조립 위치는 Unity 프리팹이 기준이다. 공통 프레임 PSD를 전체 화면 PSD로 취급하지 않는다.

## 내부 정렬 보완

- 제작대: 예약 패널 안쪽 여백에 맞춰 작업 건수, 빈 목록 설명, 하단 안내, 스크롤 범위를 수정했다. 작업 행 폭도 함께 축소하고 취소 버튼과 문구의 오른쪽 여백을 확보했다. 예상 시간 문구를 위로 옮겼다.
- 휴식: 예상 시간/회복 효과와 구분선을 재정렬해 아래 문구가 종이 가장자리에 걸리지 않도록 했다.
- 제작 레시피·담당자·재료·예약 행과 휴식 담당자 행의 아이콘/선택 표시를 행 세로 중앙에 맞췄다. 그림 원본은 변경하지 않았다.
- 재적용 순서 마지막에 `FixPopupContentAlignment.Run`을 실행한다. 외부 프레임 크기를 변경할 때 내부 스크롤/행/문구의 폭도 함께 검증한다.
- 검증: 창고/제작대/휴식 클릭, 실제 작업 등록 후 예약 행의 패널 여백, 작업 취소 확인창과 유지/닫기 통과. 실제 1920×1080 캡처 `popup-craft-aligned.png`, `popup-rest-aligned.png`, `popup-cancel-aligned.png` 검수. 모든 게임 화면의 전수 검증으로 확대 해석하지 않는다.

# 침대 · 휴식 담당자 화면

기준: `아트/UI전체시안-v1/05-생활작업지정-v2.png` (2026-09-22 구현).

## 연결

정착지의 침대 아이콘 → 휴식 패널 → 짧은 휴식/수면 → 실제 대원 선택 → 휴식 시작 → 정착지.
닫기와 Esc는 선택 초안만 버리고 정착지로 돌아간다. 작업 등록과 화면 조회는 시간·물자를 소모하지 않는다. 뒤쪽 UI는 패널을 닫기 전까지 입력을 막는다.

## 구현 범위

- 시안의 왼쪽 어두운 작업 패널, 선택 행 강조, 오른쪽 대원 종이 카드 구성을 따른다.
- 고정 4인 예시 대신 현재 합류한 대원을 동적으로 생성한다. 4행보다 많으면 세로 스크롤한다.
- 현재 체력·초상·이름을 실제 데이터에서 보여준다. 아직 없는 피로 수치를 만들어 표시하지 않는다.
- 짧은 휴식 30분, 수면 120분은 Inspector로 수정 가능한 **UI 검토용 가정**이다. 회복량·피로·소모품 세부 규칙은 미확정이다.
- 시작 버튼은 휴식 예약을 현재 정착지 화면에 등록한다. 대원 카드는 예약 상태로 바뀌고, 같은 대원 중복 배정은 막는다. 시간 진행 버튼에서 예약 목록을 확인할 수 있다.
- 시간 진행, 완료·회복 처리, 예약 취소/변경, 저장 및 다른 씬으로의 예약 유지 기능은 다음 작업이다. 시안의 ‘휴식 시작’ 버튼 문구는 유지하며 실제 등록 결과는 ‘휴식 예약’으로 안내한다.

## 편집 위치

- `Assets/Prefabs/Settlement/RestWorkPanel.prefab`: 패널·선택 정보·버튼.
- `Assets/Prefabs/Settlement/WorkAssigneeRow.prefab`: 재사용 가능한 대원 행.
- `Assets/Prefabs/Settlement/SettlementScreen.prefab`: 침대와 패널 연결.
- `Assets/Scripts/FrontEnd/SettlementWorkPanel.cs`: 조회·선택·예약 및 중복 방지.
- `아트/휴식담당자-v1/개별-PNG`, `PSD/rest-work-layout.psd`: 기존 종이 원본 및 별도 아이콘, 레이어 배치 PSD. UI 문구는 Unity Text로 편집한다.

원본과 차이: 현재 승인된 정착지 배경을 고정했으므로 왼쪽 침대 일부는 패널에 가려진다. 원본 그림 속 침대 하이라이트를 새 배경에 그대로 붙이지 않았다. 인원·체력은 실제 선택값이다. 기존 폰트와 종이 자산을 재사용하고, 달/시계 아이콘은 시안에서 분리했다. 작은 아이콘의 해상도 복원 작업은 아니다.

## 정렬 추가 보완

말의 스프라이트 기준점을 두 발 사이로 설정하고 발판 중심과 연결했다. 말 이미지를 교체해도 같은 기준점을 사용한다. 시설 말풍선은 아이콘 하단 가운데에 anchor/pivot을 맞추고 10px 간격으로 둔다.

## 검증

Unity Editor에서 침대 클릭, 실제 대원 목록, 선택 전 확정 잠금, 휴식 종류 변경, 우측 상세 연동, 닫기 시 무변경, 예약 등록과 중복 방지, 패널 뒤 입력 차단, 글자 높이를 검사했다. 선택·등록 후 시간 및 물자 불변을 확인했다. 실행 파일 빌드는 생략했다.

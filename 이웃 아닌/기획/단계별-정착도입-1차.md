# 단계별 정착 도입 1차

2026-09-23 사용자 승인: 처음부터 모두 해금된 구조를 수정하고, 시설을 마련하며 단계별로 학습한다. 배경은 더 어둡고 폐허다운 느낌으로 조정하고 셰이더 표현을 강화한다. 이전의 즉시 정착·기본 재료 지급 흐름보다 이 지시를 우선한다.

## 실제 연결한 흐름

| 저장 단계 | 행동 | 완료 후 열리는 것 |
| --- | --- | --- |
| 0 | 주변 확인 · 10분 | 남은 상자 수색 |
| 1 | 상자 수색 · 10분 | 목재2·부품3·천2·밧줄1 발견, 잠자리 정리 |
| 2 | 잠자리 정리 · 20분 | 침대와 시간 진행 |
| 3 | 담당자에게 실제 휴식 배정 후 시간 진행 | 공용 창고·개인 가방·기록 |
| 4 | 창고를 열어 물자 확인 후 닫기 | 작업대 정리 |
| 5 | 작업대 정리 · 20분 | 첫 제작: 간이 못 |
| 6 | 간이 못을 예약하고 시간 진행으로 완료 | 찬장·조리대 정리 |
| 7 | 찬장·조리대 정리 · 20분 | 식재료4·물2·목재2 발견, 조리 |
| 8 | 따뜻한 식사를 예약하고 시간 진행으로 완료 | 일반 제작·조리·물품 사용·외출 준비 |
| 9 | 첫 외출에서 귀환 | 방문자·영입·시설 개선·거주 확장 |
| 10 | 자유로운 정착 생활 | 기존 비전투 기능 사용 |

새 게임은 공용 재료·보급품·탄약이 0이며 이동으로 지친 두 사람의 체력은 최대치보다 1 낮다(최소1). 출처 없는 제작 프리팹 기본 수량을 새 게임에 적용하지 않는다. 발견 물자는 활동 기록에 출처와 수량을 남기고 저장 단계가 전진하므로 다시 지급하지 않는다. 초기 정리는 소모품 없는 고정 시간 행동이다.

완료 조건은 창을 열거나 예약하는 것과 구분한다. 휴식·제작·조리는 실제 완료가 필요하다. 취소하면 해당 단계에 남는다. 첫 창고 확인은 열고 닫는 것으로 배운다. 도입 중에는 첫 작업과 관계없는 제작법·조리법·시설 개선을 감추고, UI 외 진입도 해당 화면의 Open에서 차단한다. 식재료를 먼저 먹어 도입이 막히는 것을 막기 위해 물품 사용은 첫 조리 이후 열린다. 설정·저장·불러오기는 처음부터 사용할 수 있다.

## 배경 표현

`Assets/Shaders/RuinedRoom.shader`와 `Assets/Settings/RuinedRoom.mat`를 사용한다. URP 2D 조명을 유지하며 채도를 낮추고 차가운 암부, 가장자리 음영, 벽의 불규칙한 어두운 얼룩, 고정된 미세 입자를 추가했다. 시간에 따라 입자가 깜빡이지 않는다. 방 배경에만 셰이더를 적용하므로 UI 종이나 글씨를 함께 어둡게 처리하지 않는다.

정착지 전체광을 낮추고 벽등과 출입구 주변광의 대비를 높였다. 동일 배경 재질을 폐상가 방 전환에도 연결했다. 개별 물체 차폐·노멀맵·새 잔해 원화·시설 정리 전후 그림은 아직 없으며, 밝기/질감 변경을 새 폐허 원화 제작으로 간주하지 않는다. 원본 PNG와 기존 배치·카메라 비율 대응을 유지했다.

## 남은 범위

현재는 세 거점 공통의 첫 학습 흐름이다. 장소별 첫 문제와 내부 원화의 차별화, 정리 전후 잔해 변화, 인물 대화·이름·외형 다양성, 자율 생활 행동, 도입 건너뛰기는 후속이다. 첫 수색·시설 정리는 안내 버튼으로 실행하며 현장 오브젝트 선택과 작업 동작 연출은 아직 통합하지 않았다. 전체 비전투 콘텐츠 완성으로 보고하지 않는다.

프리팹 재생성 시 기존 생성기 이후 `BuildSettlementIntroduction.Run`을 실행한다. 이전 `PolishSettlementPresentation`은 구형 조명값이므로 이 생성기가 마지막이어야 한다.

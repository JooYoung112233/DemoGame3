# 실루엣 말 이동 시연 — 2026-09-22
작업대 → 만들 수 있는 작업(예: 간이 못) → 담당자 → 작업 시작.
지정된 대원의 말/받침대/접지 그림자가 함께 열린 통로를 따라 이동한다. 몸만 최대 2.5도 기울며 걷기 그림은 추가하지 않았다. 도착 시 자세 복원과 작은 작업 아이콘 표시. 예약 취소 시 원래 대기 자리로 복귀.
기존 제작 예약 기능에 시각적 이동만 붙였다. 작업 완료/시간 소비 기능을 추가한 것은 아니다. 다른 대원은 정지한다.
SettlementWorld.prefab의 SettlementPawnMotion에서 Speed, LeanDegrees, AisleY, WorkbenchStop_0/1을 편집할 수 있다. 현재 생존지의 기존 두 말에 적용한 시연이며 다인원 동적 생성/경로 충돌 회피/다른 시설/탐색 이동은 미적용.
기존 PNG와 PSD를 그대로 사용하며 새 이미지 자산 없음.
검증: 실제 UI로 예약 후 정확한 발판 도착점, 대기 대원 정지, 작업 아이콘, 추가 시간·보급품 차감 없음. 취소 콜백으로 원점 복귀/표시 해제 확인.
녹화 후 자동 클릭 검증에서 제작 예약 취소 버튼이 InputBlocker에 막힌 사례가 있어 해당 취소 검증은 버튼 콜백 호출로 분리했다. 취소 버튼의 실제 클릭 경로는 별도 확인 필요.
시연 GIF: Assets/Screenshots/Movement/workbench-movement.gif. Unity 카메라 프레임을 녹화한 960×540 미리보기이며 실제 게임 기준은 1920×1080.

## 추가 수정
- 작업대 캡션의 앵커/피벗을 좌상단으로 통일하고 아이콘 위 10px 간격으로 배치. 머리 가림 제거.
- WorkBubble.prefab: 대원 머리 위에서 좌우로 비켜 배치한 작업명·수량·예상 분 말풍선. 기존 종이/도구 PNG 재사용. 새로운 그림 없음.
- 도구 아이콘 ±9도, 몸 ±0.85도 작은 반복 움직임. 이동 중 말풍선 숨김, 취소 시 제거.
- 시간은 Order.Minutes를 표시한다. 실제 작업 시간 진행이 미연결이므로 임의 카운트다운 없이 ‘예상’ 표기.
- 물품/제작 분류 변경 시 유효 담당자 유지. 수량은 물품 변경 시 1로 초기화. 새로 창을 열면 담당자 선택부터 시작. 사망/다른 작업 배정 등 유효하지 않으면 물품 변경 시 선택 해제.
- VerifyPawnMotion.Record: 물품 전환·분류 전환의 담당자 유지, 작업 확정, 이동·말풍선·취소 복귀 검증 통과.

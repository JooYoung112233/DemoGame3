# 탐험 배정 표시와 턴 흐름 1차 — 2026-09-25

## 요청

> "탐험할때 턴 지나가거나 뭔가 할당했거나 하는 인터렉티브가 좀 너무 없다. 복도로 넘어갈때도 뭔가 다음턴에 넘어간다라는 표기로 … 정착지에도 그런식으로 할당했다라고 인터렉티브 하는게 좋아보이는데"
> "대원 머리위 말고 그 뭐 예를들어 상자 위에나 탐색지 위에? 그래야 아 이번턴에 거기 넣었구나 하잖아. 그리고 턴제 개념이 눈에 잘 안 띄긴 해 탐험할때. 그래서 뭔가 실시간 턴제느낌으로 해줄수 있나? 턴종료버튼이 아니여도"

## 사용자 결정 (시안 확인 뒤)

- 표시는 대원 머리 위가 아니라 **맡긴 곳 위**에 둡니다(상자·탁자·문, 정착지 시설).
- 턴 흐름은 **추천안: 한 번 + 계속 진행**입니다.
  - '턴 진행'은 1턴이며, 약 1초 동안 턴이 흐르는 모습을 보여 줍니다.
  - '계속 진행 ▶▶'을 켜면 버튼을 누르지 않아도 턴이 이어집니다. 경고·발견·수색 완료가 나오면 저절로 멈춥니다.
  - 첫 방문(튜토리얼)에는 1초 연출만 넣습니다.
- 문을 누르면 **다음 턴에 이동을 예약**합니다(두 번째 방문부터).
  - 문 위에 '다음 턴 · 복도로 이동'이 뜨고, 턴이 넘어갈 때 걸어서 이동합니다.
  - 첫 방문은 지금처럼 바로 이동합니다.

시안(계획용 그림, 승인 UI 시안 아님): [탐험-배정표시와-턴흐름-시안](탐험-배정표시와-턴흐름-시안/)
- 01 수색을 맡긴 사물 위 표시
- 02 이동 예약
- 03 정착지 시설 위 표시
- 04 턴 흐름 세 장면
- 05 참고용 B안(시간이 늘 흐름). 채택하지 않았습니다.

## 만들 것

| 무엇 | 내용 |
|---|---|
| 맡긴 곳 표시 | 종이 핀 모양 동그라미 + 담당 대원 초상 + 할 일 아이콘 + 진행 고리 + 짧은 글(예: '수색 · 1/3 → 2/3'). 맡겼을 때만 뜨고 끝나면 사라집니다 |
| 탐험 | 수색은 그 사물 위, 관리실 선반은 관리실 문 위, 흔적 관찰은 흔적 위에 표시합니다. 귀 대기는 문 옆 작은 표시를 씁니다(문에는 이미 '귀 대는 중'이 뜸). 이동을 예약하면 문 위에 모든 대원이 뜨고, 다른 표시는 숨깁니다 |
| 정착지 | 휴식은 잠자리, 조리는 식수·조리, 제작·복구는 작업대, 연구는 연구대, 창고 확장은 창고 위에 표시합니다. 남은 시간을 고리로 보여 줍니다. 대원 머리 위 작업 표시는 없앱니다 |
| 턴 연출 | 약 1초 동안 'N턴 · 10분 흐름' 띠를 띄우고, 시계를 넘기고, 소리 난 곳에 파문을 그리고, 고리를 채웁니다. 규칙·결과는 바꾸지 않습니다 |
| 계속 진행 | '턴 진행' 위의 켜고 끄는 버튼입니다. 경고, 다음 턴 조우·위험도 상승 예고, 수색 완료, 들린 것, 방 이동, 창이 열림, 맡긴 일 없음이면 멈추고 '멈춤 · 이유'를 보여 줍니다 |
| 이동 예약 | 두 번째 방문부터 문 확인이 '다음 턴 이동 예약'이 됩니다. 같은 문을 다시 누르면 취소할 수 있습니다. 잠긴 문은 지금처럼 여러 턴을 씁니다 |

## 작업 방식

- 다른 에이전트가 탐험 턴 파일을 수정하고 있습니다(장도윤 이야기, 등신대 그림). 그래서 기능은 **새 파일**로 만들고, 기존 파일에는 한두 줄 연결만 넣습니다(턴 진행 앞 이동 예약 실행, 문 확인의 예약 전환).
- 코드는 준비 폴더에서 Unity 밖 컴파일 검사를 통과시킨 뒤, 편집기가 비어 있을 때 한 번에 넣습니다.
- 아이콘은 코드로 그리는 벡터 도형이라 새 그림 파일이 없습니다. 초상은 기존 초상을 씁니다.
- 승인 UI 시안이 없는 임시 배치입니다. 시안 재현이라고 보고하지 않습니다.

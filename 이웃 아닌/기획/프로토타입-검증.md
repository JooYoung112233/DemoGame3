# 첫 프로토타입 검증 — 2026-09-21

Unity 6000.6.0f1, demo5 전용 Editor에서 수행했다.

- 스크립트 컴파일 완료: 오류 없음.
- 규칙 검사 32개 통과: 이동/점유/AP, 수색 중복 방지, 완주, 조기 철수, 전멸, 시야 차단, 명중·빗나감의 탄약/AP/소음 소모, 거리·사물 엄폐 보정, 방어, 유인 만료, 증원, 조명 하한.
- Play Mode에서 실제 uGUI Button.onClick을 호출하는 16개 검사 통과: 원정 시작부터 2개 보급품 회수, 두 대원 귀환, 성공 정산까지. 실제 마우스 장치 입력을 자동 재생한 검사는 아니다.
- 1920×1080 카메라 출력 이미지 확인: 한글 출력, 대원/소품 구분, 보드·상태·로그·행동 버튼 표시.
- Windows Standalone 빌드: Unity BuildReport `Succeeded`, Editor 로그 `Build Finished, Result: Success.` 확인.
- 빌드 호출은 Pipeline 30초 응답 제한에 걸렸지만 에디터 내부 빌드는 완료되었다. 재빌드 없이 실제 BuildReport로 확인했다.

검증 범위는 단일 임무의 규칙과 화면/빌드다. 여러 원정의 장기 밸런스, 물리 마우스 조작, 다른 OS의 한글 폰트는 별도 확인이 필요하다. 현재 감염자는 근접형만 존재하므로 원거리 적이 플레이어를 사격하는 상황은 구현 범위 밖이다.

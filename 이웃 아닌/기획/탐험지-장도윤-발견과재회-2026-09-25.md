# 이웃 아닌 — 장도윤 발견과 재회

상태: **사용자 요청으로 장도윤 대화를 하단 다이얼로그와 선택지 방식으로 변경하고 Unity 실행·화면 검수를 완료했다.** 기존 발견·선택·귀환·저장·재회 흐름을 유지한다. 최신 검증·화면과 변경 전 검수 이력을 아래에 구분한다.

기존 [숨은 NPC 발견 시나리오](탐험지-숨은NPC-발견시나리오-2026-09-24.md) 중 오락실의 장도윤만 연결한다. 기존 오락실·복도·보관실 배경과 전투 규칙을 유지하며 새 방이나 원화를 추가하지 않는다.

## 최신 사용자 수정 — 하단 다이얼로그

사용자 요청: **“대화는 다이얼로그 형태, 선택지.”** 큰 중앙 정보창에서 긴 설명과 선택 카드를 한꺼번에 읽던 대화 배치는 이전 구현으로 남기고, 관찰 이후 장도윤 대화를 아래 방식으로 바꾼다.

- 배경에 옅은 딤을 두고 화면 하단 종이 다이얼로그에 화자와 짧은 대사를 표시한다. 기존 배경·NPC 실루엣·종이 리소스를 재사용하며 새 원화 작업은 아니다.
- 각 대화 구간을 1~3개의 짧은 대사로 나눈다. 본문 영역 클릭 또는 `다음` 버튼으로 한 줄씩 진행한다. 서술은 `주변`, 이름을 모르는 인물의 대사는 `?`로 표시한다.
- 답할 차례의 마지막 줄에만 선택지 2개를 표시한다. 선택 중에는 `다음`으로 답을 건너뛸 수 없다. 명찰 확인·기록·대화 종료는 상황에 맞는 진행 버튼으로 처리한다.
- 명찰 확인 전에는 실명과 인물 그림을 숨긴다. 명찰 확인으로 Stage 2에 도달한 뒤 `장도윤`을 공개하며, 기록과 기존 이름 공개 기준도 유지한다.
- 조사 전의 담당 대원 선택·행동 배정은 조사 화면에 남긴다. 대화를 읽거나 답하는 동안에는 배경 사물 클릭·턴 진행을 차단한다.
- 적용 범위는 **현재 연결된 장도윤 대화**다. 배준·남기호를 포함한 NPC 3명 전체에 대화 콘텐츠를 연결한 것으로 보고하지 않는다.

## 이번 구현 흐름

| 단계 | 플레이어가 확인하는 내용 | 진행·공개 범위 |
|---|---|---|
| 흔적 | 두 번째 방문부터 장소 판 안내를 마친 뒤, 오락실의 `밀린 오락기`를 확인한다. | 첫 방문에는 등장하지 않는다. 조사 전 표식은 `?`이며 이름·인물 초상·등신대를 공개하지 않는다. |
| 관찰 | 살아 있는 참가 대원 1명에게 `흔적 조사`를 배정하고 `턴 진행`을 누른다. | 작업 장갑, 열쇠 소리, 사람의 목소리를 확인한다. 표식 이름은 `오락기 뒤의 사람`, 화자는 `?`다. |
| 첫 응답 | 기계를 건드리지 않고 말을 건네거나 떨어져 기다린다. | 대화 페이지를 진행한다. 이 첫 응답 두 버튼은 별도 장기 분기를 저장하지 않는다. |
| 이름 공개 | 명찰을 확인하고 대화를 잇는다. | `장도윤 · 시설관리`를 읽은 뒤부터 이름·초상·기존 공통 검정 등신대를 표시한다. 공구 가방을 복도에 두고 왔음을 듣는다. |
| 선택 | `천천히 얘기해도 괜찮아요` 또는 `우리가 들어온 입구를 알려준다`. | 거리를 존중했는지, 실제 지나온 입구 경로를 설명했는지 저장한다. 현재 복도의 안전을 보장하거나 즉시 탈출시키지 않는다. |
| 귀환 | 첫 대화를 마친 상태로 정착지에 돌아온다. | 귀환 기록을 남긴다. 기록 화면에는 직접 확인한 이름·대화·선택만 나타난다. |
| 다음 방문 | 귀환 이후 다시 오락실에서 만난다. | 이전 선택에 따라 첫 반응이 달라진다. 대사를 읽고 `기록하고 대화 마치기`로 닫히는 문을 받칠 방법과 도움이 필요하다는 후속 단서를 남긴다. |

대화를 닫거나 다른 방으로 이동해도 관찰·이름 공개·대화 단계는 초기화하지 않는다. 후속 단서는 다시 읽을 수 있다. 다른 방, 이동 중, 조우·전투 중에는 오락실의 NPC 말을 노출하지 않는다.

## 행동 비용과 기존 탐험 연결

- 흔적 관찰은 **대원 1명의 행동 1칸, 원정대의 턴 진행 1회, 관찰 자체 소음 0**이다. 같은 대원을 수색·지원·귀 대기와 중복 배정하지 않는다.
- 관찰은 **숨죽이기가 아니다.** 같은 턴의 다른 행동이 내는 소음과 기존 장소 시계·위험·조우 판정은 그대로 적용한다.
- 흔적 읽기, 담당 배정·해제, 대화 선택, 닫기·미루기, 기록 열람에는 턴이나 물품을 쓰지 않는다. 배정 클릭만으로 관찰이 완료되지 않는다.
- 관찰 완료 후 대화는 조우·발견물 처리 등 기존 창이 끝나고 현장 입력이 가능한 때 열린다. NPC 대화가 기존 턴 결과를 건너뛰거나 무효화하지 않는다.

## 기록과 저장 v15

`SavedNpcStory`에 진행 단계, 선택, 대화 페이지, 방문 횟수·첫 관찰 방문, 귀환·재회 여부, 관찰 후 대화 대기를 저장한다. 표시 이름이나 보상 물품을 DTO에 저장하지 않는다.

| Stage | 의미 | 허용 Page·Choice |
|---|---|---|
| 0 | 관찰 전 | Page 0 / Choice 0 |
| 1 | 관찰 완료, 이름 확인 전 | Page 0 또는 1 / Choice 0 |
| 2 | 이름 공개, 마지막 선택 전 | Page 2 / Choice 0 |
| 3 | 첫 대화 완료 | Page 3 / Choice 1 또는 2 |

이름은 Stage 2 이상에서만 공개한다. Stage 1 기록은 `오락기 뒤의 사람`으로 남긴다. `PendingDialogue`는 Stage 1·Page 0에서만, 귀환 표시는 Stage 3에서만, 재회 표시는 귀환 이후에만 유효하다. 관찰 방문은 두 번째 이상이며 현재 방문 횟수를 넘을 수 없다.

저장 버전은 **v15**다. v14 이전 저장은 기존 도입·장소 판·수색·물품 상태를 유지하면서 장도윤 기록을 미발견 기본값으로 만든다. 과거 방문 이력만으로 만남이나 이름을 추정하지 않는다. 기존과 같이 정착지 귀환 후 저장하며, 불러온 기록은 다음 탐험까지 유지한다. 컴포넌트가 없는 구성도 기본값으로 처리한다.

이번 다이얼로그 전환은 기존 `Stage`·`Page`·`Choice` 조합과 v15 저장 형식을 유지한다. 짧은 대사의 위치인 `DialogueLine`은 화면 표시용 상태이며 같은 구간에서 창을 닫았다 열면 유지한다. 저장 후 불러올 때는 **저장된 Stage/Page 구간의 첫 줄**부터 다시 읽는다. 이미 확정한 선택이나 기록 결과를 다시 실행하지 않으며, 대사 한 줄을 넘길 때 저장용 `Page`를 증가시키지 않는다.

## 아직 구현하지 않은 범위

- 후속 사건 `mall.held-door`: 두 사람이 문을 잡는 구조 행동, 나무 받침 사용, 공구 가방 회수와 보상은 미구현이다. 현재 재회는 **해당 사건으로 이어질 대화·기록 단서**까지만 제공한다.
- 장도윤의 자동 영입·정착지 합류·대원 전환·아이템 보상은 없다. 선택에 숨은 호감도나 적대·사망 판정을 추가하지 않았다.
- 배준·남기호는 기존 NPC 리소스와 프리팹 준비 상태다. 이번 작업에서 탐험지 발견·대화·후속 사건을 연결하지 않았다. 다른 NPC와 다중 인물 등장 일정도 별도 작업이다.
- 기존 인물·이벤트 초안 전체를 구현 완료로 간주하지 않는다. 이번 연결은 `mall.hidden_doyun` 1건이며 새 배경·지역 확장은 포함하지 않는다.

수색창에서 관찰 담당이 빈 대원처럼 보이던 표시를 보완했다. 담당자를 옮길 때 관찰 해제를 명시하고, 이동 안내가 있는 확인창은 불필요한 빈행을 줄여 기존 글자 크기를 유지했다. 검수 종료 후 Play를 멈추고 검수용 저장 경로를 해제했다.

## 변경 전 실제 Unity 화면

아래 캡처는 큰 중앙 정보창을 사용한 이전 구현 이력이다. 당시 초상 중복 크롭과 좌측 쏠림을 수정하고 중앙 종이 크기와 선택 카드 대비를 다듬었다. 최신 하단 다이얼로그 시안·검수 화면으로 사용하지 않는다. 별도 새 원화는 만들지 않았으며, 5:4와 울트라와이드 화면은 기존 게임의 화면비 유지 정책을 따른다.

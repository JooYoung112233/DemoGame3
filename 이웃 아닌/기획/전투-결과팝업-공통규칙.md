# 전투 결과 팝업 재구성 · 공통 UI 규칙 적용

2026-09-24. 첫 카드형 결과창은 공통 규칙 미적용으로 사용자에게 반려됨. 아래 프레임과 실제 캡처가 최신 구현이다.

- PopupHeading.prefab 재사용: x80/y32, 540×72, '탐험 · 전투 결과'.
- PopupBackgroundHud를 전투 Workspace에도 적용. 결과창 활성 중 전투 HUD alpha=0, 종료 시 이전 alpha 복원. 기존 팝업의 검은 딤 97% 적용.
- 귀환 보고와 같은 종이 프레임·footer-paper 카드 질감 사용. 복귀 버튼 x80/y974, 410×76, 외곽 하단 기준선 1050.
- 대원별 초상, 체력 전후/순변화, 1 HP당 1칸, 현재 체력에 따른 행동 가능/위험 상태, 사용 물품 표시. 상태 문구는 현재 체력을 설명하며 새로운 부상 시스템이 아니다.
- 오른쪽 소모/획득은 전투 시작 시 개인 가방 스냅샷과 종료 수량 차이를 아이콘·물품·소유자·증감으로 표시. 현재 전투 보상은 없으며, 기존 수색 물품은 신규 획득에 합산하지 않는다.
- 목록은 ScrollRect, 기본 두 대원 및 탄약/붕대 3행이 잘리지 않도록 배치. 빈 목록 문구 제공.
- 기존 승리/철수/패배 제목, 결과 처리, 탐험 1턴 및 소음 반영, 복귀 버튼 기능은 유지.

구현: BattleResultSummary.cs, BattleResultPanel.prefab, AgentScripts/BuildBattleResultSummary.cs. 재적용은 BuildBattleResultSummary.Run.
검증: 컴파일 성공, VerifyFieldBattle.Enter/BeginShowcase/ItemFlow/ResultAfterItems 성공. 실제 치료 1회 및 탄약 4발 소모 후 결과 표시. VerifyResultFrame.Run에서 제목/버튼 좌표·HUD 숨김/복원·붕대 소모 행·스크롤 손잡이 범위 통과.
실제 화면: Assets/Screenshots/Battle/result-common-frame.png. 이전 result-summary-v2.png는 반려된 중간 화면이다.
검수 중 별도 전투 작업의 Unity 6.6 GetInstanceID 컴파일 오류 한 곳은 GetEntityId().GetHashCode()로 호환 수정했다.

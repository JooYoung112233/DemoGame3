# 연결된 방과 턴제 탐험

현재 구현: [오락실 ↔ 복도 이동](방이동-구현.md). 단체 이동당 1턴과 왕복 보존까지 검증했다. 아래 다중 방·수색·조우는 후속 기획이다.

후속 화면 명세: [인게임 UI 연결도](UI연결도/index.html) · [버튼별 목적지·조건·취소 규칙](UI연결도/버튼연결명세.md).

2026-09-22. 사용자는 UI 전체 시안을 긍정적으로 평가하고, 한 방에 머무르는 구성에서 연결된 방 구조로의 확장을 제안했다. 탐색은 턴제로 진행하는 방향이다. 아래 방 수·턴 비용·동시 행동은 검토안이며 구현 완료 또는 수치 확정이 아니다.

## 유지할 기준

- 승인된 종이 질감, 약간 위에서 내려다보는 정면 구도, 실루엣 말과 흰 받침대를 유지한다.
- 오브젝트 클릭 → 작업과 담당자 지정 → 비용 확인 → 실행 흐름을 유지한다.
- 탐험 화면에는 전투 격자를 상시 표시하지 않는다. 조우 때 기존 양 진영 3×3 전투로 전환한다.
- 대원 목록과 개인 가방은 인원 증가에 대응한다. 초기 2명을 최대 인원으로 취급하지 않는다.

## 방 구조 제안

탐험 장소 하나를 서로 연결된 작은 방 4~6개로 구성한다. 복도·잠긴 문·우회 통로로 선택을 만든다. 첫 검증은 입구, 매장, 창고, 관리실 네 구역이면 충분하다.

입구 → 매장 → 창고가 기본 경로다. 매장 → 관리실 → 창고의 우회 경로를 둘 수 있다. 잠금 해제 도구·단서는 길과 수색 우선순위를 바꾸며, 필수 귀환 경로는 갑자기 봉쇄하지 않는다.

화면에는 현재 방을 크게 보여주고, 문 방향과 작은 연결 지도로 주변 방을 알린다. 미방문 방은 실내 물자와 적을 보여주지 않는다. 방문 여부·남은 수색도·확인한 위험을 지도에 구분한다. 큰 통짜 건물 그림 대신 같은 크기 기준의 방 배경, 출입구, 분리 소품을 재사용하는 안이다.

생존지도 침실·작업실·창고 등 연결된 공간으로 확장할 수 있다. 다만 생존지 운영까지 탐험과 같은 턴 규칙을 적용할지는 별도로 정한다.

## 탐험 턴 제안

개별 대원이 행동할 때마다 세계 시간이 흐르는 방식 대신, 한 탐험 턴에 각 대원의 행동을 배정하고 한 번에 진행한다. 망보기·동료 지원은 수색과 같은 시간에 수행된다. 미배정 대원은 대기 상태로 표시한다.

첫 검증에서는 원정대가 같은 방에 머물며 함께 이동한다. 대원별 역할은 나누되 방마다 원정대를 흩어 놓는 기능은 별도 확장으로 남긴다. 이 제한은 다인원 목록의 확장과는 별개다.

| 행동 | 검토용 비용 | 의미 |
| --- | --- | --- |
| 인접 방 이동 | 원정대 공통 1턴 | 문 상태·확인한 위험을 보고 이동 |
| 빠른 수색 | 담당자 1턴 | 작은 범위, 소음이 커질 수 있음 |
| 보통 수색 | 담당자 2턴 | 시간·발견·소음의 중간 선택 |
| 정밀 수색 | 담당자 3턴 | 더 살피지만 체류 시간이 길어짐 |
| 망보기·조명 지원 | 수색과 동시에 매 턴 | 조우 예고나 수색에 도움, 장비 조건은 별도 데이터 |

1턴을 몇 분으로 볼지는 미정이다. 원정 이동 시간·현장 탐험 턴·전투 시간을 하나의 시간 장부로 연결하되 같은 행동 시간을 중복 차감하지 않는다.

여러 턴 작업은 남은 턴을 보여주며 한 턴마다 중단·계속 여부를 판단할 수 있다. 완료 전에는 미리 보상받지 않는다. 중단한 수색도는 보존하는 안을 우선 검토하되, 방식 변경으로 같은 물체의 보상을 반복 획득하지 못하게 한다.

## 위험과 조우

턴을 확정했을 때만 작업·소음·시간과 위험 판정을 갱신한다. UI 열기·짐 확인·행동 배정·취소는 턴을 소비하지 않는다. 여러 대원의 행동을 확정해도 환경 위험 판정은 원정대 턴당 한 번이다.

소음과 장소 위험에 따라 옆방의 발소리 등 징후를 먼저 주고, 진행·우회·철수의 판단 여지를 둔다. 모든 이동마다 무조건 전투시키지 않는다. 조사한 방을 돌아갈 때 수색 상태와 문 개방 상태는 유지한다.

전투 중 탐험 작업은 일시 정지한다. 종료 뒤 생존 대원과 남은 물품, 방 상태를 복원하고 계속 수색하거나 귀환한다. 전투 턴마다 탐험 조우를 다시 뽑지 않는다.

## 필요한 UI와 리소스 변화

- 현재 방 이름·연결 지도·문 표시 및 이동 비용.
- 대원별 이번 턴 행동·남은 작업 턴·장비 조건을 보여주는 공통 카드.
- 이동 시 진행 중인 작업 중단 여부와 손실을 미리 안내.
- 턴 진행 버튼과 소음·위험 예고, 마지막 턴의 결과 알림.
- 기존 개인 가방·발견물 배분·분리 진형 전투 UI 재사용.

이번 기록은 방향 제안이며 Unity 코드·씬이나 승인 원화를 변경하지 않았다. 다음 공간 시안은 한 장소의 연결된 방과 문, 현재 방에 맞는 턴 배정 UI를 함께 보여주는 구성이 적합하다.

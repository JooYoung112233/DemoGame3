# 챕터 1 전체 점검

2026-09-09 · 사용자가 v3 방향을 승인한 뒤 진행한 원화·합성·상태 전환 점검. 현재 미리보기 범위에서 진행을 막는 오류는 발견하지 않았다. 원화 재생성이나 배치 변경 없이 이름표와 기준 문서만 보완했다.

## 수정한 것

- 360px/320px의 편의점 전체 화면에서 ‘냉장고’ 이름표가 사진 상단에 잘렸다. 위쪽 공간이 부족할 때만 아래에 표시하도록 수정했다. 창 크기를 바꿔도 재계산하고, 큰 화면에서는 원래 위쪽 위치로 돌아온다.
- 공간 일관성 문서가 v1 배경을 현 기준으로 안내하고, v2 이력에 이전 창틀 가림 방식이 남아 있었다. 현재 v3 베이스와 통합 배치를 명시하고, 초기 제작 기록을 구분했다.

## 확인 결과

| 범위 | 확인한 내용 | 결과 |
| --- | --- | --- |
| 6장면·33상태 | 주방, 첫 그림, 편의점, 별똥이, 편지, 저녁의 확대·전체 합성 | 누락·엉뚱한 자세·남은 앞벽 가림 없음 |
| 고정 배경 3개 | 편의점·집의 보호 영역, 캠핑카 실내/운전석 원본 픽셀 비교 | 보호 영역 모두 일치 |
| 소품·포즈 | 실제 알파, 파일 경로, 캔버스 경계, 손/발과 가구 위치 | 통과. 조사·교감·서랍 확인·읽기는 별도 자세 |
| 작은 화면 | 736/360/320px의 상태 총 99회, 클릭 대상 30회, 이전·다음 왕복 81회, 확대 왕복 96회 | 이름표 수정 후 잘림·누락·가로 넘침·스크립트 오류 없음 |
| 연속 조작 | 장면을 빠르게 교체한 뒤 최종 합성 픽셀 비교 | 일반 선택과 일치 |
| 편지 본문 | 사용자 원문 8문단, 읽기 4페이지와 이동 | 원문·순서 유지 |

33개 상태를 장면별 접촉 시트로 비교하고 주요 확대 화면을 별도로 살폈다. 사진이 책이나 별똥이에 집중하는 장면에서 주변 인물 일부가 프레임 밖으로 나오는 것은 해당 구도에 따른다. 대화 중심 구도에서는 수혁·소이 얼굴과 식탁이 들어오는지 확인했다.

## 작은 다듬기로 남기는 것

- 책·컵·연필의 큰 확대에서는 원래 작게 추출한 자산의 해상도와 외곽선 차이가 보인다. 사용자가 보류한 고해상도 정리 때 다듬는다.
- 새 전신 포즈와 기존 식탁 포즈의 붓결·윤곽선에는 미세한 차이가 있다. 지금의 배치와 색 기준을 유지하면서 부분 작화로 맞추면 된다.
- 휴식·기록은 현재 고정 자세 시안이다. 전용 포즈를 더 만들지는 이번 점검에서 결정하지 않았다.

이번 검수는 원화와 미리보기 대상이다. Unity 적용, 저장·날짜·행동력, 미니게임과 소음 확률은 기존 계획대로 후속이다.

## 재검사 자료

- `art/chapter01/gallery-qa/report.json`: 기존 상태·레이어·편지 검사.
- `art/chapter01/gallery-qa/review-report.json`: 작은 화면·이름표·클릭·왕복·빠른 전환 검사.
- `art/chapter01/gallery-qa/asset-review-report.json`: 원본 픽셀·베이스 공유·새 자세·알파 확인.
- `tools/review-ch01-gallery.cjs`, `tools/review-ch01-assets.py`: 재실행 가능한 전체 점검. 통합 빌더 실행 후 브라우저 점검, 자산 점검 순으로 실행한다. 자산 점검은 브라우저가 캡처한 상태 화면에서 비교용 시트를 만든다.

검수 PNG는 로컬 `gallery-qa`에 있으며 Git에는 검사 스크립트와 결과 JSON을 보관한다.

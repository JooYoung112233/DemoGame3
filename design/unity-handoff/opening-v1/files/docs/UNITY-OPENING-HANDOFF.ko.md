# Unity 개발 인계 · 시작 화면과 첫 부름

2026-09-10. 사용자와 확인한 콘티·UI 선택·해상도를 보관한다. 실행 구현 완료 문서가 아니다. 현재 원본 파일과 별도로 [고정 보관본](../design/unity-handoff/opening-v1/README.ko.md)에 선택한 이미지·PSD·런타임 PNG·폰트·좌표 기록을 복사했다.

**실제 개발용 장면별 상세 색인:** [챕터 0~1 콘티·원화·UI 연결표](CH00-01-STORYBOARD-ASSET-MAP.ko.md). 장면별 이미지, 원본 위치·크기, PSD, 좌표·가림 순서, 표시 조건과 다음 장면을 기록했다. [기계 판독 데이터](../design/unity-handoff/storyboard-assets-v1.json)도 함께 보관한다.

## 확정한 제작 기준

- 개발 환경: Unity 6.6. 기본 게임 해상도 **1920×1080, 16:9**.
- UI 화풍: **A — 크림색 활자와 얇은 선, 절제된 선택 표시**. B는 비교 이력이다.
- 편집용 UI PSD는 3840×2160, 실제 배치·글자 크기·검수 화면은 1920×1080 기준. 인게임 이미지는 문자 없는 UI PNG와 텍스트로 조합한다.
- 일반 대화는 약한 배경 블러 + 좌우 인물 일러스트 + 하단 대사창. 수혁·소이 대화 기준은 왼쪽 수혁 / 오른쪽 소이다. [대화 기준 시안](../design/dialogue/dialogue-layout-v1.png)을 보존한다.
- **대화용 인물의 표정·행동 원화는 대사집이 나온 뒤 제작한다.** 현재 평면 대화 시안은 완성된 분리 인물 원본이 아니다.
- UI는 챕터 0부터 장면 순서대로 만들고 합성 화면을 보며 하나씩 선택한다. 이후 장면까지 일괄 승인된 것이 아니다.

## 현재까지 합의한 시작 콘티

| 순서 / 상태 ID | 보이는 화면 | 자동 진행 / 사용자 입력 |
| --- | --- | --- |
| 1 · `C0-00.title` | 배경 + A 로고·시작·설정·종료. 저장이 있을 때만 이어하기 표시 | 시작 입력을 기다림. 최초 시작에 별도의 시작 확인창을 넣지 않음 |
| 2 · `C0-01.enter` | 시작 메뉴와 로고가 부드럽게 사라짐. 배경은 이어서 유지 | 시작 클릭 직후 자동 전환. 메뉴 재입력 방지 |
| 3 · `C0-01.call_reveal` | 하단 딤과 크림색 “수혁아.”가 자연스럽게 나타남 | 별도 클릭 없이 여기까지 이어짐. 음성은 미제작이며 음소거 상태에서도 문장은 표시 |
| 4 · `C0-01.await_advance` | 문장 유지, 작은 다음 표시·첫 입력 안내 | **대사를 읽고 클릭 또는 Space로 진행**. 자동으로 다음 대사를 넘기지 않음 |
| 5 · `C0-02.memory` | 가족 회상으로 자연스럽게 전환 | 다음 장면의 구체 UI 배치는 후속 검토. 새 표정·행동은 대사집과 연계 |

시작에서 부름까지 연속되는 흐름은 사용자가 확인한 내용이다. 세부 페이드 시간·겹침 비율·음성 재생 시점은 아직 정하지 않았다. 구현에서 조정 가능한 값으로 두고 실제 화면을 보며 결정한다.

구현 주의: ‘시작’을 누른 동일 입력이 `await_advance`까지 전달되어 첫 대사를 건너뛰지 않게 입력을 소비한다. 문장이 읽을 수 있게 표시된 뒤 새 입력부터 받는다. 다음 입력도 한 번만 처리한다. 저장 데이터를 실제로 덮어쓰는 경우의 확인 정책은 별도이며, 일반 시작에 불필요한 확인창을 추가하는 근거로 쓰지 않는다.

## 첫 부름 UI 배치

- 하단 중앙 대사: 기본 글자 크기 38, 크림색 `#F2E4C4`. 실제 파일별 위치와 여백은 [C0-01 데이터](../design/ui/ch00-01/C0-01.json)를 따른다.
- 하단 딤: 화면 높이 48%부터 시작하여 88%에서 최대 알파 205/255에 도달하는 smoothstep 그라데이션. 그림과 독립된 레이어다. 사용자의 글자 가독성 보강 요청을 반영했다.
- 다음 표시: 오른쪽 아래, 1920×1080 기준 28×28 PNG. 첫 입력 안내는 하단 중앙에 표시하고 이후 표시 여부는 장면별로 제어한다.
- 이 부름 시안에는 이름표·큰 대화 패널·좌우 인물이 없다. 일반 대화창 규칙을 폐기한 것이 아니며 짧은 도입의 표시 방식이다. 화자 공개 시점은 대사집에서 최종 확인한다.

## 배경·원화의 상태

사용자는 현재 손 원화가 너무 사실적이라고 지적했다. **현재 책·손 배경은 임시 검수용이며 최종 채택 배경이 아니다.** UI 선택과 배경 승인을 혼동하지 않는다. 이번 보관에서는 현재 시안을 그대로 남기고 배경 교체는 후속 작업으로 둔다. 시작에서 부름으로 배경이 이어진다는 흐름은 최종 배경을 교체한 뒤에도 적용할 수 있다.

기존 배경 1672×941을 큰 화면으로 맞춘 합성본은 고해상도 디테일이 복원된 원본이 아니다. PSD는 UI 레이어만 포함한다. 사진·배경·캐릭터를 PSD에서 전부 분리 편집할 수 있다는 의미가 아니다. PSD의 텍스트는 래스터 검수 레이어이며 런타임에서는 별도 문자열·폰트로 렌더링한다.

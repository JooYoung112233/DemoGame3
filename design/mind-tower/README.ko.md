# 마음의 등대 · 5층 시제품

Unity 적용 전 규칙을 확인하는 브라우저 시제품입니다. 임시 도형을 사용하며 기존 원화를 수정하지 않습니다.

## 조작

- 인접 칸 클릭 또는 방향키: 이동. 소이는 수혁의 이전 칸을 따라옵니다.
- 보호 / Space: 제자리에서 이번 턴 위험을 막고 빛을 1 회복합니다.
- 밀어내기 / X: 빛 1을 써서 이번 턴과 다음 행동을 보호합니다.
- 되돌리기 / Z: 직전 행동을 되돌립니다.
- 출구에 소이가 도착하면 기다립니다. 수혁도 돌아와야 다음 층으로 진행합니다.

## 단일 파일

저장소 루트에서 `node tools/bundle-mind-tower.cjs`를 실행하면 외부 파일 없이 작동하는 `preview-output/mind-tower/Live49-mind-tower.html`을 생성합니다. 브라우저 저장 정책에 따라 로컬 파일의 자동 저장은 제한될 수 있습니다.

## 비공개 배포

배포 전용 저장소는 `.tmp/mind-tower-site`에 있습니다. 해당 경로의 `.openai/hosting.json`에 기존 사이트 식별자가 있으므로 후속 배포 시 재사용합니다. 원화 저장소 전체를 업로드하지 않습니다.

5층 모두 완료 경로를 확인했습니다. 현재는 규칙 확인용 초기 난이도이며 장기 반복 재미, 최종 밸런스, Unity 구현은 후속 작업입니다.

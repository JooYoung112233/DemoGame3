# C0-01 · 서연의 부름

현재 상태: 사용자 구성 긍정 및 하단 딤 보강 요청 반영. 기존 손이 너무 사실적이라는 피드백을 기록한다. 현재 배경은 임시 합성용이며 최종 배경으로 승인된 것이 아니다. 배경 교체는 후속 원화 작업에서 진행한다.

시작 입력→메뉴·로고 페이드→딤·첫 부름 자동 표시→클릭/Space 대기→회상 전환 흐름과 파일 보관은 [Unity 개발 인계](../../../docs/00-제작관리/UNITY-OPENING-HANDOFF.ko.md)에 정리했다. 최초 시작에 별도 확인창을 띄우지 않는다. 실제 전환 시간은 구현 시 조정한다.

[합성 화면](review/C0-01-call.jpg) · [분리 PSD](psd/C0-01-call.psd) · [좌표·문구](C0-01.json)

최신 `docs/08-UI연출/DIRECTION-TOOLKIT.ko.md` 6절은 메뉴가 사라진 책·손 화면에 서연의 부름을 먼저 들려준 뒤 회상으로 전환한다. 이전 콘티의 완전 암전 안보다 이 연결을 우선했다. 새로운 대사를 쓰지 않고 기존 “수혁아.”를 사용한다.

- 시작 화면의 로고와 메뉴를 숨기고 책·손 장면을 유지한다.
- 하단 중앙의 크림색 명조 대사를 유지하고, 글씨 뒤의 딤을 더 짙게 보강했다. 화면 높이 48%부터 자연스럽게 시작해 88%에서 최대 불투명도 약 80%에 도달한다. 경계가 생기지 않는 smoothstep 그라데이션이며 별도 레이어로 조절할 수 있다. 일반 대화의 큰 패널과 좌우 인물은 이 짧은 부름에 사용하지 않는다.
- 오른쪽 아래 작은 진행 표시와 첫 입력 안내를 둔다. 읽는 동안 자동 전환하지 않고 사용자의 다음 입력 뒤 가족 회상으로 연결하는 구상이다.
- 이 시안에는 화자 이름을 표시하지 않았다. 대사집에서 결정할 인물 공개 시점을 확정한 것은 아니다.
- 인물 원화를 새로 만들지 않았다. 새로운 표정·행동은 대사집 이후 제작한다.

PSD는 3840×2160 투명 캔버스이며 하단 음영·호출 문구·진행 표시·첫 안내가 각각 분리되어 있다. 문자는 별도 래스터 검수 레이어이고 인게임에서는 JSON 문자열과 프로젝트 글꼴을 사용한다. 기존 배경의 확대는 검수 합성용이다.

게임 기본 해상도는 사용자 지정 1920×1080이다. 합성 JPEG·배치 좌표·글자 크기도 이 해상도가 기준이다. `runtime/1920x1080/C0-01/`에 딤 1920×1080과 진행 표시 28×28의 문자 없는 PNG를 별도로 제공한다. PSD만 2배 편집 크기를 유지한다.

PSD 병합 RGBA·4개 개별 레이어·납품 PNG 재합성 등 8개 검사를 통과했다. 음성·타이밍·입력·Unity 및 Photoshop 앱 직접 검증은 하지 않았다. 배치 선택 뒤 다음 화면인 가족 회상의 대화 UI를 검토한다.

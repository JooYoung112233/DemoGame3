# 미니게임 시안

| 상태 | 시안 | 실행 |
| --- | --- | --- |
| 현재 검토 기준 | `search-v2/` 진행형 탐색 | `node tools/serve-search-minigame-v2.cjs 8796` |
| 현재 검토 기준 | `cooking-v1/` 냄비 요리 | `node tools/serve-cooking-minigame.cjs 8798` |
| 이전 비교용 | `search-v1/` 단발 탐색 | V2가 장소 데이터를 참조하므로 보존 |
| 미채택 실험 | `fire-v1/` 화덕·부채질 | 캠핑카 요리에 연결하지 않음 |

명령은 저장소 루트에서 실행합니다. 시안 버튼과 도형은 정식 게임 UI·원화가 아닙니다. 새 제작은 현재 기준 폴더를 수정하거나 명확한 비교 목적의 버전을 추가하고 이 표를 갱신합니다.

# 조사·요리 상호작용 v0.1

상태: 리소스와 동작을 검토하는 시제품. Unity 프로젝트나 최종 게임이 아니다.

최신 방향은 [상호작용과 탐색 위험](../../docs/INTERACTION-DIRECTION.ko.md)을 따른다. 미니게임 상세 기획과 추가 구현은 보류한다. 캠핑카의 2개 대상은 기술 시연 범위이며 본편에는 생활 상호작용을 확장한다. 편의점 탐색에는 행동 중 발생하는 소음과 조건에 따른 후속 사건을 검토한다. 아래 타이밍·보상·비용은 기존 시제품의 시험 동작 기록이며 확정 기획이 아니다. 기존 브라우저 미리보기는 당시 명칭과 동작을 담고 있다.

## 동작

커서 올리기 또는 키보드 포커스 → 외곽과 위쪽 이름 표시 → 클릭 → 설명과 행동 버튼 → 필요한 경우 짧은 타이밍 조작 → 발견 → 가방에 넣기 → 조사 완료.

- 터치는 한 번 눌러 대상을 선택한 뒤 별도 행동 버튼으로 진행한다. 이름과 안내가 호버에만 의존하지 않는다.
- 기존 시제품의 편의점은 서랍·식품 선반·구급 물품장·문구 선반 4곳. 다른 가구는 장식이다.
- 걸린 서랍과 끼어 있는 색연필에만 탐색 미니게임을 사용한다. 기본 물자는 바로 확인하고 가져갈 수 있다.
- 문구 선반은 발견 후 색연필 상자로 표시한다. 획득 완료 상태를 재선택해도 물건이 중복되지 않는다.
- 발견 후 가져가지 않고 창을 닫아도 발견 상태를 유지한다. 미니게임을 다시 할 필요가 없다.
- 통조림을 가방에 넣은 뒤 캠핑카 주방을 선택하면 요리가 가능하다. 요리 후 통조림을 수프로 바꾼다.
- 소이의 스케치북은 색연필 보유 여부에 따른 연결 설명만 제공한다. 기존 폴라로이드 장면과의 실제 통합은 후속이다.

## 첫 시험값

탐색 왕복 2.5초, 요리 왕복 3.1초. 성공 구간 39~65%, 정밀 구간 49~55%. 선택 버튼을 누른 후 시작해야 표시가 움직인다. 판정 버튼은 마우스/터치와 기본 키보드 버튼 조작으로 사용할 수 있다.

탐색 실패는 조사 1분과 소음 1 증가. 재시도와 중단을 허용한다. 미니게임 중단에도 시도 비용을 적용해 무료 재시작 반복을 막는다. 요리 실패는 재료를 없애는 대신 조금 탄 수프를 만든다. 이 수치는 밸런스 확정값이 아니다.

가방은 시제품에서 4칸이며 시작할 때 비어 있다. 요리는 재료 1칸을 음식 1칸으로 바꾸므로 빈칸이 별도로 필요하지 않다. 여러 재료 조합, 아이템 버리기와 전역 하루/행동력은 아직 없다. 조사 시간은 본편 날짜와 연결하지 않은 미리보기 값이다.

## 데이터

- hotspots-v1.json: 배경 파일, 기준 크기, 다각형 조사 영역, 이름 기준점, 클릭 영역, 발견 전/후 이름, 보상, 행동 포즈 ID.
- interaction-model.js: 발견·획득·시도·성공·실패·취소·요리 재료 변경 상태 처리.
- ../../art/ui/interaction/: 하이라이트 SVG 6개.
- ../../art/characters/static-action-poses-v1.png: 수혁 요리/조사/앉기, 소이 앉기/올려다보기/그리기의 원화 시트.

포즈 시트는 배경이 있는 RGB 원화다. 현재 미리보기 화면에 캐릭터 포즈를 배치한 것은 아니다. 개별 분리와 가구 위치·조명에 맞춘 보정이 필요하다. 하이라이트 영역은 실제 실루엣보다 단순한 도형이며 배경에서 획득 물건을 지우는 작업도 아직 없다.

이름과 미니게임 UI는 코드/텍스트로 분리했다. 원화가 바뀌어도 문구를 다시 그릴 필요가 없다. 현재 프리뷰는 새로 열거나 다시 로드하면 초기화된다. 저장·이어하기와 내면 전투는 미구현이다.

## 검증

- 상태 테스트: 성공 경계, 실패와 재시도, 잘못된 판정값, 발견 상태 유지, 중복 획득 방지, 진행 중 대상 변경 차단, 요리 재료 필요, 4칸 가방 유지, 성공/실패 음식, 중단 비용.
- 실제 브라우저: 식품 선반의 외곽과 위쪽 이름, 통조림 획득과 완료 이름, 서랍 타이밍 성공, 발견 이름 변경, 캠핑카로 이동 후 요리 성공과 재료 소비, 중단 동작 확인.
- 360px과 736px 화면에서 선택 이름과 미니게임/버튼 배치를 확인했다. 360px에서는 작은 소품도 최소 44px 버튼 영역으로 선택한다.
- 이미지 파일의 픽셀 규격이나 최종 포즈 배치까지 검증한 것은 아니다.

테스트 실행: node tools/check-interaction-model.cjs

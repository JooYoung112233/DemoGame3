# 챕터 1 사건별 리소스 연결표

이 문서는 연출에 필요한 자산과 상태를 연결하는 제작표다. 날짜·행동력·확률의 최종 규칙이 아니며 모든 행을 하루 안에 실행하지 않는다. 순서와 대사는 1차 초안이다.

| 장면의 목적 | 조건 입력 후보 | 사용할 리소스·컷 | 남기는 결과 후보 |
| --- | --- | --- | --- |
| 소이가 그리고 싶은 것 알기 | 도입 대화 미열람 | 캠핑카 빈 스케치북 + 앉기 두 인물 | 색연필을 찾을 감정적 이유 |
| 필요한 물자를 찾기 | 편의점 도착, 조사 가능한 재고 | `store`: 입장 → 냉장고/문구 선반 | 회수 시도는 외부 미니게임 결과를 기다림 |
| 소리를 듣고 결정하기 | 조사 소음의 징후가 발생한 경우 | `store`: 같은 냉장고 → 입구 확대 | 더 찾기/잠깐 듣기/귀환 후보. 수치 확정 없음 |
| 함께 식사하기 | 해당 저녁 요리 상황이 열린 경우 | `kitchen`: 준비 → 고정 요리 자세 → 식사 | 같은 식탁의 짧은 교감 |
| 작은 바다를 그리기 | 색연필 획득 | `drawing`: 9개 대사, 빈 종이 → 파란 선 → 완성 | 첫 바다 그림·바다에 가자는 약속 |
| 빈손으로 돌아온 저녁 | 색연필 미획득 | `evening`: 빈 페이지 → 소이의 대답 | 물건 없이도 함께 이야기를 나눔. 약속 진행은 막지 않음 |
| 별똥이 합류 | 초반 합류 사건 미발생 | `byeolddongi`: 계단 밖 첫 만남 → 손 내밀기 → 러그 자리 | 합류 이후에만 내부 강아지 포즈 표시 |
| 서연의 부탁을 읽기 | 낡은 집 방문, 편지 1 미발견 | `letter`: 서랍 봉투 → 발견 자세 → 빈 서랍 → 분홍 편지 | 편지 1 발견·원문 읽기 기록 |
| 하루를 수혁의 말로 남기기 | 그날 선택 결과 | `evening`: 저널 + 앉은 수혁 | 현재 수록 문장은 색연필 미획득 경우의 초안 |
| 오늘은 쉬어 가기 | 휴식/상태 사건이 열린 경우 | `evening`: 약병·컵 → 잠들기 전 같은 공간 | 질병·피로 반영 방법은 이후 결정 |
| 다음 여행의 목적 남기기 | 첫 챕터 핵심 서사 확인 | `evening`: 다음 목적지 + 바다 약속 안내 | 챕터 2의 바다로 가는 동기 |

## 리소스 소비 규칙

같은 장소에서는 `base`를 그대로 둔다. 물건 회수는 해당 `id`만 숨기고 대화는 별도 텍스트로 교체한다. 클로즈업은 동일 합성 장면의 카메라 확대이며 새 배경을 불러오지 않는다. 컷 경계의 상태 저장·복원은 Unity 구현 단계에서 연결한다.

저널의 문구와 그림 보유 여부는 실제 결과별로 연결해야 한다. 통합 갤러리는 서로 다른 조건의 장면을 독립 선택하므로 한 회차의 인벤토리나 시간 연속성을 보장하지 않는다. 특히 미획득 분기 저널을 색연필 획득 회차에 그대로 쓰지 않는다.

소품에 하이라이트가 떠도 모든 상호작용이 언제나 열리는 것은 아니다. 최초 진입은 조사 대상 두 곳, 냉장고 선택 후에는 한 회수 대상만 보이는 샘플이다. 실제 대상 수는 사건·재고·이미 조사했는지에 따라 정한다. 아이템별 확률 값, 미니게임 성공 보정, 소음 발생 확률은 이 단계에서 임의로 넣지 않았다.

## 원문과 추가 초안

`first-letter-text.json`만 최초 기획서의 편지 1을 그대로 옮겼다. 나머지 미리보기 대사는 새 초안이다. 별똥이는 원문의 작은 유기견이며 현재 황갈색 외형은 시안이다. NPC 세진·하은과 바다·등대·천문대는 다음 챕터 범위로 남겼다. 마지막 반전과 관련된 복선을 1차 원화에 임의로 추가하지 않았다.

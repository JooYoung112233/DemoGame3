검사 / 남향 도트 v2 — 부위 형태와 걷기 연결 수정
2026-10-02

사용자 피드백:
  v1은 나쁘지 않지만 부위마다 자연스럽지 않음.
  추가 확인에서 부위 모양·연결과 움직임 둘 다 수정하도록 지시.
상태: 이 피드백에 대한 새 검토본. 사용자 최종 채택 전. Unity 미적용.

유지:
  기존 갈색 머리/얼굴, 내려다보는 남향 시점, 갈색 가죽옷,
  크림색 목도리, 왼쪽 철제 어깨갑옷, 오른손 검의 캐릭터 설정.
  v1과 승인된 고해상도 시점 원본은 보존.

형태 변경:
  어깨-팔꿈치-손목의 연결된 윤곽을 다시 그림.
  소매, 노출된 팔, 가죽 보호대, 가는 손목, 장갑이 구분되도록 조정.
  왼손 손가락과 엄지, 오른손이 검자루를 감싸는 방향을 추가.
  검과 손이 같은 손 위치를 사용하며 매 프레임 겹침을 검증.
  장화에 종아리, 발목, 발등, 앞코, 밑창을 다시 구분.
  첫 보정에서 가늘어진 다리/장화 폭은 기존 무게감에 맞춰 재보정.
  어깨갑옷을 팔에 더 가깝게 맞추고 목도리의 고리/꼬리 모양을 완화.

움직임 변경:
  걷기는 12프레임 x 80ms = 960ms 반복.
  두 길이가 일정한 다리 구간의 무릎 위치를 계산해 내려다보는 평면에 투영.
  지지 발은 접지 구간을 진행하고, 옮기는 발은 무릎을 굽히며 돌아옴.
  작은 골반/어깨 움직임, 팔꿈치/손목, 검의 작은 지연, 목도리 끝의 반응을 적용.
  머리와 얼굴의 도트 덩어리는 보존하며 위치 반응만 작게 적용.
  제자리 걷기 시안이므로 게임 이동 속도와 발 접지 검수는 Unity 단계에서 필요.

편집용 실제 원본:
  south-idle.aseprite: 128x160, 1프레임, 12레이어.
  south-walk.aseprite: 128x160, 12프레임, 12레이어, walk_south 태그.
  south-idle.png / frames/*.png: 원본 크기 RGBA.
  layers-idle/*.png: 정지 자세의 실제 분리 RGBA 레이어 12개.
  south-walk-sheet.png + .json: 가로 시트와 메타데이터.
  PSD는 제작하지 않음. 편집 가능성은 실제 Aseprite 레이어로 제공.

검수 출력:
  review/south-walk-preview.gif: 어두운 배경 합성, 4배 최근접 확대.
  review/south-idle-preview.png: 같은 배경의 정지 자세.
  review/idle-before-after.png: 왼쪽 v1 / 오른쪽 v2, 같은 4배 배율.
  확대본은 새 디테일이 있는 고해상도 원본이 아님.
  GIF의 반투명 알파 제약 때문에 배경 합성본을 검수용으로 사용.

제작/검증:
  draw_swordsman.py의 정수 픽셀/자세 데이터를 실제 Pixel MCP draw_pixels로 그림.
  Aseprite에서 레이어, 프레임, PNG/GIF/시트 저장과 내보내기를 수행.
  make_review.py에서 비교 이미지, 미리보기와 실제 분리 PNG를 제작.
  프레임 수/재생 시간, 잘림 없음, 검/손 겹침, 분리 PNG를 합친 결과가
  원본 PNG와 일치하는지를 verification.json에 기록.
  기술 검사 통과가 사용자의 미술/자연스러움 승인을 뜻하지 않음.

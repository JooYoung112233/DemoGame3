# 굴쥐·갱도 리소스 작업 및 검수 기록

2026-10-03. 최종 굴쥐 납품 원본은 ../정수리/굴쥐-v1/README.md를 따른다. 이 폴더의 원본-PNG/게임크기-PNG는 작업 초반 시험 출력이며 최종 납품이 아니다. 작업전-백업과 작업전-해시.json은 되돌리기용 원본 보존본이다.

## 맵 변경

Assets/Scripts/Game/Infra/ShapeSprites.cs의 기존 생성 텍스처만 조정했다. 흙바닥의 고주파 노이즈·자갈·가는 균열을 줄이고 큰 흙 얼룩을 유지했다. 석벽은 작은 조각 반복을 줄이고 더 큰 돌 덩어리와 줄눈으로 정리했다. 바위는 큰 면으로 묶고 입자 대비를 낮췄다. 목재 단면은 나이테를 성글게 하고 잔노이즈를 줄였다. 맵 구조·문·기둥 위치·벽/장애물 충돌·광원·시야 규칙은 수정하지 않았다.

맵-PNG의 4장은 기존 런타임 생성 결과의 검수 표본이다. 대형 수제 배경 원화나 512px 타일 납품이라고 주장하지 않는다. 원본은 ShapeSprites.cs의 생성 함수이며 색·밀도·결을 매개변수로 수정할 수 있다.

## 화면

- 검수/mine-entry-final.png: 실제 새 플레이의 시작 위치. 횃불 주변 흙바닥, 목재와 벽 확인.
- 검수/rat-corpse.png: 실제 전투 구역의 석벽·바닥·굴쥐 시체.
- 검수/rat-locomotion.png, rat-windup.png, rat-attack.png: 실제 플레이 상태.
- 검수/rat-runtime-observation.json: 최신 120표본.
- 검수/visibility.json: 시야 밖 적 11/11 숨김.
- 검수/mine-start-room.png는 임시 좌표(0,0) 이동 진단용이고 최종 시작 화면이 아니다.

## 한계

맵은 기존 절차 텍스처를 다듬은 1차 수정이다. 전체 칸 동선·모든 벽 뒤 가림·정예 밀집 전투는 재검수하지 않았다. 일반 굴쥐의 실제 걷기/준비/물기/처치와 입구·첫 전투 구역의 화면을 검수했다. 전용 Hit 자세는 기존 AI가 그 상태로 전환하지 않아 확인하지 못했다.

자동 승인 검토가 추가 npm PSD 검증기 설치를 작업 범위 밖 설치로 거절했다. 추가 설치 없이 기존 Unity PSD 임포터 검증으로 대체했고, PSD 정상 가져오기와 합성 일치를 확인했다. 추가 설치 승인은 필요하지 않다.

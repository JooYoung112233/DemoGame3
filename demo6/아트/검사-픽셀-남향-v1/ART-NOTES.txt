검사 / 남향 도트 시안 v1 — 2026-10-02

사용자 요청: Pixel MCP 연결 뒤 우리 캐릭터로 다시 제작. 도트 표현 허용.
상태: 검토용 시안. 사용자 채택 전이며 Unity에는 적용하지 않음.

기준은 ../검사-남향-시점검토-v3/south-camera-study.png.
큰 갈색 머리, 내려다보는 시점, 크림색 목도리, 갈색 가죽옷,
화면 왼쪽 철제 어깨갑옷과 화면 오른쪽 검을 유지한 새 픽셀 드로잉.
원래 고해상도 원화를 축소 필터로 바꾼 것이 아님.

실제 제작 경로:
  draw_swordsman.py에서 정수 좌표의 픽셀 덩어리와 자세를 정의하고,
  로컬 stdio Pixel MCP의 draw_pixels로 실제 Aseprite 레이어/cel을 그림.
  레이어 생성, 팔레트, 프레임, 태그, 저장 및 내보내기도 MCP로 처리.
  현재 대화의 도구 목록에는 서버가 나타나지 않아 검증된 stdio 클라이언트 사용.
  생성 이미지나 기존 평면 PNG를 레이어 파일로 포장한 결과가 아님.

편집용 원본:
  south-idle.aseprite — 128 x 160, 정지 1프레임, 실제 12개 레이어.
  south-walk.aseprite — 128 x 160, 걷기 8프레임, 실제 12개 레이어.
  south-idle.png / frames/*.png — 같은 실제 픽셀 크기의 RGBA 출력.
  south-walk-sheet.png + .json — 가로 8프레임 시트와 메타데이터.

검과 어깨갑옷은 각각 독립 레이어이며 그 아래 팔/몸도 그려져 있음.
양팔, 양다리/부츠, 몸통, 벨트/가방, 목도리, 얼굴, 머리, 그림자도 분리.
PSD는 만들지 않았으며 네이티브 Aseprite 원본으로 편집함.

걷기:
  8프레임 x 110ms = 880ms 반복. walk_south 태그.
  착지/체중 받기/통과/올라오는 구간을 양발에 반 주기 차이로 적용.
  몸과 머리의 작은 상하/좌우 이동, 어깨 축, 반대쪽 팔의 스윙을 적용.
  검 든 팔의 흔들림은 왼팔보다 작게 설정.
  머리와 의상 색 덩어리는 프레임마다 새로 생성하지 않고 일관되게 유지.
  제자리 걷기 시안이며 실제 이동 속도와 발의 미끄러짐 검수는 Unity 단계에서 필요.

미리보기:
  review/south-walk-preview.gif — 어두운 바탕에 합성한 4배 확대 검수본.
  review/south-idle-preview.png — 같은 방식의 정지 검수본.
  review/*-4x.png/gif — 투명 출력을 최근접으로 4배 확대한 검수본.
  512 x 640 파일은 단순 정수 확대이며 고해상도 디테일 복원본이 아님.
  GIF는 반투명 알파를 지원하지 않아 배경 합성 검수본을 대표로 사용.
  투명 PNG 원본의 그림자는 별도 레이어와 알파를 유지.

검수:
  8프레임과 12레이어, RGBA 크기, 가장자리 잘림 없음, 재생 시간 확인.
  브라우저에서 GIF 로드와 서로 반대인 지지 발 자세가 바뀌는 것을 확인.
  기준 원화 SHA-256은 그대로 유지. 자세/미술 채택을 대신하는 검사는 아님.
  verification.json과 *-mcp-log.json에 기록.

현재 제작 범위는 남향 정지/걷기다. 다른 방향, 공격과 장비 종류 추가는 미제작.

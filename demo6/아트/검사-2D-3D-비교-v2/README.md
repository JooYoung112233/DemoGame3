# 검사 실제 3D 외형 수정 v2

2026-10-02. 사용자 피드백: 2D 시안과 실제 3D 결과의 괴리감이 큼.

- 기존 v1은 그대로 보존했다.
- 구를 겹친 머리를 연결된 머리 메시와 납작한 앞머리 조각으로 교체했다.
- 얼굴을 연속된 사각 면 위주의 턱·볼 윤곽으로 다시 만들고 눈·눈썹·코를 조정했다.
- 서로 겹치던 흉갑과 몸통을 분리하고, 어깨 보호대와 목도리의 모양을 수정했다.
- 장갑·엄지·손가락 표시를 추가했다.
- 모두 Blender 메시·재질 수정이며 생성 이미지로 렌더를 보정하지 않았다.

검수 판단: 처음의 각진 도형 느낌은 줄었지만, 2D의 손그림 질감·옷 형태·머리 흐름을 같은 완성도로 재현한 결과는 아니다. 현재는 단순 스타일의 3D 외형 시안이다. 리그와 공격 클립은 v1 초안을 유지하며 이번에는 애니메이션을 개선하지 않았다. Unity 연결도 하지 않았다.

- `swordsman-3d-v2.png`: 실제 렌더 1800×2048.
- `swordsman-3d-v2-alpha.png`: 투명 렌더, 같은 해상도.
- `swordsman-3d-v2.blend`: 수정 메시·재질·13개 뼈대·기존 공격 클립.
- `swordsman-3d-v2.glb`: 교환용 모델. Unity 임포트 미검증.
- `refine_swordsman.py`: 옆 v1 폴더의 원본 `.blend`를 읽어 수정본을 생성한다. 재실행하면 이 폴더의 v2 산출물을 덮어쓴다.
- `model-report.json`: 실제 정점·삼각형 수.

렌더에서 전신·검의 프레이밍을 확인했고, 저장된 `.blend`를 다시 열어 뼈대와 애니메이션 연결을 확인했다. 원화와 동일한 수준으로 완성됐다는 뜻은 아니다.

# 검사 2D / 실제 Blender 3D 비교 v1

2026-10-02. demo6 「버려진 갱도」의 제작 방식 비교용. 사용자 요청: 2D와 3D 검사를 각각 보고, 3D는 실제 Blender에서 생성 가능한 수준으로 제시.

## 비교 방법과 상태

같은 의상과 장검, 짧은 갈색 머리, 한쪽 어깨 보호대, 베이지 목도리로 비교한다. 사용자 미술 승인 전이며 Unity Main 씬에는 연결하지 않았다.

| 항목 | 2D | 3D |
|---|---|---|
| 제작 | 내장 image_gen, Blender 렌더를 복장·비율 참조로 사용 | Blender 4.5.9 LTS에서 Python으로 실제 메시 생성 |
| 원본 | swordsman-2d-source-v2.png, 1024×1536 RGBA | swordsman-3d.blend |
| 편집 범위 | 단일 래스터 이미지. 부위 레이어와 PSD 없음 | 73개 메시, 13개 뼈, 재질·카메라·조명 |
| 모델 규모 | 해당 없음 | 1,324정점 / 2,352삼각형 (작성 메시 기준) |
| 애니메이션 | 미제작 | Attack_01_Blockout: 32프레임 / 24fps |
| 제한 | 본 제작 시 더 큰 개별 부위 원본과 가려진 부분 보완 필요 | 부위마다 한 뼈에 고정한 단순 리그. 부드러운 관절 변형·손가락·표정·옷 시뮬레이션 없음 |
| 검수 목적 | 화풍과 외형 | 실제 제작 가능한 형태, 재질, 기본 관절 움직임 |

3D PNG는 Blender Cycles 렌더 그대로이며 이미지 생성 도구로 후처리하지 않았다. 3D의 단순함은 이번 직접 제작 시안의 수준이며 Blender 자체의 품질 상한을 의미하지 않는다. 공격은 동작 가능성을 보는 초안으로, 실제 전투 판정과 발 접지·관절 교차·타이밍은 후속 작업이다. 2D와 3D의 애니메이션 품질을 같은 조건에서 검증한 것은 아니다.

## 파일

- swordsman-2d-source-v1.png: 첫 2D 생성 원본.
- swordsman-2d-source-v2.png: 배경 알파 정리를 요청한 후속 생성 원본. RGB의 투명 픽셀에는 배경색이 남아 있을 수 있으므로 RGBA로 표시한다.
- swordsman-3d-portrait.png: 실제 3D 스튜디오 렌더, 1800×2048.
- swordsman-3d-alpha.png: 같은 모델의 투명 렌더, 1800×2048.
- swordsman-3d-game-angle.png: 더 내려다보는 게임 시점, 1200×1200.
- swordsman-3d-attack.gif: 640×640, 32프레임 Blender 렌더를 조립한 반복 미리보기.
- frames/: GIF의 원본 렌더 프레임.
- swordsman-3d.blend: 편집 가능한 메시·재질·리그·공격 클립·스튜디오.
- swordsman-3d.glb: 캐릭터·리그·애니메이션 교환본. Unity 임포트는 이번에 검증하지 않았다.
- build_swordsman.py: 모델과 렌더를 재생성하는 원본 코드. 재실행하면 이 폴더의 3D 산출물을 덮어쓴다.
- model-report.json: 실제 생성 시 측정한 정보.
- prompts.txt: 2D 생성·수정에 사용한 전체 프롬프트.

## 검수

Blender 렌더에서 전신과 검이 프레임 안에 있는지, 게임 시점에서 실루엣이 보이는지, 준비·공격 포즈를 확인했다. PNG 원본을 확대 보간하지 않았다. 2D는 목표 제작 원본 높이 1536~2048px에 비해 실제 인물 부분이 작아, 최종 애니메이션 원본이 아닌 디자인 시안으로 보관한다. 실제 분리 레이어나 PSD가 있다고 보고하지 않는다.

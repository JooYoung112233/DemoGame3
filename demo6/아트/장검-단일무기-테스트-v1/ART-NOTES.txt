장검 단일 무기 테스트 v1
2026-10-02

요청 범위
- 테스트용 장검 한 자루. 캐릭터·공격 애니메이션·등급 변형은 제작하지 않음.
- 공식 Aseprite 1.3.18.6-x64의 숨김 --batch --script 모드에서 픽셀을 직접 그리고 저장함.
- 이미지 생성 도구는 사용하지 않음. 사용자의 열린 Aseprite 문서는 건드리지 않음.
- 현재 채팅 도구에는 Pixel MCP가 노출되지 않았고, 샌드박스 MCP 실행은 사용자 설정 파일 접근이 거부됨.
  권한이 승인된 공식 Aseprite 배치 실행으로 제작·재열기·PNG 내보내기를 완료함.

기준
- 기획/타격감-리소스-명세.md: 오른쪽(+X) 제작, 몸과 무기/효과 분리, PPU는 실제 배치 후 결정.
- 승인된 검사 남향 시점 v3의 비례·의상·철색/가죽색, 픽셀 남향 v2의 기존 팔레트를 참고.
- LIVE49의 인물·화풍을 가져오지 않음.
- 기존 픽셀 v2는 채택 전 참고 자산. 이 무기의 합성 프리뷰가 캐릭터 승인이나 게임 적용을 뜻하지 않음.

원본과 크기
- longsword-east-test-v1.aseprite: 128x48, RGBA 32비트, 1프레임(100ms), 실제 레이어 5개.
- longsword-east-test-v1.png: 같은 크기 RGBA 투명 PNG.
- 보이는 픽셀 범위: x=13..113, y=14..33 (101x20px).
- 투명 픽셀 5,245개, 완전 불투명 픽셀 899개, 중간 알파 0개.
- 네 변에 투명 여백 있음. 칼끝 잘림 없음. 테두리 약 1px, 따뜻한 손잡이와 차가운 철 면을 분리.
- 오른쪽을 향하는 가는 장검. 외형 길이는 공격 판정 사거리 2.0유닛이나 찌르기 3.4유닛과 별개.
- 손 접점: 왼쪽 위 원점에서 (25,24). Aseprite slice 'hand_grip' pivot으로 보관.
- 태그: longsword_east_static. 공격 타격 프레임이 있는 애니메이션이 아님.
- 128x48은 이번 네이티브 픽셀 테스트 원본이며 일반 소품용 512~1024px 고해상도 원화가 아님.
  8배 프리뷰는 최근접 확대본으로, 고해상도 디테일 복원이나 최종 큰 원본으로 간주하지 않음.

검수 결과
- 저장한 .aseprite를 별도 Aseprite 배치 프로세스에서 다시 열어 크기·5레이어·1프레임·slice pivot 확인.
- 재열기 후 만든 review/reopened-native.png와 처음 내보낸 투명 PNG는 SHA-256이 동일함.
- 1:1 및 8배 프리뷰에서 칼날/손잡이/가드/끝의 실루엣을 확인.
- 손 접점 합성에서 장갑이 손잡이 앞을 가리고, 손과 검이 분리돼 떠 보이지 않는 위치를 확인.
- 실제 Unity 카메라·좌우 반전·공격 중 가림·회전 시 도트 품질은 아직 검증하지 않음.
- 게임 자동 임포트·코드 수정·기획 수정·커밋·Library/외부 업로드 없음.

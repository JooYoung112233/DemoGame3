# 검사 탑다운 한 방향 시점 시안 v1

2026-10-02. 사용자 요청: 한 방향으로 탑다운 view를 먼저 잡는다.

- 방향은 화면 아래쪽을 향하는 남향 대기 자세로 가정했다. 사용자 승인 전 시안이다.
- 기존 `../검사-2D-3D-비교-v1/swordsman-2d-source-v2.png`를 인물·복장·화풍 참조로 내장 image_gen에서 제작했다.
- 머리 윗면과 어깨가 보이는 내려다보는 각도로 바꾸고, 몸·발·검의 가독성을 확인했다. 정확한 카메라 투영각을 검증한 3D 출력은 아니다.
- 갈색 머리, 가죽 흉갑, 목도리, 한쪽 어깨 보호대와 장검을 유지했다. 검은 화면 오른쪽 아래로 내려 몸과 겹침을 줄였다.
- 원본: `swordsman-south-source.png`, 실제 1024×1536 RGBA. 확대·축소하지 않고 생성 파일을 복사했다.
- 알파 범위 0~254, 네 모서리 알파 0. 알파 128 초과 영역은 (98, 88)~(1010, 1297), 높이 1209px이다. 따라서 확대·부위 편집용 최종 원본 목표에는 못 미치며, 현재는 시점·자세 확인용으로 보존한다.
- 단일 PNG이며 분리 레이어, PSD, 리깅, 애니메이션은 미제작이다. Unity 씬과 기획서는 변경하지 않았다.
- `prompt.txt`에 실제 사용한 프롬프트를 보관했다.

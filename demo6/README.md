# Demo6

Unity 6.6 (`6000.6.0f1`) / Universal 2D로 시작하는 새 데모 프로젝트.

## 시작

Unity Hub에서 이 `demo6` 폴더를 열고 `Assets/Scenes/Main.unity`를 선택한 뒤 Play를 누릅니다. 현재는 2D 카메라와 기본 조명만 있는 빈 시작 씬입니다.

## 전투 손맛 시험 (1단계)

콘텐츠보다 전투를 먼저 검증하기 위한 시험장입니다. 드랍·장비·강화·층·마을은 일부러 넣지 않았습니다. 원화 전이라 모든 모습은 도형입니다.

- 열기: 메뉴 `Demo6/전투 시험 씬 열기` 또는 `Assets/Scenes/CombatTest.unity`를 열고 Play. 씬이 없으면 `Demo6/전투 시험 씬 만들기`(레이어 이름·2D 물리 설정도 맞춤).
- 조작: 이동 WASD, 공격 좌클릭(누르고 있으면 콤보가 이어짐, 자동 조준), 회오리 베기 우클릭, 검풍 Q, 구르기 Space, 물약 R, 무기 1·2·3(장검·대검·쌍검), 시험 패널 F1, 멈춤 P.
- 무기 콤보(1차 판정 반영): 장검 베기 2번 → 찌르기, 대검 큰 베기 2번 → 내려찍기, 쌍검 2연타 3번 → 회전베기. 0.5초 멈추거나 구르기·스킬을 쓰면 처음부터.
- 시험 패널: 층 기준(1~10층 몬스터 배율과 그 층 기준 장비), 몬스터 구성(굴쥐 떼, 굴쥐·뿔멧돼지·가시 궁수 수, 허수아비), 시원함 보강(처치 날림, 타격 파편, 다중 처치 연출, 연속 처치 숫자), 손맛 조절(히트스톱·넉백·화면 흔들림 배율, 피해 숫자, 효과음, 자동 조준 2차, 무적), 통계(초당 피해, 기본공격 가동률, 최고 연속 처치, 피할 수 있었던 예고 공격에 맞은 비율, 허수아비 30초 초당 피해).
- 그림·소리 교체 자리: `Assets/Data/Combat/CombatArtSet.asset`. 칸이 비어 있으면 도형과 코드 효과음을 씁니다. 무엇을 어떤 타이밍으로 만들지는 [타격감 리소스 명세](기획/타격감-리소스-명세.md)를 따릅니다(몸은 좌우 2방향, 베기 이펙트는 조준 방향으로 회전, 공격 클립의 타격 프레임은 판정 순간에 맞춰 재생). 패널의 '그림' 칸에서 도형 / 연결된 그림 / 시험용 그림을 바꿔 볼 수 있습니다.
- 수치는 [기획 2차](기획/버려진갱도-기획-2차.md) 3·4·5장 기준입니다. 규칙 코드는 `Assets/Scripts/Core`(Unity 없이 테스트), 전투 코드는 `Assets/Scripts/Game`, EditMode 테스트는 `Assets/Tests/EditMode`.
- 판정 질문(20분 해 보고): ① 굴쥐 무리를 벨 때 시원한가 ② 멧돼지 돌진을 보고 피하는 게 공정하고 재밌나 ③ 무기 3종이 확실히 다르게 느껴지나 ④ 자동 조준이 답답하지 않나.

## 적게·강하게 시험 (M0b ①)

탐험 중심 전환([3차 초안](기획/탐험중심-전환-3차-초안.md) 3-4, 7-1)의 전투 쪽 시험입니다. 같은 `CombatTest` 씬에서 시작하며, 기본은 '3차 값' + '앞뒤' 마주침입니다.

- 규칙: 패널 '규칙'에서 `M0a 값 / 3차 값`을 바꾸면 지금 구성을 다시 세웁니다. 3차 값은 1층 기준 멧돼지 2,000·궁수 600(굴쥐 160 그대로), 공격 기회 굴쥐 3·무거운 적 2, 강한 공격 예고끼리 0.3초 엇갈림. 허수아비는 규칙과 상관없이 버팀·무너짐 없이 초당 피해를 잽니다.
- 버팀·무너짐: 무거운 적·정예는 체력 막대 아래 버팀 막대가 보입니다. 버팀이 0이 되면 2초 무너짐(받는 피해 +30%, 다시 일어나면 버팀 최대치 +25%). 벽·기둥에 박은 멧돼지는 바로 무너집니다. 버팀은 마무리·검풍이 크게 깎습니다(장검 10·10·36, 대검 18·18·60, 쌍검 타마다 4·회전 12, 회오리 8, 검풍 40). 대검은 첫 바퀴 마무리에서 멧돼지를 무너뜨립니다.
- 새 패턴: 멧돼지 뒷발차기(등 뒤 2유닛 안에 1초 넘게 있으면), 궁수는 조준이 끊기지 않고 세 번째마다 꿰뚫는 화살, 가까이 붙으면 뒤로 뛰며 가시 덫.
- 마주침 4종: 앞뒤(멧1·궁1·쥐2), 정예(체력 ×3, '단단한'·'무리 거느린' 체크), 둥지(껍질은 부른 굴쥐를 1층 12마리·그 밖 10마리 잡아야 깨짐, 연속 처치로 회복 구슬), 잠든 적. 모두 쓰러뜨리면 2.5초 뒤 같은 구성이 다시 놓입니다.
- 기습: 잠든 적은 앞 6·등 뒤 3 안에서 플레이어를 보면 '!'를 띄우고 0.5초 뒤 깨어나며, 무리는 0.8초 더 늦게 깹니다. 깨기 전에 먼저 치면 버팀 피해 ×3(검풍·회오리 ×1.5, 한 번에 최대치의 70%까지).
- 선택 토글: 회피 반격(예고 공격을 구르기로 피하면 1초 안 첫 타 버팀 ×2), 멧돼지 약하게(1,600·버팀 70, 3차 값이 너무 질길 때 먼저 내릴 값).
- 마주침 기록(3차 값으로 끝까지 정리한 마주침만): 보통(앞뒤·잠든 적)은 시간 중앙(기준 12~25초), 체력 소모 중앙(5~15%), 첫 5초 안에 멧돼지가 무너진 비율(30% 이하). 정예는 정예를 무너뜨린 싸움 비율(70% 이상)과 시간(가안 35~40초), 둥지는 시간(가안 20~25초). '무적'을 켜면 체력 소모는 0으로 기록됩니다.
- 판정 질문(10분 점검): ④ 한 마리 한 마리가 기억에 남는가 ⑤ 마무리와 검풍을 아껴 쓰게 되는가 ⑥ 둥지가 아닌 보통 싸움도 끝날 때 시원한가 ⑦ M0a 굴쥐 떼 10분과 3차 앞뒤 10분 중 다음 날 다시 켜고 싶은 쪽은.
- M0a 비교: '몬스터 구성 (M0a 비교)'의 굴쥐 떼·섞기 등은 그대로 남아 있습니다.

## 던전 1층 시험 (M0b ②)

탐험 중심 전환([3차 초안](기획/탐험중심-전환-3차-초안.md) 2장, 7-2)의 탐험 쪽 시험입니다. 2층·마을·디스크 저장·강화는 아직 없고, 모든 모습은 도형입니다(리소스는 다음 단계).

- 열기: 메뉴 `Demo6/던전 시험 씬 열기` 또는 `Assets/Scenes/DungeonTest.unity`를 열고 Play. 씬이 없으면 `Demo6/던전 시험 씬 만들기`.
- 조작: 전투는 전투 시험과 같고, F 상호작용(누르기·길게 누르기), G 바닥 무기 바로 끼기, M 큰 지도(시간 멈춤), K 스킬, I 가방, F1 탐험 기록·시험 패널, Esc 창 닫기.
- 지도: 손으로 만든 1층 글자 지도 12칸(`Assets/Scripts/Core/Dungeon/FloorOneMap.cs`, 2-3 뼈대). 칸 하나가 화면 한 장(28×16)이고 카메라가 따라간다. 주 길은 입구 → 첫 공터 → 갈림 공터 → 분필 갈림길 → 계단 앞.
- 시야(좀보이드식): 벽이 시야를 가리고, 커서 쪽 130° 부채꼴 14유닛과 몸 둘레 2.5유닛만 지금 보인다. 안 가 본 곳은 검게 가리고, 가 봤지만 지금 안 보이는 곳은 어둡게(기억) 보인다. 시야 밖 적은 그리지 않고, 시야 안이라도 등잔·켠 벽 등잔 빛 밖이면 흰 눈 두 점만 보인다. 예고·투사체·빛기둥은 지워지지 않는다(시야 밖에서는 어둡게). F1 패널에서 시야·부채꼴을 끄고 비교할 수 있다.
- 어둠: 등잔 밝은 4.5 / 흐린 7.5, 싸울 때 +1.5, 벽 그림자, 빛 밖 밝기 0.08.
- 찾을 거리: 나무 궤짝 3·쇠 궤짝 2(등급색 빛기둥, 무기 공격력 숫자), 판자벽 뒤 숨은 방(일반 벽과 똑같이 보이고 바닥 먼지 줄·분필 화살표가 단서, 쳐서 부숨), 숨은 방의 곡괭이 → 금 간 벽 2곳과 광맥, 벽 등잔 4, 광부 명패·쪽지, 사건 '광부 도시락통'. 자물쇠 문·금고는 열쇠가 필요해 이번 시험에서는 잠겨 있다.
- 적: 칸마다 무리가 자거나 먹고 있다. 칸 경계 안에서만 알아채고 쫓으며, 칸 밖으로 4초 나가 있으면 제자리로 돌아가 다시 쉰다(체력·버팀 회복). 깨어 있는 무리는 칸 밖에서 친 공격을 '회피'한다(쉬는 무리를 밖에서 먼저 치는 기습은 된다). 곡괭이·광맥 소리는 가까운 무리를 깨워 입구에서 기다리게 한다.
- 권양기 말뚝: 닿으면 켜지고, F로 다른 말뚝 이동이나 '원정 다시 시작'(적·광맥을 다시 놓음)을 고른다. 쓰러지면 마지막 말뚝에서 다시 선다. 지도·연 궤짝·켠 등잔·능력·레벨은 남는다.
- 성장: 새 칸·궤짝·등잔·말뚝·숨은 방·처치로 경험치, 레벨마다 체력 +120과 스킬 점수 1(스킬 1줄 4칸: 넓은 회오리, 날 선 바람, 마무리 일격, 질긴 몸). 무기는 맨몸 100 + 무기 공격력, 시작은 일반 장검(공격력 200).
- 판정 기록: F1 패널에 7-3 기준(1층 시간 7분 ±25%, 전투 몫 25~35%, 새 것 간격 중앙 30초 이하, 가장 긴 빈 구간 60초 이하, 되돌아간 걸음 30% 이하, 막다른 곳 빈손 0)과 지금 값이 나온다. 계단을 쓰면 1층 기록과 판정 질문 10개를 띄운다. 패널에는 어둠 끄기·무적·지도 전부 보기·곡괭이 받기·칸 순간 이동 같은 시험용 버튼도 있다.

## 기본 설정

- URP 17.6 / 2D Renderer, Input System, uGUI.
- PC 기본 창 크기 1920×1080, 창 크기 변경 허용.
- 제품명 Demo6, 버전 0.1.0.
- Main 씬을 빌드 씬 목록에 등록.
- 씬·에셋은 텍스트 직렬화, `.meta` 파일 유지.
- Unity Pipeline `0.7.0-exp.1`을 통한 에디터 제어.

## 폴더

- `Assets/Scenes`: 씬
- `Assets/Scripts`: 게임 코드
- `Assets/Prefabs`: 재사용 오브젝트
- `Assets/Art`: 게임에 넣을 이미지
- `Assets/Audio`: 음악과 효과음
- `Assets/Data`: 게임 데이터
- `Assets/Settings`: 렌더링과 입력 설정
- `기획`: 게임 기획서와 밸런스 계산 스크립트. 현재 기준은 [버려진 갱도 기획 2차](기획/버려진갱도-기획-2차.md)와 [마을과 주민 이야기 1차](기획/마을과-주민-이야기-1차.md).
- `AgentScripts`: 에디터 작업용 스크립트. `SetupProject.cs`는 새 템플릿에 초기 설정을 적용한 기록이며, 개발 진행 후 재실행하면 제품 설정과 빌드 씬 목록을 초기값으로 바꿉니다.

이 프로젝트에는 게임 로직이나 기존 데모의 원화를 복사하지 않았습니다. 원화 제작 시 저장소 루트 `AGENTS.md`의 규칙을 따릅니다. 원화 원본과 편집 레이어는 별도로 보관하고, 인게임 자산만 `Assets/Art`에 넣습니다.

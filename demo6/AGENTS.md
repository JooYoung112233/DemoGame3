# demo6 작업 규칙

2026-10-04 최신 사용자 지시를 우선한다.

- 작업은 이 `demo6` 원본 프로젝트에서만 한다. 별도 Unity 프로젝트·검증 프로젝트·복제본이 필요하면 만들기 전에 사용자에게 이유를 설명하고 승인을 받는다.
- Unity 조작과 원본 쓰기는 한 세션씩 진행한다. 사용 중인 씬, 미저장 변경, 입력, Play 상태를 먼저 확인하고 보존한다.
- 검증용 가상 입력을 실제 사용자 입력 성공으로 보고하지 않는다. 검증 장치·콜백·장치 제한을 남기지 않고 실제 키보드·마우스 연결을 복구한다.
- 최종 GIF 미리보기는 대표 동작의 연속 10프레임으로 짧게 만든다. 긴 다중 구간 GIF는 새 전달물로 만들지 않는다.
- 현재 아트는 굵은 윤곽·큰 색면·낮은 잔디테일 기준이다. 기존 형태·크기·피벗·충돌·광원을 보존하고, 승인된 Aseprite 원본과 실제 분리 레이어를 유지한다.

## 탑다운 절대 품질 규칙 — 2026-10-06 사용자 지시

- 모든 새 리소스·모션·이펙트·환경·월드 표시 UI의 제작, 수정, 적용 전에 [탑다운 제작·검수 규칙](기획/TOPDOWN-QUALITY-RULES.ko.md)을 읽는다. 여기서 절대 규칙은 프로젝트 품질 완료 조건이며 상위 안전·권한 정책을 변경하지 않는다.
- 정수리에서 내려다보는 고정 게임 시점이 기준이다. 높이와 지면 투영, sorting layer/order/group, 몸·발·머리 및 환경과의 가림을 매번 점검한다. 바닥 Telegraph/마커가 머리 위에 덧그려지면 실패다. 어둠 위 표시를 이유로 신체 위에 올리지 않는다.
- 무기는 blade face/edge 각도·손 그립·높이·몸 관통, 장식은 등/정수리 투영·몸과의 가림, 그림자는 지면 부착, 환경은 캐릭터와 같은 투영을 검수한다. 화면 고정 HUD와 월드 표시를 구분한다.
- 완료 전 `node AgentScripts/topdown-quality/check.cjs`를 실행하고 결과를 남긴다. 고정 카메라의 실제 게임 크기에서 캐릭터/오브젝트 중첩, 방향 변화, 동작 전 구간을 시각 검수한다. 자동 검사 통과만으로 시각 검수 완료를 주장하지 않는다. 미검수 항목이 있으면 완료 대신 보류로 보고한다.
- 선택적 로컬 변경 훅은 `node AgentScripts/topdown-quality/check.cjs --watch`이다. 실행 중인 터미널에서만 자동 재검사하며 상시 설치 훅이 아니다. 실행 방법·검사 범위·연결 증거는 위 규칙 문서를 따른다. Unity 소유 세션과 조율 없이 Editor 코드 설치·재컴파일·Play 조작을 하지 않는다.

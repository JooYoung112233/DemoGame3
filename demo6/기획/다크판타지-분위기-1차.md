# 버려진 갱도 — 다크 판타지 분위기 1차

요청: "약간 묵직한 다크 판타지 RPG 느낌은 너무 약하네" (2026-10-03, 던전 1층 시험 뒤).

상태: **방향 확정, 코드로 먼저 입힘(그림·소리 리소스 전).** 리소스 단계에서는 이 문서를 화풍·소리 기준으로 쓴다. 원화 원본·납품 규칙은 저장소 루트 `AGENTS.md`를 따른다.

| 무겁게 할 곳 | **화면 분위기, 소리, 전투 무게, 글·화면 연출 넷 다** |

## 지금이 가벼운 까닭 (진단)
- 화면: 밝은 베이지 원 캐릭터, 바둑판 바닥, 따뜻한 등잔만 있고 색 보정·비네트·먼지가 없다.
- 소리: 처치는 위로 튀는 '뾱', 줍기는 '띵띵', 레벨업은 밝은 장조 화음. 배경음과 발소리가 없다.
- 전투: 맞아도 흰·몸색 파편뿐이고, 쓰러지면 날아간 뒤 사라져 흔적이 없다.
- 글: "냠", "남은 주먹밥이 아직 따뜻하다…?" 같은 가벼운 문구, 기본 글꼴, 밝은 화면 틀.

## 기준 (디아블로 1·2 톤을 이 게임에 옮김)
| 영역 | 기준 |
|---|---|
| 색 | 채도를 크게 뺀다(색 보정 채도 −30 안팎). 그림자는 차가운 남청, 밝은 곳은 호박색. 대비를 올리고 전체 노출은 조금 낮춘다. 화면 가장자리 비네트, 옅은 필름 잡티. 빛나는 것(횃불·불티·빛기둥)만 번진다 |
| 빛 | 빛 밖은 차갑게(푸른 회색), 등잔·벽 등잔은 주황 횃불빛이 일렁인다(세기·반경이 조금씩 흔들림). 빨간 예고·등급색은 그대로 또렷하게(공정 규칙·2차 색 규칙) |
| 땅·벽 | 1~5층은 흙·나무 버팀목(3차 초안 2-1). 바둑판 대신 거친 흙바닥·돌 질감, 벽은 돌·버팀목. 바닥 장식: 뼈·해골·녹슨 사슬·부서진 나무·돌무더기·오래된 핏자국·거미줄. 장식은 걸음을 막지 않는다 |
| 공기 | 등잔 빛 속에 떠다니는 먼지, 횃불 위로 오르는 불티, 가끔 천장에서 떨어지는 흙먼지 |
| 소리 | 낮게 웅웅거리는 배경음, 멀리서 물방울·쇠사슬·삐걱임·짐승 소리, 동굴 울림(잔향), 무거운 발소리. 타격·처치는 낮고 둔탁하게, 줍기·레벨업·궤짝은 어둡게(낮은 종, 단조). 타격의 첫 딸깍(손맛)은 지킨다 |
| 잔혹 | 살 있는 적(굴쥐·멧돼지·궁수)을 베면 검붉은 피가 맞은 방향으로 튀고 바닥에 얼룩이 남는다. 처치하면 피 웅덩이가 번지고 시체가 남는다(원정을 다시 시작할 때까지). 크게 넘치게 베면 굴쥐는 조각난다. 무거운 적은 쓰러질 때 더 크게 튄다. 둥지는 흙·고름 조각. 플레이어가 맞으면 피가 튀고 화면 가장자리가 붉어진다 |
| 글 | 짧고 음울하게. 가벼운 말투·말줄임 웃음을 뺀다. 인물 이름은 쓰지 않는다(화자 이름 공개 규칙). 기획 이름(굴쥐, 뿔멧돼지, 광부 도시락통 등)은 그대로 두고 설명·알림만 바꾼다 |
| 화면 연출 | 층 이름 카드는 크게 천천히("제1층 — 입구 갱도" + 음울한 한 줄). 쓰러지면 붉게 어두워지며 큰 글자. 레벨업은 낮은 종소리와 함께 무겁게. 화면 틀은 검은 쇠·뼈색, 체력은 짙은 피색. 제목 글꼴은 바탕체 계열(없으면 기본) |

> **전투·보스·무기 다듬기 1차로 바뀜 (2026-10-04):** 위 '빛' 줄의 값(탐험 중 / 싸울 때 나눔, 빛 밖 밝기, 비네트·잡티) → [전투·보스·무기 다듬기 1차](전투-보스-무기-다듬기-1차.md) 1-3, 6-5. 본문은 판정 뒤 고친다.

## 지키는 것
- M0a 손맛(콤보 타이밍·히트스톱·넉백·흔들림)과 공정 규칙(빨간 예고 100%, 눈 두 점, 좀보이드식 시야)은 그대로다.
- 등급색 5가지는 장비에만 쓴다(2차 색 규칙). 피는 등급색 빨강·주황과 헷갈리지 않게 검붉게(#4A0606~#8A1010).
- 전투 시험장(`CombatTest`)은 손맛 비교용이라 후처리·잔향은 던전에만 넣는다. 피·시체·소리는 둘 다 같지만, 전투 시험장의 시체는 쌓이지 않게 25초 뒤 사라진다.
